## ⑤ 踩过的坑（绝对不要再踩）

1. **P7 那类"拿真实书库跑一遍"的提议不要再提。** 用户明确否决：`content/小说/` 有成人向书籍，
   不希望被 AI 读取。边界写进了 `AGENTS.md` 禁区，**不因"只读不写""本地不外传"而放宽**。
   所有自动化样本一律合成（现造 `tempfile` KB_ROOT）。
2. **度量类：先跑控制组、先测噪声地板。** 变异测试曾因我自己新增的一次 `Path.unlink()`
   撞上 I4 白名单 → 控制组红 → 一批 18 个变异体被虚报成 100% 杀死。视觉回归同理：
   第一版用 imgdiff 默认 2% 容差 + "占比 ≤0.05%"，把一次真实的模板改字读成了绿；
   实测两次截图 AE=0~1，阈值才定成 AE ≤ 2。**没测过自己 harness 的噪声地板，就没资格定容差。**
3. **`pathlib.read_text()/write_text()` 会把 LF 变成 CRLF。** 实测 `static/style.css` 凭空多 1479 个 CR，
   `git status` 亮 M 而 `git diff` 为空。一次性脚本改源码一律 `read_bytes/write_bytes`，
   改完 `git status --short <file>` 确认。
4. **bash heredoc 里的中文和反斜杠会被切碎**（多次 SyntaxError、bytes 装不了中文）。
   改源码/写中文文案一律用 Edit/Write 工具或 `.qa/*.py` 脚本文件。
5. **测试的 print 必须 GBK 安全**，而且"数据驱动的字符"挑不干净 —— 浏览器返回的 U+FFFD
   曾让红测试在报出名字之前就崩。修法是打印路径上过一道 `_safe()`。
6. **浏览器侧测试的临时 KB_ROOT 必须复制 `static/`**，否则 `create_app` 的 static_folder 缺失 →
   页面 `<script>` 全 404 → "每个样本都 error"却看着像通过。同理：**只断"不抛"是假网**，
   每个样本都必须有可判定的结论。
7. **改过 `app/` 源码后旧变异 manifest 立即失效**（按字符偏移定位，源码挪位即失准）：
   动过源码 → `mutate.py manifest` 重生成 + 逐条校验偏移，再谈复跑。
8. **多会话共享工作区**：只提交自己改过的文件（显式 pathspec），绝不用 `git reset/checkout` 去动
   别人的 WIP。别人 WIP 把钩子顶红时，用 `git worktree add ../.kb-head-wt --detach HEAD` 在干净
   HEAD 上复跑自证清白（本轮就这么确认过一条 archify 报错不属于我）。
9. **"绿得可疑"的两种具体形态**：判据写成"输出含不含某子串"（删掉修复也过）；
   JS 返回对象里残留初始字段让 Python 端 `== 0` 恒真（断言空转）。删判据要同时删两边字段。
