1. **隐藏类判据必须落在"用户点得到点不到"上**。选择器把 class 写成 id 不报错、只静默不命中 —— 轮次 51 那份 HIDE 清单里躺了一条死的，公网因此挂了一年不到两颗假引擎钮（台账 §6 第 108 行）。

3. **Git Bash / MSYS 会改写形如 `/xxx` 的 argv**，Windows 版 Python 收到的是 `C:/Program Files/Git/xxx`。任何接受 URL 前缀的脚本都要自己拒绝畸形值，别指望文档提醒（台账 §6 第 110 行）。本机跑导出器：`MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL='*' py -3 scripts/export_static.py --out site --base /knowledge`。
4. **服务端渲染的字符串在静态产物里是快照**：`request.host`、当前文档名、任何"跟着实例走"的取值，都必须在只读层重算，否则发到公网就是假信息（台账 §6 第 111 行）。
5. **状态栏文案要量几何，不能只看"对不对"**：新句子比本地长，375px 档溢出就翻倍。`.qa/sb_geom.js` 一次求值取全部矩形，七档跑。
6. **批量文本手术会把引号写重**：本会话用脚本给 16 行加 `roHide` 时把 `label: "X"` 写成 `label: ""X"`，靠 `git diff` 逐行看才发现。改完必查 `grep -c 'label: ""'`，且脚本读写一律走字节、绝不 `write_text`（会把 LF 变 CRLF，diff 假红）。
7. **`git status --short` 干净 ≠ 没删错东西**：删 knowledge-site 前那条"0 个未推送提交"是拿**陈旧的 remote-tracking ref** 比的，远端其实已经不存在。判仓库在不在必须 `ls-remote` 现问服务器 + 拿一个已知公共仓做对照（AGENTS 跨机器坑那条）。
