## ⑤ 踩过的坑（绝对不要再踩）

1. **无头浏览器里 `.focus()` 不一定送 focus 事件**。这台机器上 `document.hasFocus()` 是 `false`，`inp.focus()` 只把 `activeElement` 挪过去，`addEventListener('focus')` 收不到 —— 而标签补全是**懒绑定**（首次 focus 才 `TagSuggest.bind`）。表现就是"浮层永远弹不出来"，看着像产品 bug，其实是测试环境。判据：给 `TagSuggest.bind` 打桩数调用次数（`focus()` 后 0 次、补一次 `dispatchEvent(new FocusEvent('focus'))` 后 1 次）。**真人用鼠标点进去一定会发 focus**，所以这是补环境的缺口，不是绕过缺陷。
2. **`evalcdp.mjs` 的视口只有 ~764px 宽**，右栏在那一档没有布局：元素 rect 全是 0、`focus()` 无效。凡是依赖侧栏/浮层定位的行为断言，都用 `scripts/agent/geom.mjs <url> 1600 @expr` 钉一个桌面宽度跑（geom 已支持 `awaitPromise`，能跑 async 表达式）。
3. **要断"中间态"的探针必须分两趟跑，中间由 Python 查磁盘**。收件箱 purge 的"确认词写错 → 不该删"合成在一趟里时，第二次（正确词）尝试紧接着把文件删了，Python 检查永远看到最终态 → 那条断言恒假（第一版就这么假红过）。
4. **破坏性探针一律排最后**。第一版把删除排在看板抽屉之前，等抽屉去 `/tags` 时承载「渲染」标签的两篇文档已经进 `_trash/`，标签云里没那个胶囊 → 6 条集体假红。
5. **Python 字符串里写 JS/CSS 常量必须 raw**。`\n` 会被 Python 先吃掉，落到页面就是未闭合字符串 —— 这就是 §6 第 32 行那个"从来没生效过"的成因，而且它能潜伏多年全靠"没人点过那个图"。
6. **对照组不能省**：注入类逻辑要同时断"该注入的注入了"和"不该注入的没注入"，否则"无条件注入"也算绿（`has_mm = True` 变异就是专门用来验这条的）。
7. **别用 `grep` 读中文测试输出**：控制台是 GBK，中文断言名会花屏，`grep "状态栏"` 找不到 ≠ 没失败。落文件后用 `io.open(..., encoding='gbk', errors='replace')` 读，或只看退出码。
8. **一次只跑一个浏览器套**：P5 / js_props / ui_behavior 都要起 headless Chrome + 临时实例，并发会互相顶红（本轮又踩到一次输出交错）。
9. `content/小说/` 不读、不写脚本、不再提议（用户定的边界，AGENTS 禁区）。本套所有语料都是 `tempfile` 现造的合成样本。
