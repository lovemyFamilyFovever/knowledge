## ⑤ 踩过的坑（绝对不要再踩）

### 语料结构（架构师实测推翻假设，重要）

- `content/baike/` 是 **433 个文件、3 种互不兼容格式**：
  - **A 标准词条式**（≈215 篇）：`## 定义` 下是 `**一句话定义：**` **粗体行，不是 H2**；`## 常见误区` 是 H2，条目是 `- ` 列表；`## 相关术语` 是顿号分隔的 `[[双链]]`
  - **B 篇章式**（≈20 文件，一文件 8~20 词）：`## 术语名` + 粗体小节，冒号有「在 `**` 内」和「在 `**` 外、值在下一行」**两种写法，都必须支持**
  - **C 教程长文**（≈185 篇）：无可抽卡结构，**整篇跳过**（硬抽会产出噪音卡）
- `content/interview/` 有 **4 种格式**：
  - I-1 `### 题目N：标题` + `**题目描述：**`（有答案）
  - I-2 表格清单式 `| 1 | 题面 | 中级 |` —— **全篇只有题面没有答案**（`has_answer=0`）
  - I-3 扁平纯文本式（HTML 抓取压平，无任何 markdown 标题），题面以 `？` 结尾
  - I-4 `### Q1: 标题` —— 最初漏了这种，补上后 `interview_qa` 从 389 → 554

### 代码陷阱

1. **`_root` 哨兵值被安全守卫误杀**：`store.find_doc()` 开头 `if domain.startswith("_") or sub.startswith("_")` 本意挡 `_trash/_inbox/_meta`，结果把两段 rel 的 `sub="_root"` 一起拒了 → 17 篇域根文档全部 404。修法是显式放行 `_root`。
2. **`main` 缺 `single` 类 = 白屏**：`style.css:187` 给 `main{}` 默认上了 workbench 四栏网格（240px 300px 1fr 264px），新页面不加 `class="wrap single"` 会被挤成 **18px 宽**。**DOM 断言全过、文本断言全过，但肉眼完全看不见** —— 「元素存在」和「元素可见且尺寸合理」必须分开断言。
3. **`main.single` 改 flex column 又引出新 bug**：内部带 `overflow != visible` 的子块（`.kb-gl-buckets`）min-content 归 0，被 `flex-shrink` 无限压缩 → A–Z 索引条被挤成 12px 高、字母裁切不可读。已用 `main.single > *{flex:none}` 兜底。
4. **`[hidden]` 会被作者样式压过**：`.kb-grades{display:grid}` 让 `hidden` 属性完全失效 → 未翻面就显示评分按钮。已用全局 `html [hidden]{display:none}` 修（特异性 0,1,1）。
5. **`clamp(undefined, .85, 1.6)` 返回下限 0.85，而 0.85 是 truthy** → `clamp(...) || DEFAULT` 永远不生效，首访用户拿到 0.85× 字号。字段缺失必须显式回落。
6. **编辑器「打开即保存」会脏语料**：`openEditor` 用 `JSON.stringify` 重建 frontmatter → `tags: [a, b]` 被写成 `tags: ["a","b"]`。违反不变量 1。修法：从 `/raw/<rel>` 取原始 frontmatter 块原样回填。
7. **`due()` 会饿死队列**：没有到期卡时仍按 `new_ratio` 打折，1700 张新卡的库里 `?limit=20` 只返回 6 张。改成「没有到期卡时新卡填满队列」。
8. **端口 5001 残留进程接走请求**：前几轮起的服务没死干净，两个 python 同时 LISTENING，请求被旧进程接走，导致改动"看起来没生效"（曾 5 次里 2 次返回旧数据，差点误报成功）。**起服务前先 `netstat -ano | findstr :5001` 确认只有一个。**

### 环境

- **仓库里没有 `.python\python.exe`**（AGENTS.md 说有，实际不存在）。可用的解释器是系统 Python `C:/Users/Administrator/AppData/Local/Programs/Python/Python313/python.exe`（有 Flask）。
- **本机 `git config core.hooksPath` 原本是空的**（AGENTS.md 说已设置，实际没有），pre-commit 一直没生效。已修为 `.githooks`，并把 `.githooks/pre-commit` 的解释器探测改成逐个候选 `import flask`（因为默认 `python` 指向一个没装 Flask 的运行时）。
- **shell stdout 抓取不稳**：在这台机器上 Bash/PowerShell 的输出经常空返回。关键结果要**落文件再读**（`Set-Content` + Read），不要依赖直接输出。另注意 PowerShell `Set-Content -Encoding UTF8` 会带 BOM，写 git commit message 时会导致 `锘縡ix` 这种乱码，用 `git commit -F` 或注意编码。
