## ⑤ 踩过的坑（绝对不要再踩）

1. **探针里把元素选择器传给只吃元素的读数函数 → 读出一堆空串**：13 条断言集体假红，
   更糟的是「等文字变了」的轮询两边都是空串 → 立刻为真，什么都没等到就往下走。
   读数函数写成 `typeof e === 'string' ? q(e) : e` 两栖；隐藏容器里的文字要用 `textContent` 读
   （`innerText` 对 `hidden` 返回空）。判据依赖"某段文本会变"时，**先自证那段文本读得出来**。（§6 第 86 行）
2. **「已与 Rust tokenizers 交叉验证」在注释里躺了 unknown 个轮次，从没有断言真跑过**：第一次真跑就抓到
   正文里字面 `[CLS]` 被拆成 `[`+`[UNK]`+`]` 三块，而参考实现当它是一个 special token（真实语料 4 篇命中）。
   **注释里的"已验证"不是证据**，交叉验证必须是每次跑的断言。（§6 第 87 行）
3. **判据依赖的语料形状会被上游探针消耗**：复习页探针单跑 4 张卡很稳，全量跑只剩 3 张
   （探针 12 把一张卡「加入复习」后它就退出队列了），于是跳过走到队尾、底部条被清空 → 三条以看不懂的形状红。
   补语料余量 + 加一条**前提断言**（队列 >= 5）。"单跑绿、全量红"必查这个。（§6 第 88 行）
4. **本地兜底过滤会掩盖"参数没传给后端"**：`search.js` 在 `renderResults` 里留了一层本地过滤（B19），
   所以删掉 `params.domain = …` 之后**行数与接口仍然完全一致**，变异体活了下来。
   只有断言**发出去的请求 URL 带着 domain/tag** 才杀得掉。凡"真相在服务端"的判据，都要有一条看线路的断言。
5. **变异锚点要按工作区的实际换行拼**：`static/pages/governance.js` 在检出时是 CRLF，
   按 `\n` 拼的跨行锚 `count()` 得 0，被误报成「锚点不唯一」，看着像这个变异体构造不出来。
   绝不要为了迁就脚本去改文件换行（那会让 `git status` 亮一片假改动）。（§6 第 90 行）
6. **同一套浏览器套件不能并发跑两趟**：`run_expr` 把 JS 写到固定路径 `.qa/behavior-expr.js`，
   第二趟写进去的是它自己的表达式，第一趟随后求值的就是别人的 JS —— 症状是莫名红 + 莫名崩，
   两趟结果都不属于自己测的东西。已改按 PID 命名；pre-commit 在跑时别再另起全量。（§6 第 91 行）
7. **`toast` 会被后一条覆盖**：`batchDead` 报完「转为纯文本完成：成功 1 处」后立刻 `scan()` 再报一条
   「扫描完成：…」，屏幕上只剩后一条。要断批次报名就得给 `KB.util.toast` 装桩收集序列，别读 `#toast` 当前文本。
   （同类：`run_expr` 原先只捕 `ValueError`，页面抛异常时 `json.loads(dict)` 抛 `TypeError` 直接把套件崩掉 ——
   现在捕两类并打成具名红。）
8. **别把「共红 0」读成存活**：本轮 6 处第一轮判「存活/半红」，其中 4 处是我的**期望名单写错**
    （断言名里有 markdown 的 `**`、或那条判据结构上不可能红），2 处才是真缺口（第 4、7 条）。
    两种处理方式完全不同：改名单要复验，真缺口必须补断言。

8. **别把「全部跳过」那档说成"已复习完"**（本轮拍板改掉的第 ④ 条）：判据要**双向钉** ——
   新文案必须在、旧文案必须不在。只断"新文案在"的话，把分支条件退回 `false` 的变异体会活下来
   （实测：`var skipped = false` 让旧文案回来，只断新文案的检查当场变红 ✓，这就是那条断言的牙）。
   改文案前先看镜头矩阵：P5 的 `review_card` / `review_graded` 都不在 done 态 → 22 张 0 差异，不用刷基线。
9. **过滤器写错的变异驱动器会"零变异体报 OK"**：`python .qa/mutate_review.py 跳过态文案`
   在名单还没加进去之前跑了一趟，所有条目都被跳过，最后一行照样打 `MUTATION RESULT: OK` ——
   和"全杀光了"一模一样。两个驱动器现已加 `ran == 0 → 报异常退出 2`；
   任何"批量跑完给个总评"的脚本都该有这条：**一条没跑不等于全过**。

## 关键约定速查

- 新探针一律**接口当预言**：DOM 的行数/文字/数字都要能对上 `/api/...` 的同一次返回，
  不许写死下标（复习队列是 `ORDER BY RANDOM()`，向量索引/搜索结果都会随语料变）。
- 破坏性探针只动**自己的靶子**：`content/ui-r/gov/*`（批量处置断链）+ 逐字节断言
  「没勾选的那篇一个字节没动」「点取消什么都不写」。语料零污染是硬判据。
- 复习/进度环这类**分支依赖真实状态**的，走被测模块自己留的测试缝（`window.KBLEARN.refreshStats` + 打桩
  `KB.api.today`），期望数字写在 Python 侧 —— 打桩必须**自证生效**（先打桩再比引用）。
- 台账 §2 的 `不适用` 一格也不许空着：本轮把它查证成「P0 提取的幻影条目」并落到 §9 第 8 条。
