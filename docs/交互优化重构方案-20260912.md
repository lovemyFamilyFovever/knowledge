# 交互优化与重构方案（2026-09-12）

> 基于当日 HEAD（950c049）的前端全量代码审查：app.js 1140 行、kb-core.js 888 行、
> pages/{workbench,search,misc,learn,home,glossary,stats}.js、base.html、workbench.html、
> style.css/kb-core.css/pages/*.css。所有问题均给出代码位置，修复判据以"真的跑过"为准。

## 优先级定义

数据丢失 > 状态错误 > 反馈断裂 > 一致性 > 覆盖度。只按此排序推进，不按"改起来爽"排序。

## P0 硬伤（必须立即修）

### 1. 编辑器无 dirty guard，未保存内容静默丢失
- 证据：`kb-core.js:654` Escape → `window.closeEditor()`；`app.js:265` `navigate()` 开头无条件 `closeEditor()`；`closeEditor`（app.js:372）不比对 `#ed-text.value`。
- 后果：编辑中途按 Esc / 点左侧树 / j-k 路由跳转，未保存内容直接丢弃。语料是本仓库唯一事实源，这是唯一生产路径。
- 方案：`tryCloseEditor()` 统一入口——比较当前 value 与 openEditor 时快照；有差异弹 kbModal「保存并关闭 / 丢弃修改 / 继续编辑」；Escape、navigate、popstate、面板折叠全部改走该入口。Ctrl+S 后清除 dirty 状态。

### 2. deleteDoc 假乐观更新
- 证据：`app.js:503-526` 先改 TREE/列表/localStorage，再发 `/api/delete`；失败只 toast「文件仍在，可重试」，UI 不回滚。
- 后果：失败时列表没了、文件还在、错误状态被 `persistTree()` 写进缓存，直到刷新才恢复。
- 方案：改悲观更新——请求成功后再做本地移除 + persistTree；失败保持原状并给明确 toast。软删除本来就是移动到 _trash，本地网络下无感知延迟，不需要乐观。

### 3. toast 双实现竞态
- 证据：`app.js:7`（`t._h`）与 `kb-core.js:62-69`（`t._kbh`）共用 `#toast`，各自只清自己的隐藏 timer。
- 后果：两条 toast 先后出现时，第二条会被第一条的旧 timer 提前隐藏；移动/归档/合并路径全部双 toast。
- 方案：app.js 的 `toast` 改名 `toastLocal` 内部转调 `KB.util.toast`（kb-core defer 顺序在前，可依赖），删除 `_h` 路径。保留一个实现。

### 4. 学习闭环对 HTML/美化版文档断裂
- 证据：`kb-finish-bar`（已读完/已掌握）只渲染在 `renderArticle()` 的 md 分支（app.js:134-138）；interview 域默认走 pretty 分支（用户指定）。
- 方案：pretty 分支 iframe 上方同样输出 finish-bar；`refreshDocMark/renderDocMark` 已按 id 查按钮，天然兼容。

### 5. 搜索结果计数口径错乱
- 证据：`search.js:187-190` facets 多选时只有第 1 个值传后端，其余纯前端过滤；`:197` meta 显示后端 `j.total`。
- 后果：「共 N 条」≠ 屏幕列表条数；分面筛选语义不可信。
- 方案（二选一，推荐 a）：
  a. meta 改用 `picked.length`，并把后端 `j.total` 标注为"未过滤命中数"；
  b. 后端 `/api/search` 接受 `domain=a,b&tag=x,y` 多值，前端删掉本地过滤分支。b 是正解，但要动 app/store.py 查询层，放阶段 1。

### 6. kb-core 自己用原生 confirm
- 证据：`kb-core.js:839` `window.confirm("检测到 N 处断链…")`。
- 方案：换 kbModal（danger + 双按钮「仍然保存 / 回去改」）。kbModal 返回 Promise，`guardSave` 包 async 即可。

### 7. `/raw/` 拼接不 encode
- 证据：`app.js:335` `fetch("/raw/" + DOC.rel)`；同文件 docUrl/renderCrumb/openPretty 都逐段 encode，唯独这里裸拼。
- 方案：统一走已有的 encode 模式（顺手与第 8 条一起收拢成 util 单一函数）。

## P1 架构问题（重构主题，P0 修完立即启动）

### 8. 三层前端并行 + MutationObserver 补丁层
- 证据：workbench.js body 级 MutationObserver + `scheduleEnhance(setTimeout 60ms)` 事后清洗 app.js innerHTML 产物（cleanChars ◈→SVG、enhanceCodeblock）；`$ / esc / toast / icon / docUrl` 在 app.js 与 kb-core util 双实现；`_root` 补段逻辑 3 处（app.js:9、kb-core.js:57、navigate 局部 shadow app.js:282）。
- 定性：这是反模式。渲染方输出半成品，增强方赌时序打补丁；每个新页面脚本都要再学一遍这套隐性契约。
- 方案（阶段 1 主体）：
  - app.js 渲染函数直接产出 final-form DOM：icon() 已是 SVG，把 ◈（renderDocList:221 还在用）与 crumb 美化版按钮改成 icon；codeblock 包壳逻辑（语言标签+复制按钮）移进 renderArticle 后处理（同函数内，不用 observer）。
  - workbench.js 删掉 observer、cleanChars、enhanceCodeblock，只留密度切换、tabs 键盘、roam 增强（这三类是真·页面级）。
  - docUrl 唯一实现放 kb-core.util，app.js 引用；navigate 的局部变量改名。

### 9. 写操作后整页 reload（6 处）
- 证据：move app.js:943、拖拽 993-994、inbox 归档/单归档 misc.js:350/367、tag 合并 misc.js:180/209；全部带 900–1600ms setTimeout 再 reload，toast 随页面销毁。
- 方案：统一 `afterMutation({tree:true, list:true, doc:rel})`：重拉 /api/tree → renderTree + renderDocList → 当前文档受影响才 openDoc。palette 索引 sig 一并失效。删除全部 setTimeout+reload。

### 10. 缓存失效散落、无单一真相
- 证据：`TREE=null; localStorage.removeItem(LS_TREE); DIRTREE=null` 原样三处（app.js:941、992、misc.js:349）；palette 缓存（kb-palette）游离在失效体系外，靠后端 sig 校验兜底；`kb-core.js:499-501` 空 if 死代码。
- 方案：阶段 1 建 `static/kb-state.js`（或并入 kb-core 的 `store` 节）：
  - 唯一写入口 `invalidate(kind)`，kind ∈ tree|dirtree|palette|doc(rel)；
  - 后端所有写操作响应统一携带全库内容 sig（mtime 聚合即可），前端收到新 sig 集中失效；
  - LS_TREE 的 `sig:"(本地已改)"` 假标记废除——它本来就不参与校验。

### 11. 确认交互四套并存
- 现状：删除=armed 按钮 3s 计时（app.js:485-502）、拖拽移动=kbModal、标签合并=两段 kbModal、inbox 丢弃=kbModal、断链保存=native confirm。
- 方案：全部收敛到 kbModal(danger)（阶段 2 的 kbOverlay 前身）。armed-按钮模式的问题：3 秒计时不可感知、按钮文案原地变化无确认信息、跨面板状态要靠 syncEditorDelete 复制 innerHTML 手工同步（workbench.js:128-142，删掉补丁层后这套一起消失）。

### 12. 导航结构割裂
- 现状：复习(/review)、刷题(/quiz)、术语(/glossary) 只能从 home 卡片、命令面板、或 tree-foot 个别链接到达；顶栏被「统计 / 收件箱 / 全文检索就绪」三个 pill 占据，其中"全文检索已就绪"pill 的行为 = focus 搜索框（base.html:213），纯冗余；palette 跳转永远整页（kb-core.js:485），workbench 客户端路由与 palette 不互通。
- 方案：
  - 顶栏重排：brand(/home) + 一级导航组（阅读 / 复习 / 术语 / 统计页）+ 搜索框 + 设置/主题；收件箱保留但降级为 badge 链接；删"就绪"pill（状态挪进状态栏一行文字）。
  - palette execAction：目标是 `/doc|/browse` 且当前在 workbench → 调 `window.navigate(action, true)`；否则 location.href。
  - 全局「统计」弹窗与 /stats 页职责重叠：弹窗保留"快照"语义，标题加「查看月度趋势 →」链接到 /stats，不二选一。

### 13. 弹层无焦点管理
- 证据：kbModal（app.js:648）无 trap、无关闭后焦点归还；openCtxMenu 仅右键可达、无方向键；showSubStats/showGlobalStats 的 Esc 监听挂在 overlay 上但 overlay 不聚焦（`ov.addEventListener("keydown")` 而焦点在 close 按钮，实际能用是巧合路径）；rtab 是 div+onclick，`tab()`（app.js:90）不更新 aria-selected。
- 方案：阶段 2 做一个 `kbOverlay` 原语：trap Tab、Esc 关闭、关闭归还焦点、role=dialog；右键菜单加 Shift+F10/Menu 键唤起 + 方向键；rtab 换原生 button，active 时同步 aria-selected。

### 14. 加载反馈与防重复提交
- 证据：openDoc fetch 无 skeleton（app.js:295-296）；toggleFav/toggleDocMark/addNote 无 pending 态，可连点。
- 方案：openDoc 开头在 #article 放骨架（3 行灰条即可）；写操作按钮 disable 到响应返回。本地网络快，但 RAG/磁盘慢时静默失败必须可见。
