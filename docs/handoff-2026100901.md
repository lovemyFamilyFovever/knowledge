## 五、踩过的坑（绝对不要再踩）

**本轮新增五条**

1. **临时实例必须自己拷 `static/`**（§6 132）：`create_app` 的 `static_folder` 是 `<KB_ROOT>/static`，临时根没它就**每个 CSS/JS 全 404**，而 `shot.mjs` 照样逐张回 "OK"。任何出图的取证脚本要先 `fetch` 一张样式表与页面本身判 200，再进批次 —— **"截图成功"不等于"截到的是产品"**。
2. **撤掉一个元素，就要同时把拿它当锚点的断言搬走**（§6 132）：状态栏按需求隐藏后，四条老断言（`bottomGap==28`、`clipped`、`histBottom<=statusTop`、900 档 rail 高 40~80）读的是 0×0 矩形，**不报错、恒绿**。几何判据一律去量真正决定形状的节点（`.rtabs` 与视口）。
3. **满高抽屉必须把工具栏抬到它之上**（§6 133）：只改 `bottom:0` 会让页签被盖住，"再点当前页签收起"这条手势在手机上就没有落点了。让位靠抽屉的 `padding-bottom`，不是把抽屉截短。
4. **默认态只能有一个判据**（§6 131）：模板里两处 `active` 各写各的条件（一处按 `has_html`、一处硬编码）就是图 7 那类"页签亮 A、显示 B"的成因。开关态的同步要挂在**统一落点**（`navSheet` 关闭分支、`kb:article-rendered`），挂在按钮 onclick 上永远漏掉另外三条手势；同时"点外面"的白名单必须把开关按钮本身算成"里面"，否则捕获阶段先收、onclick 又顶开。
5. **代理端口每次现读注册表**（AGENTS 已改）：`reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" | grep -i ProxyServer`。本轮 7897 与直连**同时**不通、只有 7890 一次推成，"文档里写过的端口"本身就是过期信息。另：`env VAR=... python ...` 前缀在本机 Bash 通道会**静默 no-op**（rc=0、零输出），设环境变量一律 `export VAR=... && python ...`。

**仍然有效的旧坑（全文在台账 §6，这里只留最贵的半句）**

6. 覆盖 `display` 要数特异性：单类压不住 `.pill.icon-only`，也压不住 id 级 `#pane-toc.active` —— 抢显隐用 `:is(#a,#b)` 抬级别，写完在**两档宽度**各读一次 `getComputedStyle`（§6 127/128）。
7. 子元素的 `z-index` 再大也越不过父级的堆叠上下文：`main{z-index:4}` 困住抽屉，开浮层时把父级抬到 8（§6 129）。
8. 公网 `?v=` 不能依赖"渲染时才存在的文件"：导出是先渲染后拷 static，`av()` 拿 mtime 会恒 OSError → `=0` = 完全没有 cache-busting。凡"我改了你怎么没生效"，先 `grep -o 'static/[^"]*?v=[0-9a-z]*' site/index.html` 看产物 URL 有没有变（§6 128）。
9. 像素基线先测噪声地板；`--update` 顺手刷别的镜头时，字节变了而 AE=0 是编码噪声，退回 HEAD 不入提交；刷新判据是"差异只落在该落的地方"（本轮 7 张：bbox 恒 19x174+50+113 与 1248x216+50+71，裁图肉眼核对过）。
10. 清理/删除类脚本按"文件名"写回会被同名影子文件骗（§6 125）；判"删了"只看活文件字节与 `git status`。
11. 测"滚到某处"先问这一档做不做得到：`scrollTop` 越界被静默夹到 max，判据要断 `min(目标, 最大可滚)` 并配不带锚点的控制组（§6 124）。
12. 文本手术：读写走字节（`write_text` 会把 LF 变 CRLF 造假改动）、中文文案里别混 ASCII 双引号进字符串字面量、测试 `print` 必须 GBK 安全、台账 §0 表中间不能插空行（改完跑 `check_ledger_counts.py`）。
13. 提交纪律：显式 pathspec、绝不 `git add -A`、不用 `env -u` 前缀（见第 5 条）、宣称"已提交"前 `git log -1` 核实；`git status` 干净与 `log --not --remotes` 为空都**不能**证明远端还在。
