## 五、踩过的坑（绝对不要再踩）

1. **隐藏类判据必须落在"用户点得到点不到"上**：选择器把 class 写成 id 不报错、只静默不命中，公网因此挂过假引擎钮。

4. **"只在首次注入时算一次"的状态会僵在旧值**：「继续上次阅读」读完一篇回来还是 hidden。凡"每次进来看当前值"的东西都要在进来看的路径上重算。
5. **`margin:0 auto` 用在 flex item 上会退化成 fit-content**：`.land-grid` 是列 flex 的子项，居中要用 grid 自己的 `justify-content`（实测宽度从 291px 回到 420px）。
6. **像素基线先测噪声地板**：本地首页带粒子动画 + 跨文档 iframe，同页两次能差 3692 像素；钉死动画后同页 AE=0、改前改后左栏 AE=0。没有控制组就会把动画误读成回归。`--update` 会顺手刷别的镜头：字节变了而 AE=0 是 PNG 编码噪声，退回 HEAD 不入提交。
7. **判「过时」不能只看引用计数为 0**：被「沿用」二字间接消费的文档在 grep 里是隐形的（本轮差点删掉现行写作规范的两块承重板）。
8. **批量文本手术**：改完必 `git diff` 逐行看（本轮脚本把 `label: "X"` 写成 `label: ""X"` 16 处）；读写一律走字节，`write_text` 会把 LF 变 CRLF 造成假改动；台账 §0 轮次表中间不能插空行，改完跑 `check_ledger_counts.py`。

17. **删一个布局单元，必须同时搜"按数量写死的东西"**（§6 121）：`grid-template-columns` 的轨道数、`nth-child`、`order:` —— 只搜 class 名会全漏。需求 #11 删了第二列，`style.css` 里那条四轨声明活得好好的，1280 档正文被压成 264px 持续至今。
18. **测"滚到某处"先问这一档做不做得到**（§6 124）：短样本配高容器时浏览器把 `scrollTop` 写入**静默夹到 max**，不报错也不回读 —— "我连改三版实现回值逐字节相同"就是这条的指纹，而不是代码没跑。判据要断 `min(目标偏移, 最大可滚)` 并**先断可达**，再配一条不带锚点的控制组；顺带一条同族坑：探针 `init` 注入的桩必须自带回执（`addScriptToEvaluateOnNewDocument` 执行时 `document.head` 还可能是 null，`insertAdjacentHTML` 被静默丢掉，实测 `short=False` 才发现桩根本没跑）。
19. **清理脚本按"文件名"写回，而仓库里有同名文件 = 白干**（§6 125）：那 23 处 CSS 删在了没人加载的 `static/<页名>.css` 影子上，模板读的是 `static/pages/<页名>.css`；最阴的是 P5 与 A/B 全 AE=0 被读成"删除是像素中性的"，实际含义是"活文件根本没动"。**判"删了"只看活文件字节数与 `git status`**，脚本自报的清单不算证据。
20. **删一个子系统，要顺手 grep 它留下的所有"只有它生产的东西"**（§6 125 同轮）：错误码文案（6 条服务端已不再产生的 `ERR_TEXT`）、注释里已不存在的类、以及 `check_rewrite.py` 那句 `from app.cards import parse_file` —— 后者直接 ImportError 躺了一整天，因为**没有任何测试跑它**。被删模块的下游消费者要么跑一次要么 grep 一次，"没人报错"不等于"还能用"。
21. **"窄屏/首页这类按状态分叉的形状"要把每个状态都量一遍，不能只验最显眼的那一屏**（§6 126）：轮次 62~63 的移动端修复在**文档页**上量通了就收工，而公网首页是另一个状态（`kb-home-on`），那里右栏整块被裁掉、工具栏连带消失、1002 篇没有入口 —— 用户实拍才撞出来。同理，本地实例根本没有 `kb-home-on` 这个类，**浏览器两套套件结构上覆盖不到导出产物独有的形状**：改这类东西要么在本机 Pages 模拟器（junction + `serve404.py` + `geom.mjs`）逐状态量，要么就别宣称验过。
