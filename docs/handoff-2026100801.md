## 五、踩过的坑（绝对不要再踩）

1. **隐藏类判据必须落在"用户点得到点不到"上**：选择器把 class 写成 id 不报错、只静默不命中，公网因此挂过假引擎钮。
2. **只读裁剪光靠 CSS 清单必然漏**：动态生成的节点（右键菜单、拖拽、动态图、帮助面板）必须在生成处判开关。
3. **注入进来的 DOM 要连它所属页面的 CSS 一起带**：首页片段一度是裸元素，因为阅读壳只加载 `workbench.css`。
4. **"只在首次注入时算一次"的状态会僵在旧值**：「继续上次阅读」读完一篇回来还是 hidden。凡"每次进来看当前值"的东西都要在进来看的路径上重算。
5. **`margin:0 auto` 用在 flex item 上会退化成 fit-content**：`.land-grid` 是列 flex 的子项，居中要用 grid 自己的 `justify-content`（实测宽度从 291px 回到 420px）。
6. **像素基线先测噪声地板**：本地首页带粒子动画 + 跨文档 iframe，同页两次能差 3692 像素；钉死动画后同页 AE=0、改前改后左栏 AE=0。没有控制组就会把动画误读成回归。`--update` 会顺手刷别的镜头：字节变了而 AE=0 是 PNG 编码噪声，退回 HEAD 不入提交。
7. **判「过时」不能只看引用计数为 0**：被「沿用」二字间接消费的文档在 grep 里是隐形的（本轮差点删掉现行写作规范的两块承重板）。
8. **批量文本手术**：改完必 `git diff` 逐行看（本轮脚本把 `label: "X"` 写成 `label: ""X"` 16 处）；读写一律走字节，`write_text` 会把 LF 变 CRLF 造成假改动；台账 §0 轮次表中间不能插空行，改完跑 `check_ledger_counts.py`。
9. **删除前先立物证**：清单 + 校验和 + 可还原路径（bundle / 副本）验证过再动手；`gitignore` 里的东西要单独判"是否可再生"。`git status` 干净、`log --not --remotes` 为空都**不能**证明远端还在 —— 比的是本地那份可能陈旧的 remote-tracking ref。
10. **推 GitHub 先探活再选路**（7897 代理优先，不通就 `ls-remote` 实测直连）；提交前必 `env -u NO_PROXY -u no_proxy`；宣称"已提交"前复查 `git log -1`。
11. **别再提两件已否决的事**：为裸 `/doc/...` 网址新建用户站仓做跳转（用户判为多此一举，那条地址本来就缺 `/knowledge` 前缀）；重新引入任何 AI 出站能力（不变量 9）。
