## 五、踩过的坑（绝对不要再踩）

1. **往阅读壳里注入别的页面的 DOM，必须连它的 CSS 一起带**。首页片段注入后是一堆裸元素（搜索框退化成原生 input），因为壳只加载 `workbench.css`。适配器要 `ensureHomeCss()` 补 `pages/landing.css`（产物里已有一份，且它没有 `url()` 引用，前缀改写不涉及）。
2. **"只在首次注入时算一次"的状态会僵在旧值**。「继续上次阅读」在片段注入那一刻读 `localStorage`，读完一篇再回首页时钮还是 hidden —— 本地整页加载所以永远看不出。凡是"每次进来看当前值"的东西，都要放进 `showHome()` 这条路径重算（`syncContinue()`）。
3. **`margin:0 auto` 用在 flex item 上会让它退化成 fit-content**。`.land-grid` 是 `.land-panel`（列 flex）的子项，居中写成 auto 外边距后整栏被压到 291px；换成 grid 自己的 `justify-content:center` 才是要的 420px 轨道居中。**判据要量矩形，别只看截图顺眼**（`.qa/home_rect.js` 一次求值取全部 rect，公网/本地各跑一遍对照）。
4. **像素基线的噪声地板要先测**：本地首页带粒子动画 + 跨文档 iframe，同页两次都差 3692 像素；钉死动画后同页 AE=0，改前/改后左栏 AE=0 —— 没有这个控制组，"776 像素差异"会被误读成回归。
5. `--update` 刷基线会**顺手刷新别的镜头**。本轮 `doc_pretty_iframe` 字节变了而 AE=0（PNG 编码器噪声），按轮次 43 的口径退回 HEAD 不入提交；只提交真变的那一张。
6. 台账 §0 的轮次表**中间不能插空行**，且行与后面的 `>` 注记挨着；用 Edit 替换整行时容易把注记吞掉（本轮吞过一次，靠 `sed -n` 复查发现并补回）。改完必跑 `scripts/check_ledger_counts.py`。
