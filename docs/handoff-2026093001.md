## ⑤ 踩过的坑（本轮新增）

1. **heredoc 里写中文长段落，句中的 ASCII 双引号会提前终结 Python 字符串** —— 本轮台账 §6/§0 追加第一次就
   `SyntaxError: invalid character '、'`。修法：这类文本改用 Edit 工具，或中文里一律用「」而不是 `"`。
   （同族坑见跨会话记忆 `feedback-bash-heredoc-python-text-surgery`）
2. **删大文件里的整块，别用 `find(标记)` 的行号切片**。上一轮我已经栽过一次：从 `ASK_JS` 删到
   `def probe_wikilink` 会把中间的 `WIKILINK_JS` 一起带走。本轮一律先 `ast.parse` 拿
   `lineno/end_lineno`，再按名字删顶层节点，一次成功。
3. **`while lines[i].startswith("# ---")` 这类"往上收注释块"的写法会漏**：I10 的注释块里只有第一行是
   分隔线，其余是普通 `#` 行，删完函数体后留了一坨悬空注释 —— 靠"删完再 grep 一次功能名"抓回来。
4. **删功能后计数会连锁腐烂**：`test_ui_behavior` 少了两条探针 → I4 的 `unlink` 白名单计数立刻红；
   断言总数变了 → AGENTS 与台账的数字全要跟着改。改完必须 `check_ledger_counts.py` + 全量复跑，不能只改代码。
