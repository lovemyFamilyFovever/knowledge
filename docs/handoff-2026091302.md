## ⑤ 踩过的坑（本会话新增）

1. **`from x import y` 的模块级 try 探测不到懒加载依赖**：rag.py 在 `OnnxEmbedder.__init__`
   里才 `import onnxruntime`，SKIP 判据形同虚设。凡「缺依赖自动跳过」的测试，
   必须显式 import 到最深的重依赖
2. **钩子/脚本选解释器必须便携运行时优先**：GitHub Desktop、计划任务等环境的 PATH
   与交互 shell 不同，`python` 可能命中另一个只装了部分依赖的运行时
3. **交接文档的「工作区状态」保质期极短**：写完一小时后就有第三处在改。接手会话
   必须重新 `git status` 对账，不能照抄文档
4. **视觉 bug 两步定责法**：先 reduced-motion 截图看布局，再普通截图看动画；
   两图对照，不要混在一起猜
5. headless `--screenshot` 会把动画停在中间态（虚拟时间预算耗尽处的帧），
   「截图里字形残缺」≠「浏览器里也残缺」
