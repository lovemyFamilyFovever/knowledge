## ⑤ 踩过的坑（绝对不要再踩）

1. **`/doc/<domain>/<sub>/<name>` 是唯一文档路由**，两段式 URL 直接 404。给 UI 探针临时造样本
   必须放进三级路径；404 页面上没有被测控件，脚本会拿到一整套「合理的空值」——
   症状不是红，是静默空（台账 §6 第 76 行）。
2. **「函数有这个参数」≠「端点用到了这个参数」**。判据入参要有一份能区分传与不传的语料形状，
   否则变异体活着你却以为有人管（§6 第 77 行）。
3. **删类断言必须成对写**：先断"这一步之前它确实在"，再断"之后没了"。空集合上的"没有"是空气
   （§6 第 80 行，本轮变异 ⑳ 抓的）。
4. **度量脚本自己也要有"没跑"的判据**：套件路径拼错时输出里没有一条 FAIL，
   旧判据把「共红 0」读成「存活」。现在跑不出汇总行就判「运行异常」（§6 第 79 行）。
5. **AI 次数按"次"记，不按"篇"记**：一篇最多可能问两次（应引未引 + 矛盾），
   进度条与账本必须同口径；帽门的乘数是 `per_doc_calls`，抽样放大值只用于给人看花费。
6. **批量线程里不要按篇开 `index.db`**：会撞 watcher 的写锁（实测 37 篇卡 40s）。
   本轮给 `fts.search()` 加了可选 `con=`，整批复用一条连接，收尾关掉（`own` 标志，绝不 close 别人的连接）。
7. **中文串里不要出现裸 ASCII 双引号**（写测试名、台账文案都栽过：Python 语法直接崩）。
   另外别用 `head` 管道截 `git commit` 的输出——退出码会被吞掉；提交后一律 `git log` 核实落地。
8. **面板不在 P5 矩阵里 ≠ 没有布局风险**：520px 定宽头部多塞一个开关，像素基线永远绿，
   本轮改用矩形几何断言在探针里当场量（§6 第 81 行）。

- 「查与库内矛盾」是**用户勾出来的**：勾了才读索引配对，估算与帽门按每篇两次算；

  （措辞点明是从答复里推的，不冒充 AI 明说）；跑没跑都要在界面上报名。
- `indexes/ai.db` 是纯派生缓存，可随时删；建议 id = `sha1(kind|path|key)[:12]`，域级待办挂在
  `@domain:<一级域名>` 这个作用域键下（真实相对路径永不以 `@` 开头）。
