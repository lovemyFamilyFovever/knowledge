## ⑤ 踩过的坑（绝对不要再踩）

1. **（继承）`.html` 孪生遮蔽 `.md`**：store.py 同名解析存在 .html 就走 iframe，「改了 md 看不到效果」必查这条。本轮已全库清零，新语料禁止再生成整页 .html。
2. **提交删除时 pathspec 必须包含被删的 .html 本身**：`b1b3967` 只列了 3 个 .md，漏掉同批软删的 .html，被迫补一刀 `8ca7c7e`。正确做法：软删脚本跑完后用 `git status` 的 D 条目生成 pathspec 文件全量圈进提交。
3. **PowerShell 5.1 `Set-Content -Encoding UTF8` 带 BOM**：Python 按行读清单时首行含 `\ufeff` 导致路径匹配失败（软删脚本 SKIP）。清单/消息文件一律用 Python `write_text(encoding='utf-8')` 落盘。
4. **shot.mjs / evalcdp.mjs 共用 9333 调试端口**：残留 headless Chrome 的 localStorage 跨运行污染（主题态漂移、「点按钮切不了暗色」的伪影）。重拍前先清 9333 的 chrome 进程：`Get-CimInstance Win32_Process -Filter "Name='chrome.exe'" | ? { $_.CommandLine -match '9333' } | % { Stop-Process -Id $_.ProcessId -Force }`；暗色截图在全新实例上传 `clickSel=#theme-btn`。
5. **内容补齐 subagent 全部超时（20-43 分钟，卡在长文件读取/规划）**：按降级纪律不重派、主线补位。但注意残留 Agent 超时后仍可能落盘改动（patch-llm-part2 在主线提交后又改了文件）——收尾前必须重新 `git status` 查并发改动，逐行 review 对照 html 后再决定保留或丢弃，不能盲目回退也不能盲信。
6. **脚本判等的三类伪影（人工复核才定案）**：2-4 字符表头词在全文包含判定里天然难命中；html 状态表单元格与 md enum 注释是同义改写（「所需服务尚未就绪」↔「所有依赖服务就绪」）；md 反引号包裹的依赖关系（`` `Agent` 依赖 ``）会被朴素子串误判 MISS。脚本只做初筛，真删前必须人工看上下文。
7. **（继承早间）**难度徽章只认「初级/中级/高级」；禁 `--no-verify`；git index.lock 被占等锁不硬删；`content/_trash/` 被 gitignore；渲染层 style.css/app.js 单 agent 独占；PowerShell 内联中文脚本易碎，一律落盘 .py 再跑。
