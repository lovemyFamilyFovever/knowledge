## PURPOSE

个人知识库单一入口：博客、百科、agent 记忆、踩坑记录等全部语料以 **Markdown 文件为唯一事实源**。仓库提供两件事：
1. **迁移管线**（scripts/）：把外部语料（博客、百度百科、inbox 收件箱）清洗、归档进两层 taxonomy；
2. **本地阅读器**（app/，Flask）：浏览、双检索（FTS + 语义）、编辑写回、备注、收藏、收件箱工作流、阅读统计、SM-2 间隔复习（闪卡 + 面试题）。

内容资产（content/）与代码（app/scripts/static）严格分离；indexes/ 全部为可再生派生物。

## STACK

- **后端**：Python + Flask（唯一声明依赖 `flask>=3.0`，刻意保持零重依赖）
- **检索**：FTS 全文索引（fts.py，自建 index.db）+ 本地语义检索（rag.py：切块 → ONNX 嵌入 → sqlite-vec 向量库 rag.db），`?` 前缀切换语义模式
- **前端**：无框架原生 JS（static/app.js + pages/*.js 按页拆分），vendor 全部本地化（mermaid / echarts / marked / highlight / DOMPurify 的 min.js 旁挂）
- **数据**：SQLite 三库分治（index.db 全文 / rag.db 向量 / reading.db 阅读统计与复习进度），启动时按 mtime 自动重建派生索引
- **语料**：content/ 纯 Markdown，两层 taxonomy（7 域 × 子域，权威定义 content/_meta/taxonomy.json），Obsidian 直接作为 vault 共享同一份语料
- **质量**：ruff + tests/ smoke 测试（test_govern / test_learn / test_new_project / test_rag / test_reader）

## PATTERNS

- **派生即弃**：indexes/ 三库全部可再生（mtime 触发重建），唯一不可再生资产是 content/——备份策略只需保语料
- **单一事实源**：语料只有 .md（2026-09-18 全库 .html 孪生清零）；美化版 HTML 若再出现仅作迁移期过渡（片段走 Shadow DOM 内联、完整文档回退 iframe），终态是 markdown + 统一 .a-body 渲染
- **收件箱工作流**：content/_inbox/ 是新材料唯一入口，归档动作级联更新 FTS/双链/向量三索引，_trash/ 软删除
- **复习状态与语料分离**：SM-2 进度只写 reading.db，绝不写进语料 frontmatter（保证 Obsidian 侧零污染）
- **零构建前端**：无打包器，vendor 本地 min.js 旁挂 + 原生 JS 按页拆分；自研 kbModal 替代系统弹窗
- **脚本一次性**：scripts/ 迁移脚本独立无扇入（internal 层），跑完即弃不进运行时依赖

## TRADEOFFS

1. **零框架前端**：省掉构建链，代价是 app.js 手工维护 DOM/状态（3.5 万行规模的 static/ 主要体量在 vendor）。当前规模合理；若页面交互继续膨胀，考虑引入轻量视图层（如 petite-vue/Alpine）而非完整框架。
2. **本地 ONNX 嵌入**：语义检索完全离线（隐私优先），代价是嵌入质量弱于云端 API、首次建库慢。对个人语料规模（~700 文档）是正确取舍。
3. **SQLite 单文件三库**：部署为零、备份为拷贝；代价是无并发写（单用户场景无碍）。reading.db 丢失=统计与复习进度归零（README 已明示）。
4. **learn.py 已达 1,069 行**：复习调度/掌握度/quiz 三职责聚合，是全库最大模块。fan-in 高（19）说明被广泛复用；下一步若加功能，建议先把 quiz/掌握度拆出独立模块，避免继续膨胀。
5. **taxonomy 两层固定**：7 域 × 子域写死在 taxonomy.json；跨域主题（如"AI+安全"）只能挂单侧。可接受；跨域检索已由语义搜索兜底。

## PHILOSOPHY

- **语料是资产，代码是工具**：一切设计的最高原则是语料的纯净与可迁移（Markdown + Obsidian 兼容 + 零锁定）
- **离线优先**：检索、嵌入、复习全部本地可跑；网络只是锦上添花
- **可再生派生**：任何索引/缓存都设计为可随时删除重建，简化备份与故障恢复
- **小而完整**：Flask 单依赖后端 + 无构建前端，全库约 6,000 行业务 Python + 8 个页面 JS，一个人可维护
- **把「存知识」变成「练知识」**：闪卡/quiz/今日术语是第一公民功能，不只是阅读器
