首页右上角插画 · 5 个候选

选一个，告诉我编号
怎么看：这是「右上角 hero 区」的候选，渲染尺寸与实站一致（最大约 300px 宽）。
配色：全部用实站真实主题变量（--ill-* / --acc / --warn…），深浅主题都会自动适配——点右上角切换看看。
动效：带 parallax-layer 的元素在实站里会跟随鼠标做轻微视差。
技术：纯内联 SVG、零外部依赖、viewBox="0 0 340 260"（与原插画同尺寸，可直接替换）。
01叠书与微光极简几何
去掉人物，只留"积累"。三本书的层叠高度 + 一颗星，表达"读得越多越高"。几何、克制、占地小，最不容易出错。回「01」
02翻开的书与飞页动态
最有"动作感"。纸页从书里挣脱飞散，暗示知识被抽出来（正好呼应闪卡功能）。动势强，但飞行页片与背景的对比要留意。回「02」
03知识星座抽象网络
最贴"知识网络"这个隐喻。节点 + 连线 + 中心枢纽，对应双链、反链、术语门户。中性耐看、缩放不糊，但和"阅读"的情感连接弱。回「03」
04远山与日风景 / 积累
最"安静"。山象征长期积累，日象征每天一点（呼应"连续复习天数"）。用透明度拉开层次，没有细节噪音，窄屏也稳。回「04」
05夜读者氛围剪影
最有"气氛"。台灯光锥 + 阅读者剪影（没有五官，所以不会出现"脸画歪"）。一个人夜读的感觉，和"个人知识库"的私密气质契合。回「05」
