## T0 — 让我"能看见渲染结果"（这两天的根因，第一优先）

### ★1. Playwright（MCP 或 CLI）— 最重要，没有之一
- 是什么：无头浏览器自动化 + 截图 + 读 console + 点/悬停 + 抓网络。
- 解锁：我能 `打开 localhost:5001 → 截图存 PNG → 用 Read 看图`，从此宽度/对比度/对齐/动效**亲眼验证**，不再靠算 CSS 数值瞎猜；还能自动跑"点开统计弹窗""移动文档后跳转"这类交互回归。
- 装（MCP，右上角"添加"自定义 MCP，命令型）：`npx @playwright/mcp@latest`（先 `npx playwright install chromium`）。
- 或（CLI，我自己能调）：`npm i -D playwright` + `npx playwright install chromium`，然后 `npx playwright screenshot http://127.0.0.1:5001/home shot.png`。

### ★2. 浏览器连接器 / Chrome DevTools MCP
- 若"浏览器"连接器支持"打开 URL + 截图 + 读 console/network"，等价于 1。请确认它能否**返回截图给我**。

### 3. 计算机控制（市场里有）
- 兜底：整屏截图。用于看 Canvas/浏览器实际渲染。确认它能截图并让我读到。

### 4. SVG/HTML → PNG 光栅化工具
- `resvg`（`winget install Resvg`）或 `rsvg-convert`（librsvg）。
- 解锁：我手画的 SVG 图标能单独渲染成 PNG，我 Read 一下就知道图标画歪没画歪（这次"图标没居中"就是没法看导致的）。

### 5. 图像对比（视觉回归）
- ImageMagick（`winget install ImageMagick`，含 `compare`/`magick`）或 npm `pixelmatch`。
- 解锁：改动前后截图 diff，防"改 A 崩 B"。
