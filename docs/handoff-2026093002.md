## ⑤ 踩过的坑 / 该记住的判断

1. **移走数据 ≠ 移走边界**。禁区防的是"内容"，不是"目录在不在工作区" —— git 历史里那些书永远取得回来。
2. **搬家前先查 junction**。`content/` 下有过 junction 链（见 `tests/test_known_defects.py` 的 rmtree 前摘链），
   直接 `mv`/`rmtree` 会穿透删到别的盘的目标。
3. **格子数不动也要写一行**。这轮没新增/删除任何被覆盖的面，但"为什么不涨"必须落在 §0，
   否则下一个人会以为我漏更新了。
4. **别顺手删"现在空转"的配置**。`EXCLUDE_DIRS`、`"search": false` 这类是拦网，删它们不省任何东西，
   只是把回归风险留给未来。
