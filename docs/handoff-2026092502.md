## ⑤ 踩过的坑（绝对不要再踩）

1. **像素基线抓不到"两个矩形相交"**。压字这种缺陷在矩阵里是稳定地错、永远绿。判布局要用几何断言（`scripts/agent/geom.mjs`），别指望截图比对替你发现重叠。
2. **几何探针必须单快照**：第一版每个字段各自 `getBoundingClientRect()`，同一档连读三次给出三套数（页面在过渡中），断言随机红。改成"一次求值取全部矩形"后逐次一致。
3. **目测 crop 会报错对象和范围**：轮次 22 那条"1400~1600 压收藏"就是这么来的，实测区间是 1281~1796 且 1680 压的是「治理」。要么量矩形，要么别写进台账。
4. **派生不是免费的**：把域名单改成派生之后，小说域（全是 `.txt/.epub`、FTS 不收）会派生出一颗恒 0 结果的钮 —— 和原来"键名写错"是同一类缺陷，只是错在数据。派生必须同时回答"这个域有没有可检索的语料"，本轮的答案写在权威 JSON 里（`"search": false`），不在模板里开例外。
5. **动态内容会咬视觉回归**：状态栏一旦改成 `request.host`，那个端口号在 P5 里必然漂（临时实例端口现挑），必须进 `FREEZE_CSS`，同时补一条 e2e 断言接手它的正确性。冻结 = 放弃这块的视觉回归，这句代价要写在注释和台账里。
6. **断点边界要留呼吸**：临界算出来是 1796，但 1797~1840 只有 2~22px 的缝，视觉上和压字没区别。收口取 1836（= 2×(618+20)+560），并让断言直接判 `gap_nav ≥ 18`。
