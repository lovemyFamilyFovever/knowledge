# Buffer

## 一句话定义

在堆外存二进制字节序列的定长内存块。

## 面试官为什么问它

考的是你有没有处理二进制数据的经验（上传、文件、协议解析），以及知不知道它的分配成本。

## 30 秒版回答

JS 的字符串和数组表达不了原始字节，Buffer 就是 Node 提供的一段固定大小内存，用来读写文件、处理网络包、图片与上传流。要点是它不走垃圾回收堆所以分配贵——大 Buffer 频繁创建会造成压力；`alloc` 是清零的安全写法，`allocUnsafe` 快但可能读到上一块的残留数据。它和流是搭档：流按块喂，Buffer 是每一块的载体。

## 被追问三层时的诚实边界

我实际用到 Buffer 的是文件上传与导出接口里的类型转换和编码处理；`SlowBuffer` 与池化分配的内部机制我没有实操过，我的理解是 8KB 以下走内存池，这也是小 Buffer 频繁分配反而便宜的原因。
