# 浏览器渲染原理

## 一句话定义

解析成 DOM 和 CSSOM，排版算位置，绘制再合成上屏。

## 面试官为什么问它

这是前端的送分题也是筛选题：他想验证你知道「什么会阻塞渲染」，能顺势问到你 CSS/JS 放哪儿。

## 30 秒版回答

主流程是：HTML 流式解析成 DOM，CSS 解析成 CSSOM，两者都就绪才能构建渲染树；渲染树只包含可见节点，然后 Layout 算几何、Paint 分层绘制、Composite 由合成线程把图层变换拼起来上屏。阻塞点很清楚：外链 CSS 阻塞渲染，同步 script 阻塞解析（因为它可能改 DOM），所以 JS 用 defer、非关键 CSS 用媒体查询延迟。我还会区分 DOMContentLoaded 是 DOM 就绪，load 是所有资源就绪。

## 被追问三层时的诚实边界

我实际做的是首屏层面——脚本放置、关键 CSS、懒加载和骨架屏；合成层与光栅化的线程细节我属于读过没实操，我的理解是 GPU 线程不参与主线程的脚本执行，这是「前端单线程」说法的边界。
