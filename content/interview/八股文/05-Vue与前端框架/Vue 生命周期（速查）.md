# Vue 生命周期

## 一句话定义

组件从创建、挂载、更新到卸载的顺序阶段，每段留了钩子。

## 面试官为什么问它

他实际想问的是「你在哪个钩子里做什么」——尤其接口请求放哪、定时器在哪清、DOM 什么时候能读。

## 30 秒版回答

组合式 API 里关键是三个时刻：`onMounted` 时 DOM 已可用，适合初始化第三方实例和首次取数；`onUpdated` 很少用，因为要用它多半说明你该用 watch；`onUnmounted` 必须清理定时器、监听器、订阅，否则泄漏。选项式的 created/mounted/beforeDestroy 是同一套阶段的另一种命名。我还会补一句：setup 本身在创建阶段执行，所以顶层代码相当于 created。

## 被追问三层时的诚实边界

我实际踩过的坑是不清理导致的泄漏和挂载前访问未初始化实例；SSR 场景下生命周期只跑一半这件事我没有实操过，我的理解是那正是取数要放到 setup 顶层或用异步组件的原因。
