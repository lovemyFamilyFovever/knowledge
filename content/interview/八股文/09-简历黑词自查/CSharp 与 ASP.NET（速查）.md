# CSharp 与 ASP.NET

## 一句话定义

微软系语言与 Web 框架，早期我在那上面做桌面端和接口。

## 面试官为什么问它

简历有两段 C# 经历（桌面端、GIS 段的后端出图与 .ashx 交互），会被问「前端为什么懂后端」。

## 30 秒版回答

我的 C# 是工作里真用出来的：早年在医院项目做桌面端开发与实施运维，GIS 那段对接的是 ASP.NET 后端加一般处理程序（.ashx）返回 JSON，我用 jQuery 和 AJAX 调它。所以我理解那套服务端形态——会话、页面生命周期、处理程序返回数据、以及和 ArcGIS 服务出图的接法。这段经历对我的价值是：跨栈协作时我知道后端在做什么，接口怎么定最省事。

## 被追问三层时的诚实边界

我实际写的是 C# 桌面端与调试对接，ASP.NET 的 MVC 与实体框架这套我没有从零做过项目，我的理解是它和 NestJS 的思路接近：控制器加模型加仓储，只是形态更重、更依赖平台。
