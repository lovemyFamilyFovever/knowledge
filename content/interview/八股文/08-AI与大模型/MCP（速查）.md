# MCP

## 一句话定义

给模型接外部工具和数据的统一协议，一次实现多方可用。

## 面试官为什么问它

他想确认你知道 MCP 解决的是「集成爆炸」，以及它和 Function Calling 是什么关系。

## 30 秒版回答

Function Calling 是模型侧的能力——能表达要调用什么；MCP 是集成侧的协议——规定应用（宿主）怎么向服务器发现并调用工具、暴露资源与提示模板。没有 MCP 时，每个模型应用要为每个数据源各写一遍适配，是 M 乘 N 的问题；有了它，工具服务器实现一次，任何支持 MCP 的宿主都能用，等于 USB-C。代价也要讲：工具多了会挤占上下文、来源可信度与权限边界需要单独设计。

## 被追问三层时的诚实边界

我实际是以宿主侧使用者身份在用（把仓库、浏览器、数据库接成工具），并写过可复用的技能封装这套接入方式；自己实现过完整 MCP 服务器我没有，我的理解是协议里最容易被低估的是资源发现与权限声明。
