# temperature 与 top_p

## 一句话定义

一个调分布锐度，一个截断候选集，共同决定输出稳定性。

## 面试官为什么问它

考的是你会不会按任务调参——提取类要低、创意类要高，说反了就是没做过。

## 30 秒版回答

模型每步是在词表上算一个概率分布。temperature 缩放分布：接近零时最可能的 token 几乎总被选中，输出稳定；调高会把概率抹平，冷门 token 更常出现，多样但更容易出错。top_p 是从高到低累加概率到阈值就截断，只在这批候选里采样，等于给长尾加了个闸。两者都会影响多样性，实践中我更倾向 temperature 设很低加 top_p 稍松来做信息抽取，创作类才调高。要记住的是：这些参数只影响采样，不影响模型「知道多少」。

## 被追问三层时的诚实边界

我实际调的是抽取与生成两类场景的参数组合，并用批测比较过稳定性；logits 加工、beam search 与重复惩罚这些我属于读过没实操，我的理解是不同厂商 API 暴露的参数名和默认值差别很大，要按接口实测。
