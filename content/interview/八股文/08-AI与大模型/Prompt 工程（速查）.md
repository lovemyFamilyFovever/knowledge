# Prompt 工程

## 一句话定义

用指令边界、输出契约和证据供给来塑造模型行为。

## 面试官为什么问它

简历直接写了 Prompt 工程，他想要的是一两个具体手段加一条验证方法，不是背技巧清单。

## 30 秒版回答

我按四层写：先是任务与边界（做什么、不做什么、没有依据时必须拒答而不是补）；然后是输出契约（字段名、类型、枚举取值、要求纯 JSON 且禁止解释性文字）；再是证据供给（把检索片段带编号放进上下文，要求逐句挂编号）；最后才是少样本示例和分步推理。关键观念是把提示词当规格而不是咒语：改了它必须跑同一套题集证明有提升，否则只是把上一个巧合固化。

## 被追问三层时的诚实边界

我实际沉淀了提示最佳实践与踩坑文档，并把「改提示词」放在诊断链的最后一步——先查数据、再查召回、再查拼装截断；自动提示优化那类方法我读过没有实操过，我的理解是没有可靠评估集时它无从优化。
