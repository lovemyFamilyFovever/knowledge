# Token 与计费

## 一句话定义

模型按 token 计量，输入输出分开计价，上下文长度就是成本。

## 面试官为什么问它

他实际在问成本意识：你上生产有没有算过钱、有没有做拦截——这是能不能独立负责一个 AI 功能的分水岭。

## 30 秒版回答

模型处理的最小单位是 token，大致是英文的子词、中文常常一个字一到两个 token，具体由分词器决定，所以要按模型的分词算而不是按字数猜。计费一般输入输出分开，输出更贵；上下文里每一份检索到的资料都是要付钱的输入 token，所以 RAG 塞得越多越贵也越慢。工程上我会做三件事：按用户和场景计量用量、设成本阈值到线就拒答或降级、以及把长会话做摘要或截断而不是无限带上历史。

## 被追问三层时的诚实边界

我实际做过 Token 消耗计量与成本阈值拦截，并在管理后台做了用量统计页；分词器训练与词表设计我没有实操过，我的理解是那解释了为什么中文与代码的 token 密度差别很大。
