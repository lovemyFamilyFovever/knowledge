# AI Agent 技术面试题库 - 扩展部分1：深度学习与模型训练

> 深度学习与模型训练（15 题）｜涵盖神经网络、优化算法、正则化、训练技巧等核心领域。
> 每题标注难度（初级 / 中级 / 高级），编号 1–15 连续，附参考解答与关键要点。

## 主题1：神经网络基础（5 题）

### 1. 解释反向传播算法的工作原理。｜中级

反向传播（Backpropagation）是训练神经网络的核心算法，通过链式法则计算损失函数对每个参数的梯度。

**算法流程：**

1. **前向传播**：输入数据通过网络，逐层计算得到输出
2. **计算损失**：比较输出与真实值，计算损失函数
3. **反向传播**：从输出层开始，逐层计算梯度
4. **参数更新**：使用梯度下降更新参数

**数学原理：**

对于损失函数 L，参数 w 的梯度计算为：

```text
∂L/∂w = ∂L/∂y × ∂y/∂z × ∂z/∂w
```

其中 z 是加权和，y 是激活函数输出。

> 🎯 关键要点：反向传播基于链式法则。
> 需要存储前向传播的中间结果。
> 梯度消失和梯度爆炸是常见问题。

### 2. 比较不同的激活函数：ReLU、Sigmoid、Tanh、GELU。｜中级

激活函数为神经网络引入非线性，不同激活函数有不同的特性。

| 激活函数 | 公式 | 优点 | 缺点 |
|---------|------|------|------|
| ReLU | `max(0, x)` | 计算简单，缓解梯度消失 | Dead ReLU 问题 |
| Sigmoid | `1/(1+e^-x)` | 输出在 (0,1)，适合概率 | 梯度消失，非零中心 |
| Tanh | `(e^x-e^-x)/(e^x+e^-x)` | 零中心，输出在 (-1,1) | 梯度消失 |
| GELU | `x×Φ(x)` | 平滑，Transformer 常用 | 计算稍复杂 |

> 🎯 关键要点：ReLU 是目前最常用的激活函数。
> GELU 在 Transformer 中表现优秀。
> 选择激活函数需要考虑网络架构。

### 3. 解释批归一化（Batch Normalization）的原理和作用。｜中级

批归一化通过对每个 mini-batch 的数据进行归一化处理，加速训练并提高稳定性。

**计算步骤：**

1. 计算均值：`μ_B = (1/m) Σ x_i`
2. 计算方差：`σ²_B = (1/m) Σ (x_i - μ_B)²`
3. 归一化：`x̂_i = (x_i - μ_B) / √(σ²_B + ε)`
4. 缩放平移：`y_i = γ x̂_i + β`

**作用：**

- 加速训练收敛
- 允许使用更大的学习率
- 减少对参数初始化的敏感性
- 具有一定的正则化效果

> 🎯 关键要点：BN 在训练和推理时行为不同。
> Layer Norm 在 Transformer 中更常用。
> γ 和 β 是可学习的参数。

### 4. 什么是残差连接？为什么它能训练更深的网络？｜中级

残差连接（Residual Connection）通过跳跃连接将输入直接加到输出上，解决了深层网络的训练困难。

```text
y = F(x) + x
```

其中 F(x) 是残差函数，通常学习的是残差而非直接映射。

**为什么有效：**

- **梯度流**：梯度可以直接流过跳跃连接，缓解梯度消失
- **恒等映射**：网络可以轻松学习恒等映射
- **集成学习**：可以看作多个浅层网络的集成

> 🎯 关键要点：ResNet 首次提出残差连接。
> Transformer 中也广泛使用。
> 使得训练数百层的网络成为可能。

### 5. 解释梯度消失和梯度爆炸问题及其解决方案。｜高级

梯度消失和梯度爆炸是深层网络训练中的常见问题。

**梯度消失：**

- **原因**：激活函数（如 Sigmoid）的导数小于 1，连乘后梯度趋近于 0
- **影响**：深层参数无法有效更新

**梯度爆炸：**

- **原因**：权重初始化过大或激活函数导数大于 1
- **影响**：训练不稳定，参数更新过大

**解决方案：**

- 使用 ReLU：正区间导数为 1
- 残差连接：提供梯度直通路径
- 批归一化：稳定梯度流
- 梯度裁剪：限制梯度最大值
- 合适初始化：Xavier / He 初始化

> 🎯 关键要点：梯度消失在 RNN 中尤为严重。
> LSTM/GRU 通过门机制缓解问题。
> Transformer 通过残差连接解决。

## 主题2：优化算法与训练技巧（5 题）

### 6. 比较 SGD、Adam、AdamW 优化器的区别。｜中级

优化器决定了模型参数的更新方式，直接影响训练效果和速度。

| 优化器 | 特点 | 适用场景 |
|--------|------|----------|
| SGD | 基础，需要精细调参 | CV 任务，配合动量使用 |
| Adam | 自适应学习率，收敛快 | 通用，NLP 任务常用 |
| AdamW | Adam + 权重衰减解耦 | Transformer 训练标准 |

**Adam 公式：**

```text
m_t = β₁ m_{t-1} + (1-β₁) g_t      # 一阶矩估计
v_t = β₂ v_{t-1} + (1-β₂) g_t²     # 二阶矩估计
θ_t = θ_{t-1} - lr × m̂_t / (√v̂_t + ε)
```

> 🎯 关键要点：Adam 结合了动量和自适应学习率。
> AdamW 将权重衰减与梯度更新解耦。
> 大模型训练通常使用 AdamW。

### 7. 什么是学习率调度？有哪些常用策略？｜中级

学习率调度在训练过程中动态调整学习率，以获得更好的训练效果。

**常用策略：**

- **Step Decay**：每隔固定 epoch 降低学习率
- **Cosine Annealing**：余弦函数衰减
- **Warmup + Decay**：先升后降，Transformer 常用
- **One Cycle**：一个周期内先升后降

**Warmup 策略：**

```python
if step < warmup_steps:
    lr = max_lr * step / warmup_steps
else:
    lr = max_lr * decay(step)
```

> 🎯 关键要点：Warmup 帮助模型在初期稳定训练。
> Cosine Annealing 是目前最常用的策略。
> 学习率调度对最终效果影响很大。

### 8. 解释混合精度训练的原理和优势。｜高级

混合精度训练同时使用 FP16 和 FP32，在保持精度的同时提升训练速度。

**核心思想：**

- **FP16 计算**：前向和反向传播使用 FP16，加速计算
- **FP32 主权重**：参数更新使用 FP32，保持精度
- **损失缩放**：放大 loss，防止 FP16 下溢

**优势：**

- 训练速度提升 2-3 倍
- 显存占用减少约 50%
- 支持更大的 batch size

> 🎯 关键要点：需要 GPU 支持 Tensor Core。
> 损失缩放是关键技术。
> BF16 比 FP16 更稳定。

### 9. 什么是梯度累积？什么场景下使用？｜中级

梯度累积在多个 mini-batch 上累积梯度后再更新参数，模拟更大的 batch size。

**实现方式：**

```python
for i, batch in enumerate(dataloader):
    loss = model(batch) / accumulation_steps
    loss.backward()

    if (i + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```

**使用场景：**

- GPU 显存不足，无法使用大 batch
- 需要大 batch 训练效果
- 分布式训练中同步 batch size

> 🎯 关键要点：梯度累积不增加显存消耗。
> 需要注意 BN 层的行为。
> 等效于增大 batch size。

### 10. 解释权重初始化的重要性及常用方法。｜中级

权重初始化影响训练的收敛速度和最终效果。

**常用方法：**

- **Xavier 初始化**：适用于 Sigmoid/Tanh，方差为 `2/(n_in+n_out)`
- **He 初始化**：适用于 ReLU，方差为 `2/n_in`
- **零初始化**：不推荐，会导致对称性问题

**初始化原则：**

- 保持每层输出的方差一致
- 避免梯度消失/爆炸
- 打破对称性

> 🎯 关键要点：初始化不当会导致训练失败。
> 不同激活函数需要不同的初始化。
> 预训练模型提供了良好的初始化。

## 主题3：正则化与泛化（5 题）

### 11. 什么是过拟合？如何检测和防止？｜初级

过拟合是指模型在训练集上表现好，但在验证集上表现差。

**检测方法：**

- 训练 loss 持续下降，验证 loss 上升
- 训练集和验证集性能差距大

**防止方法：**

- **数据增强**：增加训练数据多样性
- **正则化**：L1/L2 正则化、Dropout
- **早停**：验证 loss 不再下降时停止
- **简化模型**：减少模型复杂度
- **交叉验证**：更可靠的评估

> 🎯 关键要点：过拟合是机器学习的核心挑战。
> 需要平衡模型复杂度和数据量。
> 正则化是常用的解决方案。

### 12. 解释 Dropout 的原理和作用。｜中级

Dropout 在训练时随机丢弃一部分神经元，防止过拟合。

**工作原理：**

```text
训练时：y = f(x) × mask / p
推理时：y = f(x)
```

其中 mask 是随机生成的 0/1 向量，p 是保留概率。

**作用：**

- 防止神经元共适应
- 隐式集成多个子网络
- 增强模型鲁棒性

> 🎯 关键要点：Dropout 只在训练时使用。
> 通常设置为 0.1-0.5。
> Transformer 中也使用 Dropout。

### 13. 比较 L1 和 L2 正则化的区别。｜中级

L1 和 L2 正则化通过在损失函数中添加惩罚项来防止过拟合。

| 正则化 | 惩罚项 | 效果 |
|--------|--------|------|
| L1 | `Σ\|w\|` | 产生稀疏解，特征选择 |
| L2 | `Σw²` | 权重衰减，防止过拟合 |

L1 产生稀疏的原因：L1 的梯度在 0 附近不连续，容易将权重推向 0。

> 🎯 关键要点：L2 也称为权重衰减。
> L1 可以用于特征选择。
> 可以结合使用 Elastic Net。

### 14. 什么是数据增强？NLP 中有哪些数据增强方法？｜中级

数据增强通过对训练数据进行变换，增加数据多样性。

**NLP 数据增强方法：**

- **同义词替换**：用同义词替换部分词汇
- **随机插入/删除**：随机添加或删除词汇
- **回译**：翻译成其他语言再翻译回来
- **文本生成**：使用 LLM 生成类似文本
- **EDA**：Easy Data Augmentation

> 🎯 关键要点：数据增强可以有效防止过拟合。
> NLP 增强比 CV 更难保持语义。
> LLM 生成是新兴的增强方法。

### 15. 解释早停（Early Stopping）的原理。｜初级

早停是一种简单有效的正则化方法，在验证性能不再提升时停止训练。

**实现方式：**

```python
best_val_loss = inf
patience_counter = 0

for epoch in range(max_epochs):
    train_loss = train(model)
    val_loss = validate(model)

    if val_loss < best_val_loss:
        best_val_loss = val_loss
        patience_counter = 0
        save_checkpoint(model)
    else:
        patience_counter += 1

    if patience_counter >= patience:
        break
```

> 🎯 关键要点：patience 参数控制容忍度。
> 需要保存最佳模型。
> 简单但非常有效。
