2. 解释DeepSpeed ZeRO优化的三个阶段。
高级
详细解答
DeepSpeed ZeRO通过分片存储优化器状态、梯度和参数来减少显存占用。
三个阶段：
ZeRO-1
：分片优化器状态
ZeRO-2
：分片优化器状态 + 梯度
ZeRO-3
：分片优化器状态 + 梯度 + 参数
显存节省：
# 假设N个GPU
ZeRO-1: 显存 ≈ 模型参数 + 优化器状态/N
ZeRO-2: 显存 ≈ 模型参数 + (优化器状态 + 梯度)/N
ZeRO-3: 显存 ≈ (模型参数 + 优化器状态 + 梯度)/N
关键知识点
ZeRO是大模型训练的关键技术
阶段越高，显存节省越多，但通信开销越大
需要根据硬件选择合适的阶段
3. 什么是流水线并行？如何解决气泡问题？
高级
详细解答
流水线并行将模型的不同层分配到不同设备，按流水线方式执行。
气泡问题：
由于流水线各阶段执行时间不同，会导致部分设备空闲（气泡）。
解决方法：
微批次
：将一个batch分成多个micro-batch
GPipe
：增加micro-batch数量减少气泡
1F1B调度
：交替执行前向和反向传播
关键知识点
流水线并行适合层间独立性强的模型
气泡率是衡量效率的重要指标
通常与数据并行结合使用
4. 解释张量并行的原理。
高级
详细解答
张量并行将单个算子（如矩阵乘法）拆分到多个设备上并行计算。
矩阵乘法并行：
# Y = XW
# 按列切分W
W = [W1, W2]
Y = X[W1, W2] = [XW1, XW2] = [Y1, Y2]

# 各设备独立计算后拼接
优势：
单层计算可以并行
通信量较小
适合Transformer的注意力层和FFN层
关键知识点
张量并行需要GPU间高速通信
Megatron-LM是张量并行的经典实现
通常在单机多卡场景使用
5. 什么是混合专家模型（MoE）？
高级
详细解答
MoE（Mixture of Experts）通过稀疏激活来扩展模型容量，同时保持计算效率。
架构：
# MoE层
y = Σ G(x)_i × E_i(x)

# G是门控网络，选择Top-K个专家
# E_i是第i个专家网络
特点：
参数量大但每次只激活部分
计算量与激活专家数成正比
需要负载均衡机制
关键知识点
MoE是扩展模型容量的有效方式
GPT-4、Mixtral使用MoE架构
负载均衡是训练的关键挑战
主题2：推理优化（5题）
6. 解释模型量化的原理和方法。
中级
详细解答
模型量化将浮点数参数转换为低精度表示（如INT8、INT4），减少存储和计算开销。
常见方法：
INT8量化
：8位整数表示
INT4量化
：4位整数表示
GPTQ
：训练后量化，保持精度
AWQ
：激活感知量化
量化公式：
# 线性量化
x_q = round(x / scale) + zero_point
x ≈ (x_q - zero_point) × scale
关键知识点
量化可以大幅减少显存占用
需要在精度和效率之间平衡
GPTQ和AWQ是目前最常用的量化方法
7. 解释vLLM的PagedAttention机制。
高级
详细解答
PagedAttention是vLLM的核心技术，通过分页管理KV Cache提高内存利用率。
核心思想：
将KV Cache分成固定大小的块（Page）
按需分配和释放
类似操作系统的虚拟内存管理
优势：
减少内存碎片
支持更大的batch size
提高吞吐量
关键知识点
vLLM是目前最流行的推理引擎
PagedAttention显著提高了显存利用率
支持连续批处理

9. 什么是投机采样（Speculative Decoding）？
高级
详细解答
投机采样使用小模型快速生成多个候选token，然后用大模型验证，加速推理。
流程：
小模型快速生成K个候选token
大模型并行验证这K个token
接受正确的token，拒绝错误的
优势：
减少大模型的调用次数
保持输出质量不变
可以加速2-3倍
关键知识点
投机采样需要小模型与大模型分布接近
接受率是影响加速比的关键
是推理加速的重要研究方向
