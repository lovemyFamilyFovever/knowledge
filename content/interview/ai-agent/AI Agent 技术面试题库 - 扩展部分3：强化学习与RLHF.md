# AI Agent 技术面试题库 - 扩展部分3：强化学习与RLHF

> 强化学习与 RLHF（10 题）｜涵盖 RL 基础、策略梯度、PPO、DPO 等核心领域。
> 每题标注难度（初级 / 中级 / 高级），编号 1–10 连续，附参考解答与关键要点。

## 主题1：强化学习基础（5 题）

### 1. 解释强化学习的基本概念：状态、动作、奖励、策略。｜初级

强化学习是通过与环境交互来学习最优行为的机器学习范式。

**核心概念：**

- **状态（State）**：环境的当前情况
- **动作（Action）**：Agent 可以执行的操作
- **奖励（Reward）**：执行动作后获得的反馈信号
- **策略（Policy）**：从状态到动作的映射，`π(a|s)`
- **价值函数（Value Function）**：评估状态或动作的长期价值

**目标：**

学习一个策略 π，使得累积奖励最大化：

```text
max_π E[Σ γ^t r_t]
```

其中 γ 是折扣因子。

> 🎯 关键要点：强化学习的核心是探索与利用的平衡。
> 奖励设计对学习效果至关重要。
> 折扣因子控制对未来奖励的重视程度。

### 2. 比较 Q-learning 和策略梯度方法。｜中级

Q-learning 和策略梯度是两种主要的强化学习方法。

| 特性 | Q-learning | 策略梯度 |
|------|-----------|---------|
| 学习目标 | 价值函数 Q(s,a) | 策略 π(a\|s) |
| 动作空间 | 离散动作 | 连续/离散动作 |
| 探索方式 | ε-greedy 等 | 随机策略自然探索 |
| 收敛性 | 可能不稳定 | 收敛到局部最优 |

> 🎯 关键要点：Q-learning 是基于价值的方法。
> 策略梯度直接优化策略。
> Actor-Critic 结合两者优势。

### 3. 解释策略梯度定理。｜高级

策略梯度定理是策略优化的理论基础，它给出了目标函数对策略参数的梯度。

**目标函数：**

```text
J(θ) = E_τ~π_θ [Σ r_t]
```

**策略梯度定理：**

```text
∇_θ J(θ) = E_τ~π_θ [Σ ∇_θ log π_θ(a_t|s_t) × A_t]
```

其中 `A_t` 是优势函数，表示动作相对于平均水平的好坏。

**REINFORCE 算法：**

```text
∇_θ J(θ) ≈ (1/N) Σ Σ ∇_θ log π_θ(a_t|s_t) × G_t
```

> 🎯 关键要点：策略梯度是无偏估计。
> 方差大，需要基线来降低方差。
> REINFORCE 是最基本的策略梯度算法。

### 4. 解释 PPO 算法的原理。｜高级

PPO（Proximal Policy Optimization）是目前最常用的策略梯度算法，RLHF 中也使用 PPO。

**核心思想：**

通过裁剪机制限制策略更新幅度，保证训练稳定性。

**PPO-Clip 目标函数：**

```text
L^CLIP(θ) = E[min(r_t(θ)A_t, clip(r_t(θ), 1-ε, 1+ε)A_t)]
```

其中 `r_t(θ) = π_θ(a_t|s_t) / π_old(a_t|s_t)` 是新旧策略的概率比。

**优势：**

- 实现简单
- 训练稳定
- 样本效率较高

> 🎯 关键要点：PPO 是 RLHF 的标准算法。
> ε 通常设置为 0.1-0.2。
> 需要多个 epoch 的更新。

### 5. 什么是 Actor-Critic 架构？｜中级

Actor-Critic 结合了策略梯度和价值函数的优势。

**两个组件：**

- **Actor**：策略网络，决定采取什么动作
- **Critic**：价值网络，评估动作的好坏

**更新过程：**

```python
# Actor更新：使用Critic的评估
∇_θ J(θ) = E[∇_θ log π_θ(a|s) × A(s,a)]

# Critic更新：最小化TD误差
L(φ) = E[(r + γ V_φ(s') - V_φ(s))²]
```

> 🎯 关键要点：Actor-Critic 是现代 RL 的基础架构。
> Critic 降低了策略梯度的方差。
> A2C、A3C 是常见的变体。

## 主题2：RLHF 与对齐（5 题）

### 6. 解释 RLHF 的完整流程。｜高级

RLHF（Reinforcement Learning from Human Feedback）是将语言模型与人类偏好对齐的关键技术。

**三个阶段：**

- **SFT（监督微调）**：使用高质量数据微调基础模型
- **奖励模型训练**：训练一个评估回复质量的模型
- **RL 优化**：使用 PPO 优化策略模型

**奖励模型训练：**

```python
# 损失函数
L = -log σ(r(x, y_w) - r(x, y_l))

# 其中y_w是优选回复，y_l是劣选回复
```

> 🎯 关键要点：奖励模型是 RLHF 的核心创新。
> 人类偏好数据质量很重要。
> KL 惩罚防止过度优化。

### 7. 比较 RLHF 和 DPO 的区别。｜高级

DPO（Direct Preference Optimization）是一种简化 RLHF 的方法，无需训练奖励模型。

| 特性 | RLHF | DPO |
|------|------|-----|
| 奖励模型 | 需要单独训练 | 隐式包含在策略中 |
| 训练复杂度 | 高（需要多个模型） | 低（单阶段） |
| 稳定性 | 需要精细调参 | 更稳定 |
| 效果 | 通常更好 | 相当 |

**DPO 损失函数：**

```text
L = -log σ(β × (log π_θ(y_w|x)/π_ref(y_w|x) - log π_θ(y_l|x)/π_ref(y_l|x)))
```

> 🎯 关键要点：DPO 将 RL 问题转化为分类问题。
> DPO 实现更简单，训练更稳定。
> 效果与 RLHF 相当。

### 8. 什么是奖励模型的过度优化问题？｜高级

过度优化是指策略模型过度拟合奖励模型，导致实际效果下降。

**表现：**

- 奖励分数持续上升
- 但人类评估质量下降
- 生成内容变得冗长或重复

**缓解方法：**

- **KL 惩罚**：限制策略偏离参考模型的程度
- **早停**：监控真实效果，适时停止
- **集成奖励**：使用多个奖励模型
- **约束优化**：设置奖励上限

> 🎯 关键要点：过度优化是 RLHF 的常见问题。
> KL 惩罚是主要的缓解手段。
> 需要监控真实效果而非奖励分数。

### 9. 什么是 Constitutional AI？｜高级

Constitutional AI 是 Anthropic 提出的对齐方法，使用 AI 自身来评估和改进输出。

**核心思想：**

- 定义一组"宪法"原则
- 让 AI 根据这些原则自我批评和修正
- 减少对人类标注的依赖

**流程：**

1. 生成初始回复
2. AI 根据宪法原则进行自我批评
3. 根据批评修改回复
4. 使用修改后的数据训练

> 🎯 关键要点：减少了对人类标注的依赖。
> 可以扩展到更多场景。
> 是 RLHF 的补充方法。

### 10. 什么是 RLAIF？与 RLHF 有什么区别？｜中级

RLAIF（Reinforcement Learning from AI Feedback）使用 AI 反馈替代人类反馈。

| 特性 | RLHF | RLAIF |
|------|------|-------|
| 反馈来源 | 人类标注者 | 强大的 AI 模型 |
| 成本 | 高 | 低 |
| 可扩展性 | 受限于标注者 | 容易扩展 |
| 质量 | 高 | 取决于 AI 模型 |

> 🎯 关键要点：RLAIF 降低了对齐成本。
> 需要强大的 AI 模型作为评判。
> 是 RLHF 的补充方案。
