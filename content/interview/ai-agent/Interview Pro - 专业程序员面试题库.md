## 热门面试题

高频出现的面试问题：

1. 请解释 JavaScript 中的闭包（Closure）是什么？它有哪些实际应用场景？（JavaScript 核心 · 中级 · 闭包/作用域）
2. React 中的虚拟 DOM 是什么？它如何提升性能？（React 框架 · 中级 · 虚拟 DOM/性能优化）
3. Vue 3 的响应式系统是如何工作的？与 Vue 2 有什么区别？（Vue 框架 · 高级 · 响应式/Proxy）
4. 如何优化前端应用的性能？请从多个维度进行说明。（性能优化 · 中级 · 性能优化/Core Web Vitals）
5. JavaScript 的事件循环（Event Loop）机制是什么？（JavaScript 核心 · 高级 · 事件循环/异步）
6. 请解释 CSS Flexbox 和 Grid 布局的区别和使用场景。（CSS 布局 · 初级 · Flexbox/Grid）
