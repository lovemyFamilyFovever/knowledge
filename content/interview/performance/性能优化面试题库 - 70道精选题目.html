1. 什么是Web性能？为什么它很重要？ 简单
性能基础 用户体验 业务价值

回答模板1：概念解释

Web性能是指网站或Web应用程序加载、交互和响应的速度和流畅度。它直接影响用户体验、SEO排名和业务转化率。

回答模板2：业务影响

性能对业务的影响：

1. 用户体验：加载时间每增加1秒，用户流失率增加32%

2. SEO排名：Google将页面速度作为排名因素

3. 转化率：页面加载时间从1秒增加到3秒，转化率下降7%

4. 移动设备：移动用户对性能更敏感

回答模板3：性能指标

关键性能指标：

1. FCP（First Contentful Paint）：首次内容绘制

2. LCP（Largest Contentful Paint）：最大内容绘制

3. TTI（Time to Interactive）：可交互时间

4. TBT（Total Blocking Time）：总阻塞时间

5. CLS（Cumulative Layout Shift）：累积布局偏移

2. 请解释浏览器渲染页面的过程 中等
浏览器渲染 渲染流程 性能

回答模板1：基础流程

浏览器渲染页面的基本流程：

1. 解析HTML → 构建DOM树

2. 解析CSS → 构建CSSOM树

3. 合并 → 生成渲染树（Render Tree）

4. 布局（Layout）→ 计算元素位置和大小

5. 绘制（Paint）→ 绘制像素

6. 合成（Composite）→ 合成到屏幕

回答模板2：详细解释

每个阶段的关键点：

• DOM构建：HTML解析器逐行解析，遇到阻塞资源会暂停

• CSSOM构建：CSS是渲染阻塞资源，必须等待加载完成

• 渲染树：只包含可见元素，不包含display:none的元素

• 布局：计算每个元素的几何信息（重排）

• 绘制：将元素转换为像素（重绘）

• 合成：将多个层合成最终图像

回答模板3：优化启示

渲染流程对性能优化的启示：

1. 减少DOM深度和复杂度

2. 避免CSS阻塞渲染

3. 减少布局和绘制的范围

4. 使用transform代替top/left

5. 合理使用will-change提示浏览器

3. 什么是重排（Reflow）和重绘（Repaint）？如何优化？ 中等
重排 重绘 性能优化

回答模板1：概念区分

重排（Reflow）：当元素的位置、大小等几何属性改变时，浏览器需要重新计算布局。

重绘（Repaint）：当元素的外观改变但不影响布局时，浏览器重新绘制像素。

回答模板2：触发条件

触发重排的操作：

• 添加/删除DOM元素

• 改变元素位置、大小

• 改变窗口大小

• 读取布局属性（offsetWidth, clientWidth等）

触发重绘的操作：

• 改变颜色

• 改变visibility

• 改变背景

回答模板3：优化策略

减少重排重绘的优化策略：

1. 批量修改DOM（使用DocumentFragment）

2. 避免频繁读取布局属性

3. 使用transform代替top/left

4. 使用will-change提示浏览器

5. 使用虚拟滚动减少DOM节点

5. 什么是Core Web Vitals？包含哪些指标？ 中等
Core Web Vitals 性能指标 Google

回答模板1：概念解释

Core Web Vitals是Google提出的衡量用户体验的一组核心指标，包括：

1. LCP（Largest Contentful Paint）：最大内容绘制，应小于2.5秒

2. FID（First Input Delay）：首次输入延迟，应小于100毫秒

3. CLS（Cumulative Layout Shift）：累积布局偏移，应小于0.1

回答模板2：测量方法

如何测量Core Web Vitals：

1. Chrome DevTools：Performance面板

2. Lighthouse：性能审计工具

3. PageSpeed Insights：在线工具

4. Web Vitals库：JavaScript库

// 使用Web Vitals库

getLCP(console.log);
getFID(console.log);
getCLS(console.log);
回答模板3：优化建议

Core Web Vitals优化建议：

• LCP优化：优化图片、预加载关键资源、减少服务器响应时间

• FID优化：减少JavaScript执行时间、拆分长任务

• CLS优化：设置图片尺寸、避免动态插入内容、使用CSS contain

45. 什么是CDN？如何使用CDN优化性能？ 中等
CDN 内容分发 性能优化

回答模板1：概念解释

CDN（Content Delivery Network）是内容分发网络，通过将内容分发到全球边缘节点，加速用户访问。

CDN的工作原理：

1. 用户请求资源

2. DNS解析到最近的边缘节点

3. 边缘节点返回缓存的资源

4. 如果没有缓存，回源获取并缓存

回答模板2：使用场景

CDN的使用场景：

1. 静态资源：CSS、JavaScript、图片

2. 视频流：视频点播和直播

3. 软件分发：软件下载

4. API加速：动态内容加速

5. 安全防护：DDoS防护

回答模板3：最佳实践

CDN使用最佳实践：

1. 选择合适的CDN服务商

2. 设置合理的缓存策略

3. 使用HTTPS保证安全

4. 监控CDN性能

5. 优化资源命名和版本管理

2. 闭包：闭包引用外部变量

1. Chrome DevTools：Memory面板

2. heapdump：生成堆快照

3. process.memoryUsage()：Node.js内存使用

4. Valgrind：C/C++内存检测

// Node.js内存监控
