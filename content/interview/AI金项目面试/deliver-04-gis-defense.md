# 能守卡 04 · 都市圈 GIS（toG 规划"一张图 / 多规合一"）

> 目标：让你被问到 2018–2020 那段 GIS 经历时**讲得出人话、术语对、且不吹成平台框架作者**。你在这段是**业务前端 + 现场定制**，深度到"会用、能讲流程"即可，不必假装懂 GIS 底层。

---

## 0. 一句话讲你做过什么（背这段）
"我给自然资源局 / 规划系统做 toG 的 **'一张图 / 多规合一'** 平台前端，以及无锡当地的现场定制开发。后端是 **ASP.NET + ArcGIS 地图服务出图**，前端用 **Leaflet 加载地图图层、ECharts 做统计、jQuery/AJAX(.ashx) 拿数据交互**；我负责在其上实现图层目录、属性查询、量测、图斑展示这些业务功能。"

## 1. 先把两个名词讲清楚（面试官常从这切）
- **"一张图"**：把规划 / 现状 / 地类 / 红线等**各类图层叠加到同一张 Web 地图**上统一查阅、比对、分析——本质是"多源 GIS 图层叠加的可视化平台"。
- **"多规合一"**：把**土规、城规、环保、林地等多个规划**在空间上做协调，核心业务是**发现图斑冲突 / 矛盾检测**（比如一块地在两个规划里用途打架），再走协调流程。你项目里那个 `ComplianceTesting(合规检测)` 就是这类"检测矛盾图斑"。

## 2. 这些 GIS 术语你要能说上一两句（懂概念即可，别装懂原理）
| 术语 | 一句话 | 你在这段怎么用 |
|---|---|---|
| 图层 / 图层目录 | 地图按主题分层，可开关叠加 | 前端做图层列表、勾选显隐、调整叠加顺序 |
| **地图服务（ArcGIS Server）** | GIS 后端把地图渲染成服务给前端调 | 后端发布，前端只是**加载 URL 瓦片**，不自己渲染 |
| **瓦片 / WMTS / WMS** | 地图切成小图块按 z/x/y 拼起来 | Leaflet `L.tileLayer(服务URL)` 加底图/叠加层 |
| **坐标系 / CGCS2000 / WGS84 / 投影** | 地图数据的空间基准 | ⚠️ 这是**GIS 后端/平台配的**，你只需知道"前后端坐标系要对齐，否则图层错位" |
| **Shapefile(.shp)/DWG/GeoJSON** | 常见地理 / CAD 数据格式 | 规划数据来源，前端展示其图形与属性 |
| **Identify / 属性识别** | 点地图某处，返回该处要素的属性 | 点选→AJAX 查 .ashx→弹出属性表 |
| **缓冲区 / 叠加分析 / 空间量测** | GIS 空间计算 | 量测(距离/面积)你前端有；**叠加/缓冲这类空间分析在 GIS 后端**，别揽到前端 |
| **mxd** | ArcMap 的地图工程文档 | 后端/制图人员出图用的，你打交道但不生产 |

## 3. 前端到底做了什么（讲得出细节 = 真实感）
- 用 **Leaflet** 初始化地图容器、加底图与各业务图层(`L.tileLayer`/`L.geoJSON`)、图层切换控件、按比例尺显隐；
- **点选查属性**：地图 click 拿经纬度 → `$.ajax` 打 `.ashx` → 弹属性面板 / 高亮图斑；
- **量测**：画折线/多边形算距离、面积（平台框架已有内核，你调用/定制）；
- **ECharts**：把规划指标（用地结构、批地量等）做成图表 / 统计面板；
- **现场定制**：无锡就你一个开发，各地规划局临时需求（改表单、加查询条件、调展示）你直接改前端交付——**这恰好体现你独立扛、沟通、快速响应**。

## 4. 你会被怎么问 · 安全答法
- "GIS 前端和后端怎么分工？"→ "**后端出地图服务和数据，我负责前端加载、交互和业务功能**，坐标系、投影、空间分析在 GIS 后端，我不碰底层。"（划清边界=不翻车）
- "为什么用 Leaflet 不用 ArcGIS 的 JS API？"→ "轻量、够用、开源；一张图主要是叠加展示+查询，Leaflet 加瓦片服务就能满足，平台框架也是基于它。"
- "多规合一的矛盾检测算法怎么实现的？"→ **诚实**："**那部分在 GIS/后端**，我做的是把检测结果在地图上展示和走业务表单，空间分析算法不是前端做的。"
- "投影 / 坐标转换讲一下？"→ 大方承认："**我是应用层前端，坐标转换是后端和平台配的，我知道概念但要我手写变换公式就不行了**。"（别硬编——这正是我们说好的不装）

## 5. 这段的"加分角度"（往你的能力上引）
GIS 本身不是你要主卖的，但这段能佐证三件事：
1. **零基础自学入行**（2019 从写页面自学前端）；
2. **toG 复杂业务系统的现场交付力**（一人扛定制、直接面客户）；
3. **地图/数据可视化经验**——和你后来 AI 金里的 **ECharts 图表、知识图谱可视化** 一脉相承，可以顺过去讲。

> 结论：GIS 讲到"懂概念、讲得清前后端分工、会 Leaflet 加载+ECharts+查询量测"就够；**被追到坐标/投影/空间分析就诚实交回后端**。别把平台组的自研框架和移动端往自己身上揽。
