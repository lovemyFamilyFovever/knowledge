📦 Webpack

1. Webpack是什么？它有哪些核心概念？ 简单
Webpack 构建工具 模块打包

回答模板1：概念解释

Webpack是一个现代JavaScript应用程序的静态模块打包工具。它能够处理JavaScript、CSS、图片等资源。

核心概念：

1. Entry：入口文件

2. Output：输出配置

3. Loader：处理非JavaScript文件

4. Plugin：扩展功能

5. Mode：开发/生产模式

回答模板2：配置示例
// webpack.config.js
const path = require('path');
const HtmlWebpackPlugin = require('html-webpack-plugin');

module.exports = {
    entry: './src/index.js',
    output: {
        path: path.resolve(__dirname, 'dist'),
        filename: 'bundle.[contenthash].js',
        clean: true
    },
    module: {
        rules: [
            {
                test: /\.js$/,
                exclude: /node_modules/,
                use: 'babel-loader'
            },
            {
                test: /\.css$/,
                use: ['style-loader', 'css-loader']
            }
        ]
    },
    plugins: [
        new HtmlWebpackPlugin({
            template: './src/index.html'
        })
    ],
    mode: 'production'
};
回答模板3：使用场景

Webpack的使用场景：

1. 模块打包：将多个模块打包成一个文件

2. 代码分割：按需加载代码

3. 资源管理：处理CSS、图片等资源

4. 开发工具：热模块替换、开发服务器

5. 优化：压缩、Tree Shaking等

2. Webpack中的Loader和Plugin有什么区别？ 中等
Loader Plugin Webpack

回答模板1：核心区别

Loader和Plugin的主要区别：

1. 作用：Loader处理文件转换，Plugin扩展功能

2. 配置：Loader在module.rules中配置，Plugin在plugins中配置

3. 执行时机：Loader在模块加载时执行，Plugin在生命周期中执行

4. 功能：Loader只能做文件转换，Plugin可以做任何事情

回答模板2：使用示例
// Loader使用
module: {
    rules: [
        {
            test: /\.js$/,
            use: 'babel-loader'
        }
    ]
}

// Plugin使用
plugins: [
    new HtmlWebpackPlugin({
        template: './src/index.html'
    }),
    new MiniCssExtractPlugin({
        filename: '[name].css'
    })
]
回答模板3：选择建议

选择建议：

1. 使用Loader：需要转换文件内容时

2. 使用Plugin：需要扩展Webpack功能时

3. 自定义Loader：有特殊的文件转换需求

4. 自定义Plugin：需要介入Webpack生命周期

5. 参考文档：查看官方文档选择合适的Loader/Plugin

4. 小函数：函数保持小而专注

回答模板2：代码示例
// 不可测试的代码
function getUser(id) {
    const db = new Database(); // 硬编码依赖
    return db.query(`SELECT * FROM users WHERE id = ${id}`);
}

// 可测试的代码
function getUser(id, database) {
    return database.query(`SELECT * FROM users WHERE id = ${id}`);
}

// 纯函数
function add(a, b) {
    return a + b;
}

// 依赖注入
class UserService {
    constructor(database) {
        this.database = database;
    }
    
    getUser(id) {
        return this.database.query(`SELECT * FROM users WHERE id = ${id}`);
    }
}

CI/CD 持续集成 持续部署

CI/CD是持续集成和持续部署的缩写：

回答模板2：流程示例
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Setup Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18'
        
    - name: Install dependencies
      run: npm ci
      
    - name: Run tests
      run: npm test
      
    - name: Build
