项目概况
AI 金 - 不锈钢智能伙伴（AI Jin · Stainless Steel AI Partner）
项目经理
我要不锈钢科技无锡有限公司 2026 年 6 月至今 Vue 3 + NestJS + PostgreSQL + 阿里云百炼

面向不锈钢行业从业者的一站式 AI 智能平台，覆盖AI 问答、AI 配单、AI 测价、智能广场（社交内容平台）、VIP 套餐体系、ERP 管理后台、数据采集标注系统七大核心模块。

平台对接 51bxg（行业数据门户）和秀吗（交易平台），实现三平台账号互通；底层采用 PostgreSQL + Drizzle ORM，AI 能力接入阿里云百炼（qwen-plus / qwen-turbo / qwen3.7-plus），部署于飞书妙搭云函数容器。

负责内容一：AI 智能核心功能（规划、架构设计与落地推进）

1. AI 问答系统

  • 设计并落地双模式架构：快速模式（qwen-turbo 流式）+ 专家模式（百炼 App API + query-policy 四策略路由），通过智能路由将用户问题分发至最优应答路径
  • 接入百炼知识库与数据连接，实现不锈钢行业专业问答的精准命中与来源溯源
  • 推动 SSE 流式响应改造，解决飞书网关 504 超时问题，实现逐字输出体验
  • 设计 Token 消耗统计与成本观测机制，支撑 AI 调用成本管控

2. AI 配单系统

  • 主导配单数据源架构改造（2026-08 重大改造）：原 51bxg 实时接口被禁用后，设计并实施"手动导出 + 本地快照"方案，实现零外部 API 依赖的配单搜索能力
  • 设计 LLM 直通架构：parse-enquiry-params（参数解析）→ score-matches（四维 100 分制评分），不使用规则引擎，确保快速迭代
  • 完成全量 3011 条现货数据迁移入库，实现 PRODUCT_ID 映射、供应商联系方式回填、仓库到城市省份补全
  • 推动配单页面桌面端视觉重构：左右双栏布局 + 供应商详情卡 + 隐私加固（供应商匿名化）

3. AI 测价系统

  • 主导 SSE 流式 8 步思考改造：获取市场数据 → 计算技术指标 → AI 分析 → 价格区间 → 趋势 → 波动性 → 支撑阻力 → 生成结果，配合假进度爬升算法（每 800ms +0.5%，封顶 80%）
  • 设计"数据采集 → 技术指标计算 → Prompt 构建 → 大模型推理 → 算法修正 → JSON 导出"六步 Pipeline 架构
  • 输出 8 个结构化 JSON 文件供智能采销系统消费（预测结果/趋势信号/多因子评分/风控参数/价格图表/防火墙状态/策略事件/月度 KPI）
  • 规划新版数据预测体系：成本地板模型（不锈钢成本公式）、四阶段走势划分、单因子关联度验证策略
阿里云百炼 qwen-plus qwen-turbo SSE 流式 Holt 指数平滑 ECharts WAF 绕过 jsdom
负责内容二：智能广场社交平台（全流程设计与开发）
  • 设计并实现完整的社交内容平台：发布（文章/图片/视频/问答）→ 推荐流（瀑布流布局）→ 互动（关注/点赞/收藏/评论/分享）→ 通知中心
  • 实现AI 智能搜索：搜索框聚焦时展示"最近搜索 + 猜你想搜"面板，后端通过 qwen-turbo 从帖子标签与用户画像生成个性化搜索推荐词，搜索结果支持 SSE 流式 AI 总结
  • 设计用户画像引导系统：首次进入触发 Onboarding 流程，采集身份/企业/关注钢种，昵称通过 qwen-turbo 自然语言解析

  • 实现供需发布系统（plaza_demands）：求购/供应信息 CRUD + AI 智能匹配 + 按品类/材质筛选
