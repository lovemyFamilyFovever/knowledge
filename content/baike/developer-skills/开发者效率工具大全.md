## 1. 终端工具：命令行的终极优化

### 1.1 终端模拟器选择

#### iTerm2 (macOS)
iTerm2 不仅仅是终端模拟器，更是开发效率倍增器。以下是我推荐的深度配置：

```bash
# 安装iTerm2
brew install --cask iterm2

# 安装推荐字体 (支持图标)
brew tap homebrew/cask-fonts
brew install --cask font-hack-nerd-font
```

**核心功能配置：**
- **分屏操作**：`Cmd+D` 垂直分屏，`Cmd+Shift+D` 水平分屏
- **搜索与高亮**：`Cmd+F` 可搜索并高亮所有匹配项
- **自动补全**：`Cmd+;` 开启历史命令智能补全
- **粘贴历史**：`Cmd+Shift+H` 查看粘贴历史
- **即时回放**：`Cmd+Shift+P` 回放之前的终端会话

## 3. Git 高级用法：版本控制的深度掌握

### 3.1 Interactive Rebase (交互式变基)

```bash
# 修改最近3次提交
git rebase -i HEAD~3

# 交互式编辑界面示例
pick abc1234 feat: 添加用户登录功能
pick def5678 fix: 修复登录验证bug
pick ghi9012 docs: 更新API文档

# 可用的操作：
# p, pick   = 使用提交
# r, reword = 使用提交，但修改提交信息
# e, edit   = 使用提交，但停下来进行修改
# s, squash = 使用提交，但合并到前一个提交
# f, fixup  = 类似于squash，但丢弃这个提交的日志信息
# x, exec   = 运行shell命令
# d, drop   = 删除提交
```

**实际案例：合并提交**
```bash
# 合并最近3个提交为一个
git rebase -i HEAD~3
# 将后两个提交的 pick 改为 squash
# 保存退出后编辑合并的提交信息
```

### 3.2 Cherry-pick (精选提交)

```bash
# 从另一个分支精选单个提交
git cherry-pick abc1234

# 精选多个提交
git cherry-pick abc1234 def5678 ghi9012

# 精选一个范围的提交
git cherry-pick abc1234..ghi9012

# 精选提交但不自动提交（用于修改）
git cherry-pick --no-commit abc1234

# 解决冲突后继续
git cherry-pick --continue

# 放弃cherry-pick
git cherry-pick --abort
```

### 3.3 Bisect (二分查找定位bug)

```bash
# 开始二分查找
git bisect start

# 标记当前版本为有问题
git bisect bad

# 标记已知正常的版本
git bisect good v1.0.0

# Git会自动切换到中间版本，测试后标记
# 如果当前版本有问题
git bisect bad

# 如果当前版本正常
git bisect good

# 重复直到找到引入bug的提交

# 结束二分查找
git bisect reset

# 自动化二分查找（使用测试脚本）
git bisect start HEAD v1.0.0
git bisect run npm test
```

### 3.4 Worktree (工作树)

```bash
# 创建新的工作树（同时在不同分支工作）
git worktree add ../hotfix-branch hotfix

# 创建新分支的工作树
git worktree add -b new-feature ../feature-branch

# 列出所有工作树
git worktree list

# 移除工作树
git worktree remove ../hotfix-branch

# 修剪无效的工作树引用
git worktree prune
```

**实际使用场景：**
```bash
# 正在开发新功能，需要紧急修复bug
git worktree add ../hotfix-v1.2.1 hotfix-v1.2.1
cd ../hotfix-v1.2.1
# 进行修复...
git commit -m "fix: 紧急修复安全漏洞"
cd ../main-project
git worktree remove ../hotfix-v1.2.1
```

**自定义fzf脚本示例：**
```bash
#!/bin/bash
# fkill - 查找并杀死进程
fkill() {
  local pid
  pid=$(ps -ef | sed 1d | fzf -m | awk '{print $2}')
  
  if [ "x$pid" != "x" ]; then
    echo $pid | xargs kill -${1:-9}
  fi
}

# fshow - 查看git提交并预览
fshow() {
  git log --graph --color=always \
    --format="%C(auto)%h%d %s %C(black)%C(bold)%cr" "$@" |
  fzf --ansi --no-sort --reverse --tiebreak=index --bind=ctrl-s:toggle-sort \
    --bind "ctrl-m:execute:
              (grep -o '[a-f0-9]\{7\}' | head -1 |
              xargs -I % sh -c 'git show --color=always % | less -R') << 'FZF-EOF'
              {}
FZF-EOF"
}

# fbr - 查找并切换git分支
fbr() {
  local branches branch
  branches=$(git --no-pager branch -vv) &&
  branch=$(echo "$branches" | fzf +m) &&
  git checkout $(echo "$branch" | awk '{print $1}' | sed "s/.* //")
}

# fcs - 查找git提交并精选
fcs() {
  local commits commit
  commits=$(git log --color=always --pretty=oneline --abbrev-commit --reverse) &&
  commit=$(echo "$commits" | fzf --tac +s +m -e --ansi --reverse) &&
  git cherry-pick $(echo "$commit" | sed "s/ .*//")
}
```
