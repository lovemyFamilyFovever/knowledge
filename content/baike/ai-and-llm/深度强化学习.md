# 深度强化学习


> 📌 **导航**：本文是 **深度强化学习** 词条，属于 ai-and-llm 术语集。相关枢纽：[[强化学习基础]]、[[机器学习基础]]、[[大模型基础术语详解]]、[[多 Agent 协作系统]]。

## 定义

**一句话定义：** 深度强化学习用神经网络近似策略或价值函数，把强化学习的"试错学策略"与深度学习的"高维感知"结合，从而能从像素等原始输入直接学到决策。

**通俗类比：** 普通 RL 的 Q 表像"小棋盘查表"，只能处理有限状态；DRL 给大脑装上眼睛——面对一堆像素（Atari 画面）也能学会玩游戏。

## 为什么需要它

现实决策的状态维度极高（图像、机器人传感），表格法既存不下也泛化差。用神经网络近似 Q 值或策略，让 RL 能端到端处理高维感知，AlphaGo、Atari、机器人控制乃至 LLM 对齐都由此而来。

## 核心机制

- **DQN（深度 Q 网络）**：用一个网络逼近动作价值 Q(s,a;θ)，输入状态、输出各动作的 Q 值，选 argmax 执行。三大稳定技巧：**经验回放**（打散连续样本相关性、复用历史轨迹）、**目标网络**（用延迟更新的参数算 TD 目标，防自举发散）、**双重 DQN**（解耦"选动作"与"评估动作"，缓解 Q 值过估计）。
- **PPO（近端策略优化）**：直接优化策略，用裁剪目标约束单步更新幅度——`L_CLIP = E[min(r_t·A_t, clip(r_t, 1-ε, 1+ε)·A_t)]`，其中 r_t 是新 / 旧策略概率比、A_t 是优势；clip 限制偏离，防止一步更新过大导致策略崩塌。
- **在 RLHF 中的应用**：收集人类偏好 → 训练奖励模型 RM → 用 PPO 优化 LLM，并以 KL 惩罚约束模型别偏离原模型太远，抑制 reward hacking 与跑偏。

## 具体示例

玩 Atari 打砖块：DQN 吃连续几帧像素，CNN 输出每个按键的 Q 值并选最大动作；经验回放让"成功击中"的轨迹被反复学习，目标网络稳住训练。在 LLM 里，PPO 则依据 RM 给出的分数强化"更受偏好"的回答。

## 何时用 / 何时不用

- **用**：高维感知下的序贯决策——游戏、控制、机器人、大模型对齐。
- **不用**：低维、可表格建模的简单 RL（表格法更省）；或根本没有奖励可定义的纯监督任务。

## 优劣与代价

✅ 端到端从原始输入学策略，通用性远超表格 RL。
⚠️ 样本效率低、训练不稳定，高度依赖回放 / 目标网络 / 裁剪等技巧。
⚠️ 超参敏感，且奖励设计不当时有 reward hacking 风险。

## 与相关概念的区别

- **vs [[强化学习基础]]**：基础版用表格 Q / 策略、只适合小状态空间；DRL 用神经网络近似，以处理高维输入。
- **vs 监督学习**：没有逐样本标签，靠稀疏奖励与探索来学习。

## 常见误区

- 用神经网络替代 Q 表后，深度强化学习训练就天然稳定，不再需要经验回放或目标网络。
- PPO 的 clip 机制是为了让每一步策略更新尽可能大、从而加速收敛。
- 深度强化学习和表格型强化学习一样，只能处理很小的离散状态空间。

## 面试速答

> 🎯 深度强化学习用神经网络近似价值/策略，补上 RL 的高维感知：DQN 靠经验回放（去样本相关）与目标网络（稳 TD 目标）稳定训练；策略侧 PPO 用裁剪目标限制单步更新防崩塌，并被用于 RLHF（偏好→奖励模型→PPO 优化 LLM 加 KL 惩罚防偏离）。能端到端从像素学决策，代价是样本效率低、训练不稳。
> 🔍 追问：DQN 里经验回放为什么有用？（打散连续样本的相关性、复用历史轨迹，使梯度更接近 i.i.d.、训练更稳）
> 🔍 追问：PPO 为什么要 clip 概率比？（限制新旧策略偏离幅度，避免一次更新过大导致策略崩溃）
