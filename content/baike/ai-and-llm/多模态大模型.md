# 多模态大模型


> 📌 **导航**：本文是 **多模态大模型** 词条，属于 ai-and-llm 术语集。相关枢纽：[[大模型基础术语详解]]、[[Transformer架构深度解析]]、[[Diffusion扩散模型]]、[[多模态 Agent]]、[[语音AI技术]]。

## 定义

**一句话定义：** 多模态大模型是能统一处理并对齐文本与图像（乃至音频、视频）的模型，用跨模态编码器把不同模态投影到共享语义空间，实现图文理解、检索与生成。

**通俗类比：** 一位"通晓图文的翻译 + 融合器"——把图片"翻译"成模型能懂的向量、与文字放进同一语义空间，于是它既能读懂图，也能图文联合推理。

## 为什么需要它

纯文本模型"看不见"图像世界，而现实信息大量是非文本的。多模态模型让一个模型同时吃下图与文，统一表征后支撑视觉问答、OCR、图文检索、视觉指令跟随等，是通向通用感知的关键一步。

## 核心机制

**跨模态对齐（CLIP）** 是基石：图像、文本各过一个编码器得到特征，算相似度矩阵后，用对称 InfoNCE 把配对的图文拉近、非配对推远（乘一个可学习温度），损失骨架很短：

```python
img = image_encoder(images); txt = text_encoder(texts)   # 双塔编码
logits = img @ txt.T * temperature                        # 相似度矩阵
loss = (CE(logits, labels) + CE(logits.T, labels)) / 2    # 对称 InfoNCE
```

**视觉语言模型（VLM）拼装**：以 LLaVA 为例，架构是"视觉编码器（CLIP ViT）→ 投影层（MLP）→ LLM（LLaMA）"。投影层把图像特征"翻译"成 LLM 词表空间里的 visual token，再与文本 token 拼成统一序列交给 LLM，从而让语言模型"把图当词读"。

| 模型 | 视觉编码器 | LLM | 特点 |
|------|-----------|-----|------|
| GPT-4V | 私有 | GPT-4 | 最强综合 |
| Gemini | 私有 | Gemini | 原生多模态 |
| LLaVA | CLIP ViT | LLaMA | 简单高效 |
| Qwen-VL | ViT | Qwen | 中文优化 |

## 具体示例

给模型一张"猫在沙发上"并问"图里有几只猫"：视觉编码器抽出图像 patch 特征 → 投影层转成 visual token → 与问题文本 token 拼成序列 → LLM 自回归生成答案。整条链的关键就在"投影对齐"那一步。

## 何时用 / 何时不用

- **用**：输入含图像、需要与语言联合理解或生成时。
- **不用**：纯文本或纯像素的单一任务——专用小模型可能更快更省，多模态训练与推理成本更高。

## 优劣与代价

✅ 统一表征、支持零样本图文迁移，解锁大量跨模态应用。
⚠️ 训练与推理成本高。
⚠️ 存在跨模态"幻觉"（描述图里其实没有的细节），对齐质量依赖数据与投影设计。

## 与相关概念的区别

- **vs [[Diffusion扩散模型]]**：多模态大模型侧重"理解 / 对齐"图文，扩散侧重"生成"图像（常由 CLIP 类对齐提供文本条件）。
- **vs [[多模态 Agent]]**：模型是感知与生成的底座，Agent 在其上加自主决策与工具调用。

## 常见误区

- LLaVA 的投影层（Projector）是把文本 token 转成图像像素。
- CLIP 靠把图文各自编码后、直接判断"是不是同一张图片"来训练。
- 多模态大模型完全不会幻觉，因为它能真正"看到"图像内容。

## 面试速答

> 🎯 多模态大模型把文本与图像对齐到共享语义空间：CLIP 用双编码器 + 对称 InfoNCE 把图文配对拉近、非配对推远，支撑跨模态检索与零样本分类；VLM（如 LLaVA = CLIP ViT + MLP 投影 + LLaMA）把图像转成 visual token 与文本拼成序列交给 LLM。亮点是统一表征，代价是成本高与跨模态幻觉。
> 🔍 追问：LLaVA 的 Projector 起什么作用？（把视觉特征映射到 LLM 词嵌入空间，让 LLM 把"图"当"词"来读）
> 🔍 追问：CLIP 为何能做零样本图像分类？（把类别名写成文本模板、与图像特征比相似度，无需针对类别重训）
