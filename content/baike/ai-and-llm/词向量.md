# 词向量

## 定义

**一句话定义：** 词向量(Word Embedding / Word Vector)是用一个稠密的低维实数向量来表示词的技术,使语义或语法相近的词在向量空间中距离接近,从而把离散的符号转为可计算的连续表示,是现代自然语言处理的基础。

**通俗类比：** 像给每个词在一张"语义地图"上安排一个坐标——意思相近的词(如"猫""狗")坐标挨得近,不相关的词离得远;于是"词的关系"变成了"坐标的距离与方向",可以被计算。

> 多义说明:词向量分**静态**(Word2Vec / GloVe,一词一向量)与**上下文相关**(ELMo / BERT,随语境变化)两类;本文以静态词向量为主并提及上下文向量。

## 原理与机制

- **分布式假设:** "观其伴而知其义"(distributional hypothesis)——词义由其上下文决定。
- **Word2Vec:** CBOW(由上下文预测中心词)与 Skip-gram(由中心词预测上下文),用浅层网络训练得到词向量。
- **GloVe:** 基于全局词共现矩阵分解。
- **特性:** 向量支持类比运算(经典示例:king − man + woman ≈ queen)。
- **局限:** 静态向量一词一义,无法处理多义词,故发展出上下文化表示(ELMo / BERT)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 稠密低维向量 | 相比 one-hot 的紧凑表示 |
| 分布式假设 | 由上下文定义词义 |
| CBOW / Skip-gram | Word2Vec 的两种架构 |
| 共现矩阵 | GloVe 的基础 |
| 类比运算 | 向量加减体现语义关系 |

## 应用场景

- 语义相似度计算
- 文本分类/聚类的特征表示
- 信息检索、推荐系统
- 机器翻译、作为下游 NLP 模型的输入表示

## 优点与局限

- 优点:把离散词转为稠密可计算表示、捕获语义关系、降维(相比 one-hot)、提升下游任务效果。
- 局限:静态向量难以处理多义与语境;需大量语料训练;向量维度与质量需权衡;已被上下文化表示(BERT 等)部分取代。

## 常见误区

- 词向量 ≠ one-hot:前者稠密低维,后者稀疏高维。
- 静态词向量一词一向量,无法区分多义(需上下文向量)。
- 类比运算(king − man + woman)是著名示例,但并非普适精确。
- 词向量是"表示",不等于"理解"。
