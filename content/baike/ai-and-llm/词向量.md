# 词向量


> 📌 **导航**：本文是 **词向量** 词条，属于 ai-and-llm 术语集。相关枢纽：[[Embedding 技术详解]]、[[BERT模型详解]]、[[注意力机制]]、[[大模型基础术语详解]]。

## 定义

**一句话定义：** 词向量（Word Embedding / Word Vector）是用稠密低维实数向量表示词的技术，使语义或语法相近的词在向量空间中彼此接近，从而把离散符号转为可计算的连续表示，是现代 NLP 的基础。

**通俗类比：** 像给每个词在一张"语义地图"上安排一个坐标——意思相近的词（如"猫""狗"）坐标挨得近，不相关的词离得远；于是"词的关系"变成了"坐标的距离与方向"，可以被计算。

> 多义说明：词向量分**静态**（Word2Vec / GloVe，一词一向量）与**上下文相关**（ELMo / BERT，随语境变化）两类；本文以静态词向量为主并提及上下文向量。

## 为什么需要它

one-hot 向量稀疏、高维，且任意两个词正交、相似度恒为 0，无法表达"猫狗相近"。词向量用稠密低维空间让相似词靠近、让语义关系可算术，把"符号"变成"可计算的几何"，是 NLP 从统计方法走向表示学习的基石。

## 核心机制

- **分布式假设**："观其伴而知其义"——词义由其上下文决定，因此可纯靠上下文共现来学表示。
- **Word2Vec**：CBOW（用上下文预测中心词）与 Skip-gram（用中心词预测上下文）两种浅层网络，配负采样提效，训练后取权重即词向量。
- **GloVe**：基于全局词共现矩阵做加权分解，兼顾全局统计与局部窗口。
- **类比运算**：向量方向编码语义关系，经典如 `king − man + woman ≈ queen`（该规律有名但并不处处精确）。
- **由静态到上下文化**：一词一向量解决不了多义，于是发展出 ELMo / BERT 让词表示随上下文动态变化。

| 组成 | 说明 |
|------|------|
| 稠密低维向量 | 相比 one-hot 的紧凑表示 |
| 分布式假设 | 由上下文定义词义 |
| CBOW / Skip-gram | Word2Vec 的两种架构 |
| 共现矩阵 | GloVe 的基础 |
| 类比运算 | 向量加减体现语义关系 |

## 具体示例

语义检索与推荐中，"苹果"与"香蕉"向量接近，可据此扩展相似查询；分类任务可把句中词向量取平均作特征。但多义词"银行"（金融机构 / 河岸）在静态向量里被压成同一个点，要靠上下文向量才能按语境区分。

## 何时用 / 何时不用

- **用**：需要轻量、离线、可解释的相似性特征，或作为下游模型的输入表示。
- **不用**：追求 SOTA 语义理解时已被 BERT 类上下文向量取代；语料太小则训不出好向量。

## 优劣与代价

✅ 把离散词转成稠密可计算表示、捕获语义与类比、较 one-hot 大幅降维、提升下游效果。
⚠️ 静态向量一词一义，处理不好多义与语境。
⚠️ 需大量语料训练、维度与质量要权衡，且已被上下文化表示部分取代。

## 与相关概念的区别

- **vs one-hot**：词向量稠密低维、可度量语义相似；one-hot 稀疏高维、任意词正交。
- **vs [[Embedding 技术详解]]**：词向量特指"词级"嵌入（且多为静态），Embedding 是更广义概念（句 / 段 / 图文、含上下文向量）。
- **vs BERT 上下文向量（[[BERT模型详解]]）**：同一词固定一个向量 vs 随语境变化。

## 常见误区

- 静态词向量能区分多义词，"银行（金融机构）"和"银行（河岸）"有各自不同的向量。
- 词向量本质上就是 one-hot 向量的另一种叫法，二者完全等价。
- king − man + woman ≈ queen 这类类比运算在所有词上都能精确成立、毫无误差。

## 面试速答

> 🎯 词向量用稠密低维向量表示词，让语义相近的词彼此靠近，把离散符号变成可计算的连续表示——源于"观其伴而知其义"的分布式假设。特点是向量可类比（king−man+woman≈queen）、远胜彼此正交的 one-hot。局限是静态向量一词一义，故被上下文向量部分取代。
> 🔍 追问：词向量相比 one-hot 的关键优势？（稠密低维、可度量相似度并编码语义关系；one-hot 稀疏且任意词正交）
> 🔍 追问：为什么静态词向量处理不好"苹果（水果 / 公司）"？（一词只对应一个固定向量，无法按语境切换）
