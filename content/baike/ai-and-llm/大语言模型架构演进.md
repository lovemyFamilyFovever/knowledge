# 大语言模型架构演进

## 概述
从GPT-1到GPT-4、Claude、Gemini，大语言模型的架构经历了巨大演进。

## 发展路线

| 模型 | 年代 | 参数量 | 关键创新 |
|------|------|--------|---------|
| **GPT-1** | 2018 | 117M | Transformer decoder |
| **BERT** | 2018 | 340M | 双向编码 |
| **GPT-2** | 2019 | 1.5B | 零样本学习 |
| **GPT-3** | 2020 | 175B | Few-shot learning |
| **ChatGPT** | 2022 | ~175B | RLHF对齐 |
| **GPT-4** | 2023 | ~1.8T(MoE) | 多模态 |
| **Claude 3** | 2024 | 未知 | 长上下文 |
| **Gemini** | 2024 | 未知 | 原生多模态 |
| **Llama 3** | 2024 | 8B-405B | 开源SOTA |
| **DeepSeek V3** | 2025 | 671B(MoE) | MoE架构 |

## Transformer 架构
```
输入 → Tokenizer → Embedding → [Attention + FFN] x N → 输出概率

自注意力: Q=XWq, K=XWk, V=XWv
Attention(Q,K,V) = softmax(QK^T/sqrt(d))V
```

## 关键技术演进

| 技术 | 说明 | 贡献 |
|------|------|------|
| **RoPE** | 旋转位置编码 | 更好的位置编码 |
| **GQA** | 分组查询注意力 | 减少KV Cache |
| **RMSNorm** | 均方根归一化 | 更稳定训练 |
| **SwiGLU** | SwiGLU激活 | 更好表达力 |
| **FlashAttention** | IO感知注意力 | 加速训练推理 |

## Mixture of Experts (MoE)
```
输入 → Router(门控) → Top-K专家 → 加权合并 → 输出
      每个token只激活部分专家，总参数量大但计算量可控
```

## 开源 vs 闭源

| 维度 | 闭源(GPT-4/Claude) | 开源(Llama/Qwen) |
|------|-------------------|------------------|
| **能力** | 最强 | 快速追赶 |
| **成本** | API付费 | 自部署 |
| **隐私** | 数据上传 | 数据本地 |
| **定制** | 有限 | 完全可控 |
| **更新** | 厂商控制 | 社区驱动 |

## 小结
大模型架构从纯文本走向多模态，从密集模型走向MoE，从闭源走向开源。Transformer仍是核心架构，但效率优化持续推进。
