# 注意力机制


> 📌 **导航**：本文是 **注意力机制** 词条，属于 ai-and-llm 术语集。相关枢纽：[[Transformer架构深度解析]]、[[BERT模型详解]]、[[Embedding 技术详解]]、[[大语言模型架构演进]]。

## 定义

**一句话定义：** 注意力机制是让模型在处理序列或集合时，动态地为不同输入位置分配不同权重、聚焦最相关部分的技术，核心是用 Query-Key-Value 计算相关性再对 Value 加权求和。

**通俗类比：** 像在嘈杂会议室里听某人讲话——你会不自觉聚焦相关的那个声音、压低无关背景；模型对每个位置也这样按"相关性"分配关注权重。

> 多义说明：有 Encoder-Decoder 注意力、自注意力（self-attention）、多头注意力（multi-head）、缩放点积注意力等；本文以 Transformer 的缩放点积自注意力为主。

## 为什么需要它

循环网络（RNN）按序传递信息、远距离依赖易衰减且难以并行。注意力让任意两个位置一步直连、按相关度动态加权聚合，既解决了长程依赖、又能整层并行，因而成为 Transformer 建模序列与关系的核心。

## 核心机制

- **缩放点积注意力**：`Attention(Q, K, V) = softmax(QK^T / √d_k) · V`。Q 查询、K 匹配、V 聚合；QK^T 算相关性分数，除以 `√d_k` 缩放以稳定梯度，softmax 归一为权重，再对 V 加权求和。
- **自注意力 vs 交叉注意力**：自注意力的 Q / K / V 均来自同一序列，可建模序列内任意两位置的依赖、天然处理长程关系；交叉注意力（encoder-decoder）则 Q 来自目标序列、K / V 来自源序列（如翻译对齐）。
- **多头注意力**：并行多组注意力、在不同子空间捕获语法 / 语义 / 指代等多样关系，再拼接融合。

| 组成 | 作用 |
|------|------|
| Query / Key / Value | 查询、匹配、被聚合的信息 |
| 缩放点积 | 计算相关性并稳定梯度 |
| softmax 权重 | 归一化的注意力分布 |
| 多头 | 并行多组、捕获多样关系 |
| 位置编码 | 为注意力注入顺序信息 |

## 具体示例

翻译"猫坐在垫子上，它很舒服"时，"它"通过自注意力给"猫"很高的权重，从而完成指代；Vision Transformer 则把图像切成 patch 当作 token，施加同样的注意力。二者都靠"按相关度加权聚合"把上下文喂给目标位置。

## 何时用 / 何时不用

- **用**：需要建模序列 / 集合内任意位置依赖时——NLP、计算机视觉（ViT）、多模态。
- **不用**：极短或纯局部固定模式的任务（简单 CNN 足够）；超长序列直接用朴素注意力代价过高时，应改稀疏 / 线性注意力或 FlashAttention。

## 优劣与代价

✅ 可并行、直接建模长程依赖、权重有一定可视化价值、扩展性强。
⚠️ 自注意力对序列长度是 O(n²) 复杂度，长序列开销大。
⚠️ 本身不含位置信息（需位置编码），注意力权重的"可解释性"亦存争议。

## 与相关概念的区别

- **vs Transformer**：注意力是其核心组件，Transformer 还含前馈网络、残差连接、层归一与位置编码（详 [[Transformer架构深度解析]]）。
- **vs 早期 seq2seq 注意力**：那是解码器对齐编码器输出的交叉注意力，自注意力则作用于同一序列内部。

## 常见误区

- 注意力权重高的位置，就一定在因果上对输出最重要、可直接当作解释。
- 注意力机制本身自带词序信息，无需再额外加位置编码。
- 自注意力对序列长度是线性 O(n) 复杂度，处理长文本没有开销瓶颈。

## 面试速答

> 🎯 注意力让模型对输入各位置按相关性动态加权、聚焦最相关部分：核心是缩放点积 Attention(Q,K,V)=softmax(QK^T/√d_k)·V——QK^T 算相关、√d_k 缩放稳梯度、softmax 归一后对 V 加权求和。代价是 O(n²) 长序列瓶颈、本身无序需位置编码。
> 🔍 追问：为什么要除以 √d_k？（点积随维度增大方差变大，缩放把 softmax 拉回梯度稳定区）
> 🔍 追问：多头注意力相比单头的好处？（在多个表示子空间并行捕获不同关系，拼接融合表达更丰富）
