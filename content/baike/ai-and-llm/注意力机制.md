# 注意力机制


> 📌 **导航**：本文是 **注意力机制** 词条，属于 ai-and-llm 术语集。相关枢纽：[[AI Agent 概述与核心架构]]、[[AI 应用详解]]、[[Agent 架构模式详解]]、[[BERT模型详解]]、[[Embedding 技术详解]]。

## 定义

**一句话定义：** 注意力机制(Attention Mechanism)是一种让模型在处理序列或集合时,动态地为不同输入位置分配不同"权重"、聚焦于最相关部分的技术;其核心是用 Query-Key-Value 计算相关性权重,再对 Value 加权求和。

**通俗类比：** 像在嘈杂的会议室里听某个人讲话——你会不自觉地把注意力聚焦到相关的那个声音上,自动压低其他无关背景;模型对每个位置也这样按"相关性"分配关注权重。

> 多义说明:有 Encoder-Decoder 注意力、自注意力(self-attention)、多头注意力(multi-head)、缩放点积注意力等;本文以 Transformer 的缩放点积自注意力为主。

## 原理与机制

- **缩放点积注意力:** Attention(Q, K, V) = softmax(Q Kᵀ / √d_k) · V。
- **Q/K/V:** 由输入经线性变换得到;QKᵀ 计算相关性分数,除以 √d_k 缩放以稳定梯度,softmax 归一化为权重,再加权求和 V。
- **自注意力:** Q、K、V 均来自同一序列,可建模序列内任意两个位置的依赖,天然解决长距离依赖问题。
- **多头注意力:** 并行多组注意力,在不同子空间捕获不同类型的关系,再拼接融合。

## 关键组成

| 组成 | 作用 |
|------|------|
| Query / Key / Value | 查询、匹配、被聚合的信息 |
| 缩放点积 | 计算相关性并稳定梯度 |
| softmax 权重 | 归一化的注意力分布 |
| 多头(multi-head) | 并行多组、捕获多样关系 |
| 位置编码 | 为注意力注入顺序信息 |

## 应用场景

- Transformer 及其衍生模型(BERT、GPT 等大模型)
- 机器翻译、语音识别与合成
- 计算机视觉(Vision Transformer)
- 多模态模型

## 优点与局限

- 优点:可并行计算、直接建模长距离依赖、注意力权重具一定可视化价值、扩展性强。
- 局限:自注意力对序列长度是 O(n²) 复杂度(长序列开销大);本身无位置信息(需位置编码);注意力权重的"可解释性"存在争议。

## 常见误区

- 注意力权重高 ≠ 因果上重要,不宜简单当作解释。
- 自注意力的 O(n²) 是长文本瓶颈,催生了 FlashAttention、稀疏/线性注意力等改进。
- 注意力机制 ≠ Transformer:Transformer = 注意力 + 前馈网络 + 残差连接 + 层归一化等。
