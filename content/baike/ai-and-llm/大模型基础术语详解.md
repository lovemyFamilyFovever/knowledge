# 大模型基础术语详解


> 📌 **导航**：本文是 **大模型基础术语详解** 词条，是 ai-and-llm 术语集的名词枢纽。相关枢纽：[[Transformer架构深度解析]]、[[大语言模型架构演进]]、[[注意力机制]]、[[Embedding 技术详解]]。

## 定义

**一句话定义：** 本词条是大模型基础术语的枢纽索引，把 LLM 领域最常考的概念汇成一张地图——能给最短定义的就地讲清，已有专题词条的索引过去，帮入门者一次看清坐标。

## 为什么需要它

入门时术语互相引用、极易迷路：不懂 Token 就没法懂 Embedding，不懂注意力就看不懂 Transformer。一个集中的术语枢纽让你按需下钻，同时建立全局联系，避免在十几个专条之间反复横跳。

## 核心机制

按"从底到用"分五层组织全部术语：

1. **模型与架构层**：LLM（大语言模型）是用海量文本训练、能理解与生成语言的模型，一个模型通吃多任务，区别于逐任务训练的传统 NLP；其骨架是 Transformer，以自注意力并行建模长程关系（详 [[Transformer架构深度解析]]）；按用法分 Encoder-Only（BERT，理解）、Decoder-Only（GPT，生成）、Encoder-Decoder（T5，序列转换）三形态（详 [[大语言模型架构演进]]），而 Self-Attention、Multi-Head、Position Encoding 属于机制细节（详 [[注意力机制]]）。
2. **文本处理层**：模型不直接读字，要先 Token 化——BPE / WordPiece 等把文本切成子词再映射为 ID（详 [[Tokenizer 技术]]）；Embedding 再把 token 转成稠密向量、让语义相近的向量彼此接近，经典如"国王 − 男人 + 女人 ≈ 女王"（详 [[Embedding 技术详解]]）；静态的词向量与之相对（详 [[词向量]]）。
3. **代表模型层**：GPT 系列沿 decoder-only 自回归一路放大（从 GPT-1 的 1.17 亿到 GPT-3 的 1750 亿再到多模态），详 [[GPT系列模型演进]]；BERT 是 Google 的双向理解模型、经 MLM 预训练后微调适配判别任务，详 [[BERT模型详解]]。
4. **生成控制层**：采样决定逐词如何选择。Temperature 是 softmax 的"温度旋钮"，越高越随机、越低越确定（写代码用低温、做创意用高温）；Top-P（核采样）从累积概率达到阈值 P 的最小候选集里随机取词，比固定选 K 个的 Top-K 更自适应——温度改变分布形状、Top-P 截断分布尾部。
5. **能力与风险层**：上下文窗口是一次能处理的最大 token 数，从 GPT-3.5 的约 4K 到 Gemini 1.5 的百万级不等（详 [[长上下文技术]]）；幻觉则是模型一本正经编造不存在事实，例如把"Guido van Rossum 发明 Python"说成"在微软"（实为荷兰 CWI），是 LLM 头号风险，常靠 RAG 与事实核查缓解。

## 具体示例

问"中国的首都是"：LLM 续写"北京"。底层是 Transformer 自注意力把问题里各 token 关联起来，分词先切成 token、Embedding 转成向量，解码时受 Temperature / Top-P 影响选词，整段问答受上下文窗口限制，且答案存在幻觉风险——一条链路恰好串起全表术语。

## 常见误区

- Temperature 设得越高，模型输出就越确定、越适合写代码。
- 上下文窗口越大，就等于模型的训练数据越多、长期记忆越强。
- Top-P 与 Top-K 完全相同，都是固定选前 K 个候选词再采样。

## 面试速答

> 🎯 大模型术语地图分五层：模型架构（LLM/Transformer/enc-dec）→ 文本处理（Token 经 BPE 成 ID、再 Embedding 成向量）→ 代表模型（GPT 生成、BERT 理解）→ 生成控制（Temperature 调随机性、Top-P 核采样）→ 能力与风险（窗口限一次能读多少、幻觉需 RAG 缓解）。
> 🔍 追问：Temperature 和 Top-P 分别管什么？（温度改概率分布的"形状"，Top-P 按累积概率"截尾"限制候选范围）
> 🔍 追问：为什么说 BERT 擅理解、GPT 擅生成？（BERT 双向看全文利于判别，GPT 单向自回归利于逐词生成）
