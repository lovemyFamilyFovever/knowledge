# 词袋模型


> 📌 **导航**：本文是 **词袋模型** 词条，属于 ai-and-llm 术语集。相关枢纽：[[AI Agent 概述与核心架构]]、[[AI 应用详解]]、[[Agent 架构模式详解]]、[[BERT模型详解]]、[[Embedding 技术详解]]。

## 定义

**一句话定义：** 词袋模型(Bag of Words, BoW)是一种把文本表示为"词及其出现次数(或权重)向量"的简单文本表示方法;它忽略词的顺序与语法,只关注"哪些词出现了、各出现多少次",是传统文本分类与信息检索的基础。

**通俗类比：** 像把一句话里的词全倒进一个袋子摇匀,然后只数每种词有几颗——不管它们原来的先后顺序;虽然丢了语序,但"袋子里有哪些词、各多少"已足以大致判断这段文字讲什么。

> 多义说明:BoW 是一种文本表示方法;权重可用词频(TF)或 TF-IDF;区别于考虑顺序的 n-gram 与考虑语义的词向量。本文讨论 BoW。

## 原理与机制

- **构建:** 建立词表(vocabulary)→ 每篇文本表示为长度等于词表大小的向量,每维是该词的出现次数(或权重)。
- **权重:** 计数(词频 TF),或用 TF-IDF(降低常见词权重、突出区分性词)。
- **特点:** 忽略词序与语法(故称"词袋");向量高维稀疏。
- **延伸:** n-gram(保留局部顺序);常与朴素贝叶斯、SVM、逻辑回归等分类器配合。

## 关键组成

| 组成 | 说明 |
|------|------|
| 词表 | 所有词的集合 |
| 词频向量 | 每维是词的出现次数 |
| TF-IDF 权重 | 突出区分性词 |
| 高维稀疏 | 向量特征 |
| 忽略词序 | 主要局限 |

## 应用场景

- 文本分类(垃圾邮件、情感分析)
- 信息检索、文档聚类
- 作为简单 NLP 基线
- 特征工程

## 优点与局限

- 优点:简单、直观、易实现,对许多分类任务有效(配合合适分类器)。
- 局限:丢失词序与语义(无法区分"狗咬人"与"人咬狗");高维稀疏;存在词汇鸿沟(同义词不共享);已被词向量/预训练模型大幅超越。

## 常见误区

- 词袋忽略词序(这是其主要局限)。
- BoW 向量高维稀疏(需 TF-IDF / 降维)。
- 词袋 ≠ 词向量:BoW 是稀疏计数,词向量是稠密语义表示。
- TF-IDF 是 BoW 的加权改进,并非不同的表示范式。
