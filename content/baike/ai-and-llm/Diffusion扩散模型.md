# Diffusion扩散模型


> 📌 **导航**：本文是 **Diffusion扩散模型** 词条，属于 ai-and-llm 术语集。相关枢纽：[[大模型基础术语详解]]、[[Transformer架构深度解析]]、[[RAG 与检索技术详解]]、[[多 Agent 协作系统]]、[[Prompt 工程与 Agent 详解]]。

## 定义

**一句话定义：** 扩散模型是一类生成模型，通过"前向逐步加噪、反向逐步去噪"把学习从噪声还原为数据的过程拆成很多小步，最终从纯噪声采样出图像、音频等样本。

**通俗类比：** 前向像往清水里一滴一滴加墨水直到全黑，反向是训练一个会"一步步把水澄清"的模型——推理时就从一缸纯墨汁反推回一杯清水。

## 为什么需要它

GAN 训练不稳、易模式崩溃，VAE 生成偏糊。扩散把"一步生成"改写成"许多步小去噪"，每步任务都简单，于是训练稳定、样本质量高、可控性强，成为图像生成的主流范式。

## 核心机制

- **前向加噪**：一个固定的过程，随时间步 `t` 逐步向数据加高斯噪声，直到它变成纯噪声。
- **反向去噪**：模型学习"给定带噪的 x_t 和时间步 t，预测这一步所加的噪声 ε"，据此从噪声里一步步雕出清晰样本。
- **训练极简**：随机取时间步、采噪声、把数据加噪成 x_t，让网络预测噪声，用 MSE 监督即可——这是它训练稳定的根本。

```python
def training_step(x0):
    t = randint(0, T)              # 随机时间步
    noise = randn_like(x0)         # 采一个高斯噪声
    x_t = q_sample(x0, t, noise)   # 前向：把原图加噪到 x_t
    pred = model(x_t, t)           # 网络预测所加噪声
    return mse_loss(pred, noise)   # 与真噪声比对，回传
```

**Stable Diffusion** 是潜空间（latent）扩散：不在像素上、而在 VAE 压缩后的潜空间去噪，大幅省算力；文本经 CLIP 编码作条件引导 UNet，Scheduler 控制每步去噪的步长与节奏。

| 组件 | 作用 |
|------|------|
| CLIP | 文本编码，提供生成条件 |
| UNet | 在潜空间预测噪声 |
| VAE | 潜空间与像素互相编解码 |
| Scheduler | 控制去噪步长调度 |

**ControlNet** 则在 SD 之上加入空间条件：Canny 边缘控制轮廓、OpenPose 骨架控制姿态、深度图控制空间关系，让"按图索骥"的结构化生成成为可能。

## 具体示例

文生图"一只戴墨镜的柴犬"：文本经 CLIP 变成条件 → 从随机潜噪声出发 → UNet 在 Scheduler 引导下多步去噪 → VAE 解码为像素。再挂上 ControlNet 的姿态图，就能把狗的坐卧姿势锁死，只换外观。

## 何时用 / 何时不用

- **用**：高保真图像/音视频生成、需要精细条件控制（结构、风格）的场景。
- **不用**：要求单步极速推理、或需要严格可解释概率密度的场合——多步采样是它天然的延迟瓶颈。

## 优劣与代价

✅ 训练稳定、样本质量高、少模式崩溃，条件注入灵活。
⚠️ 推理要多步去噪，速度明显慢于一步生成的 GAN。
⚠️ 算力开销大，Stable Diffusion 用潜空间来缓解这一矛盾。

## 与相关概念的区别

- **vs GAN**：GAN 靠生成器/判别器对抗、一步出图，快但不稳易崩；扩散靠多步去噪，稳且质高但慢。
- **vs [[NeRF与3D生成]]**：NeRF 建模/重建三维辐射场，扩散主要生成二维内容（也可外扩到三维）。

## 常见误区

- 扩散模型训练时学的是"如何一步把噪声变成完整图像"。
- Stable Diffusion 直接在像素空间做去噪，所以不需要 VAE。
- ControlNet 的作用是提升采样速度，与生成内容的结构控制无关。

## 面试速答

> 🎯 扩散模型把生成拆成前向加噪、反向去噪：训练时让网络据 x_t 和 t 预测所加噪声，推理时从纯噪声逐步雕出样本。Stable Diffusion 在 VAE 潜空间去噪、以 CLIP 文本为条件，配 ControlNet 可按边缘/姿态做结构控制——质量高、训练稳，代价是多步采样偏慢。
> 🔍 追问：为什么它比 GAN 训练更稳？（没有对抗博弈，退化为"预测噪声"的监督回归）
> 🔍 追问：Stable Diffusion 为何用潜空间？（在压缩潜空间去噪大幅省算力，再由 VAE 解码回像素）
