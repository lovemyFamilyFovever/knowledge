# 联邦学习

## 核心思想

数据不出本地，模型参数上传聚合。解决数据隐私和数据孤岛问题。

```
中央服务器
    ↓ 分发全局模型
设备A(本地数据) → 训练 → 上传梯度
设备B(本地数据) → 训练 → 上传梯度
设备C(本地数据) → 训练 → 上传梯度
    ↓ 聚合（加权平均）
更新全局模型 -> 下一轮
```

## FedAvg算法

```python
# 服务端
def federated_averaging(local_models, weights):
    """加权平均聚合"""
    global_dict = {}
    for key in local_models[0]:
        global_dict[key] = sum(
            m[key] * w for m, w in zip(local_models, weights)
        )
    return global_dict

# 客户端
def local_train(global_model, local_data, epochs=5):
    model = copy(global_model)
    for epoch in range(epochs):
        for batch in local_data:
            loss = model(batch)
            loss.backward()
            optimizer.step()
    return model.state_dict()
```

## 联邦学习类型

| 类型 | 数据分布 | 场景 | 代表 |
|------|----------|------|------|
| 横向联邦 | 样本不同，特征相同 | 手机键盘预测 | FedAvg |
| 纵向联邦 | 样本相同，特征不同 | 银行+电商联合建模 | SecureBoost |
| 联邦迁移学习 | 样本和特征都不同 | 跨域知识迁移 | - |

## 隐私保护技术

| 技术 | 原理 | 隐私强度 | 性能开销 |
|------|------|----------|----------|
| 差分隐私(DP) | 给梯度加噪声 | 中 | 低 |
| 安全聚合(SA) | 加密梯度聚合 | 高 | 中 |
| 同态加密(HE) | 密文上直接计算 | 最高 | 极高 |
| 可信执行环境(TEE) | 硬件隔离 | 高 | 低 |
| 秘密分享(SS) | 分片存储 | 高 | 中 |

## 挑战与解决

| 挑战 | 说明 | 解决方案 |
|------|------|----------|
| 数据异构性 | 各客户端数据分布不同 | FedProx, 个性化联邦 |
| 通信效率 | 参数量大，通信开销高 | 梯度压缩, 量化 |
| 模型安全 | 恶意客户端投毒 | 鲁邦聚合(Krum/Median) |
| 隐私攻击 | 梯度反推数据 | 差分隐私+安全聚合 |
