# 微调与训练技术详解


> 📌 **导航**：本文是 **微调与训练技术详解** 词条，是大模型训练技术族的枢纽。相关枢纽：[[LLM 微调技术]]、[[大模型预训练技术]]、[[大模型基础术语详解]]、[[Scaling Law]]。

## 定义

**一句话定义：** 本词条是"大模型训练技术"的枢纽索引，覆盖从预训练、SFT / 指令微调、RLHF / DPO 对齐到 LoRA / QLoRA 高效微调，以及数据标注、格式、学习率、epoch、过拟合、混合精度等训练全链概念。

**通俗类比：** 一张"把大模型养大成人"的流程图 + 名词表：预训练是义务教育、SFT 是岗前培训、对齐是"教它讨人喜欢"、LoRA 是"少花钱的进修"，每个术语都就地解释或指向专条。

## 为什么需要它

训练是一条多阶段流水线，术语彼此嵌套（微调里有 SFT，SFT 里学指令，对齐用 PPO）。一个枢纽把全链一次串清，并为每步索引专条，避免只见树木不见森林。

## 核心机制

1. **预训练（可选）**：在海量无标注文本上以"下一词预测"自监督从零学习语言与世界知识，是能力底座；工程与配比见 [[大模型预训练技术]]、[[Scaling Law]]。成本极高（公开估计：GPT-3 175B 约 460 万美元、LLaMA-2 70B 约 200 万美元，建议核验）。
2. **SFT / 指令微调**：用人工标注的 instruction-input-output（Alpaca、ShareGPT 多轮、OpenAI messages 等格式）做监督微调，教模型"听懂指令、按格式回答"；指令微调强调覆盖翻译 / 摘要 / 分类等多类指令。
3. **对齐 RLHF / DPO**：RLHF 走三步——SFT → 训练奖励模型 RM → 用 PPO 优化，教模型"生成人类更喜欢的回答"；DPO 免去独立 RM，直接在 (chosen, rejected) 偏好对上优化。方法细节见 [[LLM 微调技术]]。
4. **参数高效微调（PEFT）**：LoRA 冻结原权重、只训低秩旁路，效果可达全量微调约 90-95%、只训练约 0.1% 参数；QLoRA 再叠 4-bit 量化，可把 65B 模型压到单卡可训。详见 [[LLM 微调技术]]。
5. **训练基本功**：数据标注质量决定上限（工具如 Label Studio、Doccano、Prodigy）；过拟合表现为训练集高、验证集低（如训练 98% / 验证 65%），靠加数据、Dropout、Early Stopping、数据增强缓解，而欠拟合是两者都低；学习率太大会震荡、太小收敛慢，常用 warmup + decay；Epoch / Batch / Step 控训练量（如 10 万样本、批 32、3 轮 → 每轮约 3125 步、共约 9375 步）；混合精度（FP16 + FP32）让 7B 模型显存从约 112GB 降到约 80GB、提速约 1.5-3 倍。

## 具体示例

把通用 Llama 做成客服：一般跳过预训练 → 用数万条客服问答做 SFT → 再用 DPO / RLHF 对齐语气与合规 → 用 QLoRA 在单卡上跑 → 训练时盯训练 / 验证 loss 判断过拟合或欠拟合、并调学习率。

## 何时用 / 何时不用

- **用**：作为训练全链索引，定位某技术该去哪篇深看。
- **不用**：从零预训练最贵——多数任务只需微调 + 对齐即可。

## 优劣与代价

✅ 一条流水线串起训练全链，各概念一句定位。
⚠️ 点到为止，不能替代 LoRA / 预训练 / RLHF 等专条的深度。
⚠️ 文中成本与显存数字多为公开估计，会随硬件与版本变化，须核验。

## 与相关概念的区别

- **vs [[LLM 微调技术]]**：那条聚焦 PEFT 与对齐方法族，本条是含预训练到部署的训练全链总览。
- **vs [[大模型预训练技术]]**：那条专讲从头预训练，本条把它当作流水线的第一环来索引。

## 常见误区

- SFT 会改变模型的底层知识储备，其作用等同于再预训练一遍。
- 出现"训练集准确率 98%、验证集 65%"是欠拟合，应继续加大模型容量。
- LoRA 需要解冻并更新模型的全部权重，所谓省显存只是错觉。

## 面试速答

> 🎯 大模型训练是一条流水线：预训练（海量文本自监督打底）→ SFT 指令微调（标注问答学格式）→ 对齐 RLHF（SFT→RM→PPO）或 DPO（偏好对直训）；PEFT 让微调可负担——LoRA 冻主干只训低秩旁路、QLoRA 叠 4-bit 量化。多数场景不必从零预训练。
> 🔍 追问：RLHF 与 DPO 的关键区别？（RLHF 需训练独立奖励模型再 PPO；DPO 直接在偏好对上优化，更简更稳）
> 🔍 追问：为什么"训练集准、验证集差"是过拟合？（模型记住了训练噪声，泛化差，应加数据 / 正则而非加容量）
