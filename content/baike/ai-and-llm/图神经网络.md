# 图神经网络


> 📌 **导航**：本文是 **图神经网络** 词条，属于 ai-and-llm 术语集。相关枢纽：[[大模型基础术语详解]]、[[Transformer架构深度解析]]、[[知识图谱与 LLM 结合]]、[[机器学习基础]]。

## 定义

**一句话定义：** 图神经网络（GNN）是在图结构数据（节点 + 边）上学习的神经网络，通过"消息传递"让每个节点聚合邻居信息更新自身表示，适配社交网络、分子、知识图谱等非欧数据。

**通俗类比：** 像"近朱者赤"的迭代传播——每个节点的表示由它自己和一圈邻居不断"传染"融合；传几层后，节点就"知道"了自己周围小世界的信息。

## 为什么需要它

CNN / RNN 是为网格和序列设计的，而图数据既无固定顺序也无固定邻居数。GNN 用不依赖节点排列的消息传递把"关系结构"纳入学习，让"谁和谁相连"成为可建模的信号，这正是表格 / 序列模型做不到的。

## 核心机制

其核心是**消息传递范式（message passing）**：逐层地，每个节点聚合（aggregate）邻居特征生成消息，再与自身特征合并更新（update）表示；堆 L 层即让每个节点"看到" L 跳邻域。

```python
for layer in range(num_layers):
    for node in graph.nodes:
        msgs = [aggregate(node.feat, nb.feat) for nb in graph.neighbors(node)]
        node.feat = update(node.feat, aggregate_all(msgs))   # 聚合邻居 → 更新自身
```

不同模型的本质差异就在"如何聚合邻居"：

| 模型 | 聚合方式 | 特点 |
|------|----------|------|
| GCN | 归一化求和 | 简单高效 |
| GAT | 注意力加权 | 自适应邻居权重 |
| GraphSAGE | 采样 + 聚合 | 支持归纳学习（未见节点） |
| GIN | 求和 + MLP | 区分图结构表达力最强 |

输出层再按任务做节点级（分类）、边级（链接预测）或图级（池化后整体预测）。

## 具体示例

推荐场景：用户与商品构成二部图，消息传递让"和你买过同款的人还买了什么"沿边传播，生成带交互信号的节点表示来预测下一步点击；分子性质预测则把原子当节点、化学键当边，聚合出分子级表示。

## 何时用 / 何时不用

- **用**：数据本质是关系图时——推荐、风控反欺诈、分子建模、知识图谱。
- **不用**：样本独立同分布的表格 / 图像 / 文本且无显式关系时，CNN / RNN / Transformer 更直接。

## 优劣与代价

✅ 显式建模关系、跨节点共享信息，擅长非欧结构数据。
⚠️ 堆太多层会"过平滑"，节点表示趋于相似、难以区分。
⚠️ 大规模图需采样（如 GraphSAGE），且对噪声边、结构缺失较敏感。

## 与相关概念的区别

- **vs [[Transformer架构深度解析]]**：注意力让"任意两个 token 全连接"，GNN 只在"真实存在的边"上传消息，可把图看作被结构约束的稀疏注意力。
- **vs [[知识图谱与 LLM 结合]]**：知识图谱是结构化知识表示，GNN 是在图上学习的模型，二者常配合。

## 常见误区

- GNN 堆的层越多越好，因为深度能无限增强节点的区分度。
- GAT 与 GCN 完全相同，都不对邻居区别对待。
- 图神经网络只能处理固定长度序列，无法建模任意结构。

## 面试速答

> 🎯 GNN 在"节点 + 边"的图上做消息传递：每层让节点聚合邻居特征、更新自身表示，堆 L 层即覆盖 L 跳邻域，输出可做节点/边/图级任务。模型差异在聚合方式：GCN 归一化求和、GAT 注意力加权、GraphSAGE 采样 + 聚合支持归纳、GIN 表达力最强。适合推荐、风控、分子等关系数据；要警惕过平滑与采样开销。
> 🔍 追问：什么是过平滑、怎么缓解？（多层聚合使节点表示趋同难分，靠限制层数 / 残差 / 跳连 / 采样缓解）
> 🔍 追问：GAT 比 GCN 强在哪？（用注意力给邻居自适应加权，重要邻居影响更大，而非固定归一化）
