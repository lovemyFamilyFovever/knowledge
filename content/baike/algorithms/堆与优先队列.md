# 堆与优先队列


> 📌 **导航**：本文是 **堆与优先队列** 词条，属于 algorithms 术语集。相关枢纽：[[AVL 树]]、[[KMP 算法]]、[[二分查找]]、[[二叉搜索树]]、[[位运算]]。

## 定义

**一句话定义：** 堆(Heap)是一种用数组实现的完全二叉树,满足堆序性质(最大堆:父 ≥ 子;最小堆:父 ≤ 子);优先队列(Priority Queue)是一种按优先级取出最值元素的抽象数据结构,通常用堆来实现。

**通俗类比：** 像医院急诊分诊——不是先到先看,而是病情最重(优先级最高)的先处理;系统每次都能快速找到并取出"最紧急"的那位,新病人来了也能快速插入到合适位置。

> 多义说明:堆(数据结构)≠ 程序内存的"堆区"(见 [[垃圾回收]]);本文指数据结构堆。最常见的是二叉堆,另有斐波那契堆等变体。

## 原理与机制

- **结构:** 完全二叉树,用数组存储——下标 i 的父为 ⌊(i−1)/2⌋,左右子为 2i+1、2i+2,无需指针。
- **堆序:** 最大堆中父 ≥ 子(根为最大值);最小堆中父 ≤ 子(根为最小值)。
- **核心操作:** 插入(放到末尾后"上浮"sift-up)、取最值并删除(用末尾元素补根后"下沉"sift-down)、线性建堆(heapify,O(n))。
- **复杂度:** 插入/删除 O(log n),查看最值 O(1),建堆 O(n)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 完全二叉树 | 结构约束,可用数组紧凑存储 |
| 数组表示 | 用下标计算父子关系 |
| 堆序性质 | 父与子的大小关系 |
| 上浮 / 下沉 | 插入与删除后的修复 |
| 建堆(heapify) | O(n) 从无序数组构造堆 |

## 应用场景

- 优先队列与任务调度
- 堆排序(Heapsort)
- Top-K 问题、数据流中位数(对顶堆)
- Dijkstra、Prim 等图算法的优先队列

## 优点与局限

- 优点:取最值 O(1)、增删 O(log n);数组实现省内存;建堆线性时间。
- 局限:只能高效访问最值,不支持任意元素的快速查找或有序遍历;二叉堆的 decrease-key 较慢(斐波那契堆改进);缓存局部性一般。

## 常见误区

- 堆 ≠ 有序数组:堆只保证父子间的大小关系,整体并非有序,故遍历结果无序。
- 堆(数据结构)≠ 内存堆区(运行时内存)。
- 堆排序是原地排序但不稳定;优先队列是抽象类型,堆只是其一种实现。
