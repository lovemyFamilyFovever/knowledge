# 最小生成树

## 定义

**一句话定义：** 最小生成树(Minimum Spanning Tree, MST)是在一个连通的带权无向图中,选出若干条边把所有顶点连通、且不含环、边权之和最小的一棵生成树;它用最小的总代价连接所有节点。

**通俗类比：** 像要在几个村庄之间修路,让任意两村都能互通(直接或间接),但总修路里程(成本)最省——MST 就是这套"最省钱的全连通方案"。

> 多义说明:生成树(spanning tree)是连通全图且无环的子图;最小生成树是其中边权之和最小者。当存在权值相等的边时,MST 可能不唯一。仅适用于连通无向带权图。

## 原理与机制

- **贪心 + 切割性质(cut property):** 跨越任一"割"(把顶点分成两部分)的最短边,必定属于某个 MST。
- **Kruskal 算法:** 将所有边按权排序,依次选取不构成环的边(用并查集判环),直到选够 V−1 条;复杂度 O(E log E)。
- **Prim 算法:** 从一个顶点出发,每次加入连接"已选集合"与"未选集合"的最小边(用优先队列);复杂度 O((V+E) log V)。
- **结果特征:** V 个顶点、V−1 条边、无环、连通、边权和最小。

## 关键组成

| 组成 | 说明 |
|------|------|
| 连通带权无向图 | MST 的前提 |
| 切割性质 | 贪心正确性的依据 |
| Kruskal + 并查集 | 按边贪心、判环 |
| Prim + 优先队列 | 按点扩展 |
| V−1 条边 | 生成树的边数 |

## 应用场景

- 网络布线、通信网与公路/管道设计
- 聚类分析
- 旅行商问题(TSP)的近似算法
- 电路设计

## 优点与局限

- 优点:给出最优的全连通方案,算法高效成熟。
- 局限:仅适用于连通无向带权图;边权相等时 MST 不唯一;动态图需重新计算;它不提供两点间的最短路径(那是最短路径问题)。

## 常见误区

- MST ≠ 最短路径:MST 求"连通所有点的最小总权",最短路径求"两点间的最小路径"。
- MST 不一定唯一。
- MST 恰有 V−1 条边,但"边少"不是目标,"权和最小"才是。
- Dijkstra 求最短路径、Prim/Kruskal 求 MST,算法形似但目标不同。
