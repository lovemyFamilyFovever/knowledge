# 算法思想

> 算法思想是解决特定类型问题的通用策略模板。掌握这些模板，面对新问题时能快速匹配合适的解法。
>
> 📌 **导航**：本文是 **算法思想** 枢纽页。原 13 节汇编中，双指针 / 滑动窗口与前缀和 / 差分已各拆为一个族词条；分治、动态规划、贪心、回溯、拓扑排序、并查集、最短路径、最小生成树本就各有专条，本页只保留判据与速查表。

## 定义

**一句话定义：** 算法思想是从问题结构反推解法范式的判据集——看子问题是否独立、是否重叠、有无贪心选择性、是否要穷举、有无单调性或区间可逆性，据此在分治、DP、贪心、回溯与预处理技巧之间做选择。

**通俗类比：** 像医院的分诊台：不问"用哪种药"，先问"该挂哪一科"。科室判对，具体算法只是把套路填进去；判错，后面再努力也是白跑。

本页是**枢纽页**：给出"特征 → 范式"的映射与速查表，各思想本体走下表双链。

## 为什么需要它

同一道题换一种范式，复杂度能从 O(n²) 掉到 O(n log n) 甚至 O(n)；反过来用错范式，再精细的常数优化也救不回来。而范式不能靠背题获得，只能靠**识别问题特征**：子问题独立 → 分治；重叠 + 最优子结构 → DP；局部最优可推全局最优 → 贪心；要枚举所有解且可剪枝 → 回溯；区间运算可逆 → 前缀和；批量区间改 → 差分。把这层映射固化下来，就是本页的价值。

## 核心机制

### 判据先看子问题

三个问题依次过滤：**子问题之间是否重叠**（独立走分治、重叠走 DP）；**是否只需一条最优链**（贪心选择性质成立就不必记全表，否则退回 DP）；**是否要给出所有解**（要则回溯 + 剪枝，只需最优值则不必保留路径）。这一步判错，后面所有实现都是白写。

### 线性结构上另有三板斧

不等式的单调性与运算的可逆性，能绕过上述分诊直接给线性解：有序或单调 → [[双指针与滑动窗口]]；区间和 / 异等可逆运算 → [[前缀和与差分]]；判定单调但答案不连续 → [[二分查找]]。三者是"规模大但结构简单"时最省力的套路。

### 图与依赖另成一族

定序与判环看 [[拓扑排序]]（能排完 ⇔ 无环）；动态连通性看 [[并查集]]；两点或多点最短距离看 [[最短路径算法]]，最小代价连通看 [[最小生成树]]；遍历本身只有两种——DFS 与 BFS，见 [[图算法大全]]。

## 具体示例

同一批区间查询，两种写法差一个量级：

```python
pre = [0]
for x in a: pre.append(pre[-1] + x)      # 建表 O(n)
total = pre[r + 1] - pre[l]              # 每次查询 O(1)
```

若每次查询都重扫区间，m 次就是 O(n·m)；若中途还要单点改动，前缀和表得重建，此时才该升级到树状数组或线段树——**"会不会变"正是选范式时必须一起问的问题**。

## 何时用与何时不用

- **用**：拿到陌生问题先做范式分诊再动手；复习时按思想而非题号组织题单；评审时质疑"这题是否真需要 DP"。
- **不用**：规模很小、判错范式也不致命时，直白暴力反而更可靠可维护；也不要为套范式强改题面（把非连续问题硬塞进滑动窗口是典型错误）。
- **组合**：真实难题常是多范式串联，如"二分答案 + 贪心判定""DP + 前缀和加速转移"。

## 优劣与代价

✅ 把选型变成可推理的过程，显著缩小尝试空间，也让复杂度结论有依据。
✅ 速查表可复用，是复习与面试的高杠杆索引。
⚠️ 判据只给方向、不保证成立——贪心必须用交换论证证明，否则得到次优解。
⚠️ 过度套模板会掩盖更简单的解法，把 O(n) 哈希题做成 O(n log n) 的复杂结构。

## 与相关概念的区别

- **范式 vs 具体算法**：本页管"该用哪类方法"，[[排序与搜索]] 等是"这类方法里的实现"。
- **分治 vs DP**：都以子问题递归，区别只在子问题是否重叠——独立用分治，重叠要记忆化或填表。
- **贪心 vs DP**：贪心不回溯、只走一条选择链且需证明贪心选择性质；DP 保留所有子解，正确性只需最优子结构。
- **回溯 vs 暴力枚举**：回溯的核心是剪枝，去掉整片无效子树，否则就是指数级暴力。

## 常见误区

- 只要是在求最值，就一定得上动态规划。
- 贪心策略在样例上跑得通，就说明它是正确的。
- 双指针、前缀和只是常数级小技巧，算不上算法范式。

## 面试速答

> 🎯 算法思想靠问题特征分诊：子问题独立用分治、重叠用 DP、能证贪心选择性用贪心、要所有解用回溯加剪枝；有序或单调走双指针滑窗、区间可逆走前缀和差分、判定单调走二分，图问题再看拓扑排序、并查集与最短路。
