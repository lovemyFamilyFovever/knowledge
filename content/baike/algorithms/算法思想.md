# 算法思想

> 算法思想是解决特定类型问题的通用策略模板。掌握这些模板，面对新问题时能快速匹配合适的解法。
>
> 📌 **导航**：本文汇总通用**算法思想/套路**（分治、动态规划、贪心、回溯、双指针、滑动窗口、前缀和、差分等）。其中拓扑排序、并查集、最短路径、最小生成树已有专门词条，见 [[拓扑排序]]、[[并查集]]、[[最短路径算法]]、[[最小生成树]]；动态规划深入见 [[动态规划]]。

## 分治法（Divide and Conquer）

### 一句话定义
把大问题拆成小问题，递归解决小问题，再把结果合并。

### 通俗类比
公司拆 KPI：CEO 把目标拆给总监，总监拆给经理，经理拆给员工，最后逐级汇报汇总结果。

### 具体示例
```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])   # 分
    right = merge_sort(arr[mid:])
    return merge(left, right)       # 治（合并）

def merge(l, r):
    result, i, j = [], 0, 0
    while i < len(l) and j < len(r):
        if l[i] <= r[j]:
            result.append(l[i]); i += 1
        else:
            result.append(r[j]); j += 1
    return result + l[i:] + r[j:]
```

### 三步走
1. **分**（Divide）：将问题拆成若干子问题
2. **治**（Conquer）：递归求解子问题
3. **合**（Combine）：合并子问题的解

### 为什么需要它
适合问题可以拆分、子问题独立、合并代价低的场景。经典应用：归并排序、快速排序、最近点对问题。

## 动态规划（Dynamic Programming）

### 一句话定义
把问题分解为重叠子问题，通过**记住已算过的结果**避免重复计算。

### 通俗类比
你去一个从没去过的城市，把每条路都走一遍并记在本子上，下次遇到同样的路口直接查本子。

### 核心概念
- **状态**：子问题的描述（如 `dp[i]` 表示前 i 个元素的最优解）
- **状态转移方程**：子问题之间的递推关系
- **记忆化**：用数组/哈希表缓存已计算的结果

### 具体示例：0-1 背包
```python
def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [0] * (capacity + 1)
    for i in range(n):
        for w in range(capacity, weights[i] - 1, -1):
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    return dp[capacity]

weights = [2, 3, 4, 5]
values = [3, 4, 5, 6]
print(knapsack(weights, values, 8))  # 输出 10
```

### 两种实现方式
| 方式 | 说明 | 适用场景 |
|------|------|----------|
| 自顶向下（记忆化） | 递归 + 缓存 | 子问题不规则 |
| 自底向上（表格法） | 迭代填表 | 子问题有序 |

### 为什么需要它
斐波那契、背包问题、最长公共子序列、编辑距离、股票买卖等最优解问题。

## 贪心算法（Greedy）

### 一句话定义
每一步都选当前看起来最优的方案，不回头，期望全局最优。

### 通俗类比
找零钱：每次都给面额最大的硬币，快速凑够金额。

### 具体示例：活动选择问题
```python
def activity_selection(activities):
    activities.sort(key=lambda x: x[1])  # 按结束时间排序
    result = [activities[0]]
    for act in activities[1:]:
        if act[0] >= result[-1][1]:  # 开始时间 >= 上一个结束时间
            result.append(act)
    return result

activities = [(1,4), (3,5), (0,6), (5,7), (3,9), (5,9), (6,10), (8,11)]
print(activity_selection(activities))
```

### 为什么需要它
简单高效，但**不一定能得到全局最优解**。适用场景需要证明贪心选择性质和最优子结构。

## 回溯法（Backtracking）

### 一句话定义
系统地搜索解空间，发现走不通就**回退**撤销上一步，尝试其他选择。

### 通俗类比
走迷宫：每到一个路口选一条路走，如果碰壁就退回来换条路，直到找到出口。

### 具体示例：N 皇后
```python
def solve_n_queens(n):
    result = []

    def backtrack(board, row):
        if row == n:
            result.append([''.join(r) for r in board])
            return
        for col in range(n):
            if is_valid(board, row, col):
                board[row][col] = 'Q'
                backtrack(board, row + 1)
                board[row][col] = '.'  # 回溯：撤销选择

    def is_valid(board, row, col):
        for i in range(row):
            if board[i][col] == 'Q':
                return False
            if col - (row - i) >= 0 and board[i][col - (row - i)] == 'Q':
                return False
            if col + (row - i) < len(board) and board[i][col + (row - i)] == 'Q':
                return False
        return True

    board = [['.' for _ in range(n)] for _ in range(n)]
    backtrack(board, 0)
    return result

print(len(solve_n_queens(8)))  # 输出 92（8 皇后的解的数量）
```

### 为什么需要它
排列组合、子集、N 皇后、数独求解等需要穷举的问题。

## 双指针（Two Pointers）

### 一句话定义
用两个指针在数据结构上移动，协同完成搜索、比较或合并操作。

### 通俗类比
两人合作搬箱子：一个人在左边，一个人在右边，同时向中间推进。

### 具体示例：两数之和
```python
def two_sum_sorted(arr, target):
    left, right = 0, len(arr) - 1
    while left < right:
        s = arr[left] + arr[right]
        if s == target:
            return [left, right]
        elif s < target:
            left += 1
        else:
            right -= 1
    return [-1, -1]

print(two_sum_sorted([2, 7, 11, 15], 9))  # 输出 [0, 1]
```

### 常见变体
| 类型 | 说明 | 应用 |
|------|------|------|
| 对撞指针 | 两端向中间移动 | 有序数组两数之和 |
| 快慢指针 | 一快一慢 | 判断链表环、找中间节点 |
| 同向指针 | 两个指针同向但不同速 | 移除重复元素 |

### 为什么需要它
把 O(n²) 的暴力搜索优化到 O(n)。

## 滑动窗口（Sliding Window）

### 一句话定义
维护一个窗口范围 [left, right]，右指针扩展窗口，左指针收缩窗口，保持窗口满足某种条件。

### 通俗类比
看报纸：你的眼镜框是窗口，右眼向右多看一个字（扩展），左眼向右挪一个字（收缩）。

### 具体示例：最长无重复子串
```python
def longest_unique_substring(s):
    char_set = set()
    left = 0
    max_len = 0
    for right in range(len(s)):
        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1
        char_set.add(s[right])
        max_len = max(max_len, right - left + 1)
    return max_len

print(longest_unique_substring("abcabcbb"))  # 输出 3（"abc"）
```

### 为什么需要它
子串/子数组问题的通用模板，时间复杂度 O(n)。适用于最长/最短/包含特定元素的窗口问题。

## 前缀和（Prefix Sum）

### 一句话定义
预先计算从起点到每个位置的累加和，查询区间和时只需两次查表相减。

### 通俗类比
水电表读数：今天的读数减去昨天的读数，就是今天的用水量。

### 具体示例
```python
def prefix_sum_queries(arr, queries):
    prefix = [0] * (len(arr) + 1)
    for i in range(len(arr)):
        prefix[i + 1] = prefix[i] + arr[i]

    results = []
    for left, right in queries:
        results.append(prefix[right + 1] - prefix[left])
    return results

arr = [2, 4, 6, 8, 10]
queries = [(0, 2), (1, 3), (2, 4)]
print(prefix_sum_queries(arr, queries))  # [12, 18, 24]
```

### 为什么需要它
区间求和查询从 O(n) 降到 O(1)，也用于二维矩阵和异或运算。

## 差分数组

### 一句话定义
只记录每个位置相比前一个位置的**变化量**，批量区间增减操作只需 O(1)。

### 通俗类比
记账不记总金额，只记每天的进出差额，查余额时累加即可。

### 具体示例
```python
def difference_array(n, operations):
    diff = [0] * (n + 1)
    for left, right, val in operations:
        diff[left] += val
        diff[right + 1] -= val

    result = [0] * n
    result[0] = diff[0]
    for i in range(1, n):
        result[i] = result[i - 1] + diff[i]
    return result

# 区间 [1,3] 加 5，区间 [2,5] 加 3
print(difference_array(6, [(1, 3, 5), (2, 5, 3)]))
# [0, 5, 8, 8, 3, 3]
```

### 为什么需要它
大量区间增减操作时，从 O(n) 降到 O(1)。常用于日志分析、资源分配。

## 拓扑排序（Topological Sort）

### 一句话定义
对有向无环图（DAG）的节点进行线性排序，使得所有边从排在前面的节点指向后面的节点。

### 通俗类比
课程先修关系：学数据结构前要先学 C 语言和离散数学，排课表必须满足这个依赖。

### 具体示例
```python
from collections import deque

def topological_sort(graph, in_degree):
    queue = deque([node for node in in_degree if in_degree[node] == 0])
    result = []
    while queue:
        node = queue.popleft()
        result.append(node)
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
    return result

graph = {'A': ['B', 'C'], 'B': ['D'], 'C': ['D'], 'D': []}
in_degree = {'A': 0, 'B': 1, 'C': 1, 'D': 2}
print(topological_sort(graph, in_degree))  # ['A', 'B', 'C', 'D'] 或类似
```

### 为什么需要它
任务调度、编译依赖顺序、课程安排、构建系统（Make、Webpack）。

## 并查集（Union-Find）

### 一句话定义
高效处理**动态连通性**问题的结构，支持合并两个集合和查询两个元素是否在同一集合。

### 通俗类比
社交网络中判断两人是否是好友的好友：通过不断合并关系链来判断连通性。

### 具体示例
```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # 路径压缩
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True

# 使用示例：判断图的连通分量
uf = UnionFind(6)
edges = [(0,1), (1,2), (3,4)]
for u, v in edges:
    uf.union(u, v)
print(uf.find(0) == uf.find(2))  # True
print(uf.find(0) == uf.find(3))  # False
```

### 为什么需要它
Kruskal 最小生成树、网络连通性判断、社交网络好友关系。近 O(1) 操作。

## 最短路径算法

### 一句话定义
在加权图中找到从起点到终点（或所有点）的路径，使得边权之和最小。

### 通俗类比
导航找路：从家到公司有很多条路，你需要找到总耗时最少的那条。

### 算法选型
| 算法 | 适用场景 | 时间复杂度 |
|------|----------|-----------|
| BFS | 无权图 | O(V+E) |
| Dijkstra | 非负权图，单源 | O((V+E) log V) |
| Bellman-Ford | 可含负权，单源 | O(VE) |
| Floyd-Warshall | 全源最短路 | O(V³) |
| A* | 有启发函数的寻路 | O(E) |

### 为什么需要它
导航系统、网络路由、游戏 AI、物流配送路径规划。

## 最小生成树（MST）

### 一句话定义
在加权无向连通图中找到一棵包含所有顶点的树，使得总边权最小。

### 通俗类比
在几个村庄之间修路，怎么修能让所有村都通路且总造价最低。

### Kruskal 算法
```python
def kruskal(n, edges):
    edges.sort(key=lambda x: x[2])  # 按边权排序
    uf = UnionFind(n)
    mst = []
    for u, v, w in edges:
        if uf.union(u, v):
            mst.append((u, v, w))
            if len(mst) == n - 1:
                break
    return mst
```

### Prim 算法
```python
import heapq

def prim(graph, start=0):
    visited = {start}
    mst = []
    edges = [(w, start, to) for to, w in graph[start]]
    heapq.heapify(edges)

    while edges and len(visited) < len(graph):
        w, u, v = heapq.heappop(edges)
        if v in visited:
            continue
        visited.add(v)
        mst.append((u, v, w))
        for to, w2 in graph[v]:
            if to not in visited:
                heapq.heappush(edges, (w2, v, to))
    return mst
```

### Kruskal vs Prim 对比
| 特性 | Kruskal | Prim |
|------|---------|------|
| 思路 | 全局贪心，按权排序 | 局部扩展，从某点开始 |
| 数据结构 | 并查集 | 优先队列 |
| 适合场景 | 稀疏图 | 稠密图 |
| 时间 | O(E log E) | O(E log V) |

### 为什么需要它
网络布线、电路设计、聚类分析（删除最长边实现聚类）。

## 算法思想速查表

| 问题特征 | 推荐思想 |
|----------|----------|
| 问题可拆分且子问题独立 | 分治法 |

| 需要穷举所有可能 | 回溯法 |

| 区间求和 | 前缀和 |
| 批量区间修改 | 差分数组 |
| 依赖关系排序 | 拓扑排序 |
| 动态连通性 | 并查集 |
| 图中找最短路 | Dijkstra / Floyd |
| 图中找最小代价连接 | 最小生成树 |
