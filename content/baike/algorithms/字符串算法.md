# 字符串算法

## KMP算法

KMP（Knuth-Morris-Pratt）算法通过预处理模式串，避免重复匹配，时间复杂度O(n+m)。

```python
def build_next(pattern):
    """构建next数组（失败函数）"""
    next_arr = [0] * len(pattern)
    j = 0
    for i in range(1, len(pattern)):
        while j > 0 and pattern[i] != pattern[j]:
            j = next_arr[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        next_arr[i] = j
    return next_arr

def kmp_search(text, pattern):
    next_arr = build_next(pattern)
    j = 0
    results = []
    for i in range(len(text)):
        while j > 0 and text[i] != pattern[j]:
            j = next_arr[j - 1]
        if text[i] == pattern[j]:
            j += 1
        if j == len(pattern):
            results.append(i - j + 1)
            j = next_arr[j - 1]
    return results
```

**核心思想：** 当匹配失败时，利用已匹配的信息跳过不必要的比较。

## 后缀数组（Suffix Array）

后缀数组是文本所有后缀按字典序排序后的索引数组。

```
文本: banana
后缀: banana(0), anana(1), nana(2), ana(3), na(4), a(5)
排序: a(5), ana(3), anana(1), banana(0), na(4), nana(2)
SA:   [5, 3, 1, 0, 4, 2]
```

**应用场景：**
- 最长重复子串
- 最长公共子串
- 模式匹配（配合LCP数组）
- 生物信息学（DNA序列比对）

## AC自动机（Aho-Corasick）

多模式匹配算法，用于同时搜索多个关键词。

```
构建流程:
1. 将所有模式构建成Trie树
2. 构建失败指针（类似KMP的next数组）
3. BFS遍历，沿失败指针回跳

时间复杂度: O(n + m + z)
- n: 文本长度
- m: 所有模式串总长度
- z: 匹配结果数量
```

**应用：** 敏感词过滤、病毒特征检测、搜索引擎关键词高亮。

## Rabin-Karp算法

利用滚动哈希实现O(n)期望时间的字符串匹配：

```python
def rabin_karp(text, pattern):
    n, m = len(text), len(pattern)
    base = 256
    mod = 10**9 + 7

    # 计算pattern的哈希
    pat_hash = 0
    for c in pattern:
        pat_hash = (pat_hash * base + ord(c)) % mod

    # 滚动窗口计算text的哈希
    txt_hash = 0
    power = pow(base, m - 1, mod)
    for i in range(n):
        txt_hash = (txt_hash * base + ord(text[i])) % mod
        if i >= m:
            txt_hash = (txt_hash - ord(text[i-m]) * power) % mod
        if i >= m - 1 and txt_hash == pat_hash:
            if text[i-m+1:i+1] == pattern:  # 哈希碰撞验证
                return i - m + 1
    return -1
```

## 字符串算法对比

| 算法 | 时间复杂度 | 预处理 | 适用场景 |
|------|-----------|--------|----------|
| 暴力匹配 | O(n*m) | 无 | 短模式串 |
| KMP | O(n+m) | O(m) | 单模式匹配 |
| Rabin-Karp | O(n+m)期望 | O(m) | 多模式匹配 |
| AC自动机 | O(n+m+z) | O(m) | 多关键词匹配 |
| 后缀数组 | O(n log n) | O(n log n) | 复杂查询 |
