# 贪心算法


> 📌 **导航**：本文是 **贪心算法** 词条，属于 algorithms 术语集。相关枢纽：[[AVL 树]]、[[KMP 算法]]、[[二分查找]]、[[二叉搜索树]]、[[位运算]]。

## 定义

**一句话定义：** 贪心算法（Greedy Algorithm）是一种在每一步都做出当前看起来最优（局部最优）的选择、并期望由此得到全局最优解的算法策略；它不回溯、不穷举，一旦做出选择便不再更改。

**通俗类比：** 像找零钱时每次都先给面额最大的硬币，希望用最少硬币凑出金额；在很多币制下这样确实最优，但并非所有情况都成立（贪心不一定总对）。

> 多义说明：贪心是算法设计范式之一（与分治、动态规划并列）；只有当问题满足"贪心选择性质"与"最优子结构"时才保证全局最优。本文讨论贪心范式。

## 为什么需要它

对某些结构良好的问题，"当前最优"其实能一路导出"全局最优"——那就不必像穷举或 DP 那样保留所有子问题，直接每步选最优即可，往往做到 O(n) 或 O(n log n)，又快又易实现。活动选择、霍夫曼编码、Dijkstra 等正是如此，用贪心省下了 DP 的额外空间与时间。

## 核心机制

- **核心：** 每步取局部最优且不可逆；依赖问题具备贪心选择性质（局部最优能推出全局最优）与最优子结构。
- **正确性：** 需证明"存在一个最优解包含当前贪心选择"（反证/交换论证）。
- **经典实例：** 活动选择、霍夫曼编码、[[最短路径算法|Dijkstra]]、[[最小生成树|Prim/Kruskal]]、分数背包。

| 组成 | 说明 |
|------|------|
| 贪心选择 | 每步取当前最优 |
| 最优子结构 | 子问题最优可推出整体最优 |
| 不可回溯 | 选择一旦做出不再更改 |
| 可行性判断 | 保证选择满足约束 |

## 具体示例

活动选择（最多不冲突活动）：按结束时间升序，每次取"开始时间不早于上一个所选结束时间"的最早结束活动——直觉"结束越早留空间越多"，可用交换论证证明贪心得最优。找零用面额 {1,3,4} 凑 6：贪心先取 4 再 1、1 得 3 张，而最优是 3、3 两张，说明一般币制下贪心会失效，须换 DP。

## 何时用 / 何时不用

- **用：** 问题具贪心选择性质 + 最优子结构且易证明——活动选择、霍夫曼编码、分数背包、Dijkstra、MST 等。
- **不用：** 贪心性质不成立时（0-1 背包、一般找零非规范币制）——须用 [[动态规划]]；正确性无法证明时不要盲用贪心。

## 优劣与代价

✅ 简单高效（常 O(n log n) 或更优）、实现直观、省去 DP 的状态表。
⚠️ 不保证全局最优，仅当满足贪心性质时成立。
⚠️ 需谨慎证明正确性，许多问题贪心只能得次优（如 0-1 背包）。

## 与相关概念的区别

- **vs 动态规划：** 贪心每步选定不回溯、只看一个子问题；DP 综合所有相关子问题、可回溯。
- **vs [[分治算法]]：** 分治拆成多个独立子问题再合并；贪心沿单一"最优选择"链下降、不合并。
- **"每步最优"≠"全局最优"：** 是否等价取决于问题结构，须证明，不可想当然。

## 常见误区

- 贪心算法每一步都取局部最优，因此总能得到全局最优解。
- 0-1 背包可以直接按价值密度贪心取，得到最优解。
- 贪心算法和动态规划是一回事，只是写法不同。

## 面试速答

> 🎯 贪心=每步取当前局部最优、不回溯不穷举，期望导出全局最优；成立的前提是问题具贪心选择性质 + 最优子结构，且要用交换/反证法证明，成立时往往 O(n log n) 且比 DP 省空间（霍夫曼、分数背包、Dijkstra）。但它不总对：0-1 背包与非规范币制找零须上 [[动态规划]]。
