# 图算法大全

## 定义

**一句话定义：** 图算法是作用于图（顶点 + 边）的一类算法，涵盖遍历（DFS/BFS）、最短路径、最小生成树、拓扑排序、连通性等；本文作为**索引与速查**，各主题均已有专门词条。

**通俗类比：** 图算法就像在「地图 / 关系网」上解决各种问题——怎么走最近（最短路径）、怎么连最省（最小生成树）、谁先谁后（拓扑排序）、能不能到（连通性）。

## 核心遍历（速览）

```python
from collections import deque

# BFS：逐层扩展，用队列；无权图的最短路径
def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for nb in graph[node]:
            if nb not in visited:
                visited.add(nb)
                queue.append(nb)

# DFS：一条路走到黑再回溯，用栈 / 递归
def dfs(graph, node, visited=None):
    visited = visited if visited is not None else set()
    visited.add(node)
    for nb in graph[node]:
        if nb not in visited:
            dfs(graph, nb, visited)
```

## 复杂度速查

| 算法 | 时间复杂度 | 适用 |
|------|-----------|------|
| DFS / BFS | O(V+E) | 遍历、连通性、无权最短路(BFS) |
| Dijkstra（堆优化） | O((V+E) log V) | 非负权单源最短路 |
| Bellman-Ford | O(V·E) | 含负权单源、检测负环 |
| Floyd-Warshall | O(V³) | 全源最短路 |
| Kruskal | O(E log E) | 稀疏图 MST |
| Prim（堆优化） | O(E log V) | 稠密图 MST |
| 拓扑排序 | O(V+E) | DAG 依赖排序 |

> V 为顶点数、E 为边数；详细推导与代码见各专门词条。

## 常见误区

- Dijkstra **不能处理负权边**（贪心前提被破坏），含负权应使用 Bellman-Ford / SPFA。
- 拓扑排序**仅适用于 DAG**（有环则无法线性排序；可借「能否排完所有点」来检测环）。
- DFS 递归过深可能**栈溢出**，大图应改显式栈或迭代实现。
