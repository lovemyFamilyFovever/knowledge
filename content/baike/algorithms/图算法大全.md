# 图算法大全


> 📌 **导航**：本文是 **图算法大全** 词条，属于 algorithms 术语集。相关枢纽：[[AVL 树]]、[[KMP 算法]]、[[二分查找]]、[[二叉搜索树]]、[[位运算]]。

## 定义

**一句话定义：** 图算法是作用于图（顶点 + 边）的一类算法，涵盖遍历（DFS/BFS）、最短路径、最小生成树、拓扑排序、连通性等；本文作为索引与速查，各主题均已有专门词条。

**通俗类比：** 图算法就像在"地图 / 关系网"上解决各种问题——怎么走最近（最短路径）、怎么连最省（最小生成树）、谁先谁后（拓扑排序）、能不能到（连通性）。

> 多义说明：本文侧重导航与要点速览；图的存储结构见 [[图(数据结构)]]，各具体算法见对应专门词条，避免重复。

## 为什么需要它

图是最一般的"多对多"结构，问题五花八门，若每个算法各记细节易混。把图算法按"遍历/最短路径/生成树/拓扑/连通"归族、列清各自的适用前提与复杂度，形成一张速查地图，遇到具体需求能快速选对算法，再进子词条看实现。

复杂度速查（V 顶点数、E 边数）：

| 算法 | 时间复杂度 | 适用 |
|------|-----------|------|
| DFS / BFS | O(V+E) | 遍历、连通性、无权最短路(BFS) |
| Dijkstra（堆优化） | O((V+E) log V) | 非负权单源最短路 |
| Bellman-Ford | O(V·E) | 含负权单源、检测负环 |
| Floyd-Warshall | O(V³) | 全源最短路 |
| Kruskal | O(E log E) | 稀疏图 MST |
| Prim（堆优化） | O(E log V) | 稠密图 MST |
| 拓扑排序 | O(V+E) | DAG 依赖排序 |

## 具体示例

两大遍历骨架：

```python
def bfs(graph, start):                       # 队列逐层，无权图最短跳数
    visited, queue = {start}, deque([start])
    while queue:
        for nb in graph[queue.popleft()]:
            if nb not in visited:
                visited.add(nb); queue.append(nb)

def dfs(graph, node, visited=None):          # 栈/递归一条路到底
    visited = visited or set(); visited.add(node)
    for nb in graph[node]:
        if nb not in visited:
            dfs(graph, nb, visited)
```

选路：边全非负用 Dijkstra，含负权改 Bellman-Ford（还能查负环），全源且 V 不太大用 Floyd，有启发函数用 A*。

## 何时用 / 何时不用

- **用：** 按问题选型——单源非负最短路 Dijkstra、负权 Bellman-Ford、全源 Floyd、MST Kruskal/Prim、DAG 依赖拓扑排序、动态连通/判环并查集。
- **不用：** 不是图的问题别硬套图算法；Dijkstra 遇负权、拓扑排序遇有环图都不成立（须换算法或先判环）。

## 优劣与代价

✅ 一套算法族覆盖几乎所有关系/网络/依赖问题，复杂度与适用前提清晰。
⚠️ 选错前提会得错解（负权用 Dijkstra、有环做拓扑）。
⚠️ 超大规模图需并行/外部存储（Pregel/GraphX），朴素实现栈与内存吃紧。

## 与相关概念的区别

- **vs [[图(数据结构)]]：** 那里是存储与遍历底座，本文是建在其上的算法选型速查。
- **Dijkstra vs Bellman-Ford：** 前者贪心、要求非负、更快；后者松弛 V-1 轮、容负权可检负环、更慢。
- **Kruskal vs Prim：** 前者按边排序 + 并查集宜稀疏图；后者从点扩 + 优先队列宜稠密图。

## 常见误区

- Dijkstra 算法也能正确处理带负权边的图。
- 拓扑排序可以用在含有环的图上。
- DFS 无论图多大、递归多深都安全，不会栈溢出。

## 面试速答

> 🎯 图算法按族速查：遍历 DFS/BFS 均 O(V+E)；最短路径 Dijkstra(非负权)、Bellman-Ford(容负权/检负环)、Floyd(全源 O(V³))、A*(启发式)；MST Kruskal(稀疏)/Prim(稠密)。前提用错即错解：Dijkstra 不能负权，拓扑要求无环。
