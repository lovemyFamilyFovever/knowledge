# 排序算法

> 📌 **导航**：本文是 **排序算法** 词条，属于 algorithms 术语集。相关枢纽：[[排序与搜索]]、[[复杂度分析]]、[[基础数据结构]]、[[堆排序]]、[[二分查找]]。

## 定义

**一句话定义：** 排序算法是把一组记录按关键字重排成有序序列的算法族，按原理分为比较排序（冒泡、选择、插入、归并、快排、堆排）与非比较排序（计数、桶、基数），选型看时间阶、空间、稳定性与数据特征四件事。

**通俗类比：** 整理一副散牌有好几种手法：一张张插进手中好牌（插入）、先分成两半各排好再合（归并）、按花色分桶再各自理（桶排）——都能理完，费的时间和手的活动范围差别很大。

## 为什么需要它

有序是大量操作的前提：[[二分查找]]、去重、求逆序对、归并两路结果、按时间线扫描、取 Top-K，都要先排序。同时排序是最典型的**算法权衡教具**：比较排序有 Ω(n log n) 下界，因此想更快只能换赛道用非比较排序；而"稳定"这个性质决定了多关键字排序能否分趟进行。选错一次排序，代价是整个下游流程被迫重写。

## 核心机制

- **比较类**：冒泡（相邻交换）、选择（每轮取最小，交换次数最少）、插入（逐个插入已排序段，近有序数据极快）、归并（分治 + 线性合并，稳定但要 O(n) 空间）、快排（pivot 划分 + 递归，原地、平均最快）、堆排（见 [[堆排序]]）。
- **非比较类**：计数（统计值域内每个值出现次数，O(n+k)，要求整数且值域小）、桶（按分布撒进 k 个桶各自排，适合均匀分布）、基数（按位从低到高做稳定排序，O(d·(n+k))）。
- **稳定性**：相等元素的相对次序是否保持。归并、计数、基数、冒泡、插入稳定；选择、快排、堆排不稳定。多关键字排序要靠稳定算法分趟做。

| 算法 | 平均 | 最坏 | 最好 | 空间 | 稳定 |
|---|---|---|---|---|---|
| 冒泡 | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 插入 | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快排 | O(n log n) | O(n²) | O(n log n) | O(log n) | 不稳定 |
| 计数 | O(n+k) | O(n+k) | O(n+k) | O(k) | 稳定 |

## 具体示例

插入排序在近乎有序的数据上退化到 O(n)，快排则靠三路划分优雅处理大量重复：

```python
def insertion_sort(a):
    for i in range(1, len(a)):
        key, j = a[i], i - 1
        while j >= 0 and a[j] > key:   # 已有序则一次都不进这里
            a[j+1] = a[j]; j -= 1
        a[j+1] = key
```

生产实现都是混合策略：小节区用插入排序（常数小）、递归过深时切堆排（introsort 保最坏界）、大数据外排走归并（顺序 I/O）。

## 何时用与何时不用

- **用哪个**：n≤50 或数据近乎有序 → 插入；通用内存排序 → 快排/语言内置；要求稳定或外存/链表 → 归并；整数且值域小 → 计数；均匀分布的大规模浮点 → 桶；定长整数或字符串 → 基数。
- **不必排序**：只要能判定存在性就用 [[哈希表]]；只要最大的前 K 个用堆或快速选择即可，别整表排序。
- **别硬上非比较排序**：值域 k ≫ n 时计数排序的 O(n+k) 反而更慢且吃内存。

## 优劣与代价

✅ 一次排序换来后续查询与归并的对数级效率，还能顺带完成去重与分组。
⚠️ 比较排序有 Ω(n log n) 下界，靠换比较类算法不可能突破，只能改前提（键分布、稳定性需求）。
⚠️ 稳定性、原地性、最坏界三者不可兼得：归并稳但费空间，快排原地但最坏退化，堆排有最坏界但不稳定。

## 与相关概念的区别

- **稳定 vs 原地**：稳定关乎相等元素次序，原地关乎额外空间，是两条独立的轴（归并稳定不原地，堆排原地不稳定）。
- **比较 vs 非比较排序**：前者只依赖两两比较、受 n log n 下界约束；后者利用键的取值分布可做到线性。
- **排序 vs [[堆排序]]/[[二分查找]]**：本页是族谱与选型，那些是单个算法的展开。
- **排序 vs 选择**：只要第 K 小或 Top-K，用堆或快速选择 O(n)，无需全排序。

## 常见误区

- 快速排序平均最快，所以任何数据上都该首选它。
- 归并排序因为要额外 O(n) 空间，所以一定比快排慢。
- 所有排序算法都可以互换使用，区别只是写法习惯。

## 面试速答

> 🎯 排序分比较类与非比较类：快排平均最优但最坏 O(n²)、归并稳定但耗 O(n) 空间、堆排有最坏界却不稳定，插入适合近有序与小规模，计数/桶/基数靠键分布突破 n log n；选型看阶、空间、稳定性与数据特征。
