# 动态规划

## 定义

**一句话定义：** 动态规划（Dynamic Programming, DP）是把问题拆成**重叠子问题**、通过**保存子问题的解**避免重复计算，从而高效求解最优化问题的方法，适用于具有「最优子结构」与「重叠子问题」的问题。

**通俗类比：** 你去陌生城市把每条路走一遍并记在本子上，下次遇到同样路口直接查本子、不再重复摸索——「记住已算过的结果」就是 DP 的精髓。

> 多义说明：DP 与分治都「拆子问题」，但分治的子问题**相互独立**（如归并排序），DP 的子问题**重叠**（如斐波那契）；DP 与贪心都求最优，但贪心每步取局部最优且不回头，DP 综合所有相关子问题。思想层面见 [[算法思想]]。

## 原理与机制

- **三要素**：**状态**（子问题的描述，如 `dp[i]`）、**状态转移方程**（子问题间的递推关系）、**初始/边界条件**。
- **两种实现**：自顶向下（记忆化搜索，递归 + 缓存）与自底向上（迭代填表）；后者常用**滚动数组**把空间从 O(n²)/O(n) 降到 O(n)/O(1)。
- **前提**：最优子结构（大问题最优解包含子问题最优解）+ 重叠子问题（否则退化为分治或穷举）。

### 经典示例：0-1 背包

```python
def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], dp[i-1][w - weights[i-1]] + values[i-1])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][capacity]
```

> 空间优化：一维滚动数组 + **逆序**遍历容量（保证每件物品只被选一次）：
> `for w in range(capacity, weights[i]-1, -1): dp[w] = max(dp[w], dp[w-weights[i]] + values[i])`

### 斐波那契：从指数到线性

```python
# 朴素递归 O(2^n)：存在大量重复子问题
# 迭代 O(n) 时间、O(1) 空间：
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## DP 常见类型

| 类型 | 代表问题 |
|------|----------|
| 线性 DP | 斐波那契、最长递增子序列(LIS)、最大子数组和 |
| 区间 DP | 矩阵链乘法、戳气球 |
| 背包 DP | 0-1 背包、完全背包、多重背包 |
| 树形 DP | 树的直径、打家劫舍 III |
| 状态压缩 DP | 旅行商问题(TSP)、集合覆盖 |
| 数位 DP | 统计区间内满足条件的数的个数 |

## 应用场景

- 最优化问题：最短编辑距离、最长公共子序列(LCS)、背包、股票买卖、资源分配；也用于序列比对（生物信息）、语音识别、强化学习的值迭代等。

## 优点与局限

- 优点：把指数级穷举降到多项式（如 TSP 从 O(n!) 到 O(n²·2ⁿ)）、思路通用（状态 + 转移）。
- 局限：需问题具备最优子结构 + 重叠子问题；「设计状态与转移方程」门槛高；可能占用较多内存（需滚动数组等优化）。

## 常见误区

- 把 DP 等同于「递归 + 缓存」：记忆化只是自顶向下的一种实现，DP 的核心是**状态与转移方程**的正确定义。
- 0-1 背包一维优化时**正序**遍历容量：会导致同一物品被重复选（退化成完全背包），必须**逆序**。
- 以为贪心总能替代 DP：仅当问题满足贪心选择性质时才行，一般最优化问题需 DP。
