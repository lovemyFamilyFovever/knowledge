# 动态规划


> 📌 **导航**：本文是 **动态规划** 词条，属于 algorithms 术语集。相关枢纽：[[AVL 树]]、[[KMP 算法]]、[[二分查找]]、[[二叉搜索树]]、[[位运算]]。

## 定义

**一句话定义：** 动态规划（Dynamic Programming，DP）是把问题拆成**重叠子问题**、通过**保存子问题的解**避免重复计算，从而高效求解最优化问题的方法，适用于具有「最优子结构」与「重叠子问题」的问题。

**通俗类比：** 你去陌生城市把每条路走一遍并记在本子上，下次遇到同样路口直接查本子、不再重复摸索——"记住已算过的结果"就是 DP 的精髓。

> 多义说明：DP 与分治都"拆子问题"，但分治子问题**相互独立**、DP 子问题**重叠**；DP 与贪心都求最优，但贪心每步取局部最优且不回头，DP 综合所有相关子问题。思想层面见 [[算法思想]]。

## 为什么需要它

很多最优化问题若直接递归穷举，会把同一子问题反复算成指数级（如朴素斐波那契 O(2ⁿ)）。当问题同时具备"最优子结构"（大问题的最优解由子问题最优解拼成）和"重叠子问题"（子问题被多次用到），把每个子问题的解存下来、需要时直接查表，就能把指数降到多项式，是求解这类问题的通用范式。

## 核心机制

- **三要素：** **状态**（子问题的描述，如 `dp[i]`）、**状态转移方程**（子问题间递推关系）、**初始/边界条件**。
- **两种实现：** 自顶向下（记忆化搜索，递归 + 缓存）与自底向上（迭代填表）；后者常用**滚动数组**把空间 O(n²)/O(n) 降到 O(n)/O(1)。
- **前提：** 最优子结构 + 重叠子问题（若无重叠就退化为 [[分治算法]]/穷举）。

常见题型：

| 类型 | 代表问题 |
|------|----------|
| 线性 DP | 斐波那契、最长递增子序列(LIS)、最大子数组和 |
| 区间 DP | 矩阵链乘法、戳气球 |
| 背包 DP | 0-1 背包、完全背包、多重背包 |
| 树形 DP | 树的直径、打家劫舍 III |
| 状态压缩 DP | 旅行商问题(TSP)、集合覆盖 |
| 数位 DP | 统计区间内满足条件的数个数 |

## 具体示例

0-1 背包：`dp[i][w]` 表示前 i 件物品、容量 w 的最大价值，转移为"不选第 i 件"与"选第 i 件"取较大：

```python
for i in range(1, n + 1):
    for w in range(capacity + 1):
        if weights[i-1] <= w:
            dp[i][w] = max(dp[i-1][w], dp[i-1][w-weights[i-1]] + values[i-1])
        else:
            dp[i][w] = dp[i-1][w]
```

用一维滚动数组优化时容量必须**逆序**遍历，否则同一物品会被重复选（退化成完全背包）。斐波那契则从朴素递归 O(2ⁿ) 变为迭代 O(n) 时间、O(1) 空间：

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## 何时用 / 何时不用

- **用：** 具最优子结构 + 重叠子问题的最优化/计数问题——LCS、编辑距离、背包、股票买卖、LIS、最短路径、序列比对、强化学习值迭代等。
- **不用：** 子问题不独立也无重叠（直接分治或贪心）；不满足最优子结构；状态空间爆炸到无法枚举时（需近似/搜索/剪枝）。

## 优劣与代价

✅ 把指数级穷举降到多项式（如 TSP 从 O(n!) 到 O(n²·2ⁿ)）；"状态 + 转移"思路通用。
⚠️ 依赖最优子结构与重叠子问题两个前提。
⚠️ 设计状态与转移方程门槛高，且常占较多内存（需滚动数组等优化）。

## 与相关概念的区别

- **vs [[分治算法]]：** 分治子问题相互独立；DP 子问题重叠，用表存储各解一次。
- **vs 贪心：** 贪心每步局部最优、不回溯，仅当问题具贪心选择性质才最优；否则需 DP 综合子问题。
- **vs 记忆化搜索：** 记忆化是 DP 的自顶向下实现，DP 核心在"状态定义 + 转移方程"而非递归本身。

## 常见误区

- 动态规划就等于"递归加缓存"，会写记忆化搜索就算掌握了 DP。
- 0-1 背包做一维空间优化时，容量应当正序遍历。
- 贪心算法总能替代动态规划来求解最优化问题。

## 面试速答

> 🎯 动态规划=把具最优子结构 + 重叠子问题的最优化问题拆成子问题、存表复用避免重复计算：定状态、写转移方程、给初始条件，可自顶向下记忆化或自底向上填表，滚动数组省空间（0-1 背包一维须逆序遍历否则重复选）。它区别于子问题独立的分治与需贪心选择性质的贪心，能把指数穷举降到多项式。
