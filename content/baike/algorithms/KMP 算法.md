# KMP 算法

## 定义

**一句话定义：** KMP 算法(Knuth-Morris-Pratt)是一种高效的字符串匹配算法,它通过预处理模式串得到"部分匹配表"(next / failure 数组),在主串匹配失配时利用已匹配的信息跳过不必要的比较,使主串指针不回溯,从而在 O(n + m) 时间内完成匹配。

**通俗类比：** 像在长句里找某个词——朴素方法每次失配都要把"读取位置"退回到词头重来;KMP 则记住"这个词自身前后有哪些重复片段",失配时直接跳到该跳的位置,主句的读取位置从不后退,省掉大量重复比对。

> 多义说明:KMP 是单模式串匹配算法;区别于朴素匹配(O(n·m))、Rabin-Karp(基于哈希)与多模式匹配的 AC 自动机。本文讨论 KMP。

## 原理与机制

- **核心思想:** 主串指针 i 不回溯;模式串指针 j 在失配时依据 next 数组跳到 `next[j]`。
- **next / 失配数组:** `next[j]` = 模式串前 j 个字符中"最长相等前后缀"的长度;预处理耗时 O(m)。
- **匹配过程:** i 从头到尾扫描主串,j 跟随;失配则 `j = next[j]`(直到 j 归零或重新匹配);当 j 达到 m 即找到一次匹配。
- **复杂度:** 预处理 O(m) + 匹配 O(n) = O(n + m);空间 O(m)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 主串 / 模式串 | 被搜索文本与待匹配模式 |
| next(失配)数组 | 最长相等前后缀长度 |
| 主串指针不回溯 | KMP 的关键特性 |
| O(n + m) | 线性时间复杂度 |

## 应用场景

- 文本搜索、编辑器查找
- 字符串匹配、DNA 序列比对
- 入侵检测的特征匹配

## 优点与局限

- 优点:线性时间 O(n + m);主串不回溯(适合流式/只读一遍的场景);最坏情况有保证。
- 局限:next 数组的构建较难理解与实现;对短模式或小字母表优势不明显;常数因子可能高于朴素法(实践中有时不如 Boyer-Moore)。

## 常见误区

- KMP 的主串指针不回溯(区别于朴素匹配的回退)。
- next 数组有多种定义版本(next / nextval / failure),需注意边界。
- KMP 是单模式匹配,多模式应使用 AC 自动机。
- 最坏 O(n + m) 优于朴素的 O(n·m)。
