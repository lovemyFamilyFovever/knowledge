# 拓扑排序

## 定义

**一句话定义：** 拓扑排序(Topological Sort)是对有向无环图(DAG)的顶点排出一个线性序列,使得对图中每条有向边 (u → v),u 都排在 v 之前;它反映了在"先决约束"下的一种合法执行顺序。

**通俗类比：** 像安排课程或穿衣顺序——"穿袜子"必须在"穿鞋"之前、"数据结构"必须在"操作系统"之前;拓扑排序就是把这些先后约束排成一条可行的时间线。

> 多义说明:拓扑序仅对**有向无环图(DAG)** 存在;若图中有环则无法拓扑排序(可借此检测环)。同一 DAG 的拓扑序通常不唯一。

## 原理与机制

- **Kahn 算法(基于入度):** 反复取出入度为 0 的顶点输出,并删除其出边(使邻居入度减 1),直到没有顶点;若最终输出的顶点数 < 总数,说明存在环。
- **DFS 算法:** 对 DFS 的完成顺序(后序)取逆序即得拓扑序;DFS 中若遇到"后向边"则说明有环。
- **复杂度:** 两种方法均为 O(V + E)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 有向无环图(DAG) | 拓扑排序的前提 |
| 入度(in-degree) | Kahn 算法的核心计数 |
| 队列 / 栈 | 存放当前入度为 0 的顶点 |
| DFS 后序逆序 | 另一种求拓扑序的方式 |
| 环检测 | 无法排完即存在环 |

## 应用场景

- 任务/作业调度与依赖解析
- 编译顺序、构建系统(Make、依赖图)
- 课程先修关系
- 数据流 / DAG 计算(如 Spark)、公式求值顺序

## 优点与局限

- 优点:线性时间 O(V + E)、直观表达依赖顺序、可顺带检测环。
- 局限:仅适用于 DAG(有环无解);拓扑序不唯一(需额外约束定序);动态图变化后需重新计算。

## 常见误区

- 拓扑排序只对有向图有意义(无向图谈不上先后)。
- 有环图不存在拓扑序,此时应报告"存在环"。
- 结果不唯一;它排的是"顶点顺序",不是对边排序。
