# 主定理

> 📌 **导航**：本文是 **主定理** 词条，属于 algorithms 术语集。相关枢纽：[[复杂度分析]]、[[时间复杂度]]、[[分治算法]]、[[递归]]、[[排序与搜索]]。

## 定义

**一句话定义：** 主定理（Master Theorem）是直接给出 `T(n) = a·T(n/b) + f(n)` 这类递推式渐近解的判别法：比较**子问题总工作量** `n^(log_b a)` 与**合并工作量** `f(n)` 谁占主导，一眼定出递归算法的复杂度阶。

**通俗类比：** 装修算工期：把房子分成 a 间、每间规模缩到 1/b，你只需比较"各间施工总量"和"最后打通改造的公共工序"哪个更吃时间。

## 为什么需要它

分治算法的代价天生写成递推式，逐层展开画递归树既费时又易错。主定理把这套推导压缩成一次比较：看到 `T(n)=2T(n/2)+O(n)` 就能立刻报出 O(n log n)，不必展开。它是读解归并排序、Karatsuba 乘法、FFT 等算法复杂度章节的最短路径，也是面试里验证"你说这个递归是几分复杂度"的标准工具。

## 计算逻辑

对 `T(n) = a·T(n/b) + Θ(n^d)`（a≥1, b>1），令临界指数 `E = log_b a`：

- **d < E**：叶子占主导 → `T(n) = Θ(n^E)`。
- **d = E**：每层工作量相同 → `T(n) = Θ(n^d · log n)`。
- **d > E**：根层合并占主导 → `T(n) = Θ(n^d)`。

| 递推式 | a, b, d | 判定 | 解 |
|---|---|---|---|
| `T=T(n/2)+O(1)` 二分 | 1,2,0 | d=E=0 | Θ(log n) |
| `T=2T(n/2)+O(n)` 归并 | 2,2,1 | d=E=1 | Θ(n log n) |
| `T=3T(n/2)+O(n)` Karatsuba | 3,2,1 | d<E | Θ(n^1.585) |
| `T=2T(n/2)+O(n²)` | 2,2,2 | d>E | Θ(n²) |

## 具体示例

```text
归并排序：分成 2 半、线性合并
  T(n) = 2T(n/2) + Θ(n)
  E = log_2 2 = 1 = d  →  情况②  →  Θ(n log n)

遍历单链表长度（只是规模减半、无合并成本）
  T(n) = T(n/1) ... 不适用；应写 T(n) = T(n-1) + O(1)
  → 递推展开得 Θ(n)，主定理不覆盖"每次减常数"的情形
```

## 何时用与何时不用

- **用**：子问题规模统一缩为 n/b、且各子问题规模相同的分治式；快速判断"多路递归里到底是叶子还是根在决定复杂度"。
- **不用**：`T(n)=T(n/3)+T(2n/3)+O(n)`（子问题规模不均）、`a` 随 n 变化、`f(n)=n!` 等非多项式项、`T(n-1)` 型线性递推，以及 `f(n)` 与 `n^E` 差得不够"多项式级别"的边界情形——这些要改用递归树、Akra–Bazzi 或换元法。

## 优劣与代价

✅ 一次比较即得阶，标准分治递推上极快，可讲清、可复算。
⚠️ 只给渐近阶、丢常数，实测排序仍可能因局部性与分支预测而相反。
⚠️ 适用面窄：规模不均与临界对数因子（如 `f(n)=n log n` 且 E=1）需扩展版本才成立。

## 与相关概念的区别

- **主定理 vs 递归树展开**：树法更通用（可处理不均分规模、给出直觉），主定理是树法在等分情形下的结论封装。
- **主定理 vs [[均摊分析]]**：前者解同规模输入下的递推代价，后者分析同规模下的一串操作总代价。
- **情况② vs 情况①/③**：①是叶子最多、③是根最贵、②是每层等重，三种情形的直觉差别就是"钱花在哪一层"。

## 常见误区

- 任何递归式都能套主定理直接得出复杂度。
- `T(n)=2T(n/2)+O(n log n)` 属于情况②，所以解是 Θ(n log n)。
- 主定理给出的阶相同，两个实现的实际速度也就相同。

## 面试速答

> 🎯 主定理解 T(n)=aT(n/b)+Θ(n^d)：比 d 与临界指数 log_b a，d 小取 n^log_b a、相等取 n^d·log n、d 大取 n^d；归并与二分是其标准例子，子问题规模不均时不适用。
