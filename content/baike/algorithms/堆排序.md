# 堆排序

## 定义

**一句话定义：** 堆排序(Heap Sort)是一种基于二叉堆(通常是大顶堆)的比较排序算法:先把待排序数组构建成堆,再反复取出堆顶(最大值)与末尾元素交换并缩小堆范围、下沉调整,从而得到有序序列;时间复杂度稳定为 O(n log n)。

**通俗类比：** 像反复从一堆石头里挑出最大的搬到一边——先把石头堆成"父总比子大"的堆(建堆),然后每次拿走堆顶(最大)放到结果末尾,再把堆重新调整,直到拿完,自然就从大到小排好了。

> 多义说明:堆排序是原地(in-place)、不稳定排序;区别于快速排序(平均更快但最坏退化)与归并排序(稳定但需额外空间)。本文讨论堆排序。

## 原理与机制

- **建堆(heapify):** 把无序数组看作完全二叉树,自底向上调整为大顶堆,耗时 O(n)。
- **排序:** 交换堆顶(最大)与末尾元素 → 堆大小减 1 → 对新堆顶做下沉(sift-down)调整 → 重复 n−1 次。
- **复杂度:** 时间 O(n log n)(最好/最坏/平均一致),空间 O(1)(原地)。
- **不稳定:** 相等元素的相对顺序可能改变。

## 关键组成

| 组成 | 说明 |
|------|------|
| 大顶堆 | 父节点 ≥ 子节点 |
| 建堆(heapify) | O(n) 构造初始堆 |
| 堆顶与末尾交换 | 取出最大值 |
| 下沉调整 | 恢复堆性质 |

## 应用场景

- 需要稳定 O(n log n) 最坏保证的排序
- Top-K 问题(借助堆)
- 内存受限的原地排序
- 优先级调度

## 优点与局限

- 优点:最坏仍为 O(n log n)(优于快排的最坏 O(n²));原地、空间 O(1);可迭代实现(无递归)。
- 局限:不稳定;常数因子较大、缓存不友好;实践中通常比快排慢;依赖随机访问(不适合链表)。

## 常见误区

- 堆排序不稳定(相等元素顺序可能改变)。
- 建堆是 O(n),不是 O(n log n)。
- 堆排序原地,但通常不如快排快(缓存局部性差)。
- 堆排序基于数组(完全二叉树),不适合链表。
