# 并查集


> 📌 **导航**：本文是 **并查集** 词条，属于 algorithms 术语集。相关枢纽：[[AVL 树]]、[[KMP 算法]]、[[二分查找]]、[[二叉搜索树]]、[[位运算]]。

## 定义

**一句话定义：** 并查集(Union-Find / Disjoint Set Union, DSU)是一种维护"不相交集合"的数据结构,支持两种核心操作:查找某元素所属集合的代表(find)与合并两个集合(union),常用于动态连通性问题。

**通俗类比：** 像管理一群人的"朋友圈归属"——每个人最终都指向一个"群主"(代表);要判断两人是否同群,就看群主是否相同;两群合并,就让一个群主指向另一个群主。

> 多义说明:并查集是 DSU 的中文常称;本文讨论带**路径压缩**与**按秩合并**的近似 O(1) 实现。

## 原理与机制

- **结构:** 用数组 `parent[]` 表示一片森林,每个集合是一棵树,树根即集合代表。
- **find(x):** 沿 parent 上溯到根;**路径压缩(path compression)** 把路径上的节点直接挂到根,压平树。
- **union(x, y):** 合并两棵树;**按秩/按大小合并**(union by rank/size)把矮树挂到高树下,避免退化。
- **复杂度:** 单独操作最坏 O(log n);路径压缩 + 按秩合并后,均摊近似 O(α(n))(反阿克曼函数,实际近乎常数)。

## 关键组成

| 组成 | 作用 |
|------|------|
| parent 数组 | 表示森林中的父指针 |
| find(路径压缩) | 查找代表并压平路径 |
| union(按秩/大小) | 合并两集合、控制树高 |
| 秩 / 大小 | 决定合并方向 |
| 代表元(根) | 集合的唯一标识 |

## 应用场景

- Kruskal 最小生成树
- 动态连通性判断、朋友圈/分组
- 等价类合并、检测无向图中的环
- 离线 LCA(最近公共祖先)

## 优点与局限

- 优点:合并与查询极快(近 O(1) 均摊)、实现简洁、内存紧凑。
- 局限:只维护"是否同集合",不直接支持撤销(需可持久化或离线处理);不保存集合内顺序或附加信息(需扩展)。

## 常见误区

- 不做路径压缩/按秩合并时可能退化成链(O(n))。
- 并查集处理的是"无向"连通性,有向连通性需其他方法。
- find 返回的是集合的"代表元",而非集合本身。
