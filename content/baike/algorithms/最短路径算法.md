# 最短路径算法

## 定义

**一句话定义：** 最短路径算法用于在带权图中找到从源点到其他各顶点(或某两点之间)路径权重之和最小的路径,是图论与网络优化的核心问题;常见算法有 Dijkstra、Bellman-Ford、Floyd-Warshall 与 A* 等。

**通俗类比：** 像导航软件规划路线——把城市当作节点、道路当作带权边(距离/时间),算法帮你找出从家到公司"总路程最短"的那条路;不同算法适配不同路况(有无负权、单源还是全源)。

> 多义说明:分为单源最短路径(Dijkstra / Bellman-Ford)、全源最短路径(Floyd-Warshall)与启发式搜索(A*);边权可正可负。本文综述。

## 原理与机制

- **Dijkstra:** 贪心 + 优先队列,每次取出当前距离最小的未确定顶点并"松弛"其邻居;要求边权非负;堆优化后 O((V+E) log V)。
- **Bellman-Ford:** 对所有边反复松弛 V−1 轮,可处理负权并检测负环;O(V·E)。
- **Floyd-Warshall:** 动态规划,求所有顶点对之间的最短路径;O(V³)。
- **A\*:** Dijkstra + 启发函数 h(估计到目标的距离),优先扩展更有希望的顶点。
- **松弛(relaxation):** 若经某中转点更短,则更新目标距离。

## 关键组成

| 组成 | 作用 |
|------|------|
| 源点 | 起点 |
| 距离数组 dist | 记录当前最短估计 |
| 松弛操作 | 更新更短路径 |
| 优先队列 | Dijkstra 高效取最小 |
| 启发函数 h | A* 引导搜索方向 |
| 负环检测 | Bellman-Ford 的能力 |

## 应用场景

- 地图导航与路径规划
- 网络路由协议(OSPF、BGP)
- 物流与调度优化
- 游戏寻路(A*)、社交网络最短关系链

## 优点与局限

- 优点:模型通用、算法成熟、可适配不同约束(负权、单源/全源、启发式)。
- 局限:Dijkstra 不支持负权;Bellman-Ford 较慢;Floyd-Warshall 为 O(V³),大图昂贵;A* 依赖高质量启发函数;现实超大规模路网需专门工程优化。

## 常见误区

- Dijkstra 不能处理负权边(会得出错误结果,负权应用 Bellman-Ford / SPFA)。
- 最短路径不一定唯一。
- A* 的启发函数需"可采纳"(不高估真实代价)才能保证最优。
- 存在负权环时,最短路径可能无定义(可无限减小)。
