# 最短路径算法


> 📌 **导航**：本文是 **最短路径算法** 词条，属于 algorithms 术语集。相关枢纽：[[AVL 树]]、[[KMP 算法]]、[[二分查找]]、[[二叉搜索树]]、[[位运算]]。

## 定义

**一句话定义：** 最短路径算法用于在带权图中找到从源点到其他各顶点（或某两点之间）路径权重之和最小的路径，是图论与网络优化的核心问题；常见有 Dijkstra、Bellman-Ford、Floyd-Warshall 与 A* 等。

**通俗类比：** 像导航规划路线——把城市当节点、道路当带权边（距离/时间），算法找出从家到公司"总代价最小"的那条路；不同算法适配不同路况（有无负权、单源还是全源）。

> 多义说明：分为单源最短路径（Dijkstra / Bellman-Ford）、全源最短路径（Floyd-Warshall）与启发式搜索（A*）；边权可正可负。本文综述。

## 为什么需要它

路由、导航、调度、寻路本质都是"在带权网络上找代价最小的走法"。Floyd 之外的暴力枚举路径是指数级。最短路径算法用"松弛"这一统一原语——经中转更短就更新——配合贪心（Dijkstra）、逐轮松弛（Bellman-Ford）、区间 DP（Floyd）或启发式引导（A*），把问题降到多项式，是网络优化的基石。

## 核心机制

- **松弛（relaxation）：** 若 `dist[u] + w(u,v) < dist[v]`，则更新 dist[v]，是所有算法的共同动作。
- **Dijkstra：** 贪心 + [[堆与优先队列]]，每次取当前 dist 最小的未确定点松弛邻居；要求边权非负；堆优化 O((V+E) log V)。
- **Bellman-Ford：** 对所有边反复松弛 V−1 轮，可处理负权并检测负环；O(V·E)。
- **Floyd-Warshall：** 动态规划求所有点对最短路；O(V³)。
- **A*：** Dijkstra + 启发函数 h（估计到目标距离）优先扩展更有希望的方向；h 须可采纳（不高估）才保证最优。

| 组成 | 作用 |
|------|------|
| 源点 | 起点 |
| 距离数组 dist | 记录当前最短估计 |
| 松弛操作 | 更新更短路径 |
| 优先队列 | Dijkstra 高效取最小 |
| 启发函数 h | A* 引导搜索方向 |
| 负环检测 | Bellman-Ford 的能力 |

## 具体示例

导航求"家→公司"最快：边权非负（时间），用 Dijkstra，dist 从 0 起、每取最小距离点松弛邻边，得单源最短路。若路网允许"负权"（罕见，如返利边）改用 Bellman-Ford，还能靠"第 V 轮仍能松弛"检测负环。要做全城所有点对距离则用 Floyd。游戏寻路用 A*，取曼哈顿/欧氏距离作可采纳启发，比 Dijkstra 少探索无望区域。

## 何时用 / 何时不用

- **用：** 单源非负最短路 Dijkstra；含负权或判负环 Bellman-Ford/SPFA；全源且 V 不大 Floyd；带目标、有可用启发函数时 A*。
- **不用：** Dijkstra 遇负权会错（改 BF）；有负权环时最短路径无定义；超大规模路网需分层/预处理等专门工程。

## 优劣与代价

✅ 模型通用、算法成熟，可适配负权、单源/全源、启发式等不同约束。
⚠️ Dijkstra 不支持负权；Bellman-Ford 慢；Floyd O(V³) 大图昂贵。
⚠️ A* 效果依赖启发函数质量。

## 与相关概念的区别

- **vs [[最小生成树]]：** MST 最小化"连通所有点的总权"，最短路径最小化"两点间一条路径"，目标不同。
- **Dijkstra vs Bellman-Ford：** 前者贪心、须非负、更快；后者逐轮松弛、容负权、可检负环、更慢。
- **单源 vs 全源：** Dijkstra/BF 一个源点到全部；Floyd 所有点对。

## 常见误区

- Dijkstra 算法也能正确处理带负权边的图。
- 只要给 A* 配一个启发函数，它就一定能给出最短路径。
- 图中存在负权环时，最短路径仍然有确定的最优解。

## 面试速答

> 🎯 最短路径核心是「松弛」：单源非负用 Dijkstra（贪心+优先队列，O((V+E)logV)，不能负权）、含负权判负环用 Bellman-Ford（松弛 V−1 轮，O(VE)）、全源小规模用 Floyd（DP，O(V³)）、有可采纳启发函数时用 A* 定向加速。它区别于 [[最小生成树]]。
