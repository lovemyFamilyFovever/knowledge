# 前缀和与差分

> 📌 **导航**：本文是 **前缀和与差分** 词条，属于 algorithms 术语集。相关枢纽：[[算法思想]]、[[复杂度分析]]、[[双指针与滑动窗口]]、[[基础数据结构]]、[[排序与搜索]]。

## 定义

**一句话定义：** 前缀和与差分是一对互逆的预处理技巧：前缀和把"区间求和查询"从 O(n) 降到 O(1)（多做一次累加），差分则把"批量区间增减"从 O(n) 降到 O(1)（只在端点记变化量，最后做一次前缀和还原）。

**通俗类比：** 水电表读数（前缀和）：今天的表减去昨天的表就是本期用量，不必每月重新累计；差分像只记每天"进出差额"，想知道余额时再把差额累加起来。

## 为什么需要它

区间操作是海量场景的核心：区间求和、二维子矩阵和、异或区间统计、多次"给一段加 k"后再查询。逐次枚举区间是 O(n) 一条，m 次查询即 O(nm)，n、m 到 10⁵ 就崩。前缀和把查询变成两次查表相减，差分把修改变成两次端点打点——**两者都把 n 次工作压缩成常数，代价只是一次 O(n) 预处理**，是"空间换时间"最干净的示范（见 [[时空权衡]]）。

## 核心机制

- **前缀和**：`pre[i] = a[0] + … + a[i-1]`（约定 `pre[0]=0`），则区间和 `sum(l..r) = pre[r+1] - pre[l]`。多查询时先 O(n) 建表，之后每次 O(1)。
- **二维前缀和**：`pre[i][j]` 表示左上角到 `(i-1,j-1)` 的矩形和，子矩阵和靠容斥：`pre[x2][y2] - pre[x1][y2] - pre[x2][y1] + pre[x1][y1]`。
- **差分**：`d[i] = a[i] - a[i-1]`。要对 `[l, r]` 整体加 `v`，只需 `d[l] += v`、`d[r+1] -= v`；全部操作做完后对 `d` 求一次前缀和即还原数组。
- **互补关系**：差分数组的前缀和是原数组，原数组的差分是差分数组；"改多用差分、查多用前缀和"，两者可串成"差分 → 前缀和还原"的两段式。

| 需求 | 手法 | 单次代价 |
|---|---|---|
| 多次区间求和 | 前缀和 | 建表 O(n)、查询 O(1) |
| 子矩阵求和 | 二维前缀和 | 建表 O(nm)、查询 O(1) |
| 多次区间加 | 差分 | 每次 O(1)，还原 O(n) |
| 区间和 + 单点改 | 树状数组 / 线段树 | 均 O(log n) |

## 具体示例

批量区间加减后一次还原，是差分的标准用法：

```python
def diff_apply(n, ops):
    d = [0] * (n + 1)
    for l, r, v in ops:
        d[l] += v
        d[r + 1] -= v          # 关键：在右端点之后打回
    out = [0] * n
    for i in range(n):
        out[i] = (d[i] if i == 0 else out[i-1] + d[i])
    return out

diff_apply(6, [(1, 3, 5), (2, 5, 3)])   # [0, 5, 8, 8, 3, 3]
```

## 何时用与何时不用

- **用**：静态数组的反复区间求和（前缀和）；大量区间整体加减后统一查询（差分，含二维差分做矩形加）；异或/乘积类可逆运算同样适用（异或前缀和统计区间异或和）；配合哈希表求"和为 K 的子数组个数"。
- **不用**：区间内还要**单点修改**时前缀和失效（表要重算 O(n)），改用树状数组或线段树；数组元素为负且要求"最大子数组和"时前缀和不能直接答，需 [[动态规划]]（Kadane）；只查询一两次时建表不划算。

## 优劣与代价

✅ 一次 O(n) 预处理换来 O(1) 的单次查询或修改，实现极简、无分支。
✅ 两者互逆且可级联，能组合出二维、树状、离线扫描线等更广的套路。
⚠️ 前缀和表占 O(n) 额外空间，且数据一旦频繁更新就退化为每改必重建。
⚠️ 差分只做"批量改、末尾读"；要边改边读必须升级为树状数组。

## 与相关概念的区别

- **前缀和 vs [[双指针与滑动窗口]]**：前者答"这段的和是多少"，后者答"满足约束的最优区间"；前者要求可逆运算，后者要求单调性。
- **前缀和 vs 累加变量**：累加变量只能单向扫一次，前缀和表可任意区间随机查询。
- **差分 vs 线段树懒标记**：差分管离线批量修改后统一读；线段树支持在线任意交错地查询与修改，代价是更高实现复杂度。
- **差分 vs 频率计数**：计数只统计单点出现次数，差分统计的是区间覆盖量。

## 常见误区

- 前缀和建好之后可以随意改数组元素，查询结果仍然正确。
- 差分数组本身就是最终答案，不需要再做一次前缀和。
- 任何区间问题都可以用前缀和直接求出最优解。

## 面试速答

> 🎯 前缀和用一次 O(n) 建表把区间求和查询降到 O(1)（sum=pre[r+1]−pre[l]），差分是它的逆运算、把区间整体加减降到 O(1) 只在端点打点，末尾一次前缀和还原；一旦要边改边查就得升级成树状数组。
