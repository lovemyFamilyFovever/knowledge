# 二叉搜索树


> 📌 **导航**：本文是 **二叉搜索树** 词条，属于 algorithms 术语集。相关枢纽：[[AVL 树]]、[[KMP 算法]]、[[二分查找]]、[[二叉搜索树]]、[[位运算]]。

## 定义

**一句话定义：** 二叉搜索树(Binary Search Tree, BST)是一种二叉树,其中每个节点都满足:左子树所有节点的值小于该节点、右子树所有节点的值大于该节点,从而支持高效的查找、插入与删除。

**通俗类比：** 像查字典的"二分"思路——每次和当前词比较,目标更小就往左翻、更大就往右翻,每步排除一半;BST 就是把这种"比大小定方向"的过程组织成一棵树。

> 多义说明:BST 是基础结构;为保证平衡衍生出 AVL 树、红黑树等**自平衡二叉搜索树**;本文讲基本 BST 并提及平衡变体。

## 原理与机制

- **有序性:** 中序遍历(in-order traversal)得到升序序列。
- **基本操作:** 查找/插入从根出发按大小比较逐层下降;删除分三种情况(叶节点、单子节点、双子节点——用前驱或后继替换)。
- **复杂度:** 平均 O(log n);最坏情况(树退化为链表)为 O(n)。
- **平衡:** 自平衡 BST(AVL 严格平衡、红黑树近似平衡)通过旋转保证树高维持 O(log n)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 节点 | 键值 + 左右子树指针 |
| 有序性约束 | 左 < 根 < 右 |
| 中序遍历 | 输出升序序列 |
| 旋转(rotation) | 平衡调整的基本操作 |
| 前驱 / 后继 | 删除双子节点时替换用 |

## 应用场景

- 有序字典 / 集合(map、set)的底层实现
- 数据库与文件系统索引的基础结构
- 需要动态维护有序数据与范围查询的场景
- 红黑树广泛用于语言库(如 Java TreeMap、C++ std::map)

## 优点与局限

- 优点:动态维护有序数据;查找/插入/删除平均 O(log n);支持范围查询与有序遍历。
- 局限:普通 BST 可能退化(需自平衡);指针开销大、缓存不友好(相比数组或 B 树);实现较复杂(尤其删除与旋转)。

## 常见误区

- BST ≠ 二叉堆:堆是完全二叉树、只保证父子间大小关系,用于优先队列。
- 普通 BST 不保证平衡,最坏 O(n),需用 AVL / 红黑树。
- "中序有序"不等于"层序有序"。
- BST 与 B / B+ 树不同:后者是多路、面向磁盘块的结构。
