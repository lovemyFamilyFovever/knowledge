# 分治算法


> 📌 **导航**：本文是 **分治算法** 词条，属于 algorithms 术语集。相关枢纽：[[AVL 树]]、[[KMP 算法]]、[[二分查找]]、[[二叉搜索树]]、[[位运算]]。

## 定义

**一句话定义：** 分治算法(Divide and Conquer)是一种把原问题递归地分解为若干个规模更小、结构相同的子问题,分别求解后再合并子问题的解,从而得到原问题解的算法策略。

**通俗类比：** 像"分而治之"地整理一大摞卡片——把大摞分成几小摞分别排序(分),再把排好的小摞两两合并成有序大摞(合);大事化小、各个击破,最后合起来。

> 多义说明:分治是算法范式之一,三步为**分(divide)、治(conquer)、合(combine)**;与动态规划(子问题重叠)有别——分治的子问题通常相互独立。本文讨论分治。

## 原理与机制

- **分:** 把问题划分为若干规模更小的相同子问题。
- **治:** 递归求解子问题;当规模足够小时直接求解(base case)。
- **合:** 合并子问题的解,得到原问题的解。
- **复杂度分析:** 常用主定理(Master Theorem);如归并排序 T(n) = 2T(n/2) + O(n) = O(n log n)。
- **经典实例:** 归并排序、快速排序、二分查找、快速傅里叶变换、Karatsuba 大整数乘法、最近点对。

## 关键组成

| 组成 | 说明 |
|------|------|
| 分解(divide) | 拆成更小子问题 |
| 递归求解(conquer) | 分而治之 |
| 合并(combine) | 由子解得原解 |
| base case | 递归终止条件 |
| 主定理 | 分析递归复杂度 |

## 应用场景

- 排序(归并、快排)、二分查找
- 大数运算、FFT
- 并行计算(子问题可并行求解)
- 分治最近点对等几何问题

## 优点与局限

- 优点:思路清晰、常很高效(O(n log n));子问题独立,易于并行。
- 局限:递归有栈开销;合并步骤可能复杂;子问题重叠时不如动态规划(会重复计算)。

## 常见误区

- 分治的子问题应相互独立;若重叠,应改用动态规划/记忆化。
- 分治通常用递归实现,存在栈开销。
- 二分查找是分治的特例(每次分一半、只取其一)。
- 分治 ≠ 减治:减治每次只求解一个子问题(如二分),分治通常求解多个再合并。
