# 双指针与滑动窗口

> 📌 **导航**：本文是 **双指针与滑动窗口** 词条，属于 algorithms 术语集。相关枢纽：[[算法思想]]、[[复杂度分析]]、[[排序与搜索]]、[[前缀和与差分]]、[[基础数据结构]]。

## 定义

**一句话定义：** 双指针与滑动窗口是在**有序数组或字符串**上用两三个游标代替嵌套枚举的技巧族：双指针靠指针移动剪掉不可能的组合，滑动窗口维护一段始终满足约束的区间 `[left, right]`，二者都把 O(n²) 的子数组/子串枚举降到 O(n)。

**通俗类比：** 两人抬梯过巷：一个在头一个在尾，同时往中间收；滑动窗口像用书签在书页上推一段可读区间——读得下就右移，读不下就左移，从不回头重读整页。

## 为什么需要它

子数组、子串问题的暴力解是"枚举所有区间"，天然 O(n²) 甚至 O(n³)，n 到 10⁵ 直接不可行。而绝大多数此类问题带有**单调性**：窗口右扩时某个量单调变差、左缩时单调变好，于是无需回退即可扫描一遍求解。这类技巧把"必须试过所有区间"的直觉推翻，是面试与竞赛里出现频率最高的一族优化。

## 核心机制

**双指针三种形态**：对撞（两端向中间，适用有序数组的两数之和、盛水容器）；快慢（一快一慢，适用链表判环、找中点、原地去重）；同向不同速（一个探路一个跟随，适用移除元素、合并有序序列）。

**滑动窗口的固定四步**：右扩入窗 → 判断是否破坏约束 → 循环左缩直至合法 → 在合法时刻更新答案。关键在**左指针只前进不回退**，因此总移动次数 ≤ 2n，复杂度 O(n)。定长窗口则用计数或单调队列维护窗口内极值。

| 形态 | 前提 | 典型题 |
|---|---|---|
| 对撞指针 | 数组已排序 | 两数之和 II、三数之和 |
| 快慢指针 | 只需线性前进 | 链表环、原地去重 |
| 可变窗口 | 答案具单调性 | 最长无重复子串、最小覆盖子串 |
| 定长窗口 | 窗口尺寸固定 | 定长子数组最大和、字母异位词 |

## 具体示例

对撞指针吃的是有序性；滑动窗口靠"缩到合法"保证不重复扫：

```python
def two_sum_sorted(a, target):        # 对撞：O(n)
    l, r = 0, len(a) - 1
    while l < r:
        s = a[l] + a[r]
        if s == target: return [l, r]
        l, r = (l + 1, r) if s < target else (l, r - 1)

def longest_unique(s):                # 变长窗口：O(n)
    seen, l, best = set(), 0, 0
    for r, c in enumerate(s):
        while c in seen:              # 不合法就左缩，绝不回退 r
            seen.remove(s[l]); l += 1
        seen.add(c); best = max(best, r - l + 1)
    return best
```

## 何时用与何时不用

- **用**：有序数组的配对/三元组 → 对撞指针；链表环与中点 → 快慢指针；"最长/最短/至多 K 个"的连续子串子数组 → 滑动窗口；定长统计 → 滑窗 + 计数或单调队列。
- **不用**：数组**无序且无单调性**时双指针不成立，须先排序（会丢原下标）或改用 [[哈希表]]；窗口约束不满足"左缩必变好"时滑窗会漏解，退回前缀和或 [[动态规划]]；子序列（可不连续）问题不属于窗口模型。

## 优劣与代价

✅ 把区间枚举从平方降到线性，实现短、常数小，且不易写出错误解。
⚠️ 只适用于具单调性的问题，判错模型会得到看似正确实则漏解的代码。
⚠️ 边界（`<` 还是 `<=`、何时更新答案）是主要 bug 源，需靠不变式而非直觉来写。

## 与相关概念的区别

- **双指针 vs 滑动窗口**：前者多为两端相向或快慢差速，后者维护一段区间且右端只前进；滑窗是双指针的特化。
- **滑动窗口 vs [[前缀和与差分]]**：前者处理"满足约束的最优区间"，后者处理"区间和的快速查询与批量修改"。
- **窗口 vs 二分**：窗口要求答案随窗口扩张单调，若判定条件单调但区间不连续，用 [[二分查找]] 更合适。
- **子数组 vs 子序列**：滑窗只覆盖连续情形；不连续的最优子结构问题归 [[动态规划]]。

## 常见误区

- 只要看到子数组问题就能用滑动窗口求解。
- 双指针对任何数组都成立，因为只是少写一层循环。
- 窗口左边界可以在任何时候随意移动而不影响正确性。

## 面试速答

> 🎯 双指针用对撞/快慢/同向三种形态把配对与去重降到 O(n)，滑动窗口维护一段合法区间、靠左指针只前进把区间枚举从 O(n²) 降到 O(n)；前提是数据有序或答案具单调性，否则得改用前缀和或 DP。
