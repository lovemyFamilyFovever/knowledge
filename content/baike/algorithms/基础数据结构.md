# 基础数据结构

> 数据结构是计算机中组织、存储数据的方式，选对结构能让程序更快、更省资源。本文**详解线性结构**（数组/链表/栈/队列），而哈希表、树、堆、图、Trie 等已有专门词条，此处只给要点并双链深入，避免重复。

---

## 数组（Array）

**一句话定义：** 数组是一块**连续内存**，按序存放同类型数据，可通过下标 O(1) 随机访问任意元素。

**通俗类比：** 一排带编号、大小相同的储物柜——知道首柜位置，就能立刻算出第 N 个柜子的地址。

```python
arr = [10, 20, 30, 40, 50]   # Python list 是动态数组
print(arr[2])       # 30，O(1) 随机访问
arr.append(60)      # 末尾追加，均摊 O(1)
arr.insert(0, 5)    # 头部插入 O(n)，后续元素需后移
```

**适用**：快速随机访问——查表、矩阵运算、排序算法的底层存储。

| 特性 | 数组 | 链表 |
|------|------|------|
| 内存 | 连续 | 分散 |
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n)（需移动元素） | O(1)（已知位置时） |

---

## 链表（Linked List）

**一句话定义：** 链表由节点组成，每个节点存数据与指向下一节点的指针，节点在内存中**无需连续**。

**通俗类比：** 寻宝游戏——每条线索告诉你下一条藏在哪，不必把所有线索放在同一抽屉。

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

head = ListNode(1, ListNode(2, ListNode(3)))   # 单链表 1→2→3→None
```

- **单链表**：只能向后，省空间；**双链表**：可双向（如 `collections.deque` 的底层）；**循环链表**：尾连头，适合轮询调度。
- **适用**：频繁在头部/中间增删——实现队列、LRU 缓存等。

---

## 栈（Stack）

**一句话定义：** 只在栈顶插入/删除的线性结构，遵循**后进先出（LIFO）**。

**通俗类比：** 一摞盘子，最后放上去的最先拿下。

```python
stack = []
stack.append(1); stack.append(2); stack.append(3)   # 入栈
print(stack.pop())   # 3（后进先出）
print(stack[-1])     # 2（查看栈顶）
```

**适用**：函数调用栈、括号匹配、表达式求值、浏览器前进/后退、DFS。

---

## 队列（Queue）

**一句话定义：** 队尾插入、队头删除的线性结构，遵循**先进先出（FIFO）**。

**通俗类比：** 排队买奶茶，先排先买。

```python
from collections import deque
q = deque()
q.append(1); q.append(2)
print(q.popleft())   # 1（先进先出）

import heapq         # 优先队列：按优先级出队
pq = []
heapq.heappush(pq, (1, '低')); heapq.heappush(pq, (0, '高'))
print(heapq.heappop(pq))   # (0, '高')
```

**适用**：任务调度、消息队列、BFS、打印队列。变体：双端队列（deque）、优先队列（堆，见 [[堆与优先队列]]）。

## 数据结构总览对比表

| 数据结构 | 随机访问 | 查找 | 插入 | 删除 | 适用场景 |
|----------|----------|------|------|------|----------|
| 数组 | O(1) | O(n) | O(n) | O(n) | 读多写少 |
| 链表 | O(n) | O(n) | O(1)* | O(1)* | 频繁增删 |
| 栈 | — | O(n) | O(1) | O(1) | LIFO |
| 队列 | — | O(n) | O(1) | O(1) | FIFO |
| 哈希表 | — | O(1) 均摊 | O(1) 均摊 | O(1) 均摊 | 快速查找 |
| 二叉搜索树 | — | O(log n) | O(log n) | O(log n) | 有序数据 |
| 红黑树 | — | O(log n) | O(log n) | O(log n) | 通用有序容器 |
| B+ 树 | — | O(log n) | O(log n) | O(log n) | 数据库/文件系统 |
| 堆 | — | O(1) 取最值 | O(log n) | O(log n) | 优先级/Top-K |
| 图 | — | 取决于算法 | — | — | 关系建模 |
| Trie | — | O(m) | O(m) | O(m) | 字符串前缀匹配 |

> \* O(1) 指已知插入/删除位置的情况；哈希表 O(1) 为**平均**，最坏（全冲突）退化 O(n)。

## 常见误区

- 「链表插入/删除总是 O(1)」：仅当**已持有该位置节点引用**时；按值查找位置仍需 O(n)。
- 「哈希表永远 O(1)」：那是平均情况，哈希冲突严重或负载因子过高会退化。
- 「数组中间插入便宜」：数组中间/头部插入需搬移后续元素，是 O(n)。
