# 二分查找


> 📌 **导航**：本文是 **二分查找** 词条，属于 algorithms 术语集。相关枢纽：[[AVL 树]]、[[KMP 算法]]、[[二分查找]]、[[二叉搜索树]]、[[位运算]]。

## 定义

**一句话定义：** 二分查找(Binary Search)是一种在**有序**序列中查找目标值的算法:每次将搜索区间对半缩小,通过比较中间元素与目标决定在前半还是后半继续,时间复杂度 O(log n),远快于逐个查找的 O(n)。

**通俗类比：** 像查字典找单词——不会从第一页翻起,而是翻到中间看:目标词在前半就往前翻一半、在后半就往后翻一半,每次排除一半,很快定位。

> 多义说明:二分查找要求序列**有序**(或单调);有多种变体(查精确值、查左/右边界、二分答案)。本文讨论基本二分及变体。

## 原理与机制

- **基本流程:** 维护区间 [lo, hi],取 mid;比较 a[mid] 与 target——相等则返回;a[mid] < target 则 `lo = mid + 1`;否则 `hi = mid − 1`。
- **边界与不变式:** 区间开闭(`lo <= hi` vs `lo < hi`)、mid 取整方向需谨慎,避免死循环或越界。
- **变体:** lower_bound(第一个 ≥ target)、upper_bound(第一个 > target)、二分答案(在答案空间上二分)。
- **复杂度:** 时间 O(log n),空间 O(1)(迭代实现)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 有序前提 | 二分的必要条件 |
| 区间 [lo, hi] | 当前搜索范围 |
| mid 比较 | 决定收缩方向 |
| 边界处理 | 避免 off-by-one |
| lower/upper_bound | 查边界的变体 |

## 应用场景

- 有序数组/表的查找
- 标准库的二分与 lower_bound
- 二分答案(如"最小化最大值"类问题)
- 查找插入位置、旋转数组的变体

## 优点与局限

- 优点:O(log n) 极快;迭代实现空间 O(1);简单通用。
- 局限:要求有序(无序需先排序,O(n log n));需要随机访问(链表不适用);边界处理易错(off-by-one)。

## 常见误区

- 二分查找必须先有序。
- `mid = (lo + hi) / 2` 在大数下可能溢出,应用 `lo + (hi − lo) / 2`。
- 边界(`lo <= hi`、`mid ± 1`)处理不当会死循环或漏查。
- 二分不只用于查值,还可"二分答案"。
