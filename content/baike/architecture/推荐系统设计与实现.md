# 推荐系统设计与实现

# 推荐系统指南：从原理到大模型时代的全面解析

## 1. 推荐系统架构：工业级推荐系统的四层漏斗

### 1.1 整体架构概述

现代工业级推荐系统采用经典的**多级漏斗架构**，包含召回、粗排、精排、重排四个核心阶段。这种分层设计的核心思想是：**在保证推荐质量的同时，通过逐层过滤控制计算复杂度**。

**架构流程图**：
```
用户请求 → 召回层（候选集生成）→ 粗排层（初步筛选）→ 精排层（精准排序）→ 重排层（策略调整）→ 最终推荐结果
```

### 1.2 各层详细解析

**召回层（Recall）**：
- **目标**：从百万级物品库中快速筛选出数百到数千个候选物品
- **特点**：高并发、低延迟，通常在10-50ms内完成
- **技术**：多路召回（协同过滤、内容召回、热度召回等）、ANN近似最近邻检索
- **案例**：YouTube在召回阶段使用了深度学习模型，结合用户历史行为生成候选视频

**粗排层（Pre-ranking）**：
- **目标**：对召回层输出的候选集进行初步排序，筛选出数百个物品
- **特点**：模型相对简单，特征维度较少，延迟控制在100ms以内
- **技术**：简单的LR模型、GBDT、浅层神经网络
- **设计考虑**：平衡精度和效率，通常使用少量核心特征

**精排层（Ranking）**：
- **目标**：对粗排输出的物品进行精准排序
- **特点**：使用复杂模型和大量特征，允许较高的计算开销
- **技术**：深度模型（DeepFM、DIN等），特征数量可达数百甚至数千维
- **案例**：阿里的DIN模型在精排阶段利用注意力机制捕捉用户兴趣的动态变化

**重排层（Re-ranking）**：
- **目标**：考虑业务策略和多样性、新颖性等指标
- **特点**：应用业务规则、提升用户体验
- **技术**：多样性重排（MMR）、新颖性提升、去重、黑名单过滤
- **策略**：避免连续推荐相似内容，平衡商业目标与用户体验

### 1.3 代码示例：简化版推荐流程

```python
class RecommenderSystem:
    def __init__(self, item_pool):
        self.item_pool = item_pool  # 物品池
        
    def recommend(self, user_id, top_k=10):
        # 1. 召回阶段
        candidates = self.recall(user_id, n_candidates=500)
        
        # 2. 粗排阶段
        pre_ranked = self.pre_rank(candidates, n_items=100)
        
        # 3. 精排阶段
        ranked_items = self.ranking(pre_ranked, user_id)
        
        # 4. 重排阶段
        final_items = self.rerank(ranked_items, top_k)
        
        return final_items
    
    def recall(self, user_id, n_candidates):
        """多路召回"""
        cf_candidates = self.collaborative_filtering(user_id)
        content_candidates = self.content_based(user_id)
        popularity_candidates = self.popularity_based()
        
        # 合并去重
        candidates = list(set(cf_candidates + content_candidates + popularity_candidates))
        return candidates[:n_candidates]
    
    def pre_rank(self, candidates, n_items):
        """粗排：简单的特征评分"""
        scored_items = []
        for item_id in candidates:
            item = self.item_pool[item_id]
            # 简单特征：热度分 + 用户匹配度
            score = item['popularity'] * 0.6 + self.user_item_match(user_id, item) * 0.4
            scored_items.append((item_id, score))
        
        # 按分数排序
        scored_items.sort(key=lambda x: x[1], reverse=True)
        return [item_id for item_id, _ in scored_items[:n_items]]
    
    def ranking(self, pre_ranked_items, user_id):
        """精排：使用深度模型"""
        # 使用预训练的DeepFM模型进行预测
        user_features = self.get_user_features(user_id)
        item_features = [self.get_item_features(item_id) for item_id in pre_ranked_items]
        
        scores = self.deepfm_model.predict(user_features, item_features)
        ranked = sorted(zip(pre_ranked_items, scores), key=lambda x: x[1], reverse=True)
        return [item_id for item_id, _ in ranked]
    
    def rerank(self, ranked_items, top_k):
        """重排：应用业务规则"""
        final_items = []
        seen_categories = set()
        
        for item_id in ranked_items:
            item = self.item_pool[item_id]
            category = item['category']
            
            # 多样性规则：同一类别最多推荐2个
            if seen_categories.get(category, 0) < 2:
                final_items.append(item_id)
                seen_categories[category] = seen_categories.get(category, 0) + 1
            
            if len(final_items) >= top_k:
                break
                
        return final_items
```

## 2. 协同过滤：从基础到高级

### 2.1 用户协同过滤（UserCF）

**核心思想**：基于"相似的用户可能有相似的偏好"这一假设。通过计算用户之间的相似度，为目标用户推荐其相似用户喜欢的物品。

**算法步骤**：
1. 构建用户-物品评分矩阵
2. 计算用户之间的相似度（余弦相似度、皮尔逊相关系数等）
3. 为目标用户找到K个最相似的用户
4. 从相似用户的偏好中生成推荐

**相似度计算**：
```python
def cosine_similarity(user1_ratings, user2_ratings):
    """计算两个用户评分向量的余弦相似度"""
    common_items = set(user1_ratings.keys()) & set(user2_ratings.keys())
    if not common_items:
        return 0
    
    dot_product = sum(user1_ratings[item] * user2_ratings[item] for item in common_items)
    norm1 = sum(rating**2 for rating in user1_ratings.values()) ** 0.5
    norm2 = sum(rating**2 for rating in user2_ratings.values()) ** 0.5
    
    return dot_product / (norm1 * norm2) if norm1 * norm2 != 0 else 0

# 皮尔逊相关系数考虑用户评分偏好
def pearson_correlation(user1_ratings, user2_ratings):
    common_items = set(user1_ratings.keys()) & set(user2_ratings.keys())
    if len(common_items) < 2:
        return 0
    
    n = len(common_items)
    sum1 = sum(user1_ratings[item] for item in common_items)
    sum2 = sum(user2_ratings[item] for item in common_items)
    sum1_sq = sum(user1_ratings[item]**2 for item in common_items)
    sum2_sq = sum(user2_ratings[item]**2 for item in common_items)
    p_sum = sum(user1_ratings[item] * user2_ratings[item] for item in common_items)
    
    num = p_sum - (sum1 * sum2 / n)
    den = ((sum1_sq - sum1**2/n) * (sum2_sq - sum2**2/n)) ** 0.5
    
    return num / den if den != 0 else 0
```

**案例：电影推荐**  
假设用户A喜欢《肖申克的救赎》和《阿甘正传》，用户B喜欢《肖申克的救赎》和《泰坦尼克号》，用户C喜欢《阿甘正传》。系统会认为A和B相似（共同喜欢《肖申克的救赎》），A和C相似（共同喜欢《阿甘正传》），因此可能会给用户A推荐《泰坦尼克号》。

### 2.2 物品协同过滤（ItemCF）

**核心思想**：基于"用户可能喜欢与他之前喜欢的物品相似的物品"这一假设。ItemCF在实际应用中通常比UserCF效果更好，因为物品之间的相似度相对稳定。

**算法步骤**：
1. 计算物品之间的相似度
2. 根据用户历史行为，找到与历史物品最相似的物品
3. 对候选物品进行评分预测

**物品相似度计算**：
```python
def item_similarity(item1_ratings, item2_ratings, rating_matrix):
    """
    计算两个物品的相似度
    item1_ratings: 喜欢物品1的用户集合
    item2_ratings: 喜欢物品2的用户集合
    """
    # 用户交集
    common_users = item1_ratings.keys() & item2_ratings.keys()
    if not common_users:
        return 0
    
    # 基于共同用户的相似度计算
    numerator = sum(1 for user in common_users)
    denominator = (len(item1_ratings) * len(item2_ratings)) ** 0.5
    
    return numerator / denominator if denominator != 0 else 0
```

**改进版ItemCF：IUF（Inverse User Frequency）**  
考虑活跃用户对相似度计算的影响，降低活跃用户的贡献：
```python
def iuf_item_similarity(item1_ratings, item2_ratings, user_activity):
    """
    考虑用户活跃度的物品相似度计算
    user_activity: 用户活跃度评分，活跃度越高值越小
    """
    common_users = item1_ratings.keys() & item2_ratings.keys()
    if not common_users:
        return 0
    
    # 活跃用户的贡献降低
    numerator = sum(user_activity.get(user, 1) for user in common_users)
    denominator = (len(item1_ratings) * len(item2_ratings)) ** 0.5
    
    return numerator / denominator if denominator != 0 else 0
```

### 2.3 矩阵分解（Matrix Factorization）

**核心思想**：将用户-物品评分矩阵分解为用户矩阵和物品矩阵的乘积，通过低维向量表示用户和物品的隐含特征。

**数学模型**：
$$R \approx U \times V^T$$

其中，$R$是用户-物品评分矩阵，$U$是用户隐因子矩阵，$V$是物品隐因子矩阵。

**常用算法**：
1. **SVD（奇异值分解）**：适用于完整矩阵
2. **FunkSVD**：适用于稀疏矩阵，只考虑有评分的位置
3. **BiasSVD**：加入用户和物品的偏置项
4. **SVD++**：结合隐式反馈信息

**实现代码**：
```python
import numpy as np
from scipy.sparse import csr_matrix

class MatrixFactorization:
    def __init__(self, n_users, n_items, n_factors=50, learning_rate=0.01, regularization=0.02):
        self.n_users = n_users
        self.n_items = n_items
        self.n_factors = n_factors
        self.lr = learning_rate
        self.reg = regularization
        
        # 初始化用户和物品隐因子矩阵
        self.P = np.random.normal(0, 0.1, (n_users, n_factors))
        self.Q = np.random.normal(0, 0.1, (n_items, n_factors))
        
        # 偏置项
        self.user_biases = np.zeros(n_users)
        self.item_biases = np.zeros(n_items)
        self.global_bias = 0
    
    def train(self, train_data, n_epochs=20):
        """训练模型"""
        for epoch in range(n_epochs):
            total_loss = 0
            
            for user, item, rating in train_data:
                # 预测评分
                pred = self.predict(user, item)
                error = rating - pred
                total_loss += error ** 2
                
                # 更新偏置项
                self.user_biases[user] += self.lr * (error - self.reg * self.user_biases[user])
                self.item_biases[item] += self.lr * (error - self.reg * self.item_biases[item])
                
                # 更新隐因子矩阵
                self.P[user, :] += self.lr * (error * self.Q[item, :] - self.reg * self.P[user, :])
                self.Q[item, :] += self.lr * (error * self.P[user, :] - self.reg * self.Q[item, :])
            
            # 计算RMSE
            rmse = np.sqrt(total_loss / len(train_data))
            print(f"Epoch {epoch+1}, RMSE: {rmse:.4f}")
    
    def predict(self, user, item):
        """预测评分"""
        pred = self.global_bias + self.user_biases[user] + self.item_biases[item]
        pred += np.dot(self.P[user, :], self.Q[item, :])
        return pred
    
    def recommend(self, user_id, n_recommendations=10):
        """为用户生成推荐"""
        # 计算所有物品的预测评分
        user_vector = self.P[user_id, :]
        item_scores = np.dot(user_vector, self.Q.T) + self.user_biases[user_id] + self.item_biases + self.global_bias
        
        # 排除已评分物品（这里简化处理）
        recommended_items = np.argsort(item_scores)[::-1][:n_recommendations]
        return recommended_items
```

**案例：Netflix Prize**  
2006年Netflix举办推荐系统竞赛，Matrix Factorization方法成为获胜方案的核心组件。Netflix数据集包含480,189个用户对17,770部电影的评分，矩阵极其稀疏（99.8%为空），MF成功地通过低维向量捕捉了用户和电影的隐含特征。

## 3. 基于内容的推荐

### 3.1 基本原理

基于内容的推荐通过分析物品的内容特征，匹配用户偏好来实现推荐。核心假设是：用户未来可能喜欢与其过去喜欢的物品具有相似内容的物品。

### 3.2 关键技术

**物品内容表示**：
- 文本内容：TF-IDF、Word2Vec、BERT
- 图像内容：CNN特征提取
- 属性特征：分类标签、元数据

**用户画像构建**：
- 显式特征：用户注册信息
- 隐式特征：从历史行为中提取的偏好特征

**相似度计算**：
```python
class ContentBasedRecommender:
    def __init__(self, items_df):
        self.items_df = items_df
        self.item_features = self.extract_features(items_df)
    
    def extract_features(self, items_df):
        """提取物品内容特征"""
        features = {}
        
        for idx, item in items_df.iterrows():
            # 文本特征
            text = f"{item['title']} {item['description']}"
            text_features = self.text_to_features(text)
            
            # 属性特征
            attribute_features = self.extract_attributes(item)
            
            # 合并特征
            features[item['id']] = {
                'text': text_features,
                'attributes': attribute_features
            }
        
        return features
    
    def text_to_features(self, text):
        """将文本转换为特征向量"""
        # 使用TF-IDF
        from sklearn.feature_extraction.text import TfidfVectorizer
        
        vectorizer = TfidfVectorizer(max_features=100)
        tfidf_matrix = vectorizer.fit_transform([text])
        return tfidf_matrix.toarray()[0]
    
    def extract_attributes(self, item):
        """提取属性特征"""
        # 分类标签
        genre_features = self.encode_genres(item['genres'])
        
        # 导演、演员等（简化处理）
        director_feature = 1 if item['director'] else 0
        
        return np.concatenate([genre_features, [director_feature]])
    
    def build_user_profile(self, user_history):
        """构建用户画像"""
        if not user_history:
            return np.zeros(self.feature_dimension)
        
        user_profile = np.zeros(self.feature_dimension)
        total_weight = 0
        
        for item_id, rating in user_history.items():
            if item_id in self.item_features:
                item_features = self.item_features[item_id]
                # 考虑评分权重
                user_profile += item_features * rating
                total_weight += rating
        
        return user_profile / total_weight if total_weight > 0 else user_profile
    
    def recommend(self, user_id, user_history, n_recommendations=10):
        """基于内容的推荐"""
        # 构建用户画像
        user_profile = self.build_user_profile(user_history)
        
        # 计算用户画像与所有物品的相似度
        similarities = []
        for item_id, item_features in self.item_features.items():
            # 只考虑未交互过的物品
            if item_id not in user_history:
                similarity = self.cosine_similarity(user_profile, item_features)
                similarities.append((item_id, similarity))
        
        # 按相似度排序
        similarities.sort(key=lambda x: x[1], reverse=True)
        return [item_id for item_id, _ in similarities[:n_recommendations]]
```

### 3.3 优缺点分析

**优点**：
1. **可解释性强**：推荐理由清晰（"因为你喜欢科幻电影"）
2. **用户独立性**：不需要其他用户的行为数据
3. **冷启动友好**：对于新物品可以立即推荐
4. **无流行度偏差**：避免推荐热门物品

**缺点**：
1. **特征工程复杂**：需要大量领域知识设计特征
2. **过度专业化**：推荐结果多样性不足
3. **新用户问题**：新用户缺乏历史行为
4. **内容分析困难**：多媒体内容特征提取困难

### 3.4 混合推荐策略

实际系统中，通常将基于内容的推荐与其他方法结合：
```python
class HybridRecommender:
    def __init__(self, cf_model, content_model, alpha=0.7):
        self.cf_model = cf_model
        self.content_model = content_model
        self.alpha = alpha  # CF模型的权重
    
    def recommend(self, user_id, user_history, n_recommendations=10):
        # CF推荐
        cf_recommendations = self.cf_model.recommend(user_id, n_recommendations*2)
        
        # 内容推荐
        content_recommendations = self.content_model.recommend(
            user_id, user_history, n_recommendations*2
        )
        
        # 混合评分
        item_scores = {}
        
        for i, (item_id, cf_score) in enumerate(cf_recommendations[:n_recommendations*2]):
            rank = n_recommendations*2 - i
            item_scores[item_id] = self.alpha * rank
        
        for i, (item_id, content_score) in enumerate(content_recommendations[:n_recommendations*2]):
            rank = n_recommendations*2 - i
            if item_id in item_scores:
                item_scores[item_id] += (1 - self.alpha) * rank
            else:
                item_scores[item_id] = (1 - self.alpha) * rank
        
        # 排序并返回
        sorted_items = sorted(item_scores.items(), key=lambda x: x[1], reverse=True)
        return [item_id for item_id, _ in sorted_items[:n_recommendations]]
```

## 4. 深度推荐模型

### 4.1 DeepFM（Deep Factorization Machine）

**核心思想**：结合因子分解机（FM）的线性部分和深度神经网络的非线性部分，自动学习特征交叉。

**模型架构**：
1. **FM部分**：显式学习一阶和二阶特征交叉
2. **DNN部分**：学习高阶特征交叉

**数学表达**：
$$\hat{y} = \sigma(y_{FM} + y_{DNN})$$

**实现代码**：
```python
import tensorflow as tf
from tensorflow.keras.layers import Input, Embedding, Dense, Concatenate, Flatten

class DeepFM(tf.keras.Model):
    def __init__(self, feature_dims, embedding_dim=8, dnn_hidden_units=[256, 128, 64]):
        super(DeepFM, self).__init__()
        
        self.feature_dims = feature_dims
        self.embedding_dim = embedding_dim
        
        # FM部分：一阶特征
        self.first_order_embeddings = []
        for dim in feature_dims:
            self.first_order_embeddings.append(
                Embedding(dim, 1, name=f'first_order_{dim}')
            )
        
        # FM部分：二阶特征交叉
        self.second_order_embeddings = []
        for dim in feature_dims:
            self.second_order_embeddings.append(
                Embedding(dim, embedding_dim, name=f'second_order_{dim}')
            )
        
        # DNN部分
        self.dnn_layers = []
        for units in dnn_hidden_units:
            self.dnn_layers.append(Dense(units, activation='relu'))
            self.dnn_layers.append(tf.keras.layers.BatchNormalization())
        
        self.output_layer = Dense(1, activation='sigmoid')
    
    def call(self, inputs):
        # inputs: 字段索引列表，每个字段对应一个特征
        
        # 一阶特征
        first_order_output = 0
        for i, embedding in enumerate(self.first_order_embeddings):
            first_order_output += embedding(inputs[i])
        
        # 二阶特征交叉（FM部分）
        second_order_outputs = []
        for i, embedding in enumerate(self.second_order_embeddings):
            second_order_outputs.append(embedding(inputs[i]))
        
        # 计算二阶交叉项
        square_of_sum = tf.square(tf.reduce_sum(second_order_outputs, axis=0))
        sum_of_square = tf.reduce_sum(tf.square(second_order_outputs), axis=0)
        second_order_output = 0.5 * tf.reduce_sum(square_of_sum - sum_of_square, axis=1, keepdims=True)
        
        # DNN部分
        dnn_input = Concatenate()(second_order_outputs)
        dnn_input = Flatten()(dnn_input)
        
        dnn_output = dnn_input
        for layer in self.dnn_layers:
            dnn_output = layer(dnn_output)
        
        # 输出
        output = self.output_layer(
            first_order_output + second_order_output + dnn_output
        )
        
        return output
```

### 4.2 DIN（Deep Interest Network）

**核心思想**：引入注意力机制，动态学习用户兴趣与候选物品的相关性。

**关键创新**：
1. **注意力机制**：根据候选物品动态计算用户历史行为的权重
2. **Local Activation Unit**：专门计算注意力分数的子网络

**模型架构**：
```
用户行为序列 → 注意力网络 → 加权兴趣表示 → 与候选物品拼接 → DNN → 输出
```

**代码实现**：
```python
class DINAttention(tf.keras.layers.Layer):
    def __init__(self, hidden_units=[64, 32]):
        super(DINAttention, self).__init__()
        self.hidden_units = hidden_units
        self.attention_layers = []
        for units in hidden_units:
            self.attention_layers.append(Dense(units, activation='relu'))
        self.attention_output = Dense(1, activation=None)
    
    def call(self, query, keys, keys_length):
        """
        query: 候选物品向量 [batch_size, embedding_dim]
        keys: 用户历史行为序列 [batch_size, seq_len, embedding_dim]
        keys_length: 每个用户的有效行为长度 [batch_size]
        """
        # 重复query以匹配keys的维度
        queries = tf.tile(tf.expand_dims(query, 1), [1, keys.shape[1], 1])
        
        # 拼接query和keys
        attention_input = Concatenate()([queries, keys, queries - keys, queries * keys])
        
        # 计算注意力分数
        attention_scores = attention_input
        for layer in self.attention_layers:
            attention_scores = layer(attention_scores)
        attention_scores = self.attention_output(attention_scores)
        attention_scores = tf.squeeze(attention_scores, -1)
        
        # Masking
        mask = tf.sequence_mask(keys_length, maxlen=keys.shape[1], dtype=tf.float32)
        attention_scores = attention_scores * mask + (1 - mask) * (-1e9)
        
        # Softmax
        attention_weights = tf.nn.softmax(attention_scores, axis=1)
        attention_weights = tf.expand_dims(attention_weights, -1)
        
        # 加权求和
        user_interest = tf.reduce_sum(keys * attention_weights, axis=1)
        
        return user_interest, attention_weights

class DINModel(tf.keras.Model):
    def __init__(self, feature_dims, embedding_dim=8, attention_hidden=[64, 32]):
        super(DINModel, self).__init__()
        
        self.embedding_layers = {}
        for dim in feature_dims:
            self.embedding_layers[dim] = Embedding(dim, embedding_dim)
        
        self.attention = DINAttention(attention_hidden)
        
        # DNN部分
        self.dnn = tf.keras.Sequential([
            Dense(256, activation='relu'),
            Dense(128, activation='relu'),
            Dense(64, activation='relu'),
            Dense(1, activation='sigmoid')
        ])
    
    def call(self, inputs):
        """
        inputs: 字典，包含：
        - candidate: 候选物品特征 [batch_size, n_candidate_features]
        - behavior: 用户历史行为序列 [batch_size, seq_len, n_behavior_features]
        - behavior_length: 行为序列长度 [batch_size]
        """
        # 候选物品embedding
        candidate_embedding = self.embedding_layers[inputs['candidate'][:, 0]](inputs['candidate'][:, 0])
        
        # 用户历史行为embedding
        behavior_embedding = self.embedding_layers[inputs['behavior'][:, :, 0]](inputs['behavior'][:, :, 0])
        
        # 注意力机制
        user_interest, attention_weights = self.attention(
            candidate_embedding, 
            behavior_embedding, 
            inputs['behavior_length']
        )
        
        # 拼接特征
        concat_features = Concatenate()([candidate_embedding, user_interest])
        
        # DNN预测
        output = self.dnn(concat_features)
        
        return output, attention_weights
```

### 4.3 DIEN（Deep Interest Evolution Network）

**核心创新**：建模用户兴趣的动态演化过程，比DIN更能捕捉用户兴趣的变化趋势。

**关键组件**：
1. **兴趣抽取层（Interest Extractor Layer）**：使用GRU从行为序列中抽取兴趣
2. **兴趣演化层（Interest Evolving Layer）**：使用AUGRU（注意力更新GRU）建模兴趣演化
3. **辅助损失（Auxiliary Loss）**：辅助任务帮助学习更好的兴趣表示

**数学表达**：
$$h_t = \text{GRU}(h_{t-1}, e_t)$$
$$a_t = \frac{\exp(o_t^T h_t)}{\sum_{j=1}^T \exp(o_j^T h_j)}$$
$$\tilde{h}_t = a_t \odot \text{GRU}(h_{t-1}, e_t) + (1-a_t) \odot h_{t-1}$$

**案例：电商场景**  
用户购买手机 → 配件（手机壳、耳机）→ 电脑 → 外设。DIEN能识别出用户从手机兴趣向电脑兴趣的演化，比DIN更能理解用户的长期购买路径。

## 5. 召回策略

### 5.1 双塔模型（Two-Tower Model）

**核心思想**：将用户和物品分别映射到同一向量空间，通过向量相似度进行匹配。

**架构**：
```
用户特征 → 用户塔 → 用户向量 → 
物品特征 → 物品塔 → 物品向量 → 向量相似度计算
```

**优势**：
1. **可扩展性**：物品向量可离线预计算，线上只需计算用户向量
2. **实时性**：向量相似度计算高效
3. **灵活性**：容易融入多种特征

**实现代码**：
```python
import tensorflow as tf

class TwoTowerModel:
    def __init__(self, user_feature_dim, item_feature_dim, embedding_dim=64):
        self.user_tower = self.build_user_tower(user_feature_dim, embedding_dim)
        self.item_tower = self.build_item_tower(item_feature_dim, embedding_dim)
    
    def build_user_tower(self, input_dim, output_dim):
        """构建用户塔"""
        model = tf.keras.Sequential([
            Dense(256, activation='relu'),
            Dense(128, activation='relu'),
            Dense(output_dim, activation=None)  # 输出用户向量
        ])
        return model
    
    def build_item_tower(self, input_dim, output_dim):
        """构建物品塔"""
        model = tf.keras.Sequential([
            Dense(256, activation='relu'),
            Dense(128, activation='relu'),
            Dense(output_dim, activation=None)  # 输出物品向量
        ])
        return model
    
    def forward(self, user_features, item_features):
        """前向传播"""
        user_embedding = self.user_tower(user_features)
        item_embedding = self.item_tower(item_features)
        
        # 归一化
        user_embedding = tf.nn.l2_normalize(user_embedding, axis=1)
        item_embedding = tf.nn.l2_normalize(item_embedding, axis=1)
        
        # 计算相似度（点积）
        similarity = tf.reduce_sum(user_embedding * item_embedding, axis=1)
        
        return similarity, user_embedding, item_embedding
    
    def train_step(self, user_features, item_features, labels, optimizer):
        """训练步骤"""
        with tf.GradientTape() as tape:
            similarity, _, _ = self.forward(user_features, item_features)
            loss = tf.keras.losses.binary_crossentropy(labels, similarity)
        
        # 计算梯度
        gradients = tape.gradient(loss, 
                                self.user_tower.trainable_variables + 
                                self.item_tower.trainable_variables)
        
        # 更新参数
        optimizer.apply_gradients(zip(gradients, 
                                    self.user_tower.trainable_variables + 
                                    self.item_tower.trainable_variables))
        
        return loss
```

### 5.2 ANN近似最近邻检索

**核心问题**：在向量空间中快速找到与查询向量最相似的K个向量。

**主流算法**：
1. **局部敏感哈希（LSH）**：通过哈希函数将相似向量映射到同一桶
2. **量化方法（PQ）**：将高维向量分解为多个子空间
3. **图方法（HNSW、NSW）**：构建可导航的小世界图
4. **混合方法（ScaNN）**：结合量化与图搜索

**代码示例（使用FAISS）**：
```python
import faiss
import numpy as np

class ANNIndex:
    def __init__(self, vector_dim, index_type='HNSW'):
        self.vector_dim = vector_dim
        self.index_type = index_type
        self.index = None
        
    def build_index(self, vectors):
        """构建索引"""
        if self.index_type == 'Flat':
            # 暴力搜索
            self.index = faiss.IndexFlatIP(self.vector_dim)
        elif self.index_type == 'IVF':
            # 倒排文件索引
            nlist = 100  # 聚类中心数
            quantizer = faiss.IndexFlatIP(self.vector_dim)
            self.index = faiss.IndexIVFFlat(quantizer, self.vector_dim, nlist)
        elif self.index_type == 'HNSW':
            # 层次化可导航小世界图
            M = 32  # 每层连接数
            self.index = faiss.IndexHNSWFlat(self.vector_dim, M)
        
        # 训练（如果需要）
        if self.index_type == 'IVF':
            self.index.train(vectors)
        
        # 添加向量
        self.index.add(vectors)
        
        # 设置搜索参数
        if self.index_type == 'IVF':
            self.index.nprobe = 10  # 搜索的聚类中心数
        
        return self
    
    def search(self, query_vector, k=10):
        """搜索最近邻"""
        # 归一化
        query_vector = query_vector / np.linalg.norm(query_vector)
        
        # 搜索
        distances, indices = self.index.search(query_vector.reshape(1, -1), k)
        
        return indices[0], distances[0]

# 使用示例
def build_product_index(product_vectors):
    """构建商品索引"""
    # 向量维度
    vector_dim = product_vectors.shape[1]
    
    # 创建索引
    index = ANNIndex(vector_dim, index_type='HNSW')
    index.build_index(product_vectors.astype('float32'))
    
    return index
```

### 5.3 多路召回策略

**设计理念**：不同召回策略有不同的侧重点，组合使用可以覆盖更全面的用户需求。

**常见召回路**：
1. **协同过滤召回**：基于用户/物品相似度
2. **内容召回**：基于物品内容特征
3. **热门召回**：全局或分类别热门
4. **最新召回**：新上架物品
5. **个性化召回**：基于用户画像的召回
6. **图关系召回**：基于知识图谱或社交关系

**实现框架**：
```python
class MultiChannelRecall:
    def __init__(self):
        self.channels = {}
        self.channel_weights = {}
    
    def add_channel(self, channel_name, channel, weight=1.0):
        """添加召回通道"""
        self.channels[channel_name] = channel
        self.channel_weights[channel_name] = weight
    
    def recall(self, user_id, user_history, n_candidates_per_channel=100):
        """多路召回"""
        all_candidates = {}
        
        for channel_name, channel in self.channels.items():
            try:
                # 调用各通道的召回函数
                candidates = channel.recall(user_id, user_history, n_candidates_per_channel)
                
                # 为每个候选物品添加权重信息
                for item_id, score in candidates:
                    if item_id not in all_candidates:
                        all_candidates[item_id] = 0
                    # 加权累加
                    all_candidates[item_id] += score * self.channel_weights[channel_name]
                    
            except Exception as e:
                print(f"Channel {channel_name} recall failed: {e}")
                continue
        
        # 排序并返回
        sorted_candidates = sorted(all_candidates.items(), key=lambda x: x[1], reverse=True)
        return sorted_candidates
    
    def recall_parallel(self, user_id, user_history, n_candidates_per_channel=100):
        """并行多路召回（适合在线服务）"""
        import concurrent.futures
        
        with concurrent.futures.ThreadPoolExecutor() as executor:
            futures = {}
            
            for channel_name, channel in self.channels.items():
                future = executor.submit(
                    channel.recall, 
                    user_id, 
                    user_history, 
                    n_candidates_per_channel
