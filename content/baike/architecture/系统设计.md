# 系统设计


> 📌 **导航**：本文是 **系统设计** 枢纽页。原 10 节中 CAP / BASE / 一致性 / 分布式 ID / 限流 / 读写分离 均已各有独立专条，数据分片与热点处理合并为一个新词条，本页只做权衡主线与索引。

## 定义

**一句话定义：** 系统设计是在**容量、可用性、一致性、成本**四个互相冲突的目标之间做显式取舍的工程方法——先估算规模与读写比，再按 CAP 类定理确定故障时要保哪一头，最后用分片、缓存、副本、限流等标准构件把选择落成可实现的结构。

**通俗类比：** 像装修预算：面积、工期、用料三样不能同时全要，先定优先级，才知道哪块该省钱、哪块必须花钱。

本页是**枢纽页**：给出权衡主线与"去哪一条看细节"的索引，各构件本体走下表双链。

## 为什么需要它

需求相同的两个系统，一个能撑住、一个雪崩，差别几乎都在设计阶段做的取舍是否显式。没写下来的假设会在故障时以最难看的形态兑现：以为缓存能挡、结果热点打穿到主库；以为从库能读、结果写后读到了旧数据；以为限流是运维的事、结果一次爬虫打满连接池。系统设计要做的，是把这些取舍**在写代码之前摊到桌面上并给出可量化的口径**（QPS、存储量、可用性几个九），让"保什么、牺牲什么、代价多大"成为可讨论的结论。

## 核心机制

### 先算账再画图

任何设计前先把需求换成数字：日请求量 ÷ 86400 得平均 QPS、峰值按 2–3 倍留量、按读写比判断该堆只读副本还是该动分片、按增长率算一年后的存储与带宽。这一步决定后面所有取舍的量级——**多数"要不要分片"的争论，其实是没人先算过账**。

### 故障时保哪一头

网络分区在真实机房里是常态而非异常，因此 CAP 的落点几乎总是在 **C 与 A 之间选**：偏 CP 的系统分区时宁可拒服务也要守住一致，偏 AP 的允许两侧各自继续、事后收敛，而 BASE 正是选了 AP 之后那套"最终一致 + 补偿"的工程语言。可用性还要与可靠性分开看：能响应不等于响应得对。

### 用副本换读、用分片换容量

读压大就加只读副本，单库放不住就切分片，流量极端集中就做热点处理，突发超过承载就限流、降级、熔断。这些构件不是并列可选项，而是**分别对应"读不动 / 放不下 / 分不均 / 扛不住"四种瓶颈**——选型应先从瓶颈归因倒推，而不是从技术清单正推。

## 具体示例

可用性目标要先换算成停机预算，再反推需要几层冗余：

```text
99.9%    年停机  8.76 小时   单区域 + 主备即可
99.99%   年停机  52.6 分钟   需多可用区 + 健康检查自动摘除
99.999%  年停机  5.26 分钟   需多区域部署 + 流量切换自动化
```

同样的请求量，读写比 100:1 与 1:1 会导出完全不同的架构：前者堆只读副本与缓存，后者必须从分片与写路径入手。

## 何时用与何时不用

- **用**：面向不确定增长的服务做架构评审；容量规划与成本预算；故障复盘后判断该补哪层防护；面试设计题按"算账 → 取舍 → 构件 → 瓶颈"四步展开。
- **不用**：规模明确且很小、单体加索引即可覆盖时，引入分片与多副本只会增加运维面；探索期用架构换灵活性通常是错配。
- **警惕**：把设计当成构件堆叠（"上缓存、上 MQ、上 K8s"）而不做瓶颈归因，是过度设计的典型形态。

## 优劣与代价

✅ 把隐含假设显式化，故障与扩容都能提前推演，成本可预算。
✅ 标准构件成熟度高，团队有共同语言、评审可复用。
⚠️ 每个构件都自带复杂度与不一致窗口，堆叠越多、可解释性越差。
⚠️ 预估错误会让取舍整体失效：为十倍流量做的分片可能常年空转，为百倍做的高可用可能一次热点就被打穿。

## 与相关概念的区别

- **可用性 vs 可靠性**：可用性衡量能不能访问，可靠性衡量访问结果是否正确；持续返回错误码的系统可以"很可用"却毫不可靠。
- **扩展性 vs 性能**：性能是单请求快慢，扩展性是加资源能否线性加吞吐，后者由分片与无状态化决定。
- **一致性 vs 持久性**：一致性讲多副本看到的值是否相同，持久性讲已确认的写入是否会丢，两者相互独立。
- **系统设计 vs [[架构模式]]**：模式讲结构选型（单体/微服务/事件驱动），设计讲在目标冲突之间做量化取舍。

## 常见误区

- 架构里组件堆得越全，系统就越接近高可用高并发。
- 只要用了分布式数据库，一致性问题就自然被解决了。
- 限流、缓存、分片三者任选其一，都能兜住突发流量。

## 面试速答

> 🎯 系统设计先算账（QPS、存储、读写比）再画图，故障时按 CAP 在 C 与 A 间取舍、用 BASE 承接最终一致；构件按瓶颈归因选用：读写分离换读压、分片换容量、热点处理换分布不均、限流降级熔断换过载。
