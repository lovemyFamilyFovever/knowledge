# 事件驱动架构

## 核心概念

**事件：** 已发生的事实，不可变。如"订单已创建"、"支付已完成"。

## Event Sourcing

不存储当前状态，存储所有事件：

```
OrderCreated -> ItemAdded -> PaymentReceived -> OrderShipped
```

当前状态 = 重放所有事件。

## CQRS（命令查询分离）

```
Command(写) -> 写数据库 -> 发布事件 -> 读数据库更新
Query(读) -> 读数据库（可针对查询优化的结构）
```

## 事件驱动 vs 请求驱动

| 特性 | 请求驱动 | 事件驱动 |
|------|----------|----------|
| 耦合 | 紧耦合 | 松耦合 |
| 同步性 | 同步 | 异步 |
| 可扩展性 | 受限于被调方 | 独立扩展 |
| 复杂度 | 低 | 高（最终一致性） |
