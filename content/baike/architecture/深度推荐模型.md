# 深度推荐模型

> 📌 **导航**：本文是 **深度推荐模型** 词条，属于 architecture 术语集。相关枢纽：[[推荐系统设计与实现]]、[[推荐系统]]、[[深度学习基础]]、[[注意力机制]]。

## 定义

**一句话定义：** 深度推荐模型是用神经网络替代手工特征交叉的排序模型家族：DeepFM 让 FM 负责一阶与二阶交叉、DNN 负责高阶交叉并联输出；DIN 用注意力让"用户历史"按当前候选物品重新加权；DIEN 再把兴趣当成随时间演化的隐状态用 GRU 建模——共同回答精排层的两个问题：特征怎么交叉、行为序列怎么用。

**通俗类比：** 组合特征从"工程师手写类目 × 时段 × 年龄段"变成模型自己学；DIN 则像一位记得你全部历史、但看你今天想买什么才决定提哪段记忆的销售。

## 为什么需要它

精排只对几百个候选打分，算力预算最厚，所以放得下最复杂的模型。它的输入是高维稀疏类别特征（用户 ID、物品 ID、类目、时段、上下文），逻辑回归要有效就必须依赖人工交叉，而组合空间是特征数的笛卡尔积，人写不过来。深度模型的价值就是自动学交叉，把"记忆（高频组合直接命中）"与"泛化（没见过的组合靠相似 embedding 推）"合进一个网络。另一半痛点是行为序列：把历史硬压成一个定长向量，会让与当前候选无关的历史一起稀释信号，注意力机制就是为"按候选取相关历史"而引入的。

## 核心机制

```text
DeepFM : y_hat = sigma( y_first_order + y_FM_second + y_DNN )
FM 二阶 : 0.5 * Σ_k [ (Σ_i v_ik)^2 − Σ_i v_ik^2 ]   # 两两交叉化简成线性复杂度
```

- **DeepFM**：每个字段两份 embedding（一阶取 1 维、二阶取 embedding_dim=8），一阶项线性相加，二阶项用"和的平方减平方的和"避开 O(n²) 的两两内积，DNN 侧把二阶 embedding 拼接后过 256-128-64 全连接（带 BatchNorm），三路相加过 sigmoid 出点击概率——它顶替了"FM + 手工深度特征"的两段式流程。
- **DIN**：Local Activation Unit 把候选物品当 query、历史行为当 keys，拼接四元组后过小 MLP 出注意力分数，再用序列真实长度做 mask 后 softmax 归一化，加权求和得到"针对这个候选的兴趣表示"。同一用户面对不同候选，兴趣向量不同——这是它相对定长 pooling 的本质改进（注意力原理见 [[注意力机制]]）。
- **DIEN**：兴趣抽取层用 GRU 从行为序列逐步抽出隐兴趣，兴趣演化层用 AUGRU（注意力更新门 GRU）让与候选相关的兴趣分支活得更久，再用辅助损失以下一时刻的真实行为监督中间隐状态，让这个隐变量真的学到东西。

## 具体示例

原稿的电商案例最能说明差异：用户依次买手机 → 手机配件 → 电脑 → 键鼠。候选是"显示器"时，DIN 把注意力压在"电脑"那一步，但它拿到的仍是加权后的静态混合；DIEN 额外建模顺序——GRU 隐状态从手机域漂向电脑域，AUGRU 让这条演化链保持相关，于是能给"还没买外设"的用户提前推键鼠。这就是"序列怎么建模"与"特征怎么交叉"两条主线的分工。层间选择上：粗排用 LR / GBDT / 浅层网络（几十维特征、100ms 内），精排才上 DeepFM / DIN 这类数百到数千维特征的模型。

## 何时用与何时不用

- **用**：候选量已被召回与粗排压到几百、单次打分预算充足；特征以高维稀疏类别为主且行为序列可观。
- **不用**：物品与用户量都很小（几百条日志喂不饱深度模型，梯度提升树更稳，见 [[梯度提升树]]）；没有离线训练与在线推理基础设施时（模型上线成本见 [[模型压缩与部署]]）。
- **别忘**：注意力序列越长延迟越高，线上要截断或分层建模；离线 AUC 涨不等于线上收益，必须过实验（[[A B测试与实验设计]]）。

## 优劣与代价

✅ 自动特征交叉，省掉人工组合特征工程的主要人力。
✅ 注意力让同一段历史对不同候选产生不同表示，显著优于定长 pooling。
✅ 表达力强，可持续吸收多目标与侧信息。
⚠️ 训练与推理成本高，参数与 embedding 表体积大，对特征平台是硬依赖；可解释性弱，坏 case 难归因到某条规则。
⚠️ 序列建模（DIN → DIEN）的收益依赖行为密度，低活用户与冷启动提升有限。

## 与相关概念的区别

- **vs [[协同过滤与矩阵分解]]**：矩阵分解只有隐因子内积，不建模特征交叉与上下文；DeepFM 的 FM 部分本质是其可微版本。
- **vs [[RNN LSTM GRU]]**：DIEN 用 GRU 但目标不同——语言建模输出下一个 token，DIEN 输出的是可被候选注意力调制的兴趣隐状态。
- **vs 重排策略**：精排逐点估分，重排管列表级约束（多样性、打散、频控），见 [[推荐系统设计与实现]]。

## 常见误区

- DeepFM 里的 FM 与 DNN 是先跑 FM 再跑 DNN 的两段串联流水线。
- DIN 会把用户全部历史行为等权平均成一个固定兴趣向量再去打分。
- 排序模型离线 AUC 涨了，线上业务指标就一定跟着涨。

## 面试速答

> 🎯 精排深度模型三代主线：DeepFM 并联 FM（一阶 + 二阶交叉，用"和的平方减平方的和"线性化）与 DNN（高阶交叉）自动学特征组合；DIN 用 Local Activation 让历史行为按候选物品加注意力权重重算兴趣；DIEN 再叠 GRU + AUGRU 与辅助损失建模兴趣演化。
