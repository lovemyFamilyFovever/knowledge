## 限流算法

| 算法 | 原理 | 特点 |
|------|------|------|
| 固定窗口 | 固定时间段计数 | 简单但有窗口边界突刺 |
| 滑动窗口 | 滑动时间计数 | 平滑 |
| 令牌桶 | 匀速放入令牌 | 允许突发 |
| 漏桶 | 匀速流出请求 | 严格限速 |

```python
# 令牌桶限流
class TokenBucket:
    def __init__(self, rate, capacity):
        self.rate = rate          # 令牌生成速率
        self.capacity = capacity  # 桶容量
        self.tokens = capacity
        self.last_time = time.time()

    def allow(self):
        now = time.time()
        self.tokens = min(self.capacity, self.tokens + (now - self.last_time) * self.rate)
        self.last_time = now
        if self.tokens >= 1:
            self.tokens -= 1
            return True
        return False
```
