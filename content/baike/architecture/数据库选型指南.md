# 数据库选型指南


> 📌 **导航**：本文是 **数据库选型指南** 词条，属于 architecture 术语集。相关枢纽：[[SaaS产品技术架构]]、[[事件驱动架构]]、[[云原生与多云架构实战指南]]、[[分布式系统设计完全指南]]、[[微服务架构]]。

## 关系型数据库

| 数据库 | 特点 | 适用 |
|--------|------|------|
| MySQL | 成熟稳定，生态丰富 | Web应用 |
| PostgreSQL | 功能最强，扩展丰富 | 复杂查询/地理信息 |
| SQLite | 嵌入式，零配置 | 移动端/小型应用 |

## NoSQL数据库

| 类型 | 代表 | 适用场景 |
|------|------|----------|
| 文档型 | MongoDB | 灵活Schema |
| 键值型 | Redis | 缓存/会话 |
| 列族型 | HBase/Cassandra | 时序/宽表 |
| 图数据库 | Neo4j | 关系查询 |
| 搜索引擎 | Elasticsearch | 全文搜索 |
| 时序数据库 | InfluxDB/TDengine | 监控/IoT |

## NewSQL

| 数据库 | 特点 |
|--------|------|
| TiDB | MySQL兼容，HTAP |
| CockroachDB | PostgreSQL兼容，全球分布式 |
| OceanBase | 阿里自研，金融级 |

## 选型决策树

```
需要ACID事务? -> 是 -> 关系型(MySQL/PG)
              -> 否 -> 需要灵活Schema? -> MongoDB
                     需要极低延迟? -> Redis
                     需要全文搜索? -> Elasticsearch
                     需要关系遍历? -> Neo4j
                     需要高写入吞吐? -> Cassandra
```
