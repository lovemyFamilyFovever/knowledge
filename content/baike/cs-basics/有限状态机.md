# 有限状态机


> 📌 **导航**：本文是 **有限状态机** 词条，属于 cs-basics 术语集。相关枢纽：[[P 与 NP]]、[[信息论基础]]、[[图灵机]]、[[布尔逻辑与逻辑门]]、[[形式语言与文法]]。

## 定义

**一句话定义：** 有限状态机(Finite State Machine, FSM)是一种抽象计算模型,由有限个状态、一个输入字母表、状态转移函数、一个初始状态和一组接受状态构成;它读取输入符号并据此在状态间转移,用于识别模式、建模行为与控制流程。

**通俗类比：** 像一台自动售货机:投币、选择、出货、找零是几个固定"状态",你的每个操作(输入)让它从一个状态跳到另一个状态,只有走到"出货"这类特定状态才算完成——它的"记忆"仅限于当前处在哪个状态。

> 多义说明:本文以**确定型有限自动机(DFA)** 为主线,并提及非确定型(NFA);二者识别能力等价。FSM 也常指工程中描述对象行为的状态图(state machine)。

## 原理与机制

- 机器从初始状态开始,每读入一个符号,依据转移函数 δ(当前状态, 输入)确定下一状态。
- 输入读完时,若停在**接受状态**则接受该字符串,否则拒绝。
- DFA 每个(状态,输入)只有唯一转移;NFA 允许一个输入对应多个转移或 ε(空)转移。NFA 可通过子集构造转换为等价 DFA。
- FSM 无外部存储,只能"记住"当前状态,因此能识别的语言是**正则语言**,与正则表达式等价。

## 关键组成

形式化定义为五元组 (Q, Σ, δ, q₀, F):

| 符号 | 含义 |
|------|------|
| Q | 有限状态集合 |
| Σ | 输入字母表 |
| δ: Q × Σ → Q | 状态转移函数 |
| q₀ ∈ Q | 初始状态 |
| F ⊆ Q | 接受(终止)状态集合 |

## 应用场景

- 编译器词法分析(识别标识符、数字、关键字)
- 正则表达式匹配引擎
- 通信协议与硬件控制器建模
- 游戏 AI、UI 状态、业务流程编排
- 文本解析与协议状态跟踪(如 TCP 连接状态机)

## 优点与局限

- 优点:模型简单直观、易于分析与实现;行为确定、可穷举验证;是正则语言的精确刻画。
- 局限:无外部存储,无法处理需要"计数/任意深度记忆"的任务(如匹配任意层数括号,需下推自动机);DFA 状态数在最坏情况下可能指数膨胀。

## 常见误区

- 认为 FSM 能识别所有模式:它只能识别正则语言,上下文相关/无关语言需更强模型(下推自动机、图灵机)。
- 混淆 DFA 与 NFA 的效率:NFA 状态可能更少但模拟需回溯/子集;二者表达能力等价。
- 把工程"状态图"与理论"自动机"完全等同:前者偏行为建模,后者有严格语言识别定义。
