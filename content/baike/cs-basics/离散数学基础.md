# 离散数学基础


> 📌 **导航**：本文是 **离散数学基础** 词条，属于 cs-basics 术语集。相关枢纽：[[P 与 NP]]、[[信息论基础]]、[[图灵机]]、[[布尔逻辑与逻辑门]]、[[形式语言与文法]]。

## 为什么学离散数学？

**一句话定义：** 离散数学是研究**离散（可数、不连续）结构**的数学分支，涵盖集合论、数理逻辑、图论、组合计数、数论与代数结构等，是计算机科学的数学基础。

**通俗类比：** 如果微积分研究「平滑连续的曲线」，离散数学研究「一级一级的台阶」——计算机处理的本就是离散的 0/1、有限的集合与确定的步骤，所以它的数学工具也是离散的。

> 多义说明：本文是**入门总览**，只覆盖与编程最相关的几块（集合、逻辑、图、递归 / 归纳、组合），不展开代数结构、数论等完整体系。

### 集合论

**集合**：一组确定对象的全体。
```
A = {1, 2, 3}, B = {2, 3, 4}
A ∪ B = {1, 2, 3, 4}   (并集 union)
A ∩ B = {2, 3}          (交集 intersection)
A − B = {1}             (差集 difference)
|A|   = 3               (基数 cardinality)
A ⊆ B                   (A 是 B 的子集)
```
**编程中的映射：**
- 数据库 `UNION` / `INTERSECT` / `EXCEPT` 直接对应并 / 交 / 差集；`INNER JOIN` 则体现「按连接条件匹配」的思想；
- `WHERE` 条件是对集合的筛选（选择运算）；
- 语言内置的 `Set` 数据结构（去重、成员判定）即集合论的直接实现。

### 数理逻辑

- **命题**：可判断真假的陈述句。
- **联结词**：¬（非）、∧（与）、∨（或）、→（蕴含）、↔（等价）。
- **蕴含 P→Q**：仅当「P 真而 Q 假」时为假，其余为真（详见 [[布尔逻辑与逻辑门]]）。
- 编程中的 `if` 条件、布尔表达式、短路求值都是命题逻辑的应用；谓词逻辑（含量词 ∀ 全称、∃ 存在）进一步支撑数据库查询与形式化验证。

### 图论基础

**图 G = (V, E)**：顶点集 V + 边集 E。

| 概念 | 说明 | 应用 |
|------|------|------|
| 有向图 | 边有方向 | 依赖关系、状态转移 |
| 无向图 | 边无方向 | 社交网络 |
| 带权图 | 边有权值 | 最短路径、最小生成树 |
| 树 | 无环连通图 | 文件系统、DOM、目录结构 |
| 二分图 | 顶点分两组、边只跨组 | 匹配问题 |

**经典算法：** Dijkstra（单源最短路径）、DFS / BFS（图遍历）、拓扑排序（任务依赖顺序）、Kruskal / Prim（最小生成树）。

### 递归与数学归纳法

**数学归纳法**：
1. 基础步骤：证明 n = 初值（如 n = 0 或 1）时成立；
2. 归纳步骤：假设 n = k 成立，证明 n = k+1 也成立；
3. 结论：对所有（≥ 初值的）n 成立。

**与递归的对应**：归纳法可证明递归程序的正确性——基础情况对应递归出口，归纳假设对应递归调用。
```python
def factorial(n):
    if n == 0: return 1        # 基础情况（0! = 1）
    return n * factorial(n-1)  # 归纳步骤
```

### 组合计数

- 排列 P(n,k) = n! / (n−k)!；组合 C(n,k) = n! / (k!·(n−k)!)。
- 是分析算法「解空间大小」的基础（如穷举复杂度 O(n!)、O(2ⁿ)）。

## 应用场景

- 数据结构与算法：图、树、集合、递归无处不在。
- 数据库：关系代数本质是集合运算 + 谓词逻辑。
- 编译与形式化方法：逻辑、自动机、归纳证明支撑语法分析与程序验证。
- 密码学：数论（模运算、素数）是公钥密码的基础。

## 优点与局限

- 优点：为离散对象提供严格的语言与证明工具，是算法正确性与复杂度分析的根基；训练抽象建模与逻辑推理能力。
- 局限：入门面广而分散，各子领域（逻辑 / 图 / 组合 / 代数）方法各异；从纯理论到工程落地需要经验衔接；对连续问题（如数值优化）需借助其他数学分支。

## 常见误区

- 认为「SQL JOIN 就是集合的交集」——`INNER JOIN` 是按连接条件匹配后**生成新元组**，比单纯的交集更一般，只有在特定条件下才近似交集（原文档表述过强，已修正）。
- 忽略归纳法的**基础步骤**：只证归纳步骤会得出荒谬结论（如「所有马同色」的经典谬误）。
- 把「离散」误解为「简单」：离散数学同样有深刻难题（如 P vs NP、图着色）。
