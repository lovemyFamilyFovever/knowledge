# 离散数学基础

## 为什么学离散数学？

**一句话定义：** 离散数学是研究"离散"（不连续）结构的数学，是计算机科学的数学基础。

**通俗类比：** 如果微积分研究的是"平滑的曲线"，离散数学研究的是"一级一级的台阶"——计算机处理的本来就是离散的数据（0和1）。

### 集合论

**集合**：一组确定的对象的全体
```
A = {1, 2, 3}, B = {2, 3, 4}
A ∪ B = {1, 2, 3, 4}    (并集)
A ∩ B = {2, 3}           (交集)
A - B = {1}              (差集)
```

**在编程中的应用：**
- SQL的JOIN操作就是集合的交集
- UNION对应并集
- WHERE条件就是集合的筛选

### 图论基础

**图** = 顶点(V) + 边(E)

| 概念 | 说明 | 应用 |
|------|------|------|
| 有向图 | 边有方向 | 依赖关系、状态机 |
| 无向图 | 边无方向 | 社交网络 |
| 权重图 | 边有权值 | 最短路径 |
| 树 | 无环连通图 | 文件系统、DOM树 |
| 二分图 | 顶点分两组 | 匹配问题 |

**经典算法：**
- Dijkstra：最短路径
- DFS/BFS：图的遍历
- 拓扑排序：任务依赖顺序

### 命题逻辑

- **命题**：可以判断真假的陈述
- **蕴含**：P→Q（如果P则Q）
- **等价**：P↔Q（P当且仅当Q）
- 编程中的if-else就是命题逻辑的应用

### 递归与归纳

**数学归纳法：**
1. 证明基础情况成立（n=1）
2. 假设n=k成立，证明n=k+1也成立
3. 结论：对所有n成立

**对应编程中的递归：**
```python
def factorial(n):
    if n == 1: return 1      # 基础情况
    return n * factorial(n-1) # 归纳步骤
```
