# 离散数学基础


> 📌 **导航**：本文是 **离散数学基础** 词条，属于 cs-basics 术语集。相关枢纽：[[P 与 NP]]、[[信息论基础]]、[[图灵机]]、[[布尔逻辑与逻辑门]]、[[形式语言与文法]]。

## 定义

**一句话定义：** 离散数学是研究离散（可数、不连续）结构的数学分支，涵盖集合论、数理逻辑、图论、组合计数、数论与代数结构等，是计算机科学的数学基础。

**通俗类比：** 如果微积分研究"平滑连续的曲线"，离散数学研究"一级一级的台阶"——计算机处理的本就是离散的 0/1、有限的集合与确定的步骤，所以它的数学工具也是离散的。

> 多义说明：本文是入门总览，只覆盖与编程最相关的几块（集合、逻辑、图、递归 / 归纳、组合），不展开代数结构、数论等完整体系。

## 为什么需要它

算法正确性、复杂度、数据结构、数据库关系代数、程序验证、密码学，背后都是离散结构。掌握集合、逻辑、图、归纳与计数，等于给编程装上严格的数学语言：能把"对不对、有多少步、能不能归约"讲清楚、证出来。

## 核心机制

### 集合论

集合是一组确定对象的全体，有并 A ∪ B、交 A ∩ B、差 A − B、基数 |A|、子集 ⊆。编程映射：数据库 UNION / INTERSECT / EXCEPT 对应并 / 交 / 差，WHERE 是选择（筛选），语言内置 Set（去重、成员判定）即集合的直接实现。

### 数理逻辑

命题是可判真假的陈述句；联结词 ¬ ∧ ∨ → ↔；蕴含 P→Q 仅当"P 真而 Q 假"时为假（详见 [[布尔逻辑与逻辑门]]）。if 条件、布尔表达式、短路求值是命题逻辑的应用；含 ∀ ∃ 量词的谓词逻辑进一步支撑数据库查询与形式化验证。

### 图论

图 G = (V, E)。经典算法：Dijkstra 单源最短路径、DFS / BFS 遍历、拓扑排序（任务依赖顺序）、Kruskal / Prim 最小生成树。

| 概念 | 说明 | 应用 |
|------|------|------|
| 有向图 | 边有方向 | 依赖关系、状态转移 |
| 无向图 | 边无方向 | 社交网络 |
| 带权图 | 边有权值 | 最短路径、最小生成树 |
| 树 | 无环连通图 | 文件系统、DOM、目录 |

### 递归与数学归纳法

数学归纳法 = 基础步骤（证 n=初值成立）+ 归纳步骤（设 n=k 成立、证 n=k+1）⇒ 对所有 n 成立。它正对应递归程序：基础情况=递归出口、归纳假设=递归调用，可用来证明递归正确性（如阶乘的 0!=1 是基础、n·(n−1)! 是归纳步骤）。

### 组合计数

排列 P(n,k) = n!/(n−k)!、组合 C(n,k) = n!/(k!(n−k)!)；用于分析算法解空间大小（如穷举 O(n!)、O(2ⁿ)）。

## 具体示例

判断递归求和函数是否正确就用归纳法：基础 sum([])=0 成立；假设前 k 项正确，则"前 k 项和 + 第 k+1 项"也正确——归纳步骤即递归调用。又：一条 `A JOIN B ON a.id=b.id` 是"按条件匹配后生成新元组"，并不等同集合交集。

## 何时用与何时不用

- **用：** 数据结构与算法（图 / 树 / 集合 / 递归）、数据库（关系代数 = 集合运算 + 谓词逻辑）、编译与形式化验证、密码学（数论 / 模运算）。
- **注意：** 入门面广而散、子领域方法各异；从纯理论到工程落地需经验衔接；连续问题（数值优化）要另用其他数学分支。

## 优劣与代价

✅ 为离散对象提供严格语言与证明工具，是算法正确性与复杂度分析的根基，训练抽象建模与逻辑推理。
⚠️ 面广分散、子领域方法各异；从理论到实践有落差；不直接覆盖连续问题。

## 常见误区

- SQL 的 INNER JOIN 就是集合的交集。
- 归纳法只要证明归纳步骤就够了、基础步骤可以省。
- "离散"意味着问题都简单。

## 面试速答

> 🎯 离散数学 = 计算机的数学基础：集合（并交差，映射 SQL / 集合类型）、数理逻辑（联结词、蕴含、∀∃，映射 if / 查询）、图（Dijkstra / 拓扑排序 / 最小生成树）、递归 ↔ 数学归纳法（证递归正确）、组合计数（解空间大小）；是算法正确性与复杂度的语言。
