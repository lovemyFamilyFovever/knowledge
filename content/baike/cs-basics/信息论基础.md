# 信息论基础


> 📌 **导航**：本文是 **信息论基础** 词条，属于 cs-basics 术语集。相关枢纽：[[P 与 NP]]、[[信息论基础]]、[[图灵机]]、[[布尔逻辑与逻辑门]]、[[形式语言与文法]]。

## 信息论

**一句话定义：** 信息论是用数学方法**量化信息**、并研究信息传输与压缩之极限的理论，由 **Claude Shannon 于 1948 年**在论文《A Mathematical Theory of Communication》中创立。

**通俗类比：** 信息论回答「一条消息到底包含多少『意外』」——越出乎意料的消息，信息量越大。「太阳明天升起」几乎不含信息，「明天六月下雪」信息量就大。

### 信息熵（Entropy）

**定义**：衡量随机变量**不确定性**的度量，也等于其「平均最短编码长度」的下界。

```
H(X) = −Σ p(x) · log₂ p(x)      单位：比特(bit)
```
- 公平硬币（正反各 50%）：H = 1 bit（最不确定）；
- 必出一面的硬币：H = 0（无不确定性）；
- 熵越大 → 越不确定、信息量越大、越难压缩。

### 信源编码（数据压缩）

**无损压缩**（可完全还原）：
- 霍夫曼编码（Huffman, 1952）：高频符号用短码、低频用长码（属前缀码）；
- LZ77 / LZ78（Ziv–Lempel, 1977 / 1978）：用「引用之前出现过的串」替代重复内容；ZIP、PNG 使用的 DEFLATE = LZ77 + 霍夫曼编码；
- 香农信源编码定理：无损压缩的平均码长**下界就是熵**。

**有损压缩**（不可完全还原，换取更高压缩率）：
- JPEG：DCT 变换后丢弃人眼不敏感的高频分量；
- MP3 / AAC：基于心理声学模型丢弃人耳听不到的成分。

### 信道编码与信道容量

**香农–哈特利定理（Shannon–Hartley）：**
```
C = B · log₂(1 + S/N)      单位：bit/s
- C：信道容量的理论上限
- B：带宽(Hz)
- S/N：信噪比（线性功率比，非 dB）
```
**意义**：任何有噪声信道的传输速率都存在上限 C；只要速率 < C，就存在某种**纠错码**使差错率任意低；一旦超过 C 则必然出错。这奠定了现代纠错码（如 Reed–Solomon、LDPC、Turbo 码）的理论基础。

### 延伸度量

- **联合熵 / 条件熵**：多变量的不确定性、以及已知某变量后剩余的不确定性；
- **互信息 I(X;Y)**：知道 Y 后 X 不确定性的减少量；
- **交叉熵 / KL 散度**：机器学习中常用的损失函数与分布差异度量（如分类任务的交叉熵损失）。

## 应用场景

| 概念 | 应用 |
|------|------|
| 霍夫曼 / 算术编码 | ZIP、PNG、JPEG、视频编码 |
| 纠错码 | 二维码、CD/DVD、5G 与深空通信、内存 ECC |
| 熵 | 密码强度评估、随机数质量、密钥熵 |
| 信息增益 | 决策树（ID3 / C4.5）的分裂特征选择 |
| 交叉熵 / KL 散度 | 机器学习损失函数、语言模型评估 |

## 优点与局限

- 优点：给出信息量、压缩极限、传输极限的**严格数学刻画**，与具体实现无关，指导了压缩与通信数十年的发展。
- 局限：经典（香农）信息论关注**语法层**的比特传输，不度量信息的**语义与价值**；有损压缩的质量还需结合人类感知模型（心理声学 / 视觉）来判断。

## 常见误区

- 把**信息熵**与**热力学熵**完全等同：二者概念相通（都度量无序 / 不确定性）、公式形似，但适用对象与单位不同，不能简单划等号。
- 认为「比特(bit)」只是存储单位：它首先是**信息量**单位（消除一个二元不确定性 = 1 bit），其次才用作数据量度量。
- 以为压缩率可以无限提高：无损压缩受**熵**限制，有损压缩受**可接受失真**限制。
