# 信息论基础


> 📌 **导航**：本文是 **信息论基础** 词条，属于 cs-basics 术语集。相关枢纽：[[P 与 NP]]、[[信息论基础]]、[[图灵机]]、[[布尔逻辑与逻辑门]]、[[形式语言与文法]]。

## 定义

**一句话定义：** 信息论是用数学方法量化信息、并研究信息传输与压缩之极限的理论，由 Claude Shannon 于 1948 年在论文《A Mathematical Theory of Communication》中创立。

**通俗类比：** 信息论回答"一条消息到底包含多少『意外』"——越出乎意料的消息信息量越大："太阳明天升起"几乎不含信息，"明天六月下雪"信息量就大。

## 为什么需要它

通信与存储都有物理极限：压缩能压到多小、信道每秒最多能可靠传多少比特，凭直觉无从回答。信息论把"信息"量化为比特，给出压缩下限与信道容量上限这类硬边界，让编码与通信设计有理论可循。

## 核心机制

### 信息熵

熵衡量随机变量的不确定性，也等于其"平均最短编码长度"的下界：

```
H(X) = −Σ p(x) · log₂ p(x)   单位：比特(bit)
```

公平硬币（正反各 50%）H = 1 bit（最不确定），必出一面的硬币 H = 0；熵越大越不确定、越难压缩。

### 信源编码（数据压缩）

无损（可还原）：霍夫曼编码（Huffman, 1952，高频符号用短码、属前缀码）、LZ77 / LZ78（Ziv–Lempel，引用已出现的串），ZIP/PNG 的 DEFLATE = LZ77 + 霍夫曼；香农信源编码定理指出无损平均码长下界即熵。有损（换更高压缩率）：JPEG 经 DCT 丢弃人眼不敏感的高频，MP3 / AAC 依心理声学丢弃人耳听不到的成分。

### 信道编码与信道容量

香农–哈特利定理给出有噪信道的速率上限：

```
C = B · log₂(1 + S/N)   单位 bit/s（B 带宽 Hz，S/N 线性功率比）
```

只要传输速率 < C，就存在某种纠错码使差错率任意低；一旦超过 C 必然出错——这奠定了 Reed–Solomon、LDPC、Turbo 码等现代纠错码的理论基础。

### 延伸度量

联合熵 / 条件熵（多变量的不确定性及已知某变量后剩余的不确定性）、互信息 I(X;Y)（知 Y 后 X 不确定性的减少量）、交叉熵 / KL 散度（机器学习常用损失与分布差异度量）。

应用场景速览：

| 概念 | 应用 |
|------|------|
| 霍夫曼 / 算术编码 | ZIP、PNG、JPEG、视频编码 |
| 纠错码 | 二维码、CD/DVD、5G 与深空通信、内存 ECC |
| 熵 | 密码强度评估、随机数质量、密钥熵 |
| 信息增益 | 决策树（ID3 / C4.5）分裂特征选择 |
| 交叉熵 / KL 散度 | 机器学习损失函数、语言模型评估 |

## 具体示例

英文文本冗余度高（有些字符概率远高于其他、又充满重复子串），DEFLATE 能把它压到远小于原始字节；而真正随机的密文熵接近满，无损压缩几乎压不动——正印证"平均码长下界是熵"。5G 用 LDPC、深空与 CD 用 Reed–Solomon 纠错，都是在向香农极限逼近。

## 何时用与何时不用

- **用：** 设计压缩格式（ZIP / PNG / JPEG）、纠错码（二维码、ECC、5G / 深空）、密码熵评估、决策树信息增益、ML 的交叉熵损失。
- **注意：** 香农信息论只度量语法层的比特传输，不涉语义与价值；有损压缩"好不好"仍要靠人类感知模型判，不能只看比特数。

## 优劣与代价

✅ 给出信息量、压缩极限、传输极限的严格数学刻画，与具体实现无关，指导压缩与通信数十年。
⚠️ 关注语法层、不度量信息的语义与价值；有损压缩质量需结合感知模型判断。

## 与相关概念的区别

vs 热力学熵：信息熵与热力学熵概念相通（都度量无序 / 不确定性）、公式形似，但适用对象与单位不同，不能简单划等号；vs [[数制与编码]]：那是比特如何表示数据，信息论研究信息的量与传输 / 压缩极限。

## 常见误区

- 信息熵和热力学熵是同一个东西。
- 数据的压缩率可以无限提高。
- 比特只是一个存储单位。

## 面试速答

> 🎯 信息论（Shannon 1948）用比特量化信息：熵 H=−Σp·log₂p 度量不确定性，也是无损压缩的码长下限；信源编码（霍夫曼/LZ）近熵压缩、有损（JPEG/MP3）换感知失真；信道由香农–哈特利 C=B·log₂(1+S/N) 定上限，低于它就存在纠错码（RS/LDPC/Turbo）可靠传输。
