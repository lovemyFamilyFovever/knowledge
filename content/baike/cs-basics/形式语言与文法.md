# 形式语言与文法


> 📌 **导航**：本文是 **形式语言与文法** 词条，属于 cs-basics 术语集。相关枢纽：[[P 与 NP]]、[[信息论基础]]、[[图灵机]]、[[布尔逻辑与逻辑门]]、[[形式语言与文法]]。

## 定义

**一句话定义：** 形式语言是由某个字母表上、按精确规则定义的字符串集合;形式文法是一套生成这些字符串的产生式规则。二者共同刻画语言的语法结构,并与自动机模型一一对应,是编译原理与计算理论的基石。

**通俗类比：** 像一套严格的"造句规则"——给定词汇(字母表)和语法条文(产生式),就能判定一个句子(字符串)是否合乎语法、以及如何一步步造出所有合法句子;不合规则的句子一律不承认。

> 多义说明:乔姆斯基(Chomsky)文法层级把文法/语言分为 0~3 型,各自对应不同的自动机;本文按该层级展开。

## 原理与机制

- **文法四要素 G = (N, Σ, P, S):** 非终结符 N、终结符 Σ、产生式 P、开始符 S。
- **乔姆斯基层级(限制递增、能力递减):**
  - 3 型 正则文法 ↔ 有限状态机(正则语言)
  - 2 型 上下文无关文法(CFG)↔ 下推自动机(程序设计语言语法多用)
  - 1 型 上下文有关文法 ↔ 线性有界自动机
  - 0 型 无限制文法 ↔ 图灵机(递归可枚举语言)
- **派生与语法分析:** 最左/最右派生、解析树;LL / LR 分析法基于 CFG。

## 关键组成

| 组成 | 说明 |
|------|------|
| 字母表 Σ | 符号的有限集合 |
| 终结符 / 非终结符 | 基本符号 / 可再展开的符号 |
| 产生式 P | 生成规则 |
| 开始符 S | 派生起点 |
| 乔姆斯基层级 | 0~3 型及对应自动机 |

## 应用场景

- 编译器/解释器的词法与语法分析
- 编程语言设计
- 正则表达式、协议与格式定义
- 自然语言处理的形式化基础

## 优点与局限

- 优点:为语言语法提供精确的数学刻画、与自动机一一对应、支撑解析工具生成。
- 局限:形式语言只刻画"语法"不含"语义";高层语言(如上下文有关)分析代价高;自然语言并不完全符合 CFG。

## 常见误区

- 形式语言 ≠ 自然语言:前者由精确规则定义。
- 文法层级越高(0 型)能力越强,但也越难分析。
- 正则语言是上下文无关语言的子集。
- CFG 无法表达所有语言(如 aⁿbⁿcⁿ 需上下文有关文法)。
