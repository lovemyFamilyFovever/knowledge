# 图灵机

## 定义

**一句话定义：** 图灵机(Turing Machine)是 Alan Turing 于 1936 年提出的抽象计算模型,由一条无限长纸带、一个可读写并左右移动的读写头、一个有限状态控制器和一张转移规则表构成,用以形式化定义"什么是可计算的"。

**通俗类比：** 一个只认规则的机械抄写员:看当前格子的符号 + 自己所处的"心情(状态)",就照手册在该格写个符号、左移或右移一格、再换个心情;如此一步步重复,凡是能算的问题都能这样算出来。

> 多义说明:图灵机是**数学/理论模型**,并非真实机器;有确定型、非确定型、多带等变体,本文以标准确定型单带图灵机为主。

## 原理与机制

形式化定义为七元组 (Q, Σ, Γ, δ, q₀, q_accept, q_reject):

- 机器从初始状态 q₀、读写头置于纸带起点开始。
- 每步依据转移函数 δ(当前状态, 当前带符号) → (新状态, 写入符号, 移动方向 L/R)。
- 进入 q_accept 则接受输入,进入 q_reject 则拒绝,否则可能无限运行(不停机)。

**丘奇–图灵论题(Church–Turing Thesis):** 任何"有效可计算"的函数都能由图灵机计算。由此可证明**停机问题不可判定**——不存在通用算法判断任意图灵机对任意输入是否停机。

## 关键组成

| 部件 | 含义 |
|------|------|
| 纸带(Tape) | 无限长、分格,每格存一个符号(Γ) |
| 读写头(Head) | 读取/写入当前格,并可左移或右移 |
| 状态集(Q) | 有限个内部状态 |
| 转移函数(δ) | 规则表:状态+符号 → 新状态+写符号+移动 |
| 初始/接受/拒绝状态 | q₀ / q_accept / q_reject |

## 应用场景

- 可计算性理论(判定问题、可判定/不可判定)
- 计算复杂度理论(P、NP 等复杂度类的定义基础)
- 编程语言、编译器与自动机理论的理论根基
- "图灵完备"作为语言/系统计算能力的衡量标准

## 优点与局限

- 优点:结构极简却具通用性,奠定了可计算性的严格定义;通用图灵机是现代计算机的理论蓝本。
- 局限:高度抽象、不刻画效率(效率由复杂度理论另议);无限纸带在现实中不存在;不直接对应物理实现细节。

## 常见误区

- 把图灵机等同于真实计算机:它是理想化模型,忽略内存有限、时序等现实约束。
- "图灵完备"指某系统(语言/规则)在计算能力上等价于图灵机,并非指某台具体机器。
- 非确定型图灵机是理论工具(用于定义 NP),并非现实中可直接建造的机器。
