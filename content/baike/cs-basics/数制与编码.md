# 数制与编码

## 进制系统

**一句话定义：** 进制是用多少个数字符号来表示数值的方法。

**通俗类比：** 进制就像数数的"循环规则"——十进制逢10进1，二进制逢2进1。

### 常见进制

| 进制 | 基数 | 符号 | 用途 |
|------|------|------|------|
| 二进制 | 2 | 0,1 | 计算机底层 |
| 八进制 | 8 | 0-7 | Linux权限 |
| 十进制 | 10 | 0-9 | 人类日常 |
| 十六进制 | 16 | 0-9,A-F | 颜色、内存地址 |

### 进制转换

**十进制→二进制：除2取余**
```
13 ÷ 2 = 6 余 1
 6 ÷ 2 = 3 余 0
 3 ÷ 2 = 1 余 1
 1 ÷ 2 = 0 余 1
结果：1101（从下往上读）
```

**二进制→十六进制：每4位一组**
```
1101 0101 = D5
```

### 原码、反码、补码

计算机用补码表示负数：
- **原码**：最高位是符号位（0正1负），其余是数值
- **反码**：正数不变，负数符号位不变，其余取反
- **补码**：正数不变，负数=反码+1

```
+5 的补码：0000 0101
-5 的补码：1111 1011
```

好处：加减法统一处理，不需要单独处理减法。

## 字符编码

| 编码 | 字节数 | 说明 |
|------|--------|------|
| ASCII | 1 | 128个字符，英文 |
| GB2312/GBK | 2 | 中文编码 |
| Unicode | 2-4 | 统一所有语言字符 |
| UTF-8 | 1-4 | Unicode的可变长度实现，最常用 |

**UTF-8规则：**
- 英文字母 = 1字节
- 拉丁/希腊/阿拉伯文 = 2字节
- 中文/日文 = 3字节
- 罕见字符 = 4字节
