# 计算理论


> 📌 **导航**：本文是 **计算理论** 词条，属于 cs-basics 术语集。相关枢纽：[[P 与 NP]]、[[信息论基础]]、[[图灵机]]、[[布尔逻辑与逻辑门]]、[[形式语言与文法]]。

## 定义

**一句话定义：** 计算理论（Theory of Computation）用严格的数学模型研究"什么问题能被计算解决""用什么抽象机器计算"以及"解决它需要多少资源（时间 / 空间）"，是可计算性、复杂度与自动机理论的总称。

**通俗类比：** 像在给"可解的谜题"画地图：有些根本没有通用解法（不可判定，如停机问题），有些有解却要跑到天荒地老（不可行，如指数级），还有一大批"验证答案很快、找到答案却很难"的谜题（NP）。

> 多义说明：本文指计算机科学中的理论分支（自动机 / 可计算性 / 复杂度），而非某一种具体算法或工程实践。

## 为什么需要它

写算法前应先知道：这问题到底能不能算（可判定性）、算不算得起（复杂度）。计算理论给出与具体机器无关的严格边界——告诉你停机问题没有通用解、NP-完全问题大概率要放弃精确最优解，从而决定该求最优、用近似还是转启发式。

## 核心机制

### 三大分支

| 分支 | 核心问题 | 关键概念 |
|------|----------|----------|
| 自动机与形式语言 | 用什么抽象机器识别 / 生成语言 | 有限 / 下推 / 图灵机、乔姆斯基谱系 |
| 可计算性理论 | 什么能被算法解决 | 可判定、不可判定、归约、停机问题 |
| 计算复杂度理论 | 解决要花多少资源 | 时间 / 空间、P、NP、NP 完全 |

计算模型：图灵机是可计算性的标准模型（见 [[图灵机]]）、有限状态机识别正则语言（见 [[有限状态机]]）、乔姆斯基谱系把 0~3 型文法对应到由强到弱的机器（见 [[形式语言与文法]]）。

### 可计算性：能算与不能算

可判定指存在算法对任意输入都能在有限步内给出"是 / 否"并停机；不可判定则不存在这样的算法，经典即停机问题（Turing 1936），另有 Busy Beaver、Post 对应问题。丘奇–图灵论题断言"凡有效可计算都能由图灵机计算"，它是论题而非定理。

### 复杂度与 P vs NP

可计算性与复杂度是两条不同的轴：前者问"能不能算"、后者问"算得起吗"。可判定问题内部按多项式时间归约分层：P ⊆ NP ⊆ PSPACE ⊆ EXPTIME。P 是多项式可解（排序、最短路径、AKS 素性判定）；NP 是给定答案可多项式验证（SAT、子集和、TSP 判定版）；NPC = NP ∩ NP-hard；NP-hard 是"难度下界"、未必属于 NP。P = NP? 是克雷数学研究所 2000 年公布的千禧年七大难题之一（悬赏百万），其理论基石是 Cook–Levin 定理（Cook 1971、Levin 1973 独立证明 SAT 是 NP 完全的），学界主流相信 P ≠ NP 但至今未证；时间层次定理则给出 P ⊊ EXPTIME。

## 具体示例

时间复杂度速查（渐进上界，忽略常数与低阶项）：

| 复杂度 | 示例 |
|--------|------|
| O(1) | 哈希表查找（平均） |
| O(log n) | 二分查找 |
| O(n) | 遍历数组 |
| O(n log n) | 归并排序、快速排序（平均） |
| O(n²) | 冒泡 / 插入排序 |
| O(2ⁿ) | 子集穷举 |
| O(n!) | 全排列穷举、TSP 暴力解 |

## 何时用与何时不用

- **用：** 编译器与语言设计（词法 / 语法分析建立在自动机与形式语言上）、算法选型（值不值得求精确解、要不要近似 / 启发式）、密码学（依赖大整数分解、离散对数的计算困难性）、程序分析（静态分析多不可判定、只能保守近似）。
- **注意：** 模型高度理想化（无限纸带、忽略常数与实际硬件），不直接刻画工程效率；P vs NP 等核心问题悬而未决。

## 优劣与代价

✅ 为"计算 / 算法 / 难度"提供严格、与机器无关的数学定义，揭示计算的根本边界（不可判定）与现实瓶颈（复杂度）。
⚠️ 理想化、不刻画工程实际效率；核心问题未解；"理论难解"与"实际难解"并不总一致。

## 与相关概念的区别

vs [[图灵机]]：图灵机是本文用以界定可计算性的核心模型；vs [[P 与 NP]]：那是"复杂度"分支里最著名的开放问题，本文是含三大分支的总览；vs [[形式语言与文法]]：乔姆斯基谱系是"自动机与形式语言"这一支的内容。

## 常见误区

- NP 是"非多项式（Non-Polynomial）"的意思。
- NP-hard 就是不可判定问题。
- 不可判定就等于这个问题实际上完全算不了。

## 面试速答

> 🎯 计算理论 = 三大分支：自动机与形式语言（乔姆斯基谱系）、可计算性（可判定 vs 不可判定，停机问题不可判定）、复杂度（P⊆NP⊆PSPACE⊆EXPTIME、NP-完全 / NP-难）。可判定性与复杂度是两条轴；P=NP? 是千禧难题、主流猜 ≠；NP 的 N 是非确定型、NP-hard 未必属 NP 也 ≠ 不可判定。
