# 正则表达式

## 定义

**一句话定义：** 正则表达式(Regular Expression,regex / regexp)是用一串符号来描述、匹配字符串中符合某种模式的一类文本的形式化表达;它能简洁地表示"一个字符串集合",广泛用于文本查找、校验、提取与替换。

**通俗类比：** 像用一张"填空模板 + 通配规则"去套字符串——比如"3 个数字-4 个数字"能匹配某种电话号码格式,`*`/`+`/`?` 表示重复次数,`[abc]` 表示任选其一;凡是符合模板的字符串都被"网"住。

> 多义说明:正则表达式(记法)对应理论上的**正则语言**(由正则文法/有限状态自动机识别);工程实现有基本/扩展/Perl 兼容(PCRE)等不同方言。本文兼顾理论与工程。

## 原理与机制

- **语法要素:** 字符类(`[abc]`、`\d`、`\w`)、量词(`*`、`+`、`?`、`{n,m}`)、锚点(`^`、`$`)、分组与捕获(`( )`、`(?: )`)、或(`|`)、反向引用。
- **理论基础:** 正则表达式 ⟺ 正则语言 ⟺ 有限状态自动机(Kleene 定理,见 [[有限状态机]]);可用 NFA/DFA 实现匹配。
- **匹配引擎:** 回溯型(如 PCRE,支持反向引用但可能"灾难性回溯")与自动机型(如 RE2,线性时间但功能受限)。
- **能力边界:** 纯正则无法匹配需要计数的语言(如任意层数的括号配对,那属于上下文无关语言)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 字符类 | 匹配单个字符的集合 |
| 量词 | 控制重复次数 |
| 锚点 | 定位开头/结尾/边界 |
| 分组 / 捕获 | 分组与提取子串 |
| 引擎 | 回溯型 vs 自动机型 |

## 应用场景

- 文本搜索与替换
- 输入校验(邮箱、手机号)
- 日志解析、爬虫抽取
- 词法分析(见 [[词法分析]])、命令行工具(grep / sed / awk)

## 优点与局限

- 优点:表达紧凑、强大灵活,几乎所有语言与工具都支持。
- 局限:复杂正则可读性差;回溯引擎可能出现灾难性回溯(ReDoS);纯正则能力有限(非正则语言需其他手段);方言差异导致移植问题。

## 常见误区

- 正则不是万能的:无法匹配任意嵌套结构(如平衡括号)。
- 贪婪(`.*`)与懒惰(`.*?`)量词结果不同。
- 不同语言/工具的正则方言有差异(PCRE / POSIX / RE2)。
- 复杂正则应谨慎使用(可读性与 ReDoS 风险)。
