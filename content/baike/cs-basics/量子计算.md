# 量子计算


> 📌 **导航**：本文是 **量子计算** 词条，属于 cs-basics 术语集。相关枢纽：[[P 与 NP]]、[[信息论基础]]、[[图灵机]]、[[布尔逻辑与逻辑门]]、[[形式语言与文法]]。

## 定义

**一句话定义：** 量子计算(Quantum Computing)是一种利用量子力学原理(叠加、纠缠、干涉)进行计算的新型计算范式;它以量子比特(qubit)为基本单位,能在某些特定问题上实现相对经典计算机的显著加速,但目前仍处于早期发展阶段。

**通俗类比：** 经典比特像一枚落地后非正即反的硬币(0 或 1);量子比特像一枚正在旋转的硬币,在"落地"前同时具有正反两种可能性(叠加),测量时才坍缩为确定值;多枚旋转硬币还能彼此"心灵感应"(纠缠),协同表达海量状态。

> 多义说明:量子计算是一种计算范式/模型,不同于经典冯·诺依曼计算;量子计算机是其物理实现。本文讨论计算范式与原理。

## 原理与机制

- **量子比特(qubit):** 可处于 |0⟩、|1⟩ 的叠加态(α|0⟩ + β|1⟩),测量时按概率坍缩。
- **纠缠(entanglement):** 多个 qubit 关联,状态不可分离,提供强关联的并行表达能力。
- **量子门与线路:** 用酉变换(量子门)操作 qubit,构成量子线路;计算结束后测量。
- **加速来源:** 叠加 + 纠缠 + 干涉,使某些算法(Shor 大数分解、Grover 无序搜索)优于经典。
- **挑战:** 退相干(decoherence)、量子纠错、比特数与保真度、极低温运行环境。

## 关键组成

| 组成 | 说明 |
|------|------|
| 量子比特(qubit) | 基本信息单位 |
| 叠加 | 同时表示多种状态 |
| 纠缠 | qubit 间的强关联 |
| 量子门 / 线路 | 操作与编排计算 |
| 测量坍缩 | 读取结果 |
| 量子纠错 | 对抗噪声与退相干 |

## 应用场景

- 大数分解(影响公钥密码,Shor 算法)
- 无序搜索(Grover 算法)
- 量子化学与材料模拟
- 组合优化、机器学习探索
- 推动后量子密码(post-quantum cryptography)研究

## 优点与局限

- 优点:在特定问题上具备潜在的指数级加速;模拟量子系统天然高效。
- 局限:通用性有限(并非所有问题都加速);技术极不成熟(噪声、退相干、纠错开销大);qubit 规模与稳定性受限;编程模型与经典差异大。

## 常见误区

- 量子计算机不是"更快的经典计算机":它只对特定问题有优势,并非万能。
- 叠加不等于"同时算出所有答案并直接读出":测量会坍缩,需巧妙设计算法来提取结果。
- 量子计算不能解决不可计算问题(仍在图灵可计算范围内)。
- 当前多处于 NISQ(含噪声中等规模量子)阶段。
