# 量子计算


> 📌 **导航**：本文是 **量子计算** 词条，属于 cs-basics 术语集。相关枢纽：[[P 与 NP]]、[[信息论基础]]、[[图灵机]]、[[布尔逻辑与逻辑门]]、[[形式语言与文法]]。

## 定义

**一句话定义：** 量子计算（Quantum Computing）是一种利用量子力学原理（叠加、纠缠、干涉）进行计算的新型计算范式；它以量子比特（qubit）为基本单位，能在某些特定问题上实现相对经典计算机的显著加速，但目前仍处于早期发展阶段。

**通俗类比：** 经典比特像一枚落地后非正即反的硬币（0 或 1）；量子比特像一枚正在旋转的硬币，"落地"前同时具有正反两种可能（叠加）、测量时才坍缩为确定值；多枚旋转硬币还能彼此"心灵感应"（纠缠），协同表达海量状态。

> 多义说明：量子计算是一种计算范式 / 模型，不同于经典冯·诺依曼计算；量子计算机是其物理实现。本文讨论计算范式与原理。

## 为什么需要它

某些问题在经典计算机上没有高效算法——大整数分解（威胁 RSA）、无结构化搜索、量子体系模拟。量子力学的叠加与纠缠提供了不同的算力组织方式，让这些问题出现潜在加速，尤其模拟量子系统本身天然契合。

## 核心机制

- **量子比特 qubit：** 可处于 |0⟩、|1⟩ 的叠加态（α|0⟩ + β|1⟩），测量时按概率坍缩。
- **纠缠：** 多个 qubit 状态不可分离，提供强关联的并行表达能力。
- **量子门与线路：** 用酉变换（量子门）操作 qubit、构成量子线路，计算结束后测量。
- **加速来源：** 叠加 + 纠缠 + 干涉，使 Shor 大数分解、Grover 无序搜索等算法优于经典。
- **挑战：** 退相干（decoherence）、量子纠错、比特数与保真度、极低温运行环境。

## 具体示例

Shor 算法（1994）能在多项式时间分解大整数，直接动摇 RSA 等公钥密码——正推动了后量子密码（如基于格的密码）研究；Grover（1996）给无序搜索平方级加速，但非指数。当前多处于 NISQ（含噪声中等规模量子）阶段，纠错开销大、规模有限。

## 何时用与何时不用

- **用：** 大数分解、无结构化搜索（Grover）、量子化学与材料模拟、组合优化 / 机器学习探索，以及由此推动的后量子密码研究。
- **不用：** 绝大多数日常计算用经典机即可（量子通用加速有限）；也别指望它解决不可计算问题（量子机仍不越出图灵可计算范围）。

## 优劣与代价

✅ 在特定问题上具备潜在的指数 / 多项式级加速；模拟量子系统天然高效。
⚠️ 通用性有限（并非所有问题都加速）；技术极不成熟（噪声、退相干、纠错开销大）；qubit 规模与稳定性受限；编程模型与经典差异大。

## 与相关概念的区别

vs [[图灵机]]：量子计算机仍属图灵可计算（判不了停机问题等不可判定问题），只是某些问题的资源效率不同；vs [[P 与 NP]]：量子加速不改变 NPC 的本质（BQP 大致含于 PSPACE，普遍相信不能高效解 NP-完全）；vs 经典比特：qubit 能叠加 / 纠缠、测量才定值。

## 常见误区

- 量子计算机就是一台更快的通用经典计算机。
- 叠加意味着量子机同时算出所有答案、可直接读出。
- 量子计算能解决不可计算的问题。

## 面试速答

> 🎯 量子计算 = 用叠加 / 纠缠 / 干涉、以 qubit 为单位的计算范式：酉门组成量子线路、测量按概率坍缩；对大数分解（Shor 1994，威胁 RSA、催生后量子密码）、无序搜索（Grover 1996 平方级）有加速，但对多数问题无通用加速、仍不越出图灵可计算、当前处 NISQ 阶段受噪声 / 纠错制约。
