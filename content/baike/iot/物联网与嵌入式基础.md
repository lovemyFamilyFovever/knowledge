# 物联网与嵌入式基础


> 📌 **导航**：本文是 **物联网与嵌入式基础** 词条，属于 iot 术语集。相关枢纽：[[MQTT]]、[[物联网与嵌入式基础]]。

## IoT（Internet of Things）

**一句话定义：** 物联网是让日常物品通过网络互联互通、交换数据的技术体系。

**通俗类比：** 物联网就像给所有物品装上了"眼睛"和"嘴巴"——它们能感知环境（传感器）并能互相"说话"（网络通信）。

### IoT架构

```
感知层（传感器/执行器）
    ↓
网络层（Wi-Fi/蓝牙/LoRa/NB-IoT）
    ↓
平台层（设备管理、数据处理）
    ↓
应用层（智能家居/工业监控/智慧城市）
```

### Arduino示例

```cpp
// LED闪烁
void setup() {
    pinMode(LED_BUILTIN, OUTPUT);
    Serial.begin(9600);
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH);
    Serial.println("LED ON");
    delay(1000);
    digitalWrite(LED_BUILTIN, LOW);
    Serial.println("LED OFF");
    delay(1000);
}
```

### ESP32物联网示例

```cpp
#include <WiFi.h>
#include <HTTPClient.h>

const char* ssid = "your_wifi";
const char* password = "your_password";

void setup() {
    Serial.begin(115200);
    WiFi.begin(ssid, password);
    while (WiFi.status() != WL_CONNECTED) delay(500);
    Serial.println("Connected!");
}

void loop() {
    int sensorValue = analogRead(34);
    // 上传数据到云平台
    HTTPClient http;
    http.begin("http://api.example.com/data");
    http.POST("{"temp":" + String(sensorValue) + "}");
    http.end();
    delay(60000); // 每分钟上报
}
```

### IoT通信协议

| 协议 | 特点 | 适用场景 |
|------|------|----------|
| MQTT | 轻量发布/订阅 | 传感器数据上报 |
| CoAP | 类HTTP超轻量 | 受限设备 |
| HTTP/REST | 通用 | 云端API交互 |
| WebSocket | 全双工 | 实时控制 |
| LoRaWAN | 远距离低功耗 | 农业、城市 |
| Zigbee |  mesh网络 | 智能家居 |
| BLE | 低功耗蓝牙 | 可穿戴设备 |

### 边缘计算

**定义：** 在数据源头附近进行处理，而不是全部发送到云端。

**优势：**
- 降低延迟（不用传到云端再回来）
- 减少带宽（只传结果）
- 提高隐私（数据不出本地）

**示例：** 工厂摄像头在本地用AI检测缺陷，只把缺陷报告上传云端。
