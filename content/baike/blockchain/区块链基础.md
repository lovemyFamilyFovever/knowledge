# 区块链基础


> 📌 **导航**：本文是 **区块链基础** 词条，属于 blockchain 术语集。相关枢纽：[[区块链基础]]、[[智能合约]]。

## 区块链技术

**一句话定义：** 区块链是一个去中心化的、不可篡改的分布式账本。

**通俗类比：** 区块链就像一个所有人共享的记账本——每个人手里都有一份完整的副本，任何新记录都要经过大多数人确认才能写入，一旦写入就无法修改。

### 核心概念

**区块（Block）**
- 包含一批交易记录
- 包含前一个区块的哈希值（形成链）
- 包含时间戳和nonce

**链式结构**
```
区块0(创世) → 区块1 → 区块2 → 区块3
   ↓            ↓         ↓
 hash0       hash1     hash2
 (每个区块包含前一个的hash，改动一个就会断裂)
```

### 共识机制

| 机制 | 原理 | 代表 | 优缺点 |
|------|------|------|--------|
| PoW(工作量证明) | 谁先解出难题谁记账 | Bitcoin | 安全但耗电 |
| PoS(权益证明) | 质押越多越有机会记账 | Ethereum 2.0 | 节能但可能中心化 |
| DPoS(委托权益) | 投票选出记账人 | EOS | 高效但不够去中心 |
| PBFT | 多数投票一致 | Hyperledger | 快速但节点数有限 |

### 智能合约

```solidity
// Solidity智能合约示例
pragma solidity ^0.8.0;

contract SimpleStorage {
    uint256 private value;
    
    function set(uint256 _value) public {
        value = _value;
    }
    
    function get() public view returns (uint256) {
        return value;
    }
}
```

智能合约是部署在区块链上的程序，满足条件自动执行，无需中间人。

### 应用场景

| 领域 | 应用 |
|------|------|
| 金融 | 去中心化交易(DEX)、借贷、稳定币 |
| 供应链 | 溯源、透明化 |
| 数字身份 | 去中心化身份(DID) |
| NFT | 数字资产确权 |
| DAO | 去中心化自治组织 |
| DeFi | 去中心化金融 |

### 风险与挑战

- **51%攻击**：控制超过一半算力可篡改
- **智能合约漏洞**：代码bug可能导致资金损失
- **监管不确定性**：各国政策不同
- **能源消耗**：PoW机制耗电巨大
- **扩展性**：TPS有限（比特币7笔/秒）
