# 分布式拒绝服务攻击


> 📌 **导航**：本文是 **分布式拒绝服务攻击** 词条，属于 security 术语集。相关枢纽：[[公钥基础设施]]、[[密码学基础篇]]、[[零信任安全架构]]。

## 定义

**一句话定义：** 分布式拒绝服务攻击(Distributed Denial of Service, DDoS)是攻击者控制大量分布式机器(僵尸网络),同时向目标系统发送海量请求或流量,耗尽其带宽、连接或计算资源,使正常用户无法获得服务。

**通俗类比：** 像有人雇了成千上万人同时涌到一家小店门口堵路(甚至假意下单),真正的顾客挤不进去、店员也忙不过来,店铺瘫痪——攻击者靠"人多"压垮目标,而不是攻破门锁。

> 多义说明:DDoS 是 DoS(拒绝服务)的分布式版本;按攻击层次分为流量型(带宽)、协议型(连接/资源)、应用型(L7)。本文综述。

## 原理与机制

- **攻击链:** 攻击者 → 控制端(C&C)→ 僵尸网络(botnet,被植入木马的大量主机/IoT 设备)→ 同时攻击目标。
- **常见类型:**
  - 流量型(带宽耗尽):UDP Flood、ICMP Flood、反射放大攻击(NTP / DNS / memcached 反射放大)。
  - 协议型(资源耗尽):SYN Flood(半连接耗尽)、连接数耗尽。
  - 应用型(L7):HTTP Flood、慢速攻击(Slowloris)、CC 攻击。

## 关键组成

| 组成 | 作用 |
|------|------|
| 僵尸网络(botnet) | 发起攻击的大量受控机器 |
| 控制端(C&C) | 下发攻击指令 |
| 攻击类型 | 流量型 / 协议型 / 应用型 |
| 反射放大 | 借第三方服务放大流量 |
| 目标资源 | 带宽 / 连接 / CPU 被耗尽 |

## 应用场景

（此处指防护手段）CDN 与流量清洗(scrubbing)、黑洞路由、限流与验证码、SYN Cookie、Anycast 分散流量、WAF、弹性扩容、与上游运营商联动。

## 优点与局限

- (对攻击者)"优点":低成本、高破坏、难溯源(源伪造 + 分布式)。
- 防御局限:大带宽型难以单点扛住(需上游清洗);L7 攻击酷似正常流量、难以辨识;防护有成本;IoT 僵尸网络规模庞大。

## 常见误区

- DDoS ≠ 入侵/数据窃取:它旨在破坏"可用性",而非机密性。
- 单纯加大服务器配置未必够(带宽型需上游清洗)。
- DDoS 与 CC 攻击不同:CC 是 L7 应用层攻击的一种。
- 溯源困难,因源 IP 常被伪造或经由僵尸网络。
