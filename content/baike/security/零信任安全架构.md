# 零信任安全架构


> 📌 **导航**：本文是 **零信任安全架构** 词条，属于 security 术语集。相关枢纽：[[公钥基础设施]]、[[密码学基础篇]]、[[零信任安全架构]]。

## 核心原则

**永不信任，始终验证。**

| 传统安全 | 零信任 |
|----------|--------|
| 信任内网 | 所有请求都要验证 |
| 网络边界防护 | 微分段 |
| 一次认证 | 持续验证 |
| VPN接入 | 随时随地安全接入 |

## 核心组件

```
用户 -> 身份认证(MFA) -> 设备信任评估 -> 策略引擎 -> 最小权限访问
```

## BeyondCorp

Google的零信任实践：
- 所有应用暴露在公网
- 通过访问代理控制
- 基于设备状态+用户身份+上下文动态授权

## SASE（安全访问服务边缘）

```
SD-WAN + 安全功能(CASB/SWG/FWaaS/ZTNA) -> 云原生统一服务
```
