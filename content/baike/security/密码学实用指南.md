# 密码学实用指南


> 📌 **导航**：本文是 **密码学实用指南** 词条，属于 security 术语集。相关枢纽：[[公钥基础设施]]、[[密码学基础篇]]、[[零信任安全架构]]。

## 对称加密

| 算法 | 密钥长度 | 特点 | 适用 |
|------|----------|------|------|
| AES-128/256 | 128/256bit | 最常用 | 数据加密 |
| ChaCha20 | 256bit | 移动端友好 | TLS |

## 非对称加密

| 算法 | 用途 | 特点 |
|------|------|------|
| RSA | 加密/签名 | 经典 |
| ECC | 加密/签名 | 密钥短，性能好 |
| Ed25519 | 签名 | 快速 |

## TLS握手

```
Client -> ClientHello(支持的加密套件) -> Server
Client <- ServerHello(选定的套件) + 证书 <- Server
Client -> 验证证书 -> 生成预主密钥 -> 用服务端公钥加密 -> Server
双方用预主密钥生成会话密钥 -> 对称加密通信
```

## 国密算法

| 算法 | 类型 | 用途 |
|------|------|------|
| SM2 | 非对称 | 签名/加密 |
| SM3 | 哈希 | 摘要 |
| SM4 | 对称 | 加密 |
