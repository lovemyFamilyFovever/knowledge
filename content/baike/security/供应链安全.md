# 供应链安全

## 软件供应链

```
源代码 -> 依赖包 -> 构建 -> 制品 -> 部署
```

每个环节都可能被攻击。

## SBOM（软件物料清单）

列出软件中所有组件和依赖：
- SPDX格式
- CycloneDX格式

## 依赖安全

```bash
# Python
pip audit  # 检查已知漏洞

# npm
npm audit

# Snyk
snyk test
```

## CI/CD安全

- 代码签名
- 镜像签名(Cosign/Notary)
- 最小权限CI Token
- 密钥管理(Vault/AWS Secrets Manager)
- 构建隔离(不可信runner)
