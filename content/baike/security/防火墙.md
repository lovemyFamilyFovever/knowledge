# 防火墙

## 定义

**一句话定义：** 防火墙(Firewall)是位于网络边界、依据预设安全规则对进出的数据包进行检查与过滤(允许或拒绝)的安全设备或软件,用于在可信内网与不可信外网之间建立一道访问控制屏障。

**通俗类比：** 像小区的门卫 + 门禁——按名单(规则)决定谁能进、谁能出、走哪个门(端口),把可疑或不速之客挡在外面,只放行符合规定的通行。

> 多义说明:有网络防火墙(边界)与主机防火墙(单机,如 iptables / Windows Defender Firewall);按技术分包过滤、状态检测、应用层(下一代 NGFW)。本文综述。

## 原理与机制

- **包过滤(packet filtering):** 按 IP、端口、协议等头部信息过滤(无状态)。
- **状态检测(stateful inspection):** 跟踪连接状态(如 TCP 握手),只放行属于已建立连接的包。
- **应用层 / NGFW:** 深入应用协议(如 HTTP),可做深度包检测(DPI),集成 IDS/IPS、URL 过滤。
- **规则与策略:** 通常"默认拒绝(deny by default)"或"默认允许";按源/目的 IP、端口、协议、方向匹配。
- **部署形态:** 边界防火墙、DMZ(隔离区)、主机防火墙。

## 关键组成

| 组成 | 作用 |
|------|------|
| 规则集(ACL) | 定义允许/拒绝条件 |
| 包过滤 | 基于头部信息过滤 |
| 状态检测表 | 跟踪连接状态 |
| 应用层检测(DPI) | 识别应用协议内容 |
| DMZ | 隔离对外服务的区域 |

## 应用场景

- 企业/家庭网络的边界防护
- 主机防护
- DMZ 隔离对外服务
- 限制出入站流量、配合 VPN

## 优点与局限

- 优点:边界访问控制的第一道防线,可按策略精细过滤,隔离内外网。
- 局限:防不了内部威胁与已放行通道内的攻击;对加密流量的深层检测受限;不能替代 IDS/防病毒/应用安全;配置复杂易出错。

## 常见误区

- 防火墙 ≠ 万能:不防内部攻击、不深查已加密内容、不防社会工程。
- 防火墙 ≠ IDS/IPS:前者做访问过滤,后者做入侵检测/阻断。
- NAT ≠ 防火墙:NAT 主要做地址转换(隐藏内网只是副作用)。
- "默认允许"策略风险高,通常应"默认拒绝"。
