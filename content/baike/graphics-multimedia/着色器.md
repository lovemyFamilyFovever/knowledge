# 着色器

## 定义

**一句话定义：** 着色器(Shader)是运行在 GPU 上的小程序,用于计算渲染过程中每个顶点、片元(像素)等的属性(位置、颜色、光照、纹理),是现代可编程渲染管线的核心执行单元。

**通俗类比：** 像流水线上每个工位专属的"操作说明书"——顶点着色器负责给每个骨架点定位,片元着色器负责给每个像素上色;GPU 有成千上万个小核心,同时照着说明书处理海量顶点和像素。

> 多义说明:shader 也可泛指 GPU 通用计算程序(如计算着色器);本文以**图形渲染着色器**为主。

## 原理与机制

着色器在管线各阶段被调用,以大规模并行(SIMD/SIMT)方式执行:

- **顶点着色器(Vertex Shader):** 逐顶点做坐标变换、法线变换、逐顶点光照。
- **片元/像素着色器(Fragment/Pixel Shader):** 逐片元计算最终颜色、采样纹理、光照着色。
- **可选阶段:** 几何着色器、曲面细分着色器、计算着色器(通用计算)。

着色器用专门语言编写(GLSL / HLSL / MSL),常被编译为中间表示(如 SPIR-V)再由驱动/GPU 执行。数据通过 attribute(顶点输入)、uniform(全局常量)、varying(阶段间插值传递)等交换。

## 关键组成

| 类型 | 处理粒度 | 典型职责 |
|------|----------|----------|
| 顶点着色器 | 每个顶点 | 变换到裁剪空间、传参 |
| 片元着色器 | 每个片元 | 计算像素颜色、纹理采样 |
| 几何着色器 | 每个图元 | 增删图元 |
| 计算着色器 | 工作组/线程 | 通用 GPU 计算(非固定管线) |

## 应用场景

- 游戏与实时三维的光照、材质、阴影、后处理特效
- 影视特效与离线渲染
- GPU 通用计算(GPGPU)、图像/视频处理
- 深度学习与科学计算的并行内核

## 优点与局限

- 优点:高度并行、可编程灵活,能实现固定管线做不到的效果;充分利用 GPU 算力。
- 局限:编写与调试较难(缺断点、需可视化调试);跨平台着色语言不统一(GLSL/HLSL/MSL);性能调优复杂,易受分支/带宽影响。

## 常见误区

- 以为 shader 只处理"颜色":它也处理位置、法线、几何等。
- 把"着色器"与"材质(Material)"混为一谈:材质通常是"着色器 + 一组参数/贴图"的组合。
- 认为 shader 跑在 CPU:它在 GPU 上执行。
