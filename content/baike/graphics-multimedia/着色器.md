# 着色器


> 📌 **导航**：本文是 **着色器** 词条，属于 graphics-multimedia 术语集。相关枢纽：[[光栅化]]、[[光线追踪]]、[[全局光照]]、[[图像压缩]]、[[图形渲染管线]]。

## 定义

**一句话定义：** 着色器（Shader）是运行在 GPU 上的小型并行程序，用于在渲染管线各阶段计算顶点位置、片元颜色等属性，是现代可编程渲染的核心执行单元。

**通俗类比：** 像流水线上每个工位专属的操作说明书——顶点着色器负责给每个骨架点定位，片元着色器负责给每个像素上色；GPU 有成千上万个核心同时照着说明书并行处理。

## 为什么需要它

固定功能管线（GPU 硬件写死光照模型）无法实现自定义效果（水面反射、卡通渲染、粒子）。着色器把"怎么算"的控制权交给开发者，让 GPU 大规模并行算力可编程。

## 核心机制

- **顶点着色器（Vertex Shader）**：逐顶点做 MVP 变换、传法线/UV 给下阶段。
- **片元着色器（Fragment Shader）**：逐片元采样纹理+光照计算+输出颜色。
- **可选阶段**：几何着色器（增删图元）、曲面细分着色器（细分网格）、计算着色器（通用并行计算不绑定管线）。

语言：GLSL（OpenGL）、HLSL（D3D）、MSL（Metal），编译为 SPIR-V 等中间表示由驱动执行。数据通过 attribute/uniform/varying 或 buffer 交换。

## 具体示例

Blinn-Phong 光照片元着色器：输入法线（normal map 采样）+ 视线方向 → 计算漫反射 dot(N,L) + 镜面高光 dot(N,H)^shininess → 乘以光源颜色和强度 → 输出最终像素颜色。每个像素独立执行此逻辑，GPU 并行完成百万次计算。

## 何时用与何时不用

- **用**：任何需要自定义渲染效果的场景——游戏材质、后处理特效、GPU 计算。
- **不用**：固定输出即可的极简 2D 场景（CPU 绘制足够）。

## 优劣与代价

✅ 灵活度极高，固定管线做不到的效果都能实现。
✅ 充分利用 GPU SIMD/SIMT 并行吞吐。
⚠️ 调试困难（无断点，需 RenderDoc 等工具辅助）。
⚠️ 分支/纹理采样不连续会导致 warp divergence 性能下降。

## 与相关概念的区别

- **vs 材质（Material）**：材质通常是"一个着色器 + 一组参数（贴图、颜色常数）"的组合实例；着色器是程序，材质是配置。
- **vs 渲染管线**：管线定义数据流动顺序，着色器是每个可编程阶段中执行的具体计算代码。

## 常见误区

- 着色器只处理"颜色"：也处理位置、法线、几何。
- 着色器跑在 CPU：它在 GPU 并行执行。
- 材质和着色器是同一个东西。
