# 颜色空间


> 📌 **导航**：本文是 **颜色空间** 词条，属于 graphics-multimedia 术语集。相关枢纽：[[光栅化]]、[[光线追踪]]、[[全局光照]]、[[图像压缩]]、[[图形渲染管线]]。

## 定义

**一句话定义：** 颜色空间(Color Space,又称色彩空间)是用一组数值(通常 3~4 个分量)来系统化表示颜色的数学模型,并配合色域(gamut)界定可表示的颜色范围;不同颜色空间面向不同设备与用途(如显示、印刷、图像处理)。

**通俗类比：** 像用不同"配方体系"描述同一种颜色——RGB 像"红绿蓝三盏灯各调多亮"来混色(适合屏幕发光),CMYK 像"青品黄黑四种油墨各用多少"(适合印刷反射),HSV 像"什么色相、多鲜艳、多亮"(更贴近人的直觉描述)。

> 多义说明:常见颜色空间有 RGB、CMYK、HSV/HSL、YCbCr、CIE Lab/XYZ 等;还需区分颜色空间(模型)与色域(范围,如 sRGB / Adobe RGB)。本文综述。

## 原理与机制

- **RGB:** 加色模型(红绿蓝叠加),用于屏幕等发光设备。
- **CMYK:** 减色模型(青品黄黑油墨吸收),用于印刷。
- **YCbCr / YUV:** 分离亮度(Y)与色度(Cb/Cr),用于图像/视频压缩(利于色度下采样)。
- **HSV / HSL:** 色相/饱和度/明度,更贴近人类直觉,常用于调色。
- **CIE XYZ / Lab:** 设备无关、基于人眼感知,Lab 感知均匀性好(用于色差计算)。
- **色域与色彩管理:** sRGB、Display P3、Adobe RGB 等定义范围;ICC profile 做设备间色彩转换。

## 关键组成

| 组成 | 说明 |
|------|------|
| 分量(如 R/G/B) | 表示颜色的数值维度 |
| 加色 / 减色模型 | RGB(发光)/ CMYK(印刷) |
| 色域(gamut) | 可表示的颜色范围 |
| 设备相关 / 无关 | 是否依赖具体设备 |
| 色彩管理(ICC) | 设备间色彩转换 |

## 应用场景

- 显示器、相机、打印的色彩表示
- 图像与视频编码(YCbCr)
- 图形渲染、调色与设计
- 跨设备色彩一致性

## 优点与局限

- 优点:为不同设备与用途提供合适的颜色表示,支撑色彩管理与压缩。
- 局限:不同空间转换有精度损失;色域不匹配会导致颜色偏差;设备差异需校准;感知均匀性因空间而异。

## 常见误区

- 颜色空间 ≠ 色域:前者是模型/坐标体系,后者是可表示的范围。
- RGB 用于发光屏幕、CMYK 用于反射印刷,二者不能直接互换而不转换。
- YCbCr 利于压缩(亮度与色度分离)。
- sRGB ≠ Adobe RGB ≠ Display P3:色域不同,混用会偏色。
