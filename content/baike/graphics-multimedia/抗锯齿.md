# 抗锯齿

## 定义

**一句话定义：** 抗锯齿(Anti-aliasing, AA)是图形渲染中用于减轻或消除"锯齿"(阶梯状边缘走样)的技术,通过对边缘像素做平滑或颜色混合处理,使斜线与曲线看起来更平滑,提升图像视觉质量。

**通俗类比：** 像用马赛克拼一条斜线时,边缘会呈阶梯状(锯齿);抗锯齿就是给边缘的马赛克涂上介于两色之间的过渡色,远看就显得平滑了——用"轻微模糊边缘"换取"视觉顺滑"。

> 多义说明:锯齿(aliasing)是采样不足导致的走样现象;抗锯齿有多种技术(SSAA、MSAA、FXAA、TAA 等)。本文综述。

## 原理与机制

- **成因:** 光栅化用离散像素采样连续几何,采样率不足导致高频信息走样(锯齿)。
- **超采样(SSAA):** 以更高分辨率渲染再降采样,质量高但开销大。
- **多重采样(MSAA):** 仅对几何边缘做多次采样,兼顾质量与性能(硬件支持)。
- **后处理(FXAA):** 在成像后检测并模糊边缘,开销小但可能使画面整体略糊。
- **时域(TAA):** 利用多帧历史累积采样并配合抖动(jitter),平滑但可能产生拖影(ghosting)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 走样成因 | 采样不足 |
| SSAA / MSAA | 超采样 / 多重采样 |
| FXAA / TAA | 后处理 / 时域抗锯齿 |
| 抖动(jitter) | 时域采样的子像素偏移 |
| 质量-性能权衡 | 各技术的取舍 |

## 应用场景

- 游戏与实时三维渲染
- 3D 图形与 CAD
- 字体渲染(灰度/次像素抗锯齿)
- 图像缩放与重采样

## 优点与局限

- 优点:显著提升视觉平滑度与真实感。
- 局限:各类 AA 在质量/性能/副作用间权衡(SSAA 昂贵、FXAA 发糊、TAA 拖影);增加渲染开销与显存;对透明、细线等场景处理复杂。

## 常见误区

- 抗锯齿会牺牲一点清晰度与性能,并非"免费"。
- 不同 AA 技术原理与副作用差异很大(SSAA/MSAA/FXAA/TAA)。
- 提高分辨率能减轻锯齿,但不等同于抗锯齿。
- 字体渲染同样使用抗锯齿(灰度或次像素)。
