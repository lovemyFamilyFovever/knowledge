# 纹理映射


> 📌 **导航**：本文是 **纹理映射** 词条，属于 graphics-multimedia 术语集。相关枢纽：[[光栅化]]、[[光线追踪]]、[[全局光照]]、[[图像压缩]]、[[图形渲染管线]]。

## 定义

**一句话定义：** 纹理映射(Texture Mapping)是把二维图像(纹理)贴附到三维模型表面的技术:通过为顶点指定纹理坐标(uv),在光栅化时对表面像素采样纹理,从而在不增加几何复杂度的前提下呈现丰富的表面细节。

**通俗类比：** 像给素坯陶碗贴花纹贴纸——碗的形状(几何)不变,只是把一张图案(纹理)按位置"贴"到表面,朴素的碗立刻显得有精细花纹。

> 多义说明:广义纹理映射还包括法线贴图、置换贴图、环境贴图等(用纹理承载颜色以外的信息);本文以基础颜色纹理为主并提及扩展。

## 原理与机制

- **UV 坐标:** 每个顶点关联 (u, v)(通常范围 [0,1])纹理坐标,建立模型表面与纹理图的对应关系。
- **采样与过滤:** 光栅化时按插值后的 uv 对纹理采样(texel → pixel),用最近邻/双线性/三线性过滤平滑结果。
- **Mipmap:** 预先生成多级缩小纹理,按物体远近选用合适层级,减少走样(摩尔纹)并提升缓存命中。
- **寻址与压缩:** 寻址模式(repeat / clamp / mirror);纹理压缩格式(如 BC/ETC)节省显存与带宽。

## 关键组成

| 组成 | 作用 |
|------|------|
| 纹理图像 | 提供表面细节的位图 |
| UV 坐标 | 模型表面到纹理的映射 |
| 采样器(sampler) | 执行纹理采样与过滤 |
| 过滤方式 | 最近邻/双线性/三线性 |
| Mipmap | 多级纹理,抗走样与提速 |

## 应用场景

- 游戏与三维渲染的表面细节与材质表现
- 地形、建筑、角色的贴图
- UI 与图标绘制
- 结合法线/粗糙度贴图的 PBR(基于物理的渲染)

## 优点与局限

- 优点:以极小的几何代价获得高细节,节省面数与内存,是实时图形的基础手段。
- 局限:拉伸表面易模糊或走样(需过滤与 mipmap);纹理占用显存与带宽;UV 展开繁琐;不改变真实几何轮廓。

## 常见误区

- 纹理映射 ≠ 增加几何细节:模型轮廓仍是低模,需置换贴图/曲面细分才真正改变形状。
- Mipmap 不是"低清 bug",而是抗走样与性能优化的正常机制。
- 纹理坐标 v 轴方向在不同图形 API 中可能不一致,需注意翻转问题。
