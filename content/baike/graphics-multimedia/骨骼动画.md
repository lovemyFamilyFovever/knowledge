# 骨骼动画


> 📌 **导航**：本文是 **骨骼动画** 词条，属于 graphics-multimedia 术语集。相关枢纽：[[光栅化]]、[[光线追踪]]、[[全局光照]]、[[图像压缩]]、[[图形渲染管线]]。

## 定义

**一句话定义：** 骨骼动画(Skeletal Animation)是三维角色动画的主流技术:用一套层级化的"骨骼"(关节)驱动角色网格(mesh)变形,通过给骨骼设关键帧并插值,带动蒙皮(网格顶点绑定到骨骼)运动,从而以较小的数据量实现自然的角色动作。

**通俗类比：** 像提线木偶——木偶本身(网格/皮肤)不含关节,靠上面的提线和骨架(骨骼)牵引;你只需操纵几根线(骨骼关节),整块布(蒙皮)就跟着做出动作,不必逐点去捏。

> 多义说明:骨骼动画(骨架 + 蒙皮)区别于顶点动画(逐顶点关键帧)与变形动画(morph / blend shape)。本文讨论骨骼蒙皮动画。

## 原理与机制

- **骨骼层级:** 关节组成树状骨架(如肩 → 肘 → 腕),父关节带动子关节。
- **蒙皮(skinning):** 每个网格顶点绑定到一个或多个骨骼(带权重),骨骼变换时按权重带动顶点(线性混合蒙皮 LBS)。
- **动画:** 对骨骼的旋转/位移设关键帧,播放时插值(如四元数插值)得到每帧骨骼姿态,再驱动蒙皮。
- **动画混合 / 状态机:** 多段动画混合(blend)、过渡,由动画状态机管理(走 → 跑 → 跳)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 骨骼层级(骨架) | 关节的树状结构 |
| 蒙皮权重 | 顶点绑定到骨骼的权重 |
| 关键帧与插值 | 定义与生成中间姿态 |
| 动画状态机 | 管理动画切换与过渡 |
| 动画混合 | 多段动作融合 |

## 应用场景

- 游戏角色动画
- 影视 CG、虚拟人 / 数字人
- VR 角色、3D 交互

## 优点与局限

- 优点:数据量小(存骨骼而非逐顶点)、动作自然可复用、易混合与重定向。
- 局限:蒙皮权重制作繁琐;LBS 有"糖果纸"等失真;复杂肌肉/布料需额外技术;动画重定向需处理比例差异。

## 常见误区

- 骨骼动画 ≠ 顶点动画:前者骨架驱动蒙皮,后者逐顶点。
- 蒙皮顶点可绑定多个骨骼(带权重),并非一对一。
- 关键帧之间靠插值生成(不是逐帧存储)。
- 动画状态机管理切换,避免动作生硬跳变。
