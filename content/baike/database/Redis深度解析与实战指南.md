# Redis深度解析与实战指南

> 📌 **导航**：本文是 **Redis深度解析与实战指南** 枢纽页。原书级长文已按主题拆为四篇子词条——[[Redis 数据结构与底层实现]]、[[Redis 持久化与内存管理]]、[[Redis 高可用架构（主从·哨兵·集群）]]、[[Redis 分布式锁]]；速览见 [[Redis深入]]，NoSQL 全景见 [[NoSQL 数据库术语]]。

## 定义

**一句话定义：** 本文是 Redis 深度的知识地图枢纽，把原先一部长篇拆成数据结构与编码、持久化与内存、高可用、分布式锁四个主题并各指其条，本页只做全景导航与阶段串联、不复述子条细节。

**通俗类比：** 像一本被拆成四册的 Redis 大书，本页是封底总目录：告诉你"内存怎么存、掉电怎么救、机器挂了怎么切、跨机怎么互斥"各去哪一册看，而不把每册再抄一遍。

## 为什么需要它

Redis 的问题会散在编码、持久化、复制分片、锁四类里，单看一篇难成体系。先立"数据怎么存→怎么不丢→怎么高可用→怎么用得对"这条主线，再跳进各子条，能避免"会 SET/GET 却不懂大 key、丢锁、主从切换丢数据"这类系统性踩坑。

## 核心机制

本页是索引型枢纽，四主题各归其条（实质内容只在子条承载一次，此处不重复）：

| 阶段 | 覆盖要点 | 归口 |
|------|----------|------|
| 数据结构 | 九类型 + SDS/listpack/quicklist/skiplist/intset/hashtable 编码切换 | [[Redis 数据结构与底层实现]] |
| 持久化与内存 | RDB/AOF/混合、8 种淘汰、碎片整理 | [[Redis 持久化与内存管理]] |
| 高可用 | 主从复制、Sentinel 自动切换、Cluster 哈希槽分片 | [[Redis 高可用架构（主从·哨兵·集群）]] |
| 并发正确性 | SET NX 锁、Lua 释放、看门狗、Redlock | [[Redis 分布式锁]] |

主线：先懂编码选对类型 → 配持久化与淘汰稳住内存 → 用复制/哨兵/集群保可用与扩展 → 需要跨机互斥再上分布式锁。原理速查见 [[Redis深入]]。

## 具体示例

排查一个线上"缓存偶发变慢又恢复"：先用 [[Redis 数据结构与底层实现]] 查有无大 key/大 Hash 触发重排；[[Redis 持久化与内存管理]] 看是否 BGSAVE fork 毛刺或淘汰在内存满时抖动；[[Redis 高可用架构（主从·哨兵·集群）]] 看主从断裂是否走全量同步；若涉及抢锁超时再查 [[Redis 分布式锁]] 的 TTL/续期。按这条链定位，不必通读四册。

## 常见误区

- 会用 SET/GET/HSET 就算懂 Redis 生产实践了。
- 上了主从 + 持久化，Redis 就绝不会丢数据也绝不会偶发变慢。
- Redis 分布式锁能保证业务绝对不并发重入，不必再做幂等。
