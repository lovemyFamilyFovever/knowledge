# 搜索引擎技术详解

> 📌 **导航**：本文是 **搜索引擎技术详解**——倒排索引、分词与相关性（BM25）、分布式搜索（分片 / 副本）、聚合与分析。同类深入见 [[ElasticSearch搜索]]；NoSQL 全景见 [[NoSQL 数据库术语]]；数据库范式与建模见 [[数据库设计术语]]。

## 1. 搜索引擎架构概述

搜索引擎是一个复杂的系统，通常由四个主要模块组成：**爬虫**、**索引**、**查询**和**排序**。这四个模块协同工作，完成从互联网获取内容、存储组织、响应查询并返回相关结果的全过程。

### 1.1 系统架构图示

```
用户查询 → 查询解析 → 索引检索 → 排序算法 → 搜索结果
    ↑                                       ↓
    └───────────── 用户反馈 ←──────────────┘

网页数据 → 爬虫抓取 → 内容处理 → 索引构建
    ↑                   ↓
    └───── URL队列 ←───┘
```

### 1.2 各模块详细交互

#### 爬虫模块
- **职责**：自动发现和下载互联网上的网页内容
- **输入**：种子URL列表
- **输出**：原始网页数据（HTML、文档等）
- **关键挑战**：如何高效、合法、稳定地抓取海量网页

#### 索引模块
- **职责**：将原始网页数据转化为可快速检索的数据结构
- **输入**：原始网页数据
- **输出**：倒排索引及其他辅助数据结构
- **关键挑战**：如何设计高效的索引结构，平衡查询速度和存储空间

#### 查询模块
- **职责**：理解用户查询意图，匹配相关文档
- **输入**：用户查询字符串
- **输出**：相关文档列表
- **关键挑战**：如何准确理解多样化的查询表达

#### 排序模块
- **职责**：根据相关性对结果进行排序
- **输入**：查询和候选文档
- **输出**：排序后的结果列表
- **关键挑战**：如何设计公平、准确的排序算法

### 1.3 数据流示例

以用户搜索"机器学习教程"为例：

1. **爬虫**：定期从知名技术网站（如GitHub、Medium）抓取相关文章
2. **索引**：将抓取的文章分词、建立倒排索引
3. **查询**：将"机器学习教程"分词为["机器", "学习", "教程"]
4. **排序**：根据BM25算法计算文档相关性，返回排序结果

## 2. 爬虫设计

### 2.1 爬虫基本架构

```python
class WebCrawler:
    def __init__(self, seed_urls):
        self.url_queue = URLQueue(seed_urls)  # URL队列
        self.downloader = HTMLDownloader()    # 下载器
        self.parser = HTMLParser()           # 解析器
        self.storage = Storage()             # 存储器
        
    def crawl(self):
        while not self.url_queue.is_empty():
            url = self.url_queue.dequeue()
            
            # 1. 检查URL合法性
            if not self.is_valid_url(url):
                continue
                
            # 2. 检查robots.txt
            if not self.can_crawl(url):
                continue
                
            # 3. 检查URL去重
            if self.is_duplicate(url):
                continue
                
            # 4. 下载网页
            html = self.downloader.download(url)
            
            # 5. 解析内容
            content, new_urls = self.parser.parse(html)
            
            # 6. 存储内容
            self.storage.store(url, content)
            
            # 7. 将新URL加入队列
            self.url_queue.enqueue_all(new_urls)
```

### 2.2 URL管理策略

#### 优先级队列设计

```python
import heapq
from datetime import datetime

class PriorityURLQueue:
    def __init__(self):
        self.heap = []
        self.entry_finder = {}
        self.counter = 0
        
    def add_url(self, url, priority=0):
        """添加URL到队列"""
        if url in self.entry_finder:
            return  # 已存在
            
        # 优先级计算因素
        effective_priority = priority
        if '.com' in url:
            effective_priority += 10  # 商业网站优先级更高
        if 'news' in url:
            effective_priority += 5   # 新闻网站优先级高
            
        entry = [effective_priority, self.counter, url]
        self.counter += 1
        heapq.heappush(self.heap, entry)
        self.entry_finder[url] = entry
        
    def get_next_url(self):
        """获取下一个要抓取的URL"""
        while self.heap:
            priority, count, url = heapq.heappop(self.heap)
            del self.entry_finder[url]
            return url
        return None
```

### 2.3 URL去重技术

#### 布隆过滤器实现

```python
import mmh3
from bitarray import bitarray

class BloomFilter:
    def __init__(self, size=1000000, hash_count=7):
        self.size = size
        self.hash_count = hash_count
        self.bit_array = bitarray(size)
        self.bit_array.setall(0)
        
    def add(self, url):
        """添加URL到布隆过滤器"""
        for seed in range(self.hash_count):
            index = mmh3.hash(url, seed) % self.size
            self.bit_array[index] = 1
            
    def __contains__(self, url):
        """检查URL是否可能存在"""
        for seed in range(self.hash_count):
            index = mmh3.hash(url, seed) % self.size
            if self.bit_array[index] == 0:
                return False
        return True  # 可能存在（有误判可能）
    
    def get_false_positive_rate(self):
        """计算误判率"""
        # 公式: (1 - e^(-kn/m))^k
        k = self.hash_count
        n = self.size  # 假设已经存储n个元素
        m = self.size
        return (1 - (2.718 ** (-k * n / m))) ** k
```

#### SimHash用于近似去重

```python
import re
from collections import Counter

class SimHash:
    def __init__(self, hash_size=64):
        self.hash_size = hash_size
        
    def compute(self, text):
        """计算文本的SimHash值"""
        # 1. 分词
        words = self.tokenization(text)
        
        # 2. 计算词频
        word_counts = Counter(words)
        
        # 3. 初始化向量
        v = [0] * self.hash_size
        
        # 4. 对每个词计算hash并加权
        for word, count in word_counts.items():
            # 计算词的hash
            word_hash = self.word_hash(word)
            
            # 加权累加
            for i in range(self.hash_size):
                bitmask = 1 << i
                if word_hash & bitmask:
                    v[i] += count
                else:
                    v[i] -= count
                    
        # 5. 生成最终hash
        fingerprint = 0
        for i in range(self.hash_size):
            if v[i] > 0:
                fingerprint |= (1 << i)
                
        return fingerprint
    
    def word_hash(self, word):
        """计算单词的hash值"""
        # 使用mmh3或自定义hash函数
        return mmh3.hash(word) & ((1 << self.hash_size) - 1)
    
    def tokenization(self, text):
        """简单的分词"""
        return re.findall(r'\w+', text.lower())
    
    def hamming_distance(self, hash1, hash2):
        """计算汉明距离"""
        x = hash1 ^ hash2
        return bin(x).count('1')
    
    def is_near_duplicate(self, hash1, hash2, threshold=3):
        """判断是否近似重复"""
        return self.hamming_distance(hash1, hash2) <= threshold
```

### 2.4 Robots协议处理

```python
import urllib.robotparser
from urllib.parse import urlparse
import re

class RobotsParser:
    def __init__(self):
        self.parsers = {}  # 缓存不同站点的robots.txt解析器
        
    def can_fetch(self, user_agent, url):
        """检查是否允许抓取"""
        parsed_url = urlparse(url)
        domain = parsed_url.netloc
        
        # 获取或创建robots.txt解析器
        if domain not in self.parsers:
            robots_url = f"{parsed_url.scheme}://{domain}/robots.txt"
            parser = urllib.robotparser.RobotFileParser()
            parser.set_url(robots_url)
            try:
                parser.read()
                self.parsers[domain] = parser
            except:
                # 如果无法获取robots.txt，默认允许
                self.parsers[domain] = None
                
        parser = self.parsers.get(domain)
        if parser is None:
            return True
            
        return parser.can_fetch(user_agent, url)
    
    def get_crawl_delay(self, user_agent, domain):
        """获取爬取延迟（秒）"""
        if domain not in self.parsers:
            return 1  # 默认延迟
            
        parser = self.parsers.get(domain)
        if parser is None:
            return 1
            
        # 尝试获取Crawl-delay指令
        try:
            # 注意：Python的robotparser可能不支持所有扩展指令
            # 可能需要自定义解析
            delay = parser.crawl_delay(user_agent)
            return delay if delay else 1
        except:
            return 1
```

```python
import redis
import json
from concurrent.futures import ThreadPoolExecutor

class DistributedCrawler:
    def __init__(self, master_host, worker_id):
        self.redis = redis.Redis(host=master_host, port=6379)
        self.worker_id = worker_id
        self.workers_key = "crawler:workers"
        self.url_queue_key = "crawler:url_queue"
        self.visited_key = "crawler:visited"
        
        # 注册worker
        self.register_worker()
        
    def register_worker(self):
        """注册当前worker到Redis"""
        self.redis.sadd(self.workers_key, self.worker_id)
        
    def get_urls_to_crawl(self, batch_size=10):
        """从分布式队列获取待抓取URL"""
        urls = []
        for _ in range(batch_size):
            url = self.redis.lpop(self.url_queue_key)
            if url:
                urls.append(url.decode())
        return urls
    
    def mark_visited(self, url):
        """标记URL为已访问"""
        self.redis.sadd(self.visited_key, url)
        
    def add_urls(self, urls):
        """添加新URL到分布式队列"""
        for url in urls:
            if not self.redis.sismember(self.visited_key, url):
                self.redis.rpush(self.url_queue_key, url)
                
    def get_stats(self):
        """获取爬虫统计信息"""
        return {
            'queue_size': self.redis.llen(self.url_queue_key),
            'visited_size': self.redis.scard(self.visited_key),
            'active_workers': self.redis.scard(self.workers_key)
        }
```

## 3. 倒排索引

### 3.1 倒排索引基本概念

倒排索引是搜索引擎的核心数据结构，它将文档集合中的每个**词项**（term）映射到包含该词项的**文档列表**（posting list）。

```
正排索引：文档 → 词项列表
文档1 → [词项A, 词项B, 词项C]
文档2 → [词项A, 词项D]

倒排索引：词项 → 文档列表
词项A → [文档1, 文档2]
词项B → [文档1]
词项C → [文档1]
词项D → [文档2]
```

### 3.2 倒排索引的存储结构

```python
class PostingList:
    """倒排列表，包含文档ID和词频信息"""
    def __init__(self):
        self.doc_ids = []      # 文档ID列表
        self.term_freqs = []   # 对应文档中的词频
        self.positions = []    # 词项在文档中的位置（用于短语查询）
        
    def add(self, doc_id, term_freq, positions=None):
        """添加文档到posting list"""
        self.doc_ids.append(doc_id)
        self.term_freqs.append(term_freq)
        if positions:
            self.positions.append(positions)
            
    def get_doc_freq(self):
        """返回包含该词项的文档数（DF）"""
        return len(self.doc_ids)

class InvertedIndex:
    """倒排索引主类"""
    def __init__(self):
        self.index = {}  # term -> PostingList
        self.doc_store = {}  # doc_id -> 文档元信息
        
    def add_document(self, doc_id, terms):
        """
        添加文档到索引
        terms: 文档中的词项列表
        """
        # 统计词频
        term_counts = {}
        for i, term in enumerate(terms):
            if term not in term_counts:
                term_counts[term] = {'freq': 0, 'positions': []}
            term_counts[term]['freq'] += 1
            term_counts[term]['positions'].append(i)
            
        # 更新倒排索引
        for term, info in term_counts.items():
            if term not in self.index:
                self.index[term] = PostingList()
            self.index[term].add(doc_id, info['freq'], info['positions'])
            
        # 存储文档元信息
        self.doc_store[doc_id] = {
            'length': len(terms),
            'unique_terms': len(term_counts)
        }
        
    def get_postings(self, term):
        """获取词项的posting list"""
        return self.index.get(term, PostingList())
    
    def get_document_info(self, doc_id):
        """获取文档信息"""
        return self.doc_store.get(doc_id)
```

### 3.3 跳表优化

跳表（Skip List）用于优化posting list的遍历速度，特别是在进行posting list的合并操作时。

```python
class SkipList:
    """跳表实现，用于优化posting list的遍历"""
    def __init__(self, data, skip_distance=None):
        self.data = data  # 存储的数据（如文档ID列表）
        self.n = len(data)
        self.skip_distance = skip_distance or max(1, int(self.n ** 0.5))
        
        # 构建跳表结构
        self.skip_pointers = []
        self.build_skip_list()
        
    def build_skip_list(self):
        """构建跳表"""
        self.skip_pointers = [None] * self.n
        
        # 每隔skip_distance个元素设置一个跳表指针
        for i in range(0, self.n, self.skip_distance):
            next_skip = min(i + self.skip_distance, self.n)
            self.skip_pointers[i] = next_skip
            
    def search_with_skip(self, target):
        """使用跳表进行搜索"""
        current = 0
        
        while current < self.n:
            # 先尝试跳跃
            if (self.skip_pointers[current] is not None and 
                self.skip_pointers[current] < self.n and 
                self.data[self.skip_pointers[current]] <= target):
                # 跳跃到下一个节点
                current = self.skip_pointers[current]
            else:
                # 跳跃不安全，进行线性搜索
                while (current < self.n and 
                       self.data[current] < target):
                    current += 1
                    
                if current < self.n and self.data[current] == target:
                    return current
                return -1
                
        return -1

class OptimizedPostingList:
    """带跳表优化的posting list"""
    def __init__(self):
        self.doc_ids = []
        self.skip_list = None
        
    def add(self, doc_id):
        self.doc_ids.append(doc_id)
        
    def finalize(self):
        """排序并构建跳表"""
        self.doc_ids.sort()
        self.skip_list = SkipList(self.doc_ids)
        
    def intersect_with_skip(self, other_list):
        """使用跳表优化的posting list交集操作"""
        result = []
        p1, p2 = 0, 0
        
        while p1 < len(self.doc_ids) and p2 < len(other_list.doc_ids):
            if self.doc_ids[p1] == other_list.doc_ids[p2]:
                result.append(self.doc_ids[p1])
                p1 += 1
                p2 += 1
            elif self.doc_ids[p1] < other_list.doc_ids[p2]:
                # 使用跳表快速定位
                next_pos = self.skip_list.search_with_skip(other_list.doc_ids[p2])
                if next_pos != -1:
                    p1 = next_pos
                else:
                    p1 += 1
            else:
                # 对称处理
                p2 += 1
                
        return result
```

### 3.4 压缩存储

```python
import struct
from bitarray import bitarray

class CompressedIndex:
    """压缩存储的倒排索引"""
    def __init__(self):
        self.compressed_index = {}
        
    def compress_posting_list(self, doc_ids):
        """压缩posting list（使用Variable Byte编码）"""
        if not doc_ids:
            return b''
            
        # 排序并计算差值
        sorted_ids = sorted(doc_ids)
        deltas = [sorted_ids[0]]
        for i in range(1, len(sorted_ids)):
            deltas.append(sorted_ids[i] - sorted_ids[i-1])
            
        # Variable Byte编码
        compressed = bytearray()
        for delta in deltas:
            # 每7位一组，最高位表示是否继续
            while delta >= 128:
                compressed.append((delta & 0x7F) | 0x80)
                delta >>= 7
            compressed.append(delta & 0x7F)
            
        return bytes(compressed)
    
    def decompress_posting_list(self, compressed_data):
        """解压posting list"""
        if not compressed_data:
            return []
            
        result = []
        current = 0
        value = 0
        shift = 0
        
        for byte in compressed_data:
            if byte & 0x80:  # 继续读取
                value |= (byte & 0x7F) << shift
                shift += 7
            else:  # 最后一个字节
                value |= (byte & 0x7F) << shift
                result.append(current + value)
                current = current + value
                value = 0
                shift = 0
                
        return result
```

## 4. 分词技术

### 4.1 中文分词概述

中文分词是中文搜索引擎的关键技术，因为中文没有自然的空格分隔。主要方法包括：
1. 基于词典的分词（最大匹配法）
2. 基于统计的分词（HMM、CRF）
3. 深度学习分词（BiLSTM+CRF）

### 4.2 jieba分词器使用

```python
import jieba
import jieba.analyse

class ChineseTokenizer:
    def __init__(self, user_dict_path=None):
        """初始化分词器"""
        if user_dict_path:
            jieba.load_userdict(user_dict_path)
            
    def cut(self, text, mode='accurate'):
        """
        中文分词
        mode: 
            'accurate' - 精确模式
            'full' - 全模式
            'search' - 搜索引擎模式
        """
        if mode == 'accurate':
            return list(jieba.cut(text))
        elif mode == 'full':
            return list(jieba.cut(text, cut_all=True))
        elif mode == 'search':
            return list(jieba.cut_for_search(text))
        else:
            return list(jieba.cut(text))
    
    def extract_keywords(self, text, topK=10, withWeight=False):
        """提取关键词"""
        # TF-IDF方法
        keywords_tfidf = jieba.analyse.extract_tags(
            text, topK=topK, withWeight=withWeight
        )
        
        # TextRank方法
        keywords_textrank = jieba.analyse.textrank(
            text, topK=topK, withWeight=withWeight
        )
        
        return {
            'tfidf': keywords_tfidf,
            'textrank': keywords_textrank
        }
    
    def add_word(self, word, freq=None, tag=None):
        """动态添加词语到词典"""
        jieba.add_word(word, freq, tag)
        
    def suggest_freq(self, segment, tune=False):
        """调节单个词语的词频"""
        jieba.suggest_freq(segment, tune=tune)
```

### 4.3 HanLP分词器使用

```python
import hanlp

class HanLPTokenizer:
    def __init__(self):
        """初始化HanLP"""
        # 加载多任务中文分词模型
        self.tokenizer = hanlp.load(
            hanlp.pretrained.tok.FINE_ELECTRA_SMALL_ZH

        # 加载其他NLP工具
        self.tagger = hanlp.load(
            hanlp.pretrained.pos.CTB9_POS_ELECTRA_SMALL
        )
        
        self.ner = hanlp.load(
            hanlp.pretrained.ner.MSRA_NER_ELECTRA_SMALL_ZH
        )
        
    def tokenize(self, text, tasks=None):
        """
        多任务分词
        tasks: ['tok', 'pos', 'ner'] 或 None（全部任务）
        """
        if tasks is None:
            tasks = ['tok', 'pos', 'ner']
            
        result = {}
        
        # 分词
        if 'tok' in tasks:
            tokens = self.tokenizer(text)
            result['tokens'] = tokens
            
        # 词性标注
        if 'pos' in tasks and 'tokens' in result:
            pos_tags = self.tagger(result['tokens'])

        # 命名实体识别
        if 'ner' in tasks and 'tokens' in result:
            ner_tags = self.ner(result['tokens'])
            result['ner_tags'] = ner_tags
            
        return result
    
    def dependency_parse(self, tokens):

        parser = hanlp.load(
            hanlp.pretrained.dep.CTB9_DEP_ELECTRA_SMALL
```

```python
import re
from collections import defaultdict

class CustomDictionary:
    """自定义词典管理"""
    def __init__(self, dict_paths=None):
        self.user_dict = {}  # 用户词典
        self.stopwords = set()  # 停用词
        self.synonyms = defaultdict(list)  # 同义词词典
        
        if dict_paths:
            self.load_dictionaries(dict_paths)
            
    def load_dictionaries(self, dict_paths):
        """加载多个词典文件"""
        for path in dict_paths:
            if path.endswith('.txt'):
                self.load_user_dict(path)
            elif path.endswith('_stopwords.txt'):
                self.load_stopwords(path)
            elif path.endswith('_synonyms.txt'):
                self.load_synonyms(path)
                
    def load_user_dict(self, dict_path):
        """加载用户词典"""
        with open(dict_path, 'r', encoding='utf-8') as f:
            for line in f:
                word = line.strip()
                if word:
                    # 格式: 词语 词频 词性
                    parts = word.split()
                    word_text = parts[0]
                    freq = int(parts[1]) if len(parts) > 1 else 100
                    pos = parts[2] if len(parts) > 2 else 'n'
                    
                    self.user_dict[word_text] = {
                        'freq': freq,
                        'pos': pos
                    }
                    
    def load_stopwords(self, dict_path):
        """加载停用词"""
        with open(dict_path, 'r', encoding='utf-8') as f:
            for line in f:
                word = line.strip()
                if word:
                    self.stopwords.add(word)
                    
    def load_synonyms(self, dict_path):
        """加载同义词词典"""
        with open(dict_path, 'r', encoding='utf-8') as f:
            for line in f:
                parts = line.strip().split('\t')
                if len(parts) >= 2:
                    key = parts[0]
                    synonyms = parts[1:]
                    self.synonyms[key].extend(synonyms)
                    
    def get_synonyms(self, word):
        """获取同义词"""
        return self.synonyms.get(word, [word])
    
    def is_stopword(self, word):
        """判断是否为停用词"""
        return word in self.stopwords
```

### 5.1 查询解析器设计

```python
import re
from enum import Enum

class QueryType(Enum):
    BOOLEAN = 1
    PHRASE = 2
    WILDCARD = 3
    FUZZY = 4
    FIELD = 5

class QueryParser:
    """查询解析器"""
    def __init__(self, default_operator='AND'):
        self.default_operator = default_operator
        self.field_names = {'title', 'content', 'author', 'date'}
        
    def parse(self, query_string):
        """解析查询字符串"""
        # 1. 预处理
        query_string = self.preprocess(query_string)
        
        # 2. 检测特殊语法
        if '"' in query_string:
            return self.parse_phrase_query(query_string)
        elif '*' in query_string or '?' in query_string:
            return self.parse_wildcard_query(query_string)
        elif '~' in query_string:
            return self.parse_fuzzy_query(query_string)
        elif ':' in query_string:
            return self.parse_field_query(query_string)
        elif 'AND' in query_string or 'OR' in query_string or 'NOT' in query_string:
            return self.parse_boolean_query(query_string)
        else:
            return self.parse_simple_query(query_string)
            
    def preprocess(self, query_string):
        """预处理查询字符串"""
        # 统一空格
        query_string = re.sub(r'\s+', ' ', query_string).strip()
        
        # 处理特殊字符
        query_string = re.sub(r'[^\w\s\-.*?~:"()]', ' ', query_string)
        
        return query_string
    
    def parse_phrase_query(self, query_string):
        """解析短语查询: "machine learning" """
        pattern = r'"([^"]*)"'
        phrases = re.findall(pattern, query_string)
        
        queries = []
        for phrase in phrases:
            terms = phrase.split()
            queries.append({
                'type': QueryType.PHRASE,
                'terms': terms,
                'slop': 0  # 允许的词序偏移
            })
            
        return queries
    
    def parse_wildcard_query(self, query_string):
        """解析通配符查询: mach*ne """
        pattern = r'(\w+[\*?]+\w*)'
        matches = re.findall(pattern, query_string)
        
        queries = []
        for match in matches:
            if '*' in match:
                # 前缀查询: mach*
                if match.endswith('*'):
                    queries.append({
                        'type': QueryType.WILDCARD,
                        'prefix': match[:-1],
                        'suffix': None
                    })
                # 后缀查询: *ning
                elif match.startswith('*'):
                    queries.append({
                        'type': QueryType.WILDCARD,
                        'prefix': None,
                        'suffix': match[1:]
                    })
                # 中间通配符: mach*ne
                else:
                    prefix, suffix = match.split('*', 1)
                    queries.append({
                        'type': QueryType.WILDCARD,
                        'prefix': prefix,
                        'suffix': suffix
                    })
            elif '?' in match:
                # 单字符通配符
                queries.append({
                    'type': QueryType.WILDCARD,
                    'pattern': match.replace('?', '.'),
                    'is_regex': True
                })
                
        return queries
    
    def parse_boolean_query(self, query_string):
        """解析布尔查询: term1 AND term2 OR term3 """
        # 简单的布尔查询解析器
        tokens = query_string.split()
        queries = []
        current_op = self.default_operator
        
        i = 0
        while i < len(tokens):
            token = tokens[i]
            
            if token.upper() in ('AND', 'OR', 'NOT'):
                current_op = token.upper()
                i += 1
                continue
                
            # 处理括号
            if '(' in token or ')' in token:
                # 简化处理，实际需要完整的括号解析
                pass
                
            queries.append({
                'type': QueryType.BOOLEAN,
                'term': token,
                'operator': current_op
            })
            
            # 重置为默认操作符
            current_op = self.default_operator
            i += 1
            
        return queries
```

```python
class QueryExpander:
    """查询扩展器"""
    def __init__(self, synonym_dict=None, word2vec_model=None):
        self.synonym_dict = synonym_dict or {}
        self.word2vec_model = word2vec_model
        
    def expand_with_synonyms(self, query_terms):
        """使用同义词扩展查询"""
        expanded_terms = []
        
        for term in query_terms:
            expanded_terms.append(term)
            
            # 添加同义词
            if term in self.synonym_dict:
                synonyms = self.synonym_dict[term]
                expanded_terms.extend(synonyms)
                
        return expanded_terms
    
    def expand_with_word2vec(self, query_terms, topn=3):
        """使用词向量扩展查询"""
        if not self.word2vec_model:
            return query_terms
            
        expanded_terms = []
        
        for term in query_terms:
            expanded_terms.append(term)
            
            try:
                # 获取相似词
                similar_words = self.word2vec_model.most_similar(
                    term, topn=topn
                )
                for word, score in similar_words:
                    if score > 0.5:  # 相似度阈值
                        expanded_terms.append(word)
            except KeyError:
                # 词不在词汇表中
                pass
                
        return expanded_terms
    
    def rewrite_query(self, query):
        """查询改写"""
        # 1. 纠错
        corrected = self.correct_spelling(query)
        
        # 2. 规范化
        normalized = self.normalize_query(corrected)
        
        # 3. 扩展
        expanded = self.expand_query(normalized)
        
        return expanded
```

## 6. 相关性排序

### 6.1 TF-IDF算法

```python
import math
from collections import Counter

class TFIDFCalculator:
    """TF-IDF计算器"""
    def __init__(self, documents):
        """
        documents: 文档列表，每个文档是词项列表
        """
        self.documents = documents
        self.doc_count = len(documents)
        self.df = {}  # 词项 -> 文档频率
        self.tf = []  # 每个文档的词频统计
        
        self.calculate_statistics()
        
    def calculate_statistics(self):
        """计算文档统计信息"""
        # 计算文档频率
        for doc in self.documents:
            unique_terms = set(doc)
            for term in unique_terms:
                self.df[term] = self.df.get(term, 0) + 1
                
        # 计算词频
        for doc in self.documents:
            term_counts = Counter(doc)
            self.tf.append(term_counts)
            
    def tf(self, term, doc_index):
        """计算词频（TF）"""
        # 词频：词项在文档中出现的次数 / 文档总词数
        term_count = self.tf[doc_index].get(term, 0)
        doc_length = len(self.documents[doc_index])
        
        if doc_length == 0:
            return 0
            
        return term_count / doc_length
    
    def idf(self, term):
        """计算逆文档频率（IDF）"""
        # IDF = log(总文档数 / 包含该词项的文档数)
        doc_freq = self.df.get(term, 0)
        if doc_freq == 0:
            return 0
            
        return math.log(self.doc_count / doc_freq)
    
    def tfidf(self, term, doc_index):
        """计算TF-IDF值"""
        return self.tf(term, doc_index) * self.idf(term)
    
    def document_score(self, query_terms, doc_index):
        """计算文档的相关性得分"""
        score = 0
        for term in query_terms:
            score += self.tfidf(term, doc_index)
        return score
```
