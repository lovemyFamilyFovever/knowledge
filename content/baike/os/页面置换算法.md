# 页面置换算法

## 定义

**一句话定义：** 页面置换算法(Page Replacement Algorithm)是虚拟内存管理中,当发生缺页中断且物理内存已满时,操作系统用来决定"淘汰哪一页换出到磁盘、腾出帧给新页"的策略,目标是最小化缺页率。

**通俗类比：** 像你书桌(内存)只能摊开几本书,要用的新书没地方放时,得决定把哪本先放回书架(换出)——放错了下次又要跑去拿(缺页),所以"该放哪本"很有讲究。

> 多义说明:页面置换是虚拟内存/分页管理的一部分(见 [[虚拟内存]]);本文聚焦"选哪一页淘汰"的算法。

## 原理与机制

- **OPT(最优):** 淘汰未来最久不使用的页——理论最优但无法实现(需预知未来),用作性能基准。
- **FIFO(先进先出):** 淘汰最早进入的页;简单,但可能出现 Belady 异常(帧增多缺页反而增加)。
- **LRU(最近最少使用):** 淘汰最久未访问的页;接近 OPT,但精确实现开销大(需时间戳/栈),常用近似。
- **Clock(二次机会):** LRU 的近似,用访问位环形扫描,开销小,实际系统常用。
- **缺页与抖动:** 帧不足 + 糟糕的置换策略 → 频繁缺页甚至抖动(thrashing)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 缺页中断 | 触发置换的事件 |
| 置换策略 | OPT / FIFO / LRU / Clock |
| 访问位 / 修改位 | 辅助判断与减少写回 |
| 缺页率 | 衡量算法优劣 |
| Belady 异常 | FIFO 特有的反常现象 |

## 应用场景

- 操作系统的虚拟内存管理
- 缺页处理与内存回收
- 数据库缓冲池管理(类似思想)

## 优点与局限

- 优点:在有限物理内存下支撑更大的地址空间、提升多道程序度。
- 局限:好算法(如 LRU)实现开销大;近似算法次优;FIFO 有 Belady 异常;置换不当会导致抖动。

## 常见误区

- OPT 不可实现,仅作理论基准。
- LRU 精确实现代价高,实际常用 Clock 等近似。
- FIFO 可能出现 Belady 异常(帧越多缺页越多)。
- 置换算法影响缺页率与性能,但不改变程序逻辑。
