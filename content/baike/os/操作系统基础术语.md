# 操作系统基础术语


> 📌 **导航**：本文是 **操作系统基础术语** 词条，属于 os 术语集。相关枢纽：[[Shell脚本编程]]、[[操作系统基础术语]]、[[操作系统核心]]、[[进程管理详解]]。

## 定义

**一句话定义：** 操作系统基础术语把 OS 核心概念——进程与线程、内存管理、用户态与内核交互、并发同步与死锁——按"一句话定位 + 深入词条"串成一张入口地图，帮你先建全局框架再逐点深入。

**通俗类比：** 像操作系统这门课的目录页：每章给一句话摘要和页码，具体推导与例子翻到对应章节细看。

## 为什么需要它

OS 概念彼此咬合——进程 / 线程是调度单位，虚拟内存与页表撑起地址空间，系统调用 / 中断是进出内核的门，锁与信号量护住并发临界区。一张索引让人先看清全貌与关联，再跳转到各专门词条，避免同一内容多处重复维护。

## 核心机制

- **进程与线程：** 进程是资源分配单位、线程是 CPU 调度单位，协程是更轻的用户态执行体 → [[线程]]、[[进程调度]]、[[上下文切换]]、[[进程间通信]]。
- **内存管理：** 虚拟地址经页表 + TLB 映射到物理页，按需分页、页面置换（LRU / LFU / FIFO）、mmap 文件映射 → [[虚拟内存]]、[[页面置换算法]]。
- **用户态与内核交互：** 系统调用是受控入口、中断驱动事件处理、态切换守护特权边界 → [[系统调用]]、[[中断]]、[[用户态与内核态]]。
- **并发同步与死锁：** 互斥锁护临界区、信号量控并发上限、条件变量做等待 / 通知、自旋锁忙等短临界区；破坏死锁四条件之一即可预防 → [[信号量与互斥锁]]、[[死锁]]。
- **其他：** 文件系统与容器运行时 → [[文件系统]]、[[容器运行时]]。

## 具体示例

一次 `read()`：用户态进程经 [[系统调用]] 陷入内核（配合 [[中断]]），内核查 [[虚拟内存]] 页表定位用户缓冲、从 [[文件系统]] 取数据再拷回，全程可能因 [[上下文切换]] 让出 CPU——四个概念族在一条调用里串起来。

## 常见误区

- 把本速览当成进程 / 内存 / 死锁的完整讲解来复习。
- 以为线程切换和进程切换开销一样（进程切换要换地址空间、更贵）。
