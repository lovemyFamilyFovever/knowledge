# 操作系统核心

## 进程 vs 线程 vs 协程

| 特性 | 进程 | 线程 | 协程 |
|------|------|------|------|
| 资源 | 独立地址空间 | 共享地址空间 | 共享线程资源 |
| 切换开销 | 大(内核态) | 中(内核态) | 小(用户态) |
| 通信 | IPC(管道/消息/共享内存) | 共享变量 | 共享变量 |
| 并行 | 可 | 可 | 不可(单线程内) |

## 调度算法

| 算法 | 原理 | 特点 |
|------|------|------|
| FCFS | 先来先服务 | 简单，长作业阻塞 |
| SJF | 最短作业优先 | 平均等待最短 |
| RR | 时间片轮转 | 响应快 |
| CFS | 完全公平调度 | Linux默认 |

## 内存管理

```
虚拟地址 -> 页表(Page Table) -> 物理地址
              |
         TLB(快表缓存)
```

- 分页：固定大小(4KB)
- 分段：按逻辑段
- 段页式：先分段再分页

## 文件系统

| 文件系统 | OS | 特点 |
|----------|------|------|
| ext4 | Linux | 默认，稳定 |
| XFS | Linux | 大文件性能好 |
| NTFS | Windows | 默认 |
| APFS | macOS | SSD优化 |
| Btrfs | Linux | CoW，快照 |
