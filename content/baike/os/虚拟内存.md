# 虚拟内存

## 定义

**一句话定义：** 虚拟内存(Virtual Memory)是操作系统提供的内存管理技术,它为每个进程提供独立、连续的虚拟地址空间,由硬件(MMU)与 OS 协作把虚拟地址映射到物理内存或磁盘,从而实现进程隔离、内存"扩容"与按需调页。

**通俗类比：** 像酒店给每位客人发一本"房间号册"(虚拟地址),客人以为整座酒店都归自己用;前台(OS + MMU)在背后把房间号映射到真实房间(物理内存),暂不使用的房间先空着,需要时再安排(按需调页)。

> 多义说明:狭义"虚拟内存"常特指"用磁盘扩展可用内存"(swap/分页);广义指整套虚拟地址空间机制。本文取**广义**。

## 原理与机制

- **分页(Paging):** 虚拟地址空间划分为"页(page)",物理内存划分为"帧(frame)",通过**页表**建立页→帧映射。
- **地址转换:** MMU 在访问时把虚拟地址翻译为物理地址;TLB(快表)缓存最近映射以加速。
- **缺页中断(Page Fault):** 访问的页不在物理内存时触发,OS 从磁盘调入(可能先置换出一页)。
- **页面置换算法:** LRU、FIFO、Clock 等决定换出哪一页;物理内存不足而频繁换页会导致**抖动(thrashing)**。

## 关键组成

| 部件 | 作用 |
|------|------|
| 虚拟地址空间 | 每进程独立的连续地址视图 |
| 页表(常多级) | 记录虚拟页到物理帧的映射 |
| MMU | 硬件地址转换与保护 |
| TLB | 页表项缓存,加速转换 |
| 交换区(swap) | 磁盘上存放被换出的页 |
| 置换算法 | 决定换出策略(LRU/Clock 等) |

## 应用场景

- 现代操作系统的进程内存管理与隔离
- 内存保护(非法访问触发段错误)
- 写时复制(fork)、内存映射文件(mmap)
- 运行内存需求超过物理内存的程序

## 优点与局限

- 优点:进程相互隔离与保护;可用地址空间超过物理内存;程序员面对连续地址、编程更简单;支持共享与写时复制。
- 局限:地址转换有开销(TLB 缓解);缺页会引发磁盘 I/O、拖慢性能;置换不当导致抖动;实时系统需谨慎使用。

## 常见误区

- 虚拟内存 ≠ 磁盘交换:swap 只是虚拟内存实现的一部分。
- "虚拟内存越大越好"是错的:超出物理内存过多会引发抖动,性能骤降。
- 虚拟地址连续 ≠ 物理内存连续:二者通过页表映射,物理上通常离散。
