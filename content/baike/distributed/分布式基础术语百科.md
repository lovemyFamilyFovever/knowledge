## 定义

**一句话定义：** 分布式基础术语百科是分布式系统核心概念的索引合集——把 CAP、BASE、分布式锁、分布式事务、分布式 ID、配置中心、服务发现等高频术语按"一句话定位 + 深入词条"串成一张入口地图。

## 为什么需要它

分布式概念彼此咬合——CAP 约束选型、BASE 指导柔性事务、锁 / 事务 / ID / 共识是并发与唯一的底座。一张索引让人先建立全局地图，再按需跳转到深词条，避免同一内容在多份文档里重复维护。

## 核心机制

- **CAP 定理：** 网络分区时一致性 C 与可用性 A 二选一 → [[CAP 定理]]。
- **BASE 理论：** CAP 中 AP 的工程落地，基本可用 / 软状态 / 最终一致 → [[BASE 理论]]。
- **分布式锁：** 跨节点互斥，Redis / ZooKeeper / Redlock → [[分布式锁]]。
- **分布式事务：** 跨库跨服务的同成同败，2PC / TCC / Saga / 消息 → [[分布式事务]]。
- **分布式 ID：** 全局唯一且趋势递增的发号，UUID / 号段 / Snowflake → [[分布式 ID]]。
- **一致性算法：** 多节点对某值达成共识，Paxos / Raft → [[一致性算法]]。
- **配置中心 / 服务注册与发现：** Apollo·Nacos 动态配置、实例自动注册供消费者发现 → [[微服务治理术语百科]]。
