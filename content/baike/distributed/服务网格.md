# 服务网格

## Istio架构

```
控制面(Control Plane):
  - Pilot: 配置管理
  - Citadel: 证书管理
  - Galley: 配置验证

数据面(Data Plane):
  - Envoy Sidecar: 每个Pod旁挂代理
```

## Sidecar模式

```
[App Container] <-> [Envoy Sidecar] -> 网络
```

所有流量经过Sidecar，实现：
- 流量管理(路由/负载均衡)
- 安全(mTLS)
- 可观测(指标/日志/追踪)

## 与传统微服务对比

| 特性 | 传统 | 服务网格 |
|------|------|----------|
| 通信治理 | SDK嵌入 | Sidecar代理 |
| 语言耦合 | 需要SDK | 语言无关 |
| 升级 | 改代码重新部署 | 独立升级Sidecar |
| 复杂度 | 分散在代码中 | 集中在基础设施 |
