# 分布式缓存

## 一致性哈希

```
0 -------- 2^32-1 环形空间
   NodeA    NodeB    NodeC
       Key1    Key2
```

- 节点加入/离开只影响相邻Key
- 虚拟节点解决数据倾斜

## 缓存分片

| 方案 | 原理 | 特点 |
|------|------|------|
| 客户端分片 | 客户端计算分片 | 简单 |
| 代理分片 | Proxy路由 | 灵活 |
| Redis Cluster | Gossip协议 | 自动化 |

## 热Key处理

- 本地缓存(Caffeine/Guava)
- 热Key复制到多个分片
- 读写分离
