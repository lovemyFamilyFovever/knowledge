## 调试（Debugging）

**一句话定义：** 调试是发现并修复程序中错误的过程。

**通俗类比：** 调试就像医生看病——观察症状（bug表现）→ 检查（断点/日志）→ 诊断（找到原因）→ 治疗（修复代码）。

### 调试技巧

**1. 打印调试（最基础）**
```python
print(f"DEBUG: value={value}, type={type(value)}")
```

**2. 断点调试（推荐）**
```python
# Python
import pdb; pdb.set_trace()  # 或 breakpoint()

# JavaScript
debugger;  // 浏览器会在这里暂停

# Java
// IDE中在行号旁点击设置断点
```

**3. 条件断点**
- 只在特定条件下暂停
- 例：当 user.id == 42 时暂停

**4. 日志级别**
```python
import logging
logging.debug("详细信息，开发时用")
logging.info("正常运行信息")
logging.warning("警告但不影响运行")
logging.error("出错了")
logging.critical("严重错误")
```

### 性能分析工具

| 工具 | 语言 | 用途 |
|------|------|------|
| Chrome DevTools | JS | 前端性能、网络、内存 |
| cProfile | Python | CPU性能分析 |
| memory_profiler | Python | 内存使用分析 |
| pprof | Go | CPU/内存/阻塞分析 |
| JProfiler | Java | Java性能分析 |
| perf | Linux | 系统级性能分析 |
| strace | Linux | 系统调用跟踪 |

### 常见性能问题

| 问题 | 症状 | 排查 |
|------|------|------|
| 内存泄漏 | 内存持续增长 | 内存分析工具 |
| CPU密集 | CPU占用100% | 性能分析器找热点函数 |
| I/O阻塞 | 响应慢但CPU低 | 查看等待时间 |
| 死锁 | 程序卡住 | 线程dump分析 |
| N+1查询 | 数据库查询过多 | SQL日志/ORM分析 |
