# 显卡与GPU

## GPU（Graphics Processing Unit）图形处理器

**一句话定义：** GPU是专门处理图形和并行计算的芯片。

**通俗类比：** 如果CPU是一个数学教授（什么都会但只有一个），GPU就是一个有几千人的计算团队——每个人只会简单计算，但几千人同时算就极快。

### GPU vs CPU

| 特性 | CPU | GPU |
|------|-----|-----|
| 核心数 | 几个~几十个 | 几千个 |
| 单核性能 | 极强 | 较弱 |
| 并行能力 | 有限 | 极强 |
| 适用场景 | 复杂逻辑、串行任务 | 图形渲染、AI训练 |
| 架构 | 复杂控制逻辑 | 大量简单计算单元 |

### 显卡核心参数

| 参数 | 说明 |
|------|------|
| GPU芯片 | 核心型号（如RTX 4090的AD102）|
| CUDA核心数 | 并行计算单元数量 |
| 显存(VRAM) | 显卡专用内存（GDDR6/6X）|
| 显存位宽 | 一次传输数据宽度 |
| 核心频率 | GPU运行速度(MHz) |
| TDP | 功耗(瓦特) |

### 显卡用途

**图形渲染**
- 游戏画面渲染
- 3D建模和动画
- 视频编辑和特效

**通用计算（GPGPU）**
- AI/深度学习训练
- 科学计算（气象模拟、分子动力学）
- 加密货币挖矿
- 视频编解码

### 主要厂商

| 厂商 | 产品线 | 技术 |
|------|--------|------|
| NVIDIA | GeForce RTX | CUDA、DLSS、Ray Tracing |

### 显存类型

| 类型 | 带宽 | 用途 |
|------|------|------|
| GDDR6 | ~20 Gbps | 中端显卡 |
| GDDR6X | ~21 Gbps | 高端显卡 |
| HBM2e | ~4.6 TB/s | 专业/AI计算卡 |
