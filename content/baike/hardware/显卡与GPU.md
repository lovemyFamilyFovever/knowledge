# 显卡与GPU

## 定义

**一句话定义：** GPU（图形处理器）是拥有大量简单计算单元、擅长大规模并行处理的芯片，最初用于图形渲染，现广泛用于 AI 训练/推理与科学计算（GPGPU）；显卡则是以 GPU 为核心、配显存与供电散热的整块扩展卡。

**通俗类比：** 若 CPU 是一位数学教授（什么都会但只有一个），GPU 就是几千名小学生组成的计算团队——每人只会简单加减，但几千人同时算，海量简单运算就极快。

> 多义说明：「GPU」指芯片/处理器，「显卡（Graphics Card）」指含 GPU、显存、供电与接口的整卡；此外还有集成于 CPU/SoC 的**核芯显卡/集成 GPU**（如 Intel Iris Xe、Apple M 系列 GPU）。

## 原理与机制

- **SIMT 架构**：GPU 以「单指令多线程」方式让成百上千个线程同时执行相同指令、处理不同数据，特别适合矩阵/向量等规则并行运算。
- **图形渲染管线**：顶点处理 → 光栅化 → 像素/片元着色 → 输出，大量阶段可并行。
- **GPGPU**：借助 CUDA（NVIDIA）、ROCm/OpenCL（AMD）、oneAPI（Intel）等编程模型，把 GPU 用于非图形的通用并行计算（深度学习、物理模拟等）。

## 关键组成

| 部件 | 作用 |
|------|------|
| GPU 芯片 | 核心，含大量计算单元（如 RTX 4090 用 AD102） |
| 计算单元 | NVIDIA 称 CUDA 核心、AMD 称流处理器(SP)/计算单元(CU)、Intel 称 Xe 核心 |
| 显存(VRAM) | GPU 专用内存，存放纹理/帧缓冲/模型权重（GDDR6/6X、HBM） |
| 显存位宽与带宽 | 决定数据吞吐，AI 与高分辨率尤为关键 |
| 供电(VRM)与散热 | 高功耗器件需足量供电与散热器/风扇 |

### 显卡核心参数

| 参数 | 说明 |
|------|------|
| GPU 型号 | 核心芯片（如 AD102、Navi 31） |
| 计算单元数 | 并行单元数量（跨厂商**不可直接比较**） |
| 显存容量/类型 | 如 24 GB GDDR6X |
| 显存位宽 | 如 384-bit |
| 核心频率 | GPU 运行速度(MHz) |
| TDP/TGP | 整卡功耗(瓦特) |

### GPU vs CPU

| 特性 | CPU | GPU |
|------|-----|-----|
| 核心数 | 几个~几十个 | 数千个 |
| 单核性能 | 极强（复杂控制/分支） | 较弱（简单运算） |
| 并行能力 | 有限 | 极强 |
| 适用 | 复杂逻辑、串行、低延迟 | 图形渲染、AI、大规模并行 |
| 架构 | 复杂控制逻辑 + 大缓存 | 大量简单计算单元 + 高带宽显存 |

### 显存类型

| 类型 | 典型带宽口径 | 用途 |
|------|--------------|------|
| GDDR6 | 每引脚 ~14–20 Gbps | 中端显卡 |
| GDDR6X | 每引脚 ~21–24 Gbps | 高端显卡 |
| HBM2e/HBM3 | 每堆栈数 TB/s（如 ~4.6 TB/s） | 数据中心/AI 计算卡 |

> 说明：GDDR 的「Gbps」是**每引脚数据速率**，整卡显存带宽 = 每引脚速率 × 位宽 ÷ 8；HBM 的「TB/s」是**每堆栈带宽**——两类单位口径不同，不能直接横向比较（原文档混列，已澄清）。

### 主要厂商与技术

| 厂商 | 产品线 | 关键技术 |
|------|--------|----------|
| NVIDIA | GeForce RTX | CUDA、DLSS、光线追踪 |

## 应用场景

- **图形渲染**：游戏、3D 建模与动画、视频编辑与特效。
- **通用计算(GPGPU)**：AI/深度学习训练与推理、科学计算（气象、分子动力学）、视频编解码、密码学/挖矿。

## 优点与局限

- 优点：大规模并行吞吐远超 CPU，是 AI 与图形的主力；高显存带宽适合数据密集型运算。
- 局限：不擅长复杂分支与串行低延迟逻辑；功耗与发热高；显存容量常是 AI 大模型的瓶颈；生态（尤其 CUDA）存在厂商锁定。

## 常见误区

- **「CUDA 核心数」跨厂商不可比**：CUDA 是 NVIDIA 专有名词，AMD 用流处理器/CU、Intel 用 Xe 核心，架构不同，数量不能直接对比性能。
- **显存大 ≠ 强**：显存带宽、GPU 架构与核心数同样关键；大显存主要利于高分辨率纹理与大模型。
- 把「显卡」与「GPU」混用：GPU 是芯片，显卡是整卡；核显无独立显卡但有集成 GPU。
