# 显卡与GPU


> 📌 **导航**：本文是 **显卡与GPU** 词条，属于 hardware 术语集。相关枢纽：[[CPU 缓存]]、[[CPU与处理器架构]]、[[RAID 磁盘阵列]]、[[主板与总线]]、[[内存与存储系统]]。

## 定义

**一句话定义：** GPU（图形处理器）是拥有大量简单计算单元、擅长大规模并行处理的芯片，最初用于图形渲染，现广泛用于 AI 训练 / 推理与科学计算（GPGPU）；显卡则是以 GPU 为核心、配显存与供电散热的整块扩展卡。

**通俗类比：** 若 CPU 是一位数学教授（什么都会但只有一个），GPU 就是几千名小学生组成的计算团队——每人只会简单加减，但几千人同时算，海量简单运算就极快。

> 多义说明：「GPU」指芯片 / 处理器，「显卡」指含 GPU、显存、供电与接口的整卡；此外还有集成于 CPU / SoC 的核芯显卡 / 集成 GPU（如 Intel Iris Xe、Apple M 系列 GPU）。

## 为什么需要它

图形与 AI 都是"同一操作作用到海量数据"的规则并行任务，用少量强核串行做太慢。GPU 以成千上万个简单单元 + 高带宽显存做大规模并行，把这类计算的吞吐拉到 CPU 的几十上百倍，成为图形渲染与深度学习的算力主力。

## 核心机制

- **SIMT 架构：** 以"单指令多线程"让成百上千个线程同时执行相同指令、处理不同数据，特别适合矩阵 / 向量等规则并行运算。
- **图形渲染管线：** 顶点处理 → 光栅化 → 片元 / 像素着色 → 输出，大量阶段可并行（思想同 [[指令流水线]]）。
- **GPGPU：** 借 CUDA（NVIDIA）、ROCm / OpenCL（AMD）、oneAPI（Intel）等编程模型，把 GPU 用于深度学习、物理模拟等非图形的通用并行计算。

主要部件：

| 部件 | 作用 |
|------|------|
| GPU 芯片 | 核心，含大量计算单元（如 RTX 4090 的 AD102） |
| 计算单元 | NVIDIA 称 CUDA 核心、AMD 称流处理器(SP)/计算单元(CU)、Intel 称 Xe 核心 |
| 显存 VRAM | GPU 专用内存，放纹理 / 帧缓冲 / 模型权重（GDDR6/6X、HBM） |
| 位宽与带宽 | 决定数据吞吐，AI 与高分辨率尤为关键 |
| 供电与散热 | 高功耗器件需足量供电与散热 |

## 具体示例

GPU 与 CPU 的取向差异，正是"AI 训练为什么用 GPU"：

| 特性 | CPU | GPU |
|------|-----|-----|
| 核心数 | 几个~几十个 | 数千个 |
| 单核性能 | 强（复杂控制 / 分支） | 弱（简单单元） |
| 并行能力 | 有限 | 极强 |
| 架构 | 复杂控制 + 大缓存 | 大量简单单元 + 高带宽显存 |
| 适用 | 复杂逻辑、串行、低延迟 | 图形、AI、大规模并行 |

选型还要看清单位与可比性：整卡显存带宽 = 每引脚速率 × 位宽 ÷ 8（GDDR），而 HBM 标的是每堆栈数 TB/s，口径不同不可直接横比；NVIDIA 的"CUDA 核心数"与 AMD 的"流处理器 / CU"架构不同，数量也不能直接比性能。主要厂商：NVIDIA（GeForce，CUDA / DLSS / 光追）、AMD（Radeon，RDNA / FSR）、Intel（Arc，Xe）、Apple（M 系列集成 GPU，Metal、统一内存）。

## 何时用与何时不用

- **用：** 图形渲染（游戏、3D 建模与动画、视频特效）与 GPGPU（AI 训练 / 推理、科学计算、视频编解码）。
- **不用：** 复杂分支、串行、低延迟的控制逻辑交给 CPU；小模型 / 轻量推理用核显或 CPU 更省，不必上独显。

## 优劣与代价

✅ 大规模并行吞吐远超 CPU，是 AI 与图形的主力；高显存带宽适合数据密集型运算。
⚠️ 不擅长复杂分支与串行低延迟逻辑；功耗与发热高；显存容量常成 AI 大模型瓶颈；生态（尤其 CUDA）有厂商锁定。

## 与相关概念的区别

vs [[CPU与处理器架构]]：CPU 少而强、复杂控制 + 大缓存、擅串行低延迟，GPU 海量简单单元 + 高带宽显存、擅并行吞吐；vs [[内存与存储系统]]：显存 VRAM 是 GPU 专用的独立高带宽内存，不等同系统内存。

## 常见误区

- 比较显卡时，CUDA 核心数可以和 AMD 流处理器数直接对比性能。
- 显存越大，显卡就一定越强。
- "显卡"和"GPU"是同一个东西。

## 面试速答

> 🎯 GPU = 大量简单计算单元、以 SIMT 做大规模并行的芯片（图形 + GPGPU / AI），与 CPU 少而强相反。选型看架构 / 带宽 / 显存而非光比核心数——CUDA 核心数与 AMD 流处理器跨厂商不可比、GDDR 每引脚 Gbps 与 HBM 每堆栈 TB/s 单位不同、显存大 ≠ 强。
