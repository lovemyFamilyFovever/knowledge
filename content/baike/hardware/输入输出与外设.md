# 输入输出与外设

## 定义

**一句话定义：** 输入/输出（I/O）设备是计算机与外部世界（人或其他系统）交互的桥梁——输入设备把外部信息转换为计算机可处理的数字信号，输出设备把处理结果转换为人可感知的形式。

**通俗类比：** I/O 就像人的感官与手脚——键盘/鼠标/麦克风是「感官」（把外界信息传给电脑），显示器/音箱/打印机是「手脚与嘴巴」（把电脑的结果表达出来）。

> 多义说明：本文涵盖常见外设与其接口标准，并说明 CPU 与外设之间的 I/O 控制方式（程序查询/中断/DMA）。

## 原理与机制

CPU 与外设速度差异巨大，I/O 控制方式由低效到高效演进：

- **程序查询（轮询）**：CPU 不断询问设备是否就绪，简单但浪费 CPU。
- **中断驱动**：设备就绪后向 CPU 发中断，CPU 再去处理，无需空等（键鼠等低速设备常用）。
- **DMA（直接内存访问）**：由 DMA 控制器在设备与内存间直接搬运数据，CPU 只在开始/结束时介入，适合磁盘、网卡等大批量传输。
- **通道 / I/O 处理器**：更进一步的专用 I/O 处理（大型机/服务器）。

模拟信号与数字信号之间需转换：**ADC**（模数转换，如麦克风录音）、**DAC**（数模转换，如播放声音）。

## 关键组成

### 输入设备

- **键盘**：机械键盘每键独立轴体（青轴段落感强/声音大、红轴线性安静/游戏常用、茶轴轻微段落/通用）；薄膜键盘（橡胶碗，便宜安静）；静电容（无物理触点，手感独特、价高）。
- **鼠标**：光学/激光传感器；DPI（每英寸点数，越高越灵敏）；轮询率（每秒上报位置次数，125–8000 Hz）。
- **其他**：触摸屏（电容式如手机、电阻式如旧款 ATM）、扫描仪、麦克风（ADC）、摄像头。

### 输出设备

**显示器**

| 参数 | 说明 |
|------|------|
| 分辨率 | 像素数量（1080p/2K/4K） |
| 刷新率 | 每秒画面更新次数（60/144/240 Hz） |
| 面板类型 | IPS(色彩好)/TN(响应快)/VA(对比高)/OLED(最佳) |
| 响应时间 | 像素变色速度（1–5 ms） |
| 色域 | 能显示的颜色范围（sRGB/DCI-P3 等） |

**音频设备**
- DAC：数字→模拟（播放）；ADC：模拟→数字（录音）。
- 采样率：每秒采样次数（44.1 kHz = CD 品质）；位深：每次采样精度（16/24 bit）。

### 显示/外设接口标准

| 接口 | 传输内容 | 带宽 |
|------|----------|------|
| HDMI 2.1 | 视频 + 音频 | 48 Gbps |
| DisplayPort 2.0 | 视频 + 音频 | 80 Gbps |
| USB-C / Thunderbolt 4 | 数据 + 视频 + 供电 | 40 Gbps |

### 接口汇总

| 接口 | 类型 | 用途 |
|------|------|------|
| USB-A | 数据 | 通用外设 |
| USB-C | 数据 + 视频 + 供电 | 新一代通用接口 |
| 3.5mm | 音频 | 耳机/麦克风 |
| Ethernet(RJ45) | 网络 | 有线上网 |
| Wi-Fi | 无线 | 无线局域网 |
| Bluetooth | 无线 | 短距离外设 |

## 应用场景

- 人机交互（键鼠、显示器、音频）、数据采集（传感器、扫描仪、摄像头）、网络通信（网卡、无线模块）。
- 接口选型需匹配带宽与功能：如 4K 高刷显示器需 HDMI 2.1 / DP 2.0；「一线连」需 USB-C/TB 同时支持视频与供电。

## 优点与局限

- 优点：标准化接口（USB/HDMI/DP/蓝牙）带来良好兼容与即插即用；中断/DMA 大幅降低 I/O 对 CPU 的占用。
- 局限：外设速度远低于 CPU，常是系统瓶颈之一；接口与协议繁多、版本碎片化（如 USB 命名混乱）；模拟/数字转换存在精度与延迟限制。

## 常见误区

- **DPI 越高越好？** 过高 DPI 反而难以精确控制，应按需求与传感器质量选择。
- **USB 命名混乱**：USB 3.0 / 3.1 Gen 1 / 3.2 Gen 1 实为同一 5 Gbps；选购应看具体速率标注而非「代际」名号。
- **刷新率与响应时间混淆**：刷新率是每秒更新画面次数（Hz），响应时间是像素变色快慢（ms），二者不同。
- 以为所有 I/O 都持续占用 CPU：DMA 可让大批量传输绕过 CPU。
