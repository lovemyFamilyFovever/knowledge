# 输入输出与外设


> 📌 **导航**：本文是 **输入输出与外设** 词条，属于 hardware 术语集。相关枢纽：[[CPU 缓存]]、[[CPU与处理器架构]]、[[RAID 磁盘阵列]]、[[主板与总线]]、[[内存与存储系统]]。

## 定义

**一句话定义：** 输入 / 输出（I/O）设备是计算机与外部世界（人或其他系统）交互的桥梁——输入设备把外部信息转换为计算机可处理的数字信号，输出设备把处理结果转换为人可感知的形式。

**通俗类比：** I/O 像人的感官与手脚——键盘 / 鼠标 / 麦克风是"感官"（把外界信息传给电脑），显示器 / 音箱 / 打印机是"手脚与嘴巴"（把电脑的结果表达出来）。

> 多义说明：本文涵盖常见外设与接口标准，并说明 CPU 与外设之间的 I/O 控制方式（程序查询 / 中断 / DMA）。

## 为什么需要它

计算机再快也要与外界交互：取数据、出结果、连网络。而外设速度比 CPU 慢几个数量级，用错 I/O 方式会让 CPU 空等；各类外设又需要标准化接口才能即插即用、跨厂商互操作。

## 核心机制

I/O 控制方式由低效到高效演进：

- **程序查询（轮询）：** CPU 不断询问设备是否就绪，简单但浪费 CPU。
- **中断驱动：** 设备就绪后向 CPU 发中断、CPU 再处理，无需空等（键鼠等低速设备常用），见 [[中断]]。
- **DMA：** 由 DMA 控制器在设备与内存间直接搬数据、CPU 只在开始 / 结束介入，适合磁盘、网卡等大批量传输（见 [[直接内存访问]]）。
- **通道 / I/O 处理器：** 大型机 / 服务器上更进一步的专用 I/O 处理。

模拟与数字信号之间需转换：ADC（模数，如麦克风录音）、DAC（数模，如播放声音）；音频质量由采样率（44.1 kHz = CD 品质）与位深（16 / 24 bit）决定。

## 具体示例

接一台 4K 高刷显示器要选对接口带宽：HDMI 2.1（48 Gbps）、DisplayPort 2.0（80 Gbps）才喂得饱，"一线连"扩展则看 USB-C / Thunderbolt 4（40 Gbps，数据 + 视频 + 供电）；面板上 IPS 色准好、VA 对比高、TN 响应快、OLED 最佳。鼠标的高轮询率（125–8000 Hz）配合合适 DPI 才谈得上操控精度。

## 何时用与何时不用

- **选型看：** 接口要匹配带宽与功能；低速交互用中断驱动、大批量传输用 DMA。
- **注意：** 外设常是系统瓶颈，靠 DMA / 中断把 CPU 从搬运中解放；接口版本命名碎片化（如 USB 代际混乱）要按实际速率而非"代际名号"选。

## 优劣与代价

✅ 标准化接口（USB / HDMI / DP / 蓝牙）带来良好兼容与即插即用；中断 / DMA 大幅降低 I/O 对 CPU 的占用。
⚠️ 外设速度远低于 CPU、常成瓶颈；接口与协议繁多、版本碎片化；模数转换有精度与延迟限制。

## 与相关概念的区别

vs [[主板与总线]]：总线是 CPU↔内存↔扩展卡的内部传输通道，外设则挂在 USB / PCIe / SATA 等接口上、经 DMA 与内核同外界交换数据；vs [[内存与存储系统]]：外存（HDD / SSD）既是存储，也是一种 I/O 设备。

## 常见误区

- 鼠标 DPI 越高就一定越好。
- USB 3.0 / 3.1 Gen 1 / 3.2 Gen 1 是速度递增的不同标准。
- 显示器的刷新率就是它的响应时间。

## 面试速答

> 🎯 I/O 设备是人机 / 系统交互桥梁；CPU 与外设三种控制方式效率递增：程序查询（轮询、浪费 CPU）→ 中断驱动（就绪才打扰）→ DMA（控制器成块搬、CPU 首尾介入），模拟信号靠 ADC / DAC 转换；外设接口按带宽选（HDMI 2.1 / DP 2.0 / Thunderbolt），DPI / 刷新率 / 响应时间各有含义别混。
