# 内存与存储系统

## RAM（Random Access Memory）随机存取存储器

**一句话定义：** 内存是计算机的"工作台"，正在运行的程序和数据都放在这里。

**通俗类比：** 内存就像厨师的案板——案板越大，能同时处理的食材越多。关机后案板会被清空。

### 内存类型

**DDR4/DDR5**
- DDR = Double Data Rate（双倍数据速率）
- DDR4: 2133-3200MHz，主流
- DDR5: 4800-8400MHz，新一代
- 数字越大，速度越快，但需主板支持

### 关键参数

| 参数 | 说明 | 示例 |
|------|------|------|
| 容量 | 能存多少数据 | 8GB/16GB/32GB |
| 频率 | 数据传输速度 | 3200MHz |
| 时序(CAS) | 响应延迟 | CL16（越小越好）|
| 通道数 | 并行通道 | 双通道=两条路并行 |
| 带宽 | 每秒传输量 | 频率×位宽/8 |

## 存储设备

### HDD（机械硬盘）
- 原理：磁盘旋转+磁头读写
- 速度：80-200 MB/s
- 优点：便宜、容量大
- 缺点：慢、怕震动

### SSD（固态硬盘）
- 原理：闪存芯片，无机械部件
- SATA SSD: 500 MB/s
- NVMe SSD: 3000-7000 MB/s
- 优点：快、安静、抗震
- 缺点：贵、写入寿命有限

### 存储层次

```
寄存器(最快) → L1缓存 → L2缓存 → L3缓存 → 内存(RAM) → SSD/HDD(最慢)
```

越靠近左边越快越小越贵，越靠近右边越慢越大越便宜。

### 虚拟内存

当物理内存不够时，操作系统把部分数据"交换"到硬盘上。
- Windows: 页面文件(pagefile.sys)
- Linux: Swap分区
- 性能影响：硬盘比内存慢万倍，会明显卡顿
