# 内存与存储系统


> 📌 **导航**：本文是 **内存与存储系统** 词条，属于 hardware 术语集。相关枢纽：[[CPU 缓存]]、[[CPU与处理器架构]]、[[RAID 磁盘阵列]]、[[主板与总线]]、[[内存与存储系统]]。

## 定义

**一句话定义：** 内存（RAM）是 CPU 可直接寻址、存放正在运行的程序与数据的**易失性**高速存储；存储系统则是由寄存器、缓存、内存到外存（SSD/HDD）构成的**分层体系**，借助局部性原理在速度、容量与成本间取得平衡。

**通俗类比：** 内存像厨师的案板——正在处理的食材都摆在上面，案板越大能同时处理的越多，但收工（断电）后案板清空；冰箱/仓库（外存）容量大却取用慢。

> 多义说明：「内存」通常指主存（DRAM），区别于 CPU 缓存（见 [[CPU 缓存]]）与外存（硬盘）；「存储」一词在中文里既可指内存也可指硬盘，需按上下文区分。

## 原理与机制

- **易失性**：DRAM 用电容存电荷表示 0/1，需周期刷新（refresh），断电即丢失；SRAM（缓存用）以触发器存储，更快更贵、不需刷新。
- **存储层次与局部性**：利用时间局部性（刚访问的很可能再访问）与空间局部性（邻近地址很可能被访问），把热数据放在近 CPU 的高速层，形成寄存器→缓存→内存→外存的金字塔（缓存细节见 [[CPU 缓存]]）。
- **虚拟内存**：物理内存不足时，OS 将部分页面换出到磁盘（Windows 页面文件 pagefile.sys、Linux swap），用「内存 + 磁盘」营造更大的地址空间，代价是访问磁盘远慢于内存。

## 关键组成

### 内存类型与参数

- **DDR**（Double Data Rate）：在时钟上升沿与下降沿都传输数据，故**数据速率（MT/s）是时钟频率（MHz）的两倍**。DDR4 常见 2133–3200 MT/s，DDR5 从 4800 MT/s 起、可达 8000+ MT/s（需主板与 CPU 支持）。

| 参数 | 说明 | 示例 |
|------|------|------|
| 容量 | 能存多少数据 | 8 / 16 / 32 GB |
| 数据速率 | 每秒传输次数 | DDR4-3200 = 3200 MT/s |
| 时序(CAS/CL) | 读延迟（时钟周期数） | CL16（越小越好） |
| 通道数 | 并行通道 | 双通道带宽约翻倍 |
| 带宽 | 每秒传输量 | ≈ 数据速率(MT/s) × 8 B（64 位单通道） |

> 说明：单通道带宽 ≈ 数据速率(MT/s) × 64 bit ÷ 8 = MT/s × 8 字节/秒。例如 DDR4-3200 单通道 ≈ 25.6 GB/s，双通道 ≈ 51.2 GB/s。厂商常把「3200 MT/s」写作「3200 MHz」，严格说二者不同（MT/s = 2 × 实际 MHz）。

### 存储设备

| 设备 | 原理 | 典型速度 | 优点 | 缺点 |
|------|------|----------|------|------|
| HDD（机械硬盘） | 磁盘旋转 + 磁头读写 | 80–200 MB/s | 便宜、容量大 | 慢、怕震动、有寻道延迟 |
| SATA SSD | NAND 闪存 + SATA 接口 | ~500–550 MB/s | 快、静音、抗震 | 受 SATA 带宽上限 |
| NVMe SSD | NAND 闪存 + PCIe 直连 | 3000–7000+ MB/s | 极快、低延迟 | 较贵、写入寿命有限 |

### 存储层次

```
寄存器(最快) → L1 → L2 → L3 缓存 → 内存(RAM) → SSD/HDD(最慢)
越靠左：越快、越小、越贵（每字节成本高）
越靠右：越慢、越大、越便宜
```

## 应用场景

- 内存容量与带宽影响多任务、大型程序与集成显卡性能；双通道对核显/游戏有明显收益。
- SSD 作系统盘显著提升启动与加载速度；HDD/大容量 SSD 作冷数据仓库；NVMe 用于高性能工作站与数据库。

## 优点与局限

- 优点：分层存储在成本可控下逼近「又快又大」；DRAM 性价比高、支持随机访问。
- 局限：内存易失（断电丢数据，需外存/持久内存补充）；「内存墙」——CPU 增速快于内存，靠缓存缓解；SSD 有写入寿命（P/E 擦写次数）与掉速问题。

## 常见误区

- **内存 ≠ 硬盘**：内存易失、供 CPU 直接高速访问；硬盘持久、容量大但慢。「存储」需分清语境。
- **「3200 MHz 内存」**：通常指 3200 MT/s（数据速率），实际时钟约 1600 MHz（DDR 双沿传输）。
- 以为加内存就一定变快：仅当原内存不足（频繁换页）时提升明显，否则瓶颈可能在 CPU/磁盘/GPU。
- 混用不同频率/容量的内存条，一般会以较低频率运行、双通道也可能降级，建议同规格成对使用。
