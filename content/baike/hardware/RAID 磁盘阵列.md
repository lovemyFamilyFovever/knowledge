# RAID 磁盘阵列


> 📌 **导航**：本文是 **RAID 磁盘阵列** 词条，属于 hardware 术语集。相关枢纽：[[CPU 缓存]]、[[CPU与处理器架构]]、[[RAID 磁盘阵列]]、[[主板与总线]]、[[内存与存储系统]]。

## 定义

**一句话定义：** RAID(Redundant Array of Independent Disks,独立磁盘冗余阵列)是把多块物理磁盘按不同方式组合成一个逻辑单元的技术,通过数据条带化、镜像或奇偶校验,在提升读写性能与/或提供数据冗余(容错)之间取得平衡。

**通俗类比：** 像把重要资料分放在多个柜子——有的做法是每份都复印一份分放(镜像,坏一个还有备份),有的是把一套资料拆开同时放多个柜子加快取用(条带),还有的是额外放一份"校验清单",某个柜子坏了能据此推算还原(奇偶校验)。

> 多义说明:RAID 有多种级别(0/1/5/6/10 等),侧重不同(性能 vs 冗余);RAID **不等于备份**(不能替代离线备份)。本文综述常见级别。

## 原理与机制

- **三种基本技术:** 条带化(striping,数据分块并行写多盘 → 提速)、镜像(mirroring,完全复制 → 冗余)、奇偶校验(parity,用校验信息在盘损坏时重建)。
- **常见级别:**
  - RAID 0:纯条带,性能最高,**无冗余**(任一盘坏则全丢)。
  - RAID 1:纯镜像,冗余高,容量利用率 50%。
  - RAID 5:条带 + 分布式奇偶校验,容 1 盘故障,利用率 (n−1)/n。
  - RAID 6:双奇偶校验,容 2 盘故障。
  - RAID 10(1+0):先镜像再条带,兼顾性能与冗余,成本较高。

## 关键组成

| 组成 | 说明 |
|------|------|
| 条带 / 镜像 / 校验 | 三种基本数据布局 |
| RAID 级别 | 0/1/5/6/10 等 |
| 容量利用率 | 冗余带来的空间开销 |
| 容错盘数 | 可容忍同时损坏的盘数 |
| 硬件 / 软件 RAID | 由专用控制器或 OS 实现 |

## 应用场景

- 服务器与存储阵列
- 数据库、文件服务器
- 需要高可用/高吞吐的存储
- NAS 与数据中心

## 优点与局限

- 优点:提升性能(条带)与/或容错(镜像/校验),对上层透明。
- 局限:容量利用率下降(冗余开销);重建(rebuild)期间性能下降且风险高;RAID 5 有写惩罚;不能防误删/逻辑损坏/灾难(非备份)。

## 常见误区

- RAID ≠ 备份:它不防误删、勒索软件、火灾,仍需独立备份。
- RAID 0 无冗余,不是"更安全的方案"。
- RAID 5 只容 1 盘故障,且大容量盘重建期长、风险高(常推荐 RAID 6/10)。
- 各级别在性能/容量/容错间取舍不同,没有万能级别。
