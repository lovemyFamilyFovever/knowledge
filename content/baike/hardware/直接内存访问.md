# 直接内存访问

## 定义

**一句话定义：** 直接内存访问(Direct Memory Access, DMA)是一种让外设(如磁盘、网卡)通过专门的 DMA 控制器直接与主存交换数据、而无需 CPU 逐字节搬运的机制,从而在大批量 I/O 时释放 CPU、提升系统整体效率。

**通俗类比：** 像快递直接送进你家仓库(内存),而不是每件都先经你手(CPU)再搬进去——你只需开始时下个单、结束时收一个"送完了"的通知(中断),中间搬运由专门的搬运队(DMA 控制器)完成。

> 多义说明:DMA 指以"数据块"为单位的传输机制;区别于程序查询 I/O 与逐字节的中断驱动 I/O。本文讨论块传输的 DMA。

## 原理与机制

- **流程:** CPU 配置 DMA 控制器(源/目的地址、字节数、方向)→ DMA 控制器接管总线,在设备与内存间逐块搬数据 → 传输完成后向 CPU 发一个中断。
- **CPU 介入点:** 仅在"开始配置"与"结束响应中断"时参与,中间不逐字节搬运。
- **总线使用:** 周期窃取(cycle stealing)——DMA 分时占用总线,可能与 CPU 访存竞争。
- **现代扩展:** 分散-聚集(scatter-gather)DMA;IOMMU 为设备提供地址转换与隔离(虚拟化与安全需要)。

## 关键组成

| 组成 | 作用 |
|------|------|
| DMA 控制器 | 主导数据传输 |
| 地址 / 计数寄存器 | 记录源、目的与剩余字节 |
| 总线仲裁 / 周期窃取 | 与 CPU 分时使用总线 |
| 完成中断 | 传输结束通知 CPU |
| IOMMU | 设备侧地址转换与隔离 |

## 应用场景

- 磁盘 / SSD 读写
- 网卡收发包
- 声卡、显卡等高速外设数据传输
- 零拷贝(zero-copy)技术的基础

## 优点与局限

- 优点:大批量 I/O 时大幅降低 CPU 占用、提高吞吐。
- 局限:需额外硬件(DMA 控制器);存在总线竞争;编程更复杂;DMA 可绕过 CPU 直接读写内存,若被滥用/攻击存在安全风险(需 IOMMU 防护)。

## 常见误区

- DMA ≠ 中断驱动 I/O:后者由 CPU 逐字节搬运(每字节可能中断),DMA 按块搬运、结束才中断。
- DMA 仍需 CPU 初始化与收尾,并非完全脱离 CPU。
- DMA 直访内存带来安全隐患(如 Thunderclap 类攻击),故引入 IOMMU。
