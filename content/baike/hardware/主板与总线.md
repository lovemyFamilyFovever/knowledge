# 主板与总线


> 📌 **导航**：本文是 **主板与总线** 词条，属于 hardware 术语集。相关枢纽：[[CPU 缓存]]、[[CPU与处理器架构]]、[[RAID 磁盘阵列]]、[[主板与总线]]、[[内存与存储系统]]。

## 定义

**一句话定义：** 主板（Motherboard）是承载并互联 CPU、内存、存储与各类扩展卡的主电路板；总线（Bus）是这些部件之间传输数据 / 地址 / 控制信号的公共通道，其带宽与协议决定系统各部分的通信能力。

**通俗类比：** 主板像城市的交通网络——CPU 是市中心、内存是商业区、硬盘是仓库，各级总线就是连接它们的高速公路与支路，路越宽（带宽越大）车流（数据）越顺畅。

> 多义说明：本文「总线」既含 CPU 直连的高速互联（内存通道、PCIe），也含经芯片组的中低速通道；现代平台的"芯片组"多指 PCH（原"南桥"功能），"北桥"功能已并入 CPU。

## 为什么需要它

CPU、内存、显卡、存储、外设要协同，必须有一块物理基板和一组分层通道把它们连起来。主板提供插槽与供电，总线决定各部件之间数据 / 地址 / 控制信号怎么传、传多快——其带宽与拓扑直接框定整机的扩展与性能上限。

## 核心机制

- **分层互联：** 现代平台把高速设备（内存、显卡、NVMe）直连 CPU，中低速设备（SATA / USB / 网卡）经芯片组 PCH 转接，CPU 与 PCH 之间用 DMI 链路连接；内存控制器与"北桥"功能已并入 CPU。
- **总线三要素：** 带宽、位宽、传输速率，带宽 ≈ 位宽 × 速率 ÷ 8，且要扣编码开销（如 PCIe 的 128b/130b）。
- **点对点串行化：** PCIe 用高速串行 lane 取代早期并行总线，通过 x1/x4/x8/x16 灵活组合带宽。

主板核心组件：

| 组件 | 功能 |
|------|------|
| CPU 插槽 | 安装处理器（Intel LGA、AMD AM5 等） |
| 内存插槽 DIMM | 安装 RAM |
| 芯片组 PCH | 管理中低速设备与数据流通（原"南桥"） |
| PCIe 插槽 | 安装显卡、网卡、采集卡等扩展卡 |
| SATA / M.2 | 接 SATA 盘 / 走 PCIe 通道的 NVMe SSD |
| BIOS / UEFI | 负责开机自检 POST 与引导 |
| VRM 供电 | 为 CPU 提供稳定、足量的电力 |

## 具体示例

常见总线 / 接口带宽速查（注意 Gbps 与 GB/s 相差 8 倍）：

| 总线 | 用途 | 带宽（单向） |
|------|------|-------------|
| PCIe 4.0 x16 | 显卡 | ~32 GB/s（双向约 64 GB/s） |
| PCIe 4.0 x4 | NVMe SSD | ~8 GB/s |
| PCIe 5.0 x16 | 高端显卡 / NVMe | ~64 GB/s |
| DDR5 单通道 | 内存 | ~38–51 GB/s |
| USB 3.2 Gen 2 | 外设 | 10 Gbps |
| Thunderbolt 4 | 外设 / 显示 | 40 Gbps |

## 何时用与何时不用

- **选型看：** 主板决定可用 CPU 插槽、内存代际 / 容量、PCIe 版本与数量、M.2 位、供电与扩展；服务器 / 工作站要更多 PCIe 通道与内存槽，板型从 ATX（标准）、mATX（紧凑）、ITX（迷你主机）逐级缩小。
- **注意：** 主板规格与 CPU 代际绑定（插槽 / 芯片组常不跨代兼容）；扩展卡一多，PCIe 通道会被拆分降速。

## 优劣与代价

✅ 标准化（ATX 等）带来良好兼容与扩展性，直连 + 芯片组分层兼顾高速与低成本。
⚠️ 与 CPU 代际强绑定、常不跨代兼容；带宽受 PCIe 版本与通道数限制，多设备共享时会被拆分。

## 与相关概念的区别

vs [[CPU与处理器架构]]：CPU 是芯片本身，主板与总线是把 CPU、内存、外设连起来的平台与通道；vs [[内存与存储系统]]：内存通道是 CPU 直连的专用高速总线，本文的 PCIe / SATA 是通用设备总线。

## 常见误区

- 现代主板仍由"北桥 + 南桥"共同管理数据流。
- 8 Gbps 就等于 8 GB/s。
- 4.0 设备插进 3.0 插槽能跑满 4.0 带宽。

## 面试速答

> 🎯 主板 = 承载并互联 CPU/内存/扩展卡的主电路板，总线是传数据/地址/控制信号的通道：现代平台高速设备直连 CPU、中低速经 PCH（原南桥，北桥功能已并入 CPU），PCIe 用串行 lane 组带宽，带宽 ≈ 位宽 × 速率 ÷ 8 且 Gbps ≠ GB/s。
