# 主板与总线

## 主板（Motherboard）

**一句话定义：** 主板是计算机的"骨架和神经系统"，所有组件都通过它连接和通信。

**通俗类比：** 主板就像城市的交通网络——CPU是市中心，内存是商业区，硬盘是仓库，各种总线就是连接它们的公路。

### 主板核心组件

| 组件 | 功能 |
|------|------|
| CPU插槽 | 安装处理器（LGA/AM5等）|
| 内存插槽 | 安装RAM（DIMM插槽）|
| 芯片组 | 管理数据流通（南桥/北桥）|
| PCIe插槽 | 安装显卡、网卡等扩展卡 |
| SATA接口 | 连接硬盘、光驱 |
| M.2接口 | 安装NVMe固态硬盘 |
| BIOS/UEFI | 固件，开机自检和引导 |
| VRM供电 | 为CPU提供稳定电力 |

### 总线（Bus）

**定义：** 总线是计算机内部传输数据的通道。

**关键参数：**
- **带宽**：每秒能传输多少数据（GB/s）
- **位宽**：一次能传输多少位（64位/128位）
- **频率**：每秒传输次数

### 常见总线类型

| 总线 | 用途 | 带宽 |
|------|------|------|
| PCIe 4.0 x16 | 显卡 | ~64 GB/s |
| PCIe 4.0 x4 | NVMe SSD | ~8 GB/s |
| DDR5 | 内存 | ~50+ GB/s |
| USB 3.2 Gen2 | 外设 | 10 Gbps |
| Thunderbolt 4 | 外设/显示 | 40 Gbps |

### 芯片组架构

**现代架构：**
```
CPU ←→ 内存（直连，最快）
CPU ←→ PCIe（直连显卡/NVMe）
CPU ←→ 芯片组（DMI/QPI总线）
芯片组 ←→ SATA/USB/网卡/声卡
```

### 主板板型

| 板型 | 大小 | 特点 |
|------|------|------|
| E-ATX | 30.5×33cm | 顶级，扩展最多 |
| ATX | 30.5×24.4cm | 标准，最常用 |
| mATX | 24.4×24.4cm | 紧凑，性价比高 |
| ITX | 17×17cm | 迷你主机 |
