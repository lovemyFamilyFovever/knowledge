# 主板与总线


> 📌 **导航**：本文是 **主板与总线** 词条，属于 hardware 术语集。相关枢纽：[[CPU 缓存]]、[[CPU与处理器架构]]、[[RAID 磁盘阵列]]、[[主板与总线]]、[[内存与存储系统]]。

## 定义

**一句话定义：** 主板（Motherboard）是承载并互联 CPU、内存、存储与各类扩展卡的主电路板；总线（Bus）是这些部件之间传输数据/地址/控制信号的公共通道，其带宽与协议决定系统各部分的通信能力。

**通俗类比：** 主板像城市的交通网络——CPU 是市中心、内存是商业区、硬盘是仓库，各级总线就是连接它们的高速公路与支路，路越宽（带宽越大）车流（数据）越顺畅。

> 多义说明：本文「总线」既含 CPU 直连的高速互联（内存通道、PCIe），也含经芯片组的中低速通道；「芯片组」在现代平台多指 PCH（原「南桥」功能），「北桥」功能已并入 CPU。

## 原理与机制

- **分层互联**：现代平台把高速设备（内存、显卡、NVMe）直连 CPU，其余中低速设备（SATA、USB、网卡）经芯片组（PCH）转接，CPU 与 PCH 之间用 DMI（Intel）或等效链路连接。
- **总线三要素**：带宽（每秒传输量）、位宽（一次并行传输的位数）、传输速率；带宽 ≈ 位宽 × 速率 ÷ 8。
- **点对点串行化**：PCIe 用高速串行点对点链路（lane）取代早期并行总线，通过 x1/x4/x8/x16 灵活组合带宽。

## 关键组成

### 主板核心组件

| 组件 | 功能 |
|------|------|
| CPU 插槽 | 安装处理器（Intel LGA、AMD AM5 等） |
| 内存插槽(DIMM) | 安装 RAM |
| 芯片组(PCH) | 管理中低速设备与数据流通（原「南桥」） |
| PCIe 插槽 | 安装显卡、网卡、采集卡等扩展卡 |
| SATA 接口 | 连接机械硬盘 / SATA SSD / 光驱 |
| M.2 接口 | 安装 NVMe SSD（走 PCIe 通道） |
| BIOS/UEFI | 固件，负责开机自检(POST)与引导 |
| VRM 供电 | 为 CPU 提供稳定、足量的电力 |

### 常见总线/接口带宽

| 总线 | 用途 | 带宽（单向） |
|------|------|-------------|
| PCIe 4.0 x16 | 显卡 | ~32 GB/s（双向约 64 GB/s） |
| PCIe 4.0 x4 | NVMe SSD | ~8 GB/s |
| PCIe 5.0 x16 | 高端显卡/NVMe | ~64 GB/s |
| DDR5（单通道） | 内存 | ~38–51 GB/s（视数据速率） |
| USB 3.2 Gen 2 | 外设 | 10 Gbps |
| Thunderbolt 4 | 外设/显示 | 40 Gbps |

> 说明：原文档把 PCIe 4.0 x16 写作「~64 GB/s」是**双向**合计，单向约 32 GB/s。另注意单位：Gbps（千兆比特/秒）与 GB/s（吉字节/秒）相差 8 倍，且需扣除编码开销（如 PCIe 的 128b/130b），换算时勿混淆。

### 芯片组架构（现代）

```
CPU ←→ 内存            （内存控制器已并入 CPU，直连最快）
CPU ←→ PCIe x16 / NVMe （显卡与高速存储直连 CPU）
CPU ←→ 芯片组(PCH)     （经 DMI 链路）
PCH  ←→ SATA / USB / 网卡 / 声卡 / 低速 PCIe
```

### 主板板型

| 板型 | 尺寸 | 特点 |
|------|------|------|
| E-ATX | 30.5×33 cm | 顶级，扩展最多 |
| ATX | 30.5×24.4 cm | 标准，最常用 |
| mATX | 24.4×24.4 cm | 紧凑，性价比高 |
| ITX | 17×17 cm | 迷你主机 |

## 应用场景

- 装机选型：主板决定可用 CPU 插槽、内存代际/容量、PCIe 版本与数量、M.2 位、供电与扩展能力。
- 服务器/工作站需要更多 PCIe 通道与内存插槽；ITX 用于小型化主机。

## 优点与局限

- 优点：标准化（ATX 等）带来良好兼容与扩展性；直连 + 芯片组分层兼顾高速与低成本。
- 局限：主板规格与 CPU 代际绑定（插槽/芯片组常不跨代兼容）；带宽受 PCIe 版本与通道数限制，扩展卡多时通道会被拆分。

## 常见误区

- **「南桥/北桥」已过时**：北桥（内存控制器、显卡通道）早已并入 CPU，现代「芯片组」相当于原南桥（PCH）。
- **Gbps 与 GB/s 混淆**：8 Gbps ≈ 1 GB/s（还需扣编码开销），比较带宽先统一单位。
- PCIe 版本/通道向下兼容但会降速：4.0 设备插 3.0 槽按 3.0 速率工作；物理 x16 槽可能只走 x8/x4 电气通道。
