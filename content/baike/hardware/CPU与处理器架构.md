# CPU与处理器架构

## CPU（Central Processing Unit）中央处理器

**一句话定义：** CPU是计算机的"大脑"，负责执行所有指令和计算。

**通俗类比：** 如果把计算机比作一个厨房，CPU就是厨师——所有菜（程序）都要经过厨师的手（运算）才能做出来。

### 核心概念

**时钟频率（Clock Speed）**
- 定义：CPU每秒钟能执行的周期数，单位GHz
- 类比：厨师切菜的速度——频率越高，每秒切的次数越多
- 3.5GHz = 每秒35亿个周期

**核心数（Cores）**
- 定义：CPU内部独立的处理单元
- 类比：厨房里有几个厨师同时工作
- 单核=1个厨师，8核=8个厨师同时做菜
- 多核适合并行任务（视频渲染、编译代码）

**线程（Threads）**
- 定义：核心可以同时处理的指令流
- 超线程（Hyper-Threading）：一个核心模拟两个核心工作
- 类比：一个厨师同时看两个锅

### 指令执行过程

```
取指(Fetch) → 解码(Decode) → 执行(Execute) → 写回(Write Back)
```

这个循环每秒执行数十亿次。

### 缓存层级

| 层级 | 大小 | 速度 | 说明 |
|------|------|------|------|
| L1 | 32-64KB | 最快 | 每个核心独立 |
| L2 | 256KB-1MB | 很快 | 每个核心独立 |
| L3 | 4-64MB | 较快 | 所有核心共享 |
| 内存 | 8-128GB | 慢 | 主板上的RAM |
| 硬盘 | 256GB+ | 最慢 | 持久存储 |

### 处理器架构

**x86/x64（CISC）**
- 复杂指令集，Intel/AMD使用
- 一条指令可以做复杂操作
- 用于PC、服务器

**ARM（RISC）**
- 精简指令集，手机/平板使用
- 指令简单，功耗低
- Apple M系列、高通骁龙

### 关键指标对比

| 指标 | 说明 | 误区 |
|------|------|------|
| 频率 | 执行速度 | 不是越高越好，还要看架构 |
| 核心数 | 并行能力 | 不是越多越好，看使用场景 |
| 缓存 | 快速存储 | 越大越好，但成本高 |
| TDP | 散热设计功耗 | 功耗≠性能 |
| 制程 | 晶体管大小(nm) | 越小越先进，功耗越低 |
