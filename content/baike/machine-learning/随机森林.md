# 随机森林

## 定义

**一句话定义：** 随机森林(Random Forest)是一种基于 Bagging 的集成学习算法,它训练多棵在样本与特征上都引入随机性的决策树,并通过投票(分类)或平均(回归)汇总各树结果,以提升预测精度与稳定性、抑制单棵树的过拟合。

**通俗类比：** 像让一大群视角各异的评审独立判断,再取多数意见——单个评审可能有偏见或出错,但众多"互不相同"的评审综合起来,结论往往比任何单个评审都更准、更稳。

> 多义说明:随机森林是 **Bagging** 家族的代表;区别于 **Boosting**(如 GBDT,串行纠错)。本文讨论随机森林。

## 原理与机制

- **Bagging(自助采样):** 对训练集有放回地随机抽样得到多个子集,各子集训练一棵树。
- **特征随机:** 每次分裂只从随机选取的特征子集中挑最优(而非全部特征),使各树"去相关"。
- **结果汇总:** 分类取多数投票,回归取平均。
- 每棵树通常充分生长、不剪枝,靠"数量 + 随机性 + 平均"来降低方差。

## 关键组成

| 组成 | 作用 |
|------|------|
| 自助采样(bootstrap) | 生成多样化训练子集 |
| 特征随机子集 | 使树之间去相关 |
| 基决策树 | 单个弱/强学习器 |
| 聚合(投票/平均) | 汇总各树预测 |
| OOB(袋外)估计 | 无需额外验证集的泛化估计 |

## 应用场景

- 分类与回归任务
- 特征重要性评估与特征选择
- 金融风控、生物信息、表格数据建模(常作强基线)

## 优点与局限

- 优点:精度较高且稳健、抗过拟合、可评估特征重要性、能处理高维与混合特征、各树可并行训练。
- 局限:模型体积大、预测较慢;可解释性不如单棵树;对超参(树数量、特征子集大小)有一定敏感;外推能力有限。

## 常见误区

- 随机森林 ≠ 单棵决策树(集成 vs 单体)。
- 树越多通常越稳定,但边际收益递减、成本上升。
- 它抗过拟合,但并非完全免疫,仍需调参与验证。
- 与 GBDT 机制不同:随机森林是并行 Bagging,GBDT 是串行 Boosting。
