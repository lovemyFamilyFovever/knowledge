# 随机森林


> 📌 **导航**：本文是 **随机森林** 词条，属于 machine-learning 术语集。相关枢纽：[[决策树]]、[[梯度提升树]]、[[集成学习]]、[[机器学习基础]]。

## 定义

**一句话定义：** 随机森林（Random Forest）是一种基于 Bagging 的集成学习算法，训练多棵在样本与特征上都引入随机性的决策树，并通过投票（分类）或平均（回归）汇总各树结果，以提升精度与稳定性、抑制单棵树的过拟合。

**通俗类比：** 像让一大群视角各异的评审独立判断再取多数意见——单个评审可能有偏见或出错，但众多"互不相同"的评审综合起来，结论往往比任何单个都更准更稳。

> 多义说明：随机森林是 Bagging 家族的代表，区别于 Boosting（如 GBDT，串行纠错）；本文讨论随机森林。

## 为什么需要它

单棵决策树高方差、对数据敏感、易过拟合。随机森林用 Bagging——训练很多"去相关"的树再平均 / 投票，把单树方差大幅压低，得到更准更稳的模型，还顺带给出特征重要性。

## 核心机制

- **Bagging（自助采样）**：对训练集有放回地随机抽样得到多个子集，各子集训练一棵树。
- **特征随机**：每次分裂只从随机选取的特征子集中挑最优（而非全部特征），使各树"去相关"——这是随机森林强于普通 Bagging 的关键。
- **结果汇总**：分类取多数投票，回归取平均。
- 每棵树通常充分生长、不剪枝，靠"数量 + 随机性 + 平均"来降方差；OOB 袋外样本可作免验证集的泛化估计。

| 组成 | 作用 |
|------|------|
| 自助采样 bootstrap | 生成多样化训练子集 |
| 特征随机子集 | 使树之间去相关 |
| 基决策树 | 单个学习器 |
| 聚合（投票 / 平均） | 汇总各树预测 |
| OOB 袋外估计 | 无需额外验证集的泛化估计 |

## 具体示例

表格型风控、生物信息分类常把随机森林当强基线，并用其特征重要性筛选变量。树的数量增到一定量后，精度收益递减、而内存与预测成本继续上升。

## 何时用 / 何时不用

- **用**：需要稳健高精度、要特征重要性、可并行训练时。
- **换用**：要极致可解释（用单棵树）、追求最强精度（试 GBDT）、超大数据内存吃紧时。

## 优劣与代价

✅ 精度较高且稳健、抗过拟合、可评估特征重要性、处理高维混合特征、各树可并行。
⚠️ 模型体积大、预测较慢；可解释性不如单棵树。
⚠️ 对树数量、特征子集大小有一定敏感；外推能力有限。

## 与相关概念的区别

- **vs [[决策树]]**：森林是多树集成（降方差），单树可解释但高方差。
- **vs [[梯度提升树]]**：RF 并行 Bagging、各树独立、降方差；GBDT 串行 Boosting、每树拟合负梯度、降偏差，常更准但更慢更易过拟合。

## 常见误区

- 随机森林是 Boosting 方法，靠串行地让每棵树拟合前一轮的残差。
- 随机森林里树越多，精度一定持续提升且没有任何额外成本。
- 随机森林和普通 Bagging 完全一样，不需要在每次分裂时随机选取特征子集。

## 面试速答

> 🎯 随机森林=Bagging 集成的代表：对训练集有放回自助采样得到多子集各训一棵树，并在每次分裂只从随机特征子集挑最优，使各树去相关，最后分类投票/回归平均。它用「数量 + 随机 + 平均」把单棵决策树的高方差压下去，还能出特征重要性，OOB 袋外样本提供免验证集的泛化估计。与 GBDT 区别：RF 并行降方差。
> 🔍 追问：随机森林为什么比"普通 Bagging 树"更强？（额外做特征随机子集，进一步去相关、降方差）
> 🔍 追问：随机森林和 GBDT 的核心机制差异？（RF 各树独立并行、投票 / 平均降方差；GBDT 树串行拟合负梯度纠错降偏差）
