# 图像分割（语义·实例·全景）


> 📌 **导航**：本文是 **图像分割（语义·实例·全景）** 词条，属 machine-learning 术语集。相关枢纽：[[计算机视觉入门到实战]]、[[目标检测（YOLO 与 R-CNN 家族）]]、[[卷积神经网络(CNN)]]。

## 定义

**一句话定义：** 图像分割把"理解"细化到像素级——为图中每个像素分配类别标签，比目标检测的矩形框更精细；按是否区分同类个体分成语义分割、实例分割与统一两者的全景分割三类。

**通俗类比：** 检测是"用方框圈出每只猫"，分割是"沿着猫的毛边逐像素描出轮廓"——不仅知道这里有猫，还知道精确到哪几个像素。

## 为什么需要它

自动驾驶要分辨"可驶过的路面 vs 行人"、医学影像要勾出肿瘤边界、遥感要量算地物面积——这些都需要像素级精度，矩形框太粗，必须上分割。

## 核心机制

- **语义分割**：把所有像素分进预定义类别（人 / 车 / 天空 / 道路），同类不区分个体。代表：FCN（全卷积，端到端逐像素预测）、U-Net（编码器-解码器 + 跳跃连接，医学影像常用）、DeepLab（空洞卷积扩大感受野 + CRF 后处理）。
- **实例分割**：在语义之上进一步区分同类不同个体（第一只猫、第二只猫）。代表：Mask R-CNN = 在 Faster R-CNN 上加一条并行 FCN 分支，为每个检出物体预测二值掩码。
- **全景分割**：语义 + 实例的统一，对每个像素既给"stuff 类别"（天空、草地）又给"thing 实例"标注。代表：Panoptic FPN。

| 类型 | 是否区分同类个体 | 覆盖对象 | 代表模型 |
|------|----------------|---------|---------|
| 语义分割 | 否 | 所有像素 | FCN / U-Net / DeepLab |
| 实例分割 | 是 | 前景物体 | Mask R-CNN |
| 全景分割 | 是 + stuff | 全图像素 | Panoptic FPN |

## 具体示例

Mask R-CNN（`maskrcnn_resnet50_fpn`）对街景推理一次，即同时返回 boxes、labels、scores 与逐实例 masks；按分数阈值筛选后，把红色半透明掩码叠回原图，每个行人 / 车都被精确"抠"出轮廓而非仅框住。

## 何时用 / 何时不用

- **用**：需要像素级形状与边界——自动驾驶可行驶区域、医学病灶勾画、遥感地物、抠图。
- **不用**：只要"有什么 + 大致在哪"时用目标检测更轻（见 [[目标检测（YOLO 与 R-CNN 家族）]]）；只要整图类别时用分类。

## 优劣与代价

✅ 输出精确到像素，检测与分类都给不了的形状信息在此。
⚠️ 逐像素标注成本极高、训练算力大。
⚠️ 细边界、小目标、遮挡处易糊，实例 + 语义联合更易错。

## 与相关概念的区别

- **vs 目标检测**：检测输出矩形框（粗、不描边），分割输出像素掩码（细）。
- **语义 vs 实例**：语义把两只猫同色不分彼此，实例给每只猫独立掩码；全景再补上天空草地等 stuff。
- **vs 图像生成**：分割是"理解 / 判别"，生成是"造新图"（见 [[生成对抗网络(GAN)]]）。

## 常见误区

- 语义分割能够区分画面里两只不同个体的猫，各给一份掩码。
- Mask R-CNN 与 Faster R-CNN 毫无关系，是独立发明的实例分割网络。
- 全景分割只做背景 stuff 的分类，不关心前景物体是不是同一个实例。

## 面试速答

> 🎯 图像分割逐像素打标签，比检测的方框更细：语义分割分类别不区分个体（FCN/U-Net/DeepLab）、实例分割区分同类个体（Mask R-CNN 在 Faster R-CNN 上加掩码分支）、全景分割统一 thing 与 stuff（Panoptic FPN）。落点是"从框到像素"的理解深化。
> 🔍 追问：U-Net 为何适合医学分割？（编解码结构配跳跃连接，把浅层细节与深层语义融合，小样本也能出精细边界）
> 🔍 追问：实例分割和语义分割的判据差异？（是否把同一类的不同个体分开——语义合并、实例分开）
