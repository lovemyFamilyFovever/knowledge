# Dropout


> 📌 **导航**：本文是 **Dropout** 词条，属于 machine-learning 术语集。相关枢纽：[[LLM应用开发完全指南]]、[[强化学习从入门到实践]]、[[自然语言处理NLP完全指南]]、[[计算机视觉入门到实战]]。

## 定义

**一句话定义：** Dropout 是一种深度学习正则化技术,在训练时以一定概率随机"丢弃"(临时置零)一部分神经元的输出,迫使网络不依赖特定神经元、学到更鲁棒的特征,从而抑制过拟合;推理时使用全部神经元并做相应缩放。

**通俗类比：** 像一个团队故意每天随机让部分成员休假,逼剩下的人掌握彼此的技能、不把关键活儿只压在某一两个人身上——这样即使有人缺席或面对新情况,团队照样顶上,抗风险能力更强。

> 多义说明:Dropout 是正则化手段之一;有标准 Dropout、Spatial Dropout、DropConnect 等变体。本文讨论标准 Dropout。

## 原理与机制

- **训练阶段:** 每层每个神经元以概率 p 被丢弃(输出置 0),相当于每一步都在训练一个"子网络"。
- **效果:** 近似训练大量共享权重的子网络的集成(ensemble),减少神经元之间的"共适应"(co-adaptation)。
- **推理阶段:** 使用全部神经元;为保持期望一致,训练时常用 inverted dropout(保留的输出除以 1−p),推理时无需再缩放。
- **配合:** 常与批归一化、权重衰减等一起使用;p 常取 0.2 ~ 0.5。

## 关键组成

| 组成 | 说明 |
|------|------|
| 丢弃概率 p | 控制正则强度 |
| 训练时随机置零 | 每步训练一个子网络 |
| 推理时全用 | 不丢弃 |
| inverted dropout 缩放 | 训练时除以 (1−p) |
| 集成效果 | 近似多子网络平均 |

## 应用场景

- 全连接层的正则化(如经典 CNN 的分类头)
- 防止过拟合、提升泛化
- Transformer 中的注意力与前馈子层也使用 Dropout

## 优点与局限

- 优点:有效抑制过拟合、提升泛化、实现简单、近似集成效果。
- 局限:训练变慢(需更多轮次);引入随机性(结果需多次平均);p 需调参;与批归一化同时用有时冲突;在卷积层效果不如全连接层明显(可用 Spatial Dropout)。

## 常见误区

- Dropout 只在训练时启用、推理时关闭(常见 bug:推理时忘记关闭)。
- inverted dropout 使推理阶段无需再缩放。
- Dropout ≠ DropConnect(后者丢弃的是权重连接)。
- p 太大会欠拟合、太小则无效。
