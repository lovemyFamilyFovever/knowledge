# 迁移学习


> 📌 **导航**：本文是 **迁移学习** 词条，属于 machine-learning 术语集。相关枢纽：[[LLM应用开发完全指南]]、[[强化学习从入门到实践]]、[[自然语言处理NLP完全指南]]、[[计算机视觉入门到实战]]。

## 定义

**一句话定义：** 迁移学习(Transfer Learning)是把在一个任务/领域上学到的知识(如模型参数、特征表示)迁移到另一个相关但不同的任务/领域,以在新任务上更快、更好地学习;尤其在新任务数据有限时效果显著。

**通俗类比：** 像会弹钢琴的人学电子琴——乐理、指法、节奏感(已学知识)可以直接迁移,不必从零开始;只需适应少量新差异(键位/音色),上手比新手快得多。

> 多义说明:迁移学习是一种范式,常见形式有预训练 + 微调(fine-tuning)、特征抽取(冻结主干)、领域自适应;本文以深度学习的"预训练 + 微调"为主。

## 原理与机制

- **预训练:** 在大规模源数据(如 ImageNet、海量文本)上训练模型,学到通用特征/表示。
- **迁移方式:**
  - 特征抽取:冻结预训练主干,只训练新的任务头(分类器)。
  - 微调(fine-tune):用目标数据以较小学习率继续训练部分/全部层,适配新任务。
- **领域自适应:** 缩小源域与目标域的分布差异。
- **为何有效:** 底层特征(边缘、纹理、语法等)通用可复用,减少对新数据量与算力的需求。

## 关键组成

| 组成 | 说明 |
|------|------|
| 源域 / 源任务 | 知识来源 |
| 目标域 / 目标任务 | 迁移目的地 |
| 预训练模型 | 承载已学知识 |
| 特征抽取 vs 微调 | 两种迁移方式 |
| 领域差异 | 影响迁移效果 |

## 应用场景

- 图像分类/检测(用 ImageNet 预训练模型)
- NLP(BERT / GPT 预训练 + 下游微调)
- 小样本、标注稀缺场景
- 跨领域适配

## 优点与局限

- 优点:新任务收敛快、数据需求少、性能常更好、可复用大规模预训练成果。
- 局限:源与目标差异过大时可能出现负迁移(negative transfer);预训练成本高(但可复用);微调需调参(冻结哪些层、学习率);存在领域偏差。

## 常见误区

- 迁移不总是有益:源目标差异过大会导致负迁移。
- 微调 ≠ 从头训练(通常用小学习率、只调部分层)。
- 冻结主干 = 特征抽取,解冻 = 微调。
- 预训练模型越大不一定迁移越好,需与任务匹配。
