# 迁移学习


> 📌 **导航**：本文是 **迁移学习** 词条，属于 machine-learning 术语集。相关枢纽：[[微调与训练技术详解]]、[[大模型预训练技术]]、[[LLM 微调技术]]、[[机器学习基础]]。

## 定义

**一句话定义：** 迁移学习（Transfer Learning）是把在一个任务 / 领域上学到的知识（如模型参数、特征表示）迁移到另一个相关但不同的任务 / 领域，以在新任务上更快更好地学习，尤其在新任务数据有限时效果显著。

**通俗类比：** 像会弹钢琴的人学电子琴——乐理、指法、节奏感可直接迁移，不必从零开始；只需适应少量新差异（键位 / 音色），上手比新手快得多。

> 多义说明：迁移学习是一种范式，常见形式有预训练 + 微调、特征抽取（冻结主干）、领域自适应；本文以深度学习的"预训练 + 微调"为主。

## 为什么需要它

从零训练大模型要海量数据与算力，而多数新任务数据有限。迁移学习复用"在大数据上学到的通用表示"，让新任务只需少量数据、小算力即可快速达到好效果——是把预训练红利普惠化的关键范式。

## 核心机制

- **预训练**：在大规模源数据（如 ImageNet、海量文本）上训练，学到通用特征 / 表示。
- **迁移方式**：
  - 特征抽取：冻结预训练主干，只训练新的任务头（分类器）。
  - 微调（fine-tune）：用目标数据以较小学习率继续训练部分 / 全部层，适配新任务。
- **领域自适应**：缩小源域与目标域的分布差异。
- **为何有效**：底层特征（边缘、纹理、语法等）通用可复用，减少对新数据量与算力的需求。

| 组成 | 说明 |
|------|------|
| 源域 / 源任务 | 知识来源 |
| 目标域 / 目标任务 | 迁移目的地 |
| 预训练模型 | 承载已学知识 |
| 特征抽取 vs 微调 | 两种迁移方式 |
| 领域差异 | 影响迁移效果 |

## 具体示例

医学影像分类样本少：拿 ImageNet 预训练的 CNN，换掉最后分类头，冻结主干做特征抽取或小幅微调即可。NLP 里 BERT / GPT 的"预训练 + 下游微调"即此范式（高效微调见 [[LLM 微调技术]]）。

## 何时用 / 何时不用

- **用**：目标数据有限 / 标注稀缺、想省算力快速起模型，且源目标相关时。
- **慎用**：源与目标差异过大会负迁移；数据极小且与预训练领域毫不相关时收益有限。

## 优劣与代价

✅ 新任务收敛快、数据需求少、性能常更好，可复用大规模预训练成果。
⚠️ 源与目标差异过大时出现负迁移（negative transfer）。
⚠️ 预训练本身成本高（但可复用）；微调需调冻结层与学习率，并可能带入领域偏差。

## 与相关概念的区别

- **vs [[微调与训练技术详解]]**：微调把迁移落到具体技术（LoRA / QLoRA 高效微调），迁移学习是更广义范式（含特征抽取 / 领域自适应）。
- **vs [[大模型预训练技术]]**：预训练造"知识源"，迁移学习负责"搬运复用"它。

## 常见误区

- 只要用更大的预训练模型迁移到新任务，效果就一定会更好。
- 迁移学习总是正的收益，源领域和目标领域差多远都无所谓。
- 特征抽取和微调是一回事，都要解冻全部层重新训练。

## 面试速答

> 🎯 迁移学习=把在一个任务或领域学到的知识迁移到相关但不同的新任务，尤其在新任务数据有限时更快更好。主流做法是预训练 + 微调：先在大数据上预训练得到通用特征，再做特征抽取（冻结主干、只训新任务头）或微调（小学习率继续训部分层）。底层特征（边缘/纹理/语法）通用故可复用。注意差异过大会负迁移。
> 🔍 追问：特征抽取和微调的区别？（前者冻结预训练主干、只训新头；后者解冻部分 / 全部层以小学习率继续训练适配）
> 🔍 追问：什么是负迁移？（源域与目标域差异过大，迁移来的知识反成干扰、新任务效果不升反降）
