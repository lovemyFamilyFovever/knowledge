# 支持向量机


> 📌 **导航**：本文是 **支持向量机** 词条，属于 machine-learning 术语集。相关枢纽：[[机器学习基础]]、[[决策树]]、[[逻辑回归]]、[[特征缩放]]。

## 定义

**一句话定义：** 支持向量机（SVM）是一种监督学习模型，在特征空间中寻找一个最大化两类样本间隔（margin）的最优分类超平面，且该超平面仅由间隔边界上的少数"支持向量"决定，因而具有较好的泛化能力。

**通俗类比：** 像在两群人之间划一条分界线——SVM 不只要求"分开"，还要让这条线离两边的人都尽可能远（最大间隔），新来的人站哪边都不易判错；而真正决定线位置的，只是离得最近的那几个人（支持向量）。

> 多义说明：SVM 有线性与非线性（核技巧）、硬间隔与软间隔之分，还有用于回归的 SVR；本文以分类为主。

## 为什么需要它

把样本分开容易，但"分得稳"难——落在边界附近的点最易判错。SVM 用最大间隔找"离两边都尽量远"的决策边界，对噪声和新样本更稳健，尤其擅长高维小样本（文本、基因）。

## 核心机制

- **最大间隔**：在可分情况下，找到使两类最近样本间隔最大的超平面。
- **支持向量**：只有落在间隔边界上的样本决定超平面，其余不影响结果，故解稀疏稳健。
- **软间隔**：引入松弛变量与惩罚参数 C，容忍少量误分类以应对不可分与噪声（C 越大越不容错）。
- **核技巧**：用核函数（线性、多项式、RBF / 高斯）把数据隐式映射到高维实现非线性分类，而无需显式计算高维坐标。

| 组成 | 作用 |
|------|------|
| 分类超平面 | 决策边界 |
| 间隔 margin | 边界到最近样本的距离，越大越稳健 |
| 支持向量 | 决定超平面的关键样本 |
| 惩罚参数 C | 权衡间隔大小与误分类 |
| 核函数 | 实现非线性映射 |

## 具体示例

文本情感二分类（高维稀疏词特征）常用线性核或 RBF 核的 SVM；小样本图像分类也常用它。但面对百万级样本训练偏慢，且必须先做特征缩放（它基于距离 / 间隔）。

## 何时用 / 何时不用

- **用**：中小规模、高维、需要强泛化与间隔可解释的判别任务。
- **不用**：超大规模数据（深度学习 / 线性模型更快）；需要原生概率输出；特征噪声大、类重叠严重时。

## 优劣与代价

✅ 最大间隔带来良好泛化，核技巧可处理非线性，高维小样本有效。
⚠️ 大规模数据训练较慢，对参数 C、核参数敏感、需调优。
⚠️ 对噪声与类别重叠敏感；原生输出非概率（需 Platt scaling 等校准）。

## 与相关概念的区别

- **vs [[逻辑回归]]**：LR 直接输出概率、线性、大样本快；SVM 最大化间隔、靠支持向量、核化非线性更强，但需特征缩放且概率要校准。
- **vs [[决策树]]**：树不需缩放、可解释；SVM 必须缩放，边界由核决定、可解释性较弱。

## 常见误区

- SVM 只能处理线性可分的数据，无法分类非线性边界。
- SVM 训练前不必做特征缩放，因为它和决策树一样对量纲不敏感。
- SVM 的原始输出就是样本属于某类的概率。

## 面试速答

> 🎯 SVM 找特征空间中「最大化两类间隔」的分类超平面，该平面只由边界上少数支持向量决定，故稀疏稳健、泛化好。不可分或有噪声时用软间隔（松弛变量 + 惩罚参数 C）容忍少量误分，C 越大越不容错；核技巧隐式映射到高维实现非线性。适合高维小样本，但大规模训练慢、必须先特征缩放、原生输出非概率。
> 🔍 追问：核技巧解决了什么问题？（把非线性可分数据隐式映射到高维去找线性边界，避免显式高维计算）
> 🔍 追问：参数 C 的作用？（权衡"间隔尽量大"与"尽量少误分"，C 大偏向少误分、更易过拟合）
