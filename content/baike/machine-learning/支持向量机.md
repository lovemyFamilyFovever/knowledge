# 支持向量机

## 定义

**一句话定义：** 支持向量机(Support Vector Machine, SVM)是一种监督学习模型,它在特征空间中寻找一个能**最大化两类样本间隔(margin)** 的最优分类超平面,且该超平面仅由间隔边界上的少数"支持向量"决定,因而具有较好的泛化能力。

**通俗类比：** 像在两群人之间划一条分界线——SVM 不只要求"分开",还要让这条线离两边的人都尽可能远(最大间隔),这样新来的人站哪边都不容易判错;而真正决定线位置的,只是离得最近的那几个人(支持向量)。

> 多义说明:SVM 有线性与非线性(核技巧)、硬间隔与软间隔之分,还有用于回归的 SVR;本文以分类为主。

## 原理与机制

- **最大间隔:** 在可分情况下,找到使两类最近样本间隔最大的超平面。
- **支持向量:** 落在间隔边界上的样本决定超平面,其余样本不影响结果。
- **软间隔:** 引入松弛变量与惩罚参数 C,容忍少量误分类以应对不可分与噪声(C 越大越不容错)。
- **核技巧(kernel trick):** 用核函数(线性、多项式、RBF/高斯)把数据隐式映射到高维空间实现非线性分类,而无需显式计算高维坐标。

## 关键组成

| 组成 | 作用 |
|------|------|
| 分类超平面 | 决策边界 |
| 间隔(margin) | 边界到最近样本的距离,越大越稳健 |
| 支持向量 | 决定超平面的关键样本 |
| 惩罚参数 C | 权衡间隔大小与误分类 |
| 核函数 | 实现非线性映射 |

## 应用场景

- 文本分类、图像识别
- 生物信息学(如基因表达分析)
- 小样本、高维问题
- 异常检测(One-class SVM)

## 优点与局限

- 优点:最大间隔带来良好泛化;核技巧可处理非线性;在高维、小样本场景有效。
- 局限:大规模数据训练较慢;对参数(C、核参数)敏感、需调优;对噪声与类别重叠敏感;原生输出非概率(需 Platt scaling 等校准)。

## 常见误区

- "SVM 只能线性分类"是错的:核技巧使其能处理非线性边界。
- SVM 不直接输出概率值,需额外做概率校准。
- 特征缩放对 SVM 很重要(基于间隔/距离),这点与决策树不同。
