# 自然语言处理NLP完全指南


> 📌 **导航**：本文是 **自然语言处理NLP完全指南** 词条，属 machine-learning 教程枢纽。相关枢纽：[[词向量]]、[[Transformer架构深度解析]]、[[LLM应用开发完全指南]]。

## 定义

**一句话定义：** 本文是从基础原理到大模型实战的 NLP 教程，规划 6 章：文本预处理、词向量、语言模型演进、文本分类、序列标注、机器翻译，逐章配可运行代码（jieba / Word2Vec / N-gram / Transformer / BERT / BiLSTM-CRF / Seq2Seq）。

**通俗类比：** 像一门"NLP 全流程动手课"——从把文本切好、词变向量、语言模型从 n-gram 一路走到 Transformer，再落到分类、实体识别、翻译三大任务。

## 为什么需要它

零散的 NLP 概念缺一条"文本进、结果出"的主线。本教程按 pipeline 把预处理、表示、建模、下游任务串成可跑链路，并给每个环节指明该深入的专条。

## 核心流程

1. **文本预处理**：中文分词（最大匹配 / HMM·CRF / BiLSTM-CRF、jieba 精确·全·搜索三模式）、词性标注、NER 概览——详见子词条 [[文本预处理与中文分词]]。
2. **词向量**：Word2Vec（CBOW / Skip-gram）、GloVe（共现矩阵）、FastText（子词、处理未登录词），king − man + woman ≈ queen——概念详见 [[词向量]] 与 [[Embedding 技术详解]]。
3. **语言模型演进**：N-gram（马尔可夫假设 + 平滑）→ RNN LM（梯度消失 → LSTM / GRU）→ Transformer 自注意力 + 位置编码——见 [[大语言模型架构演进]]、[[Transformer架构深度解析]]、[[注意力机制]]。
4. **文本分类**：情感分析（规则 → 贝叶斯 / SVM → BERT 微调）、主题分类（LDA）——详见子词条 [[文本分类与主题模型]]。
5. **序列标注**：NER 的 BIO / BIOES 体系、BiLSTM-CRF 联合解码、词性标注——详见子词条 [[命名实体识别与序列标注]]。
6. **机器翻译**：Seq2Seq 编码器-解码器、teacher forcing、Bahdanau 注意力——详见子词条 [[序列到序列与神经机器翻译]]。

## 具体示例

"king − man + woman ≈ queen"：Word2Vec 把词映射到向量后，性别与语义关系表现为可加减的方向，是分布式语义最直观的演示；同一条链路上，BERT-CRF 又能把 "San Francisco" 整体识别为 LOC——表示层与任务层各显其能。

## 何时用 / 何时不用

- **用**：想建立"文本进 → 表示 → 任务出"的 NLP 全局主线，并定位每步该看哪篇专条。
- **不用**：当作某单点算法权威手册——本稿正文止于第 6 章注意力处截断，且代码为教学示例，工程落地需看专条与实测。

## 常见误区

- 本教程认为中文文本可以直接像英文一样按空格切词后送入模型。
- 按本教程，Word2Vec 这类静态词向量能为"苹果"在水果与手机两种语境给出不同向量。
- 本教程认为 N-gram 模型无需平滑即可覆盖所有未见过的新词组合。

## 面试速答
