# 计算机视觉入门到实战


> 📌 **导航**：本文是 **计算机视觉入门到实战** 词条，属 machine-learning 教程枢纽。相关枢纽：[[卷积神经网络(CNN)]]、[[目标检测（YOLO 与 R-CNN 家族）]]、[[自然语言处理NLP完全指南]]。

## 定义

**一句话定义：** 本文是从像素到智能的计算机视觉（CV）九部分实战教程：图像基础、经典算法、CNN 架构演进、目标检测、图像分割、图像生成、OCR、人脸识别、视频理解，逐节配 OpenCV / PyTorch / YOLO / PaddleOCR 可运行代码。

**通俗类比：** 像一条"看懂图像与视频"的进阶阶梯——先把像素讲清楚，再从手工算子走到 CNN，最后落到检测、分割、生成、识别各条任务线。

## 为什么需要它

CV 分支庞杂、模型更新快，缺一张"从表示到任务"的地图。本教程按地基 → 骨干 → 任务的顺序把九块串起来，并为每块指出该深入的专条。

## 核心流程

1. **图像基础**：像素与数字图像 `(高, 宽, 通道)`、8 位 0–255；色彩空间 RGB(OpenCV 为 BGR)/HSV/灰度；几何、空间域（直方图均衡、阈值、卷积滤波）与频率域（傅里叶低通去噪、高通锐边）变换。
2. **经典 CV 算法**：边缘（Sobel / Canny 多阶段）、特征（Harris / SIFT / ORB + 匹配）、光流（Lucas-Kanade 稀疏 / Farneback 稠密）——①②合并见子词条 [[图像基础与经典视觉算法]]。
3. **CNN 架构演进**：LeNet→AlexNet(ReLU·Dropout·GPU)→VGG(小核堆叠)→ResNet(残差短路解退化)→YOLO(检测转回归)→ViT(图像切块 + 自注意力)。演进史见 [[卷积神经网络(CNN)]]。
4. **目标检测**：两阶段（R-CNN→Fast→Faster R-CNN）与单阶段（YOLO / SSD），IoU·NMS·anchor·mAP——详见子词条 [[目标检测（YOLO 与 R-CNN 家族）]]。
5. **图像分割**：语义（FCN / U-Net / DeepLab）、实例（Mask R-CNN）、全景（Panoptic FPN）——详见子词条 [[图像分割（语义·实例·全景）]]。
6. **图像生成**：GAN（生成器 vs 判别器对抗，DCGAN / 条件 GAN / StyleGAN / CycleGAN）与扩散模型（前向加噪、反向去噪，DDPM / Stable Diffusion），后者已超 GAN 成 SOTA。见 [[生成对抗网络(GAN)]]、[[Diffusion扩散模型]]。

**注：OCR（文本检测 EAST/DBNet + 识别 CRNN + PaddleOCR）、人脸识别（检测→对齐→FaceNet/ArcFace 提特征→比对）、视频理解（动作识别、3D 卷积 C3D/I3D、时空 Transformer）三块在本教程为应用级小结，正文止于第 9 章视频理解中途截断，缺失部分不补写。**

## 具体示例

一条最小检测链：`YOLO('yolov8n.pt')` 预测街景，一次前向即得每辆车的类别、置信度与 `xyxy` 框；要精确到轮廓则换 Mask R-CNN 逐像素出掩码——"框 vs 掩码"正是检测与分割的分水岭（见 [[图像分割（语义·实例·全景）]]）。

## 与相关概念的区别

- **vs [[自然语言处理NLP完全指南]]**：NLP 处理文本序列，CV 处理图像 / 视频张量，但共享 CNN、Transformer 骨干。
- **vs 各任务专条**：检测 / 分割 / 生成专条讲透单线，本枢纽负责把九块连成图。

## 常见误区

- 目标检测不仅能给出物体的类别和位置，还能精确描出它的像素级轮廓。
- OpenCV 的 imread 读入彩色图时默认就是标准 RGB 通道顺序。
- 扩散模型训练比 GAN 更不稳定、生成质量也不如 GAN。

## 面试速答

> 🎯 CV 九部分从像素到智能：图像基础与经典算法（色彩空间 / 边缘 / 特征 / 光流）、CNN 演进（LeNet→ResNet→ViT）、检测 / 分割 / 生成三大任务、OCR / 人脸 / 视频应用。落点是从"是什么"到"在哪 · 什么形状 · 怎么动"的理解深化。
> 🔍 追问：ResNet 靠什么训到上百层？（残差短路连接让网络学"增量"而非直接映射，缓解梯度消失与退化）
> 🔍 追问：ViT 把图像怎么处理成序列？（切成固定大小 patch、展平加位置编码后送入 Transformer 多头自注意力）
