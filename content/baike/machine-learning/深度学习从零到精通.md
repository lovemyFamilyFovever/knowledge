# 深度学习从零到精通


> 📌 **导航**：本文是 **深度学习从零到精通** 词条，属 machine-learning 教程枢纽。相关枢纽：[[机器学习基础]]、[[反向传播]]、[[卷积神经网络(CNN)]]、[[梯度下降]]。

## 定义

**一句话定义：** 本文是从零实现深度学习的实战教程，分"神经网络基础"与"卷积神经网络 CNN"两大部分：手写感知机、多层前馈网络与反向传播，讲透激活函数与梯度消失 / 爆炸，再实现卷积层、池化层并梳理 LeNet→AlexNet→VGG→ResNet 架构演进。

**通俗类比：** 像"不用高层 API、纯手搓一遍"的深度学习实验手册——每个环节都从一张白纸写到能跑，逼你看清黑箱内部。

## 为什么需要它

会调框架 API ≠ 懂原理。本教程用"从零实现"逼出前向 / 反向、激活与梯度、卷积与池化的数学本质，是把 [[机器学习基础]] 的抽象概念落到可运行代码的桥梁。

## 核心流程

1. **神经网络基础**：生物→人工神经元与感知机（线性可分、解不了 XOR）→ 多层前馈网络（He 初始化、前向 + 反向传播更新）；激活函数族（sigmoid / tanh / ReLU / Leaky ReLU / ELU / softmax）引入非线性；反向传播用链式法则逐层求梯度；深网面临梯度消失 / 爆炸，靠 ReLU、梯度裁剪缓解。逐点见 [[激活函数]]、[[反向传播]]、[[梯度消失与梯度爆炸]]。
2. **卷积神经网络**：卷积层（感受野 / 步幅 / 填充，im2col 把卷积转成矩阵乘）+ 池化层（最大 / 平均下采样）→ 经典架构演进 LeNet-5→AlexNet→VGG→ResNet。CNN 原理与架构详见 [[卷积神经网络(CNN)]]。
3. **优化与训练通识**：以随机打乱 + 小批量 + 学习率迭代更新参数，梯度优化族谱见 [[梯度下降]]。

## 具体示例

XOR 是"单层感知机解不了、必须上多层 + 非线性"的最小反例：2-4-1 网络、隐藏层 tanh、输出层 sigmoid、交叉熵损失，训练约千轮即可把 4 个输入拟合到正确输出，直观演示了反向传播如何把误差逐层回传更新权重（详见 [[反向传播]]）。

## 常见误区

- 本教程认为单层感知机也能解决 XOR 这类线性不可分问题。
- 按本教程，sigmoid 因导数性质好，是越深的网络越该首选的激活函数。
- 本教程认为卷积层与全连接层没有本质区别，可以直接互相替换。

## 面试速答

> 🎯 深度学习从零教程两大部分：神经网络基础（感知机→多层前馈→反向传播，激活函数引入非线性，梯度消失/爆炸靠 ReLU 与裁剪缓解）+ CNN（卷积/池化/im2col，LeNet→AlexNet→VGG→ResNet 演进）。落点是"手搓一遍、理解黑箱"。
> 🔍 追问：为什么需要激活函数？（给网络引入非线性，否则多层线性堆叠等价于单层，拟合不了 XOR 等复杂函数）
> 🔍 追问：卷积相比全连接省在哪？（参数共享 + 局部连接，大幅减少参数并保留空间平移不变性）
