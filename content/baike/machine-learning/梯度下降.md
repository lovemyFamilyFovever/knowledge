# 梯度下降

## 定义

**一句话定义：** 梯度下降(Gradient Descent)是一种迭代式优化算法,它沿目标函数(通常是损失函数)在当前点梯度的**反方向**逐步更新参数,以逼近使损失最小的参数值,是训练机器学习与深度学习模型的基础方法。

**通俗类比：** 像蒙着眼下山——你站在山坡上想到达最低点(最小损失),每一步先用脚感受哪个方向最陡(梯度),再朝下坡方向迈一小步(学习率),反复直到脚下变平(收敛)。

> 多义说明:按每步使用的样本量,分为批量梯度下降(BGD)、随机梯度下降(SGD)与小批量梯度下降(mini-batch);本文综合讨论。

## 原理与机制

- **更新规则:** θ ← θ − η · ∇L(θ),其中 η 为学习率,∇L(θ) 为损失对参数的梯度。
- **梯度来源:** 在神经网络中由 [[反向传播]] 高效计算。
- **改进变体:** 动量(Momentum)、AdaGrad、RMSProp、Adam 等自适应方法,改善收敛速度与稳定性。
- **关键挑战:** 学习率选择、局部极小与鞍点、震荡、特征尺度不一致(需归一化)。

## 关键组成

| 要素 | 作用 |
|------|------|
| 损失函数 | 待最小化的目标 |
| 梯度 | 指示最陡上升方向,取其反向更新 |
| 学习率 η | 控制每步步长 |
| 批量大小 | 每次更新使用的样本数 |
| 优化器变体 | Momentum/Adam 等改进策略 |

## 应用场景

- 训练各类神经网络(CNN、RNN、Transformer)
- 线性回归、逻辑回归等可微模型拟合
- 大规模机器学习与深度学习的参数优化

## 优点与局限

- 优点:通用、可扩展到海量数据与参数、实现简单,是一阶优化主力。
- 局限:需调学习率;可能陷入局部极小/鞍点;收敛可能缓慢或震荡;对特征尺度敏感。

## 常见误区

- 梯度下降不保证找到全局最优(非凸问题下可能停在局部极小或鞍点)。
- 学习率并非越大越好:过大易发散,过小则收敛极慢。
- SGD 的"随机"指每步用样本子集,其引入的噪声有时反而有助跳出较差的局部极小。
