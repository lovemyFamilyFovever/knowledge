# 梯度下降


> 📌 **导航**：本文是 **梯度下降** 词条，属于 machine-learning 术语集。相关枢纽：[[反向传播]]、[[损失函数]]、[[机器学习基础]]、[[深度学习从零到精通]]。

## 定义

**一句话定义：** 梯度下降（Gradient Descent）是一种迭代式优化算法，沿目标函数（通常是损失函数）在当前点梯度的反方向逐步更新参数，以逼近使损失最小的参数值，是训练机器学习与深度学习模型的基础方法。

**通俗类比：** 像蒙着眼下山——你想走到最低点（最小损失），每步先用脚感受哪个方向最陡（梯度），再朝下坡方向迈一小步（学习率），反复直到脚下变平（收敛）。

> 多义说明：按每步使用的样本量分为批量梯度下降（BGD）、随机梯度下降（SGD）与小批量梯度下降（mini-batch）；本文综合讨论。

## 为什么需要它

参数维度成千上万、损失面复杂，无法枚举求最优。梯度下降用一个简单原则——沿损失下降最快的方向小步迭代——把"求最优"变成可计算、可并行的循环，是几乎所有可微模型训练的核心引擎。

## 核心机制

- **更新规则**：`θ ← θ − η · ∇L(θ)`，η 为学习率，∇L(θ) 为损失对参数的梯度；神经网络中梯度由 [[反向传播]] 高效计算。
- **三种批量**：BGD 用全量（稳但慢）、SGD 用单样本（快、噪声大）、mini-batch 折中（主流，可利用矩阵并行）。
- **改进变体**：Momentum 累积方向以抑制震荡；AdaGrad / RMSProp 做逐参数自适应步长；Adam 结合动量与自适应，是常用默认。
- **关键挑战**：学习率选择、局部极小与鞍点、震荡、特征尺度不一致（需归一化）。

| 要素 | 作用 |
|------|------|
| 损失函数 | 待最小化的目标 |
| 梯度 | 指示最陡上升方向，取其反向更新 |
| 学习率 η | 控制每步步长 |
| 批量大小 | 每次更新使用的样本数 |
| 优化器变体 | Momentum / Adam 等改进策略 |

## 具体示例

训练神经网络默认用 mini-batch + Adam；学习率太大会让 loss 上下震荡甚至发散、太小几乎不动，故常用 warmup + 衰减调度；特征尺度差异大时梯度会偏向某一维、收敛变慢，需先标准化。

## 何时用 / 何时不用

- **用**：任何可微目标的大规模参数优化。
- **变体选择**：凸 / 大数据可考虑二阶或 BGD，要快速与逃逸用 mini-SGD / Momentum，稀疏梯度用 AdaGrad，通用首选 Adam。

## 优劣与代价

✅ 通用、可扩展到海量数据与参数、实现简单，是一阶优化主力。
⚠️ 需调学习率，可能陷入局部极小 / 鞍点。
⚠️ 收敛可能缓慢或震荡，对特征尺度敏感。

## 与相关概念的区别

- **vs [[反向传播]]**：反向传播负责"算梯度"，梯度下降负责"用梯度更新参数"，二者配套但职责不同。
- **vs 牛顿法（二阶）**：牛顿用 Hessian 收敛快，但海量参数下算不动；梯度下降只用一阶梯度，scalable。

## 常见误区

- 梯度下降一定能收敛到损失函数的全局最小值。
- 学习率设得越大，训练一定越快越稳。
- 梯度下降更新参数不需要知道梯度，只是随机猜方向。

## 面试速答

> 🎯 梯度下降=沿损失梯度反方向迭代更新参数的基础优化算法：θ ← θ − η·∇L(θ)。按每步样本量分为 BGD/SGD/mini-batch；变体有 Momentum 抑制震荡、RMSProp 逐参数自适应步长、Adam 结合两者成常用默认。关键挑战是学习率调度、鞍点与特征尺度。别与反向传播混：后者只算梯度。
> 🔍 追问：SGD 与 mini-batch 的取舍？（SGD 更新频繁、噪声有助跳出差极小但方差大；mini-batch 折中、可矩阵并行更稳）
> 🔍 追问：Adam 为何常用？（动量 + 自适应学习率结合，对稀疏梯度与不同尺度鲁棒，少调参也能较快收敛）
