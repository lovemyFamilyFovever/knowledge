# 特征缩放


> 📌 **导航**：本文是 **特征缩放** 词条，属于 machine-learning 术语集。相关枢纽：[[K近邻算法]]、[[支持向量机]]、[[梯度下降]]、[[主成分分析]]。

## 定义

**一句话定义：** 特征缩放是一种数据预处理步骤，把不同特征的数值范围调整到相近尺度（如归一化到 [0,1] 或标准化为零均值、单位方差），避免量纲 / 取值范围差异过大主导基于距离或梯度的算法，提升收敛速度与模型效果。

**通俗类比：** 像把"身高（厘米，上百）"和"年龄（岁，几十）"放到同一把尺子上比较——否则数值大的身高会盖过年龄的影响；缩放后两者对结果的贡献才公平可比。

> 多义说明：常见方法有归一化（min-max）、标准化（z-score）、RobustScaler（用中位数 / 分位数，抗异常值）；本文综述。

## 为什么需要它

特征的物理量纲和取值范围常天差地别。对基于距离或梯度的模型，不缩放会让大数尺特征主导距离 / 梯度，导致收敛慢、效果差。特征缩放把各特征拉到相近尺度，让模型公平对待、优化更快。

## 核心机制

- **归一化（Min-Max）**：`x′ = (x − min) / (max − min)`，缩放到 [0,1]；受异常值影响大。
- **标准化（Z-score）**：`x′ = (x − μ) / σ`，变为均值 0、方差 1；不固定范围、较稳健，最常用。
- **Robust 缩放**：用中位数与四分位距（IQR），抗异常值。
- **为何有效**：距离类算法（KNN、K-means、SVM）与梯度优化（线性 / 逻辑回归、神经网络）对特征尺度敏感，缩放可加速收敛、提升效果、让正则更公平。
- **防泄露**：缩放参数（μ / σ / min / max）必须只用训练集拟合，再应用到验证 / 测试集。

| 方法 | 特点 |
|------|------|
| 归一化（Min-Max） | 缩放到 [0,1]，受异常值影响 |
| 标准化（Z-score） | 零均值单位方差，较稳健 |
| Robust 缩放 | 用中位数 / IQR，抗异常值 |
| 仅用训练集拟合 | 防止数据泄露 |

## 具体示例

逻辑回归里"收入（万级）"与"年龄（十级）"若不标准化，收入维度梯度占优、收敛慢；用 StandardScaler 在训练折上 fit、再 transform 验证集（防泄露）。KNN 不缩放则被大尺度特征主导距离。

## 何时用 / 何时不用

- **用**：KNN / K-means / SVM 等距离类、梯度类模型、PCA 等尺度敏感算法的预处理。
- **不用**：基于树的模型（决策树 / 随机森林 / GBDT）通常无需缩放——它们按分裂阈值划分，对单调缩放不敏感。

## 优劣与代价

✅ 加速收敛、提升基于距离 / 梯度算法的效果、使正则更公平。
⚠️ 对树模型通常无必要；Min-Max 受异常值影响（需 Robust）。
⚠️ 缩放参数泄露（在全量上 fit）会导致评估失真。

## 与相关概念的区别

- **vs [[过拟合与正则化]]**：缩放是预处理，只改尺度、不改特征分布形状；正则改变的是目标函数的复杂度约束。
- **vs [[支持向量机]] / [[K近邻算法]]**：这些基于距离 / 间隔，缩放前几乎必须做标准化。

## 常见误区

- 任何机器学习模型训练前都必须对特征做缩放，包括决策树和随机森林。
- 交叉验证时应在整个数据集上统一 fit 缩放器再分折，这样最省事也没问题。
- 特征缩放会改变各个特征的概率分布形状。

## 面试速答

> 🎯 特征缩放把不同量纲的特征拉到相近尺度：归一化 Min-Max→[0,1]、标准化 Z-score、Robust 用中位数/IQR（抗异常）。因为 KNN/K-means/SVM 基于距离、线性模型与神经网络基于梯度，否则大数尺特征主导、收敛慢。两条纪律：缩放参数只能用训练集 fit；树模型通常无需缩放。
> 🔍 追问：为什么交叉验证里缩放要放进每折 pipeline？（在全量 fit 会把验证折统计量泄漏进训练，评估偏乐观）
> 🔍 追问：Min-Max 和标准化谁更抗异常值？（Min-Max 极端值会把区间拉歪；标准化 / Robust 更稳，异常多时优先 Robust）
