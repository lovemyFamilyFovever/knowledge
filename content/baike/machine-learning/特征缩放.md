# 特征缩放


> 📌 **导航**：本文是 **特征缩放** 词条，属于 machine-learning 术语集。相关枢纽：[[LLM应用开发完全指南]]、[[强化学习从入门到实践]]、[[自然语言处理NLP完全指南]]、[[计算机视觉入门到实战]]。

## 定义

**一句话定义：** 特征缩放(Feature Scaling)是一种数据预处理步骤,把不同特征的数值范围调整到相近的尺度(如归一化到 [0,1] 或标准化为零均值、单位方差),以避免量纲/取值范围差异过大主导基于距离或梯度的算法,提升收敛速度与模型效果。

**通俗类比：** 像把"身高(厘米,上百)"和"年龄(岁,几十)"放到同一把尺子上比较——否则数值大的"身高"会盖过"年龄"的影响;缩放后两者对结果的贡献才公平可比。

> 多义说明:常见方法有归一化(min-max,缩放到固定区间)、标准化(z-score,零均值单位方差)、RobustScaler(用中位数/分位数,抗异常值)。本文综述。

## 原理与机制

- **归一化(Min-Max):** x′ = (x − min) / (max − min),缩放到 [0,1];受异常值影响大。
- **标准化(Z-score):** x′ = (x − μ) / σ,变为均值 0、方差 1;不固定范围,较稳健。
- **Robust 缩放:** 用中位数与四分位距(IQR),抗异常值。
- **为何需要:** 基于距离的算法(KNN、K-means、SVM)与基于梯度的优化(线性/逻辑回归、神经网络)对特征尺度敏感;缩放可加速收敛、提升效果。
- **防泄露:** 缩放参数(μ/σ/min/max)必须只用训练集拟合,再应用到验证/测试集。

## 关键组成

| 方法 | 特点 |
|------|------|
| 归一化(Min-Max) | 缩放到 [0,1],受异常值影响 |
| 标准化(Z-score) | 零均值单位方差,较稳健 |
| Robust 缩放 | 用中位数/IQR,抗异常值 |
| 仅用训练集拟合 | 防止数据泄露 |

## 应用场景

- KNN / K-means / SVM 等距离类算法
- 线性/逻辑回归与神经网络的梯度优化
- PCA 等降维
- 任何尺度敏感模型的预处理

## 优点与局限

- 优点:加速收敛、提升基于距离/梯度算法的效果、使正则更公平。
- 局限:对基于树的模型(决策树/随机森林/GBDT)通常无必要;受异常值影响(需 Robust);缩放参数泄露会导致评估失真。

## 常见误区

- 并非所有模型都需缩放(树模型基于分裂阈值,通常无需)。
- 归一化受异常值影响大(异常值多时宜用标准化或 Robust)。
- 缩放参数必须只从训练集学习,否则数据泄露。
- 缩放不改变特征分布的形状,只改变尺度。
