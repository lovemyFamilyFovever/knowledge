## 1. RL基础概念

### 1.1 什么是强化学习

强化学习（Reinforcement Learning, RL）是机器学习三大范式之一，与监督学习和无监督学习并列。它的核心思想是：**一个智能体（Agent）通过与环境（Environment）的交互，不断试错，根据获得的奖励（Reward）信号来学习最优行为策略（Policy）**。

与监督学习不同，强化学习没有明确的"正确答案"标签；与无监督学习不同，强化学习有一个明确的优化目标（最大化累积奖励）。

```
┌──────────────────────────────────────────────────┐
│                                                  │
│    Agent（智能体）                                │
│    ┌─────────────────┐                           │
│    │  策略 π(a|s)     │◄──── 状态 s_t            │
│    │  值函数 V(s)/Q   │                           │
│    │  模型 P(s',r|s,a)│                           │
│    └────────┬────────┘                           │
│             │ 动作 a_t                            │
│             ▼                                    │
│    Environment（环境）                            │
│    ┌─────────────────┐                           │
│    │  状态转移 s_{t+1}│                           │
│    │  奖励 r_t        │─────► 返回给Agent         │
│    └─────────────────┘                           │
│                                                  │
└──────────────────────────────────────────────────┘
```

### 1.2 核心五大元素

#### Agent（智能体）

Agent是强化学习中的决策主体。它通过观察环境状态，根据自身策略选择动作，并从环境获取反馈来改进决策。

**Agent的核心组件包括：**

- **策略（Policy, π）**：从状态到动作的映射，可以是确定性的（a = π(s)）或随机性的（π(a|s) = P(A_t = a | S_t = s)）
- **值函数（Value Function）**：评估状态或状态-动作对的长期价值
- **模型（Model）**：对环境动态的内部表示（可选）

```python
import numpy as np

class SimpleAgent:
    """一个简单的强化学习Agent示例"""
    
    def __init__(self, n_states, n_actions, learning_rate=0.1, gamma=0.99, epsilon=0.1):
        self.n_states = n_states
        self.n_actions = n_actions
        self.lr = learning_rate
        self.gamma = gamma
        self.epsilon = epsilon
        
        # Q表：存储每个状态-动作对的价值
        self.q_table = np.zeros((n_states, n_actions))
    
    def select_action(self, state):
        """ε-贪心策略选择动作"""
        if np.random.random() < self.epsilon:
            return np.random.randint(self.n_actions)  # 探索
        else:
            return np.argmax(self.q_table[state])  # 利用
    
    def update(self, state, action, reward, next_state, done):
        """Q-Learning更新规则"""
        if done:
            target = reward
        else:
            target = reward + self.gamma * np.max(self.q_table[next_state])
        
        self.q_table[state, action] += self.lr * (target - self.q_table[state, action])
```

#### Environment（环境）

环境是Agent交互的外部世界。它接收Agent的动作，返回新的状态和奖励信号。环境的复杂度直接决定了强化学习问题的难度。

**环境的分类：**

| 特征 | 完全可观测 | 部分可观测 |
|------|-----------|-----------|
| 离散 | 棋类游戏 | 扑克牌 |
| 连续 | 物理仿真 | 自动驾驶 |

```python
class GridWorldEnvironment:
    """一个简单的网格世界环境"""
    
    def __init__(self, grid_size=5):
        self.grid_size = grid_size
        self.agent_pos = [0, 0]
        self.goal_pos = [grid_size - 1, grid_size - 1]
        # 陷阱位置
        self.traps = [[1, 1], [2, 3], [3, 1]]
        # 上、右、下、左
        self.actions = [(-1, 0), (0, 1), (1, 0), (0, -1)]
        self.n_states = grid_size * grid_size
        self.n_actions = 4
    
    def reset(self):
        """重置环境"""
        self.agent_pos = [0, 0]
        return self._get_state()
    
    def step(self, action):
        """执行动作，返回 (next_state, reward, done, info)"""
        dx, dy = self.actions[action]
        new_x = max(0, min(self.grid_size - 1, self.agent_pos[0] + dx))
        new_y = max(0, min(self.grid_size - 1, self.agent_pos[1] + dy))
        self.agent_pos = [new_x, new_y]
        
        # 判断奖励
        if self.agent_pos == self.goal_pos:
            return self._get_state(), 10.0, True, {"reason": "reached_goal"}
        elif self.agent_pos in self.traps:
            return self._get_state(), -10.0, True, {"reason": "fell_in_trap"}
        else:
            return self._get_state(), -0.1, False, {"reason": "ongoing"}
    
    def _get_state(self):
        """将位置转换为状态索引"""
        return self.agent_pos[0] * self.grid_size + self.agent_pos[1]
    
    def render(self):
        """可视化环境"""
        grid = [['.' for _ in range(self.grid_size)] for _ in range(self.grid_size)]
        grid[self.goal_pos[0]][self.goal_pos[1]] = 'G'
        for trap in self.traps:
            grid[trap[0]][trap[1]] = 'X'
        grid[self.agent_pos[0]][self.agent_pos[1]] = 'A'
        
        print("\n" + "=" * (self.grid_size * 2 + 1))
        for row in grid:
            print("|" + " ".join(row) + "|")
        print("=" * (self.grid_size * 2 + 1))
```

#### Reward（奖励）

奖励是环境对Agent动作的即时反馈信号。奖励设计（Reward Engineering）是强化学习中最关键也最困难的环节之一。

```python
class RewardShaping:
    """奖励塑形示例：帮助Agent更快学习"""
    
    @staticmethod
    def sparse_reward(state, goal_state):
        """稀疏奖励：只有达到目标才有奖励"""
        if state == goal_state:
            return 1.0
        return 0.0
    
    @staticmethod
    def dense_reward(state, goal_state):
        """密集奖励：根据距离给予持续反馈"""
        distance = np.linalg.norm(np.array(state) - np.array(goal_state))
        return -distance  # 距离越近，惩罚越小
    
    @staticmethod
    def potential_based_shaping(state, next_state, goal_state, gamma=0.99):
        """基于势函数的奖励塑形（保证最优策略不变）"""
        def potential(s):
            return -np.linalg.norm(np.array(s) - np.array(goal_state))
        
        return gamma * potential(next_state) - potential(state)
```

**奖励设计的原则：**

1. **稀疏奖励**：简单但学习困难（如象棋中赢+1，输-1，其他0）
2. **密集奖励**：学习快但可能导致局部最优
3. **奖励塑形**：在不改变最优策略的前提下增加中间奖励
4. **内在奖励**：好奇心驱动的探索奖励

### 1.3 探索与利用的权衡（Exploration vs. Exploitation）

这是强化学习中最基本的困境：

```python
class ExplorationStrategies:
    """各种探索策略"""
    
    @staticmethod
    def epsilon_greedy(q_values, epsilon=0.1):
        """ε-贪心：最简单的探索策略"""
        if np.random.random() < epsilon:
            return np.random.randint(len(q_values))
        return np.argmax(q_values)
    
    @staticmethod
    def boltzmann_exploration(q_values, temperature=1.0):
        """玻尔兹曼探索（Softmax）：根据Q值概率选择"""
        exp_values = np.exp(q_values / temperature)
        probabilities = exp_values / np.sum(exp_values)
        return np.random.choice(len(q_values), p=probabilities)
    
    @staticmethod
    def ucb(q_values, counts, c=2.0, t=1):
        """上置信界（UCB）：平衡探索和利用"""
        ucb_values = q_values + c * np.sqrt(np.log(t) / (counts + 1e-10))
        return np.argmax(ucb_values)
    
    @staticmethod
    def thompson_sampling(successes, failures):
        """汤普森采样：贝叶斯方法"""
        samples = np.random.beta(successes + 1, failures + 1)
        return np.argmax(samples)
```

## 2. 马尔可夫决策过程（MDP）

### 2.1 MDP的数学定义

马尔可夫决策过程是强化学习问题的数学框架。一个MDP由五元组定义：

$$\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, P, R, \gamma \rangle$$

- **S**：状态空间（State Space）
- **A**：动作空间（Action Space）
- **P**：状态转移概率 $P(s'|s,a)$
- **R**：奖励函数 $R(s,a,s')$
- **γ**：折扣因子（Discount Factor），$0 \leq \gamma \leq 1$

### 2.2 马尔可夫性质

马尔可夫性质（Markov Property）是MDP的核心假设：

$$P(S_{t+1} | S_t, A_t, S_{t-1}, A_{t-1}, ..., S_0, A_0) = P(S_{t+1} | S_t, A_t)$$

**即：未来只依赖于现在，与过去无关。**

```python
import numpy as np

class MarkovDecisionProcess:
    """MDP的完整实现"""
    
    def __init__(self, n_states, n_actions, gamma=0.99):
        self.n_states = n_states
        self.n_actions = n_actions
        self.gamma = gamma
        
        # 状态转移概率: P[s][a] = [(prob, next_state), ...]
        self.P = {s: {a: [] for a in range(n_actions)} for s in range(n_states)}
        
        # 奖励函数: R[s][a] = [(reward, next_state, prob), ...]
        self.R = np.zeros((n_states, n_actions, n_states))
    
    def add_transition(self, state, action, next_state, reward, probability):
        """添加状态转移"""
        self.P[state][action].append((probability, next_state))
        self.R[state, action, next_state] = reward
    
    def get_expected_reward(self, state, action):
        """计算在(s,a)下的期望奖励"""
        expected_r = 0
        for prob, next_state in self.P[state][action]:
            expected_r += prob * self.R[state, action, next_state]
        return expected_r
    
    def get_transition_matrix(self, action):
        """获取特定动作的转移概率矩阵"""
        T = np.zeros((self.n_states, self.n_states))
        for s in range(self.n_states):
            for prob, next_s in self.P[s][action]:
                T[s][next_s] = prob
        return T


# 示例：构建一个简单的MDP（3状态，2动作）
def build_example_mdp():
    mdp = MarkovDecisionProcess(n_states=3, n_actions=2, gamma=0.9)
    
    # 状态0，动作0 → 80%概率到状态1（奖励+1），20%概率到状态2（奖励+0）
    mdp.add_transition(0, 0, 1, reward=1.0, probability=0.8)
    mdp.add_transition(0, 0, 2, reward=0.0, probability=0.2)
    
    # 状态0，动作1 → 50%概率到状态2（奖励+2），50%概率停留在状态0（奖励-1）
    mdp.add_transition(0, 1, 2, reward=2.0, probability=0.5)
    mdp.add_transition(0, 1, 0, reward=-1.0, probability=0.5)
    
    # 状态1，动作0 → 100%概率到状态2（奖励+5）
    mdp.add_transition(1, 0, 2, reward=5.0, probability=1.0)
    
    # 状态1，动作1 → 100%概率回到状态0（奖励+0）
    mdp.add_transition(1, 1, 0, reward=0.0, probability=1.0)
    
    # 状态2是终止状态
    mdp.add_transition(2, 0, 2, reward=0.0, probability=1.0)
    mdp.add_transition(2, 1, 2, reward=0.0, probability=1.0)
    
    return mdp

mdp = build_example_mdp()
print(f"在状态0选择动作0的期望奖励: {mdp.get_expected_reward(0, 0):.2f}")
```

### 2.3 回报（Return）与折扣因子

Agent的目标是最大化累积奖励（回报）：

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + ... = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

折扣因子 γ 的作用：
- **γ = 0**：只关注即时奖励（近视）
- **γ = 1**：完全关注长期奖励（远视，可能导致无穷大）
- **γ = 0.99**：常见值，平衡短期和长期

```python
def compute_return(rewards, gamma=0.99):
    """计算折扣回报"""
    G = 0
    returns = []
    for r in reversed(rewards):
        G = r + gamma * G
        returns.insert(0, G)
    return returns

# 示例
rewards = [1, 1, 1, 1, 1, 10]
gamma = 0.9
returns = compute_return(rewards, gamma)
print(f"奖励序列: {rewards}")
print(f"回报序列: {[f'{g:.2f}' for g in returns]}")
# 输出：回报序列: ['13.42', '13.80', '14.33', '14.93', '15.59', '10.00']
```

### 2.4 策略（Policy）

策略是从状态到动作概率分布的映射：

- **确定性策略**：$a = \pi(s)$
- **随机策略**：$\pi(a|s) = P(A_t = a | S_t = s)$

```python
class Policy:
    """策略基类"""
    
    def __init__(self, n_states, n_actions):
        self.n_states = n_states
        self.n_actions = n_actions
    
    def select_action(self, state):
        raise NotImplementedError

class RandomPolicy(Policy):
    """随机策略"""
    def select_action(self, state):
        return np.random.randint(self.n_actions)

class EpsilonGreedyPolicy(Policy):
    """ε-贪心策略"""
    def __init__(self, n_states, n_actions, q_table, epsilon=0.1):
        super().__init__(n_states, n_actions)
        self.q_table = q_table
        self.epsilon = epsilon
    
    def select_action(self, state):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.n_actions)
        return np.argmax(self.q_table[state])

class SoftmaxPolicy(Policy):
    """Softmax策略"""
    def __init__(self, n_states, n_actions, q_table, temperature=1.0):
        super().__init__(n_states, n_actions)
        self.q_table = q_table
        self.temperature = temperature
    
    def select_action(self, state):
        q_values = self.q_table[state] / self.temperature
        exp_q = np.exp(q_values - np.max(q_values))
        probs = exp_q / np.sum(exp_q)
        return np.random.choice(self.n_actions, p=probs)
```

### 2.5 部分可观测MDP（POMDP）

现实世界中，Agent往往无法完全观测环境状态，这就引入了POMDP：

$$\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, P, R, \Omega, O, \gamma \rangle$$

新增：
- **Ω**：观测空间
- **O**：观测函数 $O(o|s',a)$

```python
class POMDP:
    """部分可观测MDP示例"""
    
    def __init__(self, n_states, n_actions, n_observations):
        self.n_states = n_states
        self.n_actions = n_actions
        self.n_observations = n_observations
        
        # 观测函数: O[observation][state] = P(observation | state)
        self.O = np.random.dirichlet(
            np.ones(n_observations), 
            size=n_states
        ).T  # shape: (n_observations, n_states)
        
        # 信念状态（Belief State）：对真实状态的概率分布
        self.belief = np.ones(n_states) / n_states
    
    def update_belief(self, observation, action, transition_matrix):
        """贝叶斯更新信念状态"""
        # 预测步: b'(s') = Σ_s P(s'|s,a) * b(s)
        predicted_belief = transition_matrix.T @ self.belief
        
        # 更新步: b''(s') ∝ O(o|s') * b'(s')
        updated_belief = self.O[observation] * predicted_belief
        
        # 归一化
        if np.sum(updated_belief) > 0:
            updated_belief /= np.sum(updated_belief)
        
        self.belief = updated_belief
        return self.belief
    
    def get_most_likely_state(self):
        """获取最可能的状态"""
        return np.argmax(self.belief)
```

## 3. 值函数和贝尔曼方程

### 3.1 状态值函数（State Value Function）

状态值函数 $V^\pi(s)$ 表示在策略 π 下，从状态 s 出发的期望回报：

$$V^\pi(s) = \mathbb{E}_\pi[G_t | S_t = s] = \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1} | S_t = s\right]$$

### 3.2 动作值函数（Action Value Function）

动作值函数 $Q^\pi(s,a)$ 表示在策略 π 下，从状态 s 执行动作 a 后的期望回报：

$$Q^\pi(s,a) = \mathbb{E}_\pi[G_t | S_t = s, A_t = a]$$

两者的关系：

$$V^\pi(s) = \sum_{a} \pi(a|s) Q^\pi(s,a)$$

$$Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s')$$

### 3.3 贝尔曼期望方程（Bellman Expectation Equation）

**状态值函数的贝尔曼方程：**

$$V^\pi(s) = \sum_{a} \pi(a|s) \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s') \right]$$

**动作值函数的贝尔曼方程：**

$$Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \sum_{a'} \pi(a'|s') Q^\pi(s',a')$$

```python
import numpy as np

class ValueIteration:
    """值迭代算法：通过贝尔曼方程求解最优值函数"""
    
    def __init__(self, mdp, threshold=1e-6):
        self.mdp = mdp
        self.threshold = threshold
        self.V = np.zeros(mdp.n_states)  # 初始化值函数
    
    def evaluate_policy(self, policy, max_iterations=1000):
        """策略评估：计算给定策略的值函数"""
        V = np.zeros(self.mdp.n_states)
        
        for i in range(max_iterations):
            V_new = np.zeros_like(V)
            delta = 0
            
            for s in range(self.mdp.n_states):
                for a in range(self.mdp.n_actions):
                    action_prob = policy[s, a]
                    if action_prob > 0:
                        expected_value = 0
                        for prob, next_s in self.mdp.P[s][a]:
                            reward = self.mdp.R[s, a, next_s]
                            expected_value += prob * (reward + self.mdp.gamma * V[next_s])
                        V_new[s] += action_prob * expected_value
                
                delta = max(delta, abs(V_new[s] - V[s]))
            
            V = V_new
            
            if delta < self.threshold:
                print(f"策略评估在第 {i+1} 次迭代后收敛")
                break
        
        return V
    
    def value_iteration(self, max_iterations=1000):
        """值迭代算法"""
        V = np.zeros(self.mdp.n_states)
        
        for i in range(max_iterations):
            V_new = np.zeros_like(V)
            delta = 0
            
            for s in range(self.mdp.n_states):
                q_values = []
                for a in range(self.mdp.n_actions):
                    q = 0
                    for prob, next_s in self.mdp.P[s][a]:
                        reward = self.mdp.R[s, a, next_s]
                        q += prob * (reward + self.mdp.gamma * V[next_s])
                    q_values.append(q)
                
                V_new[s] = max(q_values)
                delta = max(delta, abs(V_new[s] - V[s]))
            
            V = V_new
            
            if delta < self.threshold:
                print(f"值迭代在第 {i+1} 次迭代后收敛")
                break
        
        self.V = V
        return V
    
    def extract_policy(self, V):
        """从值函数中提取最优策略"""
        policy = np.zeros((self.mdp.n_states, self.mdp.n_actions))
        
        for s in range(self.mdp.n_states):
            q_values = []
            for a in range(self.mdp.n_actions):
                q = 0
                for prob, next_s in self.mdp.P[s][a]:
                    reward = self.mdp.R[s, a, next_s]
                    q += prob * (reward + self.mdp.gamma * V[next_s])
                q_values.append(q)
            
            best_action = np.argmax(q_values)
            policy[s, best_action] = 1.0
        
        return policy


# 使用示例

print(f"最优值函数: {optimal_V}")
```

### 3.4 贝尔曼最优方程（Bellman Optimality Equation）

最优值函数满足：

$$V^*(s) = \max_{a} \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s') \right]$$

$$Q^*(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \max_{a'} Q^*(s',a')$$

### 3.5 策略迭代（Policy Iteration）

策略迭代包含两个交替进行的步骤：策略评估和策略改进。

```python
class PolicyIteration:
    """策略迭代算法"""
    
    def __init__(self, mdp, threshold=1e-6):
        self.mdp = mdp
        self.threshold = threshold
    
    def solve(self, max_iterations=100):
        n_states = self.mdp.n_states
        n_actions = self.mdp.n_actions
        
        # 初始化为均匀随机策略
        policy = np.ones((n_states, n_actions)) / n_actions
        
        for iteration in range(max_iterations):
            # 步骤1: 策略评估
            V = self._policy_evaluation(policy)
            
            # 步骤2: 策略改进
            new_policy = self._policy_improvement(V)
            
            # 检查策略是否改变
            if np.allclose(policy, new_policy):
                print(f"策略迭代在第 {iteration + 1} 次迭代后收敛")
                break
            
            policy = new_policy
        
        return policy, V
    
    def _policy_evaluation(self, policy, max_eval_iter=1000):
        """策略评估"""
        V = np.zeros(self.mdp.n_states)
        
        for _ in range(max_eval_iter):
            V_new = np.zeros_like(V)
            delta = 0
            
            for s in range(self.mdp.n_states):
                for a in range(self.mdp.n_actions):
                    for prob, next_s in self.mdp.P[s][a]:
                        reward = self.mdp.R[s, a, next_s]
                        V_new[s] += policy[s, a] * prob * (reward + self.mdp.gamma * V[next_s])
                
                delta = max(delta, abs(V_new[s] - V[s]))
            
            V = V_new
            if delta < self.threshold:
                break
        
        return V
    
    def _policy_improvement(self, V):
        """策略改进"""
        n_states = self.mdp.n_states
        n_actions = self.mdp.n_actions
        new_policy = np.zeros((n_states, n_actions))
        
        for s in range(n_states):
            q_values = np.zeros(n_actions)
            for a in range(n_actions):
                for prob, next_s in self.mdp.P[s][a]:
                    reward = self.mdp.R[s, a, next_s]
                    q_values[a] += prob * (reward + self.mdp.gamma * V[next_s])
            
            # 选择最优动作
            best_action = np.argmax(q_values)
            new_policy[s, best_action] = 1.0
        
        return new_policy
```

## 4. Q-Learning

### 4.1 算法原理

Q-Learning是一种无模型（Model-Free）的离策略（Off-Policy）算法。它直接学习最优动作值函数 $Q^*$，而不需要知道环境的转移概率。

**更新公式：**

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \max_{a} Q(S_{t+1}, a) - Q(S_t, A_t) \right]$$

其中：
- $\alpha$：学习率
- $\gamma$：折扣因子
- $R_{t+1} + \gamma \max_{a} Q(S_{t+1}, a)$：TD目标（TD Target）
- $R_{t+1} + \gamma \max_{a} Q(S_{t+1}, a) - Q(S_t, A_t)$：TD误差（TD Error）

### 4.2 完整实现

import numpy as np
import matplotlib.pyplot as plt
from collections import defaultdict

class QLearningAgent:
    """Q-Learning完整实现"""
    
    def __init__(self, n_states, n_actions, 
                 learning_rate=0.1, 
                 gamma=0.99, 
                 epsilon=1.0, 
                 epsilon_min=0.01, 
                 epsilon_decay=0.995):
        self.n_states = n_states
        self.n_actions = n_actions
        self.lr = learning_rate
        self.gamma = gamma
        self.epsilon = epsilon
        self.epsilon_min = epsilon_min
        self.epsilon_decay = epsilon_decay
        
        # 使用defaultdict处理未见过的状态
        self.q_table = defaultdict(lambda: np.zeros(n_actions))
        
        # 训练统计
        self.training_rewards = []
        self.training_steps = []
    
    def select_action(self, state):
        """ε-贪心策略"""
        if np.random.random() < self.epsilon:
            return np.random.randint(self.n_actions)
        return int(np.argmax(self.q_table[state]))
    
    def update(self, state, action, reward, next_state, done):
        """Q-Learning更新"""
        if done:
            td_target = reward
        else:
            td_target = reward + self.gamma * np.max(self.q_table[next_state])
        
        td_error = td_target - self.q_table[state][action]
        self.q_table[state][action] += self.lr * td_error
        
        return td_error
    
    def decay_epsilon(self):
        """衰减探索率"""
        self.epsilon = max(self.epsilon_min, self.epsilon * self.epsilon_decay)
    
    def train(self, env, n_episodes=1000, max_steps=200, verbose=True):
        """训练循环"""
        for episode in range(n_episodes):
            state = env.reset()
            total_reward = 0
            steps = 0
            
            for step in range(max_steps):
                action = self.select_action(state)
                next_state, reward, done, info = env.step(action)
                
                self.update(state, action, reward, next_state, done)
                
                state = next_state
                total_reward += reward
                steps += 1
                
                if done:
                    break
            
            self.decay_epsilon()
            self.training_rewards.append(total_reward)
            self.training_steps.append(steps)
            
            if verbose and (episode + 1) % 100 == 0:
                avg_reward = np.mean(self.training_rewards[-100:])
                print(f"Episode {episode + 1}/{n_episodes} | "
                      f"Avg Reward: {avg_reward:.2f} | "
                      f"Epsilon: {self.epsilon:.3f}")
        
        return self.training_rewards
