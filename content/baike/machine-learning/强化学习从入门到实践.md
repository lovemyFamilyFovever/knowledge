# 强化学习从入门到实践


> 📌 **导航**：本文是 **强化学习从入门到实践** 词条，属 machine-learning 教程枢纽。相关枢纽：[[强化学习基础]]、[[深度强化学习]]、[[LLM应用开发完全指南]]。

## 定义

**一句话定义：** 本文是"从基础理论到前沿实战"的强化学习（RL）长篇教程，规划 12 章：从 RL 概念、MDP、值函数与贝尔曼方程，到 Q-Learning、DQN、策略梯度、Actor-Critic，再到多智能体、Model-Based、RLHF 与 Gymnasium 实战。

**通俗类比：** 像一门"RL 从会走到跑"的实操课——每章配一个可跑的 Python 环境 / Agent，从网格世界一路训到游戏智能体。

## 为什么需要它

[[强化学习基础]] 给的是"是什么"的概念地图，但要动手训 agent，还需把 MDP 求解、TD 更新、探索率衰减、用网络替换查表等环节逐段落地。本教程正填补"概念 → 能跑代码"这段工程落差。

## 核心流程

教程按"建模 → 求解 → 学习 → 深度化 → 前沿应用"递进；**原文实际展开到第 4 章代码处即截断，第 5–12 章仅见于目录、正文缺失（不补写）**。

1. **RL 基础概念**：Agent-环境交互循环，五大元素（策略 π、值函数 V/Q、模型 P、状态、动作、奖励）；探索与利用的权衡（ε-greedy / 玻尔兹曼 / UCB / 汤普森采样）；算法按值函数、策略、Actor-Critic、Model-Based、多智能体分类。概念详见 [[强化学习基础]]。
2. **马尔可夫决策过程（MDP）**：五元组 ⟨S, A, P, R, γ⟩ 与"未来只依赖现在"的马尔可夫性质；折扣回报 G、确定性与随机策略；扩展到部分可观测的 POMDP 与信念状态更新。
3. **值函数与贝尔曼方程**：V 与 Q 的相互递归、贝尔曼期望方程与最优方程；在已知模型时用动态规划求解——详见子词条 [[值迭代与策略迭代]]。
4. **Q-Learning**：无模型、离策略的 TD 控制，更新式"Q(s,a) 加上学习率乘 TD 误差（即时奖励 + 折扣后下一状态最大 Q − 当前 Q）"，配 ε-贪心与探索率衰减，用一张表逼近最优动作价值；概念见 [[强化学习基础]]。
5. **深度化与前沿应用（目录列出、正文缺失）**：DQN、策略梯度、Actor-Critic、多智能体、Model-Based、RLHF、各领域应用与 Gymnasium 实战——深度方法见 [[深度强化学习]]，RLHF 见 [[LLM 微调技术]]。

## 具体示例

网格世界：状态 = 格子坐标、动作 = 上下左右、到目标 +10 / 落陷阱 −10 / 每步 −0.1；用 Q-Learning 反复跑 episode、探索率 ε 从 1.0 指数衰减到 0.01，Q 表逐渐收敛出一条绕开陷阱的最短路径——把"探索 → 利用 → 收敛"完整演示了一遍。

## 何时用 / 何时不用

- **用**：想从概念推进到"能自己写训练循环"时的实现级参考，配合 Gymnasium 动手。
- **不用**：当作算法综述权威教材——本稿正文在第 4 章代码处截断、5–12 章缺失，代码亦为教学示例，工业级实现需另行核验。

## 与相关概念的区别

- **vs [[强化学习基础]]**：基础条讲"有哪些方法、为何这样取舍"，本篇讲"每一步代码怎么写"。
- **vs [[深度强化学习]]**：本篇前半是表格型 / DP 的经典 RL，深条才是神经网络近似后的现代 RL。
- **vs [[值迭代与策略迭代]]**：DP 假设已知环境模型（规划），Q-Learning 则从无交互数据中学习。

## 常见误区

- 本教程认为值迭代和 Q-Learning 完全一样，都不需要环境的转移模型。
- 按本教程，折扣因子 γ=1 时任何 MDP 的回报都保证收敛、不会发散。
- 本教程主张奖励设计无关紧要，随便给稀疏奖励也能训出好策略。

## 面试速答

> 🎯 强化学习实战教程主线：把序贯决策建成 MDP（S/A/P/R/γ）→ 已知模型用动态规划（值迭代 / 策略迭代）→ 无模型用 Q-Learning（TD + ε-贪心）→ 深度化用 DQN / 策略梯度 / Actor-Critic → 前沿到 RLHF 与游戏实战。
> 🔍 追问：规划(planning)和学习(learning)的分界？（规划假设有可用模型可离线推演，学习无模型、只能靠真实交互样本）
> 🔍 追问：为什么需要折扣因子 γ？（把无限期回报折成有限值、并让 agent 权衡即时与远期）
