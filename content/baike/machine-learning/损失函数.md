# 损失函数


> 📌 **导航**：本文是 **损失函数** 词条，属于 machine-learning 术语集。相关枢纽：[[梯度下降]]、[[反向传播]]、[[过拟合与正则化]]、[[激活函数]]。

## 定义

**一句话定义：** 损失函数（Loss / 代价 / 目标函数）衡量模型预测值与真实值之间的差异，是训练中被最小化的目标；优化器（如梯度下降）依据损失对参数的梯度更新模型，使预测越来越准。

**通俗类比：** 像考试的"扣分规则"——每道题错得越离谱扣分越多，总分（损失）越高说明模型越差；训练就是不断调整做法，让总扣分最小。

> 多义说明：损失函数（单样本）、代价函数（常指全体样本平均损失）、目标函数（可能 = 损失 + 正则项）常被混用；本文统称并说明区别。

## 为什么需要它

要让机器"自动变好"，必须先把"预测有多差"写成一个可求导的数——损失函数就是优化的靶子，给出梯度方向，模型才能沿它下降。没有可微损失，就没有梯度下降。

## 核心机制

- **回归常用**：均方误差 MSE / L2（对异常值敏感）、平均绝对误差 MAE / L1（更鲁棒）、Huber（二者折中，尾部线性）。
- **分类常用**：交叉熵 / 对数损失（配 Sigmoid 二分类或 Softmax 多分类）、Hinge loss（SVM 间隔最大化）。
- **与优化的关系**：训练即最小化目标函数（常 = 损失 + 正则项），靠梯度下降 + 反向传播求梯度并更新参数。
- **选择依据**：任务类型、类别是否均衡（加权 / Focal Loss）、对异常值的敏感度、是否需要概率输出。

| 组成 | 说明 |
|------|------|
| 预测值与真实值 | 损失的输入 |
| 损失度量 | MSE / 交叉熵 / Hinge 等 |
| 正则项 | 惩罚复杂度（可选） |
| 优化目标 | 最小化损失 |
| 梯度 | 指导参数更新方向 |

## 具体示例

房价回归用 MSE，但少量天价豪宅会因平方而拉爆误差，故改用 MAE / Huber；图像分类用 Softmax + 交叉熵，类别极不平衡时改加权交叉熵或 Focal Loss；目标检测把分类损失与定位损失加权组合成一个总损失。

## 何时用 / 何时不用

- **用**：一切需要可微优化目标的监督 / 自监督训练。
- **设计要点**：损失要匹配任务与数据分布——类别不平衡、异常值、多目标都要针对性处理或加权。

## 优劣与代价

✅ 把"学得好不好"量化为可优化的数值，指导参数更新。
⚠️ 损失选错会直接导致差模型，且代理损失可能与真实评测指标不一致。
⚠️ 类别不均衡 / 异常值需特殊损失，多目标需调权平衡。

## 与相关概念的区别

- **vs [[激活函数]]**：激活决定神经元输出，损失决定优化靶子。
- **vs 评估指标（准确率 / AUC）**：损失必须可微用于优化，指标常不可微、仅用于评估。
- **vs [[过拟合与正则化]]**：目标函数 = 损失 + 正则，正则项负责控制复杂度。

## 常见误区

- 训练时可以直接把"分类准确率"当作损失函数用梯度下降优化。
- 无论是否有异常值，回归任务都应一律用 MSE，因为它对离群点很鲁棒。
- 交叉熵与 MSE 作为分类损失完全等价，用哪个都一样。

## 面试速答

> 🎯 损失函数量化「预测 vs 真值」的差距，是训练中被最小化的可微目标。常用：回归 MSE（对异常敏感）/MAE（鲁棒）/Huber（折中），分类交叉熵、Hinge（SVM）；目标函数常 = 损失 + 正则。要点：损失必须可微，准确率往往不可微、不能直接当损失；分类用交叉熵而非 MSE，与 Softmax 搭配梯度更友好。
> 🔍 追问：为什么分类用交叉熵而不是 MSE？（配合 Softmax / Sigmoid 时交叉熵梯度形式更简单、避免梯度变慢，MSE 易饱和）
> 🔍 追问：MSE 与 MAE 对异常值的表现有何不同？（MSE 平方放大误差、被离群点主导；MAE 线性、更鲁棒）
