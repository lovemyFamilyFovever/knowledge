# 损失函数


> 📌 **导航**：本文是 **损失函数** 词条，属于 machine-learning 术语集。相关枢纽：[[LLM应用开发完全指南]]、[[强化学习从入门到实践]]、[[自然语言处理NLP完全指南]]、[[计算机视觉入门到实战]]。

## 定义

**一句话定义：** 损失函数(Loss Function,又称代价函数/目标函数)用于衡量模型预测值与真实值之间的差异,是训练过程中被最小化的目标;优化器(如梯度下降)依据损失对参数的梯度来更新模型,使预测越来越准。

**通俗类比：** 像考试的"扣分规则"——每道题错得越离谱扣分越多,总分(损失)越高说明模型越差;训练就是不断调整做法,让总扣分最小。

> 多义说明:损失函数(单个样本)、代价函数(cost,常指全体样本的平均损失)、目标函数(objective,可能 = 损失 + 正则项)常被混用;本文统称并说明区别。

## 原理与机制

- **回归常用:** 均方误差 MSE / L2(对异常值敏感)、平均绝对误差 MAE / L1(更鲁棒)、Huber(二者折中)。
- **分类常用:** 交叉熵(cross-entropy)/ 对数损失(配合 Softmax / Sigmoid)、Hinge loss(SVM)。
- **与优化的关系:** 训练即最小化损失(常加正则项),用梯度下降 + 反向传播求梯度并更新参数。
- **选择依据:** 任务类型、类别是否均衡(用加权 / Focal Loss)、对异常值的敏感度、是否需要概率输出。

## 关键组成

| 组成 | 说明 |
|------|------|
| 预测值与真实值 | 损失的输入 |
| 损失度量 | MSE / 交叉熵 / Hinge 等 |
| 正则项 | 惩罚复杂度(可选) |
| 优化目标 | 最小化损失 |
| 梯度 | 指导参数更新方向 |

## 应用场景

- 各类监督学习的训练目标
- 回归、分类、排序任务
- 目标检测(多损失组合)
- 深度学习端到端训练

## 优点与局限

- 优点:把"学得好不好"量化为可优化的数值,指导参数更新。
- 局限:损失设计影响很大(不合适的损失 → 差模型);代理损失与真实目标可能不一致;类别不均衡/异常值需特殊损失;多目标需加权平衡。

## 常见误区

- 损失 ≠ 准确率:损失可微、用于优化;准确率不可微、仅用于评估。
- MSE 对异常值敏感,回归可考虑 MAE / Huber。
- 分类通常用交叉熵而非 MSE(与激活搭配后梯度性质更好)。
- 目标函数常 = 损失 + 正则,不只是拟合误差。
