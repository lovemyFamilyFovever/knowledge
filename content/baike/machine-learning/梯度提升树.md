# 梯度提升树


> 📌 **导航**：本文是 **梯度提升树** 词条，属于 machine-learning 术语集。相关枢纽：[[决策树]]、[[随机森林]]、[[集成学习]]、[[梯度下降]]。

## 定义

**一句话定义：** 梯度提升树（GBDT）是一种 Boosting 集成方法，它串行训练多棵决策树（通常是 CART 回归树），每棵新树去拟合前面模型预测的负梯度（残差方向），逐步累加纠正误差，最终得到强预测器。

**通俗类比：** 像一轮轮改作文——第一版写完（第一棵树），老师指出问题（残差 / 负梯度），下一版专门针对这些问题改进（下一棵树），如此反复叠加，每轮都在纠正上一轮的不足，越改越好。

> 多义说明：GBDT 是梯度提升以决策树为基学习器的形式，XGBoost、LightGBM、CatBoost 是其高效工程实现；区别于随机森林（Bagging，并行）。

## 为什么需要它

单棵树精度有限、易过拟合。GBDT 用 Boosting——串行地让每棵新树专攻前面模型还犯的错（拟合负梯度），一点点累积纠错，把弱树堆成强预测器，是表格数据上的常胜模型。

## 核心机制

- **前向分步**：模型 = 初始预测 + Σ（各棵树的加权和）。
- **每轮迭代**：计算当前损失对预测值的负梯度（近似残差），用一棵 CART 拟合该负梯度，再以较小学习率（shrinkage）加入模型。
- **正则化**：学习率、树数量、树深度、行 / 列子采样；XGBoost 进一步引入二阶导数与显式正则项。
- **损失函数**：支持回归（平方损失）、分类（对数损失）、排序（如 LambdaMART）等。

| 组成 | 作用 |
|------|------|
| 基学习器（CART 回归树） | 单棵弱学习器 |
| 负梯度 / 残差拟合 | 每棵树纠正的方向 |
| 学习率 shrinkage | 缩小每棵树贡献，提升稳健性 |
| 树数量 | 迭代轮数 |
| 正则与子采样 | 抑制过拟合 |

## 具体示例

风控评分、CTR 预估等表格任务常以 XGBoost / LightGBM 取胜；实践中用较小学习率（如 0.1）配更多棵树更稳；即便做分类，基树仍是回归树（拟合连续负梯度值）。

## 何时用 / 何时不用

- **用**：结构化 / 表格数据、追求高精度、需要特征重要性分析时。
- **不用 / 换用**：超大规模需极致并行或对非结构化（图像、语音）建模时深度学习更合适；可解释性要求极高时改用单棵树。

## 优劣与代价

✅ 精度高（表格数据上常为最强），灵活支持多种损失，可输出特征重要性。
⚠️ 串行训练较慢、难并行（XGBoost / LightGBM 有工程优化）。
⚠️ 易过拟合、对超参敏感、可解释性不如单棵树。

## 与相关概念的区别

- **vs [[随机森林]]**：RF 是 Bagging——多树独立并行训练再平均 / 投票，主要降方差；GBDT 是 Boosting——串行、每树拟合负梯度纠错，主要降偏差。
- **vs [[决策树]]**：GBDT 以 CART 为基学习器堆叠增强。

## 常见误区

- 梯度提升树和随机森林是同一类方法，都是并行训练多棵树再投票。
- GBDT 做分类任务时，它的基学习器一定是分类树。
- GBDT 的学习率越大越好，因为能让每棵树贡献更强、收敛更快。

## 面试速答

> 🎯 GBDT=Boosting 集成：串行训练多棵 CART 回归树，每棵新树拟合「当前模型损失对预测的负梯度」、以小学习率累加纠正，逐步把弱树堆成强预测器（如 XGBoost）。与随机森林相反：RF 是 Bagging（并行、投票、降方差），GBDT 是 Boosting（串行、纠错、降偏差）。
> 🔍 追问：为什么基树用回归树即使做分类？（拟合的是连续负梯度值，本质是回归；最后再映射到类别）
> 🔍 追问：XGBoost 相比传统 GBDT 增强了什么？（二阶泰勒展开更准、显式正则项控复杂度，并做并行与稀疏感知等工程加速）
