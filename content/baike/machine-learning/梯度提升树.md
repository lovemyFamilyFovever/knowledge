# 梯度提升树


> 📌 **导航**：本文是 **梯度提升树** 词条，属于 machine-learning 术语集。相关枢纽：[[LLM应用开发完全指南]]、[[强化学习从入门到实践]]、[[自然语言处理NLP完全指南]]、[[计算机视觉入门到实战]]。

## 定义

**一句话定义：** 梯度提升树(Gradient Boosting Decision Tree, GBDT)是一种 Boosting 集成方法,它**串行**训练多棵决策树(通常是 CART 回归树),每棵新树去拟合前面模型预测的负梯度(残差方向),逐步累加纠正误差,最终得到强预测器。

**通俗类比：** 像一轮轮改作文——第一版写完(第一棵树),老师指出问题(残差/负梯度),下一版专门针对这些问题改进(下一棵树),如此反复叠加,每轮都在纠正上一轮的不足,越改越好。

> 多义说明:GBDT 是梯度提升(Gradient Boosting)以决策树为基学习器的形式;XGBoost、LightGBM、CatBoost 是其高效工程实现。区别于随机森林(Bagging,并行)。

## 原理与机制

- **前向分步(forward stagewise):** 模型 = 初始预测 + Σ(各棵树的加权和)。
- **每轮迭代:** 计算当前损失对预测值的负梯度(近似残差),用一棵 CART 拟合该负梯度,再以较小的学习率(shrinkage)加入模型。
- **正则化:** 学习率、树数量、树深度、行/列子采样;XGBoost 进一步引入二阶导数与显式正则项。
- **损失函数:** 支持回归(平方损失)、分类(对数损失)、排序(如 LambdaMART)等。

## 关键组成

| 组成 | 作用 |
|------|------|
| 基学习器(CART 回归树) | 单棵弱学习器 |
| 负梯度 / 残差拟合 | 每棵树纠正的方向 |
| 学习率(shrinkage) | 缩小每棵树的贡献,提升稳健性 |
| 树数量 | 迭代轮数 |
| 正则与子采样 | 抑制过拟合 |

## 应用场景

- 结构化/表格数据建模(竞赛与工业界常胜方法)
- 风控评分、点击率(CTR)预估
- 排序任务(LambdaMART)
- 特征重要性分析

## 优点与局限

- 优点:精度高(表格数据上常为最强);灵活支持多种损失;可输出特征重要性。
- 局限:串行训练较慢、难并行(LightGBM/XGBoost 有优化);易过拟合、需调参;对超参敏感;可解释性不如单棵树。

## 常见误区

- GBDT ≠ 随机森林:前者串行纠错(Boosting),后者并行投票(Bagging)。
- GBDT 的基树通常是回归树,即使做分类任务。
- 学习率并非越大越好:小学习率 + 更多树通常更稳更好。
