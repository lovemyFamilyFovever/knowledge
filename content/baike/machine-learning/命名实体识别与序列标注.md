# 命名实体识别与序列标注


> 📌 **导航**：本文是 **命名实体识别与序列标注** 词条，属 machine-learning 术语集。相关枢纽：[[自然语言处理NLP完全指南]]、[[BERT模型详解]]、[[文本预处理与中文分词]]。

## 定义

**一句话定义：** 序列标注是给句子里每个 token 打一个类别标签的任务，命名实体识别（NER）是其最典型应用——从文本中定位并分类人名、地名、机构名等实体，主流范式是"逐字打分网络 + CRF 转移约束"的 BiLSTM-CRF / BERT-CRF。

**通俗类比：** 像给句子逐字"贴彩色标签"：把属于"人名"的字涂红、"地名"涂蓝、其余留白，还要保证红标签不会莫名其妙从中间断开——CRF 就是管"标签前后能不能相连"的那条规则。

## 为什么需要它

信息抽取、知识图谱、问答与检索都要先"认出实体"。序列标注把词性、实体、语义角色等一大类"给每个 token 分类"的任务统一建模，是理解下游 NLP 的基础任务骨架。

## 核心机制

- **标注体系 BIO / BIOES**：B-（实体开始）、I-（实体内部）、O（非实体），细化再加 S（单字实体）、E（实体结束），用边界标签把"跨多字的实体"编码成逐标签问题。
- **编码层**：BiLSTM（或 BERT）双向读句，为每个位置输出对各标签的打分（emission）。
- **CRF 层**：在打分之上建模"标签之间的转移约束"（如 I-PER 不能直接跟在 O 后），对整条标签序列联合评分，用维特比解码取全局最优路径——避免逐点 argmax 产生非法标签组合。
- **方法演进**：规则 / 词典 → 统计（HMM、最大熵、CRF）→ 深度（BiLSTM-CRF）→ 预训练（BERT-CRF 微调）。词性标注是同框架的另一序列标注任务。

| 阶段 | 代表方法 | 关键点 |
|------|---------|--------|
| 传统 | 规则 + 词典 | 可解释、难扩展 |
| 统计 | CRF / SVM | 特征工程 + 转移约束 |
| 深度 | BiLSTM-CRF | 自动特征 + 联合解码 |
| 预训练 | BERT-CRF | 迁移上下文表示 |

## 具体示例

CoNLL-2003 用 PER / LOC / ORG / MISC 四类，以 BIO 编码。对"Apple is opening a store in San Francisco"，BERT-CRF 会给 Apple→B-ORG、San→B-LOC、Francisco→I-LOC、其余→O，CRF 保证 I-LOC 紧跟 B-LOC 形成完整实体"San Francisco"。

## 何时用 / 何时不用

- **用**：需要从非结构文本抽实体、做知识图谱 / 检索增强 / 结构化入库时；词性、语义角色等 token 级分类同理。
- **不用**：只需要文档级判断（分类 / 情感倾向）时用分类模型即可，无需逐 token 标注；实体类型极少且固定时，词典匹配可能比训练模型更省。

## 优劣与代价

✅ 一次前向即产出全句结构化的实体 / 标签，可端到端微调。
⚠️ 强依赖标注语料，领域迁移（医学 / 金融实体）成本高。
⚠️ CRF 联合解码比逐点分类略慢，但显著减少非法标签序列。

## 与相关概念的区别

- **vs 文本分类**：分类给"整篇 / 整句"一个标签，序列标注给"每个 token"一个标签（粒度不同，见 [[文本分类与主题模型]]）。
- **vs 词性标注**：同为序列标注框架，只是标签集不同。
- **vs 分词**：中文分词也可写成 BMES 序列标注，三者共用 BiLSTM-CRF 骨架（见 [[文本预处理与中文分词]]）。

## 常见误区

- 序列标注就是逐个字独立做 softmax，标签之间彼此没有约束。
- BIO 里的 O 表示"这个词是其他类型的实体"，而不是非实体。
- 加了 CRF 层之后，模型只能对每个位置单独取最大分标签，无法考虑相邻标签合法性。

## 面试速答

> 🎯 序列标注给每个 token 打标签，NER 是其代表（识别人名地名机构等）。主流是 BiLSTM-CRF / BERT-CRF：编码层逐字打分，CRF 层建模标签转移约束、维特比联合解码，避免非法标签序列；标注用 BIO/BIOES。CoNLL-2003 四类实体是经典基准。
> 🔍 追问：CRF 相比逐点 softmax 强在哪？（引入标签间转移约束、对整条序列联合评分，抑制"B-PER 后接 I-LOC"之类非法跳变）
> 🔍 追问：为什么用 BIO 而不直接多分类？（B/I 边界编码让跨字实体可被拼回，直接分类无法表示实体范围）
