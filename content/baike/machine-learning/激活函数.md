# 激活函数


> 📌 **导航**：本文是 **激活函数** 词条，属于 machine-learning 术语集。相关枢纽：[[反向传播]]、[[梯度消失与梯度爆炸]]、[[深度学习从零到精通]]、[[Transformer架构深度解析]]。

## 定义

**一句话定义：** 激活函数是神经网络中作用于神经元加权输入的函数，它为网络引入非线性，使多层网络能逼近任意复杂函数；若没有激活（或仅用线性），再多层也等价于单层线性变换。

**通俗类比：** 像电路里的开关 / 调光器——决定"信号多大才触发、触发后输出多少"，把输入按非线性规则转换；正是这种"非直通"的转换让网络能表达复杂的决策边界。

> 多义说明：常见激活有 Sigmoid、Tanh、ReLU 及其变体（Leaky ReLU、ELU、GELU），以及用于多分类输出的 Softmax；本文综述。

## 为什么需要它

没有非线性，再多层线性变换也会塌缩成一层，网络只能画直线边界。激活函数在每层塞入非线性，才让深层网络逼近任意复杂函数——它是表达能力的开关。

## 核心机制

- **为何需要非线性**：线性函数的复合仍是线性，无法拟合非线性关系；激活函数提供非线性表达能力。
- **常见函数**：
  - Sigmoid `σ(x)=1/(1+e^(−x))`，输出 (0,1)，曾用于二分类输出，易梯度消失、非零中心。
  - Tanh，输出 (−1,1)，零中心，仍存在梯度消失。
  - ReLU `max(0,x)`，计算快、缓解梯度消失，但有"神经元死亡"（Dead ReLU）问题。
  - Leaky ReLU / PReLU / ELU / GELU：改进 ReLU 负半轴行为。
  - Softmax：把向量转为概率分布，用于多分类输出层。

| 函数 | 值域 | 特点 |
|------|------|------|
| Sigmoid | (0,1) | 概率输出；易梯度消失、非零中心 |
| Tanh | (−1,1) | 零中心；仍梯度消失 |
| ReLU | [0,+∞) | 高效、缓解消失；可能神经元死亡 |
| GELU / ELU | 视定义 | 平滑，常用于 Transformer |
| Softmax | (0,1) 且和为 1 | 多分类概率输出 |

## 具体示例

隐藏层现代默认 ReLU / GELU（Transformer 常用 GELU）；二分类或多标签输出用 Sigmoid、多分类输出用 Softmax；隐藏层几乎不再用 Sigmoid（深层梯度消失）。

## 何时用 / 何时不用

- **用**：几乎每个隐藏层都需要非线性激活。
- **选择**：隐藏层用 ReLU / GELU 系；输出层按任务选——Sigmoid（二分类 / 多标签）、Softmax（多分类）。深层隐藏慎用 Sigmoid / Tanh。

## 优劣与代价

✅ 引入非线性；ReLU 类计算高效并缓解梯度消失。
⚠️ Sigmoid / Tanh 在深层易梯度消失；ReLU 可能神经元死亡。
⚠️ 选择不当会影响收敛与精度，输出层激活需匹配任务类型。

## 与相关概念的区别

- **vs [[梯度消失与梯度爆炸]]**：饱和激活（Sigmoid / Tanh）是梯度消失的主因之一，ReLU / GELU 缓解它。
- **vs [[反向传播]]**：激活的导数进入反向传播链式相乘，决定梯度能否有效回传。

## 常见误区

- 神经网络去掉激活函数、只用很多层线性变换，照样能拟合任意复杂函数。
- ReLU 因为处处高效，绝不会出现"死亡神经元"问题。
- Sigmoid 是当下深层网络隐藏层首选的激活函数。

## 面试速答

> 🎯 激活函数给神经网络注入非线性：没有它，多层线性变换会塌缩成一层。常见有 Sigmoid（隐藏层易梯度消失且非零中心）、Tanh（零中心、仍消失）、ReLU max(0,x)（缓解消失但负区恒 0 致死亡神经元）、GELU/ELU（改进负半轴）、Softmax。经验是隐藏层用 ReLU/GELU 系。
> 🔍 追问：为什么隐藏层现在很少用 Sigmoid？（深层饱和使梯度逐层缩小 → 消失，且非零中心，ReLU 类更稳更快）
> 🔍 追问：Softmax 与 Sigmoid 分别用在什么输出？（Softmax 多类互斥归一，Sigmoid 二分类 / 多标签各自独立概率）
