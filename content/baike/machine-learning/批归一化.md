# 批归一化


> 📌 **导航**：本文是 **批归一化** 词条，属于 machine-learning 术语集。相关枢纽：[[LLM应用开发完全指南]]、[[强化学习从入门到实践]]、[[自然语言处理NLP完全指南]]、[[计算机视觉入门到实战]]。

## 定义

**一句话定义：** 批归一化(Batch Normalization, BN)是深度学习中在每层输入上,利用当前小批量数据的均值与方差做标准化、再经可学习的缩放与平移变换的技术,用以稳定各层输入分布、加速收敛,并有一定正则效果。

**通俗类比：** 像每道工序前先把半成品的规格统一校准到标准范围——避免上一步的偏差被层层放大,后续加工更平稳、更快;同时保留"要不要按标准来、偏移多少"的可调旋钮(γ、β),让网络自己学习。

> 多义说明:BN 是归一化技术之一;同类还有 LayerNorm(层归一化,常用于 NLP/Transformer)、InstanceNorm、GroupNorm。本文以 BN 为主并对比。

## 原理与机制

- **计算:** 对每个小批量,沿 batch 维计算某层激活的均值 μ 与方差 σ²,做标准化 x̂ = (x − μ) / √(σ² + ε),再仿射变换 y = γ·x̂ + β(γ、β 可学习,以恢复表达能力)。
- **作用:** 缓解"内部协变量偏移"(internal covariate shift),使损失曲面更平滑,从而可用更大学习率。
- **训练 vs 推理:** 训练用当前批统计量;推理用训练期间累积的移动平均(running mean / var)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 批均值 / 方差 | 当前小批量的统计量 |
| 标准化 | 减均值除标准差 |
| 可学习参数 γ / β | 缩放与平移,恢复表达能力 |
| ε | 防止除零 |
| 滑动平均 | 推理时使用的统计量 |

## 应用场景

- 深度卷积网络(如 ResNet)
- 加速训练收敛、允许更高学习率
- 轻微正则(可减少对 Dropout 的依赖)

## 优点与局限

- 优点:加速收敛、缓解梯度问题、对初始化不敏感、有正则效果。
- 局限:依赖批量大小(小批量效果差);训练/推理统计量不一致需谨慎;对变长序列(NLP)不友好(故 Transformer 多用 LayerNorm);分布式训练需同步统计量。

## 常见误区

- BN ≠ LayerNorm:BN 沿 batch 维、LN 沿特征维;LN 不依赖批大小,更适合 RNN/Transformer。
- 训练与推理行为不同(推理用滑动平均)。
- BN 不能完全替代 Dropout。
- 批量太小时 BN 不稳定。
