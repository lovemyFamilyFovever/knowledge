# 批归一化


> 📌 **导航**：本文是 **批归一化** 词条，属于 machine-learning 术语集。相关枢纽：[[反向传播]]、[[激活函数]]、[[梯度下降]]、[[Dropout]]。

## 定义

**一句话定义：** 批归一化（Batch Normalization, BN）在深度学习中对每层输入用小批量数据的均值与方差做标准化、再经可学习的缩放与平移变换，用以稳定各层输入分布、加速收敛，并有一定正则效果。

**通俗类比：** 像每道工序前先把半成品规格统一校准到标准范围——避免上一步的偏差被层层放大，后续加工更平稳更快；同时保留"按多少标准来、偏移多少"的可调旋钮（γ、β），让网络自己学。

> 多义说明：BN 是归一化技术之一，同类还有 LayerNorm（常用于 NLP / Transformer）、InstanceNorm、GroupNorm；本文以 BN 为主并对比。

## 为什么需要它

深层网络逐层变换会让每层输入分布不断漂移、梯度不稳、收敛慢。BN 在每层把激活拉回稳定分布、再用可学习的 γ / β 保留表达力，使训练更快更稳，还能用更大的学习率。

## 核心机制

- **计算**：对每个小批量沿 batch 维计算某层激活的均值 μ 与方差 σ²，标准化 `x̂ = (x − μ) / √(σ² + ε)`，再仿射 `y = γ·x̂ + β`（γ、β 可学习，用于恢复表达能力）。
- **作用**：缓解"内部协变量偏移"、使损失曲面更平滑，从而可用更大学习率、加速收敛。
- **训练 vs 推理**：训练用当前批的统计量；推理用训练期间累积的移动平均（running mean / var）——这是最易踩的坑。

| 组成 | 说明 |
|------|------|
| 批均值 / 方差 | 当前小批量的统计量 |
| 标准化 | 减均值除标准差 |
| 可学习 γ / β | 缩放与平移，恢复表达力 |
| ε | 防止除零 |
| 滑动平均 | 推理时使用的统计量 |

## 具体示例

ResNet 等卷积网络常在 conv 之后、激活之前插入 BN，明显加快收敛。但 batch=1~2 时批统计噪声大、BN 效果差，需更大 batch 或改用 GroupNorm / InstanceNorm；而 Transformer 因序列变长不用 BN，改用 LayerNorm。

## 何时用 / 何时不用

- **用**：CNN / 全连接网络、批量不太小时。
- **不用 / 换用**：RNN 与 Transformer（变长序列）用 LayerNorm；极小 batch 下 BN 不稳；推理分布与训练差异大时滑动平均会失准。

## 优劣与代价

✅ 加速收敛、缓解梯度问题、对初始化更鲁棒、带轻微正则。
⚠️ 依赖批大小（小批量效果差），且训练 / 推理统计不一致需谨慎。
⚠️ 分布式训练需同步统计量，对变长序列不友好。

## 与相关概念的区别

- **vs LayerNorm**：BN 沿 batch 维归一（依赖批、适合 CNN），LN 沿特征维归一（不依赖批、适合 RNN / Transformer）。
- **vs Dropout**：BN 稳分布提收敛，Dropout 抗过拟合，二者不同、BN 不能完全替代 Dropout。
- **vs 输入层特征缩放**：BN 作用在每层的激活上，而非只在输入。

## 常见误区

- 批归一化在推理阶段仍使用当前测试批的均值和方差来归一化。
- 批归一化和 LayerNorm 完全相同，都是沿特征维做归一化。
- 批大小越小，批归一化的效果就越稳定越好。

## 面试速答

> 🎯 批归一化在每层对小批量激活做「标准化 + 可学习仿射」：沿 batch 维算 μ/σ²，标准化后 y=γ·x̂+β，稳定各层输入分布，从而加速收敛。关键易错点：训练用当前批统计、推理用累积的移动平均。与 LayerNorm 不同——BN 沿 batch 维、LN 沿特征维，故 Transformer 多用 LN。
> 🔍 追问：BN 训练与推理为何要区别对待？（推理常是单样本、无批统计，用训练期滑动平均以保持分布一致）
> 🔍 追问：为什么 Transformer 用 LayerNorm 而非 BatchNorm？（序列变长、BN 的 batch 维统计不稳；LN 逐样本沿特征维归一、不依赖 batch）
