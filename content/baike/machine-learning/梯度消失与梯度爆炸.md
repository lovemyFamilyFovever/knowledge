# 梯度消失与梯度爆炸


> 📌 **导航**：本文是 **梯度消失与梯度爆炸** 词条，属于 machine-learning 术语集。相关枢纽：[[LLM应用开发完全指南]]、[[强化学习从入门到实践]]、[[自然语言处理NLP完全指南]]、[[计算机视觉入门到实战]]。

## 定义

**一句话定义：** 梯度消失与梯度爆炸是训练深层神经网络时,误差梯度在反向传播中逐层连乘而变得极小(消失)或极大(爆炸)的现象;前者导致浅层参数几乎不更新,后者导致训练发散(数值溢出),是深度网络难以训练的核心障碍。

**通俗类比：** 像多层传话游戏——每传一层信息都打个折(梯度 < 1 连乘 → 消失,传到最后几乎为零,前面的人收不到反馈);或者每层都在放大(梯度 > 1 连乘 → 爆炸,越传越夸张,最后失控)。

> 多义说明:二者是同一"梯度连乘"问题的两个极端;本文合并讲解成因与对策。

## 原理与机制

- **成因:** 反向传播中梯度是逐层雅可比/权重的连乘;若这些因子普遍 < 1,连乘趋于 0(消失);普遍 > 1,连乘趋于无穷(爆炸)。
- **易发场景:** 深层网络;Sigmoid / Tanh 激活(饱和区导数接近 0 → 消失);RNN 长序列(时间步连乘)。
- **缓解梯度消失:** ReLU 类激活、残差连接(ResNet)、批归一化、合适的初始化(Xavier / He)、LSTM / GRU(RNN 门控)。
- **缓解梯度爆炸:** 梯度裁剪(gradient clipping)、合适初始化、归一化、降低学习率。

## 关键组成

| 因素 | 作用 |
|------|------|
| 梯度连乘 | 问题根源 |
| 激活函数饱和 | Sigmoid/Tanh 易致消失 |
| 残差连接 | 让梯度跨层直达 |
| 批归一化 | 稳定各层分布 |
| 合适初始化 | Xavier / He |
| 梯度裁剪 | 抑制爆炸 |

## 应用场景

- 深层 CNN / ResNet 训练
- RNN / LSTM 序列建模
- Transformer(残差 + 归一化)
- 任何深度网络的稳定训练

## 优点与局限

- (对策)优点:使深层网络可训练、稳定收敛。
- 局限:需组合多种技术;调参复杂;不同架构对策不同;极深网络仍有挑战。

## 常见误区

- 梯度消失 ≠ 梯度爆炸(一为趋 0、一为发散),但同源(连乘)。
- ReLU 缓解消失,但可能"神经元死亡"。
- 残差连接让梯度可"跳过"层直达浅层。
- 梯度裁剪主要治爆炸,对消失作用有限;初始化不当是常见诱因。
