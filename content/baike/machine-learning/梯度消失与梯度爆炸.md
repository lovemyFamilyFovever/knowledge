# 梯度消失与梯度爆炸


> 📌 **导航**：本文是 **梯度消失与梯度爆炸** 词条，属于 machine-learning 术语集。相关枢纽：[[反向传播]]、[[激活函数]]、[[批归一化]]、[[梯度下降]]。

## 定义

**一句话定义：** 梯度消失与梯度爆炸是训练深层网络时，误差梯度在反向传播中逐层连乘而变得极小（消失）或极大（爆炸）的现象；前者使浅层参数几乎不更新，后者使训练发散（数值溢出），是深度网络难以训练的核心障碍。

**通俗类比：** 像多层传话游戏——每传一层信息都打个折（梯度 < 1 连乘 → 消失，传到最后几乎为零，前面的人收不到反馈）；或每层都在放大（梯度 > 1 连乘 → 爆炸，越传越夸张，最后失控）。

> 多义说明：二者是同一"梯度连乘"问题的两个极端；本文合并讲解成因与对策。

## 为什么需要它

网络越深越能表达复杂函数，但反向传播的逐层连乘会让梯度趋 0 或爆掉——这是深网难训的头号障碍。理解并治理它，才能把网络做深、做稳。

## 核心机制

- **成因**：反向传播中梯度是逐层雅可比 / 权重的连乘；若这些因子普遍 < 1，连乘趋于 0（消失）；普遍 > 1，连乘趋于无穷（爆炸）。
- **易发场景**：深层网络；Sigmoid / Tanh 激活（饱和区导数接近 0 → 消失）；RNN 长序列（时间步连乘）。
- **缓解梯度消失**：ReLU 类激活、残差连接（ResNet）、批归一化、合适的初始化（Xavier / He）、LSTM / GRU（RNN 门控）。
- **缓解梯度爆炸**：梯度裁剪（gradient clipping）、合适初始化、归一化、降低学习率。

| 因素 | 作用 |
|------|------|
| 梯度连乘 | 问题根源 |
| 激活函数饱和 | Sigmoid / Tanh 易致消失 |
| 残差连接 | 让梯度跨层直达 |
| 批归一化 | 稳定各层分布 |
| 合适初始化 | Xavier / He |
| 梯度裁剪 | 抑制爆炸 |

## 具体示例

很深的 CNN 若用 sigmoid 会"前面层几乎不学"，改用 ReLU + 批归一化 + 残差（ResNet）即可训到几十上百层；RNN 处理长句出现梯度爆炸时，用梯度裁剪 + 换成 LSTM 来稳住。

## 何时用 / 何时不用

- **用（对策组合）**：训练深层 CNN / RNN / Transformer 时，ReLU + 残差 + 归一化 + 合理初始化 + 裁剪已是标配。
- **注意**：梯度裁剪主要治爆炸、对消失作用有限；ReLU 缓解消失但可能"神经元死亡"（可换 LeakyReLU / GELU）。

## 优劣与代价

✅ 一整套对策（残差 + 归一 + ReLU + 好初始化 + 裁剪）使深层网络可训、收敛稳定。
⚠️ 需组合多种技术，调参复杂，不同架构对策不同。
⚠️ 极深网络下挑战依旧存在。

## 与相关概念的区别

- **vs [[反向传播]]**：反向传播是"算梯度"的机制，梯度消失 / 爆炸是它在深层连乘下暴露的"病"。
- **vs [[激活函数]]**：Sigmoid / Tanh 饱和易致消失，ReLU 缓解但可能神经元死亡。

## 常见误区

- 梯度裁剪既能有效解决梯度爆炸，也能同样有效地解决梯度消失。
- 只要网络层数足够深，就绝不会遇到梯度消失或爆炸问题。
- 把激活从 Sigmoid 换成 ReLU，就完全不会再有任何梯度相关问题。

## 面试速答

> 🎯 梯度消失/爆炸是深层网络反向传播中「逐层连乘」造成的两极：连乘因子普遍 <1 则梯度趋 0、浅层几乎不更新，普遍 >1 则梯度爆炸甚至溢出，RNN 长序列尤甚。治消失靠 ReLU 类激活、残差连接、批归一化、合理初始化、LSTM/GRU 门控；治爆炸主要用梯度裁剪与降学习率。裁剪对消失有限。
> 🔍 追问：为什么残差连接能缓解梯度消失？（恒等 shortcut 让梯度有一条"不连乘衰减"的直路传回浅层）
> 🔍 追问：梯度爆炸最直接的应急手段？（梯度裁剪——超阈值就按范数缩放梯度，只改步长不改方向）
