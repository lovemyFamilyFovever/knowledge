# 图像基础与经典视觉算法


> 📌 **导航**：本文是 **图像基础与经典视觉算法** 词条，属 machine-learning 术语集。相关枢纽：[[计算机视觉入门到实战]]、[[目标检测（YOLO 与 R-CNN 家族）]]、[[卷积神经网络(CNN)]]。

## 定义

**一句话定义：** 本文合并计算机视觉的两大"前深度学习"地基——图像基础（像素矩阵表示、色彩空间、几何 / 空间域 / 频率域变换）与经典视觉算法（边缘检测、特征点与描述子、光流），它们靠手工数学设计而非学习，至今仍是预处理与轻量任务的主力。

**通俗类比：** 像是"相机与画笔时代的手艺"——在神经网络登场前，工程师用导数、角点、频域这些数学工具，硬是把图像一步步"算"出结构与运动。

## 为什么需要它

深度模型吃进去的仍是像素张量，色彩空间选错、没去噪、增强做反都会拖垮结果；而边缘 / 特征 / 光流这些经典算子可解释、免训练、算力省，在小样本或实时预处理场景无可替代，也是理解 CNN 卷积来路的钥匙。

## 核心机制

- **图像表示与色彩空间**：数字图像是 `(高, 宽, 通道)` 张量、8 位每通道 0–255；RGB（OpenCV 默认 BGR）、HSV / HSL（按色相·饱和度·亮度，抗光照、利颜色分割）、灰度（单通道、边缘检测输入）。
- **图像变换**：几何（缩放 / 旋转 / 平移 / 仿射 / 透视，做增强与校正）；空间域点运算（直方图均衡增对比、阈值化二值）与邻域卷积（滤波、模糊、锐化）；频率域傅里叶变换——低频平坦、高频边缘与噪声，可低通去噪、高通锐边。
- **边缘检测**：Sobel 求水平 / 垂直一阶导；Canny 多阶段（高斯滤波→计算梯度→非极大值抑制→双阈值与边缘连接），公认性能最优。
- **特征点与描述子**：Harris 角点、SIFT（尺度 / 旋转 / 光照不变）、ORB（FAST 角点 + BRIEF 描述子，快且免费）；配 BFMatcher 汉明距离做跨图匹配，服务拼接、识别、三维重建。
- **光流**：像素随时间的运动矢量，稀疏用 Lucas-Kanade、稠密用 Farneback，是视频分析基础。

| 任务 | 代表方法 | 典型用途 |
|------|---------|---------|
| 边缘检测 | Sobel / Canny | 轮廓提取 |
| 特征匹配 | SIFT / ORB | 拼接、识别、重建 |
| 频域增强 | 傅里叶低通 / 高通 | 去噪、锐化 |

## 具体示例

`cv2.Canny(img, 100, 200)` 一步得到干净边缘图；ORB 对两张图 `detectAndCompute` 出关键点与描述子、再用 `BFMatcher(NORM_HAMMING)` 匹配并按距离排序，即可把"盒子"与"盒子在场景中"两图对准——免训练完成物体定位。

## 何时用 / 何时不用

- **用**：预处理与增强、颜色分割、图像拼接、无标注或极实时场景，以及教学理解卷积 / 特征由来。
- **不用**：复杂语义识别（检测 / 分割 / 分类）应交给深度模型（见 [[目标检测（YOLO 与 R-CNN 家族）]]、[[卷积神经网络(CNN)]]），手工特征难扛高层抽象。

## 优劣与代价

✅ 免训练、可解释、算力省，特定任务稳健。
⚠️ 手工特征对复杂语义与剧烈变化泛化差，易被端到端学习取代。
⚠️ 大量超参（阈值、核尺寸）需按场景调，跨域迁移弱。

## 与相关概念的区别

- **vs CNN 自动特征**：经典算法是手工设计的边缘 / 角点滤波器，CNN 用学习到的卷积核自动提特征（见 [[卷积神经网络(CNN)]]）。
- **空间域 vs 频率域**：前者直接改像素邻域（卷积 / 均衡化），后者先傅里叶变换再处理频率分量。
- **vs 光流与视频理解**：光流是低层运动，动作识别等高层视频任务在其上再建模。

## 常见误区

- OpenCV 的 imread 默认按 RGB 顺序读取彩色图像。
- 相比 RGB，HSV 色彩空间更容易受光照变化干扰、不适合做颜色分割。
- Canny 只是一个单步梯度阈值法，没有滤波和抑制过程。

## 面试速答

> 🎯 CV 前深度学习地基：图像是像素张量，色彩空间有 RGB(OpenCV 为 BGR)、HSV、灰度；变换含几何、空间域(均衡化·阈值·滤波)与频率域(傅里叶去噪·锐边)；经典算法含边缘、特征点与光流三大类。
> 🔍 追问：Canny 为什么优于简单梯度阈值？（含高斯去噪、非极大值抑制细化、双阈值连接，边缘更连续干净）
> 🔍 追问：SIFT 与 ORB 的取舍？（SIFT 更鲁棒但慢且曾涉专利；ORB 快、免费，实时与资源受限首选）
