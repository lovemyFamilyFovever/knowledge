# 主成分分析

## 定义

**一句话定义：** 主成分分析(Principal Component Analysis, PCA)是一种无监督的线性降维方法,它通过正交变换把原始特征投影到一组新的坐标轴(主成分)上,这些主成分按方差从大到小排列,用少数几个主成分即可保留数据的大部分信息。

**通俗类比：** 像给一个三维物体拍一张"信息量最大"的二维照片——选一个最佳角度(主方向),让照片里物体的展开程度(方差)最大、细节保留最多;必要时再补一张不同角度的照片(第二主成分)。

> 多义说明:PCA 是无监督的**线性**降维;区别于有监督的 LDA(线性判别分析)与非线性的 t-SNE / UMAP。本文讨论 PCA。

## 原理与机制

- **步骤:** 数据中心化(减均值)→ 计算协方差矩阵 → 求协方差矩阵的特征值与特征向量 → 按特征值从大到小取前 k 个特征向量作为投影方向 → 把数据投影到这 k 个主成分。
- **主成分含义:** 第 1 主成分是数据方差最大的方向,后续主成分与前面的正交且方差依次递减。
- **k 的选择:** 按累计解释方差比例(如保留 95%)。
- **等价视角:** 也可对数据矩阵做 SVD(奇异值分解)实现。

## 关键组成

| 组成 | 说明 |
|------|------|
| 中心化 | 减去均值 |
| 协方差矩阵 | 刻画特征间关系 |
| 特征值 / 特征向量 | 主成分方向与重要度 |
| 解释方差比 | 选择主成分个数 |
| SVD | 等价实现途径 |

## 应用场景

- 数据降维与可视化
- 去噪、特征压缩
- 消除多重共线性
- 图像压缩(如"特征脸")、建模预处理

## 优点与局限

- 优点:无监督(无需标签)、降维去噪、揭示主要变化方向、线性且可解释。
- 局限:只捕获线性关系(非线性流形无效,需核 PCA / t-SNE);主成分的物理含义有时难解释;对特征缩放敏感(需先标准化);对异常值敏感。

## 常见误区

- PCA 是无监督的(不用标签),区别于 LDA。
- 需先标准化,否则大量纲特征会主导主成分。
- 主成分是"方差最大的方向",不一定是"最有类别区分度的方向"。
- PCA 只能线性降维,非线性需用核 PCA / t-SNE / UMAP。
