# 主成分分析


> 📌 **导航**：本文是 **主成分分析** 词条，属于 machine-learning 术语集。相关枢纽：[[机器学习基础]]、[[特征缩放]]、[[K均值聚类]]、[[交叉验证]]。

## 定义

**一句话定义：** 主成分分析（PCA）是一种无监督的线性降维方法，通过正交变换把原始特征投影到一组新的坐标轴（主成分）上，这些主成分按方差从大到小排列，用少数几个即可保留数据的大部分信息。

**通俗类比：** 像给一个三维物体拍一张"信息量最大"的二维照片——选最佳角度（主方向）让物体的展开程度（方差）最大、细节保留最多；必要时再补一张不同角度（第二主成分）。

> 多义说明：PCA 是无监督的线性降维，区别于有监督的 LDA 与非线性的 t-SNE / UMAP；本文讨论 PCA。

## 为什么需要它

高维数据难可视化、计算贵，且特征间常强相关（多重共线性）。PCA 在尽量不丢信息（方差）的前提下把维度压到少数几个正交主成分，去冗余、去噪、提效率，是探索性分析与建模预处理的利器。

## 核心机制

- **步骤**：数据中心化（减均值）→ 计算协方差矩阵 → 求其特征值与特征向量 → 按特征值从大到小取前 k 个特征向量作为投影方向 → 把数据投影到这 k 个正交主成分。该过程也可通过对数据矩阵做 SVD（奇异值分解）等价实现。
- **主成分含义**：第 1 主成分是数据方差最大的方向，后续主成分与前面的正交、且方差依次递减。
- **选 k**：按累计解释方差比例（如保留 95%）确定保留几个主成分。

| 组成 | 说明 |
|------|------|
| 中心化 | 减去均值 |
| 协方差矩阵 | 刻画特征间关系 |
| 特征值 / 特征向量 | 主成分方向与重要度 |
| 解释方差比 | 选择主成分个数 |
| SVD | 等价实现途径 |

## 具体示例

20 个高度相关的客户指标，前两三个主成分可能就解释了 90% 的方差，用它们画图即可观察客群结构；做"特征脸"图像压缩时，把高维像素降到少数主成分再重建，既省空间又保留主要信息。

## 何时用 / 何时不用

- **用**：需要线性降维、消共线性、可视化或建模预处理，且特征为连续数值时。
- **不用**：需保留非线性流形结构（改用核 PCA / t-SNE / UMAP）；或每个维度语义必须能直接讲给业务方时（主成分常难解释）。

## 优劣与代价

✅ 无监督、降维去噪、揭示主要变化方向、线性且可解释性尚可。
⚠️ 只捕获线性关系，对非线性流形无效。
⚠️ 主成分物理含义有时难解释；对特征缩放与异常值都敏感。

## 与相关概念的区别

- **vs LDA**：PCA 无监督、最大化方差；LDA 有监督、最大化类间分离（找最有类别区分度的方向）。
- **vs t-SNE / UMAP**：后两者非线性、擅长保留局部流形做可视化，但不可逆、需调参。
- **vs [[特征缩放]]**：PCA 前几乎必须先标准化，否则量纲大的特征会主导主成分。

## 常见误区

- PCA 降维选出的主成分，一定是"最能区分不同类别"的方向。
- 做 PCA 前不必标准化，各特征量纲不同也不会影响主成分。
- PCA 是一种有监督的降维方法，需要用类别标签来学习主成分。

## 面试速答

> 🎯 PCA=无监督线性降维：中心化 → 算协方差矩阵 → 取特征值/特征向量 → 按特征值降序选前 k 个正交方向投影，用少数主成分保留大部分方差。价值在降维、去噪与可视化。要点：必须先标准化（否则大量纲特征主导），只捕线性关系（非线性用核 PCA/UMAP）；与 LDA 区别在 PCA 最大化方差、LDA 最大化类间区分。
> 🔍 追问：为什么 PCA 前通常要标准化？（各特征尺度不同，不标准化则方差大的特征主导协方差与主成分方向）
> 🔍 追问：PCA 和 LDA 的核心差异？（PCA 无监督、最大化总方差；LDA 用标签、最大化类间 / 类内比，找最有判别力的方向）
