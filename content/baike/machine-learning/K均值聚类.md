# K均值聚类


> 📌 **导航**：本文是 **K均值聚类** 词条，属于 machine-learning 术语集。相关枢纽：[[机器学习基础]]、[[决策树]]、[[Embedding 技术详解]]、[[逻辑回归]]。

## 定义

**一句话定义：** K均值聚类（K-means）是一种无监督学习算法，把 n 个样本划分为 k 个簇、使每个样本归属最近的簇质心，并通过迭代更新质心，最终让簇内尽量紧密、簇间尽量分离。

**通俗类比：** 像在城市规划 k 个快递分站——先随手放 k 个点，把每户划给最近的站，再把每个站搬到它所服务片区的"重心"，反复调整到稳定，让每家离所属分站都尽量近。

> 多义说明：k-means 属划分式聚类，区别于层次聚类与基于密度的 DBSCAN，且 k 需预先指定；本文讨论标准 Lloyd 算法。

## 为什么需要它

无标签数据里发现自然分组是常见需求（客户分群、颜色压缩、异常检测）。K-means 以"到质心距离"这一最简目标快速把样本聚成 k 组，是数值特征上最常用的无监督聚类基线。

## 核心机制

- **优化目标**：最小化簇内平方误差 SSE（inertia），即各样本到所属质心距离的平方和。
- **Lloyd 迭代**：① 分配步——把每个样本分给最近质心；② 更新步——将每个质心移到其簇内样本的均值位置；重复直至质心不再明显变化（收敛）。
- **初始化敏感**：随机初始化易收敛到局部最优，常用 k-means++ 让初始质心彼此远离来改善，并多次重启取最优。
- **选 k**：用肘部法则（SSE 下降拐点）、轮廓系数（silhouette）等辅助确定。

| 要素 | 说明 |
|------|------|
| 簇数 k | 需预先指定的超参数 |
| 质心 centroid | 每个簇的均值中心 |
| 距离度量 | 通常为欧氏距离 |
| 分配步 / 更新步 | 迭代的两阶段 |
| 初始化 k-means++ | 影响收敛质量 |

## 具体示例

电商用 RFM 特征对客户做 K-means，分成高价值 / 一般 / 流失群；图像颜色量化把像素按 RGB 聚到 k 个代表色。但若数据是环形或月牙形分布，K-means 会切错簇——此时应改用 DBSCAN 或谱聚类。

## 何时用 / 何时不用

- **用**：数值特征、簇近似球形且凸、数据规模大要快。
- **不用**：非凸或密度差异大的簇（用 DBSCAN）、含大量离群点（用 k-medoids）、类别型数据或需要"软归属"（用 GMM / 层次聚类）。

## 优劣与代价

✅ 简单高效、易实现、可扩到大规模，时间复杂度近线性。
⚠️ 需预设 k，对初始化与离群点敏感。
⚠️ 隐含"簇为凸、近似球形、大小相近"的假设，主要适用于数值型，且可能停在局部最优。

## 与相关概念的区别

- **vs DBSCAN**：k-means 需定 k、假设球形凸簇；DBSCAN 基于密度，能挖任意形状、自动定簇数，但需调 eps / minPts（见 [[机器学习基础]]）。
- **vs 层次聚类 / GMM**：层次聚类不需预设 k、给出谱系树但更慢；GMM 用概率软分配、可拟合椭圆簇，k-means 则硬分配、只宜球形。

## 常见误区

- K-means 能自动确定最优簇数 k，无需人为选定或额外方法估计。
- K-means 对初始化不敏感，无论随机怎样给初值都必定收敛到同一全局最优。
- K-means 特别擅长把环形或月牙形分布的数据正确聚成对应的簇。

## 面试速答

> 🎯 K-means=无监督划分聚类：预设 k，用 Lloyd 迭代——分配（样本归最近质心）↔ 更新（质心移到簇均值）直到收敛，目标是最小化簇内平方误差 SSE。需人为定 k、随机初始化易陷局部最优（k-means++ 改善）、对离群点敏感、隐含「球形凸簇且大小相近」假设，环形/月牙形须改 DBSCAN。
> 🔍 追问：k-means++ 比随机初始化好在哪？（让初始质心尽量彼此分散，显著降低坏局部最优概率、常更少轮收敛）
> 🔍 追问：为什么离群点特别影响 K-means？（质心是均值、会被远处点拉偏；DBSCAN 靠密度、k-medoids 用真实样本点更鲁棒）
