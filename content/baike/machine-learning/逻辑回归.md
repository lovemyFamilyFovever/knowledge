# 逻辑回归


> 📌 **导航**：本文是 **逻辑回归** 词条，属于 machine-learning 术语集。相关枢纽：[[LLM应用开发完全指南]]、[[强化学习从入门到实践]]、[[自然语言处理NLP完全指南]]、[[计算机视觉入门到实战]]。

## 定义

**一句话定义：** 逻辑回归(Logistic Regression)是一种用于分类(尤其二分类)的统计学习模型,它用 Sigmoid 函数把特征的线性组合映射到 (0,1) 区间,表示样本属于正类的概率,并通过极大似然估计(常用梯度下降)拟合参数。

**通俗类比：** 像根据多项指标打一个"综合分",再用一个 S 形"换算器"把分数压成 0~100% 的概率——例如依据复习时长、睡眠等,估算"通过考试的概率是 80%"。

> 多义说明:名字含"回归",但它本质是**分类**模型(输出概率再按阈值判类);有多分类扩展(Softmax / 多项逻辑回归)。本文以二分类为主。

## 原理与机制

- **模型:** 线性组合 z = w·x + b,经 Sigmoid σ(z) = 1 / (1 + e^(−z)) 得到概率 p。
- **决策:** p ≥ 阈值(默认 0.5,可调)判为正类。
- **训练:** 最大化似然等价于最小化对数损失(log loss / 交叉熵),用梯度下降求解;可加 L1/L2 正则。
- **可解释性:** 权重对应各特征对"对数几率(log-odds)"的线性贡献。

## 关键组成

| 组成 | 作用 |
|------|------|
| 线性预测子 w·x + b | 综合各特征 |
| Sigmoid | 把实数压到 (0,1) 概率 |
| 对数损失 | 分类的训练目标 |
| 正则项(L1/L2) | 抑制过拟合/做特征选择 |
| 决策阈值 | 概率转类别,可按代价调整 |

## 应用场景

- 二分类基线模型(简单强基线)
- 风控与信用评分(需要概率输出)
- 点击率(CTR)预估、医学诊断
- 作为单层神经网络的雏形

## 优点与局限

- 优点:简单高效、输出概率、可解释、易实现、可增量/在线更新。
- 局限:决策边界本质是线性的(需特征工程或多项式扩展表达非线性);对特征缩放与多重共线性敏感;难以拟合复杂关系。

## 常见误区

- 逻辑回归是分类模型,不是回归(尽管名字里有"回归")。
- 它假设特征与对数几率呈线性关系。
- 阈值 0.5 并非固定,可依据误判代价调整。
- 通常需要特征缩放,以利于优化与正则。
