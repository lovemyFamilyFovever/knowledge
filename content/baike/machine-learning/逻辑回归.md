# 逻辑回归


> 📌 **导航**：本文是 **逻辑回归** 词条，属于 machine-learning 术语集。相关枢纽：[[机器学习基础]]、[[支持向量机]]、[[朴素贝叶斯]]、[[过拟合与正则化]]。

## 定义

**一句话定义：** 逻辑回归（Logistic Regression）是一种用于分类（尤其二分类）的统计学习模型，用 Sigmoid 把特征的线性组合映射到 (0,1) 区间表示样本属于正类的概率，并通过极大似然（常用梯度下降）拟合参数。

**通俗类比：** 像根据多项指标打一个"综合分"，再用一个 S 形换算器把分数压成 0~100% 的概率——例如依据复习时长、睡眠等，估算"通过考试的概率是 80%"。

> 多义说明：名字含"回归"，但它本质是分类模型（输出概率再按阈值判类）；有多分类扩展（Softmax / 多项逻辑回归）。本文以二分类为主。

## 为什么需要它

很多业务要的是"概率 + 可解释 + 快"，而非黑盒的最高精度。逻辑回归用一个线性打分 + Sigmoid 就给出类概率、权重可解读、训练极快，是分类任务的最强基线，也是风控 / CTR 的常青主力。

## 核心机制

- **模型**：线性组合 `z = w·x + b`，经 Sigmoid `σ(z) = 1/(1 + e^(−z))` 得到概率 p。
- **决策**：`p ≥ 阈值`（默认 0.5，可调）判为正类。
- **训练**：最大化似然等价于最小化对数损失（log loss / 交叉熵），用梯度下降求解，可加 L1 / L2 正则。
- **可解释性**：权重对应各特征对"对数几率（log-odds）"的线性贡献。

| 组成 | 作用 |
|------|------|
| 线性预测子 w·x + b | 综合各特征 |
| Sigmoid | 把实数压到 (0,1) 概率 |
| 对数损失 | 分类的训练目标 |
| 正则项 L1 / L2 | 抑制过拟合 / 做特征选择 |
| 决策阈值 | 概率转类别，可按代价调整 |

## 具体示例

信用评分：用年龄 / 收入 / 负债等特征，模型输出违约概率，每个系数说明该特征如何影响对数几率；正负样本不均衡时可下调阈值以多召回高风险样本。CTR 预估也常用逻辑回归起步。

## 何时用 / 何时不用

- **用**：需要概率、可解释、快速基线，且数据线性可分或经特征工程后可分。
- **不用 / 换用**：强非线性关系（用树集成 / 神经网络）；特征交互复杂、不想手工构造时。

## 优劣与代价

✅ 简单高效、输出概率、可解释、易实现、可增量 / 在线更新。
⚠️ 决策边界本质是线性的（需特征工程或多项式扩展来表达非线性）。
⚠️ 对特征缩放与多重共线性敏感，难以拟合复杂关系。

## 与相关概念的区别

- **vs 线性回归**：LR 把线性输出经 Sigmoid 映射成概率、用交叉熵训练做分类；线性回归拟合连续值、用 MSE。
- **vs [[支持向量机]]**：LR 直接给概率；SVM 找最大间隔、原生非概率。
- **vs [[朴素贝叶斯]]**：都输出概率——LR 判别式、无独立性假设；NB 生成式、带独立假设。

## 常见误区

- 逻辑回归因名字带"回归"，所以是用来预测连续数值的回归模型。
- 逻辑回归的决策阈值固定只能是 0.5，不能更改。
- 逻辑回归无需特征缩放，且对多重共线性完全免疫。

## 面试速答

> 🎯 逻辑回归是分类模型（名字虽有"回归"）：先对特征做线性组合 z=w·x+b，再用 Sigmoid 压成 (0,1) 的属于正类概率，按阈值判类。训练是最大化似然=最小化对数损失（交叉熵），可加 L1/L2 正则防过拟合。优点是简单高效、天然给概率、权重可解释，是风控/CTR 的强基线；局限是决策边界线性。
> 🔍 追问：为什么用 Sigmoid 而不是直接线性输出？（把无界线性打分映射到 (0,1) 概率，且使交叉熵可导、便于极大似然优化）
> 🔍 追问：为什么逻辑回归要做特征缩放？（梯度下降与 L2 正则对尺度敏感，缩放后收敛更快、正则更公平）
