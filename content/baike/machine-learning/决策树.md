# 决策树


> 📌 **导航**：本文是 **决策树** 词条，属于 machine-learning 术语集。相关枢纽：[[LLM应用开发完全指南]]、[[强化学习从入门到实践]]、[[自然语言处理NLP完全指南]]、[[计算机视觉入门到实战]]。

## 定义

**一句话定义：** 决策树(Decision Tree)是一种以树状结构进行决策的监督学习模型,它通过一系列"特征—阈值"判断把样本从根节点逐级划分到叶节点,每个叶节点给出类别(分类树)或数值(回归树)预测,直观且可解释。

**通俗类比：** 像"二十个问题"猜谜或医生问诊——通过一连串是/否问题(发烧吗?咳嗽吗?)层层缩小范围,最后落到一个结论;每个问题就是树上的一个分叉。

> 多义说明:决策树既指单棵树模型,也是随机森林、梯度提升树(GBDT/XGBoost)等集成方法的**基学习器**;本文以单棵树为主。

## 原理与机制

- 递归地选择"最优特征"对数据划分,使各子集尽量"纯"(同类聚集)。
- **划分准则:** 信息增益(ID3)、信息增益率(C4.5)、基尼不纯度(CART)。
- **剪枝(pruning):** 预剪枝(限制深度/样本数)与后剪枝,用于抑制过拟合。
- 能处理数值与类别特征;对特征缩放不敏感(基于阈值划分)。

## 关键组成

| 组成 | 含义 |
|------|------|
| 根节点 / 内部节点 | 对某特征的判断 |
| 分支 | 判断的一个取值/区间结果 |
| 叶节点 | 最终预测(类别或数值) |
| 划分准则 | 信息增益 / 增益率 / 基尼 |
| 剪枝策略 | 控制复杂度、防过拟合 |

## 应用场景

- 分类与回归任务
- 风控与信用评分、医疗辅助诊断
- 特征重要性分析
- 作为随机森林、GBDT 等集成方法的基模型

## 优点与局限

- 优点:直观可解释、可可视化;无需特征缩放;能处理混合类型特征与非线性关系。
- 局限:易过拟合(需剪枝/限深);对数据变动敏感、稳定性差(可用集成改善);单树精度常不及集成;贪心划分不保证全局最优。

## 常见误区

- "可解释"不等于"不会过拟合":过深的树会记忆训练集噪声。
- 特征缩放对决策树通常无必要(与 SVM/KNN 等不同)。
- 单棵树不稳定,实践中常用随机森林/GBDT 提升稳健性与精度。
