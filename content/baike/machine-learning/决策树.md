# 决策树


> 📌 **导航**：本文是 **决策树** 词条，属于 machine-learning 术语集。相关枢纽：[[机器学习基础]]、[[支持向量机]]、[[随机森林]]、[[梯度提升树]]。

## 定义

**一句话定义：** 决策树（Decision Tree）是一种以树状结构进行决策的监督学习模型，它通过一系列"特征—阈值"判断把样本从根节点逐级划分到叶节点，每个叶给出类别（分类树）或数值（回归树）预测，直观且可解释。

**通俗类比：** 像"二十个问题"猜谜或医生问诊——通过一连串是 / 否问题（发烧吗？咳嗽吗？）层层缩小范围，最后落到一个结论；每个问题就是树上的一个分叉。

> 多义说明：决策树既指单棵树模型，也是随机森林、梯度提升树（GBDT / XGBoost）等集成方法的基学习器；本文以单棵树为主。

## 为什么需要它

很多业务（风控、诊断）既要预测、又要"说清为什么"。决策树用一串 if-then 划分把决策过程可视化、可解释，且几乎不需要特征缩放这类预处理，是入门与强可解释场景的首选。

## 核心机制

- **递归划分**：每个节点选一个"特征—阈值"把数据切成更"纯"（同类聚集）的子集，直到满足停止条件。
- **划分准则**：ID3 用信息增益（基于熵）、C4.5 用信息增益率（校正多值特征偏好）、CART 用基尼不纯度（分类）或平方误差（回归）。
- **剪枝**：预剪枝（限制最大深度、叶最少样本数）与后剪枝，用来抑制过拟合。
- **特性**：能处理数值与类别混合特征、天然建模非线性；因基于阈值划分，对特征缩放不敏感。

| 组成 | 含义 |
|------|------|
| 根 / 内部节点 | 对某特征的判断 |
| 分支 | 判断的一个取值 / 区间结果 |
| 叶节点 | 最终预测（类别或数值） |
| 划分准则 | 信息增益 / 增益率 / 基尼 |
| 剪枝策略 | 控制复杂度、防过拟合 |

## 具体示例

信用审批：用"收入 > 阈值？有逾期史？"逐层分流到批准 / 拒绝的叶节点，规则可直接读出；离根越近的特征通常越重要，可作特征重要性参考。但换一批训练样本，树结构可能大变——这种高方差正是改用随机森林 / GBDT 的动机。

## 何时用 / 何时不用

- **用**：需要可解释、可视化的规则，特征是混合类型，样本中等规模。
- **慎用**：追求最高精度（用集成）；测试分布偏移较大（单树不稳）；需要平滑决策边界时（树是阶梯状、外推弱）。

## 优劣与代价

✅ 直观可解释、可可视化、无需特征缩放、能处理混合类型与非线性。
⚠️ 易过拟合（需剪枝 / 限深）、对数据扰动敏感、稳定性差。
⚠️ 单树精度常不及集成；贪心划分不保证全局最优。

## 与相关概念的区别

- **vs [[随机森林]] / [[梯度提升树]]**：单树不稳易过拟合，Bagging（随机森林，降方差）与 Boosting（GBDT，降偏差）以它为基学习器来增强。
- **vs [[支持向量机]]**：SVM 找最大间隔超平面、需特征缩放、可解释性弱；决策树给显式规则、不需缩放。

## 常见误区

- 决策树越深、分得越细，泛化能力就一定越强。
- 和 SVM、KNN 一样，训练决策树前必须先对所有特征做标准化缩放。
- 单棵决策树非常稳定，换一批训练样本几乎不会改变树结构。

## 面试速答

> 🎯 决策树=树状监督模型：每个节点选一个「特征-阈值」把样本逐级划分到更纯的子集，叶节点给类别或数值。划分准则有信息增益（ID3）、增益率（C4.5）、基尼不纯度（CART），用预/后剪枝控复杂度防过拟合。优点是直观可解释、无需特征缩放、能处理混合特征；缺点是易过拟合、对数据扰动不稳定。
> 🔍 追问：为什么决策树通常不需要特征缩放？（它按"某特征是否大于阈值"划分，单调变换不改变分裂顺序）
> 🔍 追问：C4.5 相比 ID3 改进了什么？（用信息增益率校正 ID3 对多取值特征的偏好）
