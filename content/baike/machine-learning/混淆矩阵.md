# 混淆矩阵


> 📌 **导航**：本文是 **混淆矩阵** 词条，属于 machine-learning 术语集。相关枢纽：[[机器学习基础]]、[[逻辑回归]]、[[交叉验证]]、[[朴素贝叶斯]]。

## 定义

**一句话定义：** 混淆矩阵（Confusion Matrix）是评估分类模型性能的表格，它按"真实类别 × 预测类别"交叉列出真正例（TP）、假正例（FP）、真反例（TN）、假反例（FN），全面反映分类的对错分布。

**通俗类比：** 像考试成绩的"对错分类表"——不只告诉你答对多少，还把"该对的答对了（TP）、不该对的答错了（FP）、该对的漏了（FN）、不该对的没答（TN）"分别列清，让你看清错在哪一类。

> 多义说明：二分类是 2×2 矩阵，多分类是 n×n 矩阵；本文以二分类为主。

## 为什么需要它

单一"准确率"会掩盖错误分布——到底错在误报还是漏报，业务代价天差地别。混淆矩阵把 TP/FP/TN/FN 摊开，是所有分类指标的源头，也是按业务调阈值的依据。

## 计算逻辑

- **四象限（二分类）**：TP（预测正且实际正）、FP（预测正但实际负，即"误报"）、TN（预测负且实际负）、FN（预测负但实际正，即"漏报"）。
- **派生指标**：准确率 Accuracy =（TP+TN）/ 总数；精确率 Precision = TP/（TP+FP）；召回率 Recall = TP/（TP+FN）；F1 = 2·P·R/（P+R）；另有特异度 TN/（TN+FP）、ROC / AUC。
- **阈值**：改变分类阈值，矩阵随之变化，故常结合 ROC 曲线选点。

数值例子：对 100 个正样本预测对 80（FN=20）、把 20 个负样本误判成正（FP=20），则召回率 = 80/100 = 0.8。类别极不平衡（99 负 1 正）时，"全预测为负"也有 99% 准确率，但少数类召回为 0——可见只报准确率会被误导。

| 组成 | 说明 |
|------|------|
| TP / FP / TN / FN | 四个基本计数 |
| 准确率 / 精确率 / 召回率 / F1 | 派生指标 |
| ROC / AUC | 跨阈值的综合评估 |
| 阈值 | 影响矩阵取值 |

## 具体示例

癌症筛查重召回（宁可误报也别漏诊），垃圾邮件过滤重精确率（别把正常邮件误杀）。看混淆矩阵就知道模型偏向哪边，再据此调阈值、选指标。

## 何时用 / 何时不用

- **用**：任何分类评估、需看清错误类型、按业务权衡误报 / 漏报、调阈值时。
- **慎用**：只看准确率（不平衡会骗人）；多分类时矩阵大，需配合其他可视化。

## 优劣与代价

✅ 全面呈现分类对错分布、可派生多种指标、指导阈值与业务权衡。
⚠️ 多分类时矩阵大、不直观；类别极不均衡时准确率会误导。
⚠️ 只是单一阈值下的快照。

## 与相关概念的区别

- **vs 单一准确率**：混淆矩阵拆出 TP/FP/TN/FN、派生精确 / 召回，暴露准确率看不到的错误结构。
- **vs 排序 / 检索指标（如 [[交叉验证]] 里的 Recall@K）**：混淆矩阵面向固定阈值的分类计数，思路互补。

## 常见误区

- 只要准确率够高，就能说明模型在任何类别上都分得好，无需再看混淆矩阵。
- 在混淆矩阵里，FP 表示"漏报"、FN 表示"误报"。
- 混淆矩阵与分类阈值无关，阈值怎么调矩阵都不会变。

## 面试速答

> 🎯 混淆矩阵按「真实类 × 预测类」把结果拆成 TP/FP/TN/FN，是几乎所有分类指标的源头：准确率=(TP+TN)/总数，精确率=TP/(TP+FP)，召回率=TP/(TP+FN)，F1 是二者调和均值。价值在于指导阈值与业务权衡：癌症筛查重召回、垃圾邮件重精确率。不均衡时准确率会骗人。
> 🔍 追问：精确率和召回率分别对应哪种错误？（精确率管误报 FP，召回率管漏报 FN，通常此消彼长）
> 🔍 追问：为何不均衡场景别只看准确率？（99:1 时全预测多数类准确率也 99%、但少数类召回为 0，要看 F1 / AUC）
