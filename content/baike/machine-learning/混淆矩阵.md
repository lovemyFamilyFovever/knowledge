# 混淆矩阵

## 定义

**一句话定义：** 混淆矩阵(Confusion Matrix)是评估分类模型性能的表格,它把预测结果按"真实类别 × 预测类别"交叉列出,展示真正例(TP)、假正例(FP)、真反例(TN)、假反例(FN)的数量,从而全面反映分类的对错分布。

**通俗类比：** 像考试成绩的"对错分类表"——不只告诉你答对多少,还把"该对的答对了(TP)、不该对的答错了(FP)、该对的漏了(FN)、不该对的没答(TN)"分别列清,让你看清错在哪一类。

> 多义说明:二分类是 2×2 矩阵,多分类是 n×n 矩阵。本文以二分类为主。

## 原理与机制

- **四象限(二分类):** TP(预测正且实际正)、FP(预测正但实际负,即"误报")、TN(预测负且实际负)、FN(预测负但实际正,即"漏报")。
- **派生指标:** 准确率 Accuracy = (TP+TN)/总数;精确率 Precision = TP/(TP+FP);召回率 Recall = TP/(TP+FN);F1 = 2·P·R/(P+R);另有特异度、ROC/AUC。
- **用途:** 直观看出模型偏向(误报多还是漏报多),指导阈值调整。

## 关键组成

| 组成 | 说明 |
|------|------|
| TP / FP / TN / FN | 四个基本计数 |
| 准确率 / 精确率 / 召回率 / F1 | 派生指标 |
| ROC / AUC | 跨阈值的综合评估 |
| 阈值 | 影响矩阵取值 |

## 应用场景

- 分类模型评估
- 医疗诊断(重召回)、垃圾邮件过滤(重精确率)
- 类别不均衡分析
- 阈值调优

## 优点与局限

- 优点:全面展示分类对错、可派生多种指标、指导阈值与业务权衡。
- 局限:多分类时矩阵大、不直观;类别极不均衡时准确率会误导(需看精确率/召回率/F1);只是单一阈值下的快照。

## 常见误区

- 准确率高 ≠ 模型好:类别不均衡时被多数类主导,应看精确率/召回率/F1。
- 精确率与召回率常此消彼长,需用 F1 或按业务权衡。
- 混淆矩阵依赖分类阈值(阈值变则矩阵变)。
- FP = 误报、FN = 漏报,别记反。
