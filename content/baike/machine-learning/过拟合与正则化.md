# 过拟合与正则化

## 定义

**一句话定义：** 过拟合(Overfitting)指模型在训练数据上表现很好、但在未见过的新数据上明显变差(学到了噪声而非普遍规律);正则化(Regularization)是为抑制过拟合、提升泛化能力而对模型施加的一系列约束或惩罚手段。

**通俗类比：** 过拟合像死记硬背——学生把练习册答案背得滚瓜烂熟(训练集满分),换一道新题就不会(测试集很差);正则化像老师要求"掌握通法、别钻牛角尖",逼学生学规律而不是背答案。

> 多义说明:与泛化相关的还有**欠拟合(underfitting)**——模型太简单,连训练集都学不好。本文聚焦过拟合及其对策正则化。

## 原理与机制

- **偏差–方差权衡(bias-variance tradeoff):** 过拟合对应高方差,欠拟合对应高偏差;目标是二者平衡以最小化泛化误差。
- **常见正则化手段:**
  - L1 正则(lasso):惩罚权重绝对值,促进稀疏(特征选择)。
  - L2 正则(ridge / 权重衰减):惩罚权重平方,抑制过大权重。
  - Dropout:训练时随机丢弃神经元,增强鲁棒性。
  - 早停(early stopping)、数据增强、降低模型复杂度、集成(bagging)。
- **评估:** 用验证集/交叉验证选择超参与判断过拟合。

## 关键组成

| 手段 | 作用 |
|------|------|
| 训练/验证/测试集划分 | 客观评估泛化 |
| L1 / L2 正则 | 惩罚复杂度/权重 |
| Dropout | 随机失活,防共适应 |
| 早停 | 在验证误差回升前停止 |
| 数据增强 | 扩充样本多样性 |
| 交叉验证 | 稳健选参与评估 |

## 应用场景

- 各类监督学习模型的训练与调参
- 深度学习(Dropout、权重衰减、数据增强)
- 防止模型"记忆"训练集、提升线上泛化表现

## 优点与局限

- 优点:显著提升泛化能力与鲁棒性,使模型在新数据上更可靠。
- 局限:正则过强会导致欠拟合;引入额外超参数与调优成本;部分方法(如数据增强)增加计算开销。

## 常见误区

- 训练集准确率高 ≠ 模型好:必须看验证/测试集表现。
- 增加数据通常能缓解过拟合,但不必然消除(还取决于模型复杂度与噪声)。
- 正则化不是"参数越少越好",而是控制模型的**有效复杂度**。
