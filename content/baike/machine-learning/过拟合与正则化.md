# 过拟合与正则化


> 📌 **导航**：本文是 **过拟合与正则化** 词条，属于 machine-learning 术语集。相关枢纽：[[机器学习基础]]、[[交叉验证]]、[[Dropout]]、[[梯度下降]]。

## 定义

**一句话定义：** 过拟合指模型在训练数据上表现很好、但在未见过的新数据上明显变差（学到了噪声而非普遍规律）；正则化是为抑制过拟合、提升泛化能力而对模型施加的一系列约束或惩罚手段。

**通俗类比：** 过拟合像死记硬背——把练习册答案背得滚瓜烂熟（训练集满分），换道新题就不会（测试集很差）；正则化像老师要求"掌握通法、别钻牛角尖"，逼学生学规律而不是背答案。

> 多义说明：与泛化相关的还有欠拟合（underfitting）——模型太简单，连训练集都学不好；本文聚焦过拟合及其对策正则化。

## 为什么需要它

模型容量足、数据有限时，它会"背答案"——训练集满分、新数据拉胯。过拟合是泛化的头号敌人，正则化就是用约束换泛化，让模型学规律而非记噪声。

## 核心机制

- **偏差 – 方差权衡**：过拟合对应高方差，欠拟合对应高偏差；目标是平衡二者以最小化泛化误差。
- **常见正则化手段**：
  - L1 正则（lasso）：惩罚权重绝对值，促进稀疏（兼作特征选择）。
  - L2 正则（ridge / 权重衰减）：惩罚权重平方，抑制过大权重。
  - Dropout：训练时随机丢弃神经元，增强鲁棒、防共适应。
  - 早停、数据增强、降低模型复杂度、集成（bagging）。
- **评估**：用验证集 / 交叉验证选择超参并判断是否过拟合。

| 手段 | 作用 |
|------|------|
| 训练 / 验证 / 测试划分 | 客观评估泛化 |
| L1 / L2 正则 | 惩罚复杂度 / 权重 |
| Dropout | 随机失活，防共适应 |
| 早停 | 在验证误差回升前停止 |
| 数据增强 | 扩充样本多样性 |
| 交叉验证 | 稳健选参与评估 |

## 具体示例

训练神经网络时训练 loss 一路降、验证 loss 先降后升，就是过拟合信号——用权重衰减 + Dropout + 早停 + 数据增强拉回；小数据高维的线性回归用 L1 自动选特征、防过拟合。

## 何时用 / 何时不用

- **用**：数据有限、模型容量大、训练与验证表现差距明显时。
- **权衡**：正则过强会导致欠拟合，需按验证集调节强度（λ、深度、dropout 率）。

## 优劣与代价

✅ 显著提升泛化能力与鲁棒性，使模型在新数据上更可靠。
⚠️ 正则过强会导致欠拟合，并引入额外超参数与调优成本。
⚠️ 部分手段（如数据增强）会增加计算开销。

## 与相关概念的区别

- **vs [[Dropout]] / 权重衰减**：它们都是正则化的具体手段——L1 偏稀疏特征选择，L2 偏平滑权重，Dropout 防共适应。
- **vs [[交叉验证]]**：CV 是"发现 / 量化过拟合"的工具，正则化是"治疗手段"。

## 常见误区

- 只要训练集准确率足够高，就说明模型好，可以放心上线。
- 正则化越强、惩罚越大，模型的泛化性能就一定越好。
- L2 正则的核心作用是让大量权重精确变成 0，从而自动做特征选择。

## 面试速答

> 🎯 过拟合是模型把训练噪声也学了、训练好新数据差（高方差）；欠拟合是模型太简单连训练集都学不好（高偏差），二者是偏差–方差权衡。治过拟合靠约束：L1（促稀疏、兼特征选择）、L2/权重衰减（抑制大权重）、Dropout、早停、数据增强、降复杂度。判断靠训练/验证差距，正则化控制的是有效复杂度。
> 🔍 追问：L1 和 L2 正则的差异？（L1 绝对值惩罚→稀疏、可做特征选择；L2 平方惩罚→权重整体变小但不归零）
> 🔍 追问：早停为什么能防过拟合？（验证误差开始回升说明在记忆噪声，及时停在泛化最佳点）
