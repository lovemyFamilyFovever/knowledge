# 集成学习


> 📌 **导航**：本文是 **集成学习** 词条，属于 machine-learning 术语集。相关枢纽：[[随机森林]]、[[梯度提升树]]、[[决策树]]、[[机器学习基础]]。

## 定义

**一句话定义：** 集成学习（Ensemble Learning）是通过训练并结合多个基学习器来完成同一任务的机器学习方法，核心思想是"三个臭皮匠顶个诸葛亮"——多个较弱或各异的模型组合后，往往比任何单个模型更准确、更稳健。

**通俗类比：** 像让多位专家分别判断再综合——每位专家可能各有偏见或失误，但通过投票、平均或依次纠错把意见汇总，集体结论通常比任何单个专家都更可靠。

> 多义说明：主要流派有 Bagging（并行，降方差，如随机森林）、Boosting（串行纠错，降偏差，如 AdaBoost / GBDT）、Stacking（用元学习器融合）；本文综述。

## 为什么需要它

单个模型常"要么稳而不准、要么准而不稳"。集成学习把多个各有偏差的模型组合，用多样性换取更强的泛化——像群体智慧，往往比任何单模型更准更稳，是表格数据夺冠与降风险的通用策略。

## 核心机制

- **Bagging**：自助采样训练多个基学习器、并行执行、投票 / 平均，主要降低方差（代表：随机森林）。
- **Boosting**：串行训练，每个新模型聚焦前面出错的样本或残差，加权累加，主要降低偏差（代表：AdaBoost、GBDT、XGBoost）。
- **Stacking**：用多个异构基模型的输出作为特征，再训练一个元学习器融合。
- **关键前提**：基学习器要"好而不同"（具备多样性），否则集成收益有限。

| 组成 | 说明 |
|------|------|
| 基学习器 | 组成集成的单个模型 |
| Bagging | 并行、降方差 |
| Boosting | 串行纠错、降偏差 |
| Stacking | 元学习器融合 |
| 多样性 | 集成有效的关键 |

## 具体示例

Kaggle 表格赛常以 XGBoost / LightGBM（Boosting）取胜，或再加 Stacking 融合异构模型。Bagging 让高方差决策树变稳，Boosting 把一堆弱树堆成强模型——正是"降方差 vs 降偏差"两条路线的体现。

## 何时用 / 何时不用

- **用**：需要更稳、更准，单模型不够，且可接受更多算力时。
- **慎用**：要求极致可解释或低延迟单模型；基学习器彼此高度相似（无多样性）时集成无益。

## 优劣与代价

✅ 精度与稳健性通常优于单模型，Bagging 抗过拟合，组合灵活。
⚠️ 训练 / 推理成本高（多模型），可解释性下降。
⚠️ 需保证基学习器多样性，调参更复杂。

## 与相关概念的区别

- **vs [[随机森林]] / [[梯度提升树]]**：那两者是集成的具体代表（Bagging / Boosting），本条是统摄框架（还含 Stacking）。
- **vs [[决策树]]**：集成以决策树等为基学习器、通过堆叠增强。

## 常见误区

- 集成学习里基学习器数量一定越多越好，精度会持续上升且没有额外成本。
- Bagging 主要降低偏差、Boosting 主要降低方差。
- 只要把所有基学习器都训成几乎一样的，集成效果就最好。

## 面试速答

> 🎯 集成学习组合多个基学习器完成同一任务，前提是「好而不同」。两大流派：Bagging 自助采样并行训多模型，主要降方差（随机森林）；Boosting 串行、每个新模型聚焦前轮错误与残差、加权累加，主要降偏差（AdaBoost/GBDT/XGBoost）。代价是推理成本与可解释性下降，且并非越多越好。
> 🔍 追问：Bagging 和 Boosting 各自主攻什么？（Bagging 并行降方差、稳住高方差模型；Boosting 串行降偏差、堆弱成强）
> 🔍 追问：为什么基学习器的"多样性"是关键？（各模型误差方向不同，平均 / 纠错才能相互抵消；全一样则退化成一个模型）
