# 集成学习


> 📌 **导航**：本文是 **集成学习** 词条，属于 machine-learning 术语集。相关枢纽：[[LLM应用开发完全指南]]、[[强化学习从入门到实践]]、[[自然语言处理NLP完全指南]]、[[计算机视觉入门到实战]]。

## 定义

**一句话定义：** 集成学习(Ensemble Learning)是通过训练并结合多个基学习器(base learner)来完成同一任务的机器学习方法,其核心思想是"三个臭皮匠顶个诸葛亮"——多个较弱或各异的模型组合后,往往比任何单个模型更准确、更稳健。

**通俗类比：** 像让多位专家分别判断再综合——每位专家可能各有偏见或失误,但通过投票、平均或依次纠错把意见汇总,集体结论通常比任何单个专家都更可靠。

> 多义说明:主要流派有 Bagging(并行,降方差,如随机森林)、Boosting(串行纠错,降偏差,如 AdaBoost / GBDT)、Stacking(用元学习器融合)。本文综述。

## 原理与机制

- **Bagging:** 自助采样训练多个基学习器,并行执行,投票/平均;主要降低方差(代表:随机森林)。
- **Boosting:** 串行训练,每个新模型聚焦前面出错的样本或残差,加权累加;主要降低偏差(代表:AdaBoost、GBDT、XGBoost)。
- **Stacking:** 用多个异构基模型的输出作为特征,再训练一个元学习器融合。
- **关键前提:** 基学习器要"好而不同"(具备多样性),否则集成收益有限。

## 关键组成

| 组成 | 说明 |
|------|------|
| 基学习器 | 组成集成的单个模型 |
| Bagging | 并行、降方差 |
| Boosting | 串行纠错、降偏差 |
| Stacking | 元学习器融合 |
| 多样性 | 集成有效的关键 |

## 应用场景

- 结构化/表格数据建模(竞赛常胜方法)
- 随机森林 / GBDT / XGBoost / LightGBM
- 分类、回归、排序任务
- 提升单模型的稳健性与精度

## 优点与局限

- 优点:精度与稳健性通常优于单模型;Bagging 抗过拟合;灵活可组合。
- 局限:训练/推理成本高(多模型);可解释性下降;需保证基学习器多样性;调参更复杂。

## 常见误区

- 集成不是"越多越好":边际收益递减而成本上升。
- 基学习器需有多样性,若几乎相同则集成无益。
- Bagging 降方差、Boosting 降偏差,机制不同。
- 集成会牺牲一定的可解释性。
