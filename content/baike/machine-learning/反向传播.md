# 反向传播

## 定义

**一句话定义：** 反向传播(Backpropagation)是训练人工神经网络的算法,它利用链式法则从输出层向输入层逐层反向计算损失函数对每个参数的梯度,再配合梯度下降更新权重,以最小化预测误差。

**通俗类比：** 像考完试对答案后追溯错因——总分错了(损失),从最后一题往前逐题分析"这一步该负多少责任"(梯度),再据此调整每一处的做法(权重),下次少犯错。

> 多义说明:严格说 backpropagation 指"梯度的反向计算"部分;日常常与整个训练循环(前向传播 + 反向传播 + 参数更新)连用。

## 原理与机制

一次训练迭代包含:

1. **前向传播(Forward):** 输入逐层计算,得到预测输出与损失 L。
2. **反向传播(Backward):** 用链式法则从输出层向输入层计算 ∂L/∂w;每层把误差项 δ 反向传递,得到各参数的梯度。
3. **参数更新:** 优化器(SGD、Momentum、Adam 等)按梯度更新权重。

其实现依赖**自动微分(autodiff)** 与**计算图**(静态图/动态图),由深度学习框架自动完成求导。

## 关键组成

| 环节 | 作用 |
|------|------|
| 前向传播 | 计算输出与损失 |
| 损失函数 | 度量预测与真值的差距 |
| 链式法则 / 自动微分 | 逐层反向求梯度 |
| 优化器 | 依据梯度更新参数 |
| 计算图 | 记录运算以便反向求导 |

## 应用场景

- 训练 CNN、RNN、Transformer 等各类神经网络
- 深度学习框架(PyTorch、TensorFlow/JAX)的自动求导核心
- 回归、分类、生成模型等监督/自监督训练

## 优点与局限

- 优点:高效计算多层网络的全部参数梯度,使深度网络可训练,是深度学习成立的算法基石。
- 局限:可能出现梯度消失/爆炸;要求损失与激活可微;易陷局部极小/鞍点;需大量数据与算力;训练过程可解释性差。

## 常见误区

- 反向传播 ≠ 梯度下降:前者负责"算梯度",后者负责"用梯度更新参数"。
- 它不是对人脑神经元学习的精确刻画,只是受启发的工程算法。
- 需损失函数可微;对不可微环节需特殊处理(如直通估计)。
