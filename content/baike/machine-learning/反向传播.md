# 反向传播


> 📌 **导航**：本文是 **反向传播** 词条，属于 machine-learning 术语集。相关枢纽：[[深度学习从零到精通]]、[[激活函数]]、[[梯度下降]]、[[Transformer架构深度解析]]。

## 定义

**一句话定义：** 反向传播（Backpropagation）是训练人工神经网络的算法，它利用链式法则从输出层向输入层逐层反向计算损失函数对每个参数的梯度，再配合梯度下降更新权重，以最小化预测误差。

**通俗类比：** 像考完试对答案后追溯错因——总分错了（损失），从最后一题往前逐题分析"这一步该负多少责任"（梯度），再据此调整每一处的做法（权重），下次少犯错。

> 多义说明：严格说 backpropagation 指"梯度的反向计算"部分，日常常与整个训练循环（前向 + 反向 + 更新）连用。

## 为什么需要它

深层网络里每个权重对最终误差的"责任"无法直接算。反向传播用链式法则把误差从输出逐层反向归因，一次高效算出所有参数的梯度，使海量参数的网络能被梯度下降训练——这正是深度学习得以落地的算法基石。

## 核心机制

一次训练迭代包含三步：

1. **前向传播**：输入逐层计算，得到预测输出与损失 L。
2. **反向传播**：用链式法则从输出层向输入层计算 ∂L/∂w，逐层传递误差项 δ，得到各参数的梯度。
3. **参数更新**：优化器（SGD、Momentum、Adam 等）按梯度更新权重。

其实现依赖**自动微分**与**计算图**（静态 / 动态），由 PyTorch、TensorFlow / JAX 等框架自动求导。

| 环节 | 作用 |
|------|------|
| 前向传播 | 计算输出与损失 |
| 损失函数 | 度量预测与真值的差距 |
| 链式法则 / 自动微分 | 逐层反向求梯度 |
| 优化器 | 依据梯度更新参数 |
| 计算图 | 记录运算以便反向求导 |

## 具体示例

训练一个 MLP：一批数据前向得到交叉熵损失 → 反向算出每层权重 W 的梯度 → Adam 更新。CNN、RNN、Transformer 的训练都是这套骨架，只是计算图里的算子不同。

## 何时用 / 何时不用

- **用**：几乎一切可微神经网络的监督 / 自监督训练。
- **不适用**：损失含不可微环节时需用直通估计 / 重参数化绕过；推理阶段不需要反向传播。

## 优劣与代价

✅ 一次反向即高效算出全部参数梯度，使深层网络可训练。
⚠️ 可能出现梯度消失 / 爆炸；要求损失与激活可微。
⚠️ 易陷入局部极小 / 鞍点，需大量数据与算力，过程可解释性差。

## 与相关概念的区别

- **vs 梯度下降**：反向传播负责"算梯度"，梯度下降负责"用梯度更新参数"，二者配合而非同一物。
- **vs 数值微分 / 有限差分**：反向传播解析精确、代价与参数数成正比，有限差分要逐参数扰动、代价极高。
- **vs [[激活函数]]**：激活是否可微、是否饱和直接影响反向传播（引发梯度消失）。

## 常见误区

- 反向传播和梯度下降是同一件事的两个名字。
- 反向传播精确模拟了人脑神经元中生物学的学习机制。
- 反向传播只能用于单层隐藏层的浅网络，无法训练有海量参数的深层网络。

## 面试速答

> 🎯 反向传播=训练神经网络的求梯度算法：前向算出预测与损失，再依链式法则从输出层向输入层逐层反向计算损失对每个参数的偏导，一次高效得到所有梯度交给优化器更新。它是深度学习成立的算法基石。要分清：反向传播只算梯度、梯度下降才用梯度更新；它要求损失与激活可微，可能遭遇梯度消失/爆炸。
> 🔍 追问：反向传播与梯度下降是什么关系？（前者用链式法则算梯度，后者据该梯度更新权重，二者协同但职责不同）
> 🔍 追问：为什么激活函数选择会影响反向传播？（sigmoid / tanh 在饱和区导数趋 0，逐层相乘引发梯度消失；ReLU 类可缓解）
