# 卷积神经网络(CNN)


> 📌 **导航**：本文是 **卷积神经网络(CNN)** 词条，属于 data-science 术语集。相关枢纽：[[A B测试与实验设计]]、[[ETL]]、[[MLOps实践]]、[[RNN LSTM GRU]]、[[卷积神经网络(CNN)]]。

## 定义

**一句话定义：** 卷积神经网络（CNN）是用卷积核在局部感受野上滑动提取空间特征、通过权值共享与池化降维的深度神经网络，尤其擅长图像等网格数据，是现代计算机视觉的骨干结构。

**通俗类比：** 像拿一个小放大镜在照片上滑动作答"这一块有没有边缘、纹理"，把同一套局部规律（卷积核）复制到全图，再用池化只保留最显著的特征，层层组合出"边缘→眼睛→脸→人"。

## 为什么需要它

用全连接层处理图像会参数爆炸，且不保留空间结构、对物体平移很敏感。卷积以"局部连接 + 权值共享"把参数压到很小并天然捕捉平移不变的局部模式，池化进一步降维、提供尺度与位置鲁棒，二者叠加让深度网络能高效、可扩展地从像素学出视觉特征。

## 核心机制

- **卷积：** 卷积核在输入上滑动做点积，stride 控制步长、padding 控制边界与输出尺寸。例如 `Conv2d(3, 64, kernel_size=3, padding=1)` 把 `[B, 3, 224, 224]` 转成 `[B, 64, 224, 224]`——padding=1 保持空间尺寸，通道数从 3 变 64。
- **非线性激活：** ReLU 引入非线性，提升表达能力。
- **池化：** 最大/平均池化对特征图降采样，缩小尺寸、增强对位置与尺度的鲁棒性。
- **逐层堆叠：** 浅层学边缘纹理、深层组合出语义部件；感受野随深度扩大。
- **残差连接（ResNet）：** 用跳跃连接让恒等映射直接回传，缓解深层网络的退化与梯度消失，使上百层可训练。

```python
class ResBlock(nn.Module):
    def forward(self, x):
        return F.relu(x + self.conv2(F.relu(self.conv1(x))))  # x 经捷径直接相加
```

经典架构演进：

| 模型 | 年份 | Top-1 | 参数量 | 创新 |
|------|------|-------|--------|------|
| AlexNet | 2012 | 63.3% | 61M | ReLU、Dropout |
| VGG-16 | 2014 | 74.5% | 138M | 小卷积核堆叠 |
| ResNet-50 | 2015 | 76.1% | 25M | 残差连接 |
| EfficientNet | 2019 | 84.3% | 66M | 复合缩放 |

## 具体示例

一张 224×224×3 的猫图：先经多组"卷积+ReLU+池化"把 3 通道扩展到数百通道、空间尺寸逐减半，浅层响应边缘、深层响应耳朵与猫脸；末尾把特征图 Flatten 接入全连接层，输出 softmax 落在"猫"这一类。全程卷积核参数因权值共享远小于同规模全连接。

## 何时用 / 何时不用

- **用：** 图像分类/检测/分割、视频、任何具局部结构与平移不变性的网格数据；中小数据与边缘部署也友好。
- **不用：** 表格数据（树模型更强）、强长程全局依赖（Transformer 更优）、纯序列任务（RNN/Transformer）；1D-CNN 虽可用但通常非首选。

## 优劣与代价

✅ 权值共享参数少、局部特征 + 平移不变、硬件与部署友好、可堆得很深。
⚠️ 对旋转/大幅尺度变化不变性有限；小数据易过拟合。
⚠️ 建模远距离全局依赖弱，需靠堆深/扩大感受野，弱于自注意力。

## 与相关概念的区别

- **vs 全连接网络：** 卷积靠局部连接 + 权值共享保结构、省参数；全连接参数随像素平方爆炸且丢空间信息。
- **vs RNN：** CNN 抓空间局部模式、可并行；RNN 沿时间串行递推。
- **vs Vision Transformer：** CNN 有局部与平移归纳偏置、小数据更省更稳；ViT 用全局自注意力、大数据上限更高但更吃数据。

## 常见误区

- CNN 之所以省参数，是因为每个神经元都连接输入的所有像素。
- 残差连接的作用是给网络增加更多可学习参数以提升容量。
- 池化层的主要作用是提取更细粒度的局部特征。

## 面试速答

> 🎯 CNN=局部卷积核滑动提空间特征 + 权值共享省参数 + 池化降维增强鲁棒，逐层从边缘组合到语义，ReLU 加非线性；ResNet 残差用跳跃连接缓解深层退化、让超深可训。强在图像/网格数据的平移不变与效率，弱在全局长程依赖（交给 Transformer）与表格任务。
