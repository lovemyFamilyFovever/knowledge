# 推荐系统

## 推荐系统架构

```
召回(百万->千) -> 粗排(千->百) -> 精排(百->十) -> 重排(最终展示)
     ↓                ↓               ↓               ↓
  双塔/图         轻量模型         多目标模型      业务规则
```

## 协同过滤

### 用户协同过滤

找到与目标用户兴趣相似的K个用户，推荐他们喜欢的物品。

### 物品协同过滤

```python
# 物品相似度矩阵
# sim(i,j) = |喜欢i且喜欢j的用户| / sqrt(|喜欢i的| * |喜欢j的|)
```

### 矩阵分解（MF）

```
R ≈ U × V^T
R: 用户-物品评分矩阵 [m×n]
U: 用户特征矩阵 [m×k]
V: 物品特征矩阵 [n×k]
```

```python
# SGD优化
for epoch in range(epochs):
    for (u, i, r) in ratings:
        pred = U[u] @ V[i]
        err = r - pred
        U[u] += lr * (err * V[i] - reg * U[u])
        V[i] += lr * (err * U[u] - reg * V[i])
```

## 深度推荐模型

| 模型 | 核心思想 | 特点 |
|------|----------|------|
| Wide&Deep | 记忆(Wide)+泛化(Deep) | Google经典 |
| DeepFM | FM自动特征交叉+DNN | 无需手工特征 |
| DIN | 用户兴趣注意力建模 | 关注历史行为 |
| DIEN | 兴趣演化GRU | 时序建模 |
| DCN | 显式交叉网络 | 自动高阶交叉 |

## 召回策略

| 策略 | 原理 | 特点 |
|------|------|------|
| 双塔模型 | 用户塔+物品塔，向量检索 | 经典 |
| 图召回 | 用户-物品二部图游走 | 冷启动好 |
| 序列召回 | 用户行为序列建模 | 个性化强 |
| 多路召回 | 多种策略融合 | 覆盖全面 |

## 评估指标

| 指标 | 说明 | 计算 |
|------|------|------|
| 点击率CTR | 推荐结果被点击比例 | clicks / impressions |
| 转化率CVR | 点击后购买比例 | purchases / clicks |
| NDCG | 排序质量 | 考虑位置的DCG |
| 覆盖率 | 推荐物品多样性 | 推荐物品数 / 总物品数 |
