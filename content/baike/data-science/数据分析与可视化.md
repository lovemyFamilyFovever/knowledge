# 数据分析与可视化


> 📌 **导航**：本文是 **数据分析与可视化** 词条，属于 data-science 术语集。相关枢纽：[[A B测试与实验设计]]、[[ETL]]、[[MLOps实践]]、[[RNN LSTM GRU]]、[[卷积神经网络(CNN)]]。

## 定义

**一句话定义：** 数据分析是把原始数据经清洗、统计与建模转化为可行动洞察的过程，可视化则用图形把这些洞察直观呈现给人判断。

**通俗类比：** 像体检报告——数据分析是把血液样本化验成一堆指标，可视化再把指标画成趋势图和对照箭头，让医生一眼看出"哪里异常、要不要紧"。

## 为什么需要它

数据本身不做决策，人要快速看懂"发生了什么、为什么、该做什么"。清洗去噪保证结论不建立在脏数据上，统计给出量化依据，可视化利用人脑对图形的直觉发现趋势、异常与关系。三者合起来，把冷数字变成能被沟通、被行动的故事。

## 做法

- **数据清洗：**

| 步骤 | 操作 | 示例 |
|------|------|------|
| 缺失值 | 填充或删除 | `df.fillna(0)` |
| 重复值 | 去重 | `df.drop_duplicates()` |
| 异常值 | 检测处理 | `df[df['age'] < 150]` |
| 类型转换 | 统一格式 | `pd.to_datetime(df['date'])` |
| 特征工程 | 派生新列 | `pd.cut(df['age'], bins)` |

- **探索性统计：**

| 概念 | 说明 |
|------|------|
| 均值 Mean | 平均值，受异常值影响 |
| 中位数 Median | 中间值，更稳健 |
| 标准差 Std | 数据离散程度 |
| 相关系数 | 两变量线性关系强度（-1 到 1） |
| p 值 | 假设检验的显著性水平 |
| 置信区间 | 估计值的可靠范围 |

- **可视化工具：** NumPy 做数组与均值/标准差等数值计算，Matplotlib/Seaborn 负责绘图，核心的加载与分组聚合由 Pandas 完成：

```python
df = pd.read_csv('data.csv')
df.groupby('category')['price'].mean()
df[df['age'] > 30].sort_values('salary', ascending=False)
```

- **图表选型：**

| 图表 | 适用场景 |
|------|----------|
| 折线图 | 趋势变化（时间序列） |
| 柱状图 | 分类对比 |
| 饼图 | 占比分布 |
| 散点图 | 两个变量关系 |
| 热力图 | 相关性矩阵 |
| 箱线图 | 数据分布与异常值 |
| 直方图 | 频率分布 |

## 具体示例

拿到一份销售 csv：先 `dropna`/`drop_duplicates` 去缺失重复、`to_datetime` 统一时间、用规则剔除异常；再 `groupby('地区')['销售额'].mean()` 看区域差异；用折线看月度趋势、热力图看各指标相关、箱线图揪出异常门店；最后把关键结论用一两张图直观呈现给管理层。

## 何时用 / 何时不用

- **用：** 任何需要理解数据、汇报现状、支撑业务决策的场景；探索性分析定位问题方向。
- **不用：** 已固化成自动预测的生产闭环（交给建模 pipeline / [[MLOps实践]]）；数据脏乱到须先做工程治理时，走 [[ETL]]/数据仓库再谈分析。

## 优劣与代价

✅ 直观、门槛低、沟通力强，能快速暴露趋势、异常与关系。
⚠️ 可视化易误导：截断坐标轴、选错图型、挑选性呈现都会扭曲结论。
⚠️ 探索性分析易过拟合"看起来的模式"，图型选择高度依赖领域判断。

## 与相关概念的区别

- **vs 数据挖掘/机器学习：** 本项偏描述性 + 人做判断，ML 偏自动化预测与模式挖掘。
- **vs 可视化大屏：** 大屏只是呈现层，数据分析含清洗→统计→洞察的完整链条。
- **vs [[A B测试与实验设计]]：** 实验给出因果结论，分析可视化负责描述与呈现（相关而非因果）。

## 常见误区

- 只要图表做得漂亮，就能证明数据里的结论是对的。
- 均值最能代表整体水平，任何情况都应该用均值。
- 相关系数高，就说明两个变量之间存在因果关系。

## 面试速答

> 🎯 数据分析=清洗（缺失/重复/异常/类型）→探索统计（均值/标准差/相关系数/p 值）→可视化选型（趋势折线、对比柱、关系散点、分布直方、相关热力），Python 靠 NumPy+Pandas+Matplotlib 三件套，把数字变成可沟通的洞察。警惕截断轴与挑选呈现的误导，相关不等于因果。
