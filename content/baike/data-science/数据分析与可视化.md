# 数据分析与可视化

## 数据分析工具链

**一句话定义：** 数据分析是从数据中提取有价值信息的过程，可视化工具让数据"说话"。

### Python数据分析三件套

**NumPy（数值计算）**
```python
import numpy as np
arr = np.array([1, 2, 3, 4, 5])
print(arr.mean())   # 平均值: 3.0
print(arr.std())    # 标准差: 1.414
```

**Pandas（数据处理）**
```python
import pandas as pd
df = pd.read_csv('data.csv')
df.groupby('category')['price'].mean()  # 按分类求平均价格
df[df['age'] > 30].sort_values('salary', ascending=False)
```

**Matplotlib/Seaborn（可视化）**
```python
import matplotlib.pyplot as plt
plt.scatter(df['x'], df['y'], c=df['label'])
plt.xlabel('X轴')
plt.title('散点图')
plt.show()
```

### 数据清洗步骤

| 步骤 | 操作 | 代码示例 |
|------|------|----------|
| 缺失值 | 填充或删除 | `df.fillna(0)` |
| 重复值 | 去重 | `df.drop_duplicates()` |
| 异常值 | 检测处理 | `df[df['age'] < 150]` |
| 类型转换 | 统一格式 | `df['date'] = pd.to_datetime(df['date'])` |
| 特征工程 | 创建新特征 | `df['age_group'] = pd.cut(df['age'], bins)` |

### 常用图表

| 图表 | 适用场景 |

| 折线图 | 趋势变化（时间序列）|

### 统计分析基础

| 概念 | 说明 |
|------|------|
| 均值(Mean) | 平均值，受异常值影响 |
| 中位数(Median) | 中间值，更稳健 |
| 标准差(Std) | 数据离散程度 |
| 相关系数 | 两个变量的线性关系强度(-1到1) |
| p值 | 假设检验的显著性水平 |
| 置信区间 | 估计值的可靠范围 |
