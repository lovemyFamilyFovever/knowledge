# 时间序列分析


> 📌 **导航**：本文是 **时间序列分析** 词条，属于 data-science 术语集。相关枢纽：[[A B测试与实验设计]]、[[ETL]]、[[MLOps实践]]、[[RNN LSTM GRU]]、[[卷积神经网络(CNN)]]。

## 定义

**一句话定义：** 时间序列分析是对按时间有序采样的数据建模，捕捉其中的趋势、季节、周期与自相关，以进行预测和异常检测的方法体系。

**通俗类比：** 像看一个人每天的体重记录——找出大方向（趋势）、周期性起伏（季节/周期）、以及"今天多大程度由前几天决定"（自相关），再据此预测下周体重。

## 为什么需要它

销量、气温、股价、监控指标等数据按时间有序，存在普通表格数据没有的自相关、趋势与季节性——一旦打乱顺序信息就失真。需要专门方法刻画这些时间结构并外推未来，支撑库存、容量规划、告警等决策；且预测只能用"未来不可见"的方式滚动验证，否则极易数据泄漏。

## 核心机制

- **平稳性：** 统计特性不随时间漂移；ARIMA 用差分把非平稳序列变平稳。
- **经典方法：**

| 方法 | 原理 | 适用 | 优缺点 |
|------|------|------|--------|
| ARIMA | 自回归+差分+移动平均 | 单变量预测 | 经典但假设线性 |
| SARIMA | 季节性 ARIMA | 有季节性 | 需确定季节周期 |
| ETS | 指数平滑 | 短期预测 | 简单高效 |
| Prophet | 加法分解(趋势+季节+假期) | 业务数据 | Facebook 开源，易用 |

```
ARIMA(p, d, q): p 自回归阶 / d 差分阶(使平稳) / q 移动平均阶
X_t = c + Σ(φ_i · X_{t-i}) + Σ(θ_i · ε_{t-i}) + ε_t
```

工程上按 (p,d,q) 定阶、fit 后 forecast 未来若干步（如 statsmodels `ARIMA(data, order=(1,1,1)).fit().forecast(steps=30)`），p、q 常借 ACF/PACF 选。

- **深度方法（长序列/多变量）：**

| 方法 | 原理 | 特点 |
|------|------|------|
| LSTM | 循环网络 | 长序列建模 |
| N-BEATS / TiDE | 纯 MLP 堆叠 | 简单高效、可扩展 |
| PatchTST | Transformer + Patch | 长序列 SOTA |
| iTransformer | 变量作 token | 多变量建模 |
| TimesNet | 2D 建模 | 捕获多周期 |

PatchTST 的思路是把序列切成小段当 token，类似 ViT 处理图像：

```
序列 [t1..t8] → Patch [t1,t2][t3,t4][t5,t6][t7,t8] → 每个 Patch 作为 token 送入 Transformer
```

- **评估指标：**

| 指标 | 公式 | 特点 |
|------|------|------|
| MAE | mean(\|y-ŷ\|) | 直观 |
| RMSE | sqrt(mean((y-ŷ)^2)) | 惩罚大误差 |
| MAPE | mean(\|y-ŷ\|/\|y\|) | 百分比、可跨尺度 |
| MASE | MAE / MAE_baseline | 相对朴素预测的增益 |

## 具体示例

预测电商日销量：先看趋势/做平稳性检验，必要时差分去趋势；用 ARIMA 按 ACF/PACF 定阶拟合、forecast 未来 30 天；若节假日效应强改用 Prophet；多变量长序列上 Transformer。评估一律用滚动/前向验证算 MAE/RMSE，并与"昨天=今天"的朴素基线比 MASE——绝不能随机打乱切分，那会让模型偷看到未来。

## 何时用 / 何时不用

- **用：** 数据按（大致）等间隔时间有序、含趋势/季节、需外推预测或异常检测。
- **不用：** 样本间无时序依赖（打乱无所谓）时用普通监督模型；序列极短或近似噪声（如强随机股价）时预测上限很低，需谨慎。

## 优劣与代价

✅ 经典统计可解释、小数据可用、是强基线；深度模型长程、多变量、跨尺度能力强。
⚠️ ARIMA/ETS 假设线性、多单变量；深度模型吃数据、偏黑箱、易过拟合。
⚠️ 时序验证必须滚动，随机切分会数据泄漏，给出虚高指标。

## 与相关概念的区别

- **vs 普通回归/分类：** 时序有自相关、顺序不可打乱，需平稳性处理与滚动验证。
- **vs [[因果推断]]：** 预测未来值≠解释干预效应，相关外推不等于因果。
- **ARIMA vs ETS：** 差分 + AR/MA 与状态空间指数平滑是一体两面的等价家族。

## 常见误区

- 做时序预测时，把数据随机打乱后再切分训练集和测试集是安全的。
- ARIMA 的差分阶 d 取得越大，模型预测就越准。
- 只要模型在训练集上把趋势拟合得很好，它的未来预测就一定准确。

## 面试速答

> 🎯 时间序列=对时间有序数据建模趋势/季节/周期/自相关以预测与异常检测：经典 ARIMA(p,d,q)/SARIMA/Prophet 靠差分保平稳，深度侧 LSTM/N-BEATS/PatchTST 做长程多变量；评估用 MAE/RMSE/MAPE/MASE，必须滚动前向验证、严禁随机切分造成泄漏。
