# 时间序列分析


> 📌 **导航**：本文是 **时间序列分析** 词条，属于 data-science 术语集。相关枢纽：[[A B测试与实验设计]]、[[ETL]]、[[MLOps实践]]、[[RNN LSTM GRU]]、[[卷积神经网络(CNN)]]。

## 经典方法

| 方法 | 原理 | 适用 | 优缺点 |
|------|------|------|--------|
| ARIMA | 自回归+移动平均 | 单变量预测 | 经典但假设线性 |
| Prophet | 加法分解(趋势+季节+假期) | 业务数据 | Facebook开源，易用 |
| ETS | 指数平滑 | 短期预测 | 简单高效 |
| SARIMA | 季节性ARIMA | 有季节性 | 需要确定季节周期 |

## ARIMA模型

```
ARIMA(p, d, q):
- p: 自回归阶数（用过去p个值预测）
- d: 差分阶数（使序列平稳）
- q: 移动平均阶数（用过去q个误差）

模型: X_t = c + Σ(φ_i * X_{t-i}) + Σ(θ_i * ε_{t-i}) + ε_t
```

```python
from statsmodels.tsa.arima.model import ARIMA
model = ARIMA(train_data, order=(1, 1, 1))
fitted = model.fit()
forecast = fitted.forecast(steps=30)
```

## 深度学习方法

| 方法 | 原理 | 特点 |
|------|------|------|
| LSTM | 循环网络 | 长序列建模 |
| N-BEATS | 纯MLP堆叠 | 简单高效，可解释 |
| PatchTST | Transformer+Patch | 长序列SOTA |
| iTransformer | 变量作token | 多变量建模 |
| TimesNet | 2D建模 | 周期性捕获 |
| TiDE | 纯MLP | 快速，适合大规模 |

## PatchTST核心思想

```
时间序列: [t1, t2, t3, t4, t5, t6, t7, t8]
Patch划分: [t1,t2] [t3,t4] [t5,t6] [t7,t8]
每个Patch作为一个token送入Transformer
```

类似ViT处理图像的方式，捕获局部时序模式。

## 评估指标

| 指标 | 公式 | 特点 |
|------|------|------|
| MAE | mean(\|y-ŷ\|) | 直观 |
| RMSE | sqrt(mean((y-ŷ)^2)) | 惩罚大误差 |
| MAPE | mean(\|y-ŷ\|/\|y\|) | 百分比，可跨尺度比较 |
| MASE | MAE/MAE_baseline | 相对于朴素预测 |
