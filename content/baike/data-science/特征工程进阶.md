# 特征工程进阶

## 特征类型处理

| 类型 | 处理方法 | 代码示例 |
|------|----------|----------|
| 数值型 | 标准化、归一化、分箱 | StandardScaler, KBinsDiscretizer |
| 类别型 | One-Hot、Target Encoding | pd.get_dummies, catboost编码 |
| 文本型 | TF-IDF、BERT Embedding | TfidfVectorizer |
| 时间型 | 提取年/月/日/星期/小时 | df['hour'] = df['ts'].dt.hour |
| 地理型 | 经纬度、GeoHash、距离 | haversine公式 |

## Target Encoding

```python
# 用目标变量的统计量编码类别特征
# 例：城市 -> 该城市用户的平均购买率
city_encoding = df.groupby('city')['purchased'].mean()
df['city_encoded'] = df['city'].map(city_encoding)

# 防止过拟合：贝叶斯平滑
def bayesian_target_encode(df, cat_col, target_col, m=100):
    global_mean = df[target_col].mean()
    stats = df.groupby(cat_col)[target_col].agg(['mean', 'count'])
    smooth = (stats['count'] * stats['mean'] + m * global_mean) / (stats['count'] + m)
    return df[cat_col].map(smooth)
```

## 交叉特征

```python
# 自动生成交叉特征
import featuretools as ft
es = ft.EntitySet(id="data")
es.add_dataframe(dataframe=df, dataframe_name="orders")
feature_matrix = ft.dfs(
    entityset=es,
    target_dataframe_name="orders",
    max_depth=2,  # 交叉深度
    trans_primitives=["add_numeric", "multiply_numeric"]
)
```

## 特征选择方法

| 方法 | 原理 | 工具 |
|------|------|------|
| 方差过滤 | 删除低方差特征 | VarianceThreshold |
| 相关性过滤 | 删除高相关特征 | corr() + 阈值 |
| 单变量选择 | 统计检验 | SelectKBest |
| L1正则化 | Lasso自动选择 | LassoCV |
| 树模型重要度 | 特征重要性 | feature_importances_ |
| SHAP | 博弈论 | shap.summary_plot |

## 特征工程最佳实践

1. **理解业务**：特征的物理含义比技巧更重要
2. **避免泄露**：不能用未来信息预测过去
3. **统一处理**：训练集和测试集用相同的transformer
4. **记录Pipeline**：确保可复现
5. **监控漂移**：线上特征分布变化需告警
