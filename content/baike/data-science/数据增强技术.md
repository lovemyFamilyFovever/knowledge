## 文本增强

| 方法 | 原理 | 代码示例 |
|------|------|----------|
| 同义词替换(SR) | 用同义词替换 | "好" -> "优秀" |
| 随机插入(RI) | 插入随机同义词 | 增加多样性 |
| 随机交换(RS) | 交换词序 | 打乱语序 |
| 随机删除(RD) | 随机删除词 | 增加鲁棒性 |
| 回译 | 中->英->中 | 改写句子 |
| EDA | 综合以上4种 | 最常用 |

```python
# 回译示例
from googletrans import Translator
def back_translate(text, mid='en'):
    translator = Translator()
    translated = translator.translate(text, dest=mid).text
    return translator.translate(translated, dest='zh-cn').text
```

## Mixup

线性插值两个样本，平滑决策边界：

```python
def mixup(x1, y1, x2, y2, alpha=0.2):
    lam = np.random.beta(alpha, alpha)
    x_mix = lam * x1 + (1 - lam) * x2
    y_mix = lam * y1 + (1 - lam) * y2
    return x_mix, y_mix
```

## CutMix

```python
def cutmix(x1, y1, x2, y2, alpha=1.0):
    lam = np.random.beta(alpha, alpha)
    # 随机裁剪区域
    cx, cy = np.random.randint(w), np.random.randint(h)
    rw, rh = int(w * np.sqrt(1-lam)), int(h * np.sqrt(1-lam))
    x1[:, cy-rh:cy+rh, cx-rw:cx+rw] = x2[:, cy-rh:cy+rh, cx-rw:cx+rw]
    return x1, lam * y1 + (1-lam) * y2
```
