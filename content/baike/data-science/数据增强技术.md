# 数据增强技术


> 📌 **导航**：本文是 **数据增强技术** 词条，属于 data-science 术语集。相关枢纽：[[A B测试与实验设计]]、[[ETL]]、[[MLOps实践]]、[[RNN LSTM GRU]]、[[卷积神经网络(CNN)]]。

## 定义

**一句话定义：** 数据增强是对训练样本施加"保持语义/标签不变"的扰动，以人为扩充数据多样性、提升模型泛化能力、缓解过拟合与数据不足的技术。

**通俗类比：** 像备考时把同一道题换个数字、换个说法再练——题目本质没变，但变体更多，逼模型学到真正的规律而不是死记样题。

## 为什么需要它

标注数据稀缺、类别不平衡、模型容易记住训练集。数据增强用近似无限的"合法变体"扩充样本、平衡分布、把平移/翻转/语序等不变性先验直接注入训练，几乎零成本地提升鲁棒性与泛化——是数据侧对抗过拟合最常用的手段。

## 核心机制

- **图像增强：** 翻转、旋转、随机裁剪、颜色抖动、随机擦除，再归一化。

```python
train_transform = transforms.Compose([
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.RandomRotation(15),
    transforms.ColorJitter(brightness=0.2, contrast=0.2),
    transforms.RandomResizedCrop(224, scale=(0.8, 1.0)),
    transforms.RandomErasing(p=0.3),
    transforms.Normalize(mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])
])
```

- **文本增强：**

| 方法 | 原理 |
|------|------|
| 同义词替换 SR | 用同义词替换，如"好"→"优秀" |
| 随机插入/交换/删除 | 增加多样性、打乱语序、提升鲁棒性 |
| 回译 | 中→英→中改写句子 |
| EDA | 综合以上四种操作，最常用 |

回译即把句子翻成中间语言再翻回，用两种语言的表达差异得到语义等价的改写。

- **高级混合增强：** Mixup 对两个样本及其标签做线性插值，平滑决策边界：

```python
def mixup(x1, y1, x2, y2, alpha=0.2):
    lam = np.random.beta(alpha, alpha)
    return lam * x1 + (1 - lam) * x2, lam * y1 + (1 - lam) * y2
```

CutMix 则把一幅图的随机矩形区域贴到另一幅图上，标签按替换面积比例混合。

- **时序增强：**

| 方法 | 原理 |
|------|------|
| 时间扭曲 | 随机拉伸/压缩时间轴 |
| 窗口切片 | 随机截取子序列 |
| 加噪声 | 添加高斯噪声 |
| DTW 对齐 | 动态时间规整生成变体 |

## 具体示例

猫狗分类训练集小且易过拟合：训练阶段对每张图随机水平翻转、±15° 旋转、RandomResizedCrop、颜色抖动，并以一定概率混入一批 Mixup 样本；验证/测试集一律不增强。模型因此见到更多姿态与光照变化，测试集泛化差距收窄。注意不能把会翻转标签的变换（如把数字"6"上下翻成"9"）用进去。

## 何时用 / 何时不用

- **用：** 数据量小、类别不平衡、明显过拟合、或部署环境本身会有扰动（旋转、噪声、光照）需要鲁棒性。
- **不用/注意：** 增强必须保持标签语义；验证与测试集不应增强（否则评的是扰动而非能力）；强度过大会破坏可学习信号，需按任务调参。

## 优劣与代价

✅ 近乎免费扩样、涨点、抗过拟合，可用于类别平衡与注入不变性先验。
⚠️ 选错增强会引入偏差或直接损坏标签。
⚠️ 增强强度/组合需调参，部分任务收益有限。

## 与相关概念的区别

- **vs 重采样/SMOTE：** 采样通过复制/加权处理不平衡，SMOTE 在特征空间插值造点；数据增强在原始数据上造合法变体。
- **vs 正则化（Dropout/权重衰减）：** 正则化约束模型容量，增强扩充数据，二者互补、都能抗过拟合。
- **vs 归一化/标准化：** 后者是统一尺度的预处理，不产生新样本。

## 常见误区

- 数据增强应当同时施加在训练集和测试集上。
- 增强越猛、种类越多，模型效果就一定越好。
- 任何图像变换都能安全地用于增强而不会改变标签。

## 面试速答

> 🎯 数据增强=对样本施加标签不变的扰动来扩数据、注入不变性先验、抗过拟合：图像用翻转/旋转/裁剪/颜色抖动，文本用 EDA 与回译，Mixup/CutMix 做样本与区域插值，时序用时间扭曲与加噪。关键是保持标签语义、只增强训练集、强度需调；与正则化互补，区别于重采样。
