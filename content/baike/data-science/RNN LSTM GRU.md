# RNN/LSTM/GRU


> 📌 **导航**：本文是 **RNN/LSTM/GRU** 词条，属于 data-science 术语集。相关枢纽：[[A B测试与实验设计]]、[[ETL]]、[[MLOps实践]]、[[RNN LSTM GRU]]、[[卷积神经网络(CNN)]]。

## 定义

**一句话定义：** RNN/LSTM/GRU 是处理序列数据的神经网络家族——RNN 用隐状态沿时间步传递历史信息，LSTM/GRU 以门控机制缓解其长序列上的梯度消失，从而能建模文本、语音、时序等有序数据。

**通俗类比：** 像边读句子边做笔记——RNN 每读一个词更新一次脑内笔记（隐状态）；但普通 RNN 记性差、读到句尾就忘了句首，LSTM/GRU 给笔记加了"擦除/写入/调取"的夹子（门控），能长期记住关键信息。

## 为什么需要它

全连接与 CNN 假设输入定长、样本独立，处理不了变长、有序、上下文依赖的序列。RNN 家族用循环结构把"到目前为止的历史"压缩进隐状态并逐步递推，天然适配变长序列与时序依赖，是 Transformer 之前序列建模（语音、翻译、时间预测）的主力。

## 核心机制

- **RNN：** 隐状态沿时间递推，每步由上一步隐状态与当前输入共同更新。
- **LSTM：** 用 cell state 做长期"传送带"、三个门控制读写，缓解梯度消失、记住长程信息。
- **GRU：** LSTM 的简化，合并遗忘/输入门为更新门，无独立 cell state，参数更少、训练更快。
- **双向 RNN：** 正向与反向各编码再拼接，让每个位置看到前后文（仅适用于能拿到整段的离线任务）。

RNN 的基本递推：

```python
h_t = tanh(W_hh @ h_{t-1} + W_xh @ x_t + b)
```

其根本问题是梯度在时间步间连乘，长序列上指数衰减或增长，导致远处的信息记不住。LSTM 用 cell state 让长期信息近乎无损传递，靠门控决定增删：

```python
c_t = f_t * c_{t-1} + i_t * g_t   # 遗忘旧信息 + 写入新信息
h_t = o_t * tanh(c_t)             # 门控输出
```

| 门 | 公式 | 作用 | 类比 |
|----|------|------|------|
| 遗忘门 f | σ(W_f·[h,x]+b_f) | 决定丢弃什么 | 擦黑板 |
| 输入门 i | σ(W_i·[h,x]+b_i) | 决定写入什么 | 写笔记 |
| 输出门 o | σ(W_o·[h,x]+b_o) | 决定输出什么 | 回答问题 |
| 候选值 g | tanh(W_g·[h,x]+b_g) | 候选新信息 | 新知识 |

GRU 用更新门 z（控制保留多少旧状态、写入多少新信息）和重置门 r（决定算候选时参考多少旧状态）两个门达到相近效果。

| 特性 | LSTM | GRU |
|------|------|-----|
| 门数量 | 3 个 | 2 个 |
| 参数量 | 较多 | 较少 |
| 长序列 | 更好 | 略逊 |
| 训练速度 | 较慢 | 较快 |

## 具体示例

情感分析句子"这部电影一点都不难看"：LSTM 沿词递推，靠门控把"不""难看""一点都不"在隐状态里组合，最终判为正面。机器翻译里传统 RNN 要把整句压进单个上下文向量，句子一长就形成信息瓶颈——这正是它被 Transformer 注意力机制取代的直接原因。语音识别则偏爱 LSTM 流式逐帧处理。

## 何时用 / 何时不用

- **用：** 流式/实时任务（语音）、变长序列、数据量中小或显存受限（内存 O(n)）、需要在线逐步预测的时序。
- **不用：** 长序列 + 大规模数据且要并行训练（用 Transformer）；离线可取全文的双向上下文用 BiLSTM；非时序的表格/图像任务。

## 优劣与代价

✅ 内存 O(n)、天然流式、中小数据即可工作、结构成熟。
⚠️ 时间步串行无法并行、长程依赖弱、训练慢。
⚠️ 多数大规模 NLP 任务已被 Transformer 在精度与训练速度上全面超越。

## 与相关概念的区别

- **RNN/LSTM vs Transformer：** RNN 串行、长程弱、内存 O(n)；Transformer 自注意力直接建模远距离依赖、可并行、但内存 O(n²)、长序列成本高。
- **vs CNN：** CNN 抓局部空间特征，RNN 家族抓时序依赖。

| 特性 | RNN/LSTM | Transformer |
|------|----------|-------------|
| 长距离依赖 | 弱（梯度消失） | 强（直接注意力） |
| 并行化 | 不可（串行） | 可（并行） |
| 内存 | O(n) | O(n²) |
| 适用场景 | 小数据/流式 | 大数据/长序列 |

## 常见误区

- RNN 天生就能轻松记住很长的序列信息。
- GRU 比 LSTM 参数少，所以效果一定不如 LSTM。
- 双向 RNN 可以用来做实时流式语音识别。

## 面试速答

> 🎯 循环网络家族：RNN 用隐状态沿时间递推但长序列梯度消失、记不住远处；LSTM 加 cell state+遗忘/输入/输出三门做长期传送带，GRU 合并为更新/重置两门更省更快；双向看前后文但仅限离线。整体串行不可并行、内存 O(n)，长程与并行弱于 Transformer，故大规模 NLP 多被后者取代。
