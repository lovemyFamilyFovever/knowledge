# 因果推断

## 相关性 vs 因果性

**经典例子：** 冃淇淋销量和溺水事件正相关。但不是冰淇淋导致溺水，而是因为夏天（共同原因，混淆变量）。

```
         夏天
        ↙    ↘
冰淇淋销量    溺水事件
```

## 因果图（DAG）

有向无环图表示变量间的因果关系：

```
X -> Y  : X导致Y
X <- Z -> Y  : X和Y有共同原因Z（混淆）
X -> M -> Y  : M是中介变量
```

## do-calculus

Pearl的干预 calculus：

```
P(Y|do(X)) ≠ P(Y|X)  # 干预 ≠ 观察
P(Y|do(X)) = Σ_z P(Y|X,Z)P(Z)  # 后门准则
```

## 常用因果推断方法

| 方法 | 适用场景 | 核心思想 | 前提假设 |
|------|----------|----------|----------|
| A/B测试 | 可随机化 | 随机分组消除混淆 | 随机化可行 |
| 双重差分DID | 面板数据 | 差分去除固定效应 | 平行趋势 |
| 工具变量IV | 有不可观测混淆 | 找外生变异 | 排他性约束 |
| 断点回归RDD | 有阈值/截止点 | 阈值附近比较 | 连续性假设 |
| 合成控制 | 个体干预 | 构建反事实对照 | 预测能力 |
| PSM匹配 | 观测数据 | 匹配相似个体 | 无未观测混淆 |
