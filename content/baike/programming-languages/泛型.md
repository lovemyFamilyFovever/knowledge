# 泛型


> 📌 **导航**：本文是 **泛型** 词条，属于 programming-languages 术语集。相关枢纽：[[Go语言核心]]、[[Python高级编程完全指南]]、[[Rust系统编程入门到精通]]、[[Rust编程基础]]、[[TypeScript深入]]。

## 定义

**一句话定义：** 泛型(Generics)是一种让类、接口或方法在定义时使用**类型参数**、在实例化或调用时再指定具体类型的编程特性,从而实现"一份代码适用于多种类型"的类型安全复用(参数化多态)。

**通俗类比：** 像一个通用收纳盒的模具——模具(泛型定义)不规定装什么,你可以指定做成"装鞋的盒"或"装书的盒"(具体类型),既复用了同一套设计,又保证"鞋盒只装鞋"的类型安全。

> 多义说明:泛型即**参数化多态**;不同语言实现有别(C++ 模板、Java/C# 泛型、Rust 泛型、Go 1.18+ 泛型、TypeScript 泛型),且分"类型擦除/单态化"等不同策略。本文综述。

## 原理与机制

- **类型参数:** 用占位符(如 `T`、`K`、`V`)声明,使用时替换为具体类型。
- **实现策略:**
  - 类型擦除(type erasure,如 Java):编译后泛型信息被擦除,运行时退化为原始类型(故有桥接方法与若干限制)。
  - 单态化/具化(monomorphization,如 C++/Rust):为每个具体类型生成专门代码(性能好、体积增大)。
  - 运行时具化(如 C#):运行时保留泛型类型信息。
- **约束(bounds/constraints):** 限制类型参数需满足的条件(如实现某接口/继承某类)。
- **型变(variance):** 协变/逆变/不变(如 Java 通配符 `? extends`/`? super`、Kotlin `in`/`out`)。

## 关键组成

| 组成 | 说明 |
|------|------|
| 类型参数 | 占位类型 T/K/V |
| 约束(bounds) | 限定类型参数的能力 |
| 实现策略 | 擦除 / 单态化 / 运行时具化 |
| 型变(variance) | 协变、逆变、不变 |
| 泛型类/方法/接口 | 参数化的定义单元 |

## 应用场景

- 集合类(List<T>、Map<K,V>)与通用容器
- 通用算法与数据结构复用
- 类型安全的 API 设计
- 在不牺牲类型检查的前提下复用逻辑

## 优点与局限

- 优点:类型安全的代码复用、编译期检查、减少强制转换、提升可维护性。
- 局限:各语言实现差异大(擦除 vs 单态化各有代价);型变与约束增加复杂度;部分场景导致代码膨胀或运行时开销。

## 常见误区

- Java 泛型是编译期擦除:运行时无 `List<String>` 与 `List<Integer>` 之分,不能 `new T[]`、不能直接用基本类型作类型参数。
- C++ 模板 / Rust 泛型是单态化:为每个具体类型生成代码。
- 泛型 ≠ 动态类型的"任意类型":泛型仍有静态类型检查。
- 型变并非理所当然,需显式声明协变/逆变。
