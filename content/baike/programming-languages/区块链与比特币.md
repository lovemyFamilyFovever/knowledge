# 区块链与比特币

> 📌 **导航**：本文是 **区块链与比特币** 词条，属 [[密码学与区块链技术指南]] 子词条。共识算法见 [[一致性算法]]。

## 定义

**一句话定义：** 区块链是"用密码学哈希把区块串成不可篡改的链 + 分布式共识决定唯一账本状态 + P2P 网络去中心化传播"的复制状态机；比特币是其在"稀缺数字资产转移"上的首个落地（UTXO 模型 + 工作量证明挖矿）。

**通俗类比：** 像一本全网共同持有、每页盖了上一页骑缝章（哈希）的总账——改任何一页都会让后面所有章对不上；"由谁来记账、记哪一版"由共识（PoW 拼算力）裁决。

## 为什么需要它

传统账本需要可信中心对账、防双花。区块链用"哈希链保证篡改可检出 + 共识保证多副本对同一顺序达成一致 + P2P 免中心"，在互不信任的参与方间达成单一真相，实现无需中介的价值转移。

## 核心机制

- **区块结构与哈希链**：区块含区块头（前一区块哈希、默克尔根、时间戳、难度/nonce）+ 交易列表；改动即断链，历史不可篡改（需重算其后所有 PoW）。
- **共识机制**：PoW（最长/最重链、算力竞争+难度调整）、PoS（按质押选块）等，决定"哪条分支是唯一账本"。
- **P2P 网络**：交易与区块 gossip 传播、节点各自验证。
- **比特币专属**：UTXO 模型（未花交易输出即余额，消费=解锁旧输出+创建新输出，天然防双花）；挖矿打包+PoW 出块+区块补贴递减；SegWit 把见证数据隔离出主结构以扩容/修可延展性；闪电网络在其上做链下微支付通道。

## 具体示例

一笔比特币消费的 UTXO 视角：

```text
输入(引用先前未花 UTXO + 解锁脚本/签名) → 输出(新公钥哈希 + 金额)
节点校验：输入未双花、金额守恒、解锁脚本满足锁定脚本 → 进入 mempool → 矿工打包
```

## 何时用与何时不用

- **用**：需多方无中心对共享账本达成一致、且信任不可假设时（加密货币、部分审计/溯源）。
- **不用**：中心化机构能可信记账时别上链——多数业务用普通数据库即可；区块链吞吐量/延迟/能耗代价高。

## 优劣与代价

✅ 去中心化、防篡改、透明可验证、无需信任中介。
✅ UTXO/账户模型清晰表达资产所有权与防双花。
⚠️ 吞吐低、确认有延迟、PoW 能耗高；共识最终性概率性。
⚠️ 隐私受限（伪匿名、链上公开）、代码/密钥难纠错。

## 与相关概念的区别

- **PoW vs PoS**：算力竞争 vs 质押权益选块，能耗与" nothing-at-stake/长程攻击"取舍不同。
- **UTXO vs 账户模型**：离散未花输出 vs 全局余额状态（以太坊账户）。
- **区块链 vs 分布式复制状态机**：本质是 RSM+去中心+激励；共识细节见 [[一致性算法]]。

## 常见误区

- 区块链 = 数据库，比数据库更快更安全。
- 只要上链，数据就不可篡改且绝对正确。
- 比特币里"余额"是存在某个账户字段里的一个数字。

## 面试速答

> 🎯 区块链=哈希链(改则断链)+共识(多副本对唯一顺序达成一致,PoW/PoS)+P2P gossip 的复制状态机，实现无中心防篡改账本；比特币是其落地：UTXO 模型(消费=解旧锁+创新输出、天然防双花)+PoW 挖矿出块+SegWit 扩容/修延展性。去中心与不信任中介是核心，代价是吞吐/延迟/能耗。
