# 线性代数

> 📌 **导航**：本文是 **线性代数** 词条，属 [[程序员的数学基础]] 子词条。

## 定义

**一句话定义：** 线性代数研究向量、矩阵与线性变换——矩阵是"对空间做线性变换的编码"，特征值/SVD 则揭示变换的不变方向与低秩结构，是图形学、机器学习与数值计算的数学语言。

**通俗类比：** 向量是"带方向的箭头"，矩阵是"把整套箭头旋转/拉伸/投影的配方"；特征向量是"变换后方向不变的轴"，SVD 是"把任意变换拆成旋转—拉伸—旋转"。

## 为什么需要它

现代工程对象常以向量/张量表示（像素、特征、嵌入、图邻接矩阵），它们之间的线性关系与变换正是 ML、图形、信号处理、优化的骨架。理解矩阵=变换、特征分解=主方向，才能读懂 PCA/SVD 降维、求解方程、做变换与推荐。

## 核心机制

- **向量**：n 维数组，点积（相似度/投影）、模、线性组合、基。
- **矩阵**：线性变换的表示；矩阵乘法 = 变换复合；转置、逆、秩；解 Ax=b。
- **特征值与特征向量**：Av=λv，找变换的"不变方向"及缩放因子，是 PCA、谱方法、稳定性分析基础。
- **SVD**：A=UΣVᵀ，任意矩阵的旋转—拉伸—旋转分解，支撑降维/推荐/伪逆/最小二乘。

## 具体示例

用 numpy 看矩阵的特征分解（对称阵可正交对角化）：

```python
import numpy as np
A = np.diag([2.0, 3.0])
w, V = np.linalg.eig(A)   # 特征值 [2,3]，特征向量即坐标轴（无旋转）
```

## 何时用与何时不用

- **用**：特征/相似度与向量检索、线性回归与最小二乘、PCA/SVD 降维与推荐、图形变换、图邻接谱分析。
- **不用**：与连续量无关的纯离散/逻辑问题（见 [[离散数学与组合]]）用不上矩阵；勿把相关当因果。

## 优劣与代价

✅ 把高维数据与变换统一成向量/矩阵，ML/图形/优化的通用语言。
✅ 特征/SVD 给出降维、近似与稳定性分析的强工具。
⚠️ 大规模矩阵计算有数值精度、条件数与成本问题（迭代/稀疏/浮点误差）。
⚠️ 抽象几何直觉要求高，易"调包不懂原理"。

## 与相关概念的区别

- **特征值分解 vs SVD**：EVD 主要对（可对角化）方阵；SVD 对任意 m×n 矩阵更通用。
- **矩阵（变换）vs 数组（存储）**：同样是二维数组，赋予"线性映射"语义才是矩阵。
- 与 [[离散数学与组合]]：连续/线性世界 vs 离散结构世界。

## 常见误区

- 矩阵就是二维数组，和程序里的 array 没区别。
- 特征值分解适用于任何矩阵。
- 相似度（点积/余弦）高就说明有因果关系。

## 面试速答
