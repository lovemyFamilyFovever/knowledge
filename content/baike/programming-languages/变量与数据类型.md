# 变量与数据类型

> 📌 **导航**：本文是 **变量与数据类型** 词条，属 [[编程语言通用概念]] 子词条。类型体系深入见 [[类型系统]]。

## 定义

**一句话定义：** 变量是"带名字的存储位置"、常量是其绑定后不可再改的特例；数据类型规定值能取的范围与允许的操作，值类型按值存放/复制、引用类型按指针指向堆上对象。

**通俗类比：** 变量像贴了标签的盒子（可换内容），常量是封了口的盒子；类型是"盒子上写的规则"——数字盒子能做算术、字符串盒子能拼接，不能张冠李戴。

## 为什么需要它

程序本质是对数据施加操作；给数据命名（变量）并约束其类别（类型）是语言的基础设施。区分值/引用语义决定赋值与传参是"复制内容"还是"共享同一对象"，直接影响别名与副作用；类型还能在编译/运行期挡住一大类错误。

## 核心机制

- **变量与赋值**：名字绑定到值；作用域与生命周期另见 [[作用域与命名]]。
- **常量**：绑定后不可变，利于表达不变量与优化。
- **基本类型**：整数/浮点/布尔/字符等，通常直接存值、有取值范围与溢出边界。
- **值类型 vs 引用类型**：值类型赋值/传参复制整个值、互相独立；引用类型复制的是"指向堆对象的引用"，多个变量可指向同一对象（改动互相可见）。
- 类型标注与推断、静态/动态强弱类型体系详见 [[类型系统]]。

## 具体示例

值 vs 引用的赋值差异（Python 演示共享可变对象）：

```python
a = [1, 2]; b = a          # b 与 a 引用同一列表
b.append(3); print(a)       # [1, 2, 3] —— 别名可见彼此改动
x = 10; y = x; y = 20       # 整数是不可变值，改 y 不影响 x
```

## 何时用与何时不用

- **用**：优先用不变量（常量/`final`）、明确类型；共享可变对象时警惕别名副作用，必要时拷贝。
- **不用**：别拿引用语义的直觉去判断值类型（反之亦然）；不要为"灵活"把一切设为可变全局。

## 优劣与代价

✅ 命名与类型让数据可读、可约束、可被静态检查。
✅ 值/引用区分清楚别名与副作用。
⚠️ 引用共享易生"改一处动多处"；值拷贝大对象有成本。
⚠️ 强/弱、静态/动态类型取舍不同，混用语言时易踩隐式转换坑。

## 与相关概念的区别

- **变量 vs 常量**：能否重新绑定；**值类型 vs 引用类型**：复制值 vs 复制指向。
- **数据类型 vs 类型系统**：前者是"有哪些类"，后者是"如何规定与检查类型关系"（见 [[类型系统]]）。
- **不可变 vs 常量**：不可变对象内容不变，常量是绑定不变，二者概念不同。

## 常见误区

- 把变量赋值给另一个变量后，两者一定各自独立。
- 常量声明后，它指向的可变对象内容也不能被修改。
- 所有语言里字符串都是值类型。

## 面试速答

> 🎯 变量=具名存储、常量绑定后不改；类型规定取值与操作，基本类型(整/浮/布尔/字符)按值存、有边界溢出，引用类型(对象/数组)复制的是指向堆对象的引用→多变量可别名同一对象、改动互相可见，值类型复制独立。区分值/引用语义决定赋值与传参行为；类型体系见 [[类型系统]]。
