# 编程语言通用概念

---

## 变量（Variable）

**一句话定义：** 变量就是一个用来存放数据的"盒子"，你可以往里面放东西，也可以随时换掉里面的内容。

**通俗类比：** 就像酒店的房间号，房间号（变量名）是固定的，但住的客人（变量值）可以随时更换。

**具体示例：**
```python
# Python
name = "张三"      # 字符串变量
age = 25           # 整数变量
price = 9.99       # 浮点数变量
```

```javascript
// JavaScript
let count = 0;       // 可重新赋值
const PI = 3.14;     // 常量（不可变）
var oldWay = "少用";  // 旧语法，不推荐
```

```java
// Java
String name = "李四";
int score = 100;
double salary = 15000.50;
```

**为什么需要它：** 程序需要记住用户输入、计算结果等临时数据，变量就是程序的"记忆"。

**与相关术语对比：** 变量 vs 常量——变量的值可以改，常量的值一旦设定就不能改。变量 vs 字面量——变量有名字可以复用，字面量是直接写死的值。

---

## 常量（Constant）

**一句话定义：** 常量就是一旦赋值就永远不能改变的变量。

**通俗类比：** 就像刻在石碑上的字，写上去就改不了了。

**具体示例：**
```python
# Python（用全大写命名表示常量，但技术上可以改）
MAX_SIZE = 100
PI = 3.14159
```

```javascript
// JavaScript（const 真正不可变）
const API_URL = "https://api.example.com";
const MAX_RETRY = 3;
```

```java
// Java（final 关键字）
final double GRAVITY = 9.8;
final String APP_NAME = "MyApp";
```

**为什么需要它：** 防止关键数值被意外修改，提高代码可读性和安全性。

**与相关术语对比：** 常量 vs 变量——常量不可修改，变量可以；常量通常用于配置值、数学常数等固定不变的场景。

---

## 基本数据类型（Primitive Data Types）

**一句话定义：** 基本数据类型就是编程语言提供的最基础的几种数据"分类"。

**通俗类比：** 就像超市货架的分类标签——这是蔬菜区、那是水果区，每种类型存放不同种类的东西。

**具体示例：**
```python
# Python 基本类型
age = 25              # int 整数
height = 1.75         # float 浮点数
grade = 'A'           # str 字符串（Python 没有 char）
is_pass = True        # bool 布尔值
```

```javascript
// JavaScript 基本类型
let age = 25;          // number
let grade = 'A';       // string
let is_pass = true;    // boolean
let nothing = null;    // null
let undef;             // undefined
let id = 123n;         // BigInt
let hex = 0xFF;        // number（十六进制）
```

```java
// Java 基本类型
int age = 25;
double price = 9.99;
char grade = 'A';
boolean isPass = true;
byte smallNum = 127;
short mediumNum = 32000;
long bigNum = 9999999999L;
float pi = 3.14f;
```

**为什么需要它：** 不同数据有不同的存储和运算规则，类型系统让计算机知道如何正确处理数据。

**与相关术语对比：** 基本类型 vs 引用类型——基本类型存储实际值，引用类型存储内存地址（指针）。

---

## 引用类型与值类型

**一句话定义：** 值类型直接存数据本身，引用类型存的是数据的"门牌号"（内存地址）。

**通俗类比：** 值类型就像你口袋里的现金，钱就在你手上；引用类型就像银行卡，卡上没有钱，但指向银行里你的账户。

**具体示例：**
```python
# Python 中一切都是引用类型
a = [1, 2, 3]
b = a           # b 和 a 指向同一个列表
b.append(4)
print(a)        # [1, 2, 3, 4] —— a 也变了！
```

```javascript
// JavaScript 基本类型是值类型
let x = 10;
let y = x;      // y 是 x 的副本
y = 20;
console.log(x); // 10 —— x 没变

// 引用类型
let arr1 = [1, 2];
let arr2 = arr1; // arr2 指向同一个数组
arr2.push(3);
console.log(arr1); // [1, 2, 3] —— arr1 也变了
```

```java
// Java
int a = 10;      // 值类型（基本类型）
Integer b = 10;  // 引用类型（包装类）
String s = "hi"; // 引用类型
```

**为什么需要它：** 理解值/引用类型能避免"改了一个变量，另一个变量也跟着变"的bug。

**与相关术语对比：** 值类型传递时复制数据，引用类型传递时只复制地址（指针）。

## 运算符（Operators）

**一句话定义：** 运算符就是告诉计算机"做什么操作"的符号。

**通俗类比：** 就像数学课上的 +、-、×、÷，只不过编程里还有更多种类。

**具体示例：**
```python
# 算术运算符
print(10 + 3)   # 13  加法
print(10 - 3)   # 7   减法
print(10 * 3)   # 30  乘法
print(10 / 3)   # 3.33 除法
print(10 // 3)  # 3   整除
print(10 % 3)   # 1   取余
print(2 ** 3)   # 8   幂运算

# 比较运算符
print(10 > 5)   # True
print(10 == 10) # True
print(10 != 5)  # True

# 逻辑运算符
print(True and False)  # False
print(True or False)   # True
print(not True)        # False

# 三元运算符（Python 用条件表达式）
age = 20
status = "成年" if age >= 18 else "未成年"
```

**为什么需要它：** 没有运算符就无法进行任何计算和判断，它是程序逻辑的基础构建块。

**与相关术语对比：** 算术运算符处理数学运算，比较运算符返回布尔值，逻辑运算符组合多个条件。

## 控制流（Control Flow）

**一句话定义：** 控制流就是让程序"根据不同情况走不同路"的机制。

**通俗类比：** 就像开车时的路牌——"如果前方红灯就停车，否则就继续开"。

**具体示例：**
```python
# if/elif/else
score = 85
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")

# match/case（Python 3.10+）
day = "Monday"
match day:
    case "Monday":
        print("周一")
    case "Friday":
        print("周五")
    case _:
        print("其他天")
```

```javascript
// if/else
let hour = 14;
if (hour < 12) {
    console.log("上午好");
} else {
    console.log("下午好");
}

// switch
let fruit = "apple";
switch (fruit) {
    case "apple":
        console.log("苹果");
        break;
    case "banana":
        console.log("香蕉");
        break;
    default:
        console.log("未知水果");
}

// 三元运算符
let age = 20;
let msg = age >= 18 ? "成年" : "未成年";
```

```java
// Java switch（增强版）
String day = "MONDAY";
switch (day) {
    case "MONDAY" -> System.out.println("周一");
    case "FRIDAY" -> System.out.println("周五");
    default -> System.out.println("其他天");
}
```

**为什么需要它：** 程序需要根据输入和条件做出不同响应，控制流是实现"智能判断"的核心。

**与相关术语对比：** if/else 适合简单分支，switch 适合多值匹配，三元运算符适合简短的二选一。

## 循环（Loops）

**一句话定义：** 循环就是让程序重复执行一段代码，直到满足某个条件为止。

**通俗类比：** 就像每天早上的闹钟响了按掉，过了5分钟又响——重复直到你起床。

**具体示例：**
```python
# for 循环
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4

# while 循环
count = 0
while count < 5:
    print(count)
    count += 1

# for-in 遍历字典
person = {"name": "张三", "age": 25}
for key, value in person.items():
    print(f"{key}: {value}")
```

```javascript
// for 循环
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// while 循环
let count = 0;
while (count < 5) {
    console.log(count);
    count++;
}

// for-of 遍历数组
let fruits = ["苹果", "香蕉", "橙子"];
for (let fruit of fruits) {
    console.log(fruit);
}

// for-in 遍历对象属性
let person = {name: "张三", age: 25};
for (let key in person) {
    console.log(`${key}: ${person[key]}`);
}
```

**为什么需要它：** 处理批量数据（如列表、数组）时，循环能避免重复写相同代码。

**与相关术语对比：** for 适合已知次数，while 适合条件不确定，do-while 至少执行一次，for-of 适合遍历可迭代对象。

## 函数（Function）

**一句话定义：** 函数就是一段可以反复调用的"代码包"，接收输入、处理逻辑、返回结果。

**通俗类比：** 就像一台自动贩卖机——投币（参数）、机器处理（函数体）、出货（返回值）。

**具体示例：**
```python
# 基本函数
def greet(name):
    return f"你好，{name}！"

# 默认参数
def greet(name, greeting="你好"):
    return f"{greeting}，{name}！"

# 可变参数
def total(*numbers):
    return sum(numbers)

print(total(1, 2, 3))  # 6

# Lambda
square = lambda x: x ** 2
print(square(5))  # 25
```

```javascript
// 基本函数
function greet(name) {
    return `你好，${name}！`;
}

// 默认参数
function greet(name, greeting = "你好") {
    return `${greeting}，${name}！`;
}

// 可变参数
function total(...numbers) {
    return numbers.reduce((a, b) => a + b, 0);
}

// 箭头函数
const square = x => x ** 2;
console.log(square(5)); // 25
```

```java
// Java 方法
public static String greet(String name) {
    return "你好，" + name + "！";
}

// 方法重载
public static int add(int a, int b) { return a + b; }
public static double add(double a, double b) { return a + b; }
```

**为什么需要它：** 函数让代码模块化、可复用，避免重复，也方便测试和维护。

**与相关术语对比：** 函数 vs 方法——函数独立存在，方法属于某个对象/类；函数 vs 过程——函数有返回值，过程没有。

## 递归（Recursion）

**一句话定义：** 递归就是函数自己调用自己，直到遇到一个"不再调用"的终止条件。

**通俗类比：** 就像照镜子——镜子里还有镜子，但你不会无限照下去，因为你最终会走开。

**具体示例：**
```python
# 阶乘
def factorial(n):
    if n <= 1:        # 基线条件
        return 1
    return n * factorial(n - 1)  # 递归条件

print(factorial(5))  # 120
```

```javascript
// 斐波那契数列
function fibonacci(n) {
    if (n <= 1) return n;  // 基线条件
    return fibonacci(n - 1) + fibonacci(n - 2);  // 递归条件
}

console.log(fibonacci(10)); // 55
```

```java
// 二叉树遍历
class TreeNode {
    int val;
    TreeNode left, right;
}

void traverse(TreeNode node) {
    if (node == null) return;  // 基线条件
    traverse(node.left);       // 递归条件
    traverse(node.right);      // 递归条件
}
```

**为什么需要它：** 递归天然适合处理树形结构、分治算法等自相似问题。

**与相关术语对比：** 递归 vs 循环——递归代码简洁但可能栈溢出，循环性能更好但代码可能更复杂。

## 作用域（Scope）

**一句话定义：** 作用域决定了一个变量在哪里可以被访问，在哪里就"看不见"了。

**通俗类比：** 就像酒店房间——你在自己房间里可以随便用里面的东西，但不能随便进别人的房间拿东西。

**具体示例：**
```python
# 全局作用域
app_name = "MyApp"

def my_function():
    # 局部作用域
    local_var = "局部变量"
    print(app_name)      # 能访问全局
    print(local_var)     # 能访问局部

my_function()
# print(local_var)  # 报错！局部变量在函数外不可见

# 块级作用域（Python 用函数/类/推导式限制）
for i in range(5):
    block_var = i
# print(i)        # Python 可以访问（特殊）
# print(block_var) # Python 也可以访问
```

```javascript
// 全局作用域
var globalVar = "全局";

function myFunction() {
    // 局部作用域
    var localVar = "局部";
    console.log(globalVar);  // 能访问
}

// 块级作用域（let/const）
if (true) {
    let blockLet = "块级";
    const blockConst = "常量";
    var notBlock = "不是块级";
}
// console.log(blockLet);   // 报错
// console.log(blockConst); // 报错
console.log(notBlock);      // 能访问！
```

```java
// Java
public class Example {
    static String classVar = "类变量";  // 类作用域

    public void method() {
        String localVar = "局部变量";   // 方法作用域
        if (true) {
            String blockVar = "块级";   // 块作用域
        }
        // blockVar 不可访问
    }
}
```

**为什么需要它：** 作用域防止变量名冲突，限制变量的可见范围，让代码更安全、更易维护。

**与相关术语对比：** 全局作用域整个程序可见，局部作用域仅函数内可见，块级作用域仅花括号内可见。

## 命名规范（Naming Conventions）

**一句话定义：** 命名规范就是给变量、函数、类等起名字时要遵守的"命名习惯"。

**通俗类比：** 就像给新生儿取名——虽然法律没规定必须叫什么，但有些名字一看就知道是男是女。

**具体示例：**
```python
# Python 推荐：snake_case（蛇形命名）
user_name = "张三"
max_retry_count = 3

class UserProfile:
    pass

def calculate_total_price():
    pass
```

```javascript
// JavaScript 推荐：camelCase（驼峰命名）
let userName = "张三";
let maxRetryCount = 3;

// 类用 PascalCase
class UserProfile {}

// 常量用 UPPER_SNAKE_CASE
const MAX_RETRY_COUNT = 3;

// CSS 类名用 kebab-case（连字符）
// .user-profile { }
```

```java
// Java 推荐：camelCase（变量/方法），PascalCase（类）
String userName = "张三";
int maxRetryCount = 3;

class UserProfile {
    public void calculateTotalPrice() { }
}

// 常量
static final int MAX_RETRY_COUNT = 3;
```

**为什么需要它：** 统一的命名规范让团队协作更顺畅，代码更易读。

**与相关术语对比：** camelCase 适合 JS/Java 变量，snake_case 适合 Python 变量，PascalCase 适合类名，kebab-case 适合 CSS 类名。
