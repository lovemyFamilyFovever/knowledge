## 函数式编程全面指南：从理论到实践

## 1. FP核心概念

### 纯函数（Pure Functions）
纯函数是函数式编程的基石，它必须满足两个条件：
1. **确定性**：对于相同的输入，永远返回相同的输出
2. **无副作用**：不修改外部状态、不进行IO操作、不修改输入参数

```javascript
// 纯函数示例
const add = (a, b) => a + b;
const square = x => x * x;
const getFullName = (user) => `${user.firstName} ${user.lastName}`;

// 非纯函数示例（有副作用）
let total = 0;
const addToTotal = (amount) => {
  total += amount;  // 修改外部状态
  return total;
};

// 非纯函数示例（依赖外部状态）
const getCurrentTime = () => new Date();  // 每次调用结果不同
```

**深度分析**：纯函数的优势在于可预测性、可测试性和可缓存性。在React中，纯函数组件（PureComponent）就是基于这一思想，确保相同的props和state总是渲染相同的UI。

### 不可变性（Immutability）
不可变性意味着数据一旦创建就不能被修改。任何"修改"操作都会返回新的数据副本。

```javascript
// 可变操作
const mutableArray = [1, 2, 3];
mutableArray.push(4);  // 修改原数组
console.log(mutableArray); // [1, 2, 3, 4]

// 不可变操作
const immutableArray = [1, 2, 3];
const newArray = [...immutableArray, 4];
console.log(immutableArray); // [1, 2, 3] - 原数组不变
console.log(newArray); // [1, 2, 3, 4]

// 对象的不可变操作
const person = { name: "Alice", age: 25 };
const olderPerson = { ...person, age: 26 };
console.log(person); // { name: "Alice", age: 25 }
console.log(olderPerson); // { name: "Alice", age: 26 }
```

**持久化数据结构**：现代FP语言使用结构共享（structural sharing）来实现高效的不可变数据结构。以Clojure的Vector为例，修改操作不会复制整个结构，而是共享未修改的部分。

### 引用透明（Referential Transparency）
引用透明是指任何表达式都可以用它的值替代而不改变程序行为。

```javascript
// 引用透明示例
const calculateArea = (radius) => Math.PI * radius * radius;

// 可以直接用结果替换函数调用
const result1 = calculateArea(5); // 78.53981633974483
const result2 = 78.53981633974483; // 与result1等价

// 非引用透明示例
let counter = 0;
const increment = () => ++counter;

const x = increment(); // 1
const y = increment(); // 2
// increment()不能直接替换为结果值，因为每次结果都不同
```

## 2. 高阶函数（Higher-Order Functions）

### 常用高阶函数

#### map - 映射
```javascript
// 数字映射
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(x => x * 2);
console.log(doubled); // [2, 4, 6, 8, 10]

// 对象映射
const users = [
  { name: "Alice", age: 25 },
  { name: "Bob", age: 30 }
];
const names = users.map(user => user.name);
console.log(names); // ["Alice", "Bob"]

// 链式调用
const result = numbers
  .map(x => x * 2)
  .map(x => x + 1)
  .map(x => x * 3);
```

#### filter - 过滤
```javascript
const numbers = [1, 2, 3, 4, 5, 6, 7, 8];
const evens = numbers.filter(x => x % 2 === 0);
console.log(evens); // [2, 4, 6, 8]

// 复杂过滤
const people = [
  { name: "Alice", age: 25, city: "NYC" },
  { name: "Bob", age: 30, city: "London" },
  { name: "Charlie", age: 35, city: "NYC" }
];
const nycPeople = people
  .filter(person => person.city === "NYC")
  .filter(person => person.age > 28);
```

#### reduce - 聚合
```javascript
// 求和
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce((acc, curr) => acc + curr, 0);
console.log(sum); // 15

// 分组
const grouped = people.reduce((acc, person) => {
  const city = person.city;
  acc[city] = acc[city] || [];
  acc[city].push(person);
  return acc;
}, {});
console.log(grouped);

// 扁平化嵌套数组
const nested = [[1, 2], [3, 4], [5]];
const flattened = nested.reduce((acc, arr) => [...acc, ...arr], []);
```

#### compose 和 pipe - 函数组合
```javascript
// compose - 从右到左执行
const compose = (...fns) => (x) => fns.reduceRight((acc, fn) => fn(acc), x);

// pipe - 从左到右执行（更符合阅读习惯）
const pipe = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x);

// 使用示例
const add1 = x => x + 1;
const multiply2 = x => x * 2;
const square = x => x * x;

const transform = pipe(add1, multiply2, square);
console.log(transform(3)); // ((3+1)*2)^2 = 64

// 实际应用：数据转换管道
const processUser = pipe(
  user => user.name,
  name => name.toUpperCase(),
  upperName => `${upperName} is active`
);

const user = { name: "alice", age: 25 };
console.log(processUser(user)); // "ALICE is active"
```

**深度分析**：函数组合是FP的核心思想之一，它允许我们将复杂操作分解为简单函数的组合。Redux中的middleware就是基于函数组合的原理，通过compose函数将多个中间件组合起来。

## 3. 闭包和柯里化

### 闭包（Closure）
闭包是指函数能够记住并访问其词法作用域，即使函数在词法作用域之外执行。

```javascript
function createCounter() {
  let count = 0;
  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count
  };
}

const counter = createCounter();
counter.increment();
counter.increment();
console.log(counter.getCount()); // 2

// 实际应用：工厂模式
function createMultiplier(factor) {
  return (number) => number * factor;
}

const double = createMultiplier(2);
const triple = createMultiplier(3);
console.log(double(5)); // 10
console.log(triple(5)); // 15

// 隐私模式
function createPerson(name, age) {
  let _name = name;
  let _age = age;
  
  return {
    getName: () => _name,
    setName: (newName) => { _name = newName; },
    getAge: () => _age,
    getSummary: () => `${_name} is ${_age} years old`
  };
}
```

### 柯里化（Currying）
柯里化是将多参数函数转换为一系列单参数函数的技术。

```javascript
// 普通函数
function add(a, b, c) {
  return a + b + c;
}

// 柯里化版本
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn.apply(this, args);
    } else {
      return function(...args2) {
        return curried.apply(this, args.concat(args2));
      };
    }
  };
}

const curriedAdd = curry(add);
console.log(curriedAdd(1)(2)(3)); // 6
console.log(curriedAdd(1, 2)(3)); // 6
console.log(curriedAdd(1)(2, 3)); // 6

// 实际应用：部分应用
const logger = curry((level, timestamp, message) => {
  console.log(`[${level}] ${timestamp}: ${message}`);
});

const errorLogger = logger('ERROR');
const currentTime = () => new Date().toISOString();

errorLogger(currentTime())('Something went wrong');
errorLogger(currentTime())('Another error');

// 创建可重用的日志器
const createLogger = (level) => (message) => {
  console.log(`[${level}] ${new Date().toISOString()}: ${message}`);
};

const logError = createLogger('ERROR');
const logInfo = createLogger('INFO');

logError('Database connection failed');
logInfo('User logged in successfully');
```

**深度分析**：柯里化在实际开发中非常有用，特别是当需要创建可配置的函数或部分应用参数时。Lodash的_.curry和Ramda的R.curry都提供了强大的柯里化支持。

## 4. 函子（Functor）和单子（Monad）

### 函子（Functor）
函子是可以被映射（map）的容器类型。它实现了`map`方法，并满足两个法则：
1. 恒等律：`container.map(x => x) === container`
2. 组合律：`container.map(f).map(g) === container.map(x => g(f(x)))`

```javascript
// 最简单的函子：Array
const arr = [1, 2, 3];
arr.map(x => x); // [1, 2, 3] - 恒等律

const f = x => x * 2;
const g = x => x + 1;
arr.map(f).map(g); // [3, 5, 7]
arr.map(x => g(f(x))); // [3, 5, 7] - 组合律

// Maybe函子（可能包含值的容器）
class Maybe {
  constructor(value) {
    this.value = value;
  }
  
  static of(value) {
    return new Maybe(value);
  }
  
  isNothing() {
    return this.value === null || this.value === undefined;
  }
  
  map(fn) {
    return this.isNothing() ? this : Maybe.of(fn(this.value));
  }
  
  getOrElse(defaultValue) {
    return this.isNothing() ? defaultValue : this.value;
  }
}

const maybeNumber = Maybe.of(5);
console.log(maybeNumber.map(x => x * 2).getOrElse(0)); // 10

const maybeNull = Maybe.of(null);
console.log(maybeNull.map(x => x * 2).getOrElse(0)); // 0

// 安全访问嵌套对象
const user = {
  name: "Alice",
  address: {
    city: "NYC",
    zip: "10001"
  }
};

const safeGet = (obj, key) => 
  Maybe.of(obj).map(x => x[key]);

console.log(safeGet(user, 'address').map(addr => addr.city).getOrElse('Unknown')); // NYC
console.log(safeGet(user, 'phone').map(phone => phone.number).getOrElse('No phone')); // No phone
```

### 单子（Monad）
单子是具有`flatMap`（或`chain`、`bind`）方法的函子。它允许我们将返回容器的函数链接起来。

```javascript
// 实现Monad
class Monad {
  constructor(value) {
    this.value = value;
  }
  
  static of(value) {
    return new Monad(value);
  }
  
  map(fn) {
    return Monad.of(fn(this.value));
  }
  
  flatMap(fn) {
    return fn(this.value); // 关键：fn返回的已经是Monad
  }
}

// 示例：链式操作
const result = Monad.of(3)
  .flatMap(x => Monad.of(x * 2))
  .flatMap(x => Monad.of(x + 1))
  .flatMap(x => Monad.of(`Result: ${x}`));
  
console.log(result.value); // "Result: 7"

// 实际应用：数据库操作链
class DatabaseMonad {
  constructor(data) {
    this.data = data;
  }
  
  static query(sql) {
    // 模拟数据库查询
    return new DatabaseMonad({ sql, results: [] });
  }
  
  map(fn) {
    return new DatabaseMonad({
      ...this.data,
      results: fn(this.data.results)
    });
  }
  
  flatMap(fn) {
    const newData = fn(this.data);
    return new DatabaseMonad(newData);
  }
}
```

## 5. Either/Option/IO Monad

### Either Monad（用于错误处理）
```javascript
class Either {
  constructor(value) {
    this.value = value;
  }
  
  static left(value) {
    return new Left(value);
  }
  
  static right(value) {
    return new Right(value);
  }
  
  static of(value) {
    return Either.right(value);
  }
}

class Left extends Either {
  map(fn) {
    return this; // 错误时跳过map
  }
  
  flatMap(fn) {
    return this; // 错误时跳过flatMap
  }
  
  fold(leftFn, rightFn) {
    return leftFn(this.value);
  }
  
  getOrElse(defaultValue) {
    return defaultValue;
  }
}

class Right extends Either {
  map(fn) {
    return Either.right(fn(this.value));
  }
  
  flatMap(fn) {
    return fn(this.value);
  }
  
  fold(leftFn, rightFn) {
    return rightFn(this.value);
  }
  
  getOrElse(defaultValue) {
    return this.value;
  }
}

// 使用示例
const parseJSON = (json) => {
  try {
    return Either.right(JSON.parse(json));
  } catch (e) {
    return Either.left(`JSON解析错误: ${e.message}`);
  }
};

const result1 = parseJSON('{"name": "Alice"}');
console.log(result1.fold(
  error => `错误: ${error}`,
  data => `成功: ${JSON.stringify(data)}`
));

const result2 = parseJSON('invalid json');
console.log(result2.fold(
  error => `错误: ${error}`,
  data => `成功: ${JSON.stringify(data)}`
));
```

### Option Monad（替代null检查）
```javascript
class Option {
  constructor(value) {
    this.value = value;
  }
  
  static some(value) {
    if (value === null || value === undefined) {
      throw new Error('Option.some不能包装null或undefined');
    }
    return new Option(value);
  }
  
  static none() {
    return new Option(null);
  }
  
  static fromNullable(value) {
    return value === null || value === undefined 
      ? Option.none() 
      : Option.some(value);
  }
  
  isSome() {
    return this.value !== null && this.value !== undefined;
  }
  
  map(fn) {
    return this.isSome() ? Option.some(fn(this.value)) : Option.none();
  }
  
  flatMap(fn) {
    return this.isSome() ? fn(this.value) : Option.none();
  }
  
  getOrElse(defaultValue) {
    return this.isSome() ? this.value : defaultValue;
  }
  
  filter(predicate) {
    if (this.isSome() && predicate(this.value)) {
      return this;
    }
    return Option.none();
  }
}

// 使用示例
const getUser = (id) => {
  const users = { 1: { name: "Alice", age: 25 }, 2: { name: "Bob", age: 30 } };
  return Option.fromNullable(users[id]);
};

const getAdultUser = (id) => 
  getUser(id)
    .filter(user => user.age >= 18)
    .map(user => user.name);

console.log(getAdultUser(1).getOrElse('未找到')); // Alice
console.log(getAdultUser(3).getOrElse('未找到')); // 未找到
```

### IO Monad（隔离副作用）
```javascript
class IO {
  constructor(effect) {
    this.effect = effect; // 副作用函数
  }
  
  static of(value) {
    return new IO(() => value);
  }
  
  map(fn) {
    return new IO(() => fn(this.effect()));
  }
  
  flatMap(fn) {
    return new IO(() => fn(this.effect()).effect());
  }
  
  run() {
    return this.effect();
  }
}

// 使用示例：将副作用包装在IO中
const readLine = () => {
  return new IO(() => {
    // 模拟读取用户输入
    return "Hello World";
  });
};

const writeLine = (message) => {
  return new IO(() => {
    console.log(message);
    return message;
  });
};

const program = readLine()
  .flatMap(input => writeLine(`你输入了: ${input}`))
  .map(output => `程序输出: ${output}`);

console.log(program.run()); // 执行IO并打印结果
```

## 6. 函数式错误处理

### 传统错误处理的问题
```javascript
// 命令式错误处理
function divide(a, b) {
  if (b === 0) {
    throw new Error('除数不能为零');
  }
  return a / b;
}

try {
  const result = divide(10, 0);
  console.log(result);
} catch (error) {
  console.error('错误:', error.message);
}
```

### 函数式错误处理模式
```javascript
// 1. 使用Either
const safeDivide = (a, b) => {
  if (b === 0) {
    return Either.left('除数不能为零');
  }
  return Either.right(a / b);
};

// 2. 使用Result类型（类似Either，但更语义化）
class Result {
  constructor(isSuccess, value, error) {
    this.isSuccess = isSuccess;
    this.value = value;
    this.error = error;
  }
  
  static success(value) {
    return new Result(true, value, null);
  }
  
  static failure(error) {
    return new Result(false, null, error);
  }
  
  map(fn) {
    return this.isSuccess 
      ? Result.success(fn(this.value)) 
      : this;
  }
  
  flatMap(fn) {
    return this.isSuccess ? fn(this.value) : this;
  }
  
  fold(successFn, failureFn) {
    return this.isSuccess 
      ? successFn(this.value) 
      : failureFn(this.error);
  }
}

// 3. 函数式错误处理链
const parseNumber = (str) => {
  const num = Number(str);
  return isNaN(num)
    ? Result.failure(`'${str}'不是有效数字`)
    : Result.success(num);
};

const validatePositive = (num) => {
  return num > 0
    ? Result.success(num)
    : Result.failure('数字必须为正数');
};

const calculateSquareRoot = (num) => {
  if (num < 0) {
    return Result.failure('不能计算负数的平方根');
  }
  return Result.success(Math.sqrt(num));
};

// 组合错误处理
const processInput = (input) => {
  return parseNumber(input)
    .flatMap(validatePositive)
    .flatMap(calculateSquareRoot)
    .fold(
      result => `平方根是: ${result}`,
      error => `错误: ${error}`
    );
};

console.log(processInput('25')); // 平方根是: 5
console.log(processInput('-25')); // 错误: 数字必须为正数
console.log(processInput('abc')); // 错误: 'abc'不是有效数字
```

## 7. 不可变数据结构

### 持久化数据结构（Persistent Data Structures）
持久化数据结构在修改时创建新版本，同时保留旧版本，并通过结构共享实现高效性。

```javascript
// 使用Immer库进行不可变更新
import produce from 'immer';

const baseState = {
  users: [
    { id: 1, name: "Alice", active: true },
    { id: 2, name: "Bob", active: false }
  ],
  totalCount: 2
};

// 传统不可变更新（繁琐）
const newState1 = {
  ...baseState,
  users: baseState.users.map(user => 
    user.id === 1 ? { ...user, active: false } : user
  ),
  totalCount: baseState.totalCount - 1
};

// 使用Immer（简洁）
const newState2 = produce(baseState, draft => {
  const user = draft.users.find(u => u.id === 1);
  if (user) {
    user.active = false;
    draft.totalCount--;
  }
});

console.log(baseState.users[0].active); // true - 原状态不变
console.log(newState2.users[0].active); // false
```

### Immutable.js示例
```javascript
import { Map, List, fromJS } from 'immutable';

// 创建不可变Map
let map1 = Map({ a: 1, b: 2, c: 3 });

console.log(map1.get('b')); // 2

// 创建不可变List

console.log(list1.toArray()); // [1, 2, 3]

```

## 8. 函数式并发

### 软件事务内存（STM）
```javascript
// 模拟STM（实际需要专门的STM库）
class STM {
  constructor(initialState) {
    this.state = initialState;
    this.transactions = new Set();
  }
  
  // 开始事务
  begin() {
    const transaction = new Transaction(this);
    this.transactions.add(transaction);
    return transaction;
  }
  
  // 提交事务
  commit(transaction) {
    if (transaction.isValid()) {
      this.state = transaction.apply(this.state);
      this.transactions.delete(transaction);
      return true;
    }
    return false;
  }
}

class Transaction {
  constructor(stm) {
    this.stm = stm;
    this.localState = { ...stm.state };
    this.modifications = new Map();
  }
  
  read(key) {
    return this.localState[key];
  }
  
  write(key, value) {
    this.modifications.set(key, value);
    this.localState[key] = value;
  }
  
  isValid() {
    // 检查是否有冲突（简化版本）
    return true;
  }
  
  apply(baseState) {
    const newState = { ...baseState };
    for (const [key, value] of this.modifications) {
      newState[key] = value;
    }
    return newState;
  }
}

// 使用示例
const stm = new STM({ balance: 1000, transfers: [] });

const transfer = (from, to, amount) => {
  const tx = stm.begin();
  const balance = tx.read('balance');
  
  if (balance >= amount) {
    tx.write('balance', balance - amount);
    tx.write('transfers', [...tx.read('transfers'), { from, to, amount }]);
    
    if (stm.commit(tx)) {
      console.log(`转账成功: ${amount}元`);
      return true;
    }
  }
  
  console.log('转账失败: 余额不足');
  return false;
};

transfer('Alice', 'Bob', 500);
```

### Actor模型
```javascript
// Actor模型实现
class Actor {
  constructor(name, behavior) {
    this.name = name;
    this.behavior = behavior;
    this.mailbox = [];
    this.isProcessing = false;
  }
  
  send(message, sender = null) {
    this.mailbox.push({ message, sender });
    this.processMailbox();
  }
  
  processMailbox() {
    if (this.isProcessing || this.mailbox.length === 0) {
      return;
    }
    
    this.isProcessing = true;
    const { message, sender } = this.mailbox.shift();
    
    // 执行行为并可能产生新消息
    const responses = this.behavior(message, sender);
    if (responses) {
      responses.forEach(({ target, message }) => {
        target.send(message, this);
      });
    }
    
    this.isProcessing = false;
    this.processMailbox();
  }
}

// 创建演员
const accountActor = new Actor('Account', (message, sender) => {
  let balance = 1000;
  
  if (message.type === 'DEPOSIT') {
    balance += message.amount;
    console.log(`存款后余额: ${balance}`);
    return [{ target: sender, message: { type: 'BALANCE', value: balance } }];
  } else if (message.type === 'WITHDRAW') {
    if (balance >= message.amount) {
      balance -= message.amount;
      console.log(`取款后余额: ${balance}`);
      return [{ target: sender, message: { type: 'BALANCE', value: balance } }];
    } else {
      return [{ target: sender, message: { type: 'ERROR', error: '余额不足' } }];
    }
  }
});

const loggerActor = new Actor('Logger', (message) => {
  console.log(`[日志] ${JSON.stringify(message)}`);
});

// 使用演员
accountActor.send({ type: 'DEPOSIT', amount: 500 }, loggerActor);
accountActor.send({ type: 'WITHDRAW', amount: 200 }, loggerActor);
```

```typescript
type FilterFunction<T> = (item: T) => boolean;
type ReducerFunction<T, U> = (accumulator: U, current: T) => U;

// 实现泛型高阶函数
function map<T, U>(array: T[], fn: MapFunction<T, U>): U[] {
  return array.reduce((result, item) => [...result, fn(item)], [] as U[]);
}

function filter<T>(array: T[], fn: FilterFunction<T>): T[] {
  return array.reduce((result, item) => 
    fn(item) ? [...result, item] : result, [] as T[]);
}

function reduce<T, U>(array: T[], fn: ReducerFunction<T, U>, initialValue: U): U {
  return array.reduce(fn, initialValue);
}

// 函子模式
interface Functor<T> {
  map<U>(fn: (value: T) => U): Functor<U>;
}

class Maybe<T> implements Functor<T> {
  constructor(private value: T | null) {}
  
  static of<T>(value: T): Maybe<T> {
    return new Maybe(value);
  }
  
  static none<T>(): Maybe<T> {
    return new Maybe<T>(null);
  }
  
  map<U>(fn: (value: T) => U): Maybe<U> {
    if (this.value === null) {
      return Maybe.none<U>();
    }
    return Maybe.of(fn(this.value));
  }
  
  flatMap<U>(fn: (value: T) => Maybe<U>): Maybe<U> {
    if (this.value === null) {
      return Maybe.none<U>();
    }
    return fn(this.value);
  }
  
  getOrElse(defaultValue: T): T {
    return this.value !== null ? this.value : defaultValue;
  }
}

const maybeLength = maybeName.map(name => name.length);
console.log(maybeLength.getOrElse(0)); // 5

const mappedNull = maybeNull.map(s => s.toUpperCase());
console.log(mappedNull.getOrElse("DEFAULT")); // DEFAULT
```
