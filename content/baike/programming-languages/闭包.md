# 闭包

> 📌 **导航**：本文是 **闭包** 词条，属于 programming-languages 术语集。相关枢纽：[[Go语言核心]]、[[Python高级编程完全指南]]、[[Rust系统编程入门到精通]]、[[Rust编程基础]]、[[TypeScript深入]]。

## 定义

**一句话定义：** 闭包（Closure）是一个函数与其定义时所处的词法环境（它能访问的外部变量绑定）组合而成的整体；即使外层函数已经返回，内层函数仍能"记住"并访问那些被捕获的变量。

**通俗类比：** 像一个随身背包——函数离开它出生的作用域时，把当时能拿到的外部变量打包背在身上；此后无论在哪里被调用，都能从背包里取出这些变量来用。

## 为什么需要它

函数本应只在"定义它的作用域还活着"时才能访问外部变量，但回调、事件处理、异步续体等场景下，函数常常要等到外层作用域早已销毁之后才被调用。闭包让"函数 + 它依赖的环境"作为一个单元存活下来，从而能携带上下文状态——这也是实现函数工厂、柯里化、私有状态封装的基础。

## 核心机制

- **词法作用域**：函数能访问其**定义处**（而非调用处）可见的外部变量。
- **变量捕获**：当内层函数引用外层局部变量时，运行时把这些变量的生命周期延长（通常提升到堆上），使其不随外层栈帧销毁而消失。
- **表示**：闭包一般实现为"代码（函数体）+ 环境记录（被捕获的自由变量）"的组合。
- 不同语言（JS、Python、Rust、Kotlin、Swift）在捕获方式（按引用/按值）、可变性与生命周期上略有差异，本文讲通用概念。

## 具体示例

经典的循环捕获陷阱最能体现"捕获的是变量本身而非快照"：用 `var` 时三个闭包共享同一个 `i`，循环结束后都读到 3；改用 `let`（每轮独立绑定）或 IIFE 才得到 0 1 2。

```javascript
const fns = [];
for (var i = 0; i < 3; i++) fns.push(() => i);
fns.forEach((f) => console.log(f()));   // 3 3 3
// 把 var 换成 let → 0 1 2
```

## 何时用与何时不用

- **用**：回调与事件处理（携带上下文）、函数工厂 / 柯里化 / 偏函数应用、模块模式与私有状态封装、记忆化、React Hooks。
- **不用**：仅为一两个常量就造闭包会让数据流变隐晦；在性能极敏感的热路径上，注意闭包可能延长对象生命周期、增加内存占用。

## 优劣与代价

✅ 优雅地封装状态、实现数据隐藏与函数式抽象、简化回调编写。
✅ 把"函数需要什么环境"内聚成一个可传递单元。
⚠️ 可能意外延长被捕获变量的生命周期，增加内存占用（GC 语言里易致泄漏）。
⚠️ 循环 + 异步场景有经典捕获陷阱；过度使用降低可读性与可调试性。

## 与相关概念的区别

- **闭包 vs 匿名函数**：闭包强调"携带了外部词法环境"，匿名函数只是"没有名字"。匿名函数不一定形成闭包，具名函数也可以是闭包。
- **按引用捕获 vs 按值捕获**：多数语言默认让闭包看到变量的**当前值**（引用语义，外部后续修改可见）；Rust 的 `move` 闭包、Python 的默认参数技巧则偏"按值快照"。

## 常见误区

- 闭包捕获的是变量在创建那一刻的值快照，之后外部怎么改都无所谓。
- for 循环里用 var 声明，异步回调中的闭包各自拿到本轮循环的独立副本。
- 闭包就是匿名函数，两者可以划等号。

## 面试速答

> 🎯 闭包 = 函数 + 它定义时捕获的词法环境；即使外层函数已返回，内层仍能访问被捕获变量（其生命周期被延长），常用于回调、函数工厂与私有状态封装。
