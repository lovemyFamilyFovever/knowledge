# 软件测试完全指南

## 一、测试金字塔：构建可持续的测试策略

测试金字塔由Mike Cohn在2009年提出，是描述自动化测试层次和比例的经典模型。它强调底层测试应多而快，顶层测试应少而精，形成一个稳定的结构。

### 1.1 金字塔结构解析

**底层：单元测试（Unit Tests）**
- **占比**：约70%的自动化测试
- **特点**：执行速度极快（毫秒级）、隔离性强、不依赖外部环境
- **目标**：验证代码单元（函数、方法、类）的逻辑正确性

```python
# Python pytest 示例 - 单元测试
def calculate_discount(price, discount_rate):
    """计算折扣后的价格"""
    if price < 0:
        raise ValueError("价格不能为负数")
    if not 0 <= discount_rate <= 1:
        raise ValueError("折扣率必须在0到1之间")
    return round(price * (1 - discount_rate), 2)

# 测试文件: test_discount.py
import pytest
from discount import calculate_discount

def test_calculate_discount_basic():
    assert calculate_discount(100, 0.1) == 90.0
    assert calculate_discount(200, 0.2) == 160.0

def test_calculate_discount_zero():
    assert calculate_discount(100, 0) == 100.0

def test_calculate_discount_full():
    assert calculate_discount(100, 1) == 0.0

def test_calculate_discount_invalid_negative_price():
    with pytest.raises(ValueError) as exc_info:
        calculate_discount(-10, 0.1)
    assert "价格不能为负数" in str(exc_info.value)

def test_calculate_discount_rounding():
    assert calculate_discount(100.555, 0.1) == 90.5  # 验证四舍五入
```

**中层：集成测试（Integration Tests）**
- **占比**：约20%的自动化测试
- **特点**：验证组件间的交互，依赖真实或模拟的外部服务
- **目标**：测试模块、服务、数据库、外部API之间的集成点

**顶层：端到端测试（E2E Tests）**
- **占比**：约10%的自动化测试
- **特点**：执行速度慢（秒级）、维护成本高、易受UI变化影响
- **目标**：模拟真实用户场景，验证整个系统的业务流程

### 1.2 现代测试金字塔的演变

```
       [E2E]           ← 少量、关键的业务流测试
      /      \
  [集成测试]        ← API契约、组件交互测试
 /          \
[单元测试]          ← 大量、快速的业务逻辑测试
```

**反模式：冰淇淋锥（Ice Cream Cone）**
- 大量手工测试
- 大量E2E自动化测试
- 少量集成测试
- 几乎没有单元测试
- **后果**：测试执行慢、反馈周期长、维护成本高、测试结果不稳定

## 二、测试方法论：TDD、BDD与ATDD

### 2.1 测试驱动开发（TDD）

TDD遵循"红-绿-重构"循环：

1. **红**：先写一个会失败的测试
2. **绿**：编写最少量的代码使测试通过
3. **重构**：改进代码结构而不改变行为

```javascript
// Jest 示例 - TDD实现简单计算器
// 测试文件: calculator.test.js
const Calculator = require('./calculator');

describe('Calculator', () => {
  let calculator;
  
  beforeEach(() => {
    calculator = new Calculator();
  });
  
  test('should start with 0', () => {
    expect(calculator.result).toBe(0);
  });
  
  test('should add numbers', () => {
    calculator.add(5);
    expect(calculator.result).toBe(5);
    
    calculator.add(3);
    expect(calculator.result).toBe(8);
  });
  
  test('should subtract numbers', () => {
    calculator.subtract(5);
    expect(calculator.result).toBe(-5);
  });
  
  test('should reset calculator', () => {
    calculator.add(10);
    calculator.reset();
    expect(calculator.result).toBe(0);
  });
});

// 实现文件: calculator.js
class Calculator {
  constructor() {
    this.result = 0;
  }
  
  add(number) {
    this.result += number;
    return this;
  }
  
  subtract(number) {
    this.result -= number;
    return this;
  }
  
  reset() {
    this.result = 0;
    return this;
  }
}

module.exports = Calculator;
```

### 2.2 行为驱动开发（BDD）

BDD使用自然语言（Gherkin语法）描述行为，促进开发者、测试者、业务人员之间的沟通。

```gherkin
# 用户故事: 购物车功能
Feature: 购物车管理
  作为电商网站用户
  我想要管理我的购物车
  以便我能购买所需商品

  Background:
    Given 用户已登录网站

  Scenario: 添加商品到购物车
    Given 用户在商品列表页面
    When 用户点击"iPhone 13"商品的"加入购物车"按钮
    Then 购物车数量应显示1
    And 购物车中应包含"iPhone 13"

  Scenario: 修改购物车商品数量
    Given 购物车中有1个"iPhone 13"
    When 用户将"iPhone 13"数量改为2
    Then 购物车总价应更新为 1999 * 2 = 3998 元

  Scenario: 删除购物车商品
    Given 购物车中有"iPhone 13"和"保护壳"
    When 用户删除"保护壳"
```


### 2.3 验收测试驱动开发（ATDD）

ATDD在开发前定义验收测试，确保产品符合业务需求。

**ATDD流程：**
1. 讨论需求并定义验收标准
2. 自动化验收测试
3. 实现功能使测试通过
4. 反馈和细化

```go
// Go 单元测试
package user

import (
    "errors"
    "testing"
    "time"
)

type User struct {
    ID        int
    Name      string
    Email     string
    CreatedAt time.Time
}

type UserService struct {
    repo UserRepository
}

func NewUserService(repo UserRepository) *UserService {
    return &UserService{repo: repo}
}

func (s *UserService) GetUser(id int) (*User, error) {
    if id <= 0 {
        return nil, errors.New("invalid user ID")
    }
    
    user, err := s.repo.FindByID(id)
    if err != nil {
        return nil, err
    }
    
    if user == nil {
        return nil, errors.New("user not found")
    }
    
    return user, nil
}

// 测试套件
type MockUserRepository struct {
    FindByIDFunc func(id int) (*User, error)
}

func (m *MockUserRepository) FindByID(id int) (*User, error) {
    if m.FindByIDFunc != nil {
        return m.FindByIDFunc(id)
    }
    return nil, nil
}

func TestGetUser_Success(t *testing.T) {
    // 准备mock
    mockRepo := &MockUserRepository{
        FindByIDFunc: func(id int) (*User, error) {
            return &User{
                ID:    id,
                Name:  "John Doe",
                Email: "john@example.com",
            }, nil
        },
    }
    
    service := NewUserService(mockRepo)
    user, err := service.GetUser(1)
    
    if err != nil {
        t.Errorf("unexpected error: %v", err)
    }
    
    if user.ID != 1 {
        t.Errorf("expected user ID 1, got %d", user.ID)
    }
}

func TestGetUser_InvalidID(t *testing.T) {
    service := NewUserService(&MockUserRepository{})
    
    _, err := service.GetUser(0)
    if err == nil {
        t.Error("expected error for invalid user ID")
    }
    
    expectedError := "invalid user ID"
    if err.Error() != expectedError {
        t.Errorf("expected error '%s', got '%s'", expectedError, err.Error())
    }
}

// 表驱动测试
func TestGetUser_TableDriven(t *testing.T) {
    tests := []struct {
        name        string
        id          int
        mockFunc    func(int) (*User, error)
        expectedErr string
        expectedID  int
    }{
        {
            name: "valid user",
            id:   1,
            mockFunc: func(id int) (*User, error) {
                return &User{ID: id, Name: "Test User"}, nil
            },
            expectedID: 1,
        },
        {
            name:        "invalid ID",
            id:          0,
            expectedErr: "invalid user ID",
        },
        {

            id:   999,
            mockFunc: func(id int) (*User, error) {
                return nil, nil
            },
            expectedErr: "user not found",
        },

    for _, tt := range tests {

            mockRepo := &MockUserRepository{

                    t.Errorf("expected error, got nil")
                }
                if err.Error() != tt.expectedErr {
                    t.Errorf("expected error '%s', got '%s'", tt.expectedErr, err.Error())
                }

            }
            
            if err != nil {
                t.Errorf("unexpected error: %v", err)
            }
            
            if user.ID != tt.expectedID {

            }
        })
    }
}
```

### 3.2 Mock、Stub与Spy

**三者区别：**
- **Stub**：提供预设的返回值，不验证交互
- **Mock**：验证对象间的交互（方法调用次数、参数）
- **Spy**：包装真实对象，记录方法调用

```python
# Python mock 示例
from unittest.mock import Mock, patch, MagicMock, spy

class PaymentGateway:
    def charge(self, amount, currency, token):
        """真实支付网关调用"""
        # 实际实现...
        return {"status": "success", "transaction_id": "txn_123"}

class OrderService:
    def __init__(self, payment_gateway):
        self.payment_gateway = payment_gateway
    
    def place_order(self, order):
        # 业务逻辑...
        result = self.payment_gateway.charge(
            amount=order.total,
            currency=order.currency,
            token=order.payment_token
        )
        
        if result["status"] == "success":
            return {"order_id": order.id, "transaction_id": result["transaction_id"]}
        else:
            raise PaymentFailedError("Payment failed")

# 使用Mock
def test_place_order_success():

        "status": "success",

    assert result["transaction_id"] == "txn_mock_123"
```

```java
import org.testcontainers.containers.PostgreSQLContainer;
import org.testcontainers.junit.jupiter.Container;
import org.testcontainers.junit.jupiter.Testcontainers;

@Testcontainers
public class UserRepositoryIntegrationTest {
    
    @Container
    private static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:13")
            .withDatabaseName("testdb")
            .withUsername("test")
            .withPassword("test")
            .withInitScript("init.sql");
    
    private UserRepository userRepository;

    void setUp() {
        DataSource dataSource = DataSourceBuilder.create()
                .url(postgres.getJdbcUrl())
                .username(postgres.getUsername())
                .password(postgres.getPassword())
                .build();
        
        userRepository = new UserRepository(dataSource);
    }
    
    @Test
    void shouldSaveAndRetrieveUser() {
        // Given
        User user = new User("John Doe", "john@example.com");
        
        // When
        userRepository.save(user);
        User retrieved = userRepository.findById(user.getId());
        
        // Then

        userRepository.save(new User("User 3", "user3@test.com"));
        
        // When
        List<User> users = userRepository.findByEmailDomain("example.com");
        
        // Then

        assertThat(users).extracting(User::getEmail)

    }
```

```javascript
describe('购物车流程', () => {
  beforeEach(() => {
    cy.session('user-session', () => {
      cy.visit('/login');

      cy.get('[data-cy="password"]').type('password123');

    cy.get('@firstProduct')
      .find('[data-cy="product-name"]')
      .invoke('text')
      .as('productName');
    
    cy.get('@firstProduct')
      .find('[data-cy="add-to-cart"]')
      .click();
    
    cy.get('[data-cy="cart-badge"]')
      .should('have.text', '1');
    
    cy.get('[data-cy="cart-icon"]').click();
    cy.url().should('include', '/cart');
    
    cy.get('@productName').then((productName) => {
      cy.get('[data-cy="cart-item"]')
        .first()
        .should('contain', productName);
    });
  });
  
  it('应该显示正确的总价', () => {
    // 添加多个商品
    cy.get('[data-cy="product-card"]').eq(0).find('[data-cy="add-to-cart"]').click();
    cy.get('[data-cy="product-card"]').eq(1).find('[data-cy="add-to-cart"]').click();
    
    cy.get('[data-cy="cart-icon"]').click();
    
    // 计算预期总价
    let expectedTotal = 0;
    cy.get('[data-cy="cart-item"]').each(($item) => {
      cy.wrap($item)
        .find('[data-cy="item-price"]')
        .invoke('text')
        .then((text) => {
          expectedTotal += parseFloat(text.replace('¥', ''));
        });
    }).then(() => {
      cy.get('[data-cy="cart-total"]')
        .invoke('text')
        .then((text) => {
          const actualTotal = parseFloat(text.replace('¥', ''));
          expect(actualTotal).to.eq(expectedTotal);
        });
    });
  });
  
  // 使用Cypress自定义命令
```
