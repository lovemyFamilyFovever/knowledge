# 协程


> 📌 **导航**：本文是 **协程** 词条，属于 programming-languages 术语集。相关枢纽：[[Go语言核心]]、[[Python高级编程完全指南]]、[[Rust系统编程入门到精通]]、[[Rust编程基础]]、[[TypeScript深入]]。

## 定义

**一句话定义：** 协程(Coroutine)是一种可以主动暂停(挂起)并在之后恢复执行的程序组件,它由用户态调度、以协作方式在多个执行流之间切换,从而用同步的写法实现并发,常用于高效处理 I/O 密集型任务。

**通俗类比：** 像一个人同时看几本书——读到需要等外卖(阻塞 I/O)时,他不干等,而是先放下这本去看另一本,等外卖到了再回来接着读;一个人(单线程)靠"主动切换"推进多件事。

> 多义说明:协程是**用户态**的轻量执行单元,区别于内核线程(见 [[线程]]);分为有栈协程(如 goroutine、Lua)与无栈协程(如 C++20、Python async、Rust async)。本文综述。

## 原理与机制

- **挂起与恢复:** 协程在 `await`/`yield` 处主动让出控制权并保存自身状态,稍后从中断处恢复,而不是被抢占。
- **调度:** 通常由用户态的事件循环/运行时调度(如 asyncio、Kotlin 协程、Go runtime),避免内核态切换开销。
- **协作式:** 切换点显式且可预测(不像线程被 OS 抢占),单线程内同一时刻只有一个协程执行,简化同步。
- **有栈 vs 无栈:** 有栈协程自带独立调用栈(可在任意调用深度挂起);无栈协程由编译器转换为状态机。

## 关键组成

| 组成 | 说明 |
|------|------|
| 挂起点(await/yield) | 主动让出控制权的位置 |
| 协程状态 | 挂起时保存的上下文 |
| 事件循环 / 调度器 | 用户态调度协程 |
| 运行时 | 如 Go 的 GMP 调度模型 |

## 应用场景

- 高并发 I/O(网络服务器、爬虫、代理)
- 异步编程(async/await)
- Go goroutine、Python asyncio、Kotlin/C#/JavaScript 异步
- 游戏脚本与协作式任务

## 优点与局限

- 优点:轻量(创建/切换成本远低于线程)、单机可支撑海量并发、用同步写法表达异步逻辑、避免回调地狱。
- 局限:CPU 密集型任务无法靠协程并行(需配合多线程/多进程);协作式调度下一个协程阻塞会拖累整体;调试与生态依赖语言支持。

## 常见误区

- 协程 ≠ 线程:协程由用户态调度、更轻量;线程由内核调度。
- 协程不会自动利用多核:单线程事件循环内是"并发"而非"并行",需多 worker。
- async 函数中若调用了未 await 的同步阻塞 I/O,会卡住整个事件循环。
- 协程是并发手段,不等于并行。
