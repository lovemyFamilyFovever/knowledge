# **编译原理实战指南：从理论到构建你自己的语言**

## **第一部分：编译器架构总览**

编译器的核心任务是将一种**高级语言**（源代码）翻译成另一种**低级语言**（通常是汇编或机器码），同时**保持程序的语义不变**。一个设计良好的编译器采用分层架构，通常分为前端（Front End）、中端（Middle End）和后端（Back End），这实现了关注点分离，使得编译器能够支持多种源语言和多种目标平台。

### **1.1 前端（Front End）**
前端负责**理解源代码**。它的输入是源代码字符流，输出是**抽象语法树**和**符号表**。前端是与源语言强相关的部分。
*   **词法分析**：将字符流转换为标记（Token）流。识别关键字、标识符、字面量、运算符等。
*   **语法分析**：根据语法规则将标记流组织成树状的抽象语法结构，即**抽象语法树**。
*   **语义分析**：进行语义检查（如类型检查、变量是否声明），并收集信息（如标识符的类型、作用域）填入**符号表**。

### **1.2 中端（Middle End）**
中端是编译器的核心优化和转换阶段，它通常在**与语言和目标机器无关**的**中间表示**上进行工作。这使得针对不同语言的前端和针对不同机器的后端可以复用中端的优化能力。
*   **生成中间表示**：将AST转换为更易于优化和分析的线性或图式表示，如**三地址码**、**静态单赋值形式**。
*   **优化**：对IR进行一系列的分析和变换，旨在提升代码性能（如减少指令、减少访存）、减小代码体积，同时严格保持程序语义。这是编译器性能提升的主要舞台。

### **1.3 后端（Back End）**
后端负责将优化后的中间表示映射到**特定目标机器**的指令集上。
*   **指令选择**：将IR操作匹配到目标机器的指令上。这是一个复杂的模式匹配问题。
*   **寄存器分配**：决定哪些变量值应该保存在有限的CPU寄存器中，哪些需要溢出到内存。这是一个图着色问题。
*   **指令调度**：为了充分利用CPU的流水线和功能单元，对生成的指令序列进行重排序。
*   **代码发射**：最终生成目标文件（如`.o`文件）或汇编代码。

**流程图**：
```
源代码 -> [词法分析] -> 记号流 -> [语法分析] -> AST -> [语义分析] -> annotated AST / Symbol Table
                    |
                    v
              [中间表示生成] -> IR (如 LLVM IR) -> [优化] -> 优化后IR
                    |
                    v
              [指令选择] -> Machine IR -> [寄存器分配] -> [指令调度] -> [代码发射] -> 目标机器码
```

## **第二部分：词法分析**

词法分析器的任务是将源代码的**字符序列**转换成有意义的**词法单元**序列。

### **2.1 正则表达式、NFA与DFA**
词法规则通常用**正则表达式**描述。为了构建实际的词法分析器，我们需要将正则表达式转换为可执行的有限状态自动机。

1.  **正则表达式 -> NFA**：使用**汤普森构造法**。对于基本字符、连接、选择（`|`）和闭包（`*`）等操作，都有对应的NFA构建规则，并将它们组合起来。NFA的特点是**在同一个状态下，对于一个输入符号，可能有多个后续状态转移**。
2.  **NFA -> DFA**：使用**子集构造法**。核心思想是将NFA状态集的“子集”视为DFA的一个状态。给定一个NFA状态集S和输入符号a，计算从S中任一状态出发经过a能到达的所有状态集合（称为ε-闭包和移动的组合），这个新集合就对应DFA的一个新状态。这个过程会枚举所有可能的子集，可能产生指数级的状态数，但实际中通过优化是可控的。
3.  **DFA -> 最小化DFA**：使用**分割法**或**莫尔算法**。将等价的状态合并，得到状态数最少且等价的DFA，这是最高效的实现模型。

### **2.2 词法分析器生成**
手动编写基于DFA的词法分析器是繁琐且容易出错的。因此，我们使用**词法分析器生成器**，如`Lex`/`Flex`。

**示例：一个识别整数和简单标识符的Lex文件片段**
```lex
%{
#include <stdio.h>
%}
DIGIT   [0-9]
ID      [a-zA-Z_][a-zA-Z_0-9]*
%%
{DIGIT}+    { printf("INTEGER: %s\n", yytext); }
{ID}        { printf("IDENTIFIER: %s\n", yytext); }
[ \t\n]+    ; /* 忽略空白 */
.           { printf("Unknown character: %s\n", yytext); }
%%
int main() { yylex(); return 0; }
```
运行`lex lexer.l`，它会生成`lex.yy.c`文件，其中包含一个基于DFA的`yylex()`函数。词法分析器生成器将你的正则规则隐式地转换为了NFA，再转换为DFA，最后生成C代码。

## **第三部分：语法分析**

语法分析器的任务是将记号流组织成符合语法规则的**抽象语法树**。

### **3.1 分析方法**
*   **自顶向下（如LL分析）**：从起始符号开始，尝试匹配输入。**递归下降分析器**是最直观的手写方式，每个非终结符对应一个递归函数。LL(k)分析器需要文法满足**LL(k)条件**（无左递归，且能通过前k个符号确定产生式）。
    ```python
    # 简单的递归下降解析器示例片段（识别 `expr: term (('+'|'-') term)*`）
    def parse_expr():
        left = parse_term()
        while current_token in ('+', '-'):
            op = current_token
            consume(op)
            right = parse_term()
            left = BinOpNode(op, left, right) # 构建AST节点
        return left
    ```

*   **自底向上（如LR分析）**：从输入开始，尝试归约到起始符号。LR分析器（特别是LALR(1)，如Yacc/Bison使用）能力更强，能处理更广泛的文法，但原理更复杂。它使用**移进-归约**操作和一张预先生成的**分析表**。

### **3.2 抽象语法树**
AST是源代码结构的一种树形表示，它省略了无关的语法细节（如括号、分号），只保留核心的结构信息。

**示例：`x = 3 + 5 * y` 的AST可能表示为**
```
      Assignment
      /    \
    x      BinOp(+)
           /   \
        BinOp(*) Num(3)
        /   \
    Num(5)  Identifier(y)
```
在Python中，我们可以用类来定义各种AST节点：
```python
class ASTNode:
    pass

class Num(ASTNode):
    def __init__(self, value):
        self.value = value

class BinOp(ASTNode):
    def __init__(self, op, left, right):
        self.op = op
        self.left = left
        self.right = right

class Assign(ASTNode):
    def __init__(self, target, value):
        self.target = target
        self.value = value
```
语法分析器的任务就是根据语法规则，调用类似`parse_expr()`的函数，最终构建出这棵AST树。

## **第四部分：语义分析**

语义分析在语法分析后进行，确保程序在“含义”上是正确的。

### **4.1 符号表**
符号表是一个核心数据结构，它存储了标识符（变量、函数、类型等）的声明信息，如名称、类型、作用域、存储位置等。
```python
class Symbol:
    def __init__(self, name, sym_type, scope_level):
        self.name = name
        self.type = sym_type  # e.g., 'int', 'func(int) -> void'
        self.scope = scope_level
        # ... 其他属性

class SymbolTable:
    def __init__(self):
        self.symbols = {} # name -> Symbol
        self.scope_level = 0
    
    def define(self, symbol):
        key = (symbol.name, symbol.scope)
        if key in self.symbols:
            raise SemanticError(f"Symbol '{symbol.name}' already defined in scope {symbol.scope}")
        self.symbols[key] = symbol
    
    def lookup(self, name):
        # 从当前作用域向外逐层查找
        for level in range(self.scope_level, -1, -1):
            key = (name, level)
            if key in self.symbols:
                return self.symbols[key]
        return None
```

### **4.2 类型检查**
这是语义分析的重要组成部分。编译器需要检查表达式和语句中的类型是否一致或兼容。
*   **表达式类型推断**：如`a + b`，若`a`是`int`，`b`是`float`，则结果类型可能是`float`（隐式转换）。
*   **赋值检查**：左侧变量的类型是否能接受右侧表达式的值。
*   **函数调用检查**：实参数量和类型是否与形参匹配。

一个简化的类型检查器可能遍历AST，为每个节点计算其类型，并在发现不匹配时报错。

### **4.3 作用域分析**
确定标识符的可见性。常见的是**词法作用域**（静态作用域），即标识符的含义由其在源代码中的位置决定，与运行时调用无关。语义分析器需要维护一个作用域栈，在进入新作用域（如函数、代码块）时压栈，退出时弹栈，并根据作用域规则在符号表中查找或定义符号。

## **第五部分：中间表示**

IR是编译器内部使用的、介于源代码和目标代码之间的表示形式。

### **5.1 三地址码**
一种简单的线性IR，每条指令最多有三个操作数（两个源，一个目标）。
`x = y op z`
示例：`t1 = a * b`， `t2 = t1 + c`， `x = t2`
它易于生成、分析和优化。

### **5.2 静态单赋值形式**
SSA是现代编译器优化的基石。其核心规则是：**每个变量只被定义一次**。要使用一个变量的“值”，必须引用它最近一次定义的那个版本。当控制流汇合时，使用**φ函数**来选择来自不同路径的版本。
**示例**：
普通代码：
```
if (cond) {
    x = 1;
} else {
    x = 2;
}
y = x + 1;
```
SSA形式：
```
if (cond) {
    x1 = 1;
} else {
    x2 = 2;
}
x3 = φ(x1, x2); // x3的值取决于从哪条路径过来
y1 = x3 + 1;
```
SSA使得许多优化（如常量传播、死代码消除）变得非常自然和强大，因为变量的定义点和使用点之间的依赖关系一目了然。

## **第六部分：代码优化**

优化是在IR上进行的语义保持变换。

### **6.1 局部优化（基本块内）**
*   **常量折叠**：在编译时计算常量表达式。如 `x = 3 * 5 + 2` -> `x = 17`。
*   **常量传播**：如果一个变量被赋值为一个常量，那么在其后的使用中，可以将该变量替换为这个常量。
*   **公共子表达式消除**：如果相同的表达式被计算多次且中间没有改变，可以只计算一次，后续使用其结果。

### **6.2 循环优化**
*   **循环不变代码外提**：将循环中每次迭代结果相同的计算移到循环外。
*   **强度削弱**：将循环中昂贵的操作（如乘法）替换为廉价的操作（如加法）。例如，将`for(i=0; i<n; i++) a[i*4] = 0;`中的`i*4`用一个累加的变量代替。
*   **循环展开**：减少循环控制开销，可能增加指令级并行度。

### **6.3 全局优化与过程间优化**
*   **死代码消除**：删除永远不会执行或其结果永远不会被使用的代码。
*   **内联**：将函数体直接插入到调用处，消除函数调用开销，并可能为更多优化创造机会。
*   **别名分析**：确定两个指针是否可能指向同一内存位置，这对很多优化至关重要。

## **第七部分：代码生成**

代码生成将优化后的IR转换为目标机器代码。

### **7.1 指令选择**
这是一个将IR树模式匹配到目标机器指令树的问题。例如，`x = y + z`可以映射为：
1.  `LOAD R1, [y_addr]` (将y加载到寄存器R1)
2.  `LOAD R2, [z_addr]` (将z加载到寄存器R2)
3.  `ADD R1, R1, R2` (执行加法)
4.  `STORE R1, [x_addr]` (将结果存回x的地址)
一个复杂的IR操作（如数组访问）可能需要多条机器指令。指令选择器需要在**代码质量**和**选择速度**之间权衡。

### **7.2 寄存器分配**
目标机器的寄存器数量有限，但IR中可能使用了大量的虚拟寄存器。寄存器分配器需要决定哪些虚拟寄存器**驻留在物理寄存器**中，哪些**溢出到内存**（称为spill）。
*   **图着色算法**：构建一个**干涉图**，图中节点是虚拟寄存器，如果两个寄存器的“生命期”重叠（即同时活跃），就在它们之间连一条边。然后尝试用K种颜色（K是物理寄存器数量）为图着色，使得相邻节点颜色不同。无法着色的节点需要溢出。这是一个NP完全问题，有各种启发式算法。

### **7.3 指令调度**
为了减少CPU流水线停顿，编译器可能会重排指令顺序，但必须遵守**数据依赖**和**控制依赖**。例如，将一条访存延迟较高的指令提前，让其他无关指令填充其等待时间。

## **第八部分：垃圾回收算法**

对于支持自动内存管理的语言，垃圾回收器是运行时系统的一部分。

### **8.1 标记-清除**
1.  **标记**：从根集合（如全局变量、栈上的指针）开始，递归遍历所有可达的对象，并打上标记。
2.  **清除**：遍历整个堆，回收所有未被标记的对象。
    *   **优点**：简单，处理循环引用。
    *   **缺点**：会导致**内存碎片**，且GC时程序需暂停（Stop-The-World）。

### **8.2 分代收集**
基于“大多数对象都是朝生夕灭”的假说。将堆分为**年轻代**和**老年代**。
*   新对象分配在年轻代，年轻代GC频率高（使用**复制算法**，高效且无碎片）。
*   存活过多次年轻代GC的对象晋升到老年代，老年代GC频率低（可能使用标记-清除或标记-整理）。
*   **优点**：针对不同生命周期的对象采用不同策略，整体GC效率高。

### **8.3 增量/并发收集**
为了减少GC停顿时间，将GC工作分解成小步骤，与应用程序线程交替（增量）或同时（并发）执行。
*   **三色标记法**是并发GC的基础。对象用白色（未访问）、灰色（已访问，但子引用未完全扫描）、黑色（已访问，且子引用已扫描）表示。GC线程和应用线程并发运行，需要处理应用线程修改对象引用带来的**标记丢失**或**错误回收**问题（通过写屏障等技术）。

## **第九部分：实战：用Python实现一个简单的编程语言**

我们将实现一个支持变量、算术运算、函数定义和调用的微型语言**MPL**。

### **9.1 词法分析器**
```python
import re
from enum import Enum, auto

class TokenKind(Enum):
    INTEGER = auto()
    IDENTIFIER = auto()
    PLUS = auto()
    MINUS = auto()
    STAR = auto()
    SLASH = auto()
    EQUALS = auto()
    LPAREN = auto()
    RPAREN = auto()
    LBRACE = auto()
    RBRACE = auto()
    COMMA = auto()
    DEF = auto()
    RETURN = auto()
    IF = auto()
    ELSE = auto()
    WHILE = auto()
    SEMICOLON = auto()
    EOF = auto()

class Token:
    def __init__(self, kind, value, pos):
        self.kind = kind
        self.value = value
        self.pos = pos

def tokenize(code):
    tokens = []
    keywords = {'def': TokenKind.DEF, 'return': TokenKind.RETURN, 'if': TokenKind.IF, 'else': TokenKind.ELSE, 'while': TokenKind.WHILE}
    token_specification = [
        ('INTEGER', r'\d+'),
        ('IDENTIFIER', r'[A-Za-z_][A-Za-z0-9_]*'),
        ('PLUS', r'\+'),
        ('MINUS', r'-'),
        ('STAR', r'\*'),
        ('SLASH', r'/'),
        ('EQUALS', r'='),
        ('LPAREN', r'\('),
        ('RPAREN', r'\)'),
        ('LBRACE', r'\{'),
        ('RBRACE', r'\}'),
        ('COMMA', r','),
        ('SEMICOLON', r';'),
        ('SKIP', r'[ \t\n]+'),
        ('MISMATCH', r'.'),
    ]
    tok_regex = '|'.join('(?P<%s>%s)' % pair for pair in token_specification)
    line_num = 1
    line_start = 0
    for mo in re.finditer(tok_regex, code):
        kind = mo.lastgroup
        value = mo.group()
        column = mo.start() - line_start
        if kind == 'INTEGER':
            value = int(value)
            tokens.append(Token(TokenKind.INTEGER, value, mo.start()))
        elif kind == 'IDENTIFIER':
            if value in keywords:
                tokens.append(Token(keywords[value], value, mo.start()))
            else:
                tokens.append(Token(TokenKind.IDENTIFIER, value, mo.start()))
        elif kind == 'SKIP':
            if '\n' in value:
                line_num += 1
                line_start = mo.end()
            continue
        elif kind == 'MISMATCH':
            raise RuntimeError(f'{value!r} unexpected on line {line_num} at position {column}')
        else:
            # 对于单字符符号，kind就是TokenKind的名称，如'PLUS'
            # 我们通过getattr获取对应的枚举值
            token_kind = TokenKind[kind]
            tokens.append(Token(token_kind, value, mo.start()))
    tokens.append(Token(TokenKind.EOF, '', len(code)))
    return tokens
```

### **9.2 语法分析器（构建AST）**
```python
class ASTNode:
    pass

class Program(ASTNode):
    def __init__(self, statements):
        self.statements = statements

class Integer(ASTNode):
    def __init__(self, value):
        self.value = value

class Identifier(ASTNode):
    def __init__(self, name):
        self.name = name

class BinOp(ASTNode):
    def __init__(self, op, left, right):
        self.op = op
        self.left = left
        self.right = right

class UnaryOp(ASTNode):
    def __init__(self, op, expr):
        self.op = op
        self.expr = expr

class Assignment(ASTNode):
    def __init__(self, target, value):
        self.target = target
        self.value = value

class FunctionDef(ASTNode):
    def __init__(self, name, params, body):
        self.name = name
        self.params = params # list of Identifiers
        self.body = body # list of statements

class FunctionCall(ASTNode):
    def __init__(self, func, args):
        self.func = func # Identifier
        self.args = args # list of expressions

class ReturnStatement(ASTNode):
    def __init__(self, expr):
        self.expr = expr

class IfStatement(ASTNode):
    def __init__(self, condition, then_body, else_body=None):
        self.condition = condition
        self.then_body = then_body
        self.else_body = else_body

class WhileStatement(ASTNode):
    def __init__(self, condition, body):
        self.condition = condition
        self.body = body

class Parser:
    def __init__(self, tokens):
        self.tokens = tokens
        self.pos = 0

    def parse(self):
        statements = []
        while self.current_token().kind != TokenKind.EOF:
            statements.append(self.parse_statement())
        return Program(statements)

    def current_token(self):
        return self.tokens[self.pos]

    def eat(self, expected_kind):
        token = self.current_token()
        if token.kind != expected_kind:
            raise SyntaxError(f"Expected {expected_kind.name}, got {token.kind.name} at position {token.pos}")
        self.pos += 1
        return token

    def parse_statement(self):
        token = self.current_token()
        if token.kind == TokenKind.DEF:
            return self.parse_function_def()
        elif token.kind == TokenKind.IF:
            return self.parse_if_statement()
        elif token.kind == TokenKind.WHILE:
            return self.parse_while_statement()
        elif token.kind == TokenKind.RETURN:
            self.eat(TokenKind.RETURN)
            expr = self.parse_expression()
            self.eat(TokenKind.SEMICOLON)
            return ReturnStatement(expr)
        else:
            # 表达式语句（赋值或函数调用）
            left = self.parse_expression()
            if self.current_token().kind == TokenKind.EQUALS:
                self.eat(TokenKind.EQUALS)
                value = self.parse_expression()
                self.eat(TokenKind.SEMICOLON)
                return Assignment(left, value)
            else:
                # 函数调用语句（以Identifier后跟LPAREN开头）
                if isinstance(left, FunctionCall):
                    self.eat(TokenKind.SEMICOLON)
                    return left
                else:
                    # 普通表达式语句，这里我们只允许赋值或函数调用作为语句
                    raise SyntaxError(f"Expression cannot be a statement at position {token.pos}")

    def parse_expression(self):
        # 处理加减法，优先级低
        left = self.parse_term()
        while self.current_token().kind in (TokenKind.PLUS, TokenKind.MINUS):
            op_token = self.current_token()
            self.pos += 1
            right = self.parse_term()
            left = BinOp(op_token.value, left, right)
        return left

    def parse_term(self):
        # 处理乘除法，优先级高
        left = self.parse_factor()
        while self.current_token().kind in (TokenKind.STAR, TokenKind.SLASH):
            op_token = self.current_token()
            self.pos += 1
            right = self.parse_factor()
            left = BinOp(op_token.value, left, right)
        return left

    def parse_factor(self):
        token = self.current_token()
        if token.kind == TokenKind.INTEGER:
            self.pos += 1
            return Integer(token.value)
        elif token.kind == TokenKind.LPAREN:
            self.eat(TokenKind.LPAREN)
            expr = self.parse_expression()
            self.eat(TokenKind.RPAREN)
            return expr
        elif token.kind == TokenKind.MINUS:
            self.pos += 1
            expr = self.parse_factor()
            return UnaryOp('-', expr)
        elif token.kind == TokenKind.IDENTIFIER:
            self.pos += 1
            # 检查是否为函数调用
            if self.current_token().kind == TokenKind.LPAREN:
                self.eat(TokenKind.LPAREN)
                args = []
                if self.current_token().kind != TokenKind.RPAREN:
                    args.append(self.parse_expression())
                    while self.current_token().kind == TokenKind.COMMA:
                        self.eat(TokenKind.COMMA)
                        args.append(self.parse_expression())
                self.eat(TokenKind.RPAREN)
                return FunctionCall(Identifier(token.value), args)
            else:
                return Identifier(token.value)
        else:
            raise SyntaxError(f"Unexpected token {token.kind.name} at position {token.pos}")

    def parse_function_def(self):
        self.eat(TokenKind.DEF)
        name = Identifier(self.eat(TokenKind.IDENTIFIER).value)
        self.eat(TokenKind.LPAREN)
        params = []
        if self.current_token().kind == TokenKind.IDENTIFIER:
            params.append(Identifier(self.eat(TokenKind.IDENTIFIER).value))
            while self.current_token().kind == TokenKind.COMMA:
                self.eat(TokenKind.COMMA)
                params.append(Identifier(self.eat(TokenKind.IDENTIFIER).value))
        self.eat(TokenKind.RPAREN)
        self.eat(TokenKind.LBRACE)
        body = []
        while self.current_token().kind != TokenKind.RBRACE:
            body.append(self.parse_statement())
        self.eat(TokenKind.RBRACE)
        return FunctionDef(name, params, body)

    def parse_if_statement(self):
        self.eat(TokenKind.IF)
        self.eat(TokenKind.LPAREN)
        condition = self.parse_expression()
        self.eat(TokenKind.RPAREN)
        self.eat(TokenKind.LBRACE)
        then_body = []
        while self.current_token().kind != TokenKind.RBRACE:
            then_body.append(self.parse_statement())
        self.eat(TokenKind.RBRACE)
        else_body = None
        if self.current_token().kind == TokenKind.ELSE:
            self.eat(TokenKind.ELSE)
            self.eat(TokenKind.LBRACE)
            else_body = []
            while self.current_token().kind != TokenKind.RBRACE:
                else_body.append(self.parse_statement())
            self.eat(TokenKind.RBRACE)
        return IfStatement(condition, then_body, else_body)

    def parse_while_statement(self):
        self.eat(TokenKind.WHILE)
        self.eat(TokenKind.LPAREN)
        condition = self.parse_expression()
        self.eat(TokenKind.RPAREN)
        self.eat(TokenKind.LBRACE)
        body = []
        while self.current_token().kind != TokenKind.RBRACE:
            body.append(self.parse_statement())
        self.eat(TokenKind.RBRACE)
        return WhileStatement(condition, body)
```

### **9.3 解释器**
```python
class Environment:
    def __init__(self, parent=None):
        self.vars = {}
        self.parent = parent

    def get(self, name):
        if name in self.vars:
            return self.vars[name]
        if self.parent:
            return self.parent.get(name)
        raise NameError(f"Variable '{name}' not defined")

    def set(self, name, value):
        self.vars[name] = value

class Function:
    def __init__(self, func_def, closure_env):
        self.func_def = func_def
        self.closure_env = closure_env # 闭包环境

class Interpreter:
    def __init__(self):
        self.global_env = Environment()

    def interpret(self, program):
        result = None
        for stmt in program.statements:
            result = self.execute(stmt, self.global_env)
        return result

    def execute(self, node, env):
        if isinstance(node, Integer):
            return node.value
        elif isinstance(node, Identifier):
            return env.get(node.name)
        elif isinstance(node, BinOp):
            left = self.execute(node.left, env)
            right = self.execute(node.right, env)
            if node.op == '+': return left + right
            elif node.op == '-': return left - right
            elif node.op == '*': return left * right
            elif node.op == '/': return left / right
        elif isinstance(node, UnaryOp):
            expr = self.execute(node.expr, env)
            if node.op == '-': return -expr
        elif isinstance(node, Assignment):
            value = self.execute(node.value, env)
            if isinstance(node.target, Identifier):
                env.set(node.target.name, value)
            else:
                raise RuntimeError("Invalid assignment target")
            return value
        elif isinstance(node, FunctionDef):
            func = Function(node, env) # 创建闭包
            env.set(node.name.name, func)
            return func
        elif isinstance(node, FunctionCall):
            func = self.execute(node.func, env)
            if not isinstance(func, Function):
                raise RuntimeError(f"'{node.func.name}' is not a function")
            args = [self.execute(arg, env) for arg in node.args]
            # 创建新的作用域，继承闭包环境
            func_env = Environment(func.closure_env)
            for param, arg in zip(func.func_def.params, args):
                func_env.set(param.name, arg)
            # 执行函数体
            try:
                for stmt in func.func_def.body:
                    self.execute(stmt, func_env)
                return None # 如果没有return语句，返回None
            except ReturnException as e:
                return e.value
        elif isinstance(node, ReturnStatement):
            value = self.execute(node.expr, env)
            raise ReturnException(value)
        elif isinstance(node, IfStatement):
            condition = self.execute(node.condition, env)
            if condition: # 假设非零为真
                for stmt in node.then_body:
                    self.execute(stmt, env)
            elif node.else_body:
                for stmt in node.else_body:
                    self.execute(stmt, env)
        elif isinstance(node, WhileStatement):
            while self.execute(node.condition, env):
                for stmt in node.body:
                    self.execute(stmt, env)

class ReturnException(Exception):
    def __init__(self, value):
        self.value = value

# 示例运行
code = """
def factorial(n) {
    if (n <= 1) {
        return 1;
    } else {
        return n * factorial(n - 1);
    }
}
result = factorial(5);
"""
tokens = tokenize(code)
parser = Parser(tokens)
ast = parser.parse()
interpreter = Interpreter()
interpreter.interpret(ast)
print(interpreter.global_env.get('result')) # 输出 120
```

这个实战项目完整地演示了从**文本 -> 词法分析 -> 语法分析 -> AST -> 语义与执行**的全过程。它是一个解释器，但理解了前端和中间表示后，你可以轻松扩展，加入字节码编译和虚拟机，或者接入LLVM生成机器码。

## **第十部分：LLVM简介**

LLVM是一个模块化、可重用的编译器基础设施。它的设计哲学是提供一套**现代化的、与语言和目标无关的**优化和代码生成组件。

### **10.1 三层架构**
1.  **前端**：负责将源代码翻译成LLVM IR。Clang（C/C++/ObjC）、Rust编译器、Swift编译器等都使用LLVM前端。每个前端可以独立开发。
2.  **中端**：**LLVM IR**是核心。它是一种强类型的、类似汇编的低级语言，但带有高级特性（如SSA、无限寄存器）。所有前端都生成LLVM IR。
3.  **后端**：负责将LLVM IR翻译成特定机器码（x86, ARM, MIPS等）。LLVM为多种目标架构提供了高质量的后端。

### **10.2 LLVM IR**
LLVM IR有三种等价形式：
*   **人类可读的汇编格式** (`.ll`)：方便阅读和调试。
*   **二进制格式** (`.bc`)：紧凑，适合存储和传输。
*   **内存中的数据结构**：供优化器直接操作。
