# 移动开发概览


> 📌 **导航**：本文是 **移动开发概览** 词条，属于 mobile 术语集。相关枢纽：[[移动开发概览]]。

## 移动开发技术栈

**一句话定义：** 移动开发是为手机和平板开发应用程序的技术领域。

### 开发方式对比

| 方式 | 技术 | 优点 | 缺点 |
|------|------|------|------|
| 原生iOS | Swift/Objective-C | 性能最好、体验最佳 | 只能iOS |
| 原生Android | Kotlin/Java | 性能最好 | 只能Android |
| 跨平台 | Flutter/React Native | 一套代码两端用 | 性能略逊 |
| H5混合 | Vue/React + WebView | 开发快、热更新 | 体验差 |
| 小程序 | 微信/支付宝DSL | 无需安装 | 受限于平台 |

### Flutter

```dart
// Flutter用Dart语言，Widget构建UI
class MyHomePage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('首页')),
      body: Center(
        child: Text('Hello Flutter!'),
      ),
    );
  }
}
```

**特点：** 自绘引擎（不依赖原生组件）、热重载、高性能

### React Native

```jsx
// 用React + JavaScript
function App() {
  return (
    <View style={styles.container}>
      <Text>Hello React Native!</Text>
    </View>
  );
}
```

**特点：** 使用原生组件、JS桥接、社区生态丰富

### 移动端特有问题

| 问题 | 说明 | 解决方案 |
|------|------|----------|
| 适配 | 屏幕尺寸/分辨率多样 | 响应式布局、安全区域 |
| 性能 | 设备性能有限 | 列表虚拟化、图片优化 |
| 网络 | 信号不稳定 | 离线缓存、重试机制 |
| 电量 | 电池有限 | 减少后台活动、定位优化 |
| 存储 | 空间有限 | 数据清理、按需下载 |
| 权限 | 隐私保护 | 最小权限、动态申请 |

### 应用发布流程

**iOS：**
1. Apple Developer账号（$99/年）
2. Xcode构建 → Archive
3. App Store Connect上传
4. 审核（1-7天）
5. 上架

**Android：**
1. Google Play账号（$25一次性）
2. 签名APK/AAB
3. Play Console上传
4. 审核（通常几小时）
5. 上架
