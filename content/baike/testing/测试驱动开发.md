# 测试驱动开发

## TDD流程

```
Red(写失败测试) -> Green(写最少代码通过) -> Refactor(重构)
```

## 测试金字塔

```
        /  E2E  \         少量
       / 集成测试 \        适量
      /  单元测试   \       大量
```

| 层级 | 范围 | 速度 | 成本 |
|------|------|------|------|
| 单元测试 | 函数/类 | 毫秒 | 低 |
| 集成测试 | 模块间 | 秒 | 中 |
| E2E测试 | 全链路 | 分钟 | 高 |

## 测试框架

| 语言 | 框架 |
|------|------|
| Python | pytest |
| JavaScript | Jest, Vitest |
| Java | JUnit |
| Go | testing |
