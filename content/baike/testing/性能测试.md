# 性能测试


> 📌 **导航**：本文是 **性能测试** 词条，属于 testing 术语集。相关枢纽：[[01 - 测试基础]]、[[02 - 测试工具]]、[[03 - 性能测试]]、[[单元测试]]、[[性能测试]]。

## 测试类型

| 类型 | 目的 | 工具 |
|------|------|------|
| 负载测试 | 正常负载下表现 | JMeter, k6 |
| 压力测试 | 极限负载 | Locust, wrk |
| 浸泡测试 | 长时间运行 | 持续运行数天 |
| 尖峰测试 | 突然流量高峰 | k6 |

## 指标

| 指标 | 说明 |
|------|------|
| QPS/TPS | 每秒请求数/事务数 |
| P50/P95/P99 | 响应时间百分位 |
| Error Rate | 错误率 |
| Throughput | 吞吐量 |

## 压测方法论

```
1. 确定目标(QPS/P99)
2. 准备环境(与生产一致)
3. 逐步加压
4. 观察指标
5. 找到拐点
6. 分析瓶颈
7. 优化 -> 重新测试
```
