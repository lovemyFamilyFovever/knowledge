# 内容分发网络

## 定义

**一句话定义：** 内容分发网络(Content Delivery Network, CDN)是由分布在各地的边缘服务器组成的网络,它把内容缓存到离用户更近的位置并按需就近提供服务,从而降低访问延迟、减轻源站压力、提升可用性与抗攻击能力。

**通俗类比：** 像连锁便利店——总仓库(源站)不必服务全国每个人,各地便利店(边缘节点)就近备着常用商品(缓存内容),你在家门口就能买到,不必千里迢迢跑总仓。

> 多义说明:CDN 既指基础设施/服务,也指其缓存与分发机制;本文综合讨论。

## 原理与机制

- **缓存与回源:** 边缘节点缓存静态内容;未命中(miss)时向源站"回源"拉取并缓存。
- **请求调度:** 通过 DNS 解析、Anycast 或 HTTP 重定向,把用户请求导向最优(最近/最闲)边缘节点。
- **缓存策略:** TTL、Cache-Control、缓存键设计、缓存刷新与预热(purge / prefetch)。
- **动态加速:** 对不可缓存内容采用路由优化、连接复用、TLS 优化等手段加速。

## 关键组成

| 组成 | 作用 |
|------|------|
| 边缘节点(POP) | 就近缓存并响应请求 |
| 源站(Origin) | 内容的权威来源 |
| 调度系统(DNS/Anycast) | 把请求导向最优节点 |
| 缓存策略 | 决定缓存什么、缓存多久 |
| 回源机制 | 未命中时向源站取数据 |

## 应用场景

- 网站、图片、视频与静态资源加速
- 大文件与软件下载分发
- 直播与流媒体
- DDoS 缓解与流量吸收

## 优点与局限

- 优点:降低延迟、节省源站带宽、提升可用性与抗压能力、就近服务全球用户。
- 局限:对动态/个性化内容加速有限;缓存一致性(过期、刷新)复杂;有成本;可能被 CDN 厂商锁定;有时会掩盖源站自身问题。

## 常见误区

- CDN 主要加速"可缓存的静态内容",动态内容需专门的动态加速方案。
- 加了 CDN 不等于源站不会被打:回源流量仍可能压垮源站。
- 缓存刷新不及时会导致用户看到过期内容。
- CDN ≠ 负载均衡:二者目标不同,但常配合使用。
