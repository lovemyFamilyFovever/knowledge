# 网络基础


> 📌 **导航**：本文是 **网络基础** 枢纽页，属于 network 术语集。各子主题已归口到专门词条，本页只做体系索引与关系。

## 定义

**一句话定义：** 网络基础是计算机互联通信的底层规则与体系，本页是它的枢纽索引——把分层模型、IP 寻址与分段、端口与 Socket、ARP / NAT / DNS、路由与诊断性能等子主题各归口到专门词条，正文只留体系与关系。

**通俗类比：** 像全球邮政系统——写信要写地址（IP）、贴门牌（端口）、走分拣中心（路由）、末端投递（链路 / 物理层）；本页是把这套体系各部件指向详情的目录。

## 为什么需要它

网络知识面广（分层 / 寻址 / 编址 / 端口 / ARP / NAT / DNS / 路由 / 诊断），且多数已拆成专条。需要一张地图把"某个基础问题属于哪块、去哪深入"串清楚，本页承担这个索引角色。

## 核心机制

- **分层模型：** OSI 七层与 TCP/IP 四层的对应、封装与解封装，见 [[OSI 参考模型]]。
- **寻址与编址：** IP 报文与寻址见 [[IP 协议]]，子网 / CIDR / VLAN 分段见 [[网络分段与编址]]。
- **端点与编程：** 端口号与 Socket 编程接口见 [[Socket与端口]]。
- **地址翻译：** IP→MAC 的 ARP 见 [[地址解析协议]]，内网共用公网 IP 的 NAT 见 [[网络地址转换]]，域名→IP 的 DNS 见 [[DNS深入解析]]。
- **选路与传输：** 跨网选路见 [[路由协议]]，端到端传输见 [[TCP深入]] 与 [[用户数据报协议]]。
- **诊断与性能：** Ping / Traceroute / MTR 与带宽 / 吞吐量 / 延迟见 [[网络诊断与性能]]。

## 具体示例

一台 PC 上网串起全链：DHCP 拿地址 → DNS 解域名 → 按子网掩码判同网、否则交网关 → 经 NAT 出公网 → 路由器按路由协议选路 → 传输层 TCP 可靠送达——每一环都有对应专条。

## 何时用与何时不用

- **用：** 作为网络基础总览与跳转入口，先按主题定位、再进专条深入。
- **不用：** 某主题的细节（子网计算、路由算法）去对应专条，本页只索引。

## 优劣与代价

✅ 把网络基础组织成一张按"通信链路"排列的体系地图，便于建立整体认知、定位问题。
⚠️ 只有索引与关系，不替代专条细则；须与子词条链接保持同步。
