# IP 协议


> 📌 **导航**：本文是 **IP 协议** 词条，属于 network 术语集。相关枢纽：[[DNS深入解析]]、[[TCP深入]]、[[网络基础]]。

## 定义

**一句话定义：** IP 协议（Internet Protocol）是 TCP/IP 网络层的核心协议，负责为主机分配逻辑地址（IP 地址）、在互联网络中对数据包进行寻址与逐跳路由转发，实现端到端的"尽力而为"数据报交付。

**通俗类比：** 像邮政系统的地址与分拣规则——每个信封（数据包）写上收件地址（IP），沿途邮局（路由器）只看地址一站站分拣转发，不保证一定送到、不保证先后顺序，也不关心里面装了什么。

> 多义说明：IP 有 IPv4 与 IPv6 两个版本；本文以 IPv4 为主并说明 IPv6 的差异。

## 为什么需要它

异构的物理网络（以太网、Wi-Fi、光纤）要互联成一张网，必须有一个统一的逻辑寻址与跨网转发层。IP 屏蔽底层链路差异，给每台主机一个全局逻辑地址、让路由器据此逐跳转发，互联网才"互联"得起来。

## 核心机制

- **分层位置：** 位于 OSI 网络层（第 3 层），上承传输层（TCP/UDP），下接数据链路层。
- **寻址：** IPv4 为 32 位（点分十进制），IPv6 为 128 位（冒号十六进制）；用子网掩码 / 前缀长度划分网络位与主机位。
- **路由：** 路由器依据路由表对每个包独立选路（逐跳），不同包可能走不同路径。
- **分片与重组：** 受链路 MTU 限制，IPv4 可途中分片，IPv6 只允许源端分片。
- **尽力而为：** 不保证送达、顺序与不重复，可靠性交由上层（如 TCP）负责。
- **首部关键字段：** 版本 / 首部长度、TTL（每过一跳减 1、防无限环路）、协议号（TCP=6、UDP=17）、源 / 目的 IP、标识 / 标志 / 片偏移（IPv4 分片）、首部校验和（仅校验 IPv4 首部）。

## 具体示例

`traceroute` 逐跳打印路径：每跳 TTL 减 1，减到 0 时该路由器回 ICMP 超时——正体现 IP 的逐跳转发 + TTL 防环；而 `ping` 用的 ICMP 报文本身仍封装在 IP 里传输。

## 何时用与何时不用

- **用：** 互联网与局域网主机间通信、路由与子网划分、NAT 地址转换、VPN / 隧道封装（IP-in-IP、IPsec）。
- **不用（职责边界）：** 要可靠有序交付需上层 TCP，别指望 IP 保证；同网段寻址用 MAC / ARP，跨网段才靠 IP 路由。

## 优劣与代价

✅ 统一逻辑寻址、可跨异构网络互联、简单可扩展，是互联网互通的基石。
⚠️ 尽力而为、不可靠；IPv4 地址耗尽（依赖 NAT 与 IPv6 缓解）；无内建安全（需 IPsec 补充）。

## 与相关概念的区别

vs TCP：IP 管"寻址 + 逐跳转发、尽力而为"，TCP 在上层补可靠、有序与流量控制；vs MAC 地址：IP 是网络层逻辑地址（可跨网段、会变），MAC 是链路层物理地址，由 ARP 建立二者映射（见 [[地址解析协议]]）。

## 常见误区

- IP 协议保证数据包可靠、按序送达。
- IP 地址和 MAC 地址是一回事。
- IPv6 就是"更快的 IP"。

## 面试速答

> 🎯 IP = 网络层"逻辑寻址 + 逐跳路由"的尽力而为数据报协议：IPv4 32 位 / IPv6 128 位，首部有 TTL（防环）、协议号（TCP=6/UDP=17）、源目的 IP、分片字段；不保证可靠有序（交给 TCP），跨异构网靠它互联。
