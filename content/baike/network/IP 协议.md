# IP 协议

## 定义

**一句话定义：** IP 协议(Internet Protocol)是 TCP/IP 网络层的核心协议,负责为主机分配逻辑地址(IP 地址)并在互联网络中对数据包进行寻址与逐跳路由转发,实现端到端的"尽力而为"数据报交付。

**通俗类比：** 像邮政系统的地址与分拣规则——每个信封(数据包)写上收件地址(IP),沿途邮局(路由器)只看地址一站站分拣转发,不保证一定送到、不保证先后顺序,也不关心里面装了什么。

> 多义说明:IP 有 **IPv4** 与 **IPv6** 两个版本;本文以 IPv4 为主并说明 IPv6 的差异。

## 原理与机制

- **分层位置:** 位于 OSI 网络层(第 3 层),上承传输层(TCP/UDP),下接数据链路层。
- **寻址:** IPv4 为 32 位(点分十进制,如 192.0.2.1),IPv6 为 128 位(冒号十六进制);用子网掩码/前缀长度划分网络位与主机位。
- **路由:** 路由器依据路由表对每个包独立选路(逐跳),不同包可能走不同路径。
- **分片与重组:** 受链路 MTU 限制,IPv4 可在途中分片;IPv6 只允许源端分片。
- **尽力而为:** 不保证送达、顺序与不重复,可靠性交由上层(如 TCP)负责。

## 关键组成

| 首部字段 | 作用 |
|----------|------|
| 版本 / 首部长度 | 标识 IPv4/IPv6 与头长 |
| TTL(跳数限制) | 每过一跳减 1,防止无限环路 |
| 协议号 | 标识上层协议(如 TCP=6、UDP=17) |
| 源 / 目的 IP 地址 | 逻辑寻址 |
| 标识 / 标志 / 片偏移 | 分片与重组(IPv4) |
| 首部校验和 | 仅校验首部(IPv4) |

## 应用场景

- 互联网与局域网中所有主机间通信
- 路由、子网划分、NAT 地址转换
- VPN、隧道封装(IP-in-IP、IPsec)

## 优点与局限

- 优点:统一寻址、可跨异构网络互联、简单可扩展,是互联网互通的基石。
- 局限:尽力而为、不可靠;IPv4 地址耗尽(依赖 NAT 与 IPv6 缓解);无内建安全(需 IPsec 补充)。

## 常见误区

- IP 只负责"寻址与路由",不负责可靠传输(那是 TCP 的职责)。
- IP 地址 ≠ MAC 地址:前者是逻辑地址(可跨网段),后者是链路层物理地址;ARP 负责二者映射。
- IPv6 并非"更快的 IP":它主要解决地址空间与配置,速度取决于链路。
