# 路由协议


> 📌 **导航**：本文是 **路由协议** 词条，属于 network 术语集。相关枢纽：[[DNS深入解析]]、[[TCP深入]]、[[网络基础]]。

## 定义

**一句话定义：** 路由协议(Routing Protocol)是路由器之间用于交换网络可达性信息、据此构建路由表并选择数据转发路径的协议;它决定了数据包如何在互联网络中从源逐跳到达目的地,是网络层的核心机制。

**通俗类比：** 像导航系统之间的路况共享——各路口(路由器)互相通报"从我这能到哪、走哪条更快"(路由信息),汇总成一张地图(路由表),从而为每辆车(数据包)规划出到达目的地的路径。

> 多义说明:路由协议(路由器间交换路由信息)≠ 被路由协议(routed protocol,如 IP,承载用户数据);分内部网关协议(IGP)与外部网关协议(EGP)。本文讨论路由协议。

## 原理与机制

- **分类:**
  - IGP(自治系统内):距离向量(RIP)、链路状态(OSPF、IS-IS)。
  - EGP(自治系统间):BGP(边界网关协议,互联网骨干)。
- **距离向量:** 每个路由器把自己知道的"到各网络的距离 + 方向"告诉邻居(基于 Bellman-Ford,如 RIP)。
- **链路状态:** 每个路由器泛洪自己的链路状态,所有路由器构建相同的拓扑图,再用 Dijkstra 算最短路径(如 OSPF)。
- **关键概念:** 度量(metric,如跳数/开销)、收敛(convergence)、路由环路防范、自治系统(AS)。

## 关键组成

| 组成 | 说明 |
|------|------|
| IGP / EGP | 自治系统内 / 间 |
| 距离向量 / 链路状态 | 两大算法族 |
| 度量(metric) | 路径优劣的衡量 |
| 路由表 | 转发决策依据 |
| 收敛 | 拓扑变化后达成一致 |

## 应用场景

- 企业/数据中心内网(OSPF、IS-IS)
- 互联网骨干(BGP)
- 家用路由(RIP / 静态路由)
- SD-WAN

## 优点与局限

- 优点:自动学习并适应拓扑变化、可扩展、无需手工维护全部路由。
- 局限:收敛期间可能出现环路/黑洞;协议开销(泛洪/更新);配置复杂;BGP 依赖信任(存在路由劫持风险)。

## 常见误区

- 路由协议 ≠ IP:IP 是被路由协议(承载数据),路由协议(如 OSPF/BGP)交换路由信息。
- 距离向量与链路状态机制不同(RIP vs OSPF)。
- BGP 是路径向量协议,用于 AS 间(含策略路由)。
- 静态路由不是路由协议(由人工配置)。
