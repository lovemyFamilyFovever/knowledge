# 路由协议


> 📌 **导航**：本文是 **路由协议** 词条，属于 network 术语集。相关枢纽：[[DNS深入解析]]、[[TCP深入]]、[[网络基础]]。

## 定义

**一句话定义：** 路由协议（Routing Protocol）是路由器之间用于交换网络可达性信息、据此构建路由表并选择数据转发路径的协议；它决定数据包如何在互联网络中从源逐跳到达目的地，是网络层的核心机制。

**通俗类比：** 像导航系统之间的路况共享——各路口（路由器）互相通报"从我这能到哪、走哪条更快"，汇总成一张地图（路由表），从而为每辆车（数据包）规划出到达目的地的路径。

> 多义说明：路由协议（路由器间交换路由信息）≠ 被路由协议（routed protocol，如 IP，承载用户数据）；分内部网关协议（IGP）与外部网关协议（EGP）。本文讨论路由协议。

## 为什么需要它

网络拓扑不断变化（链路故障、新增网段），靠人工维护每台路由器的路由表既不现实也跟不上。路由协议让路由器自动交换可达性、动态算出到各目的地的路径并随拓扑收敛，支撑起可扩展的互联网路由。

## 核心机制

- **IGP（自治系统内）：** 距离向量（RIP，基于 Bellman-Ford，向邻居报"到各网段的距离 + 方向"）与链路状态（OSPF、IS-IS，各路由器泛洪链路状态、共建拓扑图后用 Dijkstra 算最短路径）。
- **EGP（自治系统间）：** BGP（边界网关协议，路径向量、含策略路由，是互联网骨干）。
- **关键概念：** 度量 metric（跳数 / 开销）、收敛 convergence、路由环路防范、自治系统 AS。

## 具体示例

RIP 以跳数做 metric、15 跳即不可达，靠周期整表更新、收敛慢且易环路；OSPF 让区域内路由器泛洪 LSA、各自跑 Dijkstra 算最短路径树，收敛快且无环路；跨运营商则靠 BGP 按 AS 路径与策略选路。

## 何时用与何时不用

- **用：** 企业 / 数据中心内网（OSPF、IS-IS）、互联网骨干（BGP）、小规模可 RIP / 静态路由、SD-WAN。
- **不用：** 极小且稳定的网络用静态路由即可（人工、无协议开销）；BGP 依赖信任模型，公网路由劫持要靠 RPKI 等机制加固。

## 优劣与代价

✅ 自动学习并适应拓扑变化、可扩展、无需手工维护全部路由。
⚠️ 收敛期间可能出现环路 / 黑洞；泛洪 / 更新有协议开销；配置复杂；BGP 依赖信任、存在路由劫持风险。

## 与相关概念的区别

vs IP：IP 是"被路由协议"承载用户数据，路由协议（OSPF / BGP）交换的是"怎么走"的控制信息；vs 静态路由：静态路由由人工写死、不是协议；vs [[最短路径算法]]：Dijkstra 是 OSPF 内部算路所用的算法，路由协议是其上的工程系统。

## 常见误区

- 路由协议就是 IP 协议。
- 静态路由也算一种路由协议。
- OSPF 和 RIP 用的是同一类算法。

## 面试速答

> 🎯 路由协议 = 路由器间交换可达性、建路由表选转发路径：IGP 分距离向量（RIP/Bellman-Ford）与链路状态（OSPF/IS-IS，泛洪+Dijkstra）、EGP 是 BGP（路径向量+策略、互联网骨干）；关键在 metric / 收敛 / 防环，区别于承载数据的 IP 协议与人工静态路由。
