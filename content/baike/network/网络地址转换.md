# 网络地址转换


> 📌 **导航**：本文是 **网络地址转换** 词条，属于 network 术语集。相关枢纽：[[DNS深入解析]]、[[TCP深入]]、[[网络基础]]。

## 定义

**一句话定义：** 网络地址转换（Network Address Translation，NAT）是在数据包经过路由器 / 网关时改写其源 / 目的 IP 地址（及端口）的技术，主要用于让多个使用私有地址的主机共享少量公网 IP 访问互联网、缓解 IPv4 地址耗尽。

**通俗类比：** 像公司总机转接——所有员工用内部分机号（私有 IP），对外打出的电话都显示为公司总机号码（公网 IP）；回电先到总机，再由它按记录转给对应分机。

> 多义说明：NAT 有静态 NAT、动态 NAT 与 NAPT/PAT（端口复用，最常见，又称"IP 伪装"）；本文以 NAPT 为主。

## 为什么需要它

IPv4 公网地址早已耗尽，而内网设备数远超可用公网 IP。NAT 让成百上千台内网主机用一个公网 IP 加不同端口对外通信，把"全球唯一地址"的压力收进私网，是 IPv4 世界能撑到今天的关键机制之一。

## 核心机制

- **私有地址：** RFC 1918 规定的 10/8、172.16/12、192.168/16 不能在公网路由，NAT 在网络边界做地址转换。
- **NAPT：** 用"IP + 端口"映射，把多个内网主机的连接复用到一个公网 IP 的不同端口，并维护 NAT 转换表。
- **转换过程：** 出站时改写源地址 / 端口并记录映射；入站回包按表反向改写目的地址 / 端口送回内网主机。
- **端到端副作用：** 破坏端到端原则，使内网主机难以被外部主动连接，需端口转发或 NAT 穿透（STUN / TURN / ICE）。

## 具体示例

家里手机上网：内网 192.168.1.5:52000 访问服务器，路由器改写成公网 IP:3001 并记一条转换表；服务器回包到公网 IP:3001，路由器查表还原为 192.168.1.5:52000 再投递——对外只见一个公网 IP，全家设备共享。

## 何时用与何时不用

- **用：** 家庭 / 企业路由器共享上网、缓解 IPv4 地址耗尽、隐藏内网拓扑、云环境的 SNAT / DNAT。
- **不用 / 注意：** 需要被公网主动访问的服务应配公网 IP 或端口转发 / 穿透，别指望裸 NAT；追求端到端或使用 IPv6 时不必依赖 NAT。

## 优劣与代价

✅ 节省公网 IP、地址复用、一定程度隐藏内网结构。
⚠️ 破坏端到端连通性（P2P、入站连接需额外技术）；增加路由器状态与处理开销；FTP / SIP 等协议需 ALG 适配；并非真正的安全防火墙。

## 与相关概念的区别

vs [[地址解析协议]]：ARP 做 IP↔同网段 MAC 映射，NAT 改写 IP / 端口以跨越公私网边界，层次与目的不同；vs 防火墙：NAT 本质是地址转换、隐藏内网只是副作用，访问控制与安全过滤才是防火墙职责。

## 常见误区

- NAT 就是一种防火墙、能起安全防护作用。
- IPv6 时代仍需靠 NAT 解决地址不足。
- NAPT 靠 IP 地址区分不同内网主机的连接。

## 面试速答

> 🎯 NAT = 在边界改写包源 / 目的 IP（及端口），让多内网主机（RFC 1918 私有地址）共享公网 IP、缓解 IPv4 耗尽；NAPT 用"IP+端口"复用并维护转换表，破坏端到端原则（入站要端口转发 / STUN/TURN 穿透），且不是防火墙。
