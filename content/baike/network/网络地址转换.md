# 网络地址转换


> 📌 **导航**：本文是 **网络地址转换** 词条，属于 network 术语集。相关枢纽：[[DNS深入解析]]、[[TCP深入]]、[[网络基础]]。

## 定义

**一句话定义：** 网络地址转换(Network Address Translation, NAT)是在数据包经过路由器/网关时改写其源/目的 IP 地址(及端口)的技术,主要用于让多个使用私有地址的主机共享少量公网 IP 访问互联网,并缓解 IPv4 地址耗尽。

**通俗类比：** 像公司总机转接——所有员工用内部分机号(私有 IP),对外打出的电话都显示为公司总机号码(公网 IP);回电先到总机,再由它按记录转给对应分机。

> 多义说明:NAT 有静态 NAT、动态 NAT 与 NAPT/PAT(端口复用,最常见,又称"IP 伪装");本文以 NAPT 为主。

## 原理与机制

- **私有地址:** RFC 1918 规定的 10/8、172.16/12、192.168/16 不能在公网路由,NAT 在网络边界做地址转换。
- **NAPT:** 用"IP + 端口"映射,把多个内网主机的连接复用到一个公网 IP 的不同端口,并维护 NAT 转换表。
- **转换过程:** 出站时改写源地址/端口并记录映射;入站回包按表反向改写目的地址/端口。
- **影响:** NAT 破坏了端到端原则,使内网主机难以被外部主动连接(需端口转发或 NAT 穿透,如 STUN/TURN/ICE)。

## 关键组成

| 组成 | 作用 |
|------|------|
| 私有 / 公网地址 | 转换的两端 |
| NAT 转换表 | 记录地址/端口映射 |
| NAPT(端口复用) | 一个公网 IP 服务多主机 |
| 静态 / 动态 NAT | 固定或临时地址映射 |
| 端口转发 | 允许外部主动访问内网服务 |

## 应用场景

- 家庭/企业路由器共享上网
- 缓解 IPv4 地址耗尽
- 隐藏内网拓扑(一定的隔离作用)
- 云环境的 SNAT / DNAT

## 优点与局限

- 优点:节省公网 IP、复用地址、一定程度隐藏内网结构。
- 局限:破坏端到端连通性(P2P、入站连接需额外技术);增加路由器状态与处理开销;部分协议(FTP、SIP 等)需 ALG 适配;并非真正的安全防火墙。

## 常见误区

- NAT ≠ 防火墙:它主要做地址转换,隐藏内网只是副作用,不等于安全防护。
- IPv6 地址充足,不依赖 NAT 来解决地址耗尽(但可能用其他机制)。
- NAPT 靠端口区分连接,一个公网 IP 可服务大量内网主机,但受端口数量上限约束。
