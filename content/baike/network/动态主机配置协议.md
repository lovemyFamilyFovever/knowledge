# 动态主机配置协议


> 📌 **导航**：本文是 **动态主机配置协议** 词条，属于 network 术语集。相关枢纽：[[DNS深入解析]]、[[TCP深入]]、[[网络基础]]。

## 定义

**一句话定义：** 动态主机配置协议(Dynamic Host Configuration Protocol, DHCP)是一种网络协议,用于让主机接入网络时自动从 DHCP 服务器获取 IP 地址、子网掩码、默认网关、DNS 服务器等配置,免去手工设置。

**通俗类比：** 像酒店入住时前台自动分配房间号(IP)、告知早餐时间(DNS)与安全出口(网关)——你不必自己找空房、记一堆规则;前台(DHCP 服务器)统一分派,退房后房间还能给别人(地址回收)。

> 多义说明:DHCP 是 BOOTP 的后继,基于 UDP(服务器 67、客户端 68 端口)。本文讨论 IPv4 DHCP 并提及 DHCPv6。

## 原理与机制

- **DORA 四步:** Discover(客户端广播寻找服务器)→ Offer(服务器提供可用 IP 等)→ Request(客户端请求选用某个 offer)→ Acknowledge(服务器确认分配,含租约时长)。
- **租约(lease):** IP 分配有期限,到期需续租(通常在过半时续);租约到期后地址回收再分配。
- **广播与中继:** 初始为广播;跨网段通过 DHCP Relay(中继)转发到服务器。

## 关键组成

| 组成 | 作用 |
|------|------|
| DHCP 服务器 / 客户端 | 分配方与请求方 |
| DORA 过程 | 四步分配流程 |
| 租约(lease) | 地址的有效期限 |
| 地址池 | 可分配的地址范围 |
| DHCP 中继 | 跨网段转发请求 |
| 选项 | 网关、DNS 等附加配置 |

## 应用场景

- 家庭/企业网络自动分配 IP
- 大型网络的地址集中管理
- 临时设备接入
- 配合 DNS 动态更新

## 优点与局限

- 优点:自动配置、减少手工错误、地址可复用(租约)、便于集中管理。
- 局限:依赖 DHCP 服务器(故障则无法获取地址);存在 DHCP 欺骗/地址耗尽攻击风险;租约管理不当会导致地址不足。

## 常见误区

- DHCP 分配的是"租约"(临时),并非永久 IP(需固定 IP 应用静态绑定/保留)。
- DHCP 以广播起步,跨网段需中继。
- DHCP 欺骗(伪造服务器分配错误网关)是常见攻击,可用 DHCP Snooping 防护。
- IPv6 可用 DHCPv6,也可用 SLAAC(无状态地址自动配置)。
