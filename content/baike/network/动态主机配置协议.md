# 动态主机配置协议


> 📌 **导航**：本文是 **动态主机配置协议** 词条，属于 network 术语集。相关枢纽：[[DNS深入解析]]、[[TCP深入]]、[[网络基础]]。

## 定义

**一句话定义：** 动态主机配置协议（Dynamic Host Configuration Protocol，DHCP）是一种网络协议，用于让主机接入网络时自动从 DHCP 服务器获取 IP 地址、子网掩码、默认网关、DNS 服务器等配置，免去手工设置。

**通俗类比：** 像酒店入住时前台自动分配房间号（IP）、告知早餐时间（DNS）与安全出口（网关）——你不必自己找空房、记一堆规则；前台统一分派，退房后房间还能给别人（地址回收）。

> 多义说明：DHCP 是 BOOTP 的后继，基于 UDP（服务器 67、客户端 68 端口）。本文讨论 IPv4 DHCP 并提及 DHCPv6。

## 为什么需要它

手工给每台设备配 IP、掩码、网关、DNS 既繁琐又易冲突，移动 / 临时设备更是频繁变化。DHCP 让地址从一个地址池按需、临时地分租给接入设备并自动回收复用，把网络配置变成开箱即用。

## 核心机制

- **DORA 四步：** Discover（客户端广播寻找服务器）→ Offer（服务器提供可用 IP 等）→ Request（客户端请求选用某个 Offer）→ Acknowledge（服务器确认分配、含租约时长）。
- **租约（lease）：** IP 分配有期限，通常在过半时续租；到期不续则地址回收再分配。
- **广播与中继：** 初始 Discover 是广播（限本二层网段），跨网段需 DHCP Relay（中继）转发到服务器。
- **选项：** 除地址外还下发网关、DNS、域名等配置选项。

## 具体示例

连上 Wi-Fi 即获地址：手机广播 Discover，路由器 / DHCP 服务器 Offer 一个 IP 与租约（如 24h），手机 Request、服务器 Ack；过半天自动续租；设备离开后租约到期，该 IP 回到地址池供下一台设备使用。

## 何时用与何时不用

- **用：** 家庭 / 企业网络自动分配 IP、大型网络地址集中管理、临时设备接入、配合 DDNS 动态更新。
- **不用 / 注意：** 服务器、打印机、网关等需固定地址的设备应用静态绑定 / DHCP 保留，别依赖会变的动态租约。

## 优劣与代价

✅ 自动配置、减少手工错误、地址可复用（租约机制）、便于集中管理。
⚠️ 依赖 DHCP 服务器（故障则无法获取地址）；存在 DHCP 欺骗 / 地址耗尽攻击风险；租约管理不当会导致地址不足。

## 与相关概念的区别

vs [[地址解析协议]]：DHCP 解决"主机初始怎么拿到 IP"，ARP 解决"已知 IP 如何找同网段的 MAC"；vs 静态 IP：DHCP 给临时租约、可复用，静态绑定才固定；IPv6 还可用 SLAAC 无状态自动配置、不一定经 DHCPv6。

## 常见误区

- DHCP 分配的是永久 IP，而不是租约。
- DHCP 不靠中继就能给跨网段的子网分配地址。
- DHCP 环境不存在欺骗风险。

## 面试速答

> 🎯 DHCP = 接入即自动拿 IP/掩码/网关/DNS：基于 UDP(67/68)、DORA 四步（Discover/Offer/Request/Ack），分的是有期限的租约（过半续租、到期回收），初始广播、跨网段要 DHCP Relay；固定设备用静态绑定。
