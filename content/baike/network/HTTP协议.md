# HTTP协议


> 📌 **导航**：本文是 **HTTP协议** 枢纽页，属于 network 术语集。各子主题已拆到专门词条，本页只做全景索引与关系。安全加密见 [[HTTPS 与 TLS]]，长连接双向见 [[WebSocket]]，缓存分发见 [[内容分发网络]]，传输层见 [[TCP深入]]。

## 定义

**一句话定义：** HTTP（超文本传输协议）是客户端与服务器之间的"语言规则"，规定了请求与响应的格式、方法与状态；本页是它的枢纽索引，把方法、状态码、头部、缓存、会话、版本演进等子主题各自归口到专门词条，正文只留全景与关系。

**通俗类比：** 像餐厅点餐：你（客户端）递出请求、服务员（服务器）端回响应，HTTP 就是那套标准的"菜单 + 餐具"格式，规定了怎么写请求、怎么返回响应。

## 为什么需要它

HTTP 是 Web 与几乎所有 API 的地基，但知识面很宽（方法、状态码、头部、缓存、会话、1.1→2→3 演进）。把这些拆成专条后，需要一张索引讲清"某个点属于哪块、去哪深入"，本页就是这张地图。

## 核心机制

- **请求方法：** 决定对资源"做何种操作"并带幂等 / 安全语义——GET 读、POST 建、PUT 全量替换、PATCH 部分更新、DELETE 删、OPTIONS 供 CORS 预检，详见 [[HTTP请求方法]]。
- **状态码：** 三位数按 1xx–5xx 分类回复结果，200/201/301/304/400/401/403/404/429/500/502/503 各有契约含义，详见 [[HTTP 状态码]]。
- **头部与内容协商：** 以 key-value 承载认证、缓存、编码等元信息，Content-Type 声明 body 格式、Accept 表达期望，详见 [[HTTP头部与内容协商]]。
- **会话保持：** HTTP 无状态，Cookie（客户端）+ Session（服务端）或 JWT 用 session_id 关联以维持登录态，详见 [[Cookie与Session]]。
- **缓存、加密与长连接：** HTTP 缓存（Cache-Control / ETag / 304）见 [[缓存策略]]，加密传输见 [[HTTPS 与 TLS]]，全双工长连接见 [[WebSocket]]，传输层队头阻塞的根治见 [[QUIC]]。

三版演进是理解现代 HTTP 的关键：

| 特性 | HTTP/1.1 | HTTP/2 | HTTP/3 |
|---|---|---|---|
| 传输层 | TCP | TCP | QUIC（UDP） |
| 多路复用 | 否（靠多连接） | 是（单连接，TCP 层仍有队头阻塞） | 是（无队头阻塞） |
| 头部压缩 | 无 | HPACK | QPACK |
| 建连开销 | TCP+TLS 2–3 RTT | 连接复用 | 1-RTT / 0-RTT、可迁移 |

HTTP/1.1 用 keep-alive 复用 TCP、避免逐请求重握手；响应定长用 Content-Length、流式用 chunked；HTTP/2 用单连接多路复用解决应用层串行；HTTP/3 落到 QUIC 才彻底消除 TCP 层队头阻塞。

## 具体示例

一次带登录态的下单：`POST /orders` 带 `Authorization: Bearer <jwt>` 与 `Content-Type: application/json`，服务端验签认人（[[Cookie与Session]]）、创建资源回 201 + Location（[[HTTP 状态码]]）；重复点击因 POST 非幂等，须靠 [[幂等性]] 令牌去重。

## 何时用与何时不用

- **用：** 作为 HTTP 全景入口，先定位问题属于方法 / 状态码 / 头部 / 缓存 / 会话 / 版本哪一块，再跳专条深入。
- **不用：** 需要某个子主题的完整规则（如全部状态码、全部缓存指令）时——本页只做索引，细则在专条。

## 优劣与代价

✅ 把 HTTP 庞杂知识面组织成一张按请求生命周期排列的地图，便于建立整体认知、避免重复维护。
⚠️ 只有指针与全景，不替代专条的字段级细节；须与子词条链接保持同步。

## 与相关概念的区别

vs 各专条（[[HTTP请求方法]]、[[HTTP 状态码]]、[[Cookie与Session]] 等）：本页是横向索引、它们是纵向细则；vs [[应用层协议]]：那篇横向铺开 DNS/HTTP/SMTP 等多协议，本张专讲 HTTP 一家。

## 常见误区

- 把本页当成方法 / 状态码 / 头部等主题的完整规则来复习。
- 认为 HTTP/2 之后就没有队头阻塞了（应用层没了，TCP 层仍有，要到 HTTP/3/QUIC 才根治）。
