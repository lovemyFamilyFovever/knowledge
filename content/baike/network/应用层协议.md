# 应用层协议


> 📌 **导航**：本文是 **应用层协议** 枢纽页，属于 network 术语集。各协议已归口到专门词条或新立族词条，本页只做索引与端口速查。

## 定义

**一句话定义：** 应用层协议是各类网络应用（网页、邮件、文件传输、远程登录、时间同步、网络管理等）各自专用的"沟通语言"与端口约定；本页是它们的枢纽索引——把 DNS/HTTP 等已立专条的指向之、把邮件/文件传输/SSH 等家族指向新立族词条，并附一张端口速查表。

**通俗类比：** 像不同行业的专用表格——医院病历、银行转账单、学校成绩单，每种业务有自己标准化的格式与"窗口号码"（端口）。

## 为什么需要它

应用层协议数量多、端口杂，且很多（DNS/HTTP/DHCP/HTTPS）已各有专条。需要一张地图说清"某个应用协议是什么、去哪深入、默认端口多少"，本页承担索引 + 端口速查的角色。

## 核心机制

- **解析与接入：** DNS 把域名解析成 IP，见 [[DNS深入解析]]；DHCP 自动分配 IP / 网关 / DNS，见 [[动态主机配置协议]]。
- **Web 与传输：** HTTP / HTTPS 见 [[HTTP协议]] 与 [[HTTPS 与 TLS]]，其下可靠传输见 [[TCP深入]]。
- **邮件：** SMTP 发送、POP3 / IMAP 收取，见 [[邮件协议族]]。
- **文件传输：** FTP 主动 / 被动、SFTP / SCP / FTPS，见 [[文件传输协议]]。
- **远程登录：** SSH（密钥 / 端口转发）取代明文 Telnet，见 [[SSH与远程登录]]。
- **运维类：** NTP(123) 统一时钟、SNMP(161/162) 设备监控、LDAP(389/636) 目录与单点登录，多为专场景协议，按需查对应 RFC 与厂商文档。

端口速查（含加密 / 安全版本）：

| 协议 | 明文端口 | 加密 / 安全版本 |
|---|---|---|
| DNS | 53 | DoH 443 |
| DHCP | 67 / 68 | — |
| FTP | 21 / 20 | SFTP 22、FTPS 990 |
| SSH | 22 | —（Telnet 23 应弃用） |
| SMTP | 25 | 465 / 587 |
| POP3 / IMAP | 110 / 143 | 995 / 993 |
| HTTP | 80 | HTTPS 443 |
| LDAP | 389 | LDAPS 636 |

## 具体示例

排"连不上某服务"常从端口与协议入手：SSH 22、Web 443、DB 3306，对照本表确认服务与端口匹配、是否该走加密版本；配邮件客户端用 587 + IMAP 而非 25 + POP3。

## 何时用与何时不用

- **用：** 作为应用层协议总览与端口速查入口，按业务跳到对应专条。
- **不用：** 要某协议的报文 / RFC 细节时去其专条或本表引用的 RFC，本页不展开。

## 优劣与代价

✅ 一页看清"业务 ↔ 协议 ↔ 端口 ↔ 加密版本"，是排障与选型的速查地图。
⚠️ 只有索引与端口、不替代专条；端口有惯例默认值也可被部署改值，勿死记。

## 与相关概念的区别

vs [[TCP深入]] / [[用户数据报协议]]：传输层管端到端的可靠 / 快速通道，本页各协议是跑在其上的应用语义；vs [[网络基础]]：那是分层与体系总览，本页专列应用层协议族与端口。

## 常见误区

- 把本页当成某个协议（如 DNS、HTTP）的完整讲解来复习。
- 认为端口号是硬编码、服务只能监听默认端口。
