# JavaScript 基础核心概念


> 📌 **导航**：本文是 **JavaScript 基础核心概念** 词条，属于 frontend-concepts 术语集。相关枢纽：[[HTML & CSS 核心概念]]、[[JavaScript 基础核心概念]]、[[React深入]]、[[Vue3核心]]、[[前端工程化核心概念]]。

## 定义

**一句话定义：** JavaScript 语言的运行时核心概念总览：声明与作用域决定变量怎么绑、怎么找，原型链决定对象怎么复用，事件循环决定异步什么时候跑，模块决定代码怎么互相引用，现代语法糖决定这些写法有多啰嗦——本页是按问题类型归口的枢纽页，机制细节由各子词条承载。

**通俗类比：** 像一间公司的接待台：人事（作用域与 this）、资产归属（原型链）、排班调度（异步）、部门边界（模块化）、办公小工具（语法糖）各有各自的办公室，本页只告诉你该推哪扇门。

## 为什么需要它

原汇编 15 节逐条平铺，同一个机制会在"闭包""作用域链""this"三处各写一遍，改一处就漂移。拆成六个族子词条后，本页只留"现象 → 归口"的选型表与判据，让一个问题只有一个权威答案，闭包这类库内已有专条的概念直接双链不重复承载。

## 核心机制

结构、查找、调度、边界四条轴各有归口；下表负责"有什么"，下面五条只讲"为什么这样归口"：

| 现象 / 面试问法 | 归口 | 关键抓手 | 详见 |
|---|---|---|---|
| for 循环里 var 闭包拿到最后一个值 | 声明方式与作用域 | let 块级 + 暂时性死区 | [[JavaScript 作用域与 this]] |
| 回调里 this 变成 window / undefined | 绑定规则 | 默认/隐式/显式/new 四条 + 箭头函数 | [[JavaScript 作用域与 this]] |
| 函数带走外部变量、私有状态 | 闭包 | 词法环境实例 | [[闭包]] |
| 属性哪来的、class 与 extends 本质 | 原型链 | 读沿链向上、写落自身遮蔽 | [[JavaScript 原型链与继承]] |
| `setTimeout(fn,0)` 与 `Promise.then` 谁先 | 事件循环 | 微任务整队清空后才取一个宏任务 | [[JavaScript 异步编程（事件循环·Promise·async·await·Generator）]] |
| 并发请求怎么等齐、一个失败怎么办 | Promise 组合子 | all / race / allSettled 分工 | [[JavaScript 异步编程（事件循环·Promise·async·await·Generator）]] |
| await 写成瀑布导致总耗时叠加 | async 编排 | 先发起再 Promise.all | [[JavaScript 异步编程（事件循环·Promise·async·await·Generator）]] |
| 惰性序列、可暂停函数 | Generator | yield 交出 `{ value, done }` | [[JavaScript 异步编程（事件循环·Promise·async·await·Generator）]] |
| require 与 import 有何不同 | 模块系统 | 同步值拷贝 vs 静态活绑定 | [[JavaScript 模块化（CommonJS·ES Modules·AMD）]] |
| 接口数据一层层判空、给默认值 | 语法糖 | `?.` 与 `??` 配合 | [[JavaScript 现代语法糖（解构·展开·可选链·空值合并）]] |
| 给 DOM 节点挂状态怕泄漏 | 引用强度 | WeakMap 键弱引用、不可枚举 | [[JavaScript 弱引用（WeakMap 与 WeakRef）]] |

1. **变量的可见性与上下文是两件事**：作用域链按词法位置静态决定变量怎么找，this 按调用方式动态决定，混谈就解释不了"闭包能拿到外部变量却拿不到外层 this"——机制在 [[JavaScript 作用域与 this]]，闭包本体在 [[闭包]]。
2. **两条链不要互相解释**：属性沿原型链向上（对象维度、可动态改），变量沿作用域链向外（函数维度、书写即定），能同时说清这两条链，`class` 与 `this` 的追问就不慌，分别见 [[JavaScript 原型链与继承]] 与 [[JavaScript 作用域与 this]]。
3. **异步的一切顺序都由"微任务整队清空"这一条推出**：宏任务每轮只取一个，所以输出顺序题、await 串成瀑布、递归微任务饿死渲染都是同一个因果，别再背四份结论——统一收在 [[JavaScript 异步编程（事件循环·Promise·async·await·Generator）]]，协程的一般模型见 [[协程]]。
4. **模块与工程化分属两层**：`require`/`import` 的语义差别属于语言，tree-shaking 与打包器怎么消费它属于工具链，前者见 [[JavaScript 模块化（CommonJS·ES Modules·AMD）]]，后者归 [[前端工程化]] 与 [[前端工程化核心概念]]。
5. **判空、拷贝、取值是三个正交小语法**：单独立条都不到 300 字，合成一族后既能讲清 `??` 与 `||` 的分界，也能讲清"展开只浅拷贝"的代价，见 [[JavaScript 现代语法糖（解构·展开·可选链·空值合并）]]；同族的引用强度问题（WeakMap/WeakRef）另成一条挂到 [[JavaScript 弱引用（WeakMap 与 WeakRef）]]，因为它管的是回收而不是写法。

## 具体示例

一次典型排查：接口返回的嵌套字段直接 `data.list[0].name` 抛错 → 语法糖族给出 `data?.list?.[0]?.name ?? "匿名"`；修完发现异步请求被 await 串成瀑布 → 异步族改成先并发再 Promise.all；页面切走后缓存仍持有 DOM → 弱引用族把 Map 换成 WeakMap。三条链各归其位，互不越界。

## 何时用与何时不用

- **用**：遇到 JS 语言层现象先在上表按"现象"定位归口，再进子词条看机制；面试体系化复习也从本页出发串六族。
- **不用**：当教程用——本页一律没有属性级细节与完整示例；也别把它当互斥菜单，真实 bug 常是两族叠加（闭包 + 事件循环最常见）。

## 与相关概念的区别

- **vs [[HTML & CSS 核心概念]]**：那条管结构与表现层，本族管行为层；交汇点是 JS 运行时改 CSS 变量。
- **vs [[前端工程化核心概念]]**：工程化管"怎么构建与交付"，本族管"语言本身怎么运行"。
- **vs [[编程语言通用概念]]**：那条给跨语言的作用域/函数/类型定义，本族是 JS 的落地规则与坑。

## 常见误区

- 指望在枢纽页读到一个 JS 概念的完整机制与可运行示例，不往子词条跳。
- 把 var/let/const 的差异当成"const 不可修改"，以为它锁的是值而不是绑定。
- 把连续写三个 await 当成并发执行，据此解释接口耗时为什么是三者之和。
