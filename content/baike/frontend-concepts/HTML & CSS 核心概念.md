# HTML & CSS 核心概念


> 📌 **导航**：本文是 **HTML & CSS 核心概念** 词条，属于 frontend-concepts 术语集。相关枢纽：[[HTML & CSS 核心概念]]、[[JavaScript 基础核心概念]]、[[React深入]]、[[Vue3核心]]、[[前端工程化核心概念]]。

## 定义

**一句话定义：** HTML 结构与 CSS 表现两层核心概念的总览：HTML 用自带语义的标签定义页面骨架，CSS 用选择器与层叠、布局、盒子、动效控制呈现——本页是按问题类型归口的枢纽页，机制细节由各子词条承载。

**通俗类比：** 像装修：HTML 是户型图（有哪些房间、各是什么用途），CSS 是设计图（墙怎么砌、灯怎么布、家具按什么顺序叠放）；本页是装修接待台，想看某项工艺都有各自的说明书。

## 为什么需要它

前端样式问题类型有限：为什么被盖住、为什么错行、为什么不生效、为什么尺寸不对、为什么掉帧。原汇编 12 节逐条平铺必然重复漂移，拆成五个族子词条后，本页只留"问题 → 归口"的选型表与判据，让一个问题只有一个权威答案。

## 核心机制

结构、排布、尺寸与层级、规则与能力四条轴各有归口；下表负责"有什么"，下面五条只讲"为什么这样选"：

| 问题信号 | 方案 | 关键抓手 | 详见 |
|---|---|---|---|
| 组件内单行排列、居中、等分 | Flexbox（一维） | 主轴 justify-content、交叉轴 align-items、子项 flex:1 | [[CSS 布局（Flexbox 与 Grid）]] |
| 页面骨架、仪表盘、圣杯布局 | Grid（二维） | grid-template 定轨道、grid-column: 1 / -1 跨列 | [[CSS 布局（Flexbox 与 Grid）]] |
| 手机/平板/桌面都正常显示 | 媒体查询 + 移动优先 | min-width 渐进增强、流式单位 | [[响应式设计]] |
| 尺寸心算对不上 | box-sizing: border-box | width 含 padding 与 border | [[CSS 盒模型与 BFC 与层叠上下文]] |
| 父元素高度塌陷、margin 穿透 | 触发 BFC | display: flow-root（推荐）/ overflow: hidden | [[CSS 盒模型与 BFC 与层叠上下文]] |
| z-index 9999 仍被遮住 | 层叠上下文 | 定位 + z-index 封顶在父级组内 | [[CSS 盒模型与 BFC 与层叠上下文]] |
| 哪条规则最终生效 | 特异性 + 源码顺序 | （ID,类,标签）三元组比较 | [[CSS 选择器与伪类伪元素]] |
| 主题切换、动效掉帧 | CSS 变量 + transform 动画 | var() 运行时生效；合成层直上 | [[CSS 变量与动画]] |
| 页面结构说不清 | 语义化标签 | header/nav/main/article/aside/footer | [[HTML 语义化]] |

1. **布局先问维度**：Flexbox 只管一行或一列，Grid 同时管行与列；骨架用 Grid、组件内部用 Flex，组合而非二选一——维度是方案选型的唯一判据，属性与陷阱见 [[CSS 布局（Flexbox 与 Grid）]]。
2. **三类"布局诡异"对应三种机制**：尺寸算错是 box-sizing 的事，塌陷是 BFC 的事，盖住是层叠上下文的事，全在 [[CSS 盒模型与 BFC 与层叠上下文]]；靠 !important 与加大 z-index 盲 hack 替代不了因果推导。
3. **选择器规则是一切样式调试的前提**：不生效时先算（ID,类,标签）三元组、再看源码顺序、最后确认没被层叠上下文压制——前两步在 [[CSS 选择器与伪类伪元素]]，伪类伪元素同条承载，不单立薄条。
4. **变量与动画是 CSS 近十年补上的运行时能力**：var() 运行时生效、可被 JS 改，这是与 Sass 编译期变量的本质分界；动效优先 transform/opacity 因为直达合成层，机理见 [[CSS 变量与动画]] 与 [[CSS渲染性能]]。
5. **HTML 的职责是结构不是样式**：语义标签是搜索引擎与屏幕阅读器读懂页面的前提，标签清单与 div 分界见 [[HTML 语义化]]，其无障碍用法与 ARIA 归口 [[无障碍访问]]，本页不重复。

## 具体示例

走查一个电商商品页：页面骨架 Grid 两列、页眉行 grid-column 横跨；卡片内标题、价格、按钮用 Flex space-between 排布；盒模型全局 border-box 让卡片 width 即占位宽；hover 上浮用 transform 不用 top；主题色与圆角全走 var()，暗色切换只重定义 :root；结构由 header/nav/main/footer 兜底，读屏可直接跳到商品主体。

## 何时用与何时不用

- **用**：定位样式问题时先用上表归口到族，再跳子词条看机制；面试体系化复习也从本页出发串族。
- **不用**：当互斥菜单用——布局、盒子、选择器正交，同一个 bug 常叠加出现；实现细节本页一律没有，都在子词条。

## 与相关概念的区别

- **vs [[响应式设计]]**：那条承载多端策略、断点与移动优先的完整机制，本页只登记其在布局体系的位置。
- **vs [[前端工程化核心概念]]**：工程化管"怎么构建与管理"，本族管"浏览器怎么渲染"。
- **vs [[JavaScript 基础核心概念]]**：JS 改结构与行为，CSS 改表现；交汇点是运行时改 CSS 变量。
