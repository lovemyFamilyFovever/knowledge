# 前端工程化

## 构建工具对比

| 工具 | 特点 | 适用 |
|------|------|------|
| Webpack | 功能全面 | 大型项目 |
| Vite | 极快启动 | 新项目首选 |
| esbuild | 极速编译 | 底层工具 |
| Turbopack | Rust实现 | Next.js |

## Monorepo

```
project/
├── packages/
│   ├── shared/       # 共享代码
│   ├── web/          # Web端
│   ├── mobile/       # 移动端
│   └── admin/        # 管理端
├── package.json
└── pnpm-workspace.yaml
```

工具：pnpm workspace, Turborepo, Nx

## 微前端

| 方案 | 原理 | 代表 |
|------|------|------|
| iframe | 原生隔离 | 简单但体验差 |
| qiankun | JS沙箱+CSS隔离 | single-spa封装 |
| Module Federation | 模块共享 | Webpack5 |
| Web Components | 原生组件 | 无框架依赖 |
