## 1. `server/main.ts` —— 飞书侧真实 bootstrap（与本地对齐确认）

```ts
import { NestFactory } from '@nestjs/core';
import { Logger } from '@nestjs/common';
import { join } from 'path';
import { __express as hbsExpressEngine } from 'hbs';
import { json, urlencoded } from 'express';
import type { NestExpressApplication } from '@nestjs/platform-express';
import { AppModule } from './app.module';

const isLocal = !process.env.SUDA_DATABASE_URL;   // ⭐ isLocal 判定 = 无 SUDA_DATABASE_URL

async function bootstrap() {
  const app = await NestFactory.create<NestExpressApplication>(AppModule, {
    abortOnError: process.env.NODE_ENV !== 'development',
  });
  if (!isLocal) {
    app.set('trust proxy', true);                 // 线上经 cpolar/Nginx 反代 → 开 trust proxy 取真实 IP
  }
  if (!isLocal) {
    const { configureApp } = require('@lark-apaas/fullstack-nestjs-core');
    await configureApp(app, { disableSwagger: true, bodyLimit: '10mb' });   // ⭐ 只传 2 选项
  } else {
    app.useStaticAssets(join(__dirname, '..', 'client'));
    app.setBaseViewsDir(join(__dirname, '..', 'client'));
    app.setViewEngine('html');
    app.engine('html', hbsExpressEngine);
  }
  // 提高 JSON body 限制：拍照识别 base64 典型 100-500KB，远超 Nest 默认 100KB
  app.use(json({ limit: '20mb' }));
  app.use(urlencoded({ extended: true, limit: '20mb' }));

  const host = isLocal ? 'localhost' : '0.0.0.0';
  const port = Number(process.env.PORT || process.env.SERVER_PORT || '3000');
  await app.listen(port, host);
  // [local] platform modules skipped
}
bootstrap();
```

### 🔎 解析
- `isLocal = !process.env.SUDA_DATABASE_URL` —— 单凭这一项判定本地/线上，本地无 SUDA_DATABASE_URL。
- 线上：`configureApp`（fullstack-nestjs-core）接管静态资源/views/页面装配；**不**走本地的 `useStaticAssets/client`。
- `trust proxy: true` 仅线上 → 印证存在反代，`X-Forwarded-For` 提供真实 IP。
- `bodyLimit:'10mb'` 是传给 configureApp 的，但后续 `json/urlencoded limit:'20mb'` **覆盖**为 20mb（项目自身要求）。**configureApp 内部可能还设了别的 limit/中间件，但被项目显式覆盖**。
- `host = isLocal?localhost:0.0.0.0`。

## 2. `server/app.module.ts` —— 飞书侧真实 module 组装

```ts
const isLocal = !process.env.SUDA_DATABASE_URL;
const imports: any[] = [
  ConfigModule.forRoot({ isGlobal: true }),
  ScheduleModule.forRoot(),
];
imports.push(DatabaseModule);
if (!isLocal) {
  const { PlatformModule } = require('@lark-apaas/fullstack-nestjs-core');
  imports.push(PlatformModule.forRoot());    // ⭐ 隐式平台模块，无显式 provider
}
// 后续 push 进所有业务模块（ViewEngine/WafBypass/Proxy/Auth/FeishuAuth/Plaza/Vip/Ai/
//   Chat/Me/View/Behavior/ErrorLog/Settlement/Trade/XiumaSync/Erp/Collect/Kg/Content/Report/Batch/YoyBaseline）
@Module({
  imports, controllers: [],
  providers: [
    { provide: APP_FILTER, useClass: GlobalExceptionFilter },
    { provide: APP_GUARD, useClass: AuthGuard },   // ⭐ 全局守卫（应用鉴权层）
  ],
})
```

### 🔎 关键
- **`PlatformModule.forRoot()` 是"只挂载、无 provider"的隐式模块** —— 行为全部藏在 `fullstack-nestjs-core/dist` 的编译产物里。
- 全项目有**全局 AuthGuard**，而 main.ts 里 isLocal 走本地 views、线上走 configureApp —— 平台逻辑在 `core/dist`。

## 3. `@lark-apaas/fullstack-nestjs-core` 包结构（关键锁定）

- `package.json`：`main: ./dist/index.js` / `types: ./dist/index.d.ts` / `type: module` / exports `.{import:./dist/index.js, types, require:./dist/index.cjs}`。
- `files: ["dist"]` —— **只有 dist/，没有 lib/**。`ls .../lib/` 无输出是因为实际实现在 `dist/`。

## 5. 构建配置细项

### nest-cli.json
- `sourceRoot: server`、`deleteOutDir:false`（**必须为 false**，否则 nest build 会清掉 dist/，见 build.sh [3] 注释）
- assets: `capabilities/**/*.json → dist/server`（capabilities 平台资产，watch=true）
- plugins: `@nestjs/swagger` 开启（introspectComments + classValidatorShim）

### vite.config.ts
- 用 `defineConfig` **来自 `@lark-apaas/fullstack-vite-preset`**（非原生 vite defineConfig）
- server.proxy：`/api → http://localhost:3000`（本地前端代理到后端）
- build.rollupOptions.manualChunks：按 echarts/react(?) / marked / tiptap / framer-motion/gsap / shiki / lucide / xlsx 分包（注意含 react/framer/gsap/shiki —— 可能客户端实际没引这些，或模板默认配置）
- optimizeDeps.include: ['vue']

### tsconfig.node.json
- extends: `@lark-apaas/fullstack-presets/lib/simple/tsconfig/tsconfig.node.json`
- paths：`@server/*`→server/*、`@shared/*`→shared/*，以及 **`@lark-apaas/client-toolkit/logger` → `./client/src/utils/logger-stub.ts`**（平台把 client-toolkit 的 logger 替换成本地 stub，避免前端异常）
- include：server/shared/erp/server/erp/data-collect/server/client/src/api/client/src/utils
