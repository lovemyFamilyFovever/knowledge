## 4. SqlExecutionContextMiddleware —— 数据通道 SQL 追踪

```js
34411  import { DataPaasModule, SqlExecutionContextMiddleware } from "@lark-apaas/nestjs-datapaas";
36533  ...DISABLE_DATAPASS ? [] : [
36533      SqlExecutionContextMiddleware   // 受 DISABLE_DATAPASS 门控（false 时才挂）
36521   ...
```
- **不在 core/index.js 内实现**——从 `@lark-apaas/nestjs-datapaas` 包导入。
- 触发范围：`/*` 全局（用户上下文链路组）。
- 职责：SQL 执行上下文（数据通道 trace），供平台观测/审计。
- 门控：`DISABLE_DATAPASS` 时**不挂载**（此时也意味着数据库不走平台数据通道）。

## 7. 中间件矩阵汇总（更新版）

| 中间件 | 归属 | 范围 | 职责 | 门控 |
