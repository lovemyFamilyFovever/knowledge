## 7. 踩坑与经验

1. **双矩阵同步是历史高频坑**：前端英文键若未在 `BACKEND_CHANNEL` 映射中登记，会透传给后端导致 `E5002`。新增渠道必须同时核对两侧矩阵与映射表，QA 按 36 格逐格比对是最可靠的兜底手段。
2. **渠道硬编码 if 分支收敛为映射表**：本次将 `content.service` / `report.service` 两处硬编码 if 收敛到 `resolveChannelContentType`，避免以后每加一个渠道要改 4 处。
3. **契约以后端实际返回为准**：前端类型与展示文案以运行时 API 返回结构为唯一依据，不凭文档/记忆假设字段。
