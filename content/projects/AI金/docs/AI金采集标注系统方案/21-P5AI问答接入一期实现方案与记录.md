# P5 AI 问答接入一期：本地数据前置检索与上下文注入

> 任务编号：#58（实施）/ #59（验证）/ #60（本文档）
> 完成日期：2026-08-22
> 路线选择：A — 本地前置检索 + 上下文注入（用户确认）

---

## 1. 背景与目标

AI 问答专家模式此前仅依赖百炼 App 知识库。一期目标：对命中「事件/解读/周报/复盘」语义的问题，从本地采集标注系统已审核数据中检索相关内容，注入专家模式 prompt，使模型基于平台自有数据回答。

**范围限定**：仅专家模式，快速模式不动。

## 2. 架构决策

| 决策点 | 结论 | 理由 |
|--------|------|------|
| 路线选择 | A：本地前置检索+注入 | 不依赖外部API，数据完全可控 |
| 路由位置 | internal-market-data 之前 | 防"304涨价原因解读"被行情正则截获 |
| 防劫持策略 | 三重条件：语义命中 && 非行情词 && 非价格查询 | 窄正则+显式排除双保险 |
| 数据访问 | CollectRepository 新增方法 | 可测试、分层清晰 |
| 超时保护 | 1500ms Promise.race | 平衡检索质量与主链路延迟 |
| 快速模式 | 不注入 | 用户明确要求 |
| 引用合并顺序 | 本地在前、百炼在后 | 保证 [n] 编号与注入块一致 |

**被否方案**：
- B（百炼知识库 OpenAPI）：外部依赖重，配额不确定
- C（MCP 回调）：需公网端点，飞书环境不可用

## 4. 实现要点

### 4.1 路由策略（ai-query-policy.ts）

- `LOCAL_DATA_SEMANTICS` 正则：`为什么|什么原因|原因|解读|点评|评论|分析|周报|月报|季报|复盘|回顾|影响|背后逻辑|事件|检修|停产|扩产|投产|限产`
- 防劫持：`LOCAL_DATA_SEMANTICS.test(q) && !INTERNAL_MARKET_TERMS.test(q) && !chartPlan.isPriceQuery`
- 保留 `chartPlan.instruction`（饼图等图表指令不丢失）

### 4.2 检索编排（local-retrieval.service.ts）

- 关键词提取：材质词（带数字边界 `(?<!\d)(316L|201J1|304|430|201)(?!\d)`）+ 行业词 + 钢厂名
- 并发四路：`searchEntities` + `searchEventsForQa` + `searchAnalysisForQa` + `searchDailyPricesForQa`
- 1500ms 超时 → 空结果降级
- 上下文块：2000 字符上限，单条 150 字截断
- 引用格式：`{ index, source }`（如 `AI金本地库·事件《标题》`）

### 4.3 Pipeline 注入（pipeline.service.ts）

- 门禁：`route === 'local-incremental-data' && context?.mode === 'expert'`
- 命中：`finalPrompt = 治理前缀 + contextBlock + [用户问题] + decision.finalPrompt`
- 未命中/异常：静默降级走原流程

### 4.4 数据过滤

所有检索均限定 `status IN ('confirmed', 'active')`，只注入已审核数据。

## 5. 数据流

```
用户提问（专家模式）
  → PipelineService.process()
    → decideAiQueryRoute() → route='local-incremental-data'
    → LocalRetrievalService.retrieve(question)
      → 关键词提取（≤5 锚点词）
      → Promise.all: [searchEntities, searchEvents, searchAnalysis, searchDailyPrices]
      → 拼装 contextBlock + references
    → 注入 finalPrompt
  → bailianService.askStream(finalPrompt)
  → done 事件：filterReferences([...localRefs, ...bailianRefs])
```

## 6. 降级与容错

| 场景 | 行为 |
|------|------|
| 锚点词为空 | 不检索，走原流程 |
| 检索零命中 | 不注入，走原流程 |
| 检索超时（>1500ms） | 返回空结果，走原流程 |
| 数据库异常（含42P01） | logger.warn + 空结果，走原流程 |
| 快速模式 | 跳过检索（mode !== 'expert'） |
