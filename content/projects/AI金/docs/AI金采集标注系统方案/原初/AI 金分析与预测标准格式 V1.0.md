# AI 金分析与预测标准格式 V1\.0

**文档目的**：在数据 V1\.0（4 维度客观数值）和事件 V1\.0（7 大类客观事实）基础上，建立第三轨——**分析与预测类**标准采集格式。分析类负责"为什么发生 \+ 影响什么"的主观解读，预测类负责"数据会怎么变 \+ 价格怎么走"的未来推断，形成"数据 → 事件 → 分析 → 预测"完整四轨飞轮。
**适用范围**：AI 金项目的分析解读与数据预测工作。与数据 V1\.0、事件 V1\.0 配套使用，形成四轨闭环采集体系。
**版本**：V1\.0 \| **主导**：待定 \| **配合**：朱铮勋、黄颖、王保杰 \| **拍板**：洛歌
**关联文档**：[AI 金数据采集标准格式 V1\.0](https://hcnbikrs8vvb.feishu.cn/docx/D64Ed53Ueol3vyxqy7rcWsSFnCc) · [AI 金事件类标准采集格式 V1\.0](https://hcnbikrs8vvb.feishu.cn/docx/Mjy4d0yF1oSe1Gxt6QKct44Fnty)

# 第一章 总体框架

## 四轨采集体系：从客观事实到未来推断

数据 V1\.0 采集"发生了什么数值"，事件 V1\.0 采集"发生了什么事"——两者都是**客观事实**。但业务决策不仅需要事实，还需要**解读**和**预判**。本文档建立第三轨（分析类）和第四轨（预测类），补齐从"知道发生了什么"到"知道为什么、知道接下来会怎样"的完整链路。

|轨道|版本|采集对象|性质|核心问题|采集频率|
|---|---|---|---|---|---|
|数据轨|V1\.0|价格/库存/产量/需求量|客观事实|数值是多少？变了多少？|日/周/月/季固定周期|
|事件轨|V1\.0|7 大类行业事件|客观事实|发生了什么事？|事件驱动，发生时即报|
|**分析轨**|**本文档**|事件解读 \+ 数据异动解读|**主观解读**|**为什么发生？影响什么？**|事件/数据异动后即时解读|
|**预测轨**|**本文档**|价格/库存/需求产量预测|**未来推断**|**数据会怎么变？价格怎么走？**|按预测时间窗口定期发布|

## 设计理念：填空 \+ 选择 \+ AI 辅助

延续数据 V1\.0 和事件 V1\.0 的核心理念——**填空题，不是写文章**。分析类和预测类的所有必填字段均提供结构化输入（下拉、多选、单选、数字），仅在"详细解读"等可选字段中允许自由文本。同时，每条分析/预测均可由 AI 生成草稿，分析师只需校核确认。

**四轨三段流程**
① **采**：数据/事件按标准格式填空（采集人员）→ ② **析**：分析师基于数据\+事件做解读和预测（填空\+校核 AI 草稿）→ ③ **出**：AI 按场景生成深度报道/报告/问答缓存/预测推送（自动化）

# 第二章 分析类 A 类·事件解读型

## 定位

A 类分析针对**某条事件**，解读"为什么发生 \+ 影响什么"。当一条事件 V1\.0 记录的影响程度 ≥ 3 星时，必须配套产出至少一条 A 类解读。

## 必填字段（11 项）

|序号|字段名|输入方式|格式/约束|说明与示例||
|---|---|---|---|---|---|
|A1|解读 ID|自动生成|ANA\-YYYYMMDD\-AXXX|系统自动生成。例：ANA\-20260817\-A001||
|A2|关联事件 ID|单选/多选引用|引用事件 V1\.0 的 E1|本条解读对应的事件。例：EVT\-20260816\-001||
|A3|关联数据 ID|多选引用|引用数据 V1\.0 记录（可多个）|本条解读涉及的数据记录。例：DP\-20260816\-304\-WX（无锡 304 日价）||
|A4|解读标题|短文本|限 30 字|一句话概括解读结论。例：太钢检修：304 供给收紧，短期价格有支撑||
|A5|解读类型|多选|5 项可选|原因解读 / 影响评估 / 趋势研判 / 风险提示 / 机会提示。可多选||
|A6|分析师 ID|人员选择|系统人员库|解读撰写人||
|A7|分析师姓名|自动填充|随 A6 联动|例：黄颖||
|A8|解读时间|日期时间选择器|YYYY\-MM\-DD HH:mm|解读发布时间。例：2026\-08\-17 10:30||
|A9|核心结论|填空模板|限 200 字|2\-3 句话按模板填空。见下方填空模板说明||
|A10|关联钢种/产品|多选下拉|与数据 V1\.0 品类对齐|不锈钢\-304 / 不锈钢\-316L / 碳钢\-热卷 等||
|A11|关联地域|多选下拉|与数据 V1\.0 区域对齐|华东 / 华南 / 华北 等||
|A12|时间维度|单选|4 档|即时解读 / 1 日内 / 1 周内 / 1 月内||
|A13|置信度|星级滑块|1\-5 星|1 星=初步判断、3 星=有依据、5 星=高度确信||

**说明**：A6/A7 计为一组字段，A1 为自动生成，实际需分析师填写的必填项为 11 项。

**A9 核心结论——填空模板**
**原因解读型**：本次【事件类型】的核心原因是【1\-2 句原因分析】，直接导致【数据维度】【上涨/下跌/持平】，幅度约【百分比/数值】。
**影响评估型**：该事件对【钢种】【地域】的【数据维度】影响方向为【利多/利空/中性】，预计影响幅度【数值/百分比】，持续时间约【时间窗口】。
**趋势研判型**：基于【事件\+数据】综合判断，【钢种】在【时间窗口】内预计【看涨/看跌/震荡】，核心驱动因素为【1\-2 句】。
**风险提示型**：需要关注的风险点为【风险描述】，若触发则可能导致【数据维度】【大幅上涨/下跌】，建议【应对措施】。
**机会提示型**：当前出现的机会为【机会描述】，窗口期约【时间】，建议【操作建议】，预期收益【数值/百分比】。

## 可选字段（8 项）

|序号|字段名|输入方式|说明与示例||
|---|---|---|---|---|
|AO1|详细解读|长文本|完整解读文章，可多段。限 2000 字||
|AO2|数据对比|数字\+百分比|具体涨跌幅度、环比同比数据。例：304 冷轧日价环比\+200 元（\+1\.4%），社会库存环比\-2\.9%||
|AO3|受影响企业清单|多选/文本|事件直接影响的钢厂/贸易商/下游企业名单||
|AO4|历史同类事件对比|引用\+文本|引用历史事件 ID 并对比差异。例：类似 2025 年 3 月青山检修，当时 304 价格 5 日内上涨 3\.2%||
|AO5|后续动态跟踪|长文本|事件后续进展，可多次追加更新（带时间戳）||
|AO6|信源链接|URL（多条）|分析参考的信息来源链接||
|AO7|图片/视频附件|文件附件|解读配图、图表、数据截图等||
|AO8|备注|长文本|其他补充信息||

# 第三章 分析类 B 类·数据解读型

## 定位

B 类分析针对**某条数据异动**，解读"为什么异动 \+ 后续影响"。当数据 V1\.0 记录的环比增减比例超过阈值（日价±2% / 周库±2% / 月产±5% / 季需±3%）时，系统自动提示创建 B 类解读。

## 必填字段（12 项）

|序号|字段名|输入方式|格式/约束|说明与示例||
|---|---|---|---|---|---|
|B1|解读 ID|自动生成|ANA\-YYYYMMDD\-BXXX|系统自动生成。例：ANA\-20260817\-B001||
|B2|关联数据 ID|单选/多选引用|引用数据 V1\.0 记录|本条解读对应的数据记录。例：DP\-20260816\-304\-WX||
|B3|关联事件 ID 列表|多选引用|引用事件 V1\.0（可多个）|导致异动的一个或多个事件。例：EVT\-20260816\-001, EVT\-20260815\-003||
|B4|解读标题|短文本|限 30 字|一句话概括。例：304 日价涨 1\.4%：检修\+需求双驱动||
|B5|异动类型|单选|4 项|涨 / 跌 / 持平 / 异常波动||
|B6|异动幅度|数字\+百分比|如 \+5\.2% / \-3\.8%|核心异动的量化数据||
|B7|涉及维度|多选|4 项|日价 / 周库 / 月产 / 季需。可多选||
|B8|涉及钢种/产品|多选下拉|与数据 V1\.0 对齐|不锈钢\-304 / 不锈钢\-201 等||
|B9|涉及地域|多选下拉|与数据 V1\.0 对齐|华东 / 华南 等||
|B10|分析师 ID \+ 姓名|人员选择|系统人员库|同 A6/A7||
|B11|解读时间|日期时间选择器|YYYY\-MM\-DD HH:mm|解读发布时间||
|B12|核心结论|填空模板|限 200 字|见下方填空模板||
|B13|置信度|星级滑块|1\-5 星|同 A13||

**说明**：B1 自动生成，B10 计为一组，实际需分析师填写的必填项为 12 项。

**B12 核心结论——填空模板**
**涨/跌型**：【钢种】【地域】【数据维度】于【日期】【上涨/下跌】【幅度】，主要驱动因素为【1\-3 个因素关键词】，预计后续【延续/反转/观望】，时间窗口约【N 天/周】。
**异常波动型**：【钢种】【数据维度】出现异常波动（幅度【百分比】），异常原因初步判断为【原因】，需进一步跟踪【跟踪方向】，预计【时间】前可明确。
**持平型**：【钢种】【数据维度】连续【N 个周期】持平，市场处于【观望/僵持/均衡】状态，打破均衡的潜在因素为【因素】，关注【时间节点】。

## 可选字段（6 项）

|序号|字段名|输入方式|说明与示例||
|---|---|---|---|---|
|BO1|详细解读|长文本|完整解读文章。限 2000 字||
|BO2|异动原因|多选|枚举事件 V1\.0 的 7 大类：A 钢厂事件 / B 原料成本 / C 政策贸易 / D 需求市场 / E 宏观金融 / F 突发不可抗力 / G 行业市场。可多选||
|BO3|异动影响|结构化文本|对上下游、对相关品种、对相关地域的传导影响||
|BO4|数据预测方向|单选×3|短期（1\-7 天）/ 中期（1\-4 周）/ 长期（1\-3 月）各选一个方向：看涨/看跌/震荡||
|BO5|后续跟踪建议|文本|建议关注的后续数据/事件/时间节点||
|BO6|备注|长文本|其他补充信息||

# 第七章 四轨双向引用机制

## 引用关系总览

四条轨道之间形成完整的双向索引链，从任一节点切入都能追溯到全链路信息。

|引用方向|源轨道|目标轨道|字段名|说明||
|---|---|---|---|---|---|
|事件 → 数据|事件轨 E10|数据轨 4 维度|数据影响方向|标注事件影响了哪些数据维度及方向||

|分析 A → 数据|分析轨 A3|数据轨 4 维度|关联数据 ID|A 类解读涉及的数据||
|分析 B → 数据|分析轨 B2|数据轨 4 维度|关联数据 ID|B 类解读对应的数据||
|分析 B → 事件|分析轨 B3|事件轨 E1|关联事件 ID 列表|导致数据异动的事件||

# 第九章 填空式 UX 设计

## 快速分析流程（A 类·事件解读）

分析师收到事件通知后，按以下顺序完成解读，预计耗时 3\-5 分钟：

1. **选事件**：从事件列表中点击关联事件（自动带入 E1\-E11 信息）

2. **选数据**：勾选受影响的数据记录（系统根据事件 E10 自动推荐）

3. **填标题**：输入 30 字以内的解读标题

4. **选类型**：多选解读类型（原因解读/影响评估/趋势研判/风险提示/机会提示）

5. **选品类地域**：多选钢种和区域（系统根据事件自动推荐）

6. **选时间维度**：单选即时/1 日/1 周/1 月

7. **填结论**：系统根据解读类型自动加载填空模板，替换占位符

8. **评置信度**：拖动星级滑块

9. **AI 辅助**（可选）：点击"AI 生成草稿"按钮，AI 基于关联的事件\+数据自动生成解读草稿，分析师校核修改后提交

## 快速预测流程（P 类·价格预测）

1. **选对象**：选择钢种\+规格\+地域（下拉联动）

2. **看当前**：系统自动拉取数据 V1\.0 最新价格

3. **选窗口**：选择预测时间窗口（1 日/7 日/30 日/90 日）

4. **填预测**：输入预测价格和方向（或点击"AI 预测"自动填入）

5. **关联依据**：勾选支撑的事件和解读记录

6. **选模型**：选择预测方法（AI 金 LLM / 历史规律 / 专家经验 / 综合）

7. **评置信度**：拖动星级滑块

8. **提交**：系统生成预测 ID 并发布
