# 19 - P3-B 周期报告实现方案与记录

> 归档日期：2026-08-21
> 阶段：P3-B（周期报告：周报 / 月报 / 季报）
> 关联文档：05-输出引擎设计、06-分期实施计划、13-老板汇报问答预演

---

## 一、需求背景

- **P3-B 定义（06 文档）**：周报 / 月报 / 季报 = 周期聚合 + 预测复盘 + 准确率统计。
- **验收标准**：周期报告可生成，且预测复盘数字准确。
- **报告矩阵（05 文档第四章）**：

| 周期 | 内容构成 |
|------|---------|
| 周报 | 事件汇总 + 库存变化 + 异动归因 + 周度复盘 |
| 月报 | 重大事件（≥3 星）+ 产量复盘 + 价格归因 + 准确率 |
| 季报 | 大事记 + 供需平衡 + 季度复盘 + 下季展望 |

---

## 二、调研结论（实现前基线）

1. **五张数据轨表全部为空**：周库存 / 月产量 / 季需求 / 分析 / 预测表均无数据，也无写入管线（对应抽取模板属 P2/P4 范围）。
2. **预测复盘机制完全缺失**：`actual_value` 回填、误差率计算均不存在。
3. **PREDICTS / VERIFIES 图谱边无写入**：本期未做，表级复盘优先。
4. **P3-A ContentService 可复用**，但渠道 × 风格矩阵缺少周报 / 月报 / 季报三个风格。
5. **结论**：造数是先决条件，采用 **SQL 种子造数（选项 A）**。

---

## 三、技术方案

### 1. 造数迁移 043

- 种子数据设计：**10 条预测刻意设计区分度**
  - 5 条已到期可复盘
  - 2 条到期但无对应数据（跳过）
  - 3 条未到期
  - 预测准 / 不准 / 方向错各有代表，保证复盘统计有区分度
- 新增列：`direction_hit`（方向命中标记，复盘时回写）。

### 2. ReportModule 四接口

| 接口 | 职责 |
|------|------|
| `GET /aggregate` | 周期聚合：事件 / 库存 / 产量 / 需求 / 价格 / 分析 + `materialPack` 素材包；环比用 SQL `LAG` 现算，**不回写** |
| `POST /verify` | 预测复盘：`parseForecastDeadline` 解析中文周期词（"上周/本月"等），以 `_created_at` 为基准相对解析，`time_window` 兜底；按 P/Q/R 分类匹配对应数据轨；回写 `actual_value` / `forecast_error_pct` / `direction_hit` / `verified_at`；**幂等** |
| `GET /accuracy` | 三维度分组统计：`forecaster` / `model_type` / `forecast_type` |
| `POST /generate` | 素材包 → `BailianService.askSync` → 落 `data_content`（style = 周报/月报/季报）+ citations；LLM 失败时 mock 兜底 |

### 3. 矩阵扩展

`CHANNEL_STYLE_MATRIX`（后端）与前端 `COMPAT_MATRIX` **双处同步**新增周报 / 月报 / 季报三个风格。

### 4. 前端页面

- 页面：`period-report/index.vue`
  - 聚合预览卡 + ECharts 图表
  - 复盘弹窗 + 误差率统计面板
  - 生成弹窗
- 路由：`/erp/data-collect/reports`，并在 `ErpLayout` 菜单注册入口。

## 四、误差率口径（重要，R6 决议）

- **`forecast_error_pct = |预测 − 实际| / |实际|`**，是**误差率，不是准确率**。
- **全链路文案纪律**：
  - 前端统计卡片统一写"平均误差率"；
  - tooltip 明示口径"越低越准"；
  - **禁止出现"准确率 90%"式夸大表述**（13 文档老板汇报红线）。

## 五、实测结果

| 场景 | 结果 |
|------|------|
| verify | verified 5 / skipped 5；误差率分布 0.55% ~ 4.23%，含 1 条方向未命中 |
| accuracy | directionHitRate 0.8、avgErrorPct 0.0188；AI金LLM-v1（3 条命中 100%、误差 0.66%）优于分析师（误差 3.20%），统计有区分度 |
| generate | 公众号周报真实 LLM 成功（qwen3.7-plus，11 条 citations）；行业群降级版成功 |
| 幂等 | 二次 verify 返回 verified 0 |

## 六、踩坑与经验

1. **造数是复盘类功能的先决条件**：表全空时先造带区分度的种子数据（刻意设计准 / 不准 / 方向错），否则验收无从谈起。
2. **中文周期词解析**：`forecast_period` 是自由文本（"上周/本月"），`parseForecastDeadline` 需相对 `_created_at` 解析，并以 `time_window` 兜底。
3. **前后端契约差异**：verify 明细字段后端为 snake_case，前端 types 需按实际返回结构对齐。教训：接口契约文档先行可避免返工。
4. **误差率 vs 准确率口径纪律**：从后端注释到前端文案全链路统一口径，避免汇报口径事故。
5. **环比现算不回写**：用 SQL `LAG` 窗口函数在聚合时计算环比，避免回写表引入数据一致性问题。
