## 二、明早 MVP 范围（P1 核心，已确认）

**MVP 黄金路径（五轮复审采纳：只证明一件事——"采 → 存 → 图 → 出"真的跑通了）**：

```
真实文章 → AI 自动识别 → AI 自动结构化 → 人工修改 1~3 个字段 → 确认入库
  → 自动生成实体/关系 → 图谱看到关系 → 一键生成内容草稿
```

**MVP 核心演示链路**：一篇真实文章 → AI 自动识别类型 → AI 结构化预填 → 人工只改少数问题 → 入库 → 结果可追溯（详情页 + 图谱可视化页 + 内容编辑工作台）。

| 模块 | MVP 范围 |
|---|---|
| 工作台 | 三页：首页（待处理队列+快捷入口）/ 处理页（左原文+右表单+底部操作条）/ 我的记录页 |
| 类型路由 | event（7 大类）、data_price、**mixed（一文多记录，正式能力）** |
| 约束抽取 | 事件模板（E1-E11+主要可选）+ 日价模板（核心字段）；字段级置信度 × 数据性质（FACT/OPINION/INFERENCE）+ 证据链 + AI 修改建议 |
| 人工校核 | UI 三态（绿/黄/红）+ AI 预填 + 判断类字段强制确认 + 一键全过（硬拦截条件）/ 提交 / 复制上次 |
| 生命周期 | 父任务（data_articles）+ 子记录（业务表）两套状态机，mixed 独立入库独立追溯 |
| 入库 | 事件/日价写入 + 同比环比自动计算（冷启动留空标记） |
| 图谱 | kg 表 + 入库自动写实体/关系（FACT/OPINION/INFERENCE 分层）+ **图谱可视化页（5 个核心功能）** |
| 输出草稿 | **内容编辑工作台**：素材选择（confirmed）→ 渠道/风格（兼容矩阵）→ AI 生成 → 人工修改/重生成（版本）→ 定稿存档（data_content），不接分发 |
| 追溯 | 文章详情页展示"此文生成了哪些记录/关联了哪些实体"；生成内容带素材引用标注 |

**MVP 明确不做**：14 万篇存量批量、问答接入、一键分发、周/月/季报、图谱高级功能（时间过滤/聚合/故事线/高亮路径）、周库/月产/季需与分析/预测抽取模板（仅建表）、内容进图谱。

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| AI 抽取准确率不达标 | 字段级置信度×性质标红 + 人工校核兜底；prompt 按校核 diff 持续迭代；分维度验收（事实/枚举/数值分开看，不混一个数） |
| 递归查询性能不达标 | 索引先行；深度限制+剪枝；结果缓存；**真实数据压测后再定方案**（P2 压测任务） |
| 同事抵触新流程 | 一键全过（操作量趋近于零）；复制上次；批量校核；UI 简单 |
| 洛歌对"AI 预填替代人工填"有异议 | 01 文档差异点说明：字段/枚举/规则全保留，只是人肉管道换机器 |
| 判断类字段 AI 高置信度但业务错误 | 判断类字段强制人工确认（即使高置信度），见 03 审核判定表 |
| INFERENCE 污染事实层 | FACT/OPINION/INFERENCE 性质标记 + 第二层只收 FACT 纪律（01 文档第六章） |
| 飞书环境限制 | 抽取为轻量 API 调用；批量流水线分片执行；不依赖常驻进程 |
| 存量 14 万篇成本 | 规则预抽先行，LLM 只做规则覆盖不到的部分；分批跑 |
