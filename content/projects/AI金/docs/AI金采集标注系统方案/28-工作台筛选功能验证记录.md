## 四、备注与边界

- **仅看我的语义**：后端按 `created_by = 当前登录用户` 过滤，开启后总数与列表一致（`countWorkbenchBucket` 随 `mine` 重新计算）。
- **历史数据**：存量文章 `_created_by` 为空，显示「外部」，属数据现状而非功能缺陷；新提交文章会由 controller 注入当前登录用户名。
- **真实命中实测（DB 直插验证）**：通过 postgres 直接插入一条 `_created_by='admin'` 的 pending 测试文章（不经 LLM 管线，零 token 消耗），验证：
  - 「只看我的」开启后全部 Tab `total=1`，唯一命中该文章，`created_by=admin`；
  - pending Tab + mine=1 同样正确命中；
  - 清理该测试文章后 `mine=1` 恢复 `total=0`。
  - 验证了「只看我的」过滤由数据库查询到接口输出全链路正确，测试数据与临时脚本均已清理。
