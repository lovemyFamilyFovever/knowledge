## 一、系统概览

- **后端三模块**（均已注册进 `server/app.module.ts`）：
  - `CollectModule`（`erp/data-collect/server/collect/`）：`/api/collect/*`，11 端点，imports AiModule
  - `KgModule`（`erp/data-collect/server/kg/`）：`/api/kg/*`，4 端点
  - `ContentModule`（`erp/data-collect/server/content/`）：`/api/content/*`，7 端点
- **数据库**：20 张 `collect_*` / `kg_*` / `data_content*` 表，迁移工具 `scripts/run-collect-migrations.mjs`（幂等），含 2 篇演示种子文章
- **前端**：采集工作台（index / review / records）、知识图谱（kg-graph）、内容生成工作台（content-studio），均带 localStorage mock 开关
- **Repository**：`server/database/{collect,kg,content}.repository.ts`

### Jimmy（采集工作台前端）
- **eslint 白名单 glob 修复**：ESLint 配置原先对 ERP 目录的白名单写法无法覆盖新目录下的 `.ts` 文件导致解析错误，改为通用 glob 后修复（commit cfc2202）。

### Robin（知识图谱前端）
- **G6 v5 与 4.x API 差异清单**（本项目使用 `@antv/g6 ^5.0.0`）：
  - 数据写入：`graph.addNodeData()` / `addEdgeData()`（v4 为 `graph.addNode()`）
  - 状态管理：`graph.setElementState(id, state)`（v4 为 `setItemState`）
  - 交互配置：`behaviors` 数组声明式配置（v4 为 modes）
  - 其余差异：Graph 构造选项、事件名、布局注册方式等均按 v5 文档对齐
- **jsdom 冒烟 23 断言替代视觉验证**：无头环境无法截图比对，用 jsdom 跑 DOM 逻辑冒烟（23 条断言）替代视觉验证。
- 残留说明：`node_modules/.tmp-kg-smoke/` 冒烟临时目录与常驻进程已由 Task #8 收尾时清理（进程已停、空目录已删）。
