## 三、后期工作计划

### 3.1 第一批（8 月中下旬）—— P1 功能

按"用户感知强、开发量适中"优先：

1. **广场**：消息提醒通知中心 → 收藏功能接入 → 会员个人主页
2. **AI 测价**：预测 vs 实际对比 → 结果导出（图片）→ 多参数对比预测 → 分享
3. **AI 问答**：图表/数据分析增强 → 回答关联广场帖子/历史问答
4. **AI 配单**：保交付最小链路（跳转秀吗成交）
5. **VIP/个人中心**：购买流程稳定性校验 → 退款申请 → 发票 → 套餐升级 → 订单超时处理
6. **ERP**：公告与消息推送 → AI 用量计费层
7. **用户画像**：引导页采集 → 行为记忆采集
8. **AI 客服**：AI 客服自动应答 + 转人工策略 → 通知中心 + 顶部横幅
9. **跨模块**：新用户引导完善 → 首页为你推荐画像驱动 → 消息通知统一入口

### 3.2 第二批（9 月）—— P2 功能

1. **广场**：私聊 → 关注分组管理 → 问答答案明细表 → 日报/周报/月报挂载 → 话题/标签系统 → 内容审核/举报机制
2. **AI 测价**：价格提醒/订阅 → 预测准确率统计 + 打分反馈 → 多钢种联动预测
3. **AI 配单**：供应商信誉展示 → 采购单保存/跟踪 → 分销佣金模式预留
4. **AI 问答**：高频问答沉淀知识库 → 追问/澄清机制
5. **VIP**：积分体系 → 续费提醒 → 优惠券/营销活动/**邀请机制**（2026-08-27 新增）
6. **ERP**：实时大屏+异常告警 → 知识库管理 → 客服工单 → Prompt A/B 测试 → 角色权限
8. **平台级**：运营后台 → 移动端适配 → 飞书 Bot 推送 → 多语言预留
