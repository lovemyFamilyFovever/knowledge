## 一、飞书开放平台集成能力全景

飞书开放平台提供 **三种应用形态**，可叠加组合：

| 形态 | 核心能力 | 适用场景 | 技术门槛 |
|------|---------|---------|---------|
| **机器人（Bot）** | 会话交互、群聊@、私聊、消息卡片、长连接事件推送 | AI 问答、行情推送、早报日报、告警通知 | ★★☆ 中等 |
| **网页应用（H5）** | 嵌入飞书客户端内运行、SSO 免登、工作台图标入口 | 完整功能入口（配单/测价/广场/VIP 管理） | ★☆☆ 较低 |
| **小组件（Block）** | 嵌入飞书文档/多维表格中、数据看板 | 行情数据嵌入飞书文档、报表嵌入多维表格 | ★★★ 较高 |

**额外通道**：

| 通道 | 说明 | 门槛 |
|------|------|------|
| **飞书应用商店** | ISV 入驻 → 上架 → 全飞书企业可安装购买 | ★★★★★ 极高（需企业认证、成立 1 年+、50 家客户、保证金） |
| **Open API 对外接口** | 第三方系统通过 API Key 调用 | ★☆☆ 已有 |
| **飞书审批流** | 嵌入审批节点（如 VIP 购买审批） | ★★☆ 中等 |
| **飞书多维表格插件** | 在多维表格内嵌入自定义功能 | ★★★ 较高 |

## 三、用户场景分析：不锈钢行业用户的自然入口

不锈钢行业用户（贸易商、供应商、采购经理）的典型工作流：

| 场景 | 用户痛点 | AI金能提供的价值 | 最自然的飞书入口 |
|------|---------|----------------|----------------|
| **早间行情速览** | 每天需打开多个网站看行情 | AI 金每日早报（行情+趋势+操作建议） | 飞书群消息自动推送 |
| **快速询价** | 打电话/发微信问多家供应商 | AI 问答："304/2B 1.0×1219 无锡今天什么价？" | 飞书机器人私聊/群聊@ |
| **采购配单** | 手动比对多家供应商报价 | AI 智能配单：自然语言描述需求 → 自动匹配最优货源 | 飞书工作台一键打开 |
| **价格趋势判断** | 凭经验判断涨跌 | AI 测价：8 步深度分析 + 图表 | 飞书工作台 / 机器人推送 |
| **VIP 到期续费** | 不知道什么时候到期 | 消息通知 + 一键续费 | 飞书消息卡片 |
| **团队协同** | 采购决策需要多人确认 | 配单结果分享到群 → 团队讨论 | 飞书群聊分享卡片 |

**核心洞察**：不锈钢用户的最高频需求是**「问行情」和「找货源」**，最自然的入口是**飞书机器人对话**（像问同事一样问 AI金）和**飞书工作台**（像打开一个应用一样打开 AI金）。

## 四、推荐方案与优先级

### 方案一：飞书机器人（ROI 最高，推荐首选）

**一句话**：用户在飞书群聊中 @AI金机器人 或在私聊中直接提问，机器人调用 AI金后端能力返回行情/问答/配单结果。

**技术实现路径**：

```
用户在飞书聊天 → @AI金机器人 / 私聊机器人
  → 飞书长连接事件推送（im.message.receive_v1）
  → AI金后端接收消息
  → 路由到 AI 问答/配单/测价服务
  → 构建飞书消息卡片（支持图表、表格、按钮）
  → 通过飞书 API 回复用户
```

**需要开发的内容**：

| 模块 | 工作量 | 说明 |
|------|-------|------|
| 飞书机器人能力配置 | 0.5 天 | 在妙搭应用后台添加机器人能力、配置事件订阅 |
| 消息接收与路由 | 2 天 | 长连接监听 → 消息解析 → 意图识别 → 路由到对应 AI 服务 |
| 飞书消息卡片构建 | 3 天 | 行情卡片（价格+涨跌+趋势图）、配单结果卡片（商品列表+操作按钮）、测价报告卡片 |
| 权限绑定 | 1 天 | 飞书 open_id → MEMBER_CODE 映射，复用现有 VIP 权限 |
| 群聊管理 | 1 天 | 机器人入群、@触发、群白名单 |
| **合计** | **~7-10 天** | |

**用户体验流程**：
1. 用户在飞书搜索「AI金」机器人，发起私聊
2. 输入："304冷轧今天什么价？"
3. 机器人 3 秒内回复消息卡片：今日 304 冷轧均价、涨跌幅、趋势迷你图、操作建议
4. 用户继续："帮我找 1.0×1219 无锡的货源"
5. 机器人回复配单结果卡片：Top 5 匹配货源、供应商信息、一键查看详情按钮
6. 点击按钮 → 跳转飞书工作台内的 AI金完整页面

**业务价值**：
- **日活提升 3-5 倍**：用户不需要打开 AI金网站，在飞书日常办公中就能使用
- **信息触达率 100%**：早报/告警直接推送到用户飞书，不会错过
- **降低使用门槛**：不需要记网址、不需要登录，飞书里直接对话

### 方案二：飞书工作台 H5 入口（最低成本，立即可做）

**一句话**：在飞书工作台中添加 AI金图标入口，点击后在飞书客户端内打开 AI金完整页面（SSO 免登）。

**技术实现路径**：

```
飞书工作台 → 点击「AI金」图标
  → 飞书客户端内打开 H5 页面（桌面端主页 + 移动端主页）
  → 飞书 SSO 免登（OAuth2.0 → 获取 user_access_token → 映射 MEMBER_CODE）
  → 展示 AI金完整功能（问答/配单/测价/广场/VIP）
```

**需要开发的内容**：

| 模块 | 工作量 | 说明 |
|------|-------|------|
| 飞书网页应用能力配置 | 0.5 天 | 在妙搭应用后台添加网页应用能力、配置桌面端/移动端主页 URL |
| 飞书 SSO 免登对接 | 2 天 | OAuth2.0 授权流程 → 获取飞书用户身份 → 映射到 MEMBER_CODE |
| 飞书 JS-SDK 集成 | 1 天 | 飞书客户端内导航、标题设置、分享能力 |
| **合计** | **~3-4 天** | |

**用户体验流程**：
1. 用户在飞书工作台看到「AI金」图标（和飞书文档、飞书审批并列）
2. 点击 → 免登录直接进入 AI金主页（自动识别飞书身份）
3. 完整使用所有功能：AI 问答、智能配单、价格预测、智能广场

**业务价值**：
- **零门槛上线**：3-4 天即可交付，让用户在飞书内一键触达 AI金
- **SSO 免登体验**：不需要再输账号密码，飞书身份直接打通
- **移动端可用**：飞书手机端也能打开 AI金

### 方案三：AI金早报自动推送（最快见效，1-2 天）

**一句话**：每天早上 8:30，AI金自动向指定飞书群推送不锈钢行业早报（行情摘要 + 价格趋势 + 操作建议）。

**技术实现路径**：

```
定时任务（NestJS Schedule）→ 每日 8:30 触发
  → 调用 AI 问答服务生成行业早报
  → 构建飞书消息卡片（行情摘要 + 趋势图 + 操作建议）
  → 通过 FeishuMessageService 推送到指定群/个人
```

**需要开发的内容**：

| 模块 | 工作量 | 说明 |
|------|-------|------|
| 早报内容生成 | 1 天 | 复用现有 AI 问答能力，定制早报 System Prompt |
| 飞书消息卡片模板 | 0.5 天 | 行情摘要卡片（价格+涨跌+迷你图+建议） |
| 定时推送任务 | 0.5 天 | 复用现有 ScheduleModule + FeishuMessageService |
| **合计** | **~1-2 天** | |

**业务价值**：
- **1-2 天见效**：最快落地的方案，立即让用户感知 AI金价值
- **被动触达**：用户不需要主动打开任何应用，早报自动送到飞书
- **引流利器**：卡片底部"查看详情"按钮 → 引导用户打开 AI金完整页面

## 七、重要澄清：不需要 ISV 资质

以上三个方案**均基于「企业自建应用」模式**，不需要申请 ISV 服务商资质。

飞书开放平台有两种应用类型：

| 类型 | 适用场景 | ISV 资质 | 审核 |
|------|---------|---------|------|
| **企业自建应用** | 企业内部使用，或妙搭平台已部署的应用 | **不需要** | 企业管理员自行发布 |
| **商店应用（ISV）** | 上架飞书应用商店，供所有飞书企业购买安装 | **需要** | 飞书平台审核（资质审核→方案审核→产品验收→安全验收） |

AI金当前已是飞书妙搭上的企业自建应用（app_4k9x70cg0jws9）。添加机器人能力、H5 网页应用能力、消息推送等，都是在现有自建应用上配置，**无需 ISV 资质，无需飞书平台审核**。

只有当未来需要将 AI金上架到飞书应用商店、面向所有飞书企业销售时，才需要申请 ISV 资质。

## 八、总结

**核心结论**：AI金已经部署在飞书妙搭之上，与飞书的「镶嵌」具备天然优势。建议分三步走：

1. **早报推送**（1-2 天）— 让 AI金能力「出现在」用户的飞书消息流中
2. **工作台入口 + SSO 免登**（3-4 天）— 让 AI金「出现在」用户的飞书工作台中
3. **飞书机器人**（7-10 天）— 让 AI金能力「融入」用户的飞书对话中

三步完成后，AI金在飞书生态中形成**三个触点**：消息推送（被动触达）+ 工作台入口（主动使用）+ 机器人对话（自然交互），构成完整的「AI金 × 飞书」嵌入式体验。

**以上所有方案均不需要 ISV 资质**，在现有企业自建应用上即可实施。
