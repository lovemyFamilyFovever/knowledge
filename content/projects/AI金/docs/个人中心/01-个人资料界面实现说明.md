## 一、功能概述

个人资料界面是用户查看和管理个人信息的入口，展示用户头像、昵称、公司信息、统计数据以及发布的内容（作品/点赞/收藏/历史）。支持背景自定义、头像上传裁切、个人信息编辑、内容管理等功能。

**核心能力：**
- 背景自定义（预设渐变 + 自定义上传）
- 头像上传与裁切
- 个人资料编辑（昵称/公司/职位）
- 账号安全管理（手机/邮箱/密码）
- 内容展示与管理（作品/点赞/收藏/观看历史）
- 关注/粉丝查看与互动

**入口路由：** `/personal/profile`

```typescript
async function handleBgUpload(e: Event) {
  const file = e.target.files?.[0]
  
  // 校验大小（≤ 5MB）
  if (file.size > 5 * 1024 * 1024) {
    toast('图片不能超过 5MB')
    return
  }
  
  // 读取为 DataURL
  const reader = new FileReader()
  reader.onload = async () => {
    const dataUrl = reader.result as string
    const newBg = `url("${dataUrl}")`
    const oldBg = currentBg.value
    currentBg.value = newBg
    
    try {
      await updateProfile({ profileBackground: newBg })
    } catch {
      currentBg.value = oldBg
      toast('背景保存失败')
    }
  }
  reader.readAsDataURL(file)
}
```

## 四、头像管理

### 4.1 头像加载策略

```typescript
async function loadAvatar() {
  try {
    const res = await fetchVipProfile()
    if (res.data.avatarUrl) {
      avatarSrc.value = res.data.avatarUrl
      avatarLoadError.value = false
    } else {
      // 无头像，显示文字头像
      avatarLoadError.value = true
      avatarText.value = (profile.nickname || 'U').charAt(0)
    }
  } catch {
    // 加载失败，显示文字头像
    avatarLoadError.value = true
    avatarText.value = (profile.nickname || 'U').charAt(0)
  }
}
```

## 十四、已知限制

1. **背景存储**：自定义背景仅存储 DataURL，未上传到服务器，清理浏览器数据会丢失
2. **头像裁切**：当前使用简单的预览裁切，未实现复杂的拖拽缩放
3. **账号安全**：密码修改、邮箱验证需跳转独立页面，未实现弹窗内操作
4. **作品管理**：仅支持修改可见性和删除，不支持编辑已发布内容
5. **分页加载**：滚动加载更多基于 IntersectionObserver，极端情况下可能需要手动刷新
6. **历史记录**：观看历史仅保留最近 30 天，更早的记录会被清理
7. **弹窗交互**：关注/粉丝弹窗内容较多时需要滚动，无分页加载更多
8. **数据同步**：个人资料修改后需手动刷新广场页面才能看到最新信息
