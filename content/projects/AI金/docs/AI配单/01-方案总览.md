# AI 配单方案总览

> 最后更新：2026-07-22
> 状态：已重写为 LLM 直通架构

## 一、架构定位

AI 配单是「智能采销」场景下的核心能力：用户用一句自然语言描述采购需求（如「无锡 304 2B 1.2mm 50 吨 预算 14500」），系统自动完成 **需求解析 → 商品搜索 → 匹配评分排序 → 结果展示** 的全流程，并把 Top 3 商品以雷达图 + 推荐理由的形式呈现给采购员。

当前实现采用 **LLM 直通架构**：不依赖独立的规则引擎做确定性匹配，而是由阿里云百炼的 `qwen-turbo` 模型统一承担「自然语言解析」与「候选商品评分排序」两件事。规则匹配的复杂判断（厚度公差、品牌加权、地域距离、面议价格处理等）全部通过 prompt 评估要点交给 LLM 完成约束。

## 二、整体流程

```
用户输入自然语言
      │
      ▼
┌──────────────────────────┐
│ ① AI 解析 (parse-enquiry) │  qwen-turbo 提取材质/表面/规格/预算/城市等结构化参数
└──────────────────────────┘
      │
      ▼
┌──────────────────────────┐
│ ② 表单确认 / 修改          │  解析结果回填表单，用户可校正后触发搜索
└──────────────────────────┘
      │
      ▼
┌──────────────────────────┐
│ ③ 搜索商品 (queryXiuma)    │  调用秀玛商品搜索 API 拉取候选列表
└──────────────────────────┘
      │
      ▼
┌──────────────────────────┐
│ ④ AI 评分排序 (score-matches)│ qwen-turbo 给出 Top 3 + 4 维 100 分制评分 + 推荐理由
└──────────────────────────┘
      │
      ▼
┌──────────────────────────┐
│ ⑤ 结果展示                │  雷达图 + 推荐理由 + 得分明细
└──────────────────────────┘
```

## 四、关键设计决策

### 为什么用 LLM 评分，而不是规则引擎？

历史上曾规划「规则引擎做确定性匹配 + AI 外壳」的架构，实际落地后改为 LLM 直通，原因如下：

1. **软性规则难形式化**：厚度 ±0.3mm 公差属正常、知名大厂（太钢/宝钢/张浦）加分、本地仓库优于跨省、面议价格无法判断性价比……这些判断在规则引擎里需要大量 if/else 与权重调参，维护成本高；而 LLM 通过 prompt 描述即可稳定遵循。
2. **近似匹配优于精确相等**：材质/表面/规格的「完全匹配或近似匹配」用规则表达困难（如 `1.2*1219*C` 与 `1.2mm 1220` 的等价判断），LLM 具备语义近似能力。
3. **自然语言推荐理由是刚需**：每条入选商品需要 50-80 字的口语化采购建议，涵盖规格匹配、价格对比、距离评估、库存情况四要素。规则引擎只能输出冷冰冰的分数，而 LLM 可一次性产出「评分 + 维度拆解 + 自然语言理由」。
4. **综合权衡能力**：价格低于预算但跨省、库存勉强够；或本地库存充足但价格超预算——这种多维权衡规则引擎难以给出统一排序，LLM 可综合四维给出 0-100 的总体匹配度。

### 取舍

- **延迟**：两次 LLM 调用（解析 + 评分）均为 `qwen-turbo` 同步快通道，单次通常秒级返回；评分接口在飞书妙搭网关 30s 超时内可完成。
- **稳定性**：LLM 失败时两端均有 fallback——后端 catch 返回前 3 条候选（score=0），前端 doSearch 再包一层 catch 兜底，保证页面不白屏。
- **可观测**：所有 LLM 调用通过 `bailianService.askFastSync(prompt, [], 'session-tag')` 传入 topic 标签（`enquiry-parse`、`score-matches`）便于日志追踪。

## 五、与后续阶段的衔接

当前候选商品数组 **不含企业（Supplier）信息**，因此评分维度仅围绕商品本身的材质/价格/距离/库存。阶段六将在配单链路中注入 **企业曝光特权**（`priorityRecommend` 字段），让 VIP 企业的商品在评分排序中获得加权曝光。

详见 `../VIP系统/` 中 AI 配单曝光特权相关文档。
