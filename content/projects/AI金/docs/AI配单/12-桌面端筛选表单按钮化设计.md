# 桌面端 AI 配单筛选表单按钮化设计

> 日期: 2026-08-18
> 范围: `client/src/pages/AiStockPage.vue` 桌面端 `.filter-form` 区块(L57-89)及其 scoped 样式(L3036-3081)
> 关联: 对齐移动端抽屉已有的按钮单选交互(L575-720)

## 1. 目标

把桌面端高级筛选表单的控件形态从「文本框 + 下拉框」改造为「圆角按钮 toggle 单选/多选」,与移动端抽屉交互完全一致。仅改桌面端 form;移动端抽屉、AI Tags、NLP 解析、`doAnalyze` 提交逻辑、`editForm` 数据结构均不变。

桌面端 `.filter-form` 由 `v-show="filterExpanded && !isMobile"` 控制,仅桌面端显示,移动端走独立抽屉,二者天然隔离,互不影响。

## 2. 字段映射(桌面端 现状 → 改后)

| 字段 | 现状 | 改后(对齐移动端) |
|---|---|---|
| 快捷组合 | 无 | 新增 `QUICK_COMBOS` 按钮(同时设定材质+表面) |
| 材质 | 文本框 | `MOBILE_MATERIALS`(9)toggle 单选 |
| 表面 | 文本框 | `SURFACES`(6)toggle 单选 |
| 城市 | 下拉框 | `CITIES`(11)toggle 单选 |
| 钢厂 | 下拉框 | `FACTORIES`(18)toggle 单选,默认全部展开 |
| 品类 | checkbox 多选 | `CATEGORIES`(4)按钮 toggle 多选,复用 `toggleMobileCategory` |
| 厚度 | 数字区间输入框 | `THICK_PRESETS`(6)预设按钮 + 保留 min/max 输入框,复用 `toggleThickPreset` |
| 宽度 | 数字区间输入框 | 不变(移动端亦为纯输入框) |
| 重量 | `WEIGHT_SHORTCUTS` 按钮 + 输入框 | 保留(已是按钮形态),仅统一按钮选中样式 |
| 预算 | 数字输入框 | `BUDGET_PRESETS`(5)按钮,纯按钮、去掉数字输入框 |

复用常量:`MOBILE_MATERIALS`/`SURFACES`/`CITIES`/`FACTORIES`/`CATEGORIES`/`THICK_PRESETS`/`BUDGET_PRESETS`/`WEIGHT_SHORTCUTS`/`QUICK_COMBOS`(均已在文件内定义)。

## 3. 布局

- 现状 `.filter-form` 是 `display: grid; grid-template-columns: repeat(8, 1fr)`,为紧凑 input/select 设计。
- 改为 **纵向字段块堆叠**:`display: flex; flex-direction: column; gap`。每个字段块结构:`label`(上)+ `filter-chips` 按钮组(`flex-wrap`,下),与移动端抽屉结构一致;桌面端宽度让按钮组横向排开更宽松。
- 这是对 8 列网格的有意替换,由控件形态变化驱动(按钮组不适合塞进 8 列单格),非无关重构。
- 操作按钮(清除 / AI 智能配单)保持在 `.filter-form` 外的 `.panel-actions`,不动。

## 4. 样式

- 新增 `.filter-field`(字段块:纵向 label+chips)、`.filter-chips`(按钮容器 flex-wrap)、`.filter-chip`(单按钮:圆角、未选中 `bg + border`、选中 `bg-brand + 白字`,对齐移动端 `bg-brand text-white`)。
- `.filter-chip.active` 与 `.weight-shortcut.active` 统一为「填充品牌色 + 白字」选中态,保证表单内所有按钮视觉一致。
- 移除/调整不再使用的 8 列 grid 专属规则;保留 `.range-inputs`(厚度/宽度/重量输入框仍用)。
- 复用现有 scoped 变量:`--brand`/`--bg`/`--surface`/`--border`/`--text-secondary`/`--text-tertiary`/`--radius-md`。

## 5. 交互逻辑

- 材质/表面/城市/钢厂:内联 toggle,`@click="editForm.xxx = editForm.xxx === val ? '' : val"`(与移动端 L602/L616/L630 一致)。
- 快捷组合:`@click` 同时赋值 `material_code` + `surface_code`(与移动端 L588 一致)。
- 品类:复用 `toggleMobileCategory(c)`。
- 厚度预设:复用 `toggleThickPreset(tp)`。
- 预算:`@click="editForm.budget = editForm.budget === bp.value ? null : bp.value"`(与移动端 L716 一致)。

## 6. 能力变化(已与用户确认)

1. 材质/表面:自由文本 → 固定 9/6 按钮,列表外值(如 904L、304L)无法选。
2. 预算:自由数字 → 5 个预设按钮(1万/1.2万/1.5万/2万/2.5万),无法输入任意值。

用户已确认按「全部对齐移动端」执行,接受上述收窄。

## 7. 不改动的部分

## 8. 验证

- 桌面端展开筛选,各按钮 toggle 选中/取消正确;`editForm` 值与改动前同参数一致 → 查询结果一致。
- 回归:移动端抽屉不受影响。
- 响应式:窄屏走移动端抽屉,桌面 form 不显示,无影响。
