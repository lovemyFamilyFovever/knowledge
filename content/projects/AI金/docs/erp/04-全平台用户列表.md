# 04-全平台用户列表

> 版本: v1.1 | 日期: 2026-08-12 | 状态: 已实现

## 一、目标

为 ERP 后台提供全平台用户管理功能，支持查看所有注册用户、筛选搜索、查看用户详情（购买记录、成员关系），并支持导出用户数据。

## 二、功能范围

- 用户列表：分页展示昵称与完整手机号，支持关键词搜索、平台筛选、套餐等级筛选、购买状态筛选、日期范围筛选
- 用户详情：顶部展示昵称与完整手机号，并保留用户ID、平台、手机号、邮箱等详细字段
- 数据导出：全量导出 / 单用户导出为 Excel

## 三、数据来源

用户数据从飞书 Bitable 的 VIP用户表、VIP购买记录表、VIP成员关系表 三表聚合查询，不依赖本地数据库。

详见 `../VIP系统/02-多维表格设计.md`。

## 四、后端实现

### 4.1 文件

```
erp/server/
├── erp-vip-admin.service.ts    ← 用户聚合查询逻辑
├── erp-vip-admin.controller.ts ← API 接口 + Excel 导出
├── erp-vip-admin.dto.ts        ← 查询参数类型定义
```

### 4.2 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/erp/vip-admin/users` | 用户列表（分页+筛选+排序） |
| GET | `/api/erp/vip-admin/users/:userId/purchases` | 用户购买记录 |
| GET | `/api/erp/vip-admin/users/:userId/members` | 用户成员关系 |
| GET | `/api/erp/vip-admin/export-all` | 导出全量用户 Excel |
| GET | `/api/erp/vip-admin/export/:userId` | 导出单用户 Excel（含购买记录+成员关系） |

### 4.3 查询参数（GET /users）

| 参数 | 类型 | 说明 |
|------|------|------|
| page | number | 页码（默认 1） |
| pageSize | number | 每页条数（默认 20） |
| keyword | string | 关键词搜索（用户ID/昵称/手机号/企业名称） |
| platform | string | 平台筛选 |
| packageLevel | number | 套餐等级筛选（0-7） |
| purchaseStatus | string | 购买状态：all / active / expired |
| startDate | string | 购买日期范围-开始 |
| endDate | string | 购买日期范围-结束 |
| sortBy | string | 排序字段：purchaseDate / packageLevel |
| sortOrder | string | 排序方向：asc / desc |

## 五、前端实现

### 5.1 文件

```
erp/vip-admin/
├── index.vue      ← 页面主体（左侧用户列表 + 右侧详情面板）
├── UserList.vue   ← 用户列表组件（分页+筛选）
├── api.ts         ← API 调用
```

### 5.2 页面布局

- 左侧面板（560px 固定宽度）：用户列表 + 筛选条件 + 分页
- 右侧面板（flex: 1）：用户详情（购买记录 + 成员关系）

### 5.3 侧边栏

位于「运营管理」分组下，菜单项「VIP用户管理」，路由 `/erp/vip-admin`。
