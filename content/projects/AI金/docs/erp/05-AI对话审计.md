# 05-AI对话审计

> 版本: v1.0 | 日期: 2026-07-27 | 状态: 已实现

## 一、目标

为 ERP 后台提供 AI 对话质量审计能力，支持管理员查看真实对话记录、进行质量评估标注、分析对话趋势，持续优化 AI 回答质量。

## 二、功能范围

- 对话记录浏览：查看历史对话记录，支持筛选和搜索
- 对话详情查看：展开单条对话，查看完整问答内容
- 质量评估标注：对对话进行质量评分和标注
- 批量测试：创建批量测试任务，评估 AI 回答质量
- 数据导出：导出对话记录和评估结果

## 三、实现位置

### 3.1 后端

AI 对话审计的后端接口在 `server/modules/ai/` 中（非 erp/server/），与 AI 问答服务共享模块。

### 3.2 前端

```
erp/ai-qa-optimization/
├── index.vue      ← 主页面（对话列表 + 详情面板 + 批量测试）
├── api.ts         ← API 调用
└── types.ts       ← 类型定义
```

### 3.3 侧边栏

位于「系统管理」分组下，菜单项「AI问答测试看板」，路由 `/erp/ai-qa-optimization`。

## 四、页面功能

### 4.1 对话记录浏览

- 对话列表展示：用户、问题摘要、回答摘要、时间、来源
- 支持筛选条件：日期范围、用户、关键词搜索
- 分页加载

### 4.2 对话详情

- 展开单条对话查看完整问答内容
- 显示 Token 消耗、模型信息、响应时间
- 支持质量评分和标注

### 4.3 批量测试

- 创建测试任务：选择测试问题集，指定模型和参数
- 查看测试结果：对比不同参数下的回答质量
- 批量导出测试结果

## 五、关联文件

- `server/modules/ai/ai.controller.ts` — AI 问答接口（后台复用的 API）
- `erp/ai-qa-optimization/index.vue` — 前端页面
- `erp/ErpLayout.vue` — 侧边栏菜单项
