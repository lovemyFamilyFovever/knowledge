# 02-订单管理与营收报表

> 版本: v1.2 | 日期: 2026-07-27 | 状态: 已实现

## 一、目标

为 ERP 后台新增「订单管理」和「营收报表」两个核心功能模块，实现对 VIP 套餐购买订单的全生命周期管理和营收数据分析。

## 二、功能范围

### 2.1 订单管理

| 功能点 | 说明 |
|--------|------|
| 订单列表 | 分页展示所有购买订单，支持搜索/筛选/排序 |
| 订单详情 | 查看订单完整信息（购买者、套餐、金额、支付方式、状态等） |
| 手动创建订单 | 管理员为用户手动开通套餐（线下支付/人工开通） |
| 订单状态变更 | 标记退款、取消订单等状态变更 |
| 导出订单 | 导出筛选后的订单列表为 Excel |

### 2.2 营收报表

| 功能点 | 说明 |
|--------|------|
| 收入总览 | 总营收、本月营收、今日营收、订单数等核心指标 |
| 收入趋势 | 按日/周/月展示收入趋势折线图 |
| 套餐销量 | 各套餐的销量和金额分布（柱状图/饼图） |
| 支付方式分布 | 支付宝/微信/银联/线下的金额占比 |
| 同比环比 | 本月 vs 上月、本月 vs 去年同期的对比分析 |

## 三、数据模型

### 3.1 现有表结构复用

**复用现有的飞书 Bitable（VIP购买记录表），无需新增字段：**

| 字段名 | 类型 | 用途 |
|--------|------|------|
| 订单编号 | 文本 | 业务主键 |
| 登录名 | 文本 | 购买者标识 |
| 套餐名称 | 文本 | 套餐名 |
| 购买价格（分） | 数字 | 金额（分） |
| 购买日期 | 日期 | 支付成功时间 |
| 到期日期 | 日期 | 套餐到期时间 |
| 状态 | 单选 | pending/active/cancelled/expired/**refunded** |
| 支付方式 | 单选 | alipay/wechat/bank/**offline** |

**关键逻辑：**

1. **手动创建订单**：
   - 校验用户是否存在
   - 校验用户是否已有有效套餐
   - 生成订单号（格式同普通订单）
   - 直接写入 `状态=active`，跳过支付流程

2. **营收统计**：
   - 从飞书 Bitable 批量拉取购买记录
   - 在服务端进行聚合计算（飞书不支持复杂聚合）
   - 可考虑增加缓存（TTL 5 分钟）

## 九、风险与注意事项

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 飞书 API 分页限制 | 订单量大时需多次请求 | 使用 `pageSize=500` 批量拉取，前端分页 |
| 营收统计性能 | 实时计算可能较慢 | 增加缓存层，5 分钟 TTL |
| 手动开通权限 | 普通管理员不应有此权限 | 后续实现角色权限管理（P3） |
| 退款状态歧义 | `refunded` 订单可能被误统计 | 营收统计排除 `refunded` 状态 |

## 十三、留存分析与流失预警（已实现）

> 状态：已实现 | 文件：`erp/server/erp-retention.*`

### 13.1 功能概述

对 VIP 套餐用户进行留存分析，监控即将到期用户和已过期高价值用户，提供流失预警。

### 13.2 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/erp/retention/overview` | 流失概览（总用户数、活跃数、7/15/30天到期数、高风险用户数） |
| GET | `/api/erp/retention/expiring?days=30` | 即将到期用户列表 |
| GET | `/api/erp/retention/expired-high-value` | 已过期高价值用户（未续费） |
| GET | `/api/erp/retention/churn-trend?months=12` | 流失率趋势（按月） |
| GET | `/api/erp/retention/renewal-stats` | 续费率统计 |
| GET | `/api/erp/retention/clear-cache` | 清除缓存 |

### 13.3 关键指标

| 指标 | 说明 |
|------|------|
| 活跃用户数 | 当前有有效套餐的用户数 |
| 7/15/30天到期数 | 未来 N 天内到期的用户数 |
| 高风险VIP数 | 已过期但未续费的高价值用户 |
| 流失率 | 本月到期用户中未续费的比例 |
| 续费率 | 上月到期用户中已续费的比例 |

### 13.4 前端

侧边栏路由：`/erp/retention-warning`，菜单项「留存分析与流失预警」。

### 13.5 关联文件

- `erp/server/erp-retention.service.ts` — 留存分析服务
- `erp/server/erp-retention.controller.ts` — API 控制器
