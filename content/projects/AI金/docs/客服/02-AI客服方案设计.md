# AI 客服方案设计

> 最后更新：2026-07-23

## 1. 概述

AI客服是与「人工客服（飞书 Bot）」互补的自动应答系统。当人工客服离线或排队时，AI客服可接管常见问题，降低人工压力。

### 范围限定

| 能力 | 说明 |
|------|------|
| 常见问题自动回复 | 套餐价格、功能说明、使用方法等 FAQ 类问题 |
| 上下文理解 | 基于当前会话历史给出连贯回答 |
| 转接人工 | 无法回答时无缝转接人工客服 |
| **不做** | 不替代人工处理投诉、退款、定制需求 |

## 2. 架构

```
网页访客 ←→ SSE ←→ ChatModule ←→ AI客服 (百炼 qwen-turbo)
                    ↓  (转人工)
                飞书 Bot → 人工客服
```

- 复用现有 `ChatModule` 的会话管理和 SSE 推送机制
- AI客服与人工客服在同一个会话通道，无缝切换

## 3. 实现方案

### 3.1 会话流程

```
访客发消息
  ├─ AI客服在线 → AI 直接回复（SSE 流式）
  ├─ AI客服离线 → 飞书 Bot 转人工客服
  └─ AI无法回答 → Bot 通知人工 + 回复访客"已转接人工"
```

### 3.2 AI 回复接入

在 `ChatService.sendToAgent()` 中增加 AI 分支：

```typescript
async sendToAgent(sessionId: string, message: string) {
  // 1. 判断是否启用 AI 客服
  if (this.aiEnabled) {
    const reply = await this.aiService.chat(sessionId, message)
    this.sseService.push(sessionId, { type: 'message', content: reply, role: 'ai' })
    return
  }
  // 2. 原有逻辑：转发飞书 Bot
  await this.feishuBotService.sendMessage(...)
}
```

### 3.3 System Prompt

```
你是不锈钢市场使用中心的 AI 客服助手。你的职责：
1. 回答用户关于平台功能、套餐价格、使用方法的常见问题
2. 如果用户问的是个性化问题（订单状态、退款、投诉等），告知用户已转接人工，不要自行回答
3. 保持礼貌、简洁，每次回答不超过 200 字
4. 基于当前会话上下文回答，不要重复已说过的内容

平台知识：
- 套餐：7档年费制（免费版/试用/入门版/标准版/专业版/旗舰版/尊享版）
- 功能：AI问答、AI测价、AI配单、智能采销、竞价排名（规划中）、企业AI等
- 共享账号：3/6/9个共享账号
```

### 3.4 转人工策略

| 条件 | 行为 |
|------|------|
| AI连续2次回答"无法回答" | 自动转人工 |
| 访客输入"人工"/"转人工" | 立即转人工 |
| 人工客服上线 | 接管当前会话，AI停止回复 |
