# 环境准备与配置指南

> 最后更新：2026-08-26

## 一、运行环境

| 项目 | 说明 |
|------|------|
| 操作系统 | Windows（本地开发） / Linux（部署） |
| 前端 | Vue 3 + TypeScript + Tailwind CSS v4 + ECharts |
| 后端 | NestJS + TypeScript + Drizzle ORM |
| 数据库 | PostgreSQL（历史价格表、库存表、`data_forecast`、`ai_token_records`） |
| 大模型 | 阿里云百炼：「千问」模型，compatible-mode API |

## 二、环境变量配置

在项目根 `.env` 中配置以下变量（`forecast.service.ts` 第 162-165 行读取）：

| 变量 | 默认值 | 用途 |
|------|--------|------|
| `BAILIAN_FORECAST_API_KEY` | 空 | 百炼 API Key（兼容模式） |
| `BAILIAN_FORECAST_APP_ID` | 空 | 百炼应用 ID |
| `BAILIAN_FORECAST_MODEL` | `qwen3.7-plus` | 预测模型名 |

> 读取优先级：`.env` 文件（`envFile.*`） → `ConfigService`。两份都为空时用默认模型名 `qwen3.7-plus`。

## 三、启动命令

项目根目录（Windows）使用 `cross-env` 设置环境变量：

| 命令 | 说明 |
|------|------|
| `npm run dev:server:win` | 启动后端开发服务 |
| `npm run dev:client:win` | 启动前端开发服务 |
| `npm run type:check` | TypeScript 类型检查 |
| `npx vite build` | 前端构建验证 |

> PowerShell 不支持 `set NODE_ENV=xxx && ...`，必须用 `cross-env`。

## 四、依赖服务

AI 测价运行依赖以下外部服务：

| 服务 | 用途 | 调用方式 |
|------|------|---------|
| 阿里云百炼（兼容模式） | 流式文本生成预测分析 | HTTP `compatible-mode/v1/chat/completions` |
| 51bxg API | 历史价格降级来源、库存、行业资讯 | `ProxyService`（`QueryCoilPriceInfo` / `PostQueryPriceList` / `PostIndexNews`） |
| PostgreSQL | 历史价格、库存、预测结果落库、Token 统计 | `DrizzleORM`（`DRIZZLE_DB` 注入） |
