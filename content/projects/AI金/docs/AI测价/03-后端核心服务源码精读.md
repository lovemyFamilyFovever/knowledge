## 二、核心数据流（predictWithExports）

`predictWithExports()` 是流式主流程，按阶段调用 `onProgress` 推送进度：

```
1. 并行采集（第 325-339 行）  Promise.all([fetchPriceData, fetchInventoryData, fetchNewsData])
2. 计算技术指标（第 351-357 行）
3. 构建 Prompt（第 360 行）
4. 百炼流式调用（第 442 行）  callBailianForecast(prompt, onChunk)
5. 解析结果（第 463 行）      parseForecastResult
6. 构建图表（第 464 行）      buildChartData
7. 计算预测因子（第 465 行）  buildPredictionFactors
8. 生成预测序列（第 466 行）  generatePredictions
9. 计算支撑阻力 + 落库       computeSupportResistance + persistForecast
```

## 四、百炼调用（callBailianForecast）

- **接口**：`https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`（第 148 行）
- **参数**：`stream: true`、`stream_options: { include_usage: true }`（第 1080-1081 行）
- **temperature**: `0.15`、`top_p`: `0.25`、`max_tokens`: `8196`
- **协议**：
  ```
  data: {"choices":[{"delta":{"content":"xxx"}}]}\n\n
  data: [DONE]\n\n
  ```
- **解析**（第 1127-1147 行）：按 `data:` 前缀分割 → 解析 JSON → 提取 `choices[0].delta.content`，捕获 `usage`。
- **封装**：`callBailianForecast` 返回 `{ text, usage }`，其中 usage 经 `extractForecastUsage` 拆分为 `{totalTokens, inputTokens, outputTokens, cachedTokens}`。

## 五、解析与兜底（parseForecastResult）

- 用正则提取 JSON，`JSON.parse` 后做字段校验。
- 缺失字段用兜底值填充；置信度映射（如 `0.82 → 4 星`）。
- 预测方向映射：`up → 涨`，`down → 跌`，`side → 平`。
- 预测 ID：`PRC-YYYYMMDD-6位随机数`。
- 完整解析失败时返回带默认值 / 空 `analysis` 的结构，避免前端白屏。

## 六、落库（persistForecast）

向 `data_forecast` 幂等写入：`forecastType='P'` + 同材质 + 同周期 + 同模型 + 状态 pending 时，先删除旧记录再写入，避免同一请求重复落库。

## 七、Token 统计

每次百炼调用后，通过 `extractForecastUsage` 上报 `ai_token_records`（按日 + 用户 + 分类聚合），用于测价 Token 用量监控。
