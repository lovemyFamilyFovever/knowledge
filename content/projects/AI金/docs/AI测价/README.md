## 架构一句话

```
用户选择钢种/周期 → ForecastService.predictWithExports()
    → 并行采集（历史价格 + 库存 + 行业资讯）
    → 计算技术指标（MA5/MA10/MA20 + 动量 + 波动率）
    → 构建 Prompt → 百炼兼容模式流式调用（qwen3.7-plus）
    → SSE（start / progress / chunk / done / error）
    → parseForecastResult 解析
    → buildChartData + generatePredictions 生成预测序列
    → 支撑位 = min(预测)、阻力位 = max(预测)
    → 前端 AiPredictPage 渲染 4 张图表 + 五层面分析
    → 落库 data_forecast（幂等）
```

## 路由速查

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/ai/v1/forecast` | POST | 同步预测，返回 `{ prediction, exports }` |
| `/api/ai/v1/forecast/stream` | POST | SSE 流式预测（页面实际使用） |
| `/api/ai/v1/forecast/export` | POST | 预测 + 8 个 JSON 导出文件 |
| `/api/ai/forecast-history` | GET | 历史预测结果（4 钢种每日价格） |

## 关键配置速查

| 配置项 | 值 |
|--------|-----|
| 百炼兼容接口 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` |
| 预测模型 | `qwen3.7-plus`（默认） |
| 请求参数 | `stream: true`, `temperature: 0.15`, `top_p: 0.25`, `max_tokens: 8196` |
| 页面路由 | `/#/ai/price` |
| 预测周期 | week 7 / month 30 / quarter 90 / halfyear 180 / year 365 天 |
| 支撑/阻力 | 支撑 = min(预测价格序列)，阻力 = max(预测价格序列) |
| 假进度爬升 | 每 1500ms +0.5%，封顶 80%（85% 后走最终爬升封顶 100%） |
