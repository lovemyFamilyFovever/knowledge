# 问题诊断与经验教训

> 最后更新：2026-08-26

## 一、往期预测结果走势图不更新

**现象**：`AI测价往期预测结果走势图` 停留在旧日期（如 8 月 5 日），新写入的 `历史预测结果.xlsx` 数据不显示。

**根因**：`AiPredictPage.vue` 缺少 `loadForecastHistory()` 调用，图表的 `forecastHistoryData` 一直使用静态兜底数据 `FORECAST_HISTORY_DATA`，未实时读取后端 `GET /api/ai/forecast-history`（该接口真实读取 Excel）。

**修复**：前端补充 `loadForecastHistory()`，通过 `ensureForecastHistoryLoaded()` 共享 Promise 避免重复请求；每次图表渲染前重新拉取最新数据。更新 Excel 后刷新页面即自动同步。部署需重新构建/重启前端与后端。

## 二、走势图横轴起始问题

**硬约束**：价格预测走势图横轴从预测日期前一天（当天）起，**仅显示当天及未来预测价格**，不显示更早历史日期。

**实现**：`renderChart` 用 `todayStr` 作为 X 轴起点，数据 `predData = [lastHistPrice, ...futurePreds]`，横向截断到 `todayStr + futureDates` 区间。

## 三、异常波动段剔除

**问题**：历史价格中存在异常大幅波动段（偶发错误报价），直接用会破坏曲线连续性。

**策略**：不在预测主流程硬删数据，而是多级过滤 + 曲线连续处理：

1. 数据获取层：51bxg 按材料基准价 ±25% 过滤；本地 DB 仅 `price > 0`。
2. 事件检测层：`<= 0` 不参与；局部极值偏离均价不足 1.5% 跳过。
3. 前端 `fixZeroValues` / 线性插值补齐 0 值，`connectNulls: false` 避免断点连成毛刺。

经验：**单个相邻点比较无法处理成簇异常点**，需多轮统计检测；3σ 方法对成簇异常无效，配合 MAD（中位数绝对偏差）作二次过滤。

## 四、AI 生成出入参偶发漂移

**现象**：依赖模型解析 `chartData.dates` 偶发生成畸形字符串（如单个含「到」的字符串），导致图表错乱。

**经验**：预测主流程的日期与价格序列改用**真实历史数据**（`buildChartData`），再用 `generatePredictions` 生成未来序列，不依赖模型直接产出的 chartData。

## 五、阶段性历史数据不足

`QueryPriceChart` API 仅返回少量历史（约 2 天），早期不足以支撑图表。后改用 `PostQueryPriceList` 拉取更长历史段。

## 六、路径强依赖

库存等文件路径使用 `path.resolve(__dirname, '../../../../docs/AI测价/...')` 而非 `process.cwd()`，避免因工作目录变化读取失败。

## 七、长期运行注意

| 项 | 建议 |
|----|------|
| 等待进度条 | 等待期用假进度保底，避免长周期预测被误判为卡死 |
| API 超时 | 预测接口不对百炼响应设超时，长周期（年/半年）耗时较长，前端提示耐心等待 |
| Token 统计 | 每次调用后上报 `ai_token_records`，便于监控成本 |
