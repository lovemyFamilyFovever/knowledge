# 数据获取与数据源指南

> 最后更新：2026-08-26
> 核心方法：`fetchPriceData` / `fetchInventoryData` / `fetchNewsData` / `loadInventoryData`

## 一、历史价格获取

### 优先级两级

```
① 本地数据库（4 张表，优先）
      │  查不到 / 为空
      ▼
② 51bxg API 降级（QueryCoilPriceInfo）
```

本地 DB 映射（`PRICE_DB_TABLE_MAP`）：

| 材质/表面 | 表名 | 库存列 | 价格列 |
|-----------|------|--------|--------|
| 304/2B | `price_taigangbuxiu_304_2b` | `kucun3042b` | `price` |
| 304/NO.1 | `price_baogangdesheng_304_no1` | `kucun304No1` | `price` |
| 430/2B | `price_ningbobaoxin_430_2b` | `kucun4302b` | `price` |
| 201J2/2B | `price_hongwang_201j2_2b` | `kucun201j22b` | `price` |

51bxg 产品 ID 映射（`COIL_PRICE_ID_MAP`）：`304/2B=1`、`304/NO.1=2`、`201J2/2B=3`、`430/2B=5`。

### 51bxg API 参数

| API | 用途 | 参数 |
|-----|------|------|
| `QueryCoilPriceInfo` | 历史价格 | `start_time`, `end_time`, `id`, `type=0` |
| `PostQueryPriceList` | 库存/价格列表 | `category`, `material`, `page=1`, `page_size=10` |
| `PostIndexNews` | 行业资讯 | `index_type='0'`, `keywords`, `page=1`, `page_size=10` |

### 日期范围配置（getDateRangeConfig）

| 参数 | 天数 | 标签 |
|------|------|------|
| 默认 / `week` | 7 | 未来7天 |
| `month` | 30 | 未来30天 |
| `quarter` | 90 | 未来90天 |
| `halfyear` | 180 | 未来180天 |
| `year` | 365 | 未来365天 |

## 二、库存数据

### 数据来源：`price_stock_wuxi`

来源标注为「细分钢种库存（AI 推测 · 无锡）」。列名映射（`INVENTORY_DB_COLUMN_MAP`）：

| 钢种 | 库存列 |
|------|--------|
| 304/2B | 冷轧·300系 × α(0.80) |
| 304/NO.1 | 热轧·300系 × α(0.80) |
| 430/2B | 冷轧·400系 × α(0.75) |
| 201J2/2B | 冷轧·200系 × α(0.68) |

- `loadInventoryData()`（第 747-780 行）：查询最近 4 周库存，拼装成文本注入 Prompt。
- `loadInventoryPressure()`（第 787-810 行）：最新周相对前 4 周均值的偏离，正 = 累库偏空，负 = 去库偏多。
- 库存推算系数 α 的行业依据见 [09-数据文件与知识库素材.md](./09-数据文件与知识库素材.md) 与 `docs/AI测价/库存推算占比系数依据.html`。

## 三、行业资讯

`fetchNewsData()` 通过 `PostIndexNews` 拉取近期行业资讯（`index_type='0'`），注入 Prompt 作为背景信息，帮助模型判断升跌的政策/事件因素。

## 四、成本结构

`getMaterialCostHint()` 返回钢种成本结构提示。成本支撑线 `MATERIAL_COST_FLOOR`（第 821-826 行）：

| 钢种 | 成本支撑线（元/吨） |
|------|-------------------|
| 304/2B | 14000 |
| 304/NO.1 | 13000 |
| 430/2B | 9500 |
| 201J2/2B | 7000 |

完整成本公式（每个钢种 / 加工费）见 `docs/AI测价/各钢种成本利润测算.docx`（整理版见 [09-数据文件与知识库素材.md](./09-数据文件与知识库素材.md)）。

## 五、历史预测结果

`loadForecastHistory()`（第 873-909 行）读取历史预测结果数据（4 钢种每日价格：304/2B、304/NO.1、430/2B、201J2/2B），通过 `GET /api/ai/forecast-history` 提供给前端「往期预测结果走势图」与「价差走势图」。数据日常维护在 `docs/AI测价/历史预测结果.xlsx`。

## 六、数据合理性校验

| 校验点 | 规则 |
|--------|------|
| 价格合理性阈值 | 基准价 ±50%（不做删除，仅标记） |
| 单日跳变 | 单日涨跌幅 >8% 的记录标记、在后续分析中排除 |
| 缺失日期 | 需在报告中说明 |
| 非精确匹配 | 相近规格必须注明「非精确匹配，仅供参考」 |

## 七、产量与产能知识库（外部素材）

`docs/AI问答系统架构/知识库建设/正式知识库/产量与产能知识库.xlsx` 提供钢种月度产量、粗钢总量、产能历史数据，用于供 Prompt 或后续联动判断供需。当前 AI 测价预测主流程不依赖该表，属规划中的增量数据源。
