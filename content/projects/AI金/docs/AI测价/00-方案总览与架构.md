# AI 测价方案总览与架构

> 最后更新：2026-08-26
> 状态：SSE 流式架构（8 步细分思考 + 多因子预测）

## 一、架构定位

AI 测价是「AI 价格预测」场景下的核心能力：用户选择钢种与预测周期（近一周/一月/一季度/半年/一年），系统并行采集历史价格、库存快照、行业资讯，交给百炼大模型做 8 步细分思考分析，最终输出价格区间、趋势方向、波动率、支撑阻力位、操作建议、五层面深度分析，以及一条基于多因子生成的未来价格预测走势线。

当前实现采用 **SSE 流式架构**：后端 `ForecastService` 一步步推送思考进度（`fetch_data → compute_indicators → ai_analyzing → … → ai_analysis`），前端实时渲染思考过程卡片与进度条，最后一次性下发完整的 `ForecastResponse`。

它区别于同仓库的 `AI测价系统提示词.txt`（该文件定义的是一个「纯数据查询 + 格式化输出」的 DB 模块，见 [08-系统提示词与业务边界.md](./08-系统提示词与业务边界.md)）。本文档描述的是**实际运行在 `/#/ai/price` 的完整预测系统**。

## 二、整体流程

```
用户选择钢种 + 周期（或自然语言快捷提问）
      │
      ▼
┌────────────────────────────────────┐
│ ① 数据并行采集 (fetchPriceData)      │  历史价格(local DB/51bxg) + 库存 + 资讯
└────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────┐
│ ② 计算技术指标 (computeTechIndicators)│  MA5/MA10/MA20 + 动量 + 波动率σ
└────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────┐
│ ③ 构建 Prompt (buildForecastPrompt) │  注入价格/库存/资讯/指标/成本结构
└────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────┐
│ ④ 百炼流式调用 (callBailianForecast) │  qwen3.7-plus，compatible-mode SSE
└────────────────────────────────────┘
      │ ── 期间按阶段推送 progress 事件
      ▼
┌────────────────────────────────────┐
│ ⑤ 解析结果 (parseForecastResult)     │  价格区间/趋势/波动率/建议/5层分析
└────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────┐
│ ⑥ 构建图表 (buildChartData)          │  历史价格序列 + 重大事件节点
└────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────┐
│ ⑦ 生成预测序列 (generatePredictions) │  5 因子 + OU 随机游走 → 未来价格线
└────────────────────────────────────┘
      │
      ▼
┌────────────────────────────────────┐
│ ⑧ 支撑阻力 + 落库                   │  支撑=min(预测) 阻力=max(预测)，write data_forecast
└────────────────────────────────────┘
      │
      ▼
    前端 AiPredictPage 渲染 4 张图表 + 分析卡片
```

## 三、支撑位/阻力位口径

预测序列生成后，由 `computeSupportResistanceFromPredictions()` 从**预测价格序列**计算：

- **支撑位** = `Math.min(...predictions)`
- **阻力位** = `Math.max(...predictions)`

即使 Prompt 层要求 AI 输出 `supportResistance` 字段，最终展示仍以预测序列的 min/max 为准（代码会用预测序列结果覆盖）。

## 六、关键配置常量

| 配置 | 值 |
|------|-----|
| 百炼兼容接口 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` |
| 预测模型 | `qwen3.7-plus`（`BAILIAN_FORECAST_MODEL`） |
| temperature / top_p / max_tokens | `0.15` / `0.25` / `8196` |
| 最小波动宽度 | 周 1.5% / 月 3% / 季 5% / 半年 8% / 年 12% |
| 锚点融合 | `历史最新价 × 0.7 + AI基准价 × 0.3` |
| 成本支撑折算 | 跌破成本线部分按 30% 折算 |
| 每日预测价取整 | 50 的正整数倍数 |
| 历史价格过滤 | 51bxg 基准价 ±25%；DB 仅 `price > 0` |
| 事件检测窗口 | 前后 ±2 天，偏离均价 >1.5% |

## 七、与后续阶段的衔接

当前预测覆盖 4 个核心钢种（304/2B、304/NO.1、430/2B、201J2/2B），历史数据复用本地 PostgreSQL + 51bxg API 降级。后续可扩展更多牌号预测、接入产量/产能知识库（见 [09-数据文件与知识库素材.md](./09-数据文件与知识库素材.md)），并将预测结果用于 AI 采销策略联动。
