# 数据结构与接口

> 最后更新：2026-08-26
> 类型定义：后端 `ai.controller.ts` / `forecast.service.ts`；前端 `client/src/api/ai.ts`、`proxy.types.ts`

## 一、接口清单

| 接口 | 方法 | 入参 | 出参 | 说明 |
|------|------|------|------|------|
| `/api/ai/v1/forecast` | POST | `ForecastRequest` | `{ prediction, exports }` | 同步预测 |
| `/api/ai/v1/forecast/stream` | POST | `ForecastRequest` | SSE 流 | 流式预测（页面实际使用） |
| `/api/ai/v1/forecast/export` | POST | `ForecastRequest` | `{ prediction, exports }` | 预测 + 8 个 JSON 导出 |
| `/api/ai/forecast-history` | GET | 无 | `Array<ForecastHistoryRow>` | 历史预测结果 |

统一响应包装：`{ success: boolean, data?: T, error?: string }`。

## 二、ForecastRequest

```typescript
export interface ForecastRequest {
  category: string           // 品类，如 "卷"
  materialName: string       // 材质，如 "304"、"201J2"
  region?: string            // 地区，如 "无锡"
  surfaceName?: string       // 表面，如 "2B"、"NO.1"
  thickness?: number         // 厚度 mm
  width?: number             // 宽度 mm
  edge?: string              // 边部
  remark?: string            // 备注
  dateRange?: string         // week | month | quarter | halfyear | year
}
```

## 三、ForecastResponse

```typescript
export interface ForecastResponse {
  priceRange: {
    min: number; max: number; base: number; confidence: number
  }                                        // 价格区间 + 基准价 + 置信度
  trend: { direction: 'up' | 'down' | 'sideways'; reason: string }
  volatility: { level: 'high' | 'medium' | 'low'; description: string }
  supportResistance: {
    supportPrice?: number; resistancePrice?: number; description: string
  }
  recommendation: { action: 'buy' | 'hold' | 'sell' | 'watch'; reason: string }
  analysis: {
    overall: string
    costSupply: string        // 层面1 成本与供应
    demandDownstream: string  // 层面2 需求与下游
    policyMacro: string       // 层面3 政策与宏观
    marketSentiment: string   // 层面4 市场情绪
    inventoryAnalysis: string // 库存分析
  }
  predictionDate: string
  dateRangeLabel: string
  chartData: {
    dates: string[]
    prices: number[]
    predictions: (number | null)[]
    priceEvents?: PriceEvent[]
  }
  rawResponse: string
}
```

### PriceEvent

```typescript
interface PriceEvent {
  date: string
  price: number
  event: string                       // 事件描述
  type: 'surge' | 'plunge' | 'peak' | 'trough'
}
```

## 四、历史预测结果（ForecastHistoryRow）

```typescript
interface ForecastHistoryRow {
  date: string
  '304/2B': number
  '304/NO.1': number
  '430/2B': number
  '201J2/2B': number
}
```

例如：`{ date: '2026-07-17', '304/2B': 15500, '304/NO.1': 14400, '430/2B': 10450, '201J2/2B': 7900 }`。

## 六、8 个 JSON 导出文件（ForecastJsonExports）

`/export` 接口在 `prediction` 外额外返回 `exports`：

| 键 | 内容 |
|----|------|
| `prediction_result` | 预测结果（价格区间、趋势、波动率、支撑阻力、建议、情景分析） |
| `trend_signals` | 周期研判信号（大/小周期、策略、技术指标） |
| `factor_scores` | 多因子评分（供需/成本/趋势动量/情绪） |
| `risk_params` | 风控参数（保守/平衡/激进） |
| `price_chart` | 价格走势（历史/预测/SMA5/SMA10） |
| `firewall_status` | 三层防火墙状态（止损/止盈/时间止损） |
| `strategy_events` | 策略事件日志 |
| `performance_kpi` | 月度经营 KPI（预测统计/数据源） |

## 七、落库字段（data_forecast）

`persistForecast()` 写入关键派生值：

| 字段 | 值 |
|------|-----|
| 预测 ID | `PRC-YYYYMMDD-6位随机数` |
| 预测方向 | `up→涨 / down→跌 / side→平` |
| 置信度星级 | `0.82 → 4星` |
| 幂等条件 | `forecastType='P'` + 同材质 + 同周期 + 同模型 + pending |
