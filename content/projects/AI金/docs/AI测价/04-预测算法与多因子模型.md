## 二、5 类预测因子

`generatePredictions()` 综合 5 类因子（第 1621-1625 行注释）：

| 因子 | 来源 | 作用 |
|------|------|------|
| 预测基准价 | AI `priceRange.base` + 历史最新价 | 锚点融合 |
| 价格趋势 | AI `trend.direction` | 权重 50% |
| 历史价格 | 最新真实价锚点 + MA5/MA20 动量 | 权重 30% |
| 成本价格 | 行业成本支撑线 | 跌破成本按 30% 折算 |
| 库存量 | `price_stock_wuxi` 最新周 vs 前 4 周均值 | 权重 20% |

### 锚点融合（第 1656-1659 行）

```
anchor = 历史最新价 × 0.7 + AI基准价 × 0.3
```

### 区间宽度下限（第 1645-1646 行）

按周期强制最小波动宽度，防止预测线过于平直失真：

| 周期 | 最小波动宽度 |
|------|-------------|
| 周 | 1.5% |
| 月 | 3% |
| 季 | 5% |
| 半年 | 8% |
| 年 | 12% |

### 综合评分（第 1661-1668 行）

```
composite = 0.5 × trendScore + 0.3 × momentumScore + 0.2 × inventoryScore
```

范围 `[-1, 1]`：

- `trendScore`：`up=+1`，`down=-1`，其他 `0`
- `momentumScore`：MA5/MA20 偏离，±3% 封顶
- `inventoryScore`：累库/去库压力

## 三、随机游走生成模型（OU 过程）

`generatePredictions()` 用两级 Ornstein-Uhlenbeck（OU）过程生成每日预测价（第 1675-1724 行）：

| 机制 | 参数 | 说明 |
|------|------|------|
| 短期日噪 | `thetaShort = 0.35` | 记忆约 2~3 天 |
| 中期波段 | `thetaMid = 2.2/days` | 自适应记忆周期 |
| 波动聚集 | `volState` 对数随机游走 | 范围 `[0.5, 2.2]` |
| 偶发跳变 | 约 5% 概率 | 2~4 倍冲击（第 1713 行） |
| 软反射边界 | 非硬夹死 | 越界按超出量弹回 |
| 成本支撑 | 跌破成本部分按 30% 折算 | 第 1728-1731 行 |
| 价格取整 | 50 的正整数倍数 | 第 1738 行 |

## 四、支撑位/阻力位

`computeSupportResistanceFromPredictions()`（第 1757-1769 行）：

```typescript
const supportPrice = Math.min(...preds);   // 支撑位 = 预测序列最低价
const resistancePrice = Math.max(...preds); // 阻力位 = 预测序列最高价
```

> 即使 Prompt 让 AI 输出 `supportResistance`，代码仍用预测序列的 min/max 覆盖，保证图表与支撑阻力口径一致。

## 五、重大事件检测（detectPriceEvents）

行业事件知识库 `STEEL_EVENTS`（第 1443-1468 行）内置 21 条 2024-2026 年不锈钢行业重大事件，类型分 `surge`（暴涨）/ `plunge`（暴跌）/ `peak`（高点）/ `trough`（低点）。

检测规则：

| 规则 | 参数 |
|------|------|
| 局部高点/低点窗口 | 前后各 2 天 |
| 极值显著性 | 偏离均价 > 1.5% 才保留 |
| 连续上涨 | ≥3 天 且累计涨幅 >3% |
| 连续下跌 | ≥3 天 且累计跌幅 >3% |
| 排序与去重 | 按 significance 排序，同日期仅留最显著，间隔 ≥3 天 |
| 数量上限 | 最多 6 个 |

前端用 ECharts `markPoint` 的 `pin` 标记展示，标签截取前 15 字符，完整描述放 tooltip。颜色：大涨红 ↑、大跌蓝 ↓、高点琥珀 ↑、低点绿 ↓。

## 六、异常/毛刺数据过滤

多级过滤，逐层剔除异常价：

| 阶段 | 规则 |
|------|------|
| 数据获取 | 51bxg 数据按材质基准价 ±25% 过滤；本地 DB 仅 `price > 0` |
| 图表构建 | 负价过滤，用平均价兜底 |
| 事件检测 | `price <= 0` 不参与，数量不足 10 个直接返回空 |
| 连续涨跌段 | 遇 `<= 0` 提前终止该段检测 |
| 真实数据不足 | fallback 用 sin 函数 + 随机扰动生成波动 |
| 前端兜底 | 预测值 `>0` 过滤；0 值用前后有效值插值（`fixZeroValues`） |

## 七、8 个 JSON 导出文件

`buildJsonExports()`（第 1946-2612 行）生成 8 个导出文件：

1. `prediction_result` — 预测结果（产品、日期、价格区间、趋势、波动率、支撑阻力、操作建议、情景分析）
2. `trend_signals` — 周期研判信号（大周期/小周期/策略/技术指标）
3. `factor_scores` — 多因子评分（供需/成本/趋势动量/情绪）
4. `risk_params` — 风控参数（保守/平衡/激进）
5. `price_chart` — 价格走势数据（历史/预测/SMA5/SMA10）
6. `firewall_status` — 三层防火墙状态（止损/止盈/时间止损）
7. `strategy_events` — 策略事件日志（策略切换/场景触发）
8. `performance_kpi` — 月度经营 KPI（预测统计/数据源）
