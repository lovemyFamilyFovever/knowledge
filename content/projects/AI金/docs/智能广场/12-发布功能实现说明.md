## 一、功能概述

发布功能是 AI金 智能广场的核心入口，支持四种类型内容发布：视频、图文、文章、供需。

**核心能力：**
- 四种发布类型切换（含未保存内容确认）
- 媒体文件上传（图片压缩 AVIF/WebP、视频首帧截取）
- 草稿自动保存与恢复（IndexedDB + localStorage 混合存储）
- AI 辅助功能（智能标题/润色/扩写/封面推荐）
- 供需信息结构化表单与 AI 自动解析

**入口路由：** `/promo/plaza/publish`

**发布类型：**

| 类型 | Tab 标题 | 特殊处理 |
|------|---------|---------|
| `video` | 发布视频 | 阿里云 VOD 上传、截取首帧封面 |
| `image` | 发布图文 | 最多 9 张图片、AVIF/WebP 压缩 |
| `article` | 发布文章 | contenteditable 编辑器、10 种封面模板 |
| `demand` | 发布供需 | 结构化表单、AI 自动解析 |

```typescript
type PublishType = 'video' | 'image' | 'article' | 'demand'
```

## 四、媒体上传

### 4.1 图片上传流程

```
选择文件/拖拽 → 格式校验(JPG/PNG/WEBP) → 压缩(最大1920px, AVIF/WebP, 0.85) → 上传51bxg → 获取remoteUrl
```

**压缩逻辑：**
```typescript
async function compressImage(file: File): Promise<Blob> {
  const img = await createImageBitmap(file)
  const maxWidth = 1920
  const scale = Math.min(1, maxWidth / img.width)
  const w = Math.round(img.width * scale)
  const h = Math.round(img.height * scale)
  
  const canvas = new OffscreenCanvas(w, h)
  const ctx = canvas.getContext('2d')
  ctx.drawImage(img, 0, 0, w, h)
  
  // 优先 AVIF，降级 WebP
  try {
    return await canvas.convertToBlob({ type: 'image/avif', quality: 0.85 })
  } catch {
    return await canvas.convertToBlob({ type: 'image/webp', quality: 0.85 })
  }
}
```

### 4.2 视频上传流程

```
选择文件 → 格式校验(MP4/MOV/WEBM) → 截取首帧(0.1s位置, JPEG) → 压缩封面 → 上传阿里云VOD → 上传封面 → 获取videoId+coverUrl
```

**封面截取：**
```typescript
async function extractVideoCover(videoFile: File): Promise<Blob> {
  const video = document.createElement('video')
  video.src = URL.createObjectURL(videoFile)
  video.load()
  
  await new Promise(resolve => {
    video.onloadedmetadata = () => {
      video.currentTime = Math.min(0.1, video.duration * 0.1)
      video.onseeked = resolve
    }
  })
  
  const canvas = document.createElement('canvas')
  canvas.width = video.videoWidth
  canvas.height = video.videoHeight
  canvas.getContext('2d')!.drawImage(video, 0, 0)
  
  return canvas.toBlob({ type: 'image/jpeg', quality: 0.85 })
}
```

### 4.5 错误处理

- **压缩失败**：标记 `uploadError`，Toast 提示，支持删除重试
- **上传失败**：标记 `uploadError`，Toast 提示服务器返回错误
- **发布检查**：发布前检查是否有 `uploading` 或 `uploadError` 文件，阻止发布并提示
- **存储空间不足**：检查 IndexedDB 剩余空间，不足 10MB 时提示用户清理

### 4.6 文件操作

**删除单个文件：**
```typescript
function removeFile(index: number) {
  const file = uploadedFiles.value[index]
  if (file?.url?.startsWith('blob:')) URL.revokeObjectURL(file.url)
  if (file?.imageId) void deleteDraftImage(file.imageId)
  if (file?.coverImageId) void deleteDraftImage(file.coverImageId)
  uploadedFiles.value.splice(index, 1)
}
```

**清空所有文件：** 遍历所有文件执行相同的清理逻辑后，`uploadedFiles.value = []`

**切换类型时自动清理异类型文件：**
```typescript
const oppositeType = fileType === 'image' ? 'video' : 'image'
const oppositeIdx = uploadedFiles.value.findIndex(f => f.type === oppositeType)

```

## 五、草稿箱

### 5.1 混合存储方案

采用**混合存储**策略，兼顾数据持久化与用户体验：

| 存储内容 | 存储位置 | 说明 |
|---------|---------|------|
| 图片二进制 | IndexedDB (`draft_images`) | ArrayBuffer 格式 |
| 视频封面 | IndexedDB | 同上 |
| 视频文件 | 阿里云 VOD | 仅存 videoId |
| 元数据 | localStorage (`plaza_publish_drafts`) | JSON 格式 |

**存储优势：**
- IndexedDB 存储大量二进制数据，比 localStorage 容量大（通常 50MB+）
- localStorage 存储轻量元数据，读写快速
- 视频文件存储在云端，不占用本地存储空间

### 5.2 数据结构

```typescript
interface DraftItem {
  id: string              // 草稿唯一 ID（时间戳+随机数）
  type: PublishType
  title: string
  content: string         // 正文
  files: DraftFileItem[]  // 文件引用列表
  hashtags?: string[]
  visibility?: 'public' | 'private' | 'friends'
  aiHelpersUsed?: string[]
  savedAt: number         // 保存时间戳
}

interface DraftFileItem {
  id: string
  name: string
  type: 'image' | 'video'
  remoteUrl?: string      // 远程服务器 URL
  videoId?: string        // 阿里云视频 ID
  imageId?: string        // IndexedDB 存储 ID
  coverImageId?: string   // 封面 IndexedDB 存储 ID
  compressedUrl?: string  // 本地预览 URL（从 IndexedDB 读取生成）
  mimeType?: 'image/avif' | 'image/webp'
}
```

### 5.3 自动保存机制

**触发条件：** 标题、正文或文件列表变化时自动防抖保存。

**关键参数：**
- **防抖**：1 秒延时
- **检查**：上传中文件不触发保存
- **竞态保护**：`isSavingDraft` 防止重复保存，`isEditingDraft` 防止编辑时保存

**保存流程：**
```
saveDraft()
  │
  ├─ 1. 检查 isSavingDraft（防止并发保存）
  ├─ 2. 检查存储空间（不足 10MB 时提示）
  ├─ 3. 处理待上传图片（压缩后存入 IndexedDB，获取 imageId）
  ├─ 4. 组装 DraftItem（按 selectedType 过滤文件）
  ├─ 5. 写入 localStorage（超过 5 个草稿时删除最早的）
  ├─ 6. 更新保存时间显示
  └─ 7. 重置 isSavingDraft 状态
```

### 5.4 编辑草稿流程

```typescript
async function editDraft(draftId: string) {
  // 1. 设置编辑状态（防止自动保存竞态）
  isEditingDraft.value = true
  
  // 2. 读取草稿数据
  const drafts = loadAllDrafts()
  const draft = drafts.find(d => d.id === draftId)
  if (!draft) return
  
  // 3. 恢复基础信息
  selectedType.value = draft.type
  titleInput.value = draft.title || ''
  rawInput.value = draft.content || ''
  hashtags.value = draft.hashtags || []
  visibility.value = draft.visibility || 'public'
  
  // 4. 从 IndexedDB 读取图片并恢复
  const files = await Promise.all(
    draft.files.map(async f => {
      if (f.imageId) {
        const blob = await getDraftImage(f.imageId)
        return { ...f, url: URL.createObjectURL(blob), compressedBlob: blob }
      }
      return f
    })
  )
  uploadedFiles.value = files
  
  // 5. 恢复完毕，清除编辑状态
  isEditingDraft.value = false
}
```

### 5.5 草稿上限

- 每种类型最多 **5 个**草稿
- 超出时自动删除最早草稿（含清理 IndexedDB 图片）
- 存储 key: `plaza_publish_drafts`

**删除草稿：** 清理 DraftItem 中所有 imageId/coverImageId 对应的 IndexedDB 图片，然后更新 localStorage。

## 八、发布提交流程

### 8.1 完整流程

```
doPublish()
  │
  ├─ 1. 前置检查
  │   · 防重复提交（publishing 状态）
  │   · 检查是否有文件正在上传（uploading === true）
  │   · 检查是否有上传失败的文件（uploadError === true）
  │   · 未通过检查时 Toast 提示并 return
  │
  ├─ 2. 内容校验
  │   · 视频类型：必须有 videoId
  │   · 图文类型：必须有图片
  │   · 文章类型：编辑器必须有内容
  │   · 供需类型：content 必填，且不为空字符串
  │
  ├─ 3. 处理发布时间
  │   · now → 立即发布（scheduledTime = null）
  │   · today → 今日 23:59:00
  │   · tomorrow → 明日 09:00:00
  │
  ├─ 4. 处理封面（文章类型）
  │   · 如有自定义封面，上传到服务器获取 URL
  │   · 如有模板封面，上传生成的 JPEG 图片
  │
  ├─ 5. 上传图片（图文/文章类型）
  │   · 图文：压缩图片直接传 Blob 给接口
  │   · 文章：上传图片到 51bxg，获取 CDN URL
  │
  ├─ 6. 调用发布接口
  │   · video  → publishPlazaPost({ type: 'video', videoId, ... })
  │   · image  → publishPlazaPostWithImages({ type: 'image', images: Blob[], ... })
  │   · article → publishPlazaPost({ type: 'article', content: HTML, imagePaths, ... })
  │   · demand → publishPlazaDemand({ ...demandFields })
  │
  ├─ 7. 清理草稿
  │   · 删除已发布类型的草稿
  │   · 清理 IndexedDB 中对应的图片数据
  │
  └─ 8. 跳转
      · 成功：Toast 提示"发布成功" → 1.5 秒后跳转回广场首页
      · 失败：Toast 提示错误信息 → 保留当前页，用户可修改重试
```

### 8.2 发布条件汇总

### 8.7 Toast 提示系统

```typescript
// Toast 状态
const toastMsg = ref('')
const toastType = ref<'success' | 'error'>('success')
let toastTimer: ReturnType<typeof setTimeout> | null = null

// Toast 显示函数
function showToast(msg: string, type: 'success' | 'error') {
  if (toastTimer) clearTimeout(toastTimer)
  toastMsg.value = msg
  toastType.value = type
  toastTimer = setTimeout(() => {
    toastMsg.value = ''
    toastTimer = null
  }, 3000)  // 3 秒自动消失
}
```

**使用场景：**
- 文件校验失败：错误提示
- 上传失败：错误提示
- AI 调用完成：成功/错误提示
- 发布成功：成功提示
- 发布失败：错误提示

## 十一、已知限制

1. **图片格式**：仅支持 JPG、PNG、WEBP，不支持 BMP、TIFF 等格式
2. **视频格式**：仅支持 MP4、MOV、WEBM、3GP、AVI、MKV
3. **视频数量**：仅支持单个视频发布，不支持多视频
4. **图片数量**：最多 9 张，超出部分需分批次发布
5. **单张图片大小**：建议不超过 10MB（压缩后会更小）
6. **单视频大小**：建议不超过 500MB（阿里云 VOD 限制）
7. **AI 超时**：所有 AI 功能 15 秒超时，超时需手动重试
8. **草稿存储**：依赖浏览器 IndexedDB，清理浏览器数据会丢失草稿
9. **供需类型**：当前仅支持供应发布，需求发布待后续版本实现
10. **AI 封面**：模板封面仅支持文章类型，视频/图文类型使用 AI 智能匹配
11. **封面裁剪**：自定义封面自动裁剪为 4:3 比例，非此比例会被裁剪
12. **AI 功能隐藏**：供需类型页面不显示 AI 助手面板
