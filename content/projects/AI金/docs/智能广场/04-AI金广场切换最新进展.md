# AI智能伙伴切换至AI金数据库——最新进展
> 最后更新：2026-08-26

> 文档性质：历史切换阶段记录；当前实现以 01 概述、02 接口清单和代码为准  
> 适用范围：AI金项目中的AI智能伙伴、发布、评论、点赞、关注、图片与视频链路

## 一、当前结论

本次复核确认：广场当前帖子、图片索引、视频索引、评论、点赞、收藏、关注、通知和供需挂单均读取和写入 AI 金 PostgreSQL 的 `plaza_*` 表；不再通过 AI智能伙伴 `PostQueryContributeContent` 获取帖子，也不再通过 `AddNewsFlash` 发布帖子。本文件中其余“飞书多维表格”表述仅反映当时的过渡阶段，已不代表当前实现。

目前仍然保留的AI智能伙伴依赖只有以下几类：

1. AI智能伙伴账号和密码校验。
2. 图片文件上传及历史图片文件访问。
3. 阿里云VOD视频上传凭证、续期凭证和播放授权。
4. 部分历史头像、历史图片等静态资源地址。

除上述文件和认证能力外，帖子、图片索引、视频索引、评论、点赞、关注和问答等业务记录均以AI金数据库为准。

## 三、当前广场数据来源

广场页面不再直接读取AI智能伙伴帖子接口。AI金后端会按业务关系组合以下多维表格：

| 页面数据 | AI金数据表 | 主要关联字段 |
|---|---|---|
| 帖子正文和状态 | 投稿作品 | `NEWS_ID` |
| 作者昵称和头像 | 会员信息 | `MEMBER_CODE` → `MemberCode` |
| 帖子图片 | 作品图片 | `NEWS_ID` |
| 视频ID和视频信息 | 视频资源 | `FLASH_ID` → `ID` |
| 当前用户点赞状态 | 点赞记录 | `NEWS_ID` + `MEMBER_CODE` |
| 评论数量和评论列表 | 评论表 | `NEWS_ID` |
| 当前用户关注状态 | 关注关系 | `MemberCode` + `FOLLOW_MEMBER` |

作者展示名称按以下顺序回退：

1. `nickname`
2. `CustomName`
3. `RealName`
4. 默认显示“AI智能伙伴”

广场仅展示 `STATUS=10-正常展示` 的投稿。迁移的4,450条投稿中有9条删除状态数据，不在广场展示，因此正常可展示数量为4,441条。

## 四、发布链路

### 4.1 统一发布入口

前端发布统一调用：

```text
POST /api/plaza/posts
```

服务端从AI金签名会话中取得 `MemberCode`，然后根据发布类型写入不同表格。

| 发布类型 | 投稿作品 | 作品图片 | 视频资源 | 51问答表 |
|---|---:|---:|---:|---:|
| 文章 | 写入 | — | — | — |
| 图片 | 写入 | 写入 | — | — |
| 视频 | 写入 | — | 写入 | — |
| 问答 | 写入 | — | — | 同时写入 |

`NEWS_TYPE` 当前映射如下：

| 类型 | NEWS_TYPE |
|---|---:|
| 普通文章、图片、视频 | 1 |
| 问答 | 2 |

当前发布页面仅允许图片类型选择图片、视频类型选择视频；问答暂不支持媒体附件。后端字段保留了后续扩展空间，但不能把预留能力当成已经开放的前端功能。

### 4.2 投稿作品写入内容

新发布投稿会生成文本型业务ID，并写入以下核心字段：

- `ID`
- `NEWS_ID`
- `MEMBER_CODE`
- `NEWS_TYPE`
- `CONTENT`
- `CREATE_TIME`
- `OPERATOR`
- `STATUS=10-正常展示`
- `HIT_NUMS=0`
- `SPEC_ACTIV_ID=12`
- `EVENT_TYPE=0`
- `FLASH_ID`（视频帖使用）
- `NEWS_HIT=0`

长ID统一按文本保存，避免飞书数值字段发生精度丢失。

### 4.3 图片发布

图片采用以下链路：

```text
浏览器选择图片
→ AI金AI智能伙伴图片上传代理
→ AI智能伙伴图片服务器返回 IMAGE_PATH
→ 发布帖子
→ AI金“作品图片”表创建索引记录
```

“作品图片”表目前只有3个实际业务字段，新发布时全部保存：

| 字段 | 写入规则 |
|---|---|
| `ID` | AI金生成 `IMAGE-UUID` |
| `NEWS_ID` | 关联本次新投稿 |
| `IMAGE_PATH` | 保存AI智能伙伴图片服务器返回的路径 |

重要边界：

- 图片文件不存飞书素材空间。
- “作品图片”表不增加 `IMAGE_FILE` 附件字段。
- 服务端会校验新图片路径必须来自AI智能伙伴图片服务器。
- 旧媒体路径继续保留，不做批量替换。

### 4.4 视频发布

项目目前没有配置自有阿里云VOD，因此采用过渡方案A：

1. 使用AI智能伙伴 `CreateUploadVideo` 获取阿里云VOD上传凭证。
2. 浏览器通过阿里云VOD SDK直传视频。
3. 凭证过期时调用AI智能伙伴 `RefreshUploadVideo`。
4. AI金“视频资源”表保存 `VIDEO_ID` 和业务元数据。
5. 播放时通过AI智能伙伴 `PostVideoPlayAuth` 获取播放授权。

视频帖子正文和业务记录不会再写入AI智能伙伴帖子数据库，但视频文件及其授权链路暂时仍依赖AI智能伙伴。

## 五、登录与身份安全

登录流程当前为：

```text
用户输入AI智能伙伴账号密码
→ AI智能伙伴验证账号
→ AI金取得 MEMBER_CODE
→ AI金签发本地HMAC签名会话
→ 前端保存 auth_sessionToken
```

发布、评论、点赞和关注均只使用服务端会话中的 `MemberCode`。即使前端请求中伪造用户ID，后端也不会采用。

会话默认有效期为30天，可通过 `AI_JIN_SESSION_TTL_DAYS` 调整。签名密钥优先使用 `AI_JIN_SESSION_SECRET`，未配置时暂回退到 `FEISHU_APP_SECRET`。

旧版本已经登录的浏览器没有AI金签名令牌，升级后需要重新登录一次。

## 六、评论、点赞与关注

### 6.1 评论

评论接口：

```text
GET  /api/plaza/posts/:newsId/comments
POST /api/plaza/posts/:newsId/comments
```

当前规则：

- 必须登录后才能发布评论和回复。
- 评论内容为1至150字。
- 评论支持 2 级结构：一级评论 + 回复。回复通过 `parentCommentId` 关联，回复对象（`replyTo`）由父评论的 `MemberCode` 推导，不信任前端传入。
- 旧评论已迁移（720条，2026-08-02），评论表已重建为旧平台字段结构。
- 新评论状态写为 `10-正常`。
- 评论列表根据 `MemberCode` 补充会员昵称和头像，并返回当前登录用户的点赞状态 `is_liked`。
- 评论点赞记录写入独立的「评论点赞记录」表，取消点赞删除记录，并重算回写评论表 `LikeCount`。

详情页性能已做过一次优化：详情查询不再预读评论表，评论只通过评论接口读取一次；从广场列表进入详情时会复用帖子缓存，评论在后台独立加载。

### 6.2 点赞

接口：

```text
POST /api/plaza/posts/:newsId/like
```

同一接口执行点赞或取消点赞。新增点赞时写入“点赞记录”，取消时删除对应记录，并重新计算、回写投稿的 `HIT_NUMS`。

### 6.3 关注

接口：

```text
POST /api/plaza/members/:memberCode/follow
```

同一接口执行关注或取消关注。服务端拒绝用户关注自己。新增关注写入“关注关系”，默认 `FGROUP_ID=0`。

## 七、列表与详情性能

最初实现曾对投稿、会员、图片、视频、点赞、关注和评论进行全表读取，首次请求会超过120秒。当前已改为：

1. 投稿按页查询。
2. 仅查询当前页涉及的会员编码。
3. 仅查询当前页涉及的 `NEWS_ID` 图片和评论。
4. 仅查询当前页涉及的 `FLASH_ID` 视频。
5. 关联查询并行执行。
6. 详情页跳过评论预读，避免评论表重复查询。
7. 从列表进入详情时复用前端帖子缓存。

本地只读联调结果曾测得：

- 广场分页查询从超时优化到约1.3秒。
- 直接详情查询约1.26秒。
- 空评论列表查询约0.57秒。

这些数据仅代表本地到飞书开放平台的测试环境，飞书生产环境、网络状态和图片服务器状态会影响最终耗时。

## 八、环境变量与代码位置

`.env` 已配置统一的 `BITABLE_MAIN_APP_TOKEN` 和13张表的 `TABLE_ID`。主要变量以 `BITABLE_PLAZA_*` 开头。

App Token 采用共享模式：AI金广场复用主应用 token（`BITABLE_MAIN_APP_TOKEN`，与反馈/统计/VIP/聊天记录同一应用），全部表ID已从 `.env` 的 `BITABLE_PLAZA_*_TABLE_ID` 读取，`server/modules/plaza/plaza.constants.ts` 中的固定值仅作本地兜底回退。

主要代码位置：

| 文件 | 职责 |
|---|---|
| `server/modules/auth/local-session.service.ts` | AI金签名会话 |
| `server/modules/auth/auth.service.ts` | AI智能伙伴登录后签发AI金会话 |
| `server/modules/plaza/plaza.controller.ts` | 广场HTTP接口 |
| `server/modules/plaza/plaza.service.ts` | 多维表格聚合、发布及互动逻辑 |

| `client/src/pages/plaza/PlazaPublishPage.vue` | 发布及图片、视频上传 |

## 九、当前已知限制

1. 视频上传和播放授权仍依赖AI智能伙伴。
2. 图片文件仍依赖AI智能伙伴图片服务器。
3. 登录验证仍依赖AI智能伙伴账号系统。
4. 收藏交互尚未接入新后端。
5. 问答表当前仅保存问题主体和采纳答案快照，没有独立答案明细表。
6. 代码需要同步至飞书运行环境后才会对线上页面生效。
