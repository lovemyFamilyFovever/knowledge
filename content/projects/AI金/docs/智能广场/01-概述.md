# 智能广场概述
> 最后更新：2026-08-26

智能广场是 AI 金内的行业内容与供需交流模块，面向不锈钢贸易商、加工商和行业分析人员，提供内容发布、搜索、互动、个性化推荐、个人主页、通知及供应挂单能力。

## 一、入口与页面

| 页面 | 路由 | 说明 |
|---|---|---|
| 广场主页 | `/promo/plaza` | 推荐、最新、供需信息流及搜索入口 |
| 发布内容 | `/promo/plaza/publish` | 发布文字、图文或视频内容 |
| 内容详情 | `/promo/plaza/post/:id` | 阅读、评论、点赞、收藏与关注 |
| 供需详情 | `/promo/plaza/demand/:id` | 供应挂单详情与智能匹配 |
| 用户主页 | `/user/:memberCode` | 用户资料、作品与关注关系 |
| 个人资料 | `/personal/profile` | 个人信息及我的作品、收藏、点赞和观看历史 |
| 分享页 | `/share/:newsId` | 免登录分享预览页 |

主页顶部公共入口为“推荐｜最新｜供需”。个人内容入口收纳在个人中心和头像个人卡片中，避免公共信息流混入个人筛选项。

个人内容入口统一使用 `/personal/profile`；旧的 `/personal/plaza` 路由已从路由表移除，个人资料页继续承载作品、点赞、收藏和观看历史。

## 二、主要能力

- 内容：发布文字、图文和视频帖子；可设置 `public`、`private`、`friends` 可见范围，作者可删除帖子或修改可见范围。
- 互动：帖子点赞、收藏、评论、评论点赞、关注/取消关注；评论为两级结构。
- 内容发现：搜索、输入联想、按相关度或最新排序；AI 可生成“猜你想搜”和搜索结果总结。
- 推荐：推荐流基于用户画像、近期行为、互动、作者关系、热度及时效排序；未登录或缺少信号时降级为热门与时效排序。
- 个人与消息：用户主页、我的作品/收藏/点赞/历史、关注与粉丝列表，以及互动通知的查询、未读统计和已读处理。
- 供需：当前仅支持供应挂单，可创建、编辑、删除、筛选、按材质匹配，并可由 AI 解析文本参数。

## 三、当前数据与依赖边界

广场业务数据存储在 PostgreSQL，主要使用 `plaza_posts`、`plaza_images`、`plaza_videos`、`plaza_likes`、`plaza_favorites`、`plaza_comments`、`plaza_comment_likes`、`plaza_follows`、`plaza_notifications`、`plaza_ai_helpers`、`plaza_demands` 等表；用户画像和行为数据分别来自 `user_profiles`、`user_behavior_records`、`user_recent_views`。

图片随帖子上传到 AI 金服务，并由 `/api/plaza/images/:rowId/:index` 提供读取。视频播放授权仍通过 51bxg 的只读代理获取；登录账号校验也仍复用既有 51bxg 能力。帖子、互动和供需业务记录不再写入飞书多维表格，也不回写 51bxg。

## 四、认证与安全

广场 API 默认需要 AI 金本地 HMAC 会话；当前代码明确标记为 `@Public()` 的只有图片读取接口 `/api/plaza/images/:rowId/:index`。分享页前端路由 `/share/:newsId` 虽在页面白名单中，但对应的 `/api/plaza/share/:newsId` 当前仍受全局 `AuthGuard` 保护，不能把“页面免登录”理解为“接口免登录”。服务端始终以会话中的 `MEMBER_CODE` 作为当前用户身份，不信任请求体中的用户标识。

飞书运行环境下，前端调用 `/api/*` 还必须通过统一请求封装附带 `x-suda-csrf-token`。
