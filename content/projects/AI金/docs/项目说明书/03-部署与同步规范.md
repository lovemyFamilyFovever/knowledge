## 同步范围

本地（`C:\Users\liuxi\Desktop\code`）与飞书工作台之间保持同步的目录：

```
client/      →  前端代码（src + index.html + public）
server/      →  后端代码（modules / common / database / main.ts / app.module.ts）
shared/      →  共享类型与工具（api.interface.ts / ai-chart.ts / ai-chat.ts / ai-display-sanitizer.ts）
erp/         →  ERP 后台（server + 各子页面）
.env         →  环境变量配置
```

**标准操作**：将上述目录和 `.env` 复制覆盖到飞书工作台对应位置，然后在飞书平台验证。

> **说明**：根目录 `package.json`、`vite.config.ts`、`tailwind.config.ts`、`tsconfig*.json`、`index.html`、`scripts/` 等构建相关文件也需随代码变更同步，确保飞书构建环境一致。

## 构建与发布（飞书/沙箱）

飞书平台构建链路由 @lark-apaas/fullstack-cli 模板驱动：

1. `scripts/build.sh`：安装插件 → 清 `dist/` → 生成 API/页面路由定义 → 并行构建 server + client（预留 8GB heap）→ 移动 HTML → 复制 `run.sh`/`.env` → `prune-smart.js` 裁剪依赖
2. `scripts/run.sh`：`cd dist && SERVER_PORT=8000 NODE_ENV=production node server/main.js`
3. `prune-smart.js`：用 @vercel/nft 追踪 `dist/server/main.js` 实际依赖，生成精简 `node_modules` 和 `package.json`
