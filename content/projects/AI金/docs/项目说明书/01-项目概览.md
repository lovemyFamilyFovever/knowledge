# 项目概览

> 最后更新：2026-08-02

---

## 产品定位

| 维度 | 说明 |
|------|------|
| 产品名称 | 不锈钢市场使用中心（AI金 · 不锈钢智能伙伴） |
| 产品类型 | 中后台管理系统 |
| 目标用户 | 不锈钢市场运营人员、行业分析师、管理人员 |
| 核心价值 | 提供 51bxg.com 和 xiuma.com 网站信息的每日早报式提炼展示 |
| 前端入口 | 根目录 `index.html`（`/client/src/main.ts`） |
| 后端入口 | `server/main.ts`（NestJS，端口 `SERVER_PORT`，默认 8000） |

## 样式体系

使用 Tailwind CSS v4 `@theme` 自定义语义色，定义在 `client/src/styles/tailwind.css`：

| 令牌 | 原始 HSL | 用途 |
|------|---------|------|
| `--color-brand` | hsl(174 55% 39%) | 品牌主色（按钮、链接） |
| `--color-brand-light` | hsl(174 50% 45%) | 品牌浅色（hover、渐变末端） |
| `--color-brand-lighter` | hsl(174 30% 90%) | 品牌极浅（侧边栏背景、hover 背景） |
| `--color-brand-bg` | hsl(180 14% 96%) | 页面/卡片背景 |
| `--color-brand-hover` | hsl(174 45% 34%) | 品牌深色（hover 状态） |
| `--color-text-primary` | hsl(216 24% 22%) | 正文主色 |
| `--color-text-secondary` | hsl(214 18% 40%) | 次要文本、标签 |
| `--color-text-muted` | hsl(215 16% 47%) | 弱化文本（占位符、禁用） |
| `--color-text-dark` | hsl(222 47% 11%) | 深色文本（标题、强调） |
| `--color-border` | hsl(206 15% 91%) | 分割线、边框 |
| `--color-success` | hsl(142 71% 45%) | 成功状态 |
| `--color-warning` | hsl(38 92% 50%) | 警告状态 |
| `--color-danger` | hsl(0 72% 51%) | 危险/删除状态 |

使用方式：`text-text-primary`、`bg-brand`、`border-border`、`hover:bg-brand-lighter`、`bg-brand/10`（支持透明度修饰符）。

**禁止使用 Tailwind 预设色**（如 `bg-blue-100`、`text-green-600`），必须使用上述语义色。

## 项目脚本工具

### 开发启动

| 命令 | 说明 |
|------|------|
| `npm run dev` | 默认开发入口（仅后端） |
| `npm run dev:server` | 后端开发（`cross-env NODE_ENV=development nest start --watch`） |
| `npm run dev:client` | 前端开发（`vite --config vite.config.ts`） |
| `npm run dev:local` | **本地一键启动前后端**（`scripts/dev-local.js`，concurrently 并行） |
| `start-local.bat` | Windows：杀 8000/5173 端口 → 启后端 → 启前端 → 打开浏览器 |

### 构建与校验

| 命令 | 说明 |
|------|------|
| `npm run type:check` | TS 类型检查（`type:check:server` + `type:check:client`） |
| `npm run build` / `npm run build:prod` | 全量构建（server + client） |
| `npm run eslint` | ESLint（`scripts/lint.js` 聚合 lint 入口） |
| `npm run stylelint` | CSS lint |
| `npm test` | jest（当前无任何 `.spec.ts`，命中为空） |

### scripts/ 辅助脚本

| 脚本 | 用途 |
|------|------|
| `dev-local.js` | 本地前后端并行启动（dotenv 加载 `.env.local` + `.env`） |
| `dev.js` | 沙箱/生产环境 dev 启动器（@lark-apaas/fullstack-cli 生成） |
| `dev.sh` / `build.sh` / `run.sh` | 飞书/沙箱的启动、构建、生产运行入口 |
| `restart-server.ps1` / `.sh` | 重启后端（杀占用端口进程 + 重新启动，默认 8000） |
| `prune-smart.js` | 智能依赖裁剪（@vercel/nft 追踪产物依赖，生成精简 node_modules） |
| `lint.js` | 聚合 lint（eslint + type:check + stylelint） |
| `init-token-bitable.mjs` | 初始化 Token 统计飞书多维表格 |
| `hooks/run-precommit.js` | pre-commit 钩子（跑 `npm run lint`） |
