## 一、AI 服务模块

### AI 问答（`/ai/qa`）

**功能概述**：基于百炼大模型的智能问答，支持快速模式和专家模式，SSE 流式输出，含思考过程、分析进度、关键词、结构化图表。

**技术要点**：
- 快速模式：qwen-turbo，支持多轮对话（最近 5 轮历史），`askFastStream`/`askFastSync`
- 专家模式：`PipelineService` 路由判断（行业/地域/品类）→ 允许联网搜索（`allowWebSearch`）→ 百炼 App API（`BAILIAN_APP_ID`，知识库）
- 结构化图表：`buildStructuredChartFromObservations` 根据 `toolObservations` 生成 line/bar/pie 图，模型自由生成的 ECharts 一律移除（`sanitizeAiAnswerCharts`）
- `sanitizeAiAnswerForDisplay` 移除内部实现细节后展示
- 关键词提取：快速模式（temp 0.1）提取 2–4 个关键词
- 反馈：点赞/点踩 + 二级原因标签（`feedback.service.ts` 写库 + 同步多维表格）

**关键文件**：
- `client/src/pages/AiQaPage.vue`、`composables/useChatSession.ts`、`composables/useChatHistory.ts`、`api/ai.ts`
- `client/src/components/chat/`（ChatMessages / ChatSidebar / ChatInput / ChatWelcome / ChatHistoryItem / BotMessage / UserMessage / AiAnswerFeedback）
- `server/modules/ai/ai.controller.ts`、`bailian.service.ts`、`pipeline.service.ts`、`analysis-progress.service.ts`、`ai-chart-builder.ts`、`feedback.service.ts`

### AI 价格预测（`/ai/price`）

**功能概述**：不锈钢价格预测，8 步细分思考流程 + SSE 流式输出（解决飞书妙搭网关 504 超时）。

**技术要点**：
- 8 步思考：市场数据采集 → 技术指标 → 价格区间 → 趋势研判 → 波动率 → 支撑阻力 → 操作建议 → 深度分析（对应字段级进度：marketData 35 → technical 48 → priceRange 55 → trend 55 → volatility 62 → supportResistance 70 → recommendation 78 → analysis 85 → predictionDate 95 → ai_parsing 97 → done 100）
- SSE 事件：`start` / `progress` / `chunk`（打字机）/ `done` / `error`，每 15s 心跳
- 模型：`BAILIAN_FORECAST_MODEL`（默认 `qwen3.7-plus`）
- 输出包含预测区间 + 3 层防火墙 + 因子评分 + 风控参数

**关键文件**：
- `client/src/pages/AiPredictPage.vue`、`api/ai.ts`（`forecastPriceStream`）
- `server/modules/ai/forecast.service.ts`、`ai.controller.ts`（`/api/ai/v1/forecast/stream`）

### AI 智能配单（`/ai/stock`）

**功能概述**：用自然语言描述采购需求，AI 解析为结构化参数并匹配最优货源。

**技术要点**（LLM 直通模式，无规则引擎）：
- `parse-enquiry-params`：LLM 解析材质/表面/规格/厂家/城市/预算等 → 结构化参数
- `score-matches`：LLM 对候选商品 4 维打分排序（materialMatch / priceAdvantage / locationMatch / stockLevel，各 0-100）
- 候选数据来自 xiuma 商品搜索（`queryXiumaProductSearch` → `PostQueryList`）
- 降级查询级别：0 精确 → 3 仅材质+表面；含 MarketOverview 市场概览

**关键文件**：
- `client/src/pages/AiStockPage.vue`、`api/ai.ts`（`parseEnquiryParams`/`scoreMatches`）、`api/proxy.ts`（`queryXiumaProductSearch`）
- `server/modules/ai/ai.controller.ts`

## 五、VIP 套餐与权限模块（`/vip`）

**功能概述**：套餐对比、我的套餐、购买流程、子账号管理。数据存飞书多维表格（6 张表）。

### 数据存储（飞书多维表格）

| 表 | 环境变量 | 说明 |
|----|---------|------|
| 用户表 | `BITABLE_VIP_USERS_TABLE_ID` | 登录名（MEMBER_CODE）、手机号、企业名称、资料 |
| 套餐表 | `BITABLE_VIP_PACKAGES_TABLE_ID` | 套餐（名称/等级/年费/最大账号数/包含能力） |
| 功能特性表 | `BITABLE_VIP_FEATURES_TABLE_ID` | 能力元数据（能力编号/名称/分类/权限类型/路由/特性Key） |
| 购买记录表 | `BITABLE_VIP_PURCHASES_TABLE_ID` | 购买/到期日期、状态、订单号 |
| 成员关系表 | `BITABLE_VIP_MAPPING_TABLE_ID` | 用户/购买记录/角色/状态 |
| 操作日志表 | `BITABLE_VIP_OPERATION_LOG_TABLE_ID` | VIP 管理操作日志 |

> 飞书不支持 JOIN，跨表关联分步查询；套餐/特性表数据量小，全表拉取后客户端过滤。

### 核心服务（VipService）

| 方法 | 说明 |
|------|------|
| `ensureUser(loginName, phone)` | 确保用户存在（先查后建） |
| `getUserPermission(memberCode)` | 用户完整权限（pageAccess/features/package，5 分钟缓存） |
| `checkEnterpriseFeature(enterpriseName, featureKey)` | 企业曝光特权检查（5 分钟缓存） |
| `getPackages()` / `getFeatures()` | 套餐/特性查询 |
| `getMyPackage(memberCode)` | 我的套餐 + 成员列表 |
| `createOrder({packageId, paymentMethod, memberCode, phone})` | 创建购买订单 |
| `getOrderStatus(orderId)` / `handlePaymentSuccess(orderId)` | 订单状态查询 / 支付成功处理 |
| `addMember / removeMember / toggleMember / getMembers / previewMember` | 子账号管理（含配额校验） |
| `getPurchases` / `getPurchaseDetail(orderNo)` | 购买记录 |
| `updateProfile(...)` / `getQuota(memberCode)` | 资料更新 / 共享名额 |

### 默认权限（免费用户）

可访问 `/ai/qa`、`/ai/stock`，其余页面不可访问（`DEFAULT_PAGE_ACCESS`）。

### 前端集成

- `client/src/stores/vip.ts`：`loadPermission` / `refreshPermission` / `canAccess(route)` / `hasFeature(key)` / `clear`，持久化到 localStorage
- `client/src/api/vip.ts`：`fetchVipApi` 封装，自动带 `x-user-id`（MEMBER_CODE）/`x-login-name` header
- 页面：`VipCenterPage.vue`（`?tab=packages` 对比矩阵 / `?tab=my` 我的套餐）、`PaymentPage.vue`（支付轮询）、`PaymentResultPage.vue`、`AgreementPage.vue`（商用授权协议）

### 身份识别

后端通过 header `x-user-id`（MEMBER_CODE）识别用户，`x-login-name`（手机号）用于业务参数。无 JWT，前端登录态存 localStorage。

## 六、认证模块（auth）

**功能概述**：独立认证路由 `/api/auth`，统一管理登录/注册/改密码/验证码，全部使用 AI金本地数据库。

**技术要点**：
- 存量用户首登校验 `legacy_password_hash`，成功后升级为加盐 `scrypt`
- 本地校验失败不调用 51bxg 兜底；代理入口同时拦截老认证方法
- 验证码只保存 HMAC 哈希，带过期、限发、失败次数和一次性消费
- 登录成功签发 `sessionToken`（`LocalSessionService`，HMAC-SHA256 + base64url，默认 30 天）
- 登录后联动 `VipService.getUserPermission`，`permission` 合并进返回 data
- 前端 `stores/auth.ts` 持久化 `auth_*`（含 `auth_sessionToken`），`isLoggedIn` 要求 loginName + sessionToken + 未过期

**接口**：POST `/api/auth/login|register|sms-code|forget-sms-code|edit-password`

**关键文件**：`server/modules/auth/`（controller / service / repository / password-hash / verification-code / local-session / dto）

> 完整说明见 `08-登录认证说明.md`。
