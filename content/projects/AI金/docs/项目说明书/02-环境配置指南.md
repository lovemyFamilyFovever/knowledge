## 环境对比总览

| 对比项 | 本地开发环境 | 飞书生产环境 |
|--------|-------------|-------------|
| 前端入口 | 根目录 `index.html`（`/client/src/main.ts`） | 同左（路径已统一） |
| 后端入口 | `server/main.ts` | `server/main.ts`（`configureApp`） |
| 后端端口 | `SERVER_PORT=8000` | 平台自动注入 |
| 前端端口 | 5173（Vite） | 平台托管 |
| `SUDA_DATABASE_URL` | 空 → `isLocal=true` | 自动注入 → `isLocal=false` |
| 飞书 PlatformModule | 跳过 | 加载（`@lark-apaas/fullstack-nestjs-core`） |
| 数据库 | 无本地库（走飞书多维表格云端 API） | PostgreSQL |
| 飞书多维表格 | ✅ 可直接调用（`BITABLE_*` 配置） | ✅ 可直接调用 |
| 构建配置 | 根目录 `vite.config.ts`（同一份，不区分环境） | 同左 |

> **关键变化**：项目已统一为「单份代码 + `isLocal` 判断」，不再维护本地/飞书两套 `app.module.ts`、`main.ts`、`vite.config.ts`。`client/index.html` 与根目录 `index.html` 的脚本路径都已固定为 `/client/src/main.ts`，两地一致。

### 飞书多维表格（BITABLE_*）

本地和飞书环境都通过 `FeishuBitableService`（@Global 模块）调用飞书多维表格 API，`BITABLE_*` 配置在两地一致。

| 业务 | 环境变量前缀 | 用途 |
|------|------------|------|
| AI 问答反馈 | `BITABLE_FEEDBACK_*` / `BITABLE_SITE_FEEDBACK_*` | 站点反馈同步 |
| 统计 | `BITABLE_STATS_*` | 页面访问/运营统计 |
| Token 统计 | `BITABLE_TOKEN_STATS_*` | Token 消耗统计 |
| VIP 套餐 | `BITABLE_VIP_*` | 用户/套餐/功能特性/购买记录/成员关系/操作日志（6 张表） |
| ~~数据大屏~~ | ~~`BITABLE_ACQUISITION_*` `BITABLE_SUCCESS_*` `BITABLE_KEY_ACCOUNT_*` `BITABLE_TARGET_*`~~ | ~~拓新/客户成功/大客户/月度目标~~（**已下线** 2026-08-18） |
| 店铺装修 | `BITABLE_STORE_DECORATION_*` | 店铺装修数据 |
| AI 广场 | `BITABLE_PLAZA_*` | 51用户/成员/帖子/图片/视频/点赞/收藏/关注/关注组/问答/评论（12 张表） |
| 聊天记录 | `BITABLE_CHAT_*` | 客服/问答聊天记录 |

> 各表 `TABLE_ID` 变量命名均为 `<业务前缀>_TABLE_ID`。`APP_TOKEN` 为共享模式：主应用（反馈/统计/VIP/AI广场/聊天记录）统一用 `BITABLE_MAIN_APP_TOKEN`。完整变量清单以 `.env` 为准。

## isLocal 机制

通过环境变量 `SUDA_DATABASE_URL` 区分运行环境：

```typescript
const isLocal = !process.env.SUDA_DATABASE_URL;
```

| 环境 | `SUDA_DATABASE_URL` | `isLocal` | 行为 |
|------|-------------------|-----------|------|
| 本地 | 空 | `true` | `main.ts` 走本地静态资源 + hbs 渲染；跳过 `PlatformModule` |
| 飞书 | 自动注入 | `false` | `main.ts` 调用 `configureApp(app, { disableSwagger: true })`；加载 `PlatformModule.forRoot()` |

**要点**：同一份代码复制到飞书后，`isLocal` 自动变为 `false`，无需修改代码。

## 本地启动

### 方式一：一键启动（推荐）

```powershell
npm run dev:local
# 或双击 start-local.bat
```

### 方式二：分开启动

```powershell
# 窗口 1 - 后端（8000）
npm run dev:server

# 窗口 2 - 前端（5173，/api 代理到 http://localhost:8000）
npm run dev:client
```

### 端口说明

| 服务 | 默认端口 | 说明 |
|------|---------|------|
| 前端（Vite） | 5173 | 配置在根目录 `vite.config.ts`，`/api` 代理到 8000 |
| 后端（NestJS） | 8000（`SERVER_PORT`） | 重启可用 `scripts/restart-server.ps1` |

### 端口冲突处理

```powershell
netstat -ano | findstr :8000
netstat -ano | findstr :5173
taskkill /PID <pid> /F
# 或直接运行 restart-server.ps1（自动杀 8000 占用并重启后端）
```

## 常见配置错误

### 修改 `.env` 后不生效

`.env` 修改后必须**重启后端服务**（`npm run dev:server` / `restart-server.ps1`）才生效。前端 `VITE_*` 变量由 Vite 在启动时读取，修改后需重启 `dev:client`。

### 本地访问飞书多维表格失败

本地调用多维表格依赖 `.env` 中的 `BITABLE_*_APP_TOKEN` / `BITABLE_*_TABLE_ID` 完整配置。缺失对应配置时，`FeishuBitableService` 相关业务会失败（如 VIP 权限查询），需补齐配置。

### 登录后权限为空

登录返回的 `permission` 由后端 `AuthService.login` 注入（依赖 `VipService` + 多维表格配置）。多维表格不可达时登录不阻塞，前端按免费用户处理（默认仅可访问 `/ai/qa`、`/ai/stock`）。
