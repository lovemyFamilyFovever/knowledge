## 三、联网搜索配置（v3.0 新增）

### 3.1 白名单机制

后端通过 `search-source-policy.ts` 对联网搜索来源做三层约束：

1. **域名白名单**：默认 `gov.cn / cninfo.com.cn / sse.com.cn / szse.cn / hkexnews.hk`
2. **扩展配置**：`BAILIAN_SEARCH_ALLOWED_DOMAINS`（逗号分隔，可加企业官网、行业协会）
3. **URL 校验**：`normalizeAllowedSourceUrl` 拒绝带账号/密码/非 80/443 端口/危险重定向参数的 URL；重定向参数（url/u/target/redirect 等）指向白名单外域名时拒绝

### 3.2 触发时机

当前 `decideAiQueryRoute()` 的所有路由均返回 `allowWebSearch=false`，因此正式问答链路不会启用百炼联网搜索；外部官方信息路由直接返回“暂未检索到可核实的公开信息”。白名单代码作为后续启用受控联网时的安全边界保留。普通不锈钢行情始终只走内部数据。

### 3.3 竞品约束

`filterAllowedSearchSources` 过滤后若无可核实来源，回答「暂未检索到可核实的公开信息」（`NO_VERIFIED_PUBLIC_INFO_MESSAGE`），不展示受限来源名称、链接、数据。

## 四、后端路由与图表（配合平台使用）

### 4.1 路由决策（ai-query-policy.ts）

| 路由 | 触发 | 平台侧行为 |
|------|------|-----------|
| data-capability-check | “AI金有没有/能不能查某数据” | 只核验登记的内部来源，返回四态结果 |
| internal-industry-news | 51bxg/不锈钢行业新闻资讯动态 | 强制只查 `erp_cms_article_data`，禁联网/知识库 |
| external-official-public-info | 政府/协会/上市公司公告 | 直接返回「暂未检索到可核实的公开信息」 |
| internal-market-data | 价格/行情/库存等市场问题 | 注入图表规则指令，意图 line/bar/pie |
| general | 材质知识等 | 透传，百炼自主决定 |

### 4.2 结构化图表（ai-chart-builder.ts）

- 平台**不需要**在回答中输出 ```` ```echarts ```` JSON
- 后端从工具调用结果（toolObservations）解析价格/占比数据，构建 `AiStructuredChart`（line/bar/pie）经 SSE `chart` 事件发送
- 模型自由输出的 ECharts 代码块会被 `sanitizeAiAnswerCharts` 移除
- 图表类型由 `price-chart-policy.ts` 判定：占比→pie，多口径对比→bar，趋势→line
- 价格趋势图、关键指标、正文核心数据表和一句话结论共用同一 canonical series
- 后端还会发送 `metrics` 与 `conclusion`，不需要平台生成对应 JSON

### 4.3 后端治理优先于平台 Prompt

调用百炼之前，`AiGovernanceService` 会先判定用户 INTERNAL/EXTERNAL 数据范围，拦截敏感数据和未授权能力；工具 observation、流式正文、最终文本和 references 仍会再次过滤。平台 Prompt 是行为指导，不能替代后端权限与内容治理。

## 六、API Key 管理

- 点击左侧菜单「系统设置」→「API Key管理」
- API Key 只配置在 `.env`，禁止提交到代码仓库、禁止写入前端代码
- 飞书应用凭证（`FEISHU_APP_ID`/`FEISHU_APP_SECRET`）同理，App Secret 与 tenant_access_token 禁止进入前端

## 七、调用统计与计费

- 平台「概览」页可看调用次数与 Token
- 后端 `token-record.service.ts` 会按「日期+用户+分类」聚合 Token 用量，并通过 PostgreSQL `ON CONFLICT` 原子写入 `ai_token_records`
- 查询：`GET /api/ai/token-stats/my`（前台）、`GET /api/ai/token-stats/all`（ERP）
