## 三、QU分类问题

### 3.1 意图分类不准确

**问题**：意图分类错误

**可能原因**：
1. 分类边界不清晰
2. Few-shot示例不足
3. 温度设置太高
4. 动态约束模板不匹配（v2.3新增）

**解决方案**：
```typescript
// 1. 明确分类边界
const INTENT_BOUNDARIES = {
  'QU01 vs QU03': 'QU01查具体价格，QU03查统计数据',
  'QU02 vs QU03': 'QU02涉及未来判断，QU03涉及历史/当前数据',
  'QU04 vs QU05': 'QU04企业/钢厂动态，QU05材料/工艺知识',
  'QU06 vs QU07': 'QU06找供应商，QU07办理交易服务',
};

// 2. 检查动态约束模板选择
const TEMPLATE_MAP = {
  'QU01': 'sql_execution_machine',
  'QU03': 'sql_execution_machine',
  'QU06': 'sql_execution_machine',
  'QU05': 'knowledge_base_retrieval',
  'QU07': 'knowledge_base_retrieval',
};

// 3. 增加Few-shot示例
// 4. 降低温度（0.1）
```

## 五、工具调用问题

### 5.1 工具调用失败

**问题**：工具调用失败

**可能原因**：
1. 工具定义错误
2. 参数格式错误
3. 数据库连接失败
4. 约束模板选择错误（v2.3新增）

**解决方案**：
```typescript
// 1. 检查工具定义
const toolDefinition = {
  name: 'get_price',
  description: '查询不锈钢价格',
  parameters: {...},
};

// 2. 检查参数格式
const params = {
  grade: '304',
  region: '无锡',
};

// 3. 添加错误处理
try {
  const result = await executeTool(toolName, params);
} catch (error) {
  console.error('工具调用失败:', error);
  return { error: '查询失败，请稍后重试' };

// 4. v2.3: 检查约束模板是否正确
const constraintTemplate = getConstraintTemplate(quResult.intent_primary);

  console.error('约束模板选择错误:', quResult.intent_primary);

```

### 5.2 工具返回空数据

**问题**：工具返回空数据

**可能原因**：
1. 查询条件过严
2. 数据库无数据
3. 参数错误
4. alias_map未正确标准化（v2.3新增）

**解决方案**：
```typescript
// 1. 放宽查询条件
const fallbackParams = {
  ...params,
  surface: undefined,  // 去掉表面限制
  thickness: undefined, // 去掉厚度限制
};

// 2. 检查数据库数据
const count = await countData(tableName);
if (count === 0) {
  return { error: '暂无数据' };
}

// 3. 检查参数

  return { error: '请指定钢种' };

// 4. v2.3: 检查alias_map是否正确标准化
if (!aliasMap[params.grade]) {
  console.error('钢种别名未找到:', params.grade);

```

### 5.3 工具调用超时

**问题**：工具调用超时

**可能原因**：
1. 数据库查询慢
2. 网络延迟
3. 数据量太大

**解决方案**：
```typescript
// 1. 添加超时控制
const timeout = 5000; // 5秒
const result = await Promise.race([
  executeTool(toolName, params),
  new Promise((_, reject) => 
    setTimeout(() => reject(new Error('超时')), timeout)
  ),
]);

// 2. 优化查询
// 添加索引
// 限制返回数量
// 缓存常用查询

// 3. 添加重试机制
const maxRetries = 3;
for (let i = 0; i < maxRetries; i++) {
  try {
    return await executeTool(toolName, params);
  } catch (error) {
    if (i === maxRetries - 1) throw error;
  }
}
```

## 六、模型输出问题

### 6.1 输出格式错误

**问题**：模型输出不是JSON格式

**可能原因**：
1. Prompt没有要求JSON格式
2. temperature太高
3. 示例格式不一致
4. 约束模板不匹配（v2.3新增）

**解决方案**：
```
# 输出（严格 JSON，禁止任何额外文字、解释、Markdown）
{
  "field": "value"
}

# 自我校验
1. JSON格式是否合法？
2. 检查约束模板是否与intent_primary匹配
```

### 6.2 幻觉问题

**问题**：模型编造数据

**可能原因**：
1. Prompt约束不足
2. 工具数据不足
3. temperature太高
4. 约束模板选择错误（v2.3新增）

**解决方案**：
```
# 约束
1. 基于工具返回的数据回答，不要编造数据
2. 如果没有数据，明确说明"未找到相关数据"
3. 不要猜测或推测
4. 根据intent_primary使用正确的约束模板
```

### 6.3 回答过于冗长

**问题**：回答太长

**可能原因**：
1. 未限制字数
2. 包含过多分析

**解决方案**：
```
# 回答规则
1. 回答简洁，不超过200字
2. 只回答核心信息
3. 不要过度分析
```

## 十三、FAQ

2. 分析错误原因
3. 优化Prompt或工具

2. 使用分隔符（;）分隔
3. intent_primary填主意图
4. intent_secondary填次意图
5. routing包含所有工具

1. 维护对话状态
2. 继承上一轮实体
3. 指代词消解
