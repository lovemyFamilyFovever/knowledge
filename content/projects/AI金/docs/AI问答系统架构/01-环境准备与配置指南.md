## 二、项目启动步骤

### 2.1 进入项目

在终端进入项目根目录（包含 `package.json` 的目录）。

### 2.2 安装依赖

```bash
npm install
```

### 2.3 配置环境变量

项目根目录下的 `.env` 文件已配置好，核心项如下（敏感值已脱敏）：

```env
# 服务端口
SERVER_PORT=8000

# Bailian (百炼) 主配置
BAILIAN_API_KEY=sk-****
BAILIAN_APP_ID=37f9b024dd594c06ae272228a421e03b   # aijin-qu Agent 2.0
BAILIAN_MODEL=qwen-plus
BAILIAN_ENABLE_WEB_SEARCH=false
BAILIAN_ENABLE_THINKING=true

# 测价专用配置
BAILIAN_FORECAST_API_KEY=sk-****
BAILIAN_FORECAST_APP_ID=edd37112268c4244857ba424fe583ccd
BAILIAN_FORECAST_MODEL=qwen3.7-plus

# Few-shot 知识库 ID（创建后填入）
BAILIAN_KB_ID=<Few-shot知识库ID>

# 联网搜索来源白名单（逗号分隔，可扩展企业官网/协会）
BAILIAN_SEARCH_ALLOWED_DOMAINS=gov.cn,cninfo.com.cn,sse.com.cn,szse.cn,hkexnews.hk

# 代理上游
BXG_API_HOST=https://www.51bxg.com
XIUMA_API_HOST=https://www.xiuma.com
XIUMA_API_PORT=443

# 登录鉴权
VITE_REQUIRE_AUTH=true
VITE_TOKEN_EXPIRE_DAYS=30

# 前端开关
VITE_SHOW_QUICK_MODE=true
VITE_SHOW_THINKING=true

# 遗留变量（无实际作用，路由在代码内硬编码）
AI_PIPELINE_MODE=simplified

# AI 思考展示：brief=简要阶段，original=内部受控原版思考
AI_THINKING_DISPLAY_MODE=brief

# 本地 PostgreSQL；飞书环境使用平台自动注入的 SUDA_DATABASE_URL
DATABASE_URL=postgresql://<user>:<password>@<host>:<port>/<database>
```

> `isLocal = !process.env.SUDA_DATABASE_URL`。本地由 `DatabaseModule` 使用 `DATABASE_URL` 和 `DRIZZLE_DB`；飞书环境由平台注入 `SUDA_DATABASE_URL`。聊天记录、Token 和反馈均写 PostgreSQL，不再依赖 Bitable 环境变量。

### 2.4 启动项目

```bash
# 方式1：前端 + 后端分别启动（两个终端）
npm run dev:server   # 后端（NestJS watch 模式）
npm run dev:client   # 前端（Vite）
```

> **注意**：PowerShell 不支持 `set NODE_ENV=xxx && ...`，npm scripts 已用 `cross-env` 处理。

### 2.5 访问项目

- 前端地址：http://localhost:5173（Vite 代理 `/api` → `http://localhost:8000`）
- 后端地址：http://localhost:8000
- AI问答页面：http://localhost:5173/#/ai/qa

### 2.6 类型检查

```bash
npm run type:check   # 前后端 tsc --noEmit
```

## 四、后端服务架构

### 4.1 AI 模块结构（server/modules/ai/）

```
├── ai.controller.ts           # 路由 /api/ai/*（chat/feedback/forecast/token-stats/tts/配单）
├── ai.module.ts               # 模块定义（providers/exports）
├── ai-batch-test.controller.ts# AI批量测试
├── ai-batch-test.service.ts   # AI批量测试服务
├── ai-query-policy.ts         # 四类路由决策（news/official/market/general）
├── price-chart-policy.ts      # 图表意图判定（line/bar/pie/none）
├── search-source-policy.ts    # 联网来源白名单过滤
├── config/search-source-allowlist.ts  # 默认白名单（gov.cn 等）
├── analysis-progress.service.ts      # SSE 阶段进度上下文
├── ai-chart-builder.ts        # 结构化图表构建
├── ai-data-insight-builder.ts # 关键指标和一句话结论
├── ai-governance.service.ts   # 权限、敏感数据和来源治理
├── data-capability-registry.ts# 内部数据能力核验
├── ai-thinking-display.service.ts # 简要/原版思考模式
├── bailian.service.ts         # 百炼API调用（askFast/askStream/TTS/关键词提取）
├── pipeline.service.ts        # 轻量路由编排（mode=query-policy）
├── feedback.controller.ts / feedback.service.ts  # 二级反馈
├── forecast.service.ts        # AI测价
├── chat-record.service.ts     # 聊天记录持久化（PostgreSQL）
└── token-record.service.ts    # Token 统计（PostgreSQL）
```

### 4.2 服务调用链路

```
用户请求（前端 SSE）
    ↓
ai.controller.ts POST /api/ai/chat
    ├── fast 模式 → bailianService.askFastStream（qwen-turbo）
    └── expert 模式 → pipelineService.process（治理 + 能力核验 + 路由）
                       → bailianService.askStream（百炼 App）
    → SSE：start / analysis_progress|thinking / delta|content
           / chart / metrics / conclusion / done
    → chatRecordService.saveChatRecord（异步持久化）
    → tokenRecordService.record（异步 Token 统计）
```

### 4.3 共享类型与清洗（shared/）

| 文件 | 内容 |
|------|------|
| `shared/ai-chat.ts` | progress、chart、metrics、conclusion、presentation 类型 |
| `shared/ai-chart.ts` | `validateAiChartOption`、`sanitizeAiAnswerCharts` |
| `shared/ai-display-sanitizer.ts` | `sanitizeAiAnswerForDisplay`（过滤 SQL/内部细节） |
| `shared/api.interface.ts` | 全局 API 类型（含 `CreateAiFeedbackRequest`） |

## 五、常见环境问题排查

### 5.1 npm install 失败

```bash
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### 5.2 端口被占用

```bash
netstat -ano | findstr :5173   # 前端
netstat -ano | findstr :8000   # 后端
taskkill /PID <进程ID> /F
```

### 5.3 百炼 API 调用失败

检查项：API Key、App ID（`BAILIAN_APP_ID=37f9b024…`）、网络、账户余额。

### 5.4 Agent 2.0 应用调用失败

检查项：应用 ID、数据连接器是否挂载、知识库是否创建并挂载、百炼控制台生效 Prompt 是否与仓库候选稿一致。

### 5.5 聊天记录不保存

- 未登录用户（无 `x-user-id` 或为 `anonymous`）不保存 —— 属预期行为
- 检查 `DATABASE_URL` / `SUDA_DATABASE_URL`、`ai_chat_records` 表和 `AiRepository` 注入
- 检查服务端 `MEMBER_CODE`，未登录或 `anonymous` 不保存
