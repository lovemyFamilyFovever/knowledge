# AI 问答系统技术总结

> 最后更新：2026-08-21  
> 当前状态：v3.0 增量架构，代码实现以本仓库为准

## 一、当前架构

```text
用户提问
  → AiController /api/ai/chat
  → PipelineService
      ├─ AiGovernanceService：权限、敏感数据、受限来源
      ├─ DataCapabilityRegistry：内部数据能力四态核验
      └─ ai-query-policy：新闻/官方/市场/通用轻量路由
  → BailianService
      ├─ 快速模式：qwen-turbo
      └─ 专家模式：百炼 Agent 2.0 + 工具 observation
  → 后端结构化层
      ├─ canonical 图表
      ├─ 关键指标
      ├─ 一句话 AI 结论
      └─ 正文治理和展示清洗
  → SSE + 前端任务级稳定渲染
  → PostgreSQL 持久化
```

## 二、当前核心能力

| 能力 | 当前实现 |
|---|---|
| 快速/专家双模式 | 快速通用问答 + 专家内部数据工具链 |
| 轻量路由 | 能力核验、内部新闻、外部官方、市场数据、通用 |
| 数据权限 | INTERNAL / EXTERNAL，失败按 EXTERNAL 收紧 |
| 数据能力核验 | FOUND / NOT_FOUND / NOT_SUPPORTED / PERMISSION_DENIED |
| 分析过程 | 默认简要阶段，内部受控原版思考 |
| 结构化回答 | chart + metrics + conclusion |
| 价格一致性 | 图表、指标、核心表和结论共用 canonical series |
| 流式稳定性 | 任务 ID 绑定、content 快照、pending 暂存、固定排序 |
| 内容安全 | 敏感数据、受限来源、SQL/表名/工具过程过滤 |
| 历史记录 | PostgreSQL 同步、摘要列表、消息懒加载、软删除、重命名 |
| 前端历史栏 | 搜索、批量管理、移动抽屉、桌面拖拽调宽 |
| 运营支撑 | PostgreSQL Token 聚合和回答二级反馈 |

## 三、最重要的数据原则

价格趋势不允许多个展示组件分别计算。`CanonicalPriceSeriesResult` 是单轮价格结构化回答的唯一事实源：

```text
canonical series → chart
                 → metrics
                 → 正文核心数据表
                 → conclusion
```

任何末值不一致都应阻止图表和价格指标发送，而不是在前端修补数字。

## 四、最重要的流式原则

SSE 事件到达顺序不等于页面展示顺序。前端以生成任务为边界暂存 chart/metrics/conclusion，以 `BotMessage.vue` 的固定区域排序；`content` 只校正正文，不能替换消息对象。

所有结构化事件必须在 `done` 前完成，`done` 后不允许补发。

## 五、最重要的安全原则

1. Prompt 约束不能替代后端权限和输出过滤。
2. 未登录或权限失败按 EXTERNAL 处理。
3. 数据能力 FOUND 必须来自有效内部 observation。
4. 受限第三方来源过滤覆盖工具结果、正文流、最终文本和引用。
5. 模型自由 ECharts、SQL、工具参数和查询过程不进入正式界面。

## 六、数据存储

| 表 | 用途 |
|---|---|
| `ai_chat_records` | 一问一答、模式、Token、结构化展示 JSON、软删除状态 |
| `ai_token_records` | 按日期 + 用户 + 分类聚合 Token |
| `ai_feedbacks` | 点赞/点踩、标签和文本反馈 |
| `plaza_ai_helpers` | 智能广场发布时汇总的 AI 辅助记录 |

早期文档中的 Bitable 正式存储方案已经废弃。

## 七、Prompt 与百炼配置说明

- 专家模式使用 `BAILIAN_APP_ID` 指向的百炼 Agent 2.0 应用。
- 仓库保留 v11、v13 和 v13 保守 Token 优化稿，但部分文件名与文档头版本不一致。
- 线上实际生效版本必须以百炼控制台为准；更新 Prompt 时应同步记录发布时间和校验问题集。
- 快速模式 System Prompt 在 `bailian.service.ts` 内维护，与百炼 App Prompt 是两条链路。

## 八、已验证的关键经验

1. `schemaName=public` 和字段映射必须明确。
2. 430 是材质，不是厚度；2B 属于表面。
3. 模型自由图表不可作为正式数据组件。
4. 多市场价格不能跨市场平均，多规格不能混成一条趋势线。
5. 图表和指标不能在 observation 尚未完整时提前生成。
6. 模型第一句话可能是查询计划，不能流式抢占 AI 结论。
7. 结构化 SSE 需要前端任务模型，不能依赖事件时序。
8. 权限和来源治理必须覆盖输入、工具结果、流式输出、最终文本和引用全链路。
9. 历史列表使用摘要 + 懒加载，避免首屏下载全部长回答。
