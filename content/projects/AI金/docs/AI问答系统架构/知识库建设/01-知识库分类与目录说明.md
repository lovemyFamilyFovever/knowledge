# AI金知识库分类与目录说明

> 最后更新：2026-08-06  
> 分类依据：`正式知识库/` 中现有 11 个正式文件

---

## 一、分类原则

本目录不按理想模型重新设计分类，而是按当前“待上传”正式文件一一对应。文件名即当前维护和上传时的识别依据，不自行增加“钢厂档案”“焊接知识”等并列正式分类。

## 二、正式知识库逐项说明

### 2.1 不锈钢标准与牌号知识库.md

- **解决的问题**：国标、行业标准、团体标准、企业标准边界；常见牌号正式名称、化学成分、力学性能和跨标准近似对应。
- **实际内容**：GB/T 20878-2024 与板、带、棒、丝、管等产品标准的区别；304、304L、316/316L、430、409L、410/420、2205/2507、201 与 J 系列；国标/美标/日标/欧标对应；标准替代关系和可信度分级。
- **典型问题**：“304 国标叫什么？”“304 和 304L 有什么区别？”“J2 是不是国标 201？”“304 冷轧板抗拉强度是多少？”
- **不应放入**：当天报价、某批货实测结果、没有绑定产品标准的万能性能值、未经核验的牌号对应关系。
- **采用 Markdown 的原因**：结论必须连同标准版本、产品形态、交货状态、例外和来源一起检索；分层标题比单行表更适合保持这些条件。

### 2.2 不锈钢板、管计算与价格折算知识库.md

- **解决的问题**：板材和卷材的名义厚度/实际厚度、负公差、理计/实计/过磅、重量和价格折算口径。
- **实际内容**：厚度差计算、材质密度参考、平板和卷板理论重量、卷长反推、卷板与开平板价格折算、板材报价构成。
- **典型问题**：“2.0 mm 实厚 1.88 mm 是多少负差？”“理计和过磅有什么区别？”“卷价如何折算为开平板参考价？”
- **不应放入**：当前原始资料未提供的管材公式；把待确认公式、密度或公差直接用于自动报价；实时加工费和市场基价。
- **采用 Markdown 的原因**：公式必须和适用范围、变量含义、例外、待确认状态及示例放在同一知识块，不能只保留一个计算表达式。

> 文件名包含“管”，但当前正文明确只覆盖板材与卷材，不补充管材计算规则。

### 2.3 采购常识知识库.md

- **解决的问题**：不锈钢采购渠道、起订规则、卷板/平板选择、加工方式、质保书、询价、公差、交期和采购风险。
- **实际内容**：钢厂直订、大型流通商和零采；一炉钢、母卷和小卷；开平、定尺、零切；质保书核对；询价信息；现货与期货；代理商/贸易商/钢厂的区别。
- **典型问题**：“3 吨 304 应找钢厂还是贸易商？”“询价要提供哪些信息？”“拆卷后质保书怎么处理？”“负公差如何影响采购？”
- **不应放入**：某商家当前库存、当天价格、即时交期承诺、特定合同未经确认的条款。
- **采用 Markdown 的原因**：采购判断需要场景、条件、风险和例外连续表达，适合按业务主题形成自包含段落和对照表。

### 2.4 不锈钢企业信息库（完整版）.xlsx

- **解决的问题**：企业名称归一化后，查询企业所在地区、业务类型、主营业务、主要产品和主要材质。
- **实际内容**：1,513 家企业记录；字段为企业名称、常用简称、其他别名/关联名称、地区、业务类型、主营业务、主要产品、主要材质、数据质量备注。
- **典型问题**：“佛山有哪些 430 相关企业？”“某企业主营什么产品？”“哪些企业做不锈钢加工？”
- **不应放入**：联系人、联系电话、实时库存、实时报价、未经量化依据的企业排名或“最大企业”结论。当前正式文件本身不含联系人和电话字段。
- **采用 Excel 的原因**：企业是一行一实体、字段统一，便于按地区、业务类型、产品和材质组合检索，也能保留少量数据质量备注。

### 2.5 钢厂名称／简称映射词典.xlsx

- **解决的问题**：将钢厂简称、旧称、中文别名和英文简称映射到标准企业名称，为后续企业、价格、产量和物流查询消歧。
- **实际内容**：36 条映射记录、23 个标准企业名称；另有说明工作表。当前“太钢”是一对多映射，必须结合上下文判断。
- **典型问题**：“东特指哪家钢厂？”“张浦的正式名称是什么？”“Harita 和哈利达镍业是不是同一主体？”
- **不应放入**：没有来源的自创简称；把一对多简称强行合并成唯一主体；实时企业经营数据。
- **采用 Excel 的原因**：一行表示一个“检索词 → 标准名称”关系，可明确记录关系类型、来源、歧义和核验状态，适合名称归一化和程序处理。

### 2.6 库存分析知识库.md

- **解决的问题**：如何分析不锈钢社会库存，而不是提供某周库存数值。
- **实际内容**：市场口径、社会库存/仓单库存区别、环比计算、总量与 200/300/400 系拆分、供应/需求归因、季节性、历史趋势、误区、输出模板和数据质量检查。
- **典型问题**：“库存下降是否代表需求变好？”“为什么价格涨了还累库？”“分析 300 系库存要看哪些变量？”
- **不应放入**：某一天或某周的具体库存、当期价格、当周盘价和临时行情结论；这些应由 SQL 或最新数据提供。
- **采用 Markdown 的原因**：库存分析是有顺序的判断方法，必须把口径、证据、条件和反例放在同一语义结构中。

### 2.7 产量与产能知识库.xlsx

- **解决的问题**：检索钢厂生产范围、月度产量、国内主流钢厂粗钢统计总量、钢厂产能历史和新增产能项目。
- **实际内容**：文档说明、钢厂生产范围、14,998 条月度产量明细、224 条国内粗钢总产量、119 条钢厂产能历史、64 条新增产能项目及 6 项待确认问题；月度数据覆盖 2022-01 至 2026-08，其中 2026-07、2026-08 标记为预估。
- **典型问题**：“某钢厂 2025 年产能是多少？”“2026 年 7 月某钢厂产量是统计还是预估？”“有哪些新增冷轧产能项目？”
- **不应放入**：库存数据、当前价格；没有时间和统计范围的“全国总量”；把预估数据说成已发生事实；自行合并“鑫海/山东鑫海/太钢鑫海”等待确认主体。
- **采用 Excel 的原因**：原始资料是钢厂×月份×产品×系别及钢厂×年份×产能的规则表，已转成长表，使每行成为带时间、状态、单位、来源的独立事实。

### 2.8 进出口政策与规则知识库.md

- **解决的问题**：进出口反倾销/贸易救济规则、适用产品和主体、计税口径、海关字段、商品编码和贸易伙伴编码。
- **实际内容**：中国进口侧措施；中国出口欧盟、美国、日本、韩国、泰国、土耳其、东南亚和墨西哥的规则；中国海关商品及国家（地区）编码；政策使用边界。
- **典型问题**：“中国出口欧盟冷轧不锈钢涉及哪些措施？”“某 HS 编码是什么产品？”“反倾销税率能否套到集团其他企业？”
- **不应放入**：逐月进出口数量、未经最新官方核验的“当前税率”、用中国海关编码推断境外税则、把初裁当终裁。
- **采用 Markdown 的原因**：政策事实必须和贸易方向、国家、产品、企业主体、生效日期、资料更新时间及例外共同出现，按章节组织能减少跨场景误用。

### 2.9 废钢废料知识库.md

- **解决的问题**：废不锈钢定义、来源、质量分类、鉴别、回收加工和加工配送准入条件。
- **实际内容**：精铸料、一级料/新料、二级料、并炉钢水、统料；韧性、颜色、磁性等鉴别方法；裁切、压块、破碎、磁选和清理。
- **典型问题**：“精铸料和统料有什么区别？”“废不锈钢常见鉴别方法有哪些？”“废旧不锈钢加工配送企业需要什么条件？”
- **不应放入**：当日废料回收价、未经检测直接判定材质、临时收购政策。
- **采用 Markdown 的原因**：分类特征、鉴别限制和加工方法需要完整描述，不能只靠一个分类代码或孤立字段。

### 2.10 长材及基础行业术语知识.md

- **解决的问题**：解释不锈钢表面、原料、冶炼工艺、贸易交割、加工、库存和物流中的基础术语及同义词。
- **实际内容**：2B、BA、8K、NO.1、NO.4、HL、SB；NPI、MHP、RKEF、HPAL、AOD；基价/基差、SS、升贴水、仓单、点价、加工费等。
- **典型问题**：“NPI 是什么？”“RKEF 和 HPAL 分别是什么工艺？”“SS 在不锈钢交易中指什么？”
- **不应放入**：实时盘面、当前升贴水、实时加工费、需要更完整专业论证的长篇工艺参数。
- **采用 Markdown 的原因**：每个术语可形成短小自包含知识块，标题就是高质量检索词，并可保留中英文简称和业务别名。

### 2.11 不锈钢钢厂物流与包送规则知识库.xlsx

- **解决的问题**：查询 13 家钢厂的正式名称/简称、发货地和核心库点、常规包送区域、到货价/自提运补规则及最低发货量等限制。
- **实际内容**：太钢、青山、溧阳瑞达、江苏德龙、北港新材、太钢鑫海、山东盛阳、宝钢德盛、张浦、酒钢、太钢天管、宁波宝新、东方特钢；数据更新时间为 2026-08-05。
- **典型问题**：“太钢无锡货从哪里提？”“青山整卷能否包送无锡？”“酒钢原厂价是否包含运费？”
- **不应放入**：未在表内确认的钢厂；超范围路线的即时运费；把历史运补值当作永久承诺；与具体订单、吨位和收货点未核实的最终物流报价。
- **采用 Excel 的原因**：每行是一家钢厂，发货地、包送区域、运费规则、限制和更新时间字段固定，适合先按简称归一化，再检索整行完整规则。

## 三、格式选择说明

当前正式文件只有 Markdown 和 Excel，没有 CSV。

| 格式 | 当前使用场景 | 选择条件 |
|---|---|---|
| Markdown | 标准、计算口径、采购、库存分析、政策、废料、术语 | 需要标题层级、解释、条件、例外、公式或多段逻辑；检索块应随标题保持语义完整 |
| Excel | 企业、名称映射、产量产能、物流规则 | 数据字段统一，一行可表达一个实体、映射或时间事实；需要保留单位、状态、来源、更新时间等列 |
| CSV | 当前无正式文件 | 仅当资料确实是单表、无多工作表说明、无复杂格式，并经百炼实测证明检索更合适时使用；不能为了转换而丢失中文、前导零、日期、备注或工作表信息 |

格式不是越统一越好。是否转换应以召回准确性和维护成本为准，转换后必须按 [05-知识库测试与效果验证](./05-知识库测试与效果验证.md) 回归验证。
