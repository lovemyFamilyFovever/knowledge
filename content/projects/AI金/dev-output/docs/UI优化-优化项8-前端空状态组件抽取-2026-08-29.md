# 前端 UI 统一 · 优化项8 · PC 前台空状态组件抽取（EmptyState）

日期：2026-08-29
范围：client PC 前台页面自研空状态（`.empty-state`）去重
目标：抽取统一 `<EmptyState>` 组件，收敛重复的自研空状态标签与样式，保留品牌视觉与交互不变。

## 改造前问题

- PC 前台各页面重复手写同一套空状态结构（`empty-state / empty-icon / empty-title / empty-desc / empty-btn`）与样式，硬编码品牌色（`#d1fae5 / #ecfdf5 / #10b981 / hsl(174…)`）。
- 经盘点，client `src/pages` 下使用自研 `.empty-state` 的页面共 6 个（58 处标签属性，含模板与样式）：
  - `PersonalPackagePage.vue`（3 处模板 + 样式）、`VipMyPackagePage.vue`（4 处模板 + 样式）、`AiStockPage.vue`、`PersonalPlazaPage.vue`、`PersonalFeedbackPage.vue`、`PersonalProfilePage.vue`、`settlement/ContractManage.vue`。
- 视觉上高度同构的是两处套餐相关页（PersonalPackage / VipMyPackage），结构完全一致，是最合理的统一抽取试点。

## 现状盘点结论

- 采用「抽取统一组件 · 先落同构试点（低风险）」策略，视觉语义不变。
- 已抽取统一组件 `EmptyState.vue`，并在**结构完全同构**的两页（PersonalPackagePage / VipMyPackagePage）率先替换。
- 其余页面（AiStockPage / PersonalPlazaPage / PersonalFeedbackPage / PersonalProfilePage / ContractManage）的空状态结构**异构**（或缺少 icon/btn、或布局不同），本轮不强改，避免过度工程；后续如需可逐个评估按组件收敛。

## 改动内容

### 新增 `client/src/components/EmptyState.vue`
- Props：`icon?: Component`（可选图标）、`title: string`、`desc?: string`、`outerStyle?: Record<string,string>`（覆盖外层边距）。
- 插槽 `default`：承载操作区（按钮 / router-link）。
- 样式：保留原两套件一致的品牌视觉——白底 + `#d1fae5` 边框 + 圆角 14px、图标 56px 圆角块（`#ecfdf5` 底 / `#10b981`）、渐变按钮（`hsl(174…)`）与 hover 动效。
- 操作区样式通过 `:deep(.empty-btn)` 提供，调用方可直接使用 `empty-btn` 类。

### 重构 `client/src/pages/PersonalPackagePage.vue`
- 免费用户态（Package 图标 + “查看 VIP 套餐”链接）、全部未解锁能力（无图标 + “查看套餐”）、共享成员空态（Users 图标 + “添加成员”）3 处均改为 `<EmptyState>…</EmptyState>`。
- 删除页面内冗余的 `.empty-state / .empty-icon / .empty-title / .empty-desc / .empty-btn` 样式（约 52 行）。

### 重构 `client/src/pages/VipMyPackagePage.vue`
- 共享成员空态（Users + “添加成员”）、购买记录空态（Receipt + “选购套餐”）、能力数据空态（仅有标题）4 处均改为 `<EmptyState>…</EmptyState>`。
- 删除页面内冗余的空状态样式（约 52 行）。
