# 前端 api 封装收敛

日期：2026-08-29
范围：`client/src/api/*` 各封装成功/失败解包与后端已统一信封对齐

## 目标

后端已统一为 `{ code, message, data }`（成功 `code===0` / 失败 `data:null`）。前端 wrapper 对**后端已统一**的模块，解包应统一为：成功=`code===0`、错误消息读 `message`，移除死亡的旧字段（`success`/`error`/`msg`）分支。对后端**尚未统一**的模块保持原兼容口径，避免误伤。

## 验证

- `npm run type:check`（server + client）通过。
- `announcement.ts`：后端统一后 `result.success` 恒 undefined、`result.code===0` 有效；错误体来自 `ok()/fail()` 的 `message`，收紧安全。
- `vip.ts`：后端 `ok()/fail()` 后 `result.success` 恒 undefined，`code===0` 判定等价，收紧安全。
- ai.ts：所有 `aiRequest` 调用点仅命中 `/api/ai/*`（已统一）与 `/api/feedback/submit`（批次1 统一），无调用 `test/auto-test`。
