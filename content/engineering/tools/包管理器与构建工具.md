# 包管理器与构建工具

## 包管理器

**一句话定义：** 包管理器是自动下载、安装、管理项目依赖的工具。

**通俗类比：** 包管理器就像一个"自动购物清单"——你列出需要什么材料，它自动去仓库取货，还处理材料之间的依赖关系。

### 各语言包管理器

| 语言 | 包管理器 | 仓库 | 配置文件 |
|------|----------|------|----------|
| JavaScript | npm/yarn/pnpm | npmjs.com | package.json |
| Python | pip/poetry/conda | PyPI | requirements.txt |
| Java | Maven/Gradle | Maven Central | pom.xml |
| Go | go modules | pkg.go.dev | go.mod |
| Rust | cargo | crates.io | Cargo.toml |
| PHP | composer | packagist.org | composer.json |

### npm深入

```json
// package.json
{
  "dependencies": {
    "express": "^4.18.0"    // ^允许更新小版本
  },
  "devDependencies": {
    "jest": "^29.0.0"       // 只在开发时使用
  }
}
```

**锁文件：**
- package-lock.json (npm)
- yarn.lock (yarn)
- 确保团队成员安装完全相同的版本

### 构建工具

**Webpack**
- 模块打包器，把散落的模块打包成文件
- 支持代码分割、Tree Shaking
- 配置复杂但功能强大

**Vite**
- 新一代构建工具，开发时利用ES Module
- 启动速度极快（不需要打包）
- 生产环境用Rollup打包

**Babel**
- JavaScript编译器
- 把新语法编译成旧浏览器能理解的代码
- 支持JSX、TypeScript等

### Make/CMake

```makefile
# Makefile示例
build:
    gcc -o main main.c utils.c

clean:
    rm -f main

test: build
    ./main --test
```

CMake是跨平台构建系统生成器，生成Makefile或VS项目。
