# 计算理论

## 计算理论概述

**一句话定义：** 计算理论研究"什么问题能被计算机解决"以及"解决它需要多少资源"。

**通俗类比：** 计算理论就像探索"哪些谜题是可以解的"——有些问题根本没有解法（不可判定），有些虽然有解法但需要的时间比宇宙寿命还长（不可行）。

### 计算模型

**图灵机（Turing Machine）**
- 一个无限长的纸带 + 一个读写头 + 一套规则
- 能模拟任何计算机算法
- 图灵可计算 = 任何计算机能计算的

**有限状态机（FSM）**
```
状态A --[输入0]--> 状态B
状态B --[输入1]--> 状态A
```
- 用于：正则表达式、词法分析、协议设计

### 问题分类

```
所有问题
├── 可计算的
│   ├── P问题：多项式时间可解（"容易"）
│   │   排序、最短路径、矩阵乘法
│   ├── NP问题：多项式时间可验证
│   │   旅行商、背包问题、SAT
│   ├── NP完全（NPC）：NP中最难的
│   │   所有NP问题都能归约到NPC
│   └── NP困难：比NPC还难
│       停机问题（不可判定）
└── 不可计算的
    停机问题：无法判断程序是否会停止
```

### P vs NP问题

- **P**：能快速求解的问题
- **NP**：能快速验证答案的问题
- **核心问题**：P = NP？（能否快速求解所有能快速验证的问题？）
- 千禧年七大数学难题之一，奖金100万美元
- 大多数计算机科学家认为 P ≠ NP

### 复杂度类

| 复杂度 | 名称 | 示例 |
|--------|------|------|
| O(1) | 常数 | 哈希查找 |
| O(log n) | 对数 | 二分查找 |
| O(n) | 线性 | 遍历数组 |
| O(n log n) | 线性对数 | 快速排序 |
| O(n²) | 平方 | 冒泡排序 |
| O(2ⁿ) | 指数 | 暴力穷举 |
| O(n!) | 阶乘 | 全排列 |
