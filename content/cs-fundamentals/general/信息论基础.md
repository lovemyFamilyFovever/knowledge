# 信息论基础

## 信息论

**一句话定义：** 信息论是用数学方法量化"信息"的理论，由香农(Shannon)在1948年创立。

**通俗类比：** 信息论回答了一个核心问题——"一条消息到底包含了多少' surprises'？"越出乎意料的消息，信息量越大。

### 信息熵（Entropy）

**定义：** 衡量不确定性的度量。

```
H(X) = -Σ p(x) × log₂ p(x)
```

- 抛硬币（正反面各50%）：熵 = 1 bit
- 抛两面都是正面的硬币：熵 = 0（没有不确定性）
- 熵越大，信息量越大

### 数据压缩

**无损压缩：**
- 霍夫曼编码：常用字符用短编码，不常用字符用长编码
- LZ77/LZ78：查找重复模式（ZIP、PNG使用）
- 可以完全恢复原始数据

**有损压缩：**
- JPEG：丢弃人眼不敏感的高频信息
- MP3：丢弃人耳听不到的频率
- 不能恢复原始数据，但压缩率更高

### 信道容量

**香农公式：**
```
C = B × log₂(1 + S/N)
```
- C: 信道最大传输速率
- B: 带宽
- S/N: 信噪比

**意义：** 任何信道都有传输极限，超过这个极限就一定会出错。

### 在编程中的应用

| 概念 | 应用 |
|------|------|
| 霍夫曼编码 | ZIP压缩、JPEG |
| 哈希 | 数据校验、去重 |
| 纠错码 | 二维码、CD/DVD、通信 |
| 熵 | 密码强度、随机数质量 |
| 信息增益 | 决策树算法 |
