# 容器运行时

## OCI规范

```
OCI Runtime Spec -> 定义容器如何运行
OCI Image Spec   -> 定义镜像格式
OCI Distribution Spec -> 定义镜像分发
```

## 容器运行时层次

```
Docker/Podman (高级运行时)
    |
containerd (容器运行时)
    |
runc (OCI运行时)
    |
Linux Kernel (cgroups + namespaces)
```

## cgroup v2

```bash
# 限制CPU
echo "50000 100000" > /sys/fs/cgroup/myapp/cpu.max  # 限制50% CPU

# 限制内存
echo "512M" > /sys/fs/cgroup/myapp/memory.max
```

## Namespace

| Namespace | 隔离内容 | 系统调用标志 |
|-----------|----------|-------------|
| PID | 进程ID | CLONE_NEWPID |
| NET | 网络栈 | CLONE_NEWNET |
| MNT | 挂载点 | CLONE_NEWNS |
| UTS | 主机名 | CLONE_NEWUTS |
| IPC | 进程间通信 | CLONE_NEWIPC |
| USER | 用户ID | CLONE_NEWUSER |
| Cgroup | cgroup根 | CLONE_NEWCGROUP |
