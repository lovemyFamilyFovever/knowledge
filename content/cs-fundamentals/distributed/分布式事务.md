# 分布式事务

## 2PC（两阶段提交）

```
协调者 -> Prepare -> 参与者A(锁定资源)
                   -> 叔与者B(锁定资源)
协调者 <- 全部OK?
         是 -> Commit -> A提交, B提交
         否 -> Abort  -> A回滚, B回滚
```

问题：同步阻塞、单点故障、数据不一致。

## TCC（Try-Confirm-Cancel）

```
Try:     预留资源(冻结库存)
Confirm: 确认(扣减冻结库存)
Cancel:  取消(释放冻结库存)
```

## Saga

```
T1 -> T2 -> T3 (成功路径)
         失败 -> C2 -> C1 (补偿路径)
```

## 本地消息表

```
1. 业务操作 + 写消息表 (同一个本地事务)
2. 后台轮询消息表，发送消息
3. 下游消费消息，处理成功后确认
```
