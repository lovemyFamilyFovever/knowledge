# 排序与搜索

> 排序是将数据按特定顺序排列的过程，搜索是在数据中找到目标的过程。不同的算法适用于不同的数据规模和场景。

---

## 冒泡排序（Bubble Sort）

### 一句话定义
反复比较相邻元素并交换，把最大的元素像气泡一样"冒"到末尾。

### 通俗类比
体育课排队，老师从头到尾两两比较，高的往后站，每轮保证最高的到最右边。

### 具体示例
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:  # 优化：没有交换说明已有序
            break
    return arr
```

### 为什么需要它
简单直观，适合小数据量或几乎有序的数据。时间复杂度 O(n²)，实际开发中很少用。

---

## 选择排序（Selection Sort）

### 一句话定义
每轮从未排序部分选出最小值，放到已排序部分的末尾。

### 通俗类比
整理书架：每次从乱书中找到最薄的那本，放到最左边，重复直到整理完。

### 具体示例
```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr
```

### 为什么需要它
交换次数少（最多 n-1 次），适合写入代价大的场景（如 Flash 存储）。时间复杂度 O(n²)。

---

## 插入排序（Insertion Sort）

### 一句话定义
从第二个元素开始，每次把当前元素插入到前面已排序部分的正确位置。

### 通俗类比
打牌时理牌：你一张一张抓牌，每抓一张就插到手中已排好的牌的合适位置。

### 具体示例
```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr
```

### 为什么需要它
小数据量时效率高，几乎有序的数据表现优异，也是其他排序算法（如快速排序）的优化手段。时间复杂度 O(n²)。

---

## 归并排序（Merge Sort）

### 一句话定义
把数组不断对半分，分别排序后再合并，核心是**分治思想**。

### 通俗类比
整理一副扑克牌：先把牌分成两半各自排好序，再像合牌一样把两堆有序牌合并成一整堆。

### 具体示例
```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(l, r):
    result = []
    i = j = 0
    while i < len(l) and j < len(r):
        if l[i] <= r[j]:
            result.append(l[i]); i += 1
        else:
            result.append(r[j]); j += 1
    result.extend(l[i:])
    result.extend(r[j:])
    return result
```

### 为什么需要它
稳定排序，时间复杂度稳定 O(n log n)，适合链表排序和外部排序（大数据文件）。

---

## 快速排序（Quick Sort）

### 一句话定义
选一个基准值（pivot），把数组分成"比 pivot 小的"和"比 pivot 大的"两部分，再递归排序。

### 通俗类比
考试按成绩分组：老师选一个分数做标准，比它低的站左边，比它高的站右边，然后两组再各自分。

### 具体示例
```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```

### 为什么需要它
实际应用中最快的通用排序算法，平均 O(n log n)，原地排序，缓存友好。但不稳定，最坏 O(n²)。

---

## 堆排序（Heap Sort）

### 一句话定义
利用最大堆的性质，每次取堆顶（最大值）放到末尾，逐步缩小堆范围完成排序。

### 通俗类比
从一堆沙子里反复找最大的石头：每次找出最大的放一边，堆越来越小，排好的越来越长。

### 具体示例
```python
def heap_sort(arr):
    n = len(arr)
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        heapify(arr, i, 0)
    return arr

def heapify(arr, n, i):
    largest = i
    l, r = 2 * i + 1, 2 * i + 2
    if l < n and arr[l] > arr[largest]:
        largest = l
    if r < n and arr[r] > arr[largest]:
        largest = r
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)
```

### 为什么需要它
原地排序、时间 O(n log n)、不需要额外空间，适合嵌入式等内存受限场景。

## 计数排序（Counting Sort）

### 一句话定义
统计每个值出现的次数，然后依次输出，适用于**值域较小的整数**。

### 通俗类比
统计班级考试成绩：先数 100 分几个、99 分几个……然后按顺序写出来。

### 具体示例
```python
def counting_sort(arr):
    if not arr:
        return arr
    min_val, max_val = min(arr), max(arr)
    count = [0] * (max_val - min_val + 1)
    for x in arr:
        count[x - min_val] += 1
    result = []
    for i, c in enumerate(count):
        result.extend([i + min_val] * c)
    return result
```

### 为什么需要它
当数据范围有限时（如年龄、分数），可以达到 O(n) 的线性时间。

---

## 桶排序（Bucket Sort）

### 一句话定义
把数据分配到若干个桶中，每个桶内单独排序，最后按桶顺序合并。

### 通俗类比
图书馆按首字母分区，每个区内的书再各自排好序。

### 具体示例
```python
def bucket_sort(arr):
    if not arr:
        return arr
    min_val, max_val = min(arr), max(arr)
    bucket_count = max_val - min_val + 1
    buckets = [[] for _ in range(bucket_count)]
    for x in arr:
        buckets[x - min_val].append(x)
    return [x for bucket in buckets for x in sorted(bucket)]
```

### 为什么需要它
均匀分布的数据可以达到 O(n) 时间，常用于浮点数排序。

---

## 基数排序（Radix Sort）

### 一句话定义
从最低位到最高位，逐位进行稳定排序（通常用计数排序），最终完成整体排序。

### 通俗类比
按邮政编码排序：先按最后一位排，再按倒数第二位排……直到第一位，最终整体有序。

### 具体示例
```python
def radix_sort(arr):
    max_val = max(arr)
    exp = 1
    while max_val // exp > 0:
        counting_sort_by_digit(arr, exp)
        exp *= 10
    return arr

def counting_sort_by_digit(arr, exp):
    output = [0] * len(arr)
    count = [0] * 10
    for x in arr:
        count[(x // exp) % 10] += 1
    for i in range(1, 10):
        count[i] += count[i - 1]
    for x in reversed(arr):
        digit = (x // exp) % 10
        output[count[digit] - 1] = x
        count[digit] -= 1
    arr[:] = output
```

### 为什么需要它
当位数不大时（如手机号、身份证号），O(nk) 可以优于 O(n log n)。

## 二分查找（Binary Search）

### 一句话定义
在**有序数组**中，每次比较中间值，把搜索范围缩小一半。

### 通俗类比
猜数字游戏：朋友说"大了"或"小了"，你每次都取中间值，迅速锁定答案。

### 具体示例
```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

# 使用示例
sorted_arr = [1, 3, 5, 7, 9, 11, 13]
print(binary_search(sorted_arr, 7))  # 输出 3
```

### 为什么需要它
查找效率从 O(n) 降到 O(log n)，是搜索算法的基石。

---

## 线性查找（Linear Search）

### 一句话定义
从头到尾逐个检查每个元素，直到找到目标或遍历完毕。

### 通俗类比
在抽屉里翻钥匙：一把一把找，直到找到为止。

### 具体示例
```python
def linear_search(arr, target):
    for i, val in enumerate(arr):
        if val == target:
            return i
    return -1
```

### 为什么需要它
不需要数据有序，实现最简单，适合小数据量或无序数据。时间 O(n)。

## 深度优先搜索（DFS）

### 一条定义
沿着一条路径尽可能深地探索，走不通再回退，用**栈**（或递归）实现。

### 通俗类比
走迷宫：一条路走到黑，撞墙了就退回来换条路。

### 具体示例
```python
def dfs(graph, node, visited=None):
    if visited is None:
        visited = set()
    visited.add(node)
    print(node, end=' ')
    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)

# 使用示例
graph = {'A': ['B', 'C'], 'B': ['A', 'D'], 'C': ['A'], 'D': ['B']}
dfs(graph, 'A')  # 输出 A B D C（顺序可能不同）
```

### 为什么需要它
路径查找、连通性检测、拓扑排序、迷宫求解。

---

## 广度优先搜索（BFS）

### 一句话定义
逐层探索，先访问所有距离起点为 1 的节点，再访问距离为 2 的，用**队列**实现。

### 通俗类比
在湖面扔石头，波纹一圈一圈向外扩散，先近后远。

### 具体示例
```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        print(node, end=' ')
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

# 使用示例
graph = {'A': ['B', 'C'], 'B': ['A', 'D'], 'C': ['A'], 'D': ['B']}
bfs(graph, 'A')  # 输出 A B C D
```

### 为什么需要它
最短路径问题（无权图）、层序遍历、社交网络的"度"计算。

### DFS vs BFS 对比
| 特性 | DFS | BFS |
|------|-----|-----|
| 数据结构 | 栈/递归 | 队列 |
| 空间 | O(h)，h 为深度 | O(w)，w 为最宽层 |
| 最短路径 | 不保证 | 无权图下保证 |
| 适用场景 | 深度探索、路径问题 | 最短路径、层序遍历 |

## A* 搜索算法

### 一句话定义
在 BFS 基础上加入**启发函数**，优先扩展 f(n) = g(n) + h(n) 最小的节点，g 是已走距离，h 是预估到终点的距离。

### 通俗类比
导航软件：不只看当前在哪，还预估到目的地的距离，优先走"看起来最近"的路。

### 具体示例
```python
import heapq

def a_star(graph, start, goal, heuristic):
    open_set = [(0, start)]
    came_from = {}
    g_score = {start: 0}

    while open_set:
        _, current = heapq.heappop(open_set)
        if current == goal:
            return reconstruct_path(came_from, current)
        for neighbor in graph[current]:
            tentative = g_score[current] + graph[current][neighbor]
            if tentative < g_score.get(neighbor, float('inf')):
                came_from[neighbor] = current
                g_score[neighbor] = tentative
                f = tentative + heuristic(neighbor, goal)
                heapq.heappush(open_set, (f, neighbor))
    return None
```

### 为什么需要它
游戏 AI 寻路、机器人导航，在保证最优的前提下大幅减少搜索空间。

## Dijkstra 算法

### 一句话定义
求**单源最短路径**，每次从未访问节点中选距离最小的，用**贪心 + 优先队列**优化。

### 通俗类比
你从家出发到各个地方：每次都先去最近的还没去过的地方，逐步扩展已知最短距离。

### 具体示例
```python
import heapq

def dijkstra(graph, start):
    dist = {node: float('inf') for node in graph}
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

### 为什么需要它
导航系统、网络路由协议（OSPF）的核心算法。不能处理负权边。

## Floyd-Warshall 算法

### 一句话定义
求**所有节点对之间的最短路径**，用三重循环动态规划，时间 O(n³)。

### 通俗类比
办公室里所有员工之间的最短沟通路径：逐个检查"经过某人中转是否更快"。

### 具体示例
```python
def floyd_warshall(n, edges):
    dist = [[float('inf')] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for u, v, w in edges:
        dist[u][v] = w

    for k in range(n):
        for i in range(n):
            for j in range(n):
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
    return dist
```

### 为什么需要它
需要查询任意两点间最短路径的场景，如交通网络、社交网络中的"六度分隔"。

## 排序算法复杂度对比表

| 算法 | 平均时间 | 最坏时间 | 最好时间 | 空间 | 稳定性 |
|------|----------|----------|----------|------|--------|
| 冒泡排序 | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | O(n log n) | O(log n) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 计数排序 | O(n+k) | O(n+k) | O(n+k) | O(k) | 稳定 |
| 桶排序 | O(n+k) | O(n²) | O(n+k) | O(n+k) | 稳定 |
| 基数排序 | O(nk) | O(nk) | O(nk) | O(n+k) | 稳定 |

> k 表示数据范围或桶的数量

## 搜索算法复杂度对比

| 算法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|----------|
| 线性查找 | O(n) | O(1) | 无序小数据 |
| 二分查找 | O(log n) | O(1) | 有序数组 |
| DFS | O(V+E) | O(V) | 路径、连通性 |
| BFS | O(V+E) | O(V) | 最短路径（无权） |
| A* | O(E) | O(V) | 启发式寻路 |
| Dijkstra | O((V+E) log V) | O(V) | 单源最短路（非负权） |
| Floyd-Warshall | O(V³) | O(V²) | 全源最短路 |

> V 为顶点数，E 为边数
