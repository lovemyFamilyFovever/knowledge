# 高级数据结构

## 红黑树（Red-Black Tree）

自平衡二叉搜索树，保证O(log n)操作。

| 性质 | 说明 |
|------|------|
| 节点颜色 | 红色或黑色 |
| 根节点 | 必须是黑色 |
| 叶子(NIL) | 必须是黑色 |
| 红节点约束 | 红节点的子节点必须黑色（无连续红） |
| 黑高相等 | 从任一节点到叶子的路径上黑色节点数相同 |

**应用场景：**
- Java TreeMap / TreeSet
- C++ std::map / std::set
- Linux CFS进程调度器
- Nginx定时器管理

## B+树

数据库索引的核心数据结构：

```
        [10 | 20 | 30]          <- 非叶子节点只存索引
       /    |    |    \
  [1,5,8] [12,15] [22,25] [31,35]  <- 叶子节点存数据
      <->    <->    <->    <->    <- 叶子节点双向链表
```

**特点：**
- 所有数据在叶子节点
- 叶子节点用链表连接（范围查询高效）
- 一棵3层B+树约可存2000万行数据
- MySQL InnoDB和PostgreSQL都使用B+树索引

## 跳表（Skip List）

```
Level 3:  1 ---------------------------------> 9
Level 2:  1 -----------> 5 -----------------> 9
Level 1:  1 ---> 3 ---> 5 ---> 7 ---> 9
```

- 平均O(log n)查找，最坏O(n)
- 实现简单，比红黑树容易
- Redis的ZSet（有序集合）使用跳表
- 支持范围查询

## 布隆过滤器（Bloom Filter）

**概率型数据结构：** 可能存在，一定不存在。

```python
class BloomFilter:
    def __init__(self, size, hash_count):
        self.size = size
        self.hash_count = hash_count
        self.bit_array = [0] * size

    def add(self, item):
        for i in range(self.hash_count):
            idx = hash(f"{item}:{i}") % self.size
            self.bit_array[idx] = 1

    def might_contain(self, item):
        for i in range(self.hash_count):
            idx = hash(f"{item}:{i}") % self.size
            if self.bit_array[idx] == 0:
                return False  # 一定不存在
        return True  # 可能存在（有误报率）
```

**应用场景：**
- 缓存穿透防护（Redis Bloom Filter）
- 爬虫URL去重
- 垃圾邮件过滤
- 区块链轻节点验证

## Trie（前缀树）

```
        root
       / | \
      a  b  c
     / \   |
    p   n   a
    |   |   |
    p   d   t
```

- 自动补全：输入前缀，快速查找所有匹配词
- 拼写检查
- IP路由表（最长前缀匹配）
- 时间复杂度：O(m)，m为字符串长度（与字典大小无关）

## 各数据结构对比

| 结构 | 查找 | 插入 | 删除 | 有序 | 适用 |
|------|------|------|------|------|------|
| 红黑树 | O(log n) | O(log n) | O(log n) | 是 | 内存有序Map |
| B+树 | O(log n) | O(log n) | O(log n) | 是 | 磁盘索引 |
| 跳表 | O(log n) | O(log n) | O(log n) | 是 | Redis ZSet |
| 哈希表 | O(1) | O(1) | O(1) | 否 | 快速查找 |
| 布隆过滤器 | O(k) | O(k) | - | 否 | 存在性判断 |
