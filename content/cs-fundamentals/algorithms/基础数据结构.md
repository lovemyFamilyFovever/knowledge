# 基础数据结构

> 数据结构是计算机中组织和存储数据的方式，选择合适的数据结构能让程序运行得更快、更省资源。

---

## 数组（Array）

### 一句话定义
数组是一块连续内存空间，按顺序存放相同类型的数据，通过下标直接访问任意元素。

### 通俗类比
想象一排带编号的储物柜，每个柜子大小一样，你知道第一个柜子的编号，就能立刻算出第 N 个柜子在哪。

### 具体示例
```python
# Python 中列表就是动态数组
arr = [10, 20, 30, 40, 50]
print(arr[2])       # 输出 30，O(1) 随机访问
arr.append(60)      # 末尾添加，均摊 O(1)
arr.insert(0, 5)    # 头部插入，O(n)，后面元素都要挪
```

### 为什么需要它
需要快速随机访问的场景，比如查表、矩阵运算、排序算法的底层存储。

### 与相关术语的对比
| 特性 | 数组 | 链表 |
|------|------|------|
| 内存 | 连续 | 分散 |
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n)（需移动元素） | O(1)（已知位置时） |

---

## 链表（Linked List）

### 一句话定义
链表由若干节点组成，每个节点存数据和指向下一个节点的指针，节点在内存中不需要连续。

### 通俗类比
像一个寻宝游戏，每个线索告诉你下一个线索藏在哪，你不需要把所有线索放在同一个抽屉里。

### 具体示例
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# 单链表：1 -> 2 -> 3 -> None
head = ListNode(1, ListNode(2, ListNode(3)))

# 双链表：多一个 prev 指针，可以双向遍历
# 循环链表：尾节点指向头节点，形成环
```

### 为什么需要它
频繁在头部/中间插入删除的场景，如实现队列、LRU 缓存、多项式加法。

### 与相关术语的对比
- **单链表**：只能向后走，省空间
- **双链表**：前后都能走，操作更灵活（Python 的 `collections.deque`）
- **循环链表**：尾连头，适合轮询调度（如操作系统的时间片轮转）

## 栈（Stack）

### 一句话定义
只能在栈顶进行插入和删除的线性结构，遵循**后进先出（LIFO）**原则。

### 通俗类比
一摞盘子，最后放上去的最先拿下来。

### 具体示例
```python
stack = []
stack.append(1)     # 入栈
stack.append(2)
stack.append(3)
print(stack.pop())  # 出栈，输出 3（后进先出）
print(stack[-1])    # 查看栈顶，输出 2
```

### 为什么需要它
函数调用栈、括号匹配、表达式求值、浏览器前进/后退、深度优先搜索。

---

## 队列（Queue）

### 一句话定义
只在队尾插入、队头删除的线性结构，遵循**先进先出（FIFO）**原则。

### 通俗类比
排队买奶茶，先排先买。

### 具体示例
```python
from collections import deque

# 普通队列
q = deque()
q.append(1)         # 入队
q.append(2)
print(q.popleft())  # 出队，输出 1

# 双端队列：两端都能进出
dq = deque()
dq.appendleft(0)    # 头部插入
dq.append(3)        # 尾部插入

# 优先队列：按优先级出队（而非入队顺序）
import heapq
pq = []
heapq.heappush(pq, (1, '低优先级'))
heapq.heappush(pq, (0, '高优先级'))
print(heapq.heappop(pq))  # 输出 (0, '高优先级')
```

### 为什么需要它
任务调度、消息队列、广度优先搜索、打印机任务排队。

---

## 哈希表（Hash Table）

### 一句话定义
通过哈希函数把键映射到数组下标，实现**近乎 O(1)** 的查找、插入和删除。

### 通俗类比
图书馆的索书号系统：你知道书名，通过索书号系统直接定位到具体书架，不用逐个书架去找。

### 具体示例
```python
# Python 字典就是哈希表
phone = {"张三": "138xxxx", "李四": "139xxxx"}
print(phone["张三"])  # O(1) 查找
phone["王五"] = "137xxxx"  # O(1) 插入

# 冲突解决演示
# 链地址法：冲突的键挂在同一个桶的链表上
# 开放寻址法：冲突后按规则找下一个空位（线性探测、二次探测）
```

### 为什么需要它
需要快速查找的场景，如数据库索引、缓存系统（Redis）、编译器符号表。

### 冲突解决方法
| 方法 | 原理 | 优缺点 |
|------|------|--------|
| 链地址法 | 同一位置用链表存多个元素 | 实现简单，负载因子高时性能下降慢 |
| 开放寻址法 | 冲突后探测下一个空位 | 缓存友好，但负载因子需控制在 0.7 以下 |

## 树（Tree）

### 一句话定义
树是层级关系的数据结构，由节点和边组成，每个节点最多有一个父节点，可以有多个子节点。

### 通俗类比
公司组织架构图，CEO 下面有几个总监，每个总监下面有几个经理，逐层往下。

### 具体示例
```python
# 二叉搜索树：左 < 根 < 右
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

#     8
#    / \
#   3   10
#  / \    \
# 1   6   14

root = TreeNode(8,
    TreeNode(3, TreeNode(1), TreeNode(6)),
    TreeNode(10, None, TreeNode(14))
)
```

### 常见树结构
| 类型 | 特点 | 应用 |
|------|------|------|
| 二叉树 | 每个节点最多两个子节点 | 表达式树、决策树 |
| 二叉搜索树 | 左 < 根 < 右，查找 O(log n) | 内存中的有序数据 |
| AVL 树 | 严格平衡（左右子树高度差 ≤ 1） | 需要频繁查找的场景 |
| 红黑树 | 近似平衡，插入/删除更快 | Java TreeMap、Linux CFS 调度器 |
| B 树 | 多叉平衡树，磁盘友好 | 数据库索引 |
| B+ 树 | 叶子节点形成链表，范围查询高效 | MySQL InnoDB 索引 |

## 堆（Heap）

### 一句话定义
堆是一棵完全二叉树，满足**最大堆**（父 ≥ 子）或**最小堆**（父 ≤ 子）性质。

### 通俗类比
比赛排名：第一名永远在最前面，你只需要知道谁是第一就行，不需要完全排序。

### 具体示例
```python
import heapq

# 最小堆
heap = [5, 3, 8, 1, 2]
heapq.heapify(heap)        # 原地建堆，O(n)
heapq.heappush(heap, 0)    # 插入元素
smallest = heapq.heappop(heap)  # 取出最小值，输出 0

# 最大堆：取负数技巧
max_heap = []
heapq.heappush(max_heap, -5)
heapq.heappush(max_heap, -3)
largest = -heapq.heappop(max_heap)  # 输出 5
```

### 为什么需要它
Top-K 问题、任务优先级调度、堆排序、求中位数。

## 图（Graph）

### 一句话定义
图由顶点和边组成，表示对象之间的关系，比树更通用（可以有环、多对多关系）。

### 通俗类比
社交网络：每个人是顶点，好友关系是边。微信好友是无向图，微博关注是有向图。

### 具体示例
```python
# 邻接矩阵表示（适合稠密图）
#   A B C
# A 0 1 1
# B 1 0 1
# C 1 1 0
adj_matrix = [[0,1,1],[1,0,1],[1,1,0]]

# 邻接表表示（适合稀疏图）
adj_list = {
    'A': ['B', 'C'],
    'B': ['A', 'C'],
    'C': ['A', 'B']
}

# 加权图：边上带权重（距离、费用等）
```

### 为什么需要它
导航系统（最短路径）、社交网络分析、网络路由、任务依赖关系。

## Trie（前缀树/字典树）

### 一句话定义
一种专门处理字符串的树形结构，相同前缀的字符串共享父节点，查找前缀匹配只需 O(m)（m 为前缀长度）。

### 通俗类比
字典的翻页逻辑：先翻到以 "C" 开头的区域，再翻到 "Ch"，再翻到 "Cha"，逐步缩小范围。

### 具体示例
```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.is_end = True

    def search(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return node.is_end

trie = Trie()
trie.insert("apple")
trie.insert("app")
print(trie.search("app"))    # True
print(trie.search("apl"))    # False
```

### 为什么需要它
自动补全、拼写检查、IP 路由表、单词游戏（如 Scrabble）。

## 数据结构总览对比表

| 数据结构 | 随机访问 | 查找 | 插入 | 删除 | 适用场景 |
|----------|----------|------|------|------|----------|
| 数组 | O(1) | O(n) | O(n) | O(n) | 读多写少 |
| 链表 | O(n) | O(n) | O(1)* | O(1)* | 频繁增删 |
| 栈 | — | O(n) | O(1) | O(1) | LIFO 场景 |
| 队列 | — | O(n) | O(1) | O(1) | FIFO 场景 |
| 哈希表 | — | O(1) | O(1) | O(1) | 快速查找 |
| 二叉搜索树 | — | O(log n) | O(log n) | O(log n) | 有序数据 |
| 红黑树 | — | O(log n) | O(log n) | O(log n) | 通用有序容器 |
| B+ 树 | — | O(log n) | O(log n) | O(log n) | 数据库/文件系统 |
| 堆 | — | O(1) 取最值 | O(log n) | O(log n) | 优先级/Top-K |
| 图 | — | 取决于算法 | — | — | 关系建模 |
| Trie | — | O(m) | O(m) | O(m) | 字符串前缀匹配 |

> *O(1) 指已知插入/删除位置的情况
