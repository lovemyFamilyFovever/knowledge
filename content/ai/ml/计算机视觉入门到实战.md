# 计算机视觉入门到实战：从像素到智能的全面指南

计算机视觉是人工智能领域最激动人心、应用最广泛的分支之一，旨在让机器“看懂”并理解图像和视频中的世界。本指南将带你系统性地探索这一领域的核心知识与技术栈。

## 1. 图像基础：数字视觉的基石

在让机器“看懂”图像之前，我们必须先了解图像在计算机中是如何表示的。

### 1.1 像素与图像表示
- **像素**：图像是由无数个微小的点（像素）组成的网格。每个像素携带颜色信息。
- **数字图像**：是一个多维数组（矩阵）。对于彩色图像，通常是三维张量 `(高度, 宽度, 通道)`。
- **位深度**：决定每个通道可表示的颜色级别。8位最常见，可表示0-255共256个级别。

### 1.2 色彩空间：描述颜色的数学模型
色彩空间是用一组数值（通常为三个）来表示颜色的系统。

- **RGB（红绿蓝）**：最常用，基于光的三原色混合。在OpenCV中，顺序为BGR。
- **HSV/HSL（色相、饱和度、亮度/明度）**：更符合人类对颜色的感知。对光照变化不敏感，在颜色分割、目标跟踪等任务中常用。
- **灰度图**：单通道，只包含亮度信息，是许多CV算法（如边缘检测）的输入。

**代码示例：色彩空间转换**
```python
import cv2
import numpy as np

# 读取图像（OpenCV默认读取为BGR格式）
img_bgr = cv2.imread(‘image.jpg‘)
# 转换为RGB
img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)
# 转换为HSV
img_hsv = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2HSV)
# 转换为灰度图
img_gray = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2GRAY)

# 显示（注意：OpenCV的imshow也期望BGR格式）
cv2.imshow(‘Original BGR‘, img_bgr)
cv2.imshow(‘Grayscale‘, img_gray)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 1.3 图像变换
对图像进行数学变换可以提取关键特征或方便处理。

- **几何变换**：缩放、旋转、平移、仿射变换、透视变换。用于数据增强、图像校正。
- **空间域变换**：直接在像素矩阵上操作。
    - **点运算**：直方图均衡化（增强对比度）、阈值化（二值化）。
    - **邻域运算**：卷积（图像滤波、模糊、锐化）。
- **频率域变换**：将图像从空间域（像素位置）转换到频率域（频率分量）。
    - **傅里叶变换**：分析图像的频率成分。低频对应平坦区域，高频对应边缘和噪声。可用于设计滤波器（如低通滤波去噪，高通滤波增强边缘）。

**代码示例：直方图均衡化与傅里叶变换**
```python
import cv2
import numpy as np
from matplotlib import pyplot as plt

img = cv2.imread(‘image.jpg‘, 0) # 以灰度模式读取

# 1. 直方图均衡化（空间域，增强对比度）
equ = cv2.equalizeHist(img)

# 2. 傅里叶变换（频率域）
f_transform = np.fft.fft2(img)
f_shift = np.fft.fftshift(f_transform) # 将零频率移到中心
magnitude_spectrum = 20 * np.log(np.abs(f_shift) + 1) # 计算幅度谱

# 可视化
plt.figure(figsize=(12, 4))
plt.subplot(131), plt.imshow(img, cmap=‘gray‘), plt.title(‘Original‘)
plt.subplot(132), plt.imshow(equ, cmap=‘gray‘), plt.title(‘Equalized‘)
plt.subplot(133), plt.imshow(magnitude_spectrum, cmap=‘gray‘), plt.title(‘Fourier Spectrum‘)
plt.show()
```

**小结**：图像在计算机中是数字矩阵，通过不同的色彩空间和数学变换，我们可以从不同角度（几何、光强、频率）分析和处理它。

## 2. 经典CV算法：深度学习之前的智慧

在深度学习浪潮之前，基于数学和统计的经典算法统治了CV领域，它们思想深刻，至今仍有重要应用。

### 2.1 边缘检测
边缘是图像中像素强度发生剧烈变化的区域，是物体轮廓的重要线索。

- **Sobel算子**：计算图像在水平和垂直方向的一阶导数，对噪声有一定抑制作用。
- **Canny边缘检测**：多阶段算法，被认为是性能最优的边缘检测器。包括：高斯滤波、计算梯度、非极大值抑制、双阈值检测和边缘连接。

**代码示例：Canny边缘检测**
```python
import cv2
import numpy as np

img = cv2.imread(‘building.jpg‘, 0)
# 应用Canny边缘检测，设定低阈值和高阈值
edges = cv2.Canny(img, 100, 200)

plt.figure(figsize=(10, 5))
plt.subplot(121), plt.imshow(img, cmap=‘gray‘), plt.title(‘Original‘)
plt.subplot(122), plt.imshow(edges, cmap=‘gray‘), plt.title(‘Canny Edges‘)
plt.show()
```

### 2.2 特征提取与描述
特征点是图像中具有独特性和稳定性的点，如角点、斑点。它们用于图像匹配、物体识别、三维重建。

- **Harris角点检测**：通过分析图像窗口在不同方向移动时的能量变化来寻找角点。
- **SIFT**：尺度不变特征变换。对尺度、旋转、光照变化具有极强鲁棒性。包括：尺度空间极值检测、关键点定位、方向分配、关键点描述。
- **ORB**：FAST角点检测+BRIEF描述子。速度快，免费，是SIFT/SURF的实用替代品。

**代码示例：使用ORB进行特征匹配**
```python
import cv2
import numpy as np

img1 = cv2.imread(‘box.png‘, 0) # 查询图像
img2 = cv2.imread(‘box_in_scene.png‘, 0) # 训练（场景）图像

# 创建ORB检测器
orb = cv2.ORB_create()
# 寻找关键点和描述符
kp1, des1 = orb.detectAndCompute(img1, None)
kp2, des2 = orb.detectAndCompute(img2, None)

# 创建BFMatcher匹配器，使用汉明距离
bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
matches = bf.match(des1, des2)
# 按距离排序
matches = sorted(matches, key=lambda x: x.distance)

# 绘制前50个匹配点
img3 = cv2.drawMatches(img1, kp1, img2, kp2, matches[:50], None, flags=2)
plt.imshow(img3), plt.show()
```

### 2.3 光流
光流描述了图像序列中像素随时间运动的速度和方向。是视频分析的基础。

- **稀疏光流**：跟踪图像中一组特定的特征点（如角点）的运动。代表算法：Lucas-Kanade。
- **稠密光流**：计算图像中每一个像素的运动矢量。代表算法：Farneback。

**代码示例：Lucas-Kanade稀疏光流跟踪**
```python
import cv2
import numpy as np

cap = cv2.VideoCapture(‘slow_traffic_small.mp4‘)
# 读取第一帧
ret, old_frame = cap.read()
old_gray = cv2.cvtColor(old_frame, cv2.COLOR_BGR2GRAY)

# 选择初始特征点（这里手动选一个）
p0 = np.array([[300, 200]], dtype=np.float32).reshape(-1, 1, 2)

# 设置光流参数
lk_params = dict(winSize=(15, 15), maxLevel=2,
                 criteria=(cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 10, 0.03))

while True:
    ret, frame = cap.read()
    if not ret: break
    frame_gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    
    # 计算光流
    p1, st, err = cv2.calcOpticalFlowPyrLK(old_gray, frame_gray, p0, None, **lk_params)
    
    # 选择好的跟踪点
    good_new = p1[st == 1]
    good_old = p0[st == 1]
    
    # 绘制跟踪轨迹
    for i, (new, old) in enumerate(zip(good_new, good_old)):
        a, b = new.ravel()
        c, d = old.ravel()
        frame = cv2.circle(frame, (a, b), 5, (0, 0, 255), -1)
    
    cv2.imshow(‘Frame‘, frame)
    k = cv2.waitKey(30) & 0xff
    if k == 27: break
    
    # 更新上一帧和特征点
    old_gray = frame_gray.copy()
    p0 = good_new.reshape(-1, 1, 2)

cap.release()
cv2.destroyAllWindows()
```

**小结**：经典算法依靠精巧的数学设计，在特定问题上高效、可解释性强。理解它们有助于把握CV的核心思想，并为理解深度学习模型打下基础。

## 3. CNN架构演进：从识别到理解的革命

卷积神经网络是计算机视觉进入深度学习时代的标志。其架构的演进史，就是一部追求更高性能、更深理解能力的历史。

1.  **LeNet (1998)**：CNN的开山鼻祖。用于手写数字识别。结构简单：卷积层->池化层->全连接层。证明了CNN在视觉任务上的潜力。
2.  **AlexNet (2012)**：在ImageNet竞赛上以巨大优势夺冠，开启了深度学习的热潮。创新：使用ReLU激活函数、Dropout、数据增强、GPU训练。更深的网络（5卷积层+3全连接层）。
3.  **VGGNet (2014)**：探索网络深度的极限。使用3x3的小卷积核堆叠（如VGG16有16层），证明网络深度对性能至关重要。结构规整，易于理解。
4.  **ResNet (2015)**：解决了深层网络（如152层）的**梯度消失/爆炸**和**退化**问题。核心创新：**残差学习块**。通过“短路连接”，让网络学习输入与输出之间的残差函数，而不是直接学习映射。这使得训练数百甚至上千层的网络成为可能。
5.  **YOLO (2016)**：将目标检测从“分类”范式转变为**回归**范式。单次前向传播即可同时预测多个物体的位置和类别。开创了**单阶段目标检测**的先河，实现了速度的巨大飞跃。
6.  **Vision Transformer (ViT, 2020)**：将NLP中强大的Transformer架构迁移到视觉领域。将图像分割成固定大小的图块，将其序列化，然后使用多头自注意力机制进行全局建模。在超大数据集上预训练后，性能可超越CNN，证明了Transformer在视觉领域的巨大潜力。

**核心思想演进**：从**局部感受野**（CNN的卷积核）到**全局注意力**（Transformer的自注意力），从**层级特征提取**（CNN的堆叠层）到**全局关系建模**（Transformer）。

**代码示例：PyTorch实现一个简化版的ResNet残差块**
```python
import torch
import torch.nn as nn

class BasicBlock(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super(BasicBlock, self).__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, kernel_size=3, stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU(inplace=True)
        self.conv2 = nn.Conv2d(out_channels, out_channels, kernel_size=3, stride=1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, kernel_size=1, stride=stride, bias=False),
                nn.BatchNorm2d(out_channels)
            )

    def forward(self, x):
        identity = x
        
        out = self.conv1(x)
        out = self.bn1(out)
        out = self.relu(out)
        
        out = self.conv2(out)
        out = self.bn2(out)
        
        out += self.shortcut(identity) # 关键：残差连接
        out = self.relu(out)
        return out

# 测试
block = BasicBlock(64, 64)
x = torch.randn(1, 64, 32, 32)
out = block(x)
print(f‘Input shape: {x.shape}, Output shape: {out.shape}‘)
```

**小结**：CNN架构的演进，核心围绕着**深度**、**宽度**、**多尺度特征**、**计算效率**和**全局建模能力**展开。ResNet的残差思想是深度学习的里程碑。

## 4. 目标检测：定位与识别

目标检测任务是在图像中找出所有感兴趣的目标（物体），给出其类别和位置（通常用边界框表示）。

### 4.1 两阶段检测器
先生成可能包含物体的“候选区域”，再对这些区域进行分类和精修。精度高，速度相对较慢。
- **R-CNN**：开创性工作。使用选择性搜索生成候选框，用CNN（如AlexNet）对每个候选框提取特征，再用SVM分类。步骤繁琐，速度极慢。
- **Fast R-CNN**：引入**感兴趣区域池化**，让整张图共享卷积计算，大幅提高速度。但候选框生成仍依赖外部算法。
- **Faster R-CNN**：革命性改进。用**区域提议网络**代替选择性搜索，将候选框生成也纳入神经网络，实现了真正的端到端训练。速度和精度达到当时最佳平衡。

### 4.2 单阶段检测器
直接在整张图上进行回归和分类，一步到位。速度快，适合实时应用。
- **YOLO系列**：将检测视为回归问题。将图像划分为网格，每个网格单元直接预测边界框和类别概率。从YOLOv1到YOLOv8/v9，在速度和精度上不断突破极限，统治了工业应用。
- **SSD**：结合了YOLO的回归思想和Faster R-CNN的锚框机制。在多个不同尺度的特征图上进行检测，以适应不同大小的物体。

**代码示例：使用Ultralytics YOLOv8进行目标检测（最简易实战）**
```python
# 安装：pip install ultralytics
from ultralytics import YOLO

# 1. 加载预训练模型（首次运行会自动下载）
model = YOLO(‘yolov8n.pt‘) # nano版本，最快
# model = YOLO(‘yolov8s.pt‘) # small版本，更准

# 2. 在图像上进行预测
results = model(‘https://ultralytics.com/images/bus.jpg‘) # 也可以是本地路径

# 3. 解析结果
for result in results:
    boxes = result.boxes # 边界框
    for box in boxes:
        cls = int(box.cls) # 类别索引
        conf = float(box.conf) # 置信度
        xyxy = box.xyxy[0].tolist() # 边界框坐标 [x1, y1, x2, y2]
        print(f‘Class: {result.names[cls]}, Confidence: {conf:.2f}, Box: {xyxy}‘)

# 4. 可视化结果（会保存为runs/detect/predict/bus.jpg）
result_img = results[0].plot()
cv2.imshow(‘YOLOv8 Detection‘, result_img)
cv2.waitKey(0)
```

**小结**：两阶段追求精度，单阶段追求速度。YOLO系列的成功证明了在强大特征提取网络支持下，单阶段模型可以同时实现高速度和高精度。

## 5. 图像分割：像素级的精细理解

图像分割是将图像中的每个像素分类到特定的类别，是比目标检测更精细的任务。

- **语义分割**：将图像中所有像素分类为预定义的类别（如：人、车、天空、道路），不区分同一类别的不同实例。
    - **经典模型**：FCN（全卷积网络）、U-Net（用于医学图像分割，编码器-解码器结构+跳跃连接）、DeepLab系列（使用空洞卷积和CRF后处理）。
- **实例分割**：在语义分割的基础上，进一步区分同一类别的不同实例（如：图片中的第一个人、第二个人）。
    - **经典模型**：Mask R-CNN。在Faster R-CNN基础上增加一个并行的FCN分支，为每个检测到的物体预测一个二值掩码。
- **全景分割**：语义分割和实例分割的统一。对图像中的每一个像素都进行实例级的标注（属于某个物体实例，或属于某个“stuff”类别如天空、草地）。
    - **经典模型**：Panoptic FPN。

**代码示例：使用PyTorch和预训练的Mask R-CNN进行实例分割**
```python
import torch
import torchvision
from torchvision.models.detection import maskrcnn_resnet50_fpn
from PIL import Image
import matplotlib.pyplot as plt
import numpy as np

# 加载预训练的Mask R-CNN模型
model = maskrcnn_resnet50_fpn(pretrained=True)
model.eval() # 设置为评估模式

# 读取并预处理图像
image = Image.open(‘street.jpg‘)
image_tensor = torchvision.transforms.functional.to_tensor(image)

# 推理
with torch.no_grad():
    predictions = model([image_tensor])

# 解析预测结果
boxes = predictions[0][‘boxes‘].numpy()
labels = predictions[0][‘labels‘].numpy()
scores = predictions[0][‘scores‘].numpy()
masks = predictions[0][‘masks‘].numpy() # [N, 1, H, W]

# 可视化
fig, ax = plt.subplots(1, figsize=(12, 9))
ax.imshow(image)

# 设置置信度阈值
threshold = 0.8
for i in range(len(scores)):
    if scores[i] > threshold:
        # 绘制边界框
        x1, y1, x2, y2 = boxes[i]
        rect = plt.Rectangle((x1, y1), x2-x1, y2-y1, fill=False, edgecolor=‘red‘, linewidth=2)
        ax.add_patch(rect)
        # 绘制掩码（透明覆盖）
        mask = masks[i, 0] > 0.5 # 二值化掩码
        masked_image = np.zeros_like(image)
        masked_image[mask] = np.array([255, 0, 0]) # 红色掩码
        ax.imshow(masked_image, alpha=0.3)
        ax.text(x1, y1-5, f‘Class {labels[i]}: {scores[i]:.2f}‘, color=‘white‘, fontsize=10, backgroundcolor=‘red‘)

plt.axis(‘off‘)
plt.show()
```

**小结**：分割是对图像理解的深化，从“有什么”到“在哪里、是什么形状”。U-Net、Mask R-CNN等模型在各领域（自动驾驶、医学、遥感）有广泛应用。

## 6. 图像生成：创造新的视觉世界

图像生成模型旨在学习数据的分布，并生成新的、逼真的图像样本。

- **生成对抗网络**：由一个生成器和一个判别器组成，通过对抗训练不断提升生成图像的质量。
    - **基础架构**：生成器从随机噪声生成图像，判别器判断图像是真实的还是生成的。两者博弈，最终使生成器能产出以假乱真的图像。
    - **挑战**：训练不稳定、模式坍塌（生成器只能生成有限种类的样本）。
    - **进展**：DCGAN（使用CNN）、条件GAN（可控制生成内容的类别）、StyleGAN（可精细控制生成图像的风格和属性）、CycleGAN（实现无配对数据的风格迁移）。
- **扩散模型**：当前最强大的生成模型，其效果已超越GAN。
    - **核心思想**：包含两个过程：1）**前向过程**：逐步向图像添加高斯噪声，直到变成纯噪声；2）**反向过程**：学习一个神经网络，从纯噪声中逐步去噪，还原出清晰的图像。
    - **优势**：训练稳定、生成质量极高、多样性好。
    - **代表**：DDPM、Stable Diffusion（结合了潜在扩散模型和文本条件）。

**代码示例：使用PyTorch实现一个简化的GAN生成手写数字**
```python
import torch
import torch.nn as nn
import torchvision
import torchvision.transforms as transforms
from torchvision.utils import save_image

# 超参数
latent_dim = 100
img_size = 28
channels = 1
batch_size = 64
epochs = 200

# 生成器
class Generator(nn.Module):
    def __init__(self):
        super(Generator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(latent_dim, 128),
            nn.LeakyReLU(0.2),
            nn.Linear(128, 256),
            nn.BatchNorm1d(256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 512),
            nn.BatchNorm1d(512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, img_size * img_size * channels),
            nn.Tanh() # 输出像素值归一化到[-1, 1]
        )

    def forward(self, z):
        img = self.model(z)
        img = img.view(img.size(0), channels, img_size, img_size)
        return img

# 判别器
class Discriminator(nn.Module):
    def __init__(self):
        super(Discriminator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(img_size * img_size * channels, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 1),
            nn.Sigmoid() # 输出真/假概率
        )

    def forward(self, img):
        img_flat = img.view(img.size(0), -1)
        validity = self.model(img_flat)
        return validity

# 加载MNIST数据集
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize([0.5], [0.5]) # 归一化到[-1, 1]
])
dataset = torchvision.datasets.MNIST(root=‘./data‘, train=True, download=True, transform=transform)
dataloader = torch.utils.data.DataLoader(dataset, batch_size=batch_size, shuffle=True)

# 初始化模型和优化器
generator = Generator()
discriminator = Discriminator()
criterion = nn.BCELoss()
optimizer_G = torch.optim.Adam(generator.parameters(), lr=0.0002, betas=(0.5, 0.999))
optimizer_D = torch.optim.Adam(discriminator.parameters(), lr=0.0002, betas=(0.5, 0.999))

# 训练循环
for epoch in range(epochs):
    for i, (imgs, _) in enumerate(dataloader):
        # 真实和虚假标签
        real = torch.ones(imgs.size(0), 1)
        fake = torch.zeros(imgs.size(0), 1)
        
        # 训练判别器
        z = torch.randn(imgs.size(0), latent_dim)
        gen_imgs = generator(z)
        real_loss = criterion(discriminator(imgs), real)
        fake_loss = criterion(discriminator(gen_imgs.detach()), fake)
        d_loss = (real_loss + fake_loss) / 2
        optimizer_D.zero_grad()
        d_loss.backward()
        optimizer_D.step()
        
        # 训练生成器
        z = torch.randn(imgs.size(0), latent_dim)
        gen_imgs = generator(z)
        g_loss = criterion(discriminator(gen_imgs), real) # 希望判别器认为生成的图是真的
        optimizer_G.zero_grad()
        g_loss.backward()
        optimizer_G.step()
        
        if i % 400 == 0:
            print(f‘[Epoch {epoch}/{epochs}] [Batch {i}/{len(dataloader)}] [D loss: {d_loss.item():.4f}] [G loss: {g_loss.item():.4f}]‘)
    
    # 每轮保存一些生成的样本
    if epoch % 10 == 0:
        save_image(gen_imgs.data[:25], f‘images/{epoch}.png‘, nrow=5, normalize=True)

print(‘Training finished.‘)
```

**小结**：GAN通过对抗训练开创了生成建模，但挑战较大。扩散模型通过巧妙的“加噪-去噪”框架，实现了更稳定、更高质量的生成，是当前Sora、Stable Diffusion等爆款应用的核心。

## 7. OCR文字识别：让机器读懂文字

光学字符识别是从图像中识别并提取文字信息的技术，通常分为两个主要步骤：

1.  **文本检测**：在图像中定位文本行或单词的区域。常用方法有基于回归的（如EAST）、基于分割的（如DBNet）。
2.  **文本识别**：对检测到的文本区域进行字符识别。常用序列模型（如CRNN: CNN+RNN+CTC Loss， Transformer-based）。

**实战案例**：使用PaddleOCR（一个强大且易用的开源OCR工具库）进行中英文识别。
```python
# 安装：pip install paddlepaddle paddleocr
from paddleocr import PaddleOCR, draw_ocr

# 初始化OCR模型（第一次运行会下载模型）
ocr = PaddleOCR(use_angle_cls=True, lang=‘ch‘) # 使用方向分类器，中文模型

# 识别图像
img_path = ‘chinese_doc.jpg‘
result = ocr.ocr(img_path, cls=True)

# 解析结果
for line in result[0]:
    box = line[0] # 文本框坐标
    text = line[1][0] # 识别出的文字
    confidence = line[1][1] # 置信度
    print(f‘Text: {text}, Confidence: {confidence:.4f}‘)

# 可视化
image = Image.open(img_path).convert(‘RGB‘)
boxes = [line[0] for line in result[0]]
txts = [line[1][0] for line in result[0]]
scores = [line[1][1] for line in result[0]]
im_show = draw_ocr(image, boxes, txts, scores, font_path=‘simfang.ttf‘) # 需要中文字体
im_show = Image.fromarray(im_show)
im_show.save(‘result.jpg‘)
```

**小结**：现代OCR系统是检测+识别的流水线，深度学习（特别是序列到序列模型和Transformer）极大地提升了其准确率和鲁棒性。

## 8. 人脸识别：生物特征识别的核心

人脸识别是一个系统性的工程，通常包含以下子任务：

1.  **人脸检测**：从图像中找出所有人脸的位置。
2.  **人脸对齐**：将检测到的人脸通过仿射变换摆正，消除姿态和表情的影响。
3.  **人脸特征提取**：使用深度CNN将人脸图像映射到一个低维的、具有区分性的特征向量（嵌入）。这个向量应该满足：同一个人的人脸向量距离近，不同人的向量距离远。经典模型如FaceNet（使用三元组损失）、ArcFace（使用加性角度间隔损失）。
4.  **人脸比对/验证**：计算两个人脸特征向量之间的距离（如余弦相似度），与阈值比较，判断是否为同一个人。

**代码示例**：使用`dlib`和`face_recognition`库进行基础人脸识别（需提前下载模型文件）。
```python
import face_recognition
import cv2

# 加载已知人脸图像并编码
known_image = face_recognition.load_image_file(‘known_person.jpg‘)
known_encoding = face_recognition.face_encodings(known_image)[0]

# 加载待识别图像
unknown_image = face_recognition.load_image_file(‘unknown_group.jpg‘)
unknown_encodings = face_recognition.face_encodings(unknown_image)

# 找到人脸位置
face_locations = face_recognition.face_locations(unknown_image)

# 比较人脸
for (top, right, bottom, left), face_encoding in zip(face_locations, unknown_encodings):
    matches = face_recognition.compare_faces([known_encoding], face_encoding, tolerance=0.6)
    name = “Unknown”
    if True in matches:
        name = “Known Person”
    
    # 绘制边框和标签
    cv2.rectangle(unknown_image, (left, top), (right, bottom), (0, 0, 255), 2)
    cv2.putText(unknown_image, name, (left, top - 10), cv2.FONT_HERSHEY_SIMPLEX, 0.75, (0, 0, 255), 2)

# 显示结果（需转换颜色空间）
cv2.imshow(‘Result‘, cv2.cvtColor(unknown_image, cv2.COLOR_RGB2BGR))
cv2.waitKey(0)
```

**小结**：人脸识别的性能核心在于人脸特征提取模型的质量。如今，人脸识别已广泛应用于安防、支付、门禁等领域。
