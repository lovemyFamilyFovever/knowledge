# 图神经网络

图 = 节点 + 边。社交网络、分子结构、知识图谱都是图数据。

## 消息传递范式

```python
for layer in range(num_layers):
    for node in graph.nodes:
        messages = [aggregate(node_feat, neighbor_feat) for neighbor in graph.neighbors(node)]
        node_feat = update(node_feat, aggregate_all(messages))
```

## GNN模型对比

| 模型 | 聚合方式 | 特点 |
|------|----------|------|
| GCN | 归一化求和 | 简单高效 |
| GAT | 注意力加权 | 自适应权重 |
| GraphSAGE | 采样+聚合 | 归纳学习 |
| GIN | 求和+MLP | 表达力最强 |
