# 向量数据库技术

## 概述

**向量数据库**专门用于存储和检索高维向量，是RAG和AI Agent的基础设施。

## 工作原理

```
原始数据 → Embedding模型 → 高维向量 → 向量数据库存储
                                           ↓
用户查询 → Embedding → 查询向量 → 相似度搜索 → 返回最相似文档
```

## 主流向量数据库对比

| 特性 | Pinecone | Weaviate | Milvus | Chroma | Qdrant |
|------|----------|----------|--------|--------|--------|
| **部署** | 云托管 | 云+自托管 | 云+自托管 | 本地嵌入式 | 云+自托管 |
| **开源** | 否 | 是 | 是 | 是 | 是 |
| **混合搜索** | 支持 | 支持 | 支持 | 有限 | 支持 |
| **适用规模** | 中大型 | 中大型 | 超大型 | 小型/原型 | 中大型 |
| **学习曲线** | 低 | 中 | 高 | 很低 | 低 |

## Chroma：轻量级入门

```python
import chromadb

client = chromadb.PersistentClient(path='./chroma_db')
collection = client.create_collection('my_docs')

collection.add(
    documents=['向量数据库存储嵌入向量', 'RAG是检索增强生成'],
    metadatas=[{'source':'wiki'}, {'source':'blog'}],
    ids=['doc1', 'doc2'],
)

results = collection.query(query_texts=['什么是向量存储？'], n_results=2)
```

## Milvus：大规模生产

```python
from pymilvus import connections, Collection, FieldSchema, CollectionSchema, DataType

connections.connect('default', host='localhost', port='19530')

fields = [
    FieldSchema(name='id', dtype=DataType.INT64, is_primary=True, auto_id=True),
    FieldSchema(name='title', dtype=DataType.VARCHAR, max_length=200),
    FieldSchema(name='embedding', dtype=DataType.FLOAT_VECTOR, dim=1536),
]
schema = CollectionSchema(fields)
collection = Collection('documents', schema)

collection.create_index('embedding', {
    'metric_type': 'COSINE', 'index_type': 'HNSW',
    'params': {'M': 16, 'efConstruction': 256}
})
collection.load()
results = collection.search(
    data=[query_embedding], anns_field='embedding',
    param={'metric_type':'COSINE', 'params':{'ef':64}},
    limit=10, output_fields=['title'],
)
```

## 索引算法对比

| 算法 | 原理 | 速度 | 精确度 | 内存 | 适用场景 |
|------|------|------|--------|------|--------|
| **FLAT** | 暴力搜索 | 慢 | 100% | 高 | 小数据集 |
| **IVF** | 倒排索引 | 快 | 高 | 中 | 中等规模 |
| **HNSW** | 层次可导航小世界 | 很快 | 很高 | 高 | 通用推荐 |
| **ANNOY** | 随机投影树 | 快 | 中 | 低 | 内存受限 |
| **PQ** | 乘积量化 | 很快 | 中 | 很低 | 超大规模 |

## 最佳实践

1. 原型用Chroma，生产用Milvus/Qdrant，托管用Pinecone
2. chunk_size 500-1000，overlap 50-200
3. 通用场景用HNSW，超大规模用IVF+PQ
4. 结合向量搜索和BM25关键词搜索提高效果

## 小结

向量数据库是AI应用的基础设施。选择需考虑数据规模、部署方式、成本和团队技术栈。
