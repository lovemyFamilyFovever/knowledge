# 大模型预训练技术

## 数据处理Pipeline

```
URL过滤 -> 语言检测 -> 去重(MinHash) -> 质量过滤 -> PII脱敏 -> 混合采样
```

## 分布式训练方案

| 方案 | 原理 | 显存 | 通信 |
|------|------|------|------|
| DP | 数据切分，参数广播 | 高 | AllReduce |
| DDP | 每个进程独立模型 | 中 | Ring-AllReduce |
| FSDP | 参数也切分 | 低 | AllGather + ReduceScatter |

### 3D并行

```
数据并行(DP) x 张量并行(TP) x 流水线并行(PP)
```

```python
# PyTorch混合精度训练
scaler = torch.cuda.amp.GradScaler()
with torch.cuda.amp.autocast():
    output = model(input)
    loss = criterion(output, target)
scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()
```
