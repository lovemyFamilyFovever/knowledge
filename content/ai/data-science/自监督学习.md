# 自监督学习

无需人工标注，从数据本身构造监督信号。

## SimCLR

```python
x_i, x_j = augment(image), augment(image)
z_i, z_j = encoder(x_i), encoder(x_j)
loss = -log(exp(sim(z_i,z_j)/tau) / sum(exp(sim(z_i,z_k)/tau)))
```
