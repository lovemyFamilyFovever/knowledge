# 大数据技术栈

## 大数据生态系统

**一句话定义：** 大数据技术是处理海量（TB/PB级）数据的工具和方法的总称。

**通俗类比：** 如果传统数据库是一个小仓库，大数据技术就是一个超级物流系统——能处理每天数百万包裹的入库、分拣、运输和查询。

### 大数据4V特征

| 特征 | 英文 | 说明 |
|------|------|------|
| 大量 | Volume | TB/PB级数据 |
| 高速 | Velocity | 实时或近实时处理 |
| 多样 | Variety | 结构化/半结构化/非结构化 |
| 价值 | Value | 从数据中挖掘价值 |

### 核心组件

| 组件 | 工具 | 功能 |
|------|------|------|
| 分布式存储 | HDFS, S3 | 海量文件存储 |
| 计算引擎 | Spark, MapReduce | 分布式计算 |
| 流处理 | Kafka, Flink | 实时数据流 |
| 数据仓库 | Hive, ClickHouse | OLAP分析 |
| 调度 | Airflow, DolphinScheduler | 任务编排 |
| 查询引擎 | Presto, Trino | 交互式查询 |

### Hadoop生态

```
Hadoop
├── HDFS（分布式文件系统）
├── MapReduce（分布式计算框架）
├── YARN（资源管理）
└── 生态系统
    ├── Hive（SQL查询）
    ├── HBase（NoSQL数据库）
    ├── ZooKeeper（协调服务）
    └── Sqoop（数据导入导出）
```

### Spark

```python
# PySpark示例
from pyspark.sql import SparkSession

spark = SparkSession.builder.appName("demo").getOrCreate()
df = spark.read.parquet("hdfs://data/users/")

# 比MapReduce快10-100倍（内存计算）
result = df.groupBy("department")            .agg(avg("salary").alias("avg_salary"))            .orderBy("avg_salary", ascending=False)
result.show()
```

### 数据湖 vs 数据仓库

| 特性 | 数据仓库 | 数据湖 |
|------|----------|--------|
| 数据格式 | 结构化 | 任意格式 |
| Schema | 写入前定义 | 写入后可变 |
| 成本 | 较高 | 较低（用对象存储）|
| 适用 | BI分析 | 机器学习+分析 |
| 代表 | Snowflake, Redshift | Delta Lake, Iceberg |
